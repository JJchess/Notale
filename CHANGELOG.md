# Changelog

## 0.1.0

First public source release of Notale's five TypeScript projects:

- `notale-format`: shared native project and page runtime contract.
- `notale-editor` and `notale-editor-frontend`: document editing, revision storage, interactive presentation, and local deployment.
- `notale-ts` and `notale-viewer`: lecture generation, progress inspection, and preview.
- 51 selected mini samples and 40 original lecture-page style references.

The local starter uses a development identity. Public deployments must provide authentication and authorization, a private preview-signing secret, and an independent slide-content origin. See the root README and editor integration guide for setup and current feature coverage.
