# page-05 · 梯度：不只知道错多少,还知道往哪改 · **120 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `GRADIENT · 梯度` |
| 主标题 | 损失不但告诉你错多少,还告诉你往哪个方向改权重会变小 |
| 收束句 | 这个"往哪个方向、改多少"的信号,就叫梯度——它是从损失里算出来的,不是猜的 |
| 下一问 | 知道了方向,那一步该走多大? |

## 知识结构：process

关系不变量：左侧的权重读数框、右侧的梯度箭头与新损失读数框必须共享同一条时间轴——点一次「单步」按钮,三者同步刷新到下一时刻的值,不能有的先变有的后变。梯度箭头的粗细/方向必须直接对应权重将要移动的方向和幅度,不能只是装饰。

共享原语：用 `.k-process` 骨架串联「当前权重→算梯度→挪一步→新权重」四个阶段,`.step` 之间用 `.arw` 连接,箭头方向即因果方向;每个阶段用 `.panel` 装当前数值(权重、损失、梯度),数值用 `.big.num` 等宽字体呈现,保证逐位可比。梯度箭头本身用强调色 `--accent` 画在权重读数框旁,粗细编码梯度绝对值大小。

## 表征形式

交互，读数框 + 手绘风格梯度箭头，由原生 DOM/SVG 实现（不需要坐标轴系统，用不到 ECharts；单步离散状态用 SVG 箭头足够直观，Konva 命中检测在此无必要）。左栏：权重、偏置、损失的 `.panel` 读数组；右栏：一支粗细可变的 SVG 箭头贴在权重数值旁指示梯度方向，箭头上方浮出梯度数值（等宽字体）。每次点击「单步」调用一次计算接口，读数与箭头同步刷新，无需坐标轴或图例。

## 主工作流

build-interaction ← 需要设计"单步梯度下降"这一个可重复触发、状态清晰前进的最小交互单元，核心难点是把梯度值到箭头视觉（方向+粗细）的映射做对，而非画图表

## 不许碰

不出现学习率滑块或"步子大小可调"的说法——学习率的大小效应留给 p06/p08 专门处理，本页学习率固定用默认值不做变量。不展示连续多步的轨迹曲线，那是 p09 的责任；本页只做"点一次、看一步"。

## 单步演示的数值设定

| 项目 | 值 | 说明 |
|---|---|---|
| 任务 | AND 逻辑门 | 输入取 `Lec.K.LOGIC_INPUTS` 中的 `[1, 0]`，目标 `Lec.K.AND_TARGETS[2] = 0` |
| 激活函数 | sigmoid | 与 p02–p04 保持同一神经元设定 |
| 初始权重 | w = 0.60, b = -0.10 | 页面固定初值，保证首次点击效果明显（初始预测偏离目标） |
| 学习率 | 0.1 | 取 `Lec.K.LR_DEFAULT`，本页不做变量，仅作固定参数使用 |
| 单步计算入口 | `Lec.P.neuronGradientStep([1,0], 0, [0.6], -0.1, 'sigmoid', 0.1)` | 返回 `{z, a, loss, gradW, gradB, newWeights, newBias}` |
| 梯度含义提示 | `Lec.K.SIGMOID_DERIV_MAX = 0.25` | 用于旁注说明"sigmoid 在 0 附近梯度最大,饱和区梯度会变小" |

## 交互

学习者只操纵一个按钮「算一步」（无滑块、无拖拽范围）。点击后：左栏当前权重 `w`、偏置 `b`、当前损失依次高亮刷新为计算结果中的 `newWeights`、`newBias` 和新一轮 `loss`；右栏箭头先于数值 0.3 秒短暂闪烁指示本次梯度的方向（正/负）和粗细（`|gradW|` 越大箭头越粗），再触发权重数值的变化，让学生看清"先有方向、后有移动"的因果顺序。可重复点击，每次都基于上一次结果继续单步计算，观察损失逐渐从暖变凉（复用温度计式换算，读数框描边颜色随损失值在 `--accent` 到 `--ink` 之间过渡）。提供「复位」按钮一键回到初始权重 0.60 / 偏置 -0.10，状态可逆。不设"正确答案"，本页只呈现"算一次"这个动作本身。

## 核对

- 首次点击前：`w=0.6, b=-0.1`，输入 `[1,0]`，`z = 0.6×1 + 0×(-0.1)... ` 按 `neuronForward([1,0],[0.6],-0.1,'sigmoid')` 计算，期望 `a ≈ 0.622`，`loss(mse目标0) ≈ 0.387`。
- 单步后：期望 `gradW` 为正值（因为输出偏大、需要把 w 往下调才能让对输入1的预测更接近0），`newWeights` 应小于 0.6；箭头应指向"减小"方向。
- 连续点击 3 次后：损失应单调下降（若出现震荡或上升，说明学习率或梯度符号接反，需排查 `updateParams` 的减法方向）。
