# page-13 · 责任回传 · **140 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `BACKPROPAGATION` |
| 主标题 | 反向传播：把输出层的错，按权重比例分给前一层 |
| 收束句 | 每条连接的权重越大，它分到的责任就越多——反向传播不是新魔法，是按比例分账 |
| 下一问 | 每一层拿到自己的责任之后，怎么用它算出自己该往哪个方向调？ |

## 知识结构：process

**关系不变量**：输出层的一个误差读数框必须与前一层的多个神经元同时可见、同一竖直流向；从输出误差出发的箭头必须落在前一层每个神经元上，箭头粗细必须与该连接权重的大小成比例，让"谁分得多"一眼可辨。

**共享原语**：用 `.k-process` 的 `.step` + `.arw` 串联"输出误差 → 按权重分配 → 前一层各自的责任"三步，`.arw` 的粗细直接编码权重绝对值；左栏用圆圈神经元（母题3）画两层小网络（输入层可省略，只画隐藏层→输出层），右栏用多个 `.panel` 读数框（母题1）列出前一层每个神经元分到的责任数值，责任箭头用红铅笔色强调（母题2的手绘箭头变体），权重大小以线宽区分，不引入矩阵记号。

## 表征形式

交互式 Canvas：左栏画一个两层小网络（隐藏层2–3个神经元圆圈 + 输出层1个神经元圆圈），右栏是责任分配读数框列表。点击输出层神经元，触发一次误差回传动画：输出误差数值从输出层圆圈弹出，沿手绘箭头流向隐藏层各神经元，箭头粗细按权重绝对值渲染，落点处的读数框同步显示分到的责任数值。用 Konva 实现（命中检测点击 + 箭头自定义绘制 + 数值动画三者都需要），不用 ECharts（非常规图表编码）。

## 主工作流

build-interaction ← 点击触发误差回传动画，并让箭头粗细与责任数值实时对应权重比例，是本页核心难点

## 责任分配示例

| 隐藏层神经元 | 连接到输出层的权重 | 输出层误差 | 分到的责任（权重×误差，归一化前） |
|---|---|---|---|
| h1 | 0.8 | 0.6 | 0.48 |
| h2 | -0.3 | 0.6 | -0.18 |
| h3 | 1.2 | 0.6 | 0.72 |

计算入口：`Lec.P.backpropTwoLayer(input, target, layer1, layer2)` 返回的 `gradW2` 即对应本层到输出的权重梯度分量，页面展示时取其与输出误差项的乘积关系，用于生成上表中"分到的责任"一列的实时数值（点击后按当前权重重新计算，不是固定表格）。

## 交互

学习者点击右侧输出层神经元圆圈（唯一可点对象），触发一次误差回传动画：默认权重取上表三值（0.8 / -0.3 / 1.2），默认输出误差取 0.6。点击后：输出误差读数框以红铅笔色高亮弹出，三条手绘箭头依次（错开 150ms）从输出层流向三个隐藏层神经元，箭头粗细固定映射权重绝对值（映射范围 1–6px），到达后对应责任读数框数值从 0 滚动到最终值，正负号用读数框角落小三角表示（不依赖颜色，呼应负值语义）。可重复点击任意次数，每次都是同一次确定性回放，不设"正确答案"，只用于建立"权重越大、箭头越粗、分到责任越多"的直觉。无需复位按钮，再次点击即重新播放。

## 动效

三条责任箭头从输出层圆圈出发，依次错开 150ms 流向三个隐藏层神经元，单条箭头动画时长 400ms，采用手绘曲线路径（非直线），到达终点后读数框数字用 300ms 从 0 滚动至目标值；全部动效在 1.2 秒内完成，不循环、不自动重播。
