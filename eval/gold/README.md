# GOLD 金样本库

人类高水平讲义。它们**定义**"丰满""多样""正确"长什么样——是成对比较的天花板锚点、
时长模型的经验数据源、BORROW 取经轮的逆向工程对象（`methodology/EVAL.md` §1.3）。

## 目录约定

```
eval/gold/
  <slug>/                  # 一份金样本一个目录，如 ds-linear-60min/
    source/                # 原始文件（PDF/PPT/HTML/图片，原样保存）
    CARD.md                # 注解卡（必填，模板见下）
```

## 注解卡模板（CARD.md）

```markdown
# <标题>
- 来源：<课程/作者/机构，获取日期>
- 授课时长：<分钟>；页数：<n>；≈ <分钟/页>
- 结构：<章节划分，每章页数>
- 每页字数分布：<粗略统计：中位数/最大/最小>
- 图文比：<有图形元素（图/表/代码/公式演算）的页占比>
- 习题/互动密度：<每隔几页出现一次练习或提问>
- 好在哪的三个具体机制（写"机制"不写"感觉"，供取经轮逆向）：
  1. <例：每个新概念先给反例再给定义，页面左栏固定放"陷阱"侧注>
  2. <…>
  3. <…>
- 版权说明：<仅内部评测参照使用 / 其他>
```

## 从首批样本得出的时长模型数据点（供 T-LONG 拟合起步）

两份清华讲义都是**整章合并讲义**（150–200 min），不是单次 60 min 课——拟合 minutes→pages 时不能拿
"114 页/讲"当 60 分钟的目标页数。已提取的经验值：
- 配速（讲授型 16:9 课件）：概念/图示页 ~1.3 min、代码页 ~2–2.5 min（逐行走读）、证明推导页 ~2.5–3.5 min、
  分隔页 ~5–15 s、课堂练习页 ~5 min → **60 min ≈ 35–45 页（其中分隔/路标 ~15%）**
- 有效独立画面/总页比：0.73–0.97（该系列用"空间换时间轴"的反动画手法，不灌页数）
- 正文页字数：中位 110–180 字符，>300 字即"文字墙"（两份样本中均为公认缺陷段）
- 图文比（正文页）：~85%
- 显式练习密度：金样本本身严重不足（每 45–48 页一次）——**此项以缺点入卡，生成器应高于金样本**

**纪律**：无注解卡的样本不算入库——没有"好在哪的三个机制"，样本只是装饰。
