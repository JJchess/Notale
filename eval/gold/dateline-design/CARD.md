# Dateline v0.9（人文社科 PPT 模板自演示）

- 来源：Jonathan W. Wilson, Blue Book Diaries（2023-05-06），CC BY-NC 4.0；owner 提供（2026-08-08）
- 类型：**设计参考（design reference），不是内容参考**——9 页里没有真实讲授内容（占位示例+版权页），信息密度接近零。评"看起来是不是专业设计系统"用它，评"讲得对不对"不能用它
- 页数：9（p1 空白封面模板 → p2 封面 → p3 价值主张 → p4–7 四种主力版式各演示一次 → p8/9 致谢）；7 页有演讲者备注（含逐图溯源）
- 授课时长 / 字数分布 / 习题密度：不适用（模板自演示）
- 视觉系统（可直接提取为 theme token）：
  - 色板：深灰底（bg2@50%≈#202020）+ 双主色 **酒红 #990033 / 靛紫 #332288** + 中灰 #4D4D4D（副标题）+ 浅灰 #A6A6A6（图片来源）——三级信息层次：白/主色 > 中灰 > 浅灰；**全部走 schemeClr 无一处硬编码**，换主题色即整套换肤
  - 字体：Atkinson Hyperlegible（盲人协会无障碍字体，8 个字体文件嵌入包内保真）；字号阶梯 **12/28/36/40/48/54/60pt**——跨度 5 倍、无中间灰色地带
  - 版式语言：**满版出血图 + 边缘信息带**——图像 100% 铺满，文字退到四边（底部标签带/右上日期徽章/右侧中线来源/底部脚注），中央 60% 永远留给图像。与清华讲义的"左文右图分栏"是两种各自自洽的版式语言
- 好在哪的三个具体机制（生成器可模仿粒度）：
  1. **元数据槽位化**：每个 layout 硬编码 Title/Subheading/Credit(右侧中线 12pt)/Date(右上角)/Footnote 五槽位——"这是什么、什么年代、哪来的"靠**版式强制**而非提醒保证不遗漏。→ 可作"传统 PPT 风格档"的版式白名单与出处 lint
  2. **用占位符尺寸做行为约束（设计即规训）**：引文占位符限死尺寸+大默认字号，物理上阻止贴过长引文；List 版式的示例文字本身就是"Don't overuse / Don't read from slides / Keep points short"。→ 生成器的约束应长在版式里，不是长在提示词里
  3. **无障碍是技术决策不是口号**："High readability"有四处具体兑现——无障碍字体、链接强制白色（避免深底低对比蓝）、果断字阶、schemeClr 全覆盖。→ 每条设计主张必须能指到具体实现，否则不写
  - 附加：**素材合规链条完整**（每图 notes 记作者/年代/藏馆/公有领域声明/永久链接）——可直接抄为 media 溯源规范
- 明显偏差（入库必记）：9 页是"每页一种版式"的展示柜，**页间无叙事连续性**；若当作页面分布样本喂生成器，会诱导"每页换版式"的错误风格——真实 30 页 Dateline 演示应是同一两种版式重复 20 遍
- 配对使用：与清华讲义构成互补两极——清华 = 内容结构与推进机制的金标准；Dateline = 视觉系统与元数据规范的金标准
