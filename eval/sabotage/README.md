# SABOTAGE 破坏样本库（掺沙抽查样本 / canary）

故意做坏的页/deck。**唯一用途**：掺进每个评审批次里，抽查判官（LLM/VLM judge）和硬门有没有在偷懒——
judge 放过任何一个 → 本批全部分数作废、该轮降级人工验收（见 `methodology/PREP.md` §4）。

**禁止**任何其他用途（尤其禁止当负样本训练/调 prompt——样本一旦被生成侧"学会"就失效）。

## 目录约定

```
eval/sabotage/
  <slug>/
    doc.json | page.html     # 坏产物本体
    DEFECT.md                # 缺陷说明：类型、位置、正确答案（judge 不可见，仅比对用）
```

## 缺陷类型清单（每类至少保有 2 个在役样本）

| 类型 | 例 | 应被哪层抓住 |
|---|---|---|
| 布局溢出/裁切 | 纵向溢出 300px 被 overflow:hidden 吃掉 | G0（render-check F/I） |
| 错误公式/数字 | T=2π√(g/L)；百分比求和 112% | T1/T2 |
| 展示输出 ≠ 实际输出 | 代码块旁标注的运行结果是编的 | G2 |
| 占位/腐坏文本 | "undefined"、"此处填入…" | G0（断言 H） |
| 图文不符 | 文字说三层树，图画的是四层 | T4 盲测 VQA |
| 叙事不变量违反 | 两幕水位线明显不等高却宣称等重 | T4 |
| 无据事实 | 编造的引文/统计，无 evidenceId | G4 |
| 前后矛盾 | 第 3 页定义的符号第 9 页换义 | G3 / notation ledger |
| 伪多样 | 同题两份仅换主色，版式序列全同 | 风格指纹 |

## 换血纪律

CALIBRATE 轮（每 ~8 轮）淘汰已被 judge 稳定识破的样本、补新样本；换血记录写入 `eval/LEDGER.md`。
