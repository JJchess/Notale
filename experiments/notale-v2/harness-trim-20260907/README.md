人工看图尚未通过内容质量验收：精简版代码样页三项准确率均为 100%，结论却写“超过单决策树（100%）”；树形区域也存在大面积空容器。旧版代码样页对比数据更有区分度，但同样有装饰网格和大面积留白。这是本次生成的实际问题，不能被“运行检查通过”覆盖，也不足以凭一次抽样归因到某句删改。未手工修饰样页来美化对照结果。

原始结果及最终截图分别保存在 [baseline](baseline/) 和 [candidate](candidate/)。精简版首轮实验的 `reads: []` 是上述相对路径记账问题，不代表没有读取 reference / sample；修复已由单测覆盖，该旧结果保留原样。
