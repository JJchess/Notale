Adaptation: a rectangular New York-area crop requested from WGS84 bounds
[-74.35, 40.50, -73.65, 41.08]. NoData cells and values rounding below one
resident were omitted; remaining source values were rounded to whole residents.
The packaged JSON names its schema and retains a stable source-grid ID for every
cell. Scene height is population / 2500 logical Three.js units, with no random or
hand-authored heights. Its continuous color also reads the population field.
