# Page contract

The learner should understand that a network image persists by being copied into many
contexts because five stable image identities visibly multiply, hand off to five technical
screenshots, and converge on the same low-resolution portrait.

| Decision | Answer |
|---|---|
| Audience | Readers who already recognize memes, screenshots, and pixels |
| Page job | Trace an authored image-propagation sequence |
| Decisive evidence | Stable image identities move from five thumbnails to 25 copies, five technical contexts, and one 84×84 portrait |
| Entities | Five seed images, 20 propagated copies, five screenshots, one pixelated portrait, seven short claims |
| Representation | Directed authored state sequence in one fixed evidence field |
| Reading path | Begin with five bordered images, follow their outward multiplication, then the mint-bordered context handoff, and resolve at the portrait |
| Motion role | Preserve identity through movement, growth, fading, overlap, delayed entry, and convergence |
| Signature | Five context screenshots shrink to colored pixel-like anchors while the portrait enlarges beneath them |
| First view | Five complete 200×200 thumbnails with distinct 8px borders and a concise propagation claim |

The informative initial state is `five`; the focus states are `sprout`, `exchange`, and
`gather`; the decisive state is `contexts`; the settled final state is `portrait`.
Reduced motion preserves all seven states and removes interpolation.
