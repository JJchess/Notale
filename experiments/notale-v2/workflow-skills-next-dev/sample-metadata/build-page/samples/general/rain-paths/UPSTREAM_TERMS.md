# Upstream terms audit

The upstream repository has no standalone license file. Its README permits the resource to be integrated into or built upon for personal and commercial projects, while prohibiting redistribution, republication, resale, or pluginized resale of the resource as-is. It also asks integrators to consider the licenses of bundled libraries, scripts, and images.

This sample follows that boundary by reimplementing the mechanism, substantially changing the subject and page, excluding all upstream photographs and code, and retaining a direct source link and pinned revision in `SOURCE.md`.

The local chassis supplies Three.js under its existing library manifest and license. The ten files in `pages/media/` are original SVG image assets created for this sample and contain no runtime behavior.
