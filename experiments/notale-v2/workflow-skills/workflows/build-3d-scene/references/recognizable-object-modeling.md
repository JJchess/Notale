# Recognizable Object Modeling

Use this reference for a named artifact, body, vehicle, instrument, or piece of equipment. The model may be simplified, but it must retain the construction cues that identify the subject.

## Block out identity first

1. List three to five recognition anchors: overall proportion, dominant opening, joint pattern, appendage, support, tool, or carried module.
2. Build a low-detail silhouette from those anchors before creating internal layers or animation.
3. Use a three-quarter camera that reveals both profile and depth. Let the object occupy roughly 55–75% of its canvas region.
4. Render at thumbnail size with labels hidden. If it reads as a slab, capsule, coffin, or unrelated generic object, revise the blockout.

Primitive geometry is acceptable; an uncomposed primitive is not. Combine boxes, cylinders, spheres, lathed profiles, curves, and grouped parts so joints and negative spaces explain how the object is built.

## Preserve construction logic

- Parent parts according to the real assembly: torso to shoulder, shoulder to arm, chassis to axle, instrument body to controls.
- Keep bilateral parts paired and proportionally aligned.
- Model gaps where separation matters: neck rings, arm clearance, wheel wells, handles, windows, joints, and interfaces.
- Use edge bands, seams, thickness, and contact shadows to clarify adjoining shells without turning every part into a different color.
- Add one scale cue when unfamiliar size would distort interpretation.

## Build cutaway and exploded states

- Start every layer from the same host silhouette. A layered suit, hull, or enclosure should read as nested shells around one object, not as unrelated parallel boards.
- Explode along a meaningful axis or local surface normal while preserving order, orientation, and approximate thickness.
- Keep an outline, ghost shell, connector, or shared centerline so the learner can reconstruct the compact object.
- Reveal the selected part's function in DOM text; do not rely on color alone.
- Provide Compact, Exploded, and one useful Section or Side preset when they expose distinct relationships.

## Inspect before delivery

- Compare front, three-quarter, side, and exploded views for missing parts and impossible intersections.
- Check that the compact state looks like the named object before it looks like a layer diagram.
- Confirm selected highlights do not erase material form.
- Test at the actual page crop and at one-quarter scale; titles must not be required to recognize the subject.
