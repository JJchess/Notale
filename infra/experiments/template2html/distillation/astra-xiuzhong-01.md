## 素材与生图

本轮 Code mode `additional_tools` 中确实声明 `image_gen__imagegen`，见快照 `capabilities.json`。
这补上了正式运行前仅靠模拟探针无法确认的能力声明。

**实际生图/编辑调用为零。** `output/assets/generation.json` 记录全部素材可提取，
两个 EMF 标记由路径确定性转换为 SVG，无需生成位图。
本轮可提炼“何时不必生图”的判断，不能提炼“参考图→生成指令→生成结果→采用/修改”的真实调用回路。
后续需找本身有素材补全或编辑需求的任务，保留能力、指令、原生调用 ID、结果和采用位置；
不能为补数据而强迫这个模板生成本来已有的校标。

## 不可直接固化的模板特例

`output/tools/build.py` 和 runtime 中存在：固定 7/15 枚举、固定 `slideMaster1/theme1`、
1280×720 与 9525 EMU/px、`image1.jpeg/image3.png/image7.png` 的语义命名、校名匹配、
按页面分组手写内容区坐标。shape 解析只覆盖有限类型，母版静态装饰没有通用处理。
有限 EMF record 解析也不等同通用 EMF converter。

因此可提炼的是数据字段、源对象关联、插槽机制和修正判断；
不能把此文件复制为“任意 PPTX→HTML”引擎。
从 WQY TTC 派生字体并移除 `vhea/vmtx` 是本字体的解决方案，保留原字体、脚本与证据，
不对后续所有字体执行同样修改。
