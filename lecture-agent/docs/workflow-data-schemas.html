lecture-agent Workflow 数据传输全景

入口链:scripts/generate.py → app/generate.py::run_generation → engine/pipeline.py::generate_lecture(llm, …) → 返回 GenerateResult。

数据主干:一个可变的 doc: dict 从 plan 阶段的「占位骨架」逐阶段被原地填充,最终成为完整 LectureDoc;旁路(side-channel)字典按 scene/block id 携带规划元数据(page_briefs、placeholder_specs、planned_skeleton 等);仅在浏览器验证时序列化为 JSON。

LectureDoc / Scene / Layout / VisualSystem / Asset 内核 schema

LectureDoc

  • "schemaVersion": "1.0" 模式版本
  • "id" / "title" / "language": 文档 id / 标题 / 语言
  • "theme": str? 主题(15 个候选,见 schema/enums.py)
  • "visualSystem": 编译后的视觉系统(见下)
  • "assets": {assetId: Asset} 媒体资源表
  • "tutor": {suggestions?, kb:[{pattern, answer, flags?}]} 助教
  • "scenes": [Scene] 页面列表

Scene

  • "id" / "kind": 场景 id / hero|content|quiz|statement|section
  • "notes": str 演讲者讲稿
  • "eyebrow" / "headline" / "lead" / "transition" / "autoAnimate" / "background": 文案与转场、场景背景 {assetId, purpose, fit, overlay, overlayStrength, safeZone}
  • "layout": 布局(见下)
  • "compositionFamily": 构图族
  • "blocks": [Block] 内容块(24 种联合类型,见下节)

Layout

  • "kind": flow|index|split|compose|full|artboard|frames
  • "columns" / "rows" / "gap" / "titleRegion" / "areas": 栅格布局参数(titleRegion:{col,row,align,justify,maxWidth,z};areas:[{blockIds,col,row,role,z,align,justify,bleed,clip,styleRole}])
  • "canvas": {width:1280, height:720} 帧模式画布
  • "titleFrame": {x,y,w,h,z} 绝对标题帧
  • "frames": [{blockId, x,y,w,h,z, role, clip}] 绝对块帧
  • "plannedFrameSignature": 规划帧签名(用于漂移检测)

VisualSystem

  • "palette": {background, surface, surfaceAlt, ink, muted, accent, accent2, line} 色板

  • "shape": {radius, borderWidth, shadow} 形状语言
