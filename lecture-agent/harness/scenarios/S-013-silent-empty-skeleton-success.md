id: S-013
title: A truncated/malformed skeleton response can parse as valid JSON with no scenes and still be logged as a clean success
kind: observed
context: domain/planning.py::plan_lecture parses the planner's response via parse_json and returns whatever JSON object results, with no check that the skeleton actually has a non-empty "scenes" list; agent/orchestrator.py::generate_lecture then does doc.get("scenes", []) (defaults to empty, does not crash) and the fan-out loop simply has zero placeholders to process.
trigger: During the genre_routing real-run concurrency batch (llm=glm_5_2, 5x concurrent), topic "存在主义哲学入门" produced a saved deck containing only {id, title, subtitle: "从", schemaVersion, language} — no "scenes" key, no theme, subtitle itself visibly truncated mid-word ("从"). Only one log line exists for this topic ([plan] 课题: ...); no block-completion lines, no "N 页 / 丢弃 M / 错误 K" summary line followed. Yet the ExperimentRecord for this run shows errors: [], warnings: [], dropped: [] — a fully "clean" result.
bad_outcome: A batch experiment (or any generation call) can silently produce a near-empty artifact that looks, by every automated signal (errors/warnings/dropped counts), identical to a successful run with real content — there is no automated way to distinguish "genuinely simple 0-page deck" from "the model's response got cut off and we never noticed." This directly cost the genre_routing prose group one of its four data points without any visible failure signal — it was only caught by manually opening the saved JSON and noticing the empty scenes list and the truncated subtitle.
why_it_matters: This is a different, more insidious failure mode than S-011 (which at least crashes loudly). Here nothing crashes, nothing warns — a shape gap (skeleton must have a non-empty scenes list, each with content) silently degrades into "trust the JSON parsed, therefore it's fine." The same root gap as S-011 (JSON-syntax validity is being treated as skeleton-shape validity) but manifesting as silent data loss instead of a crash.
