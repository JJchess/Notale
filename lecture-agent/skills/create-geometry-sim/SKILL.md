# Create a geometry simulation plan

Prefer named SVG geometry. Require a mathematical-to-screen coordinate mapping, explicit constraints/invariants, a visible manipulation result, and verification cases that exercise the mapping and boundaries. Use canvas only for genuinely dense fields or particles.

Describe the evidence in `interactionBrief`; do not write final HTML.
