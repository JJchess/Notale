# Create purposeful lecture media

Treat media as one optional design capability. Never add it by quota and never use it to replace a more exact diagram, chart, simulation, runnable, formula, or native shape.

Before requesting an asset, declare:

1. `purpose`: `evidence`, `explanatory`, `narrative`, or `atmospheric`.
2. `placement`: `illustration`, `decoration`, or `background`.
3. `subject`, `relationshipToContent`, `fidelity`, and whether the asset is required.
4. A source strategy appropriate to the purpose.

Read [references/usage-modes.md](references/usage-modes.md) for purpose and placement rules. Read [references/source-selection.md](references/source-selection.md) before choosing search or generation. Read [references/prompt-guidelines.md](references/prompt-guidelines.md) when generating an asset. Apply [references/quality-gates.md](references/quality-gates.md) before accepting it.

Keep critical Chinese text, formulas, data, labels, and citations out of generated pixels. Use a text-free visual layer and let the LectureDoc viewer render those elements natively.
