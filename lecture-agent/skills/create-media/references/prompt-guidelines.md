# Generation prompt guidelines

Describe the subject, teaching relationship, medium, composition, focal point, negative space, aspect ratio, palette relationship to the Design DNA, and intended placement.

For backgrounds, reserve a named safe zone for native text and request no letters, labels, watermarks, logos, charts, formulas, UI, or pseudo-writing. Specify the overlay-friendly value range.

For explanatory illustrations, make the visual correspondence explicit without embedding labels. Ask for separable objects and clean silhouettes when native annotations will be overlaid.

For decoration, request a restrained motif or texture with low semantic salience. Do not produce a second focal point.
