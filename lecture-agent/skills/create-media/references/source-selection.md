# Source selection

- Search first for documentary evidence, named people, places, historical objects, artworks, specimens, instruments, and observable real-world phenomena.
- Generate first for explanatory metaphors, unified illustration systems, abstract concepts, textures, decorative motifs, and atmospheric backgrounds.
- Never present a generated approximation as documentary evidence. If generation is used for an evidence purpose, label it as a reconstruction or illustration.
- Prefer supplied assets over search, and search over generation when exact identity matters.
- If a required asset cannot be obtained, fail visibly so the planner can choose a different design. Optional decoration may be dropped without replacing it.
- Preserve source, attribution, query or prompt, dimensions, and focal point in the asset manifest when available.
