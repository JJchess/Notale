# Longitudinal scene playbooks

Use these playbooks when a deck matches the knowledge forms, not merely the example subject.

## Discrete algorithm and data structure

- Evidence spine: fixed invariant → state transition → implementation → execution/debugging → transfer.
- Capability sequence: diagram for one stable structure; state-sim for insertion, rotation, or traversal; runnable for implementation and test evidence.
- Composition rhythm: annotated-specimen → interactive-stage → proof-equation-stage or data-evidence → interactive-stage → comparison.
- Visual language: technical grid, restrained state colors, stable node geometry, monospaced implementation surface. Reserve the brightest accent for the changed state.
- Good: the learner can step a rotation, see the changed edge, reset, then run the corresponding implementation.
- Bad: several tiny static tree diagrams, decorative code screenshots, or explanation cards that shrink the sim.

## Biological mechanism and scientific observation

- Evidence spine: faithful appearance/context → labeled structures → causal mechanism → comparison/prediction → synthesis.
- Capability sequence: evidence media for appearance; native labels or diagram for relations; state/model sim only when the learner must manipulate a causal process.
- Composition rhythm: annotated-specimen → process-path → comparison → interactive-stage when required → research-figure.
- Visual language: scientific fidelity, organic but controlled shapes, low-noise surfaces, explicit scale and provenance. Keep labels native.
- Good: a sourced specimen anchors callouts while a separate mechanism diagram owns causal arrows.
- Bad: generated pseudo-science presented as evidence or atmospheric art replacing the mechanism.

## Research or business evidence report

- Evidence spine: decision question → method/data → principal result → uncertainty/limitation → implication.
- Capability sequence: chart/table for quantitative evidence, research-figure for dense inspection, media only for documented context or narrative framing.
- Composition rhythm: poster or focal-object opener → data-evidence → comparison → research-figure → restrained synthesis poster.
- Visual language: editorial hierarchy, strong numeric contrast, consistent axes and sources, compact but readable method rails.
- Good: the principal mark, conclusion, source, and limitation share one inspection field.
- Bad: invented precision, repeated KPI-card grids, or a full-bleed photo that pushes methods off the page.
