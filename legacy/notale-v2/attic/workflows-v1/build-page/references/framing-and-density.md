# Framing and density recipes

Read this reference when the page feels loose, crowded, or over-carded. Add a frame only when it communicates grouping, measurement, selection, or physical containment.

## Space budget

With the standard `56px 28px` stage inset, compose inside `1488x844`:

```text
┌ title / question: 72–112 high ──────────────────────────────┐
│                                                             │
│ primary relationship: flexible, largest uninterrupted field │
│                                                             │
├ instrument / evidence / hint: 44–180 when needed ───────────┤
```

Treat these ranges as diagnostics, not mandatory templates. Let the teaching relationship determine whether the lower/side region exists.

## Choose the lightest grouping device

Use the first device that makes the grouping clear:

1. proximity and alignment;
2. negative space;
3. a shared baseline, bracket, or divider;
4. one quiet panel fill;
5. an outlined or material surface only when it represents an instrument or object.

Do not wrap a filled card inside another filled card. Do not use equal rounded rectangles as the default answer to unrelated content.

## Structural framing

- Draw container guides only on true layout edges and keep them behind content.
- Place tiny corner marks only at actual intersections or measured bounds.
- Use one line weight family and one corner family throughout the page.
- Use chamfered corners only when the subject supports engineered geometry; keep cut sizes proportional and hit areas intact.
- Use a directional border only for the active or primary surface, not every region.
- Keep focus rings independent from decorative borders.

## Density correction

When occupancy is low:

- enlarge the model, comparison, or relationship before enlarging chrome;
- shorten the distance between evidence and its labels;
- turn prose into attached annotation when the object can carry it;
- verify a flex spacer or fixed height is not swallowing the frame.

When occupancy is high:

- remove repeated explanations and decorative framing;
- combine labels that point to the same feature;
- move secondary evidence to another state or page;
- split the teaching claim rather than dropping below type floors;
- keep controls compact but preserve target and label legibility.

## Failure signatures

- **Dashboard drift:** many equal panels, no dominant explanatory visual.
- **Poster drift:** large title and atmosphere, too little relationship or evidence.
- **Card-grid drift:** categories are spatially equal although their knowledge roles differ.
- **Annotation fog:** leaders cross, labels float far from anchors, every object has a callout.
- **False emptiness:** decorative whitespace separates items that should be compared.
- **False density:** nested surfaces consume more area than the content they group.
