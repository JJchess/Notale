## 已撤回的假设

**"字号约束导致更多分块与粗描边"** —— 证据不成立。两轮不是同一份 planner
产物（页表 md5 不同，27 页里标签+主题完全相同的是 0 页），比的是两套不同的
讲义，差值里混着题材、页型和内容差异。

要验证它需要同一份冻结规划上"有字号约束 vs 无"的配对实验，而 A/B 两臂
恰好能顺带给出。**在此之前不动字号约束** —— 它把脱离字阶从 41% 压到 9%，
是本轮唯一确凿的收益。

## 明确不做

- 不动 SKILL 选型说明、`<tech>`、`<theme_css>`、工具 schema。
- 不为"视觉中心"补出路（本轮只给数没给话，1.5 → 1.8）。那是下一步，
  混进来会读不出效应。
- 不设任何硬门禁。
