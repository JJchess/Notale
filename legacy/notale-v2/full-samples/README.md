# Retired full samples

The 52 full examples and bundles were retired on 2026-09-10. They are historical
artifacts, not Builder candidates. Archived catalogs contain only full metadata;
the live workflow catalogs contain only mini (or the code `one` example).

`migration.json` records the original full and live mini file hashes. Full source
trees were moved here intact. Seven visual examples that shared a source tree now
have independent byte-identical live copies at their existing mini entry paths.
The code workflow retains only edit-distance; all four original author layers are
archived here. No live mini needs this directory to run.

The archive is not regenerated by `core.sample_bundles`. Its old galleries are
historical snapshots, not live navigation. There is no `--samples full` mode or
mini-to-full fallback. No original full source was deleted; it can be recovered
from this directory using the recorded original paths.
