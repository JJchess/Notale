### 1.2 B-HOLD（轮换保留集）

每个里程碑由 owner 现场出 2–3 道新题（可以就是当天真实想做的讲义），跑完计分后归档 `eval/queries/holdout/`、下次换新。永不进入日常调参。**B-HOLD 胜率显著低于 B-CORE → 判过拟合，里程碑不通过。**

### 1.3 GOLD（金样本库，`eval/gold/`，导入规范见其 README）

人类高水平讲义——它们**定义**"丰满""多样"长什么样。首批：owner 的大学《数据结构》60 分钟讲义。每份配**注解卡**：页数/分钟、每页字数分布、图占比、习题密度、"它好在哪的三个具体机制"。三用途：
1. 成对比较的**天花板锚点**（北极星第 3 条）；
2. **时长模型的经验数据源**——minutes → 页数/每页信息量/图文比/习题间隔的分布，全仓库目前没有这个模型，从 Q1 金样本拟合起（T-LONG 第一交付物）；
3. BORROW 取经轮的逆向工程对象。

### 1.4 SABOTAGE（破坏样本库，`eval/sabotage/`）

故意做坏的页/deck：溢出、错公式、占位文本、图文不符、前后矛盾。**唯一用途**：掺进评审批次里抽查判官和硬门有没有在偷懒（canary，见 [`PREP.md`](./PREP.md) §4）。CALIBRATE 轮换血。

## 3. 趋势指标（每轮记录，不阻塞；里程碑必须交代走向）

- **成对胜率**：候选 vs baseline（主趋势）；候选 vs gold 败率（天花板距离）。
- **视觉厚度**（T-VIS）：图形元素在位率（figure/diagram/sim/table 至少其一的页占比）、内容墨水比、PPTEval 式三维页评分（含"无视觉元素封顶 3 分"硬规则，继承 v2 轨道③）。
- **多样性**（T-STYLE）：**风格指纹距离**——每 deck 提取向量（主题 token、字阶、栅格用法、版式序列直方图、截图嵌入），Q9 同题三跑两两最小距离；全语料 block-type 分布熵（数据源：`viewer/telemetry/coverage.json`；现状病灶：flow 632 / list 311 / callout 229 vs table 26 / agenda 22）。
- **模板化迹象计数**：按宪章 §7 做人工盲评与成对比较，作为 authoring profile 的迭代信号；
  不把文案短语直接晋升为运行时黑名单。
- **正确性抽检通过率**：T2 不可推导抽检、T3 来源支持性、T4 盲测 VQA 通过率。
- **quiz 可答性**（T5 代理）：只读 deck 的 LLM 答自带 quiz + 外部题库抽题的正确率。

晋升/降级规则见宪章 §5（渐进法制）。

## 4. 证据协议（复活 v2 宪章被荒废的截图制度）

现状教训：全仓库只有**一个**截图快照（2026-07-30 的 40 张），没有 before/after 对、没有趋势线。协议：

- 每次基准运行落盘 `eval/runs/<date>-<git-hash>/`：
  - 产物 JSON（LectureDoc 或等价物）
  - **全量真机截图**（render-check `--shot`）
  - render-check `--json` 机读结果
  - **stage log**（每个 QA 阶段的执行回执——G1 的证据）
  - scorecard.json（门表 + 全部趋势指标）
  - contact-sheet（每 deck 一张缩略拼图，供 checklist 第 1/5 步肉眼比对）
- **保留策略**：accepted baseline 的 run 目录永久保留；候选 run 保留最近 N 个。contact-sheet 与 scorecard.json 进 git；全量截图留磁盘。
- `eval/BASELINE.md` 记当前 accepted baseline 指针 + 记分卡快照；`eval/LEDGER.md` 记轮次日志（`legacy/ITERATIONS.md` 的继任者）。
- 趋势线：dashboard 脚本（待建，落 `eval/dashboard/`）从历代 scorecard.json 汇出——"这三个月 harness 有没有变好"必须是一条能画出来的曲线，不是一句话。
