## 一句话

> **正确 = 与一个外生参照物一致。验证的全部工作，是找参照物。**

调研里那些名字唬人的技术——制造解、收敛阶检验、蜕变测试、差分对拍、契约回读、确定性重放、
运行时监视——**全都是同一件事的不同实例，区别只在参照物从哪来**。

## 参照物从哪来（按可信度排序）

| 参照物 | 强度 | 抓什么 | 例 |
|---|---|---|---|
| **闭式解**（学科给的） | 最强·绝对 | **系统性偏差——其余参照物对此全盲** | 小角周期 `T=2π√(L/g)`；无阻力射程 `v²sin2θ/g`；排序结果有序且是输入的置换 |
| **独立参考实现** | 强 | 实现级错误 | JS 动画 vs Pyodide 里 scipy 的 `solve_ivp` |
| **声明的规格** | 强 | 意图漂移（"能跑但解错物理"） | 从产物回读它实际实现的方程，与契约声明做结构比对 |
| **学科定律** | 中 | 整类物理错误 | 守恒 / 量纲 / 极限退化（阻力→0 应回到抛物线）。**必须按系统类别挂**，见下 |
| **变换不变性** | 中 | 系数、符号、单位错 | 反射对称抓屏幕 y 轴与重力符号反（LLM 头号错）；参数单调性抓因果方向讲反 |
| 自身 · 更细步长 | 中 | 数值实现错误 | `dt / dt2 / dt4` 三跑，误差比是否匹配格式的理论阶 |
| 自身 · 上一次运行 | 弱 | 生成器漂移、竞态 | 同 seed 两跑，状态 hash 一致 |
| 通用页面性质 | 弱 | 一整类低级毛病 | 可见文本无 NaN/undefined/占位符、无 uncaught error、canvas 非零尺寸 |

**唯一的规则**：**每个可执行物至少绑一个外生参照物**（前五行任一）。后三行是自身参照，只能当补充，
不能当唯一依据。**一个都绑不到 → 降级为静态图并标注**（沿用已有的降级纪律）。

对应到门表：`EVAL.md` 的 **G2** 就是这条规则，**没有新门**——上表是满足它的菜单，不是门的清单。

## 三条红线（都是被数据证伪的做法）

1. **"跑通"不算验收。** 实测：只靠执行反馈修复之后，仍有 **39–40%** 是"能跑、能收敛、解的却是另一个方程"。
2. **同一个 agent 不许既写产物又写它的检查。** 实证：LLM 写出的断言描述"代码实际做了什么"而非
   "代码应该做什么"——等于把现状拍成快照，然后宣布现状正确。
3. **返工循环必须累积反例且有次数上限。** 我们现在是"报错 → 重新生成"，那是重试不是反例制导：
   会出现"修好 A 弄坏 B、修 B 又弄坏 A"的震荡；无上限重试还会让模型学会**无条件服从执行反馈**，
   连错的反馈也照着改。反例要进一个只增不减的清单，每轮全部重放。

底层理由一句话：**凡是从产物自身导出的检查都可以被绕过**。生成器若知道我们查能量守恒，
它会每帧把能量重整化回去——裕度完美，物理错误。所以参照物必须**外生**。

## 两条便宜且我们现在没有的做法

**一、契约先于代码。** 每个可执行物在写代码之前先产出一份契约（合并了 PhET `model.md` 的形态）：

- 控制方程 / 采用的近似（小角？无阻力？点质量？）
- **主动声明的已知不准确处**（"阻力系数取常数，实际依赖雷诺数"）
- **哪些视觉量不对应物理单位**（"速度矢量的长度经过缩放以便看清"）
- 有效参数区间与失效边界；数值方法与步长
- 学习目标 + 学生应当读出的结论

三重作用：**验证的输入** · **审查的对照物** · **给师生的披露文档**（PhET 已证明这在教育场景是必需品）。
它还把"这个模型对不对"这个不可判定的问题，改写成两个可判定的问题：

- 「**声明的简化是否被忠实实现**」→ 机器查
- 「**声明的简化是否与学习目标相容**」→ judge 只看两段短文本，判断质量远高于让它判整份代码

（后者有反例教材：教"测量不确定度"时，"零噪声"这个简化是致命错误——PhET 为此专门往仿真里加了统计噪声。）

**二、quiz 必须附可执行推导，不能只给答案。** 检查器执行推导、与标注答案对拍。
教育产物里最丢人也最常见的失效是 quiz 答案错，而它 100% 落在"可自证"里——这是全篇最便宜的一条。

## 三处修正（改错，不是加新机制）

1. **"能量守恒"当通用自检条件是外行做法。** 辛积分器的能量是**有界振荡**（不守恒到机器精度）、
   耗散系统能量**本应下降**、RK4 对保守系统**会缓慢漂移**（这是正确行为）。一刀切会产生大量假警报，
   然后 checker 被人关掉。→ 按系统类别（保守 / 耗散 / 混沌）挂不同判据；**主力检查换成"更细步长"那一行**
   （零 oracle、零标注、能抓导数写错 / 系数写错 / 格式用错一整类硬伤）。
2. **不变量与变换不变性全都是必要不充分。** 一个把 `g` 写成 98 的单摆，能量守恒、无 NaN、时间反演对称、
   参数单调性**全过**，物理却是错的。所以表里第一行（闭式解）不是可选项。
3. **我否决"给每个组件写测试"时 overcorrect 了。** 反例制导循环里的反例**不是"采样行为空间"，
   是"约束合成空间"**——它的作用是让下一次生成收敛，不是证明正确。这与当初的否决理由（采样≠证明）
   不矛盾，两者性质不同。原否决记录仍然有效，见 `PREP.md` §6。

## 调研里想到了、但现在不做的

差分对拍的工程化、契约的确定性回读、STL 时序性质与对抗式搜索（falsification）、从 IR 自动导出覆盖模型、
GSN 保障案例、Simplex 式降级架构——都在调研文档里，都是好东西，但**属于"想到了还不需要"**。
按宪章渐进法制：**等真实运行中出现需要它们的失败再说**，不预防性立法。
