输出

教学性交互遵循 input/action → domain engine → trace/result → render。算法、方程、状态机、判定器或数据变换是唯一教学状态源；界面只投影实际计算结果。

Builder 使用 acquire_media / generate_media；最终 HTML 只绑定已登记的本地素材。

Delivery report
只陈述本次交付状态；不自动沉淀经验
输入
manifest + consistency-report
终态页面列表与跨页装配结果
输出
quality-report （最终交付）
deck互动讲义

degradedPagesBuilder 未能提交后生成静态安全页的页面

经验沉淀由用户监督，在实验日志诊断之后另行完成，不是每次 run 的自动阶段。
