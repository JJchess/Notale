# 动画与讲授步骤

动画面板沿用「单击时／与上一动画同时／上一动画之后」，时长、延迟及步骤自动前进统一使用秒。多选对象时可选择同时播放、依次播放或逐次单击；一次添加仍是一个可撤销操作。单条预览仅播放该条，多选预览播放选中对象的动画；跨步骤的临时预览自动串联，正式放映仍遵循实际单击及自动前进设置。

普通动画页调整列表顺序或触发方式时，同步重新编排单击步骤，保持列表与播放一致。已有讲稿、原生互动或组件步骤的页面保留步骤身份：步骤内可调整顺序，跨步骤通过动画「步骤」字段，整步调整通过「讲授步骤与讲稿」。

讲授步骤支持命名、讲稿、自动前进、预览、插入、复制、删除和排序；初始画面固定在第一位。步骤变化复用后端现有动画、互动和媒体映射协议。HTML 导出继续使用与预览一致的播放器及动画时间线。

定向验证：
- 后端 animation-authoring / teaching-steps：组合时间、重复与反向、对象触发、步骤映射与保护。
- 前端 animation-sequence：独立双对象样本的触发、排序、时长、延迟、步骤操作、保存重开及导出 HTML 实际播放。
