# 编辑器中英文

范围：编辑器、菜单、面板、对话框、错误和状态、可访问名称、画布操作控件、放映及演讲者视图、导出播放器。

首次打开按浏览器语言选择简体中文或美式英语，其他语言回退英语。手动选择写入同源 cookie 与 localStorage；服务端首屏读取 cookie，其他已打开窗口通过 storage 事件同步。切换只重绘界面文案，不刷新页面、不重建画布、不触发保存，也不重置正在输入的草稿。

英语以 Microsoft 365 / PowerPoint 术语为基准：Slide、Slide Show、Slide Master、Presenter View、Notes、Arrange、Group、Bring to Front。采用句式大小写和常用短词。长度按实际显示宽度衡量，短按钮优先一至两个词；不能为等长缩写标准术语或丢失错误中的操作建议。图标入口保留 tooltip 和可访问名称。

参考：[Microsoft 简洁用语规范](https://learn.microsoft.com/en-us/style-guide/word-choice/use-simple-words-concise-sentences)、[Slide Master](https://support.microsoft.com/en-us/powerpoint/training/what-is-a-slide-master-in-powerpoint)、[Presenter View](https://support.microsoft.com/en-gb/office/what-is-presenter-view-98f31265-9630-41a7-a3f1-9b4736928ee3)。

共享词表在 `notale-editor/src/i18n/catalog.ts`，通过 `@notale/editor/i18n` 提供给前端和运行时。当前使用中文源文案作为稳定消息键，保留既有状态、错误匹配和恢复逻辑。React 使用 `useI18n()`；命令行或服务端使用显式 locale；命令式前端控件使用 `translateUi()`。组合文案使用带参数的消息，参数不递归翻译。

用户内容不能传入翻译函数：讲义、页面和对象名称、正文、备注、批注、图表数据、代码、组件状态名称、AI 输入和输出均原样保留。内置素材的入口名称可翻译，其模板内容不变。不要遍历 DOM 替换中文。

后端兼容保留 `error`、`message`、`details` 等字段；已知错误和 AI 进度可附带 `messageKey`、`messageParams`，前端将其保留为可重新翻译的消息。未知错误保留原始文本。AI 的界面进度翻译不改变模型请求和会话历史。

画布使用现有校验来源、通道的消息桥接传递 `locale-change`，只更新运行时自己创建的标签。`GET /api/documents/:id/export?locale=en-US` 将导出播放器固定为该语言；省略 locale 保持原有中文行为。导出的工程内容和格式不增加语言字段。

验证集中于词表参数完整性、语言优先级、导出内容不变，以及浏览器中切换时保留输入、画布实例和选择、跨窗口同步。既有中文浏览器用例显式设置 `zh-CN`，双语用例另设 locale。
