# Backend-to-frontend integration audit

User release rule (2026-09-09): expose only connected workflows. Advanced component base override/layout authoring, raw source editing, advanced placeholder authoring and unverified layout presets remain hidden behind static release gates in src/feature-availability.ts. These capabilities remain in backend scope; they are not removed from the delivery objective. A workflow must gain recorded integration evidence before its gate is removed.

This is a gap audit, not a declaration that the broad editor goal is complete. It distinguishes verified product interactions from backend capabilities still exposed mainly through inherited technical controls. Evidence below refers to the real-lecture tests in `tests/editor.spec.ts` and the module audits in `.local/`.

Priorities follow coherent user workflows: improve the inherited technical authoring areas, then consolidate whole-product acceptance and host integration. Green focused tests do not close unrelated rows.

`tests/editor.spec.ts` was migrated to the current interface on 2026-09-10: media entries open through the insert drawer (`openMedia`), teaching steps through the collapsed details (`openSteps`), objects are selected through the workbench API because page content overlaps the fixed insertion point, interactive preview assertions target the `#preview-canvas` overlay and leave through `#preview-close`, animation authoring goes through the sidebar effect library with seconds-based timing, the document tool lives in the style tab, and full-lecture exports get a 60-second request timeout. The concurrent-409 scenario is marked `fixme` because the sync endpoint now merges concurrent edits. Three scenarios that upload SVG files fail until the backend accepts the `svg.import` command the frontend already emits; they are not regressions of the insert work.

The reference-style floating dock and modal preview have focused acceptance in `tests/preview-dock.spec.ts`: page edits/undo, notes, preview save gating and load recovery, native Canvas/steps, origin isolation, view restoration and 390px layout. Evidence: `.local/preview-dock-results.json`. Legacy inline-preview selectors are superseded by `#preview-canvas`; this targeted pass does not imply that all legacy cases have been migrated.
