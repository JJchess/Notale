# 对象编辑与排版

- 位置面板显示页面坐标中的选区外框 X、Y、宽度和高度。多选改位置时整体平移，改尺寸时围绕左上角调整整个选区；锁定宽高比可保持比例。单对象旋转显示已有变换的角度，多选旋转输入表示整体旋转量。
- 数值修改直接生效，复用几何保存队列与增量画布更新。文字框开启保持字号时复用拖拽的文字重排逻辑；不适用文字重排的对象保留几何缩放。切页、切工程、预览和导出等待数值编辑完成。
- 组合：Ctrl/Cmd+G；取消组合：Ctrl/Cmd+Shift+G。层级：Ctrl/Cmd+[ 或 ]，增加 Shift 置底或置顶。文字输入中保留原生快捷键。
- 右键提供对齐与分布。一个对象或组合默认对齐页面，多对象默认对齐选区，可在面板更改基准。组合参与对齐和分布时视为一个整体，保留组内相对位置；至少三个独立对象或组合才可分布。
- Shift 拖动约束方向后，吸附不会引入另一轴的位移；现有页面、对象、网格与手动参考线继续共用屏幕容差。

验证使用独立混合对象样本，覆盖文字重排、单对象定位、多选平移和缩放、组合、层级、对齐分布、撤销重做、保存重开及导出页面的实际几何对照。复用 selection、snapping 和 layout-clipboard 定向用例。
