# 对照 PowerPoint 的编辑体验审查（2026-09-14）

审查方法：在自建 build（`.next-arrange` / 4319）上跑真实文档，逐个面板截图（`.local/audit/`），
再回到代码核实每条现象的成因。对照面：PowerPoint 的「开始 / 插入 / 形状格式 / 设计」四个选项卡。

下面分三类：**A 确认的缺陷**（行为不对，跟口味无关）、**B 缺的编辑体验**（PPT 有我们没有）、
**C 已经对齐的**（不要动）。每条都标了成因位置和验证方式，方便逐条批。

## A. 确认的缺陷

### A1. 从插入面板插入对象后不选中它
点形状库的矩形，对象插入到画布中央，但 5 秒内 `getSelection()` 一直为空，右侧属性面板保持关闭
（`#property-panel` 仍是 `display:none`）。用户必须自己再去画布上点一下那个新对象，才能改颜色或移动。

PowerPoint、Figma、Keynote 插入后都立即选中，并把格式面板切到对应的上下文。这是插入面板每一次使用都要多付一次点击。

- 验证：插入后轮询 `NotaleWorkbench.getSelection()` 10×500ms，全程为空
- 做法：插入命令返回新 id 后 `changeSelection([id])`，并 `editorShell.inspect('format')`。插文本框时还应直接进入文字编辑。

### A2. 所有形状都拿不到「渐变」和「圆角」
`appearance.ts:50` 的 `isVector()` 把**任何带 `data-notale-shape` 的元素**判成矢量图形，
而 `appearance-editor.tsx` 里渐变行 `hidden={!model.html}`、圆角同理，于是形状库插进来的矩形、圆角矩形
在「外观」里看不到渐变和圆角——可这两个恰恰是矩形最常用的两项，我们的形状库里甚至单列了一个「圆角矩形」。

- 验证：选中插入的矩形，`#appearance-gradient-row.hidden === true`，`#appearance-radius` 不可见
- 做法：形状按几何分两类。矩形类（rect / rounded / callout，靠 `border-radius` + `background` 画）走 HTML 路径，
  给渐变和圆角；clip-path 类（三角/菱形/星形等）继续隐藏圆角，但渐变可以留（`background-image` 一样生效）。

### A3. 填充读不到 `background` 简写
`appearance.ts:152` 只读 `background-color`（矢量读 `fill`）。一个写成 `style="background:#6120ce"` 的对象，
面板判定为「无填充」，色板显示黑色。手写模板、AI 生成的页面、PPTX 导入的对象都可能用简写。
危险的不是显示错，是**用户随手动一下别的字段就会把原来的紫色写成透明**。

- 验证：给对象写 `style="background:#6120ce"`，选中后 `#appearance-fill.value === "#000000"`
- 做法：读取时按 `background-color ?? background 里解析出的颜色` 兜一层，和第 156 行处理 `background-image` 的写法一致。

### A4.「无描边」勾上后，描边色和粗细仍然可点
填充那侧有 `paint-off` 置灰，描边侧没有。勾了「无描边」还能调粗细，调完不生效，是假控件。

- 位置：`appearance-editor.tsx` 的第三个 `paint-row`
- 做法：照填充的写法加 `paint-off` 并 `disabled`。一行的事。

## B. PPT 有、我们没有的编辑体验

### 第一梯队 — 高频，改动都不大

**B1. 颜色控件只有系统原生取色器。**
PowerPoint 每个颜色按钮点开先是「主题颜色」10 格 + 「标准色」10 格 + 「最近使用的颜色」，
想调细节才进取色器。我们直接扔一个 `<input type=color>`，用户要配一套统一配色只能靠记忆里的十六进制。
我们已经有主题配色（`--accent / --text / --muted / --bg / --rule` 和主题预设），把这套色直接摆成色板是顺理成章的。
**这是形状格式里最高频的动作，也是这一批里最值的一项。**

**B2. 段落对齐还是下拉框。**
刚把「排列与对齐」改成图标了，文字面板里的「段落对齐」和「文字方向」还是 select。
PPT 是四个图标按钮（左/中/右/两端）。同一套 `.icon-button` 样式直接复用。

**B3. 对象级文字工具只有加粗、斜体。**
下划线、删除线、项目符号、编号、增大/减小字号，现在只存在于「编辑文字」弹窗（`rich-editor.tsx` 里都实现了）。
PPT 把它们放在常驻工具栏，选中文本框就能点。至少把下划线、删除线、项目符号、编号四个提上来。

**B4. 文本框缺垂直对齐和内边距。**
PPT 的「对齐文本：顶端 / 中部 / 底端」和「文本框内部边距」是排版最常用的两个控件，我们一个都没有
（文本框本身是 flex 容器，`align-items` + `padding` 就能落）。

**B5. 打开文档时页面缩略图栏是关的。**
`state/sidebar-state.ts:4` 的 `initialSidebar` 是 `pages:false, inspector:false`。
PowerPoint 永远显示缩略图栏——用户进来第一眼要知道自己有几页、在第几页。建议默认展开页面栏（属性栏保持按选中打开）。

### 第二梯队 — 值得做，工作量明显更大

**B6. 形状快速样式库。** PPT「形状样式」一整组：主题色 × 填充/描边/强调 的预设组合，一点就换一套。
我们有主题变量，做 6 色 × 3 变体的 gallery 是可行的，但要新面板 + 预设表。

**B7. 格式刷 + 「设为默认形状」。** Ctrl+Shift+C / Ctrl+Shift+V 复制粘贴格式。
我们的外观字段是结构化的，复制一份 style 子集再套到别的对象上，实现不难，难在定义「哪些字段算格式」。

**B8. 更改形状。** 保留位置、尺寸、文字、配色，只换几何形状。PPT 在右键菜单和形状格式里都有。

**B9. 形状库只有 12 个。** PPT 有 9 类约 160 个。建议至少补「流程图」「星与旗帜」「公式形状」三类
（都是 clip-path，边际成本很低），并给形状类目加搜索（现在只有图标类目有）。

**B10. 效果只有 4 档阴影。** PPT 还有发光、柔化边缘、映像。柔化边缘 = `filter: blur()`，发光 = 彩色 `drop-shadow`，
各加一行就能覆盖两个最常用的。

### 第三梯队 — 细节

- **B11.** 插入面板「文字」类目里，代码块和日期两个图标没有组标题（`insert-panel.ts:21`），
  紧跟在「艺术字」网格后面，看起来像艺术字的第 4、5 个样式。加一个「其他」组标题即可。
- **B12.** 字体框对没设字体的对象显示浏览器解析出的 `Times New Roman`，而不是占位符说的「沿用页面字体」。
- **B13.** Tab 键不在对象之间切换。PPT 用 Tab 逐个选中当前页对象，是纯键盘操作的入口。
- **B14.** 右键菜单没有「另存为图片」（矢量对象有「导出 SVG」，普通对象没有对应项）。

## C. 已经对齐 PowerPoint 的（不要动）

- 画布手势齐全：吸附对齐线、标尺、Shift 约束、Alt 从中心缩放、Ctrl 临时关吸附（`moveable-gestures.ts`）
- 右键菜单结构和 PPT 基本同构：剪切/复制/粘贴/副本 → 排列 → 对齐与分布 → 组合 → 锁定 → 动画 → 设置对象格式 → 删除
- 快捷键：Ctrl+G/Shift+G 组合、Ctrl+[ ] 层级、Ctrl+D 副本、方向键微调（Shift 十倍）、Ctrl+Z/Y
- 双击进入文字编辑、多选混合值显示「多种值」、锁定宽高比、主题配色预设与页面背景
