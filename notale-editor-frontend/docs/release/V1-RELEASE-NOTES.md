# Notale v1.0.0

Notale 是面向讲授的互动演示编辑器：用熟悉的页面、图层和属性面板编辑 HTML 讲义，组织页内步骤，并通过放映和演讲者视图完成授课。

本版本包含独立的 TypeScript 后端与 Next.js / React / TypeScript 前端，前后端保持同级目录。

## 编辑与讲授

- 文字、图片、形状、连接线、SVG、表格和图表编辑，以及多选、排列、快捷键、撤销与重做。
- 八套原创整页模板及配套独立图示，使用可编辑 HTML/SVG，不依赖参考截图或外部字体文件。
- 页内动画、讲授步骤、互动组件参数、页面排序与讲稿。
- 独立放映、演讲者备注、计时、标注和观众窗口。

## 保存与交付

- 本机草稿、保存队列、失败恢复、历史版本与工程导入导出。
- 讲稿停笔自动保存，中文合成期间暂停；新输入、远端冲突和保存失败保留草稿。
- 工程导出附带互动运行时及其许可通知，并避免覆盖用户同名资源。
- 界面、属性面板、动画效果图标与常用弹窗统一精修。

## 运行

按仓库根 README 安装前后端依赖、启动 PostgreSQL、完成构建，在前端执行 `npm run start:local`，打开 http://localhost:4312。

本机启动方式使用开发身份。接入已有系统时复用宿主认证、授权及独立内容源，不另建账号系统。复杂 HTML、Canvas、CSS 和外部脚本的可视化编辑范围取决于对应适配器，详细范围见集成覆盖说明。

Notale 自有代码和原创模板使用 MIT；第三方许可与通知随源码和运行时导出提供。用户讲义和媒体的所有权不变。
