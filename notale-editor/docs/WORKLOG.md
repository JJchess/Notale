## Architecture under implementation

- Preserve original HTML, CSS, SVG, script and asset dependencies. Parse author source using parse5, assign stable node identifiers, edit source through typed commands. Never serialize the interactive runtime DOM as author content.
- PostgreSQL immutable document revisions, atomic compare-and-swap commits, idempotency and content-addressed resources. Host-injected access policy, no new account system.
- A browser bridge connects native slide runtime to object selection, interaction defaults and a reversible animation/step timeline. Reveal.js supplies presentation navigation and overview.
- A real browser integration workbench exercises backend commands rather than pretending the backend alone supplies a complete UI.
