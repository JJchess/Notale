# SVG 编辑

前端独立目录：`../notale-editor-frontend`。SVG DOM 是编辑与导出的共同数据源。图形操作接入现有文档队列、IndexedDB 草稿和版本历史；没有独立的保存或撤销系统。

## 已接入

- 文件选择、拖放、SVG 文本粘贴转为内联 SVG；导入时分配实例身份、改写引用并隔离样式。
- 图形填充、描边、透明度、虚线、端点、连接方式、箭头、混合、图片填充、渐变和基础效果。
- 基础形状参数；SVG 文字片段的中文输入、字体样式及横竖排。提供实际字体文件时可将单一横排文字转换为轮廓。
- 真正的 SVG 组合／取消组合，布尔合并、相减、相交、排除，描边转轮廓、偏移、复合路径拆分。布尔结果保留源形状。
- 路径节点与控制柄、端点连接与断开、开合、反向、简化、顶点剪贴板和选中顶点的缩放旋转。
- 矩形、椭圆、直线、多边形、星形、箭头、圆弧、钢笔与自由曲线；Enter 完成、Esc 取消绘制。
- 渐变画布手柄；裁剪／蒙版创建与解除；用户空间裁剪边界的路径编辑。
- `use` 实例分离；已知互动组件的独立静态副本。
- 页内“描边绘制”动画，通过共享播放运行时用于预览和 HTML 导出。
- 独立 SVG 导出收集定义引用、内联计算后的外观并嵌入图片。

## 命令契约

`svg.import`：`{slideId, parent?, html}`。

`svg.patch`：`{slideId, mutations}`。

`svg.structure`：`{slideId, action, mutations}`。

Mutation 包括 `set`、`insert`、`remove`、`replace`、`move`。`replace` 必须保留目标的 `data-notale-id`。操作会检查锁定边界、互动目标、路径合法性和身份冲突；同一命令内的所有变更原子应用。普通属性变化与结构变化都通过现有同步队列提交。编辑时不因为 SVG 保存确认而重载 iframe。

Paper.js 负责曲线操作，PathKit 在 Worker 中负责布尔／轮廓计算，fontkit 在 Worker 中负责字形轮廓。整个图形工具按需加载。

## 完整规划中仍未完成的部分

本次代码不是原完整规划的全量验收：仍缺顶点框选／套索、跨路径剪切与橡皮擦、完整共享 symbol 源编辑、任意富文本片段选区的格式化及沿路径排字创建、已知动态图形的统一覆盖适配器、未知脚本图形的可靠自动判定、Alt 拖拽复制与吸附迟滞。现有本地预览入口仍沿用保存后取服务器版本的机制，尚未改为完整离线草稿播放。

相对包围盒裁剪边界、字体缺字、字体合集、纵排文字转轮廓会明确拒绝，不隐式破坏原图。节点与渐变编辑属于进入式编辑模式，Esc 退出。外部图片无法读取时独立 SVG 导出会报告失败。
