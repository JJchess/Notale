# 模板约束

根据当前页规格创作内容，保留指定模板。默认使用适用列表中的第一个版式，只有内容功能确实需要其他空间结构时才切换；同级页面保持标题字阶和排版基准。把选中的版式 ID 写在唯一 #stage 的 data-notale-template 属性中。
每个内容区用 #stage 的直接子元素 <section data-notale-slot="区域ID"> 表达，必填区域须有内容。位置与尺寸由宿主在 Check 时装配，你在区域内部布局；坐标从各区域左上角起算。不要自行移动/缩放区域。slot 只限定可用空间，不需要画成容器。可选区域不用时可以省略。标题区域使用 h1；metadata 只填已知信息。
固定骨架在首次 Check 时注入，Read 可能看到带 data-notale-template-fixed/geometry 的宿主块；这些块不编辑、不复制、不移除。不能用脚本修改固定元素、改变区域边界或在区域外绘制。CSS 尽量限定在区域内的类/ID，禁止全局重写 svg/path/text/img。使用统一主题字阶与颜色，不重绘背景、徽标，不用整块底色遮住模板。
主题已按“版式＋slot”设置局部 --text、--muted：标题和普通文字使用 color:var(--text)，副标题和次级文字使用 color:var(--muted)。变量在文字所在区域解析，不能从 :root/#stage 读取整页颜色再写回区域。不要写死文字色、覆盖区域变量或降低文字 opacity；深色页眉与浅色正文不会共用同一种文字色。图形与真实控件状态仍可使用主题的语义色。

本模式已预加载页型教学要求；材料足够时直接生成。存在具体信息缺口时，定点读取所需 API 文档、LIBS.md 或本页引用的资料；仅交互页按已注入的 sample_read_policy 读取参考和样例，迁移操作、计算与反馈机制；不迁移其布局、配色或 CSS。其他页不额外读取自由设计样例或原版 SKILL。
Check 时查看完整装配截图，确认标题和副标题在实际背景上清晰可读、固定模板与新内容协调、区域内无遮挡和裁切。渲染无报错不等于文字可读；发现本页硬编码颜色时恢复区域变量，修正后再交付。
