# 模板页面生成

根据当前页规格创作内容，保留指定模板。仅从适用版式列表中选一种，把版式 ID 写在唯一 #stage 的 data-notale-template 属性中。
每个内容区用 #stage 的直接子元素 <section data-notale-slot="区域ID"> 表达，必填区域须有内容。位置与尺寸由宿主在 Check 时装配，你在区域内部布局；坐标从各区域左上角起算。不要自行移动/缩放区域。可选区域不用时可以省略。标题区域使用 h1；正文区域承载图示、说明和交互。metadata 只填已知信息，不能编造讲师、日期。
固定骨架在首次 Check 时注入，Read 可能看到带 data-notale-template-fixed/geometry 的宿主块；这些块不编辑、不复制、不移除。不能用脚本修改固定元素、改变区域边界或在区域外绘制。CSS 尽量限定在区域内的类/ID，禁止全局重写 svg/path/text/img。使用统一主题字阶与颜色，不重绘背景、徽标，不用整块底色遮住模板。

公共要求：页面 HTML 使用 assets/base.css、assets/theme.css，在 #stage 之后加载 assets/base.js，再运行依赖 Deck 的脚本；固定 1600×900，缩放与指针坐标遵循 chassis。只修改当前目标 HTML，不修改共享 assets，不读其他页面。首轮直接生成，不读取自由设计的 Main/样例或原版 SKILL；可按功能需要 Read references 中的 API 文档。只引用本地库，不用 CDN。
封面：呈现当前主题及必要的学习目标，不把正文挤进封面。内容页：把概念变成能讲清的对象、关系与推演；有因果/过程时使用页内步骤。交互页：必须有真实控件、可见因果反馈与可重置初态，不能仅用切换文字冒充互动。对比、数据和连续案例必须遵守本页规格和 continuity。
步骤使用现有 Deck 契约；不要因使用模板省略页内步骤。图形与正文在预留区域内保持可读和充分净空；可改变区域内构图，不能通过缩小字号强塞内容。
完成后必须 Check，查看完整装配截图和反馈，修正真实问题再交付。不得把空占位区、无工具文本或未检查页面当作完成。
