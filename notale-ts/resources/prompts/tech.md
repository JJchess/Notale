# 技术契约

## 运行与资源

样式按 `assets/base.css` → `assets/theme.css` → 本页样式加载；可视内容放进唯一的 `#stage`，讲稿（如需）放在其外。
在 `#stage` 之后加载 `assets/base.js`，使用 `Deck` 的本页脚本放在它之后。
目标 HTML 从零创建；不修改 `assets/`，不新建旁路文件，不读其他 `page-*.html`。
只引用 `pages/` 内相对路径，不用 CDN。画面不可滚动；逻辑尺寸 {canvas_w}×{canvas_h}，缩放、坐标和工具类遵循 chassis。

## 构图

先定主对象、对象关系／状态和说明依附位置，再布局；不先划面板填内容。
主体可用 absolute／inset:0 占满可用空间，文字压在其上；自由模式的可用空间是舞台，模板模式是指定 slot 内部。flex/grid 用于真实行列关系。
移除不合适外壳时一并收回外壳留白，保留绘图区净空、事件绑定和控件命中区。
一次性尺寸可内联，不为单页尺寸创建公共类。

## 主题承接

- **分工**：Director 定主题方向；你决定本页主体、布局和交互。字体、颜色、形状、笔触和材质依主题接口落实到内容，
  不只取背景色；reference/Main 迁移机制，不覆盖主题外观。类名可不用，可自写局部实现，但同类角色的依据一致，不另造皮肤或补齐所有装饰。
- **排版**：标题、正文、数字和中英混排使用对应字体与字阶；同角色沿用默认排版，不按 h1/h2 名称重新解释角色。
  封面／正文可有不同尺度，单语不凑双语。标题先调整可用空间内的布局、换行及图文关系，不随页换字阶或缩字塞单行；
  换行高度须留给后续内容。含中文标签不能用纯数字字体栈；不用本机宋体／雅黑替换主题。
  token、具名类及类内相对字号均合法，不要求最终像素等于根 token。{font_floor}
- **图形**：具名样式有宿主作用域时先挂宿主类。SVG 核对实际 fill/stroke，文字不能误套曲线粗描边或 fill:none；
  CSS stroke 优先于 SVG 属性。颜色按公开 currentColor、局部变量或本页 CSS 赋值。
  ECharts/Canvas 同样承接主题笔触、点形、标签与主次关系，通过现有图表配置实现，不建 adapter 或逐线像素补偿。
  数据系列、几何和状态归本页，不把装饰／通用选中态当正确性证据。Canvas 字体加载、测量、重绘遵循 chassis。
- **边界**：语义色按声明用途，装饰用允许的强调，不自建跨页概念映射；仅选已声明变体。
  常规使用预置主题接口，首版后具体样式问题才定点 Read `assets/theme.css`，不修改或复制共享实现。
  不用全屏盖白压主题；优先安静变体或调整布局，局部净空遮罩可用，无可读状态则报告主题缺陷。

## 数据与图片

常量、范围、初值和结果依据本页内容；需推导时实际计算，不预录结果或展示假数据；随机过程固定种子。
首屏静止状态须有可讲信息。
优先使用 brief 素材，必要时 ImageSearch/ImageGen 补图并看结果后采用；真实对象用搜索图，数据和精确几何自行绘制。
图片来源保留在 `<img title="…">`，不挤入主画面。
