# 精简整修实施与复测 · 2026-09-08

结论：两项修改已实施，122 项回归测试通过。本轮神经网络不再提交空素材映射，Commons 主图定位未再拿到网站图标；但集成学习仍有一张人物错配。没有证明整体稳定改善，也没有加入自动核验或强制用图。

## 实施范围

- `core/image_search.py`：Commons 文件页只解析 `div#file.fullImageLink` 主图；非 Commons 来源只下载给出的直链。删除 og:image／任意 img 兜底，并撤掉新增的“在 title 中描述图片”要求。原网络、重定向、解码与路径安全检查保留。
- `core/media.py`：query 参数说明承接图片主体、类型和用途；字符串／数组 schema 未改。
- `prompts/deck.md`：完整 query 只输入一次；明确看图后进行素材分配，保留页表格式、ImageGen、内容 guidelines 与无图完成。未改 Builder 或 Style Director。
- 原实验脚本保存每轮 Planner 输入；不记录认证头，不新增回放平台，不回灌日志。
- 回归测试新增真实 Commons 页面片段、图标在主图前、SVG 栅格预览、主图缺失和主图下载失败不替换、普通文章不换图、精确域名识别；更新 Planner 职责与 query 去重断言。

测试命令：`python -m unittest discover -s core -p 'test_*.py'`，122 项通过。两个 HTML fixture 是真实页面相关片段，不是整站快照；无主图等负例为构造用例。

### 神经网络

首批四项需求：LeNet、MNIST、早期感知机、LSTM 来源图。LeNet 的三个普通文章候选均未提供直链，代码如实报告失败，未抓封面。Planner 随后补搜两条 LeNet 需求，取得实际架构图。

最后采用：page-02 MNIST 数字样本，page-03 早期感知机照片，page-11 LeNet 架构图。第一次 FinalizePlan 把页号写为 `page_03` 等，既有校验拒绝后修正为 `page-03` 等，所以总共四次 Planner 调用。没有新增修复机制。

删除普通文章兜底的代价确实出现了：首批没有 LeNet 可下载图，需要补搜。不能只凭静态提示词变短就宣称总成本降低。

### 光合作用

首批五项需求中，叶绿体、恩格尔曼实验、光谱与电子传递取得对应图；卡尔文循环候选下载 403，未采用外部素材，也未补搜，相关内容仍在页表中。

Commons 返回 10 张主图，逐张目视确认没有许可、格式或绘图图标。采用的叶绿体图是电镜切片与三维重建组合，恩格尔曼图展示了光谱与细菌聚集关系；不再用仅有水绵照片代替实验关系。其余三张分别支持色素吸收、Z 型电子传递和跨膜质子梯度。这里的“匹配”表示支持页面主题，不表示一张图涵盖该页全部讲解。

### 集成学习：人物错配仍未解决

该图片直接来自搜索模型提供的 image_url，**没有经过被删除的 HTML 兜底**。此次主图定位修复解决不了这类错指直链；Planner 仅看人物照片，也不能可靠核验身份。未擅自新增人物识别、第二选图模型或来源审核流程，未手工改写实验映射。
