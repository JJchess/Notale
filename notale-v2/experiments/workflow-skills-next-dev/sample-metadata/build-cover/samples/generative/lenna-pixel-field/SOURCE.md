# Source record

This local study is an independent Canvas reimplementation of the interactive pixel field on The Pudding's “Can Data Die?” title page.

- Upstream repository: `https://github.com/the-pudding/lenna`
- Local research checkout: `/data1/home/zhuyifan/ws2/Notale/refs/lenna`
- Fixed commit: `5a70e912806291a4c350be17546daba1a3c4a25b`
- Files studied: `src/components/Hero.svelte`, `src/components/PixelGalaxy.svelte`, and `src/data/variables.json`
- Published visual reference: `https://pudding.cool/2021/10/lenna/`
- Reference reviewed at 1600×900 on 2026-08-30.

The sample keeps the governing interaction and composition: a 15px deep-purple grid, a large three-line title on the left, and colored grid cells launched from the pointer with per-particle velocity and alpha decay. The implementation here is new, uses a fixed local seed, prewarms a deterministic representative frame, adds a reduced-motion still, and uses the local Notale chassis.

The Pudding logo, upstream font files, bylines, subtitle, article imagery, and article content were not copied. The title is rendered with locally available open system monospace fallbacks and the page performs no external runtime requests.
