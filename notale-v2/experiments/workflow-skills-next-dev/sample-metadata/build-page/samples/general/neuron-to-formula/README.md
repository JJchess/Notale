# Neuron to formula

`build-page / general` 的正式样例。页面用同一组可追踪对象，把一颗神经元连续改写为 `a = σ(Σxᵢwᵢ + b)`。

## 页面契约

学习者应理解神经元的数学表达保留了输入、突触强度、整合、阈值、激活和输出，因为五条树突、突触、胞体、轴突小丘与轴突会连续变形成各自的符号和路径。

## 实现要点

- 五条主树突对应 `x₁...x₅`，突触对应 `w₁...w₅`，胞体对应 `Σ`，阈值对应 `b`，轴突小丘对应 `σ`，轴突对应 `a`。
- 一个归一化 `progress` 同时驱动画面几何、公式强调、说明文字、状态导航和百分比读数。
- 七个状态可以直接查看。完整推导可播放、暂停、继续、复位和重播。
- 生物结构由固定种子生成，复位与重载后的几何完全一致。
- 原生 Canvas 按需绘制，不加载 p5 或其他运行时依赖。
- `?t=0` 到 `?t=1` 可用于检查任意静态帧。减少动态效果模式直接呈现终式。
- 方向键切换相邻状态，Home 或 R 复位，End 查看终式，空格控制播放。

## 视觉论点

冷灰绿色场地接近显微观察和生物图谱的材料感。深墨色保留生物形态，朱红色追踪信号路径，赭色只标记权重与偏置。画面不使用发光、网格或仪表盘容器。

## 工程结构

- `pages/index.html`：页面结构和视觉规则。
- `pages/visual.js`：确定性几何、绘制和单一状态控制器。
- `pages/assets/`：Notale chassis 与本地库。
