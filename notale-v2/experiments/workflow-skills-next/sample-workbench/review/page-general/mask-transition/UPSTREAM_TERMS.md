# Upstream terms audit

The audited upstream revision has no standalone standard open-source license file. Its README permits integration or adaptation in personal and commercial projects, while prohibiting republication, redistribution, or sale of the resource “as-is”.

This sample treats the upstream as a mechanism reference only: CSS advances a horizontal mask plate with a discrete `steps()` animation while a controller swaps authored views. Every redistributed file is independently authored or copied unchanged from the local Notale chassis. Upstream images, fonts, mask plates, HTML, CSS, JavaScript, and branding are excluded.

The SVG files in `pages/media/` are original static visual assets. They contain no script, animation, event handling, or hidden application logic.
