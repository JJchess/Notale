“固定 Workflow”到底固定了什么？

当前只固定了 Agent 能加载哪份说明书，没有把说明书编译成 Harness 可观察的流程状态。

CURRENT · FIXED DOCUMENT

固定了 SKILL.md

只允许加载指定 workflow 名称，并把对应自然语言正文放入上下文。

CURRENT · FREE AGENT

没有固定执行路径

模型仍可跳步、乱序、重复步骤，也可以没有任何阶段产物就停止。

MISSING · STATE MACHINE

没有 Workflow Ledger

Harness 不知道当前处于哪一步，也不知道哪些步骤 PASSED、FAILED 或尚未执行。
