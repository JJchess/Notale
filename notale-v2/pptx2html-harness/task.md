将 `input/template.pptx` 这套 PowerPoint 模板转换成可复用的 HTML 模板，供后续制作互动讲义使用。

交付要求：

1. 保持这套模板的视觉特征：构图、文字层级、字体、颜色、留白、图形和素材处理。展示页逐页有对应的 HTML；对母版/布局中有价值但没有展示页的版式，说明是否支持及原因。
2. 文字、图片和主要内容区域可以独立替换。不能把整页截图作为转换结果。装饰、纹理、背景可以作为独立素材保留，页面的内容结构仍须可编辑、可接入交互。
3. 必要时使用本环境实际可用的图片生成/编辑能力，处理无法直接复用的视觉素材，并保持模板风格。现有素材可以直接使用时不必重新生成；不要为凑调用次数而生图。工具不可用或生成失败时如实说明。
4. 交付可以在浏览器中运行的模板集合及浏览入口。资源使用本地相对路径；写明启动方式、各页与原模板的对应关系、字体替代和未能还原的部分。
5. 提供最小复用示例，展示同一模板更换文字/图片后仍然成立，以及在一个合适的内容区域接入一个简单交互后的样子。主体任务是模板转换，示例不需要扩写成整套课程。
6. 保留用于检查的原模板参照和 HTML 渲染结果。列出素材来源：PPTX 提取、代码绘制、生成/编辑或其他来源；生成素材还应保留参考素材、生成指令和最终使用位置，能定位的使用原生调用 ID。

最终交付放在 `output/`。输入文件只读。实现方式、库、工作顺序和验证方法由你选择。
