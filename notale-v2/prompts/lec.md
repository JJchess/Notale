为互动讲义《{query}》编写全套页面共用的 `assets/lec.js`，挂到全局 `Lec`。

`Lec` 只提供计算能力：

- `Lec.K`：主题相关的物理常量、单位换算和关键参考值。
- `Lec.P`：页面会复用的算法与公式；函数名、参数名和返回字段应清楚稳定。

此时页表尚未生成，因此不要假装知道每页的细节。根据题目选择一组紧凑的核心接口：
覆盖讲清主题通常必需的量，优先保留跨页复用或容易算出口径分歧的计算；不要为了“完整”罗列
边缘公式、同义包装函数或猜测性的工具函数。

约束：

- 页面需要展示的关键量应能从 `Lec.K` 读取，需要推导的结果应能由 `Lec.P` 当场计算。
- `Lec.K` 不收 `one`、`half`、`hundred`、`pi` 这类语言或 JavaScript 已有的纯数字别名。
- 不生成 DOM，不写 `mount()`，不处理标题、页眉页脚、导航、样式或任何版面。
- 不把页号或总页数拼成可见字符串。`data-page` / `data-total` 只供底盘计算进度和翻页。
- 使用 ES5 兼容的 IIFE，不依赖第三方库，必须能在 `file://` 下运行并通过 `node --check`。

输出一个完整文件，放在唯一一个标注为 `js` 的 Markdown 代码围栏中；围栏外不要输出其他代码块。
