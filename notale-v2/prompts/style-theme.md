## 边界

只定义 token 和一段风格契约。**不写任何形状**：没有 `border-radius`、`border`、`display`、
`position`、`box-shadow`、组件类、页眉页脚、utility 类。各页怎么排、有没有框、圆角多少,
由建页 agent 按内容自己决定。

**也不发「面」。** 不许定义承载面、底板、卡片底、面板、容器背景这一类 token
（`--surface` `--panel` `--card` `--board` 及其同义词一律不要,`--bg` 只有一个,就是整幅画面的底）。
内容的分组靠留白、对齐和共享基线,不靠给每块垫一层底色。

线条 token 只能有一个,并且必须在接口块里写死用途:**坐标轴、刻度、真实的分隔线;
不得用于包裹或圈起任何区块**。

必须包含：

    :root { --pad-x: 56px; --pad-y: 28px; }

定义 `--bg`、`--text`、`--muted`、`--focus`、`--font-sans` 与必要的语义色槽位。
`--muted` 与底色至少 4.5:1。不用 `@import`、不联网。

字阶 token：`--fs-h1 34px` 页标题；`--fs-h2 22px` 区块标题；`--fs-lead 19px` 导语；
`--fs-body 18px` 正文；`--fs-sec 16px` 次级成句；`--fs-label 15px` 标签；
`--fs-tick 13px` 纯数字刻度。{font_floor}只可上调。

## 接口块

文件第一段必须是下列定界符包住的接口块,逐行列出每个 token 的 hex、唯一语义和允许位置,
外加四行契约。未列出的 token 等于不可用。

    /* ==== INTERFACE ====
       token  --bg #101418        页面底色
       token  --model #2457A6     当前模型值｜预测、前向箭头
       token  --fs-body 18        正文
       版心   1488×844            #stage 已含 padding
       论点   一句话说清这套画面为什么长这样,以及它跟题材的关系
       材质   一句话:纸/金属/墨/玻璃/粉笔…,以及它如何由题材而来
       签名   一句话:整套里唯一那个让人记住的视觉手法
       禁令   三条,由你这次的选择推导,不是通用清单
       修订   一句话:我原本会选什么,为什么改掉
       ==== /INTERFACE ==== */
