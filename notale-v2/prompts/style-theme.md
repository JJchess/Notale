## 字体与可读性
使用已加载详情中的中英字体搭配和真实 @font-face 声明；主要字体随包交付，不依赖服务器安装。
选择需要的字体与字重声明写入 CSS；宿主自动复制被引用的 fonts/library/ 文件及授权，不用再取字体。
用户提供的字体及明确要求优先，不擅自换成库内字体。没有可用文件则说明未满足，不能发明 family。
修改已有主题时，新要求覆盖相应旧默认值：指定新风格须落实其字体搭配或说明替代原因；只改配色则保留未要求改动的字体。
混排通常把英文字体放在中文字体之前，确保拉丁字符命中指定英文；中文字体承接汉字与中文标点。
数字字体不等于完整标签字体；含中文的图注、图例和数值说明必须有中文承接字体，纯数字无需额外 CJK。
标题、正文、数字角色分开；像素/窄斜/装饰字不强迫用于长正文。尊重实际字重与字姿，不靠合成粗斜体冒充资源。
得意黑是固有 italic，必要时用局部语言样式区分英文字姿。通用族只作兜底，不声称兜底就是还原。
语言分支使用 .nt-title:lang(zh) 等能匹配继承语言和 zh-CN 的选择器，不只匹配显式 [lang="zh"]。
同一混排栈的中英字重不同时，分别给局部语言元素声明真实字重；需要避免浏览器合成时使用 font-synthesis:none。
定义 --bg、--text、--font-sans，以及 --muted、--focus、所需语义色、字阶和间距。
{font_floor}正文和图注清楚可读；提供 --fs-h1/h2/lead/body/sec/label/tick 等可用字阶。
明确普通页题名、区块标题和封面强调的角色、默认字号/字重/行高及中英主次；同套同角色保持同一默认排版，不让 Builder 每页重新选字阶。
新创主题沿用 --fs-h1 为普通页题名、--fs-h2 为区块标题的命名惯例；具名标题类与它声明的角色对应。封面可有明确的强调用法，不强制所有标题等大或每页双语。
复用或修改已有主题时按实际接口理解角色，不仅因 h1/h2 命名不同重解释或重写主题；只改用户要求改变的部分。
不固定 padding 或唯一线条数。不依赖网络、@import 或嵌入式 data URL。
字号和排版尺寸按固定逻辑画布设计，用逻辑 px 或基于稳定逻辑尺寸的相对单位；不随外部视口的 vw/vh 或宽度断点二次缩放。
em、calc()、clamp() 可用，但基准不得随外部视口变化；整体缩放只交给底盘。

## 原生 CSS 边界
根 token 与 html[data-variant="名称"] 配对切换前景/背景；未设置属性为默认。
#stage 可写 background-color/background-image 的多层图与渐变；提供相容底色和无图状态。
变体换图层时配套检查 background-size/position/repeat；多层属性列表会循环匹配，整幅圆弧/色带不能误用基础网格的小块尺寸。
整幅形体通常整幅尺寸、不重复；故意平铺的网格/纹理保留对应尺寸与重复方式。共用值可留基础规则，不机械复制声明。
只提供确有用途的变体；默认、开篇、操作状态可有强弱差异，但保留同套形体与排版依据，不要求固定变体名。
不写 data-backdrop 开关；不覆盖舞台 position/transform/width/height/overflow 等缩放机制。
局部字体、边框、圆角、阴影、玻璃与控件状态写在具名 .nt-* 及其子元素上。
不全局重置 div/button 或第三方组件。Builder 决定每页几何、排版与交互，不给整套固定页面骨架。
具名局部样式是可用基础，不是必用清单；Builder 可在主题方向内创作本页的视觉主体、图形和局部表达。
按钮、节点、线条等共享视觉样式及 hover/focus/aria-pressed 等通用状态外观可以保留；Builder 决定何时选中、显示哪些对象以及它们的关系。
不要预设训练集/验证集、已读词等领域语义或数据结构，不要求页面遵循隐藏的 DOM 组合协议，也不规定“唯一允许的操作台”。
图表样式区分线、点、文字：曲线的 fill:none、粗 stroke 不得无差别命中文字；用元素限定选择器或用途类，不定义数据与坐标。
通用曲线/节点样式不绑定具体数据系列；通过 currentColor 或公开的局部 CSS 变量承接系列颜色，由 Builder 按内容赋值，不暗藏 validation 等状态入口。
需要 SVG 与 ECharts/Canvas 共用的笔触、点和标签样式不能只藏在私有选择器里：实际需要的共享值用少量 CSS 变量公开，并说明用途、单位和必要用法，不要求逐线像素一致。
供 JS 直接读取的数值保持可直接使用；复杂表达式须从适用元素的 computed style 解析。不造固定图表 token 表或 adapter，无需要不造图表系统。
根与公开接口禁止 --surface/--panel/--card 等无用途的容器底色许可；
具名局部控件实现中的私有 --surface 可以使用，不因此要求每段内容有面板。
logo 只在明确提供/要求时定义于 #stage::after；该层由底盘保留，内容低于 z-index:100 并留净空。
无 logo 不生成可见品牌，图中示例品牌不可冒用。其他伪元素可自由使用。
不覆盖 hidden、焦点、指针或 reduced-motion 行为。代码页独立，不优化或覆盖代码工作台。

## 简短公开接口
文件首段用以下完整定界符，列实际可用的 token、class、variant 与必要净空。
说明实际可用的字阶、字体角色及必要组合关系，不只写“高对比标题”等空泛名称；写出必要排版角色的少量值，与下面的 CSS 一致，不抄全量 token 或实现选择器，也不强制写论点/材质/签名/修订自述：
/* ==== INTERFACE ====
方向：本套共用的排版、形体与材质依据；组合参考说明如何协调，不规定每页布局。
token --bg：页面底色。
token --text：正文。
token --font-sans：正文与控件字体。
class .nt-title：普通页题名的实际字体、字号/行高及主次语言；区块标题、封面强调若不同，分别说明实际用法。
variant opening：开篇外观、与默认的共同点及适用净空（如确实定义）。
默认：不设 data-variant；说明无图状态。
品牌：若存在，说明位置、尺寸和净空。
==== /INTERFACE ==== */
接口只能列实际实现的项。实现写在下面的原生 CSS 中。
凡 Builder 必须写进 DOM 的类名、宿主关系和组合限制，都属于公开用法，不能以私有实现为由省略。
复杂样式给一个与你的实际 CSS 一致的最小 HTML/SVG 例子，区分线、点、文字的用法即可；不要求统一图表类名或创建组件库。
标题/正文类不限定宽度、列数或页面位置，避免把页面几何藏进共享字体样式。
