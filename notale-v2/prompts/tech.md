# 技术契约

## 固定骨架

    <!doctype html>
    <html lang="zh">
    <head>
      <meta charset="utf-8">
      <link rel="stylesheet" href="assets/base.css">
      <link rel="stylesheet" href="assets/theme.css">
    </head>
    <body data-page="NN" data-total="{n_pages}">
      <div id="stage"></div>
      <script src="assets/base.js"></script>
    </body>
    </html>

## 版面

- 只修改 `#stage` 内容；不把页码显示给读者。
- 目标 HTML 由你从零创建；不修改 `assets/`，不新建旁路文件，不读其他 `page-*.html`。
- 每页是一个不可滚动的画面。`#stage` 就是这块画面，坐标系 {canvas_w} × {canvas_h}
  （底盘负责缩放铺满视口）。元素可以用 `position:absolute` 直接落在坐标上；
  画面主体可以 `inset:0` 满幅铺底，文字压在它上面。
  flex 和 grid 留给真正的行列关系，需要收缩的子元素加 `.min0`。
- 不移除或覆盖 `.min0`、`.cv-fill`、`.no-pan` 的机制；`position:fixed` 会脱出缩放，不能用
  （`absolute` 相对 `#stage`，不受影响）。

## 构图

- 内容分组不自动等于独立底板；可用邻近、对齐、间距和文字层级，也可使用主题中适合本页的风格化容器。
- 先定这一页的主对象和对象之间的关系，再安排说明与操作；不得先划出几块面板再往里填内容。
- 弱化不合适的底板时，同时收回仅为外壳设置的空白；保留必要绘图区净空、布局与事件绑定、控件命中区。
  换浅彩底或把 div 改成 SVG rect，不等于解决默认套壳。
- 创建前确定主证据、对象关系／状态和说明依附位置；reference 的问题用于完善这同一份决定，
  不另写契约、声明或构图说明。

## 视觉

- 字号使用主题 token 或具名排版类；类内的相对字号也是合法主题实现，不要求最终像素值等于某个根 token。{font_floor}
- 颜色、字体、具名局部样式和变体取自 `<theme_css>` 接口，CSS 实现由浏览器加载；本页决定几何与构图。
  Director 定主题方向，你决定本页主体、布局和交互；把适用的形状、笔触、材质或图像处理落实到主体、图解、批注或操作，不只取背景色和字体。
  类名可以不用，同类角色的视觉依据仍沿用主题；可自行实现，不必添加所有装饰，也不另造一套皮肤。reference/Main 样例教内容关系与实现方法，其默认外观不覆盖最终主题。
  常规实现使用预置接口；首版之后遇到具体样式问题才定点读 `assets/theme.css`，不能修改或复制共享实现。
  语义色遵守声明用途，装饰可使用主题允许的强调；不自行建立跨页概念映射。
- 舞台内字号与排版尺寸以固定逻辑画布为基准，不用外部视口单位或宽度断点二次缩放；整体适配只交给底盘。
- 图表初始化前在 html 选择已声明的 data-variant，SVG 用 CSS，Canvas 通过 Deck.token() 读根值；
  局部反色需读对应元素的 computed style。不要用 #stage 的 background 简写清空主题背景合成。
- 中英标题、正文、数字沿用主题各自的字体接口，不以本机宋体/雅黑替换。中英字姿不同可用局部语言元素承接。
  普通页题名、区块标题与封面强调按本套接口选用，同角色沿用同一默认排版；按实际角色理解 token，不因名称 h1/h2 擅自重新解释已有主题。
  先调整标题区域、换行和图文关系，不每页另选一个字阶或随意缩标题来塞入单行；标题换行后的高度必须留给后续导语和图形，不能按单行假设写死它们的位置。
  封面和正文可按接口有不同尺度，单语内容不必凑双语；不是所有标题等大。
  含中文的图表标签须使用带中文承接的主题字体栈，不把纯数字字体误作完整混排栈。
  Canvas 测量或绘字前，先对实际字号和字体栈执行 document.fonts.load(font, sampleText)，再等待 document.fonts.ready；
  字号与字体栈从对应元素的 computed style 取得；Deck.token() 是原始字符串，不把尚未解析的 clamp()/calc() 直接拼进 ctx.font。
  字体加载后重绘一次，不能把首次 fallback 的字宽缓存为最终结果。字体文件由主题提供，不由本页重复下载。
- #stage::after 保留给主题品牌，内容低于 z-index:100 并留接口要求的净空；不要覆盖主题资源。
- 一次性尺寸可写内联，不为单页尺寸造公共类。
- 具名样式有宿主作用域时，先挂宿主类再使用子元素样式；只写私有子类可能完全不生效。
  SVG 曲线必须确认实际 fill/stroke，不能把默认黑色填充当作主题效果。
  系列身份不等于元素用途；遵循公开用法区分曲线、点与文字，避免标签套用曲线的粗描边或 fill:none。
  共享按钮/节点/线条的视觉样式可用；数据系列、对象关系和状态切换由本页决定，不把主题装饰或通用选中外观当成正确性判据。
  系列颜色按公开的 currentColor/局部变量或本页 CSS 赋值；主题 CSS 已设置 stroke 时，SVG 的 stroke 属性不会覆盖它，不依赖隐藏的领域状态入口。
  ECharts/Canvas 也承接主题公开的笔触、点形和标签关系，不只取颜色后沿用库默认皮肤；在现有图表配置里使用共享值，不换库、不建 adapter。
  同类图形沿用主题的线条气质和主次关系；不额外建立逐线像素对齐或渲染器补偿流程，数据可区分性与几何仍由本页负责。
  若需全屏盖白才能压住主题，优先选择已有安静变体或调整布局；局部净空遮罩仍可用，无可读状态则报告主题缺陷，不改共享 CSS。

- 图表优先用已安装库，不重复实现成熟能力；ECharts 必须用 SVG renderer 并显式设置可读字号。

## 数据

教学常量、范围、初值和结果，以本页内容里写明的真实数值为准，需要推导的当场计算。
禁止预录结果或展示假数据；随机生成、抽样和初始化必须使用固定种子。
首屏静止状态就要包含可讲的信息。

## 图片

优先用本页 brief 中的素材；有实际需要可用 ImageSearch / ImageGen 补图，看结果后采用。
真实对象用搜索图片，数据与精确几何自己绘制；来源保留在 `<img title="…">`，不挤入主画面。
