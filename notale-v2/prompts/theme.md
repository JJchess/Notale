## 输出职责

这份 CSS 只负责四类共享能力：

1. 颜色、字体和字阶 token。
2. 全套统一的版心与每种实际版式。
3. 四种知识关系的骨架原语。
4. 页面会复用的读数、控件、图例、提示和媒体包裹组件。

不要生成页眉页脚，不定义 `mount()`，不替页面安排标题位置。不要制造 utility 类或间距阶梯；
一次性的尺寸、gap 和 flex 份额由页面内联设置。

## 固定版心

必须原样包含：

    :root { --pad-x: 56px; --pad-y: 28px; }
    #stage { display: flex; flex-direction: column; padding: var(--pad-y) var(--pad-x); }

逻辑画布是 {canvas_w} × {canvas_h}。`#stage` 的 padding 已经定义版心，页面不得再加外层边距。
顶层区域使用固定高度或 flex 份额，主内容区使用 `flex:1`。

`base.css` 已提供舞台缩放、reset、`[hidden]`、`.sr-only`、`.min0`、`.cv-fill`、`.no-pan`、
`:focus-visible` 和 `prefers-reduced-motion`；不要重复或覆盖这些机制。

## Token

至少定义 `--bg`、`--text`、`--font-sans`、`--focus`，以及规划列出的每一个「需要专属色的概念」。
**hex 由你挑**——规划只说了哪些概念需要专属色、各自代表什么，一个概念对一个 token，
不得合并两个概念到同一个颜色，也不得让一个颜色兼任第二种用途。中性元素用灰阶。

**语义色的权威声明只在接口块**：每个有概念含义的 token 都在那里写清 hex、唯一含义和
允许出现的位置，建页 agent 只读接口块就能判断某个颜色能不能用在手头这个元素上。

定义职责明确的字阶 token，名字必须编码用途。**七个档位，各档的像素值和相邻比例由你定**，
定完在接口块的 `## 字阶与字体角色` 里写清依据：整套是不是等比、比例是几、为什么这一课的
内容适合这个比例。

    --fs-h1     页标题
    --fs-h2     区块标题
    --fs-lead   导语或强调正文
    --fs-body   正文
    --fs-sec    次级成句说明
    --fs-label  控件、图例、图注、提示
    --fs-tick   仅纯数字刻度

一套字阶要让人一眼看出档位差别。相邻两档差得太小，画面上就只剩一种字号，层次全靠加粗撑——
上一轮七档落在 34/22/19/18/16/15/13，中间五档相邻比例是 1.10、1.11、1.13、1.07、1.15，
那不是一套字阶。

成句文字不得使用 tick 或 label 档。{font_floor}可以按受众和场合上调，不得下调地板。

`--font-sans` 点名的中文家族**必须在渲染机上真实存在**，否则中文会静默掉到系统兜底字体，
一行里混出三种字形而页面照样打得开。这台机器上装了的中文家族只有：

    Noto Sans CJK SC     无衬线，字重齐全
    Noto Serif CJK SC    衬线
    LXGW WenKai          楷体，笔画有书写感
    AR PL UMing CN       明体，笔画细
    WenQuanYi Zen Hei    黑体，兜底用，不要主动点名

注意 `Noto Sans SC`（少了 `CJK`）**在这台机器上不存在**，写了等于没写。
西文家族和中文家族分别点名、西文在前中文在后，混排时数字和西文标点归西文家族管。
不要引 CDN 字体，也不要 `@font-face` 指向 `assets/` 之外的路径。

## 版式与知识骨架

为输入列出的每个版式提供同名类，并让其几何与名称一致；不要用一个万能两栏冒充全部版式。
版式只定义区域关系，不规定某页的具体内容。kicker 须与标题同栏堆叠，不得排成同行两栏，也不做成边框徽章。

四种知识骨架都必须提供可拼装原语：

- `.k-process`：阶段 `.step` 由 `.arw` 或贯穿的 `.axis` 连接，方向可见；不能只是并排。
- `.k-comparison`：`.dim`、`.hdr`、`.rowline`、`.diff` 形成同行、同尺度、同基线比较。
- `.k-classification`：`.lv`、`.box`、`.bt` 用嵌套、包含或缩进显示归属。
- `.k-generalization`：`.claim` 比 `.supports > .support` 更重，支撑挂在 `.trunk` 主干上。

骨架类是默认工具，不限制页面使用 SVG、Canvas 或图表表达同一关系。

## 共享组件

提供一套紧凑而完整的组件，状态必须可用：

- 数值：`.big`、`.big.sm`、`.big.lg`、`.num`、`.unit`；数字使用等宽或 tabular nums。
- 操作：`.hint`、`.btn`、`.btns`、`.ctl`、`input[type=range]`；包含焦点、选中和禁用态。
- 标记：`.tag`、`.legend > .li > .sw`、`.sw.line`。
- 媒体：`.cvbox` 只负责定位、圆角和裁切。
- 作答：`.quiz`、`.opt`、`.fb`；选中态与正确性分开，不默认使用红绿对错色。
- 文字：`.lead`、`.small`、`.note`。
- 仪器容器：`.panel`；`.panel.q` 保留同样边距但不填色。

共享组件不用粗色侧边条、渐变文字或装饰边框 hero-metric 卡片做默认样式。

表面层级保持克制：舞台底色之外，填色主要留给 `.panel` 这类读数或控件区域；
`.step`、`.it`、`.lv`、`.box`、`.cvbox` 等骨架原语用线、缩进和字号表达关系，不堆多层卡片底色。

**但压掉了卡片底色，就必须给层次另一个承担者**，否则整页只是平的。在接口块的
`## 层次语言` 里声明这套系统靠什么拉开前后关系——色块反转、线宽 family、留白节奏、
材质（阴影或纹理）任选，也可以自定——并在 `## 不许` 里把没选的那几种禁掉。
选一种并贯彻，比每样来一点更像一套系统。

`.backdrop` 用于整页氛围图：绝对定位铺满、`object-fit:cover`，通常压到 `opacity:.16–.22`，
或使用由 `--bg` 推出的高不透明罩层；`.backdrop-note` 放在不遮挡内容的角落。

文件末尾加入 SVG 防覆盖规则：

    svg .bar, svg .step, svg .cell, svg .box, svg .arw { width:auto; height:auto; }

## 接口块

文件第一段必须是接口块。**它是这份 CSS 到建页 agent 的唯一通道。**

建页的 {n_pages} 个 agent 并行工作、互相看不见，而且不许打开 `assets/` 下的实现源码。
所以块里没写的类和 token，对它们来说就是不存在——然后它们各自发明一个。
上一轮块里只点到 61 个类里的 33 个、23 个 token 里的 18 个，平均每条 45 字符，
结果是页面内联 CSS 长出 466 个自造类、86,411 字符，是这份共享主题的 5.3 倍，
`.btn` 被 10 页各自重定义、`.claim` 9 页、`.kicker` 8 页。

块的内容是 markdown，八节，顺序固定，一节都不能少：

    /* ==== INTERFACE ====

    ## 视觉论点
    ## 调色板
    ## 字阶与字体角色
    ## 形与处理
    ## 层次语言
    ## 类名录
    ## 不许
    ## 加新东西时

    ==== /INTERFACE ==== */

每节要交付的东西：

**`## 视觉论点`**——一段话。这套系统是什么、借自哪个物质世界、为什么这一课该长成这样。
不罗列 token，那是下一节的事。

**`## 调色板`**——每个有概念含义的 token 一行：hex ｜ 唯一含义 ｜ 允许出现的位置。
中性灰阶也要列。**`--` 开头的 token 全部列完**，不要只列语义色——漏掉的那个下游就得自己配。

**`## 字阶与字体角色`**——七档各自的 px 值、角色、什么内容该用它，以及整套的比例依据。
字体家族按角色写清：西文谁、中文谁、数字谁。中文配对单独说一句：点名的中文家族在这台机器上
真实存在，中西混排时数字和西文标点归谁管。

**`## 形与处理`**——圆角、线宽、间距节奏、边缘处理各有**几档、分别是多少、什么时候用哪一档**。
给具体数值，这是下游唯一能对齐的依据；只写"克制"、"统一"这类形容词等于没写。

**`## 层次语言`**——这套系统靠什么承担层次，以及主层、次层、背景层分别长什么样、
怎么把两个相邻层拉开距离。这一节的选择必须在 `## 不许` 里有对应的禁令。

**`## 类名录`**——CSS 里定义的**每一个**类都要在这里出现，**一个不漏**。一行一个：

    `.选择器`  —— 用途｜什么时候该拿它｜和谁组合

状态修饰类（`.btn.on`、`.panel.q`）跟在主类那一行里说完，不另起一行。
这一节是块里最长的一节。写的时候对着 CSS 从头到尾数一遍，不要凭印象。

**`## 不许`**——8–12 条**这套系统特有**的禁令，每条给理由，而理由要指回这套系统的选择。
不要写通用排版常识（"不要用太多字体"这种谁都适用的话，写了不产生任何约束）。
参考这个形状：

    不要用 2px 以上的边框。1px 发丝线是这套系统的结构节奏，加粗一条就把整页的层级打乱。
    不要加 box-shadow。这套系统的纵深全部来自色块相邻，投影会让两种纵深语言互相打架。

这两条互相矛盾、各自都对——因为它们是各自系统**选择的后果**，不是普遍真理。
你的禁令也要是你这套系统的后果。

**`## 加新东西时`**——8–10 条「任何新的 X 都是 Y，从这个梯子里挑，不要发明」。参考形状：

    任何新标题都是 Noto Serif CJK SC 400，从 --fs-h1/--fs-h2/--fs-lead 里挑，不要发明新字号。
    任何新的分隔都是 1px 发丝线，不要用间距翻倍或加底色来代替。
    任何新的容器都是 .panel 或 .panel.q，不要新建一种卡片。

这一节是直接写给那 {n_pages} 个互相看不见的 agent 的：能让它们做出同一个决定的，只有这几句。

**运动词汇也在这一节声明。** 用 `[data-anim="名字"]` 加可选的 `[data-delay="0|1|2|3"]`，
在 CSS 里给出对应的 `@keyframes` 和 `animation`。名字有限、含义固定，例如"入场上浮"、
"读数跳变"、"沿轴推进"。`base.css` 已经在 `prefers-reduced-motion` 下全局压掉动画，
不需要额外的 JS；页面要逐帧动画时用 `Deck.loop`，那是另一回事。

### 一份完整样例

下面这份是**另一套系统**（暖纸墨线，与你手上的视觉世界无关）。
照抄它的**结构和详细程度**，不要照抄它的任何一个决定：

    ## 视觉论点

    这是一张摊在工作台上的墨线图纸。所有信息都画在同一张暖白纸面上，没有浮起来的卡片，
    也没有第二层背景——纵深全部由线的粗细和留白的疏密造出来。这一课讲的是尺度之间的换算，
    读者要能把两个量放在同一根基线上比，所以画面必须共享一个平面，任何"浮起"都会暗示
    它们不在同一个量纲里。

    ## 调色板

    `--bg`        #F4F0E8  纸面。整页唯一底色，任何区域都不许换第二种底色
    `--text`      #1C1A17  墨。正文、标题、轴标
    `--ink-2`     #5B564E  淡墨。次级说明、图注、刻度文字
    `--rule`      #C9C2B4  线。所有分隔线、轴线、边框，只此一档颜色
    `--measure`   #1B5E7A  量。被测量的对象本身｜柱、点、轴上的实体
    `--derive`    #A8560F  算。由公式推出的值｜预测线、结果读数、结论箭头
    `--focus`     #A8560F  焦点环，与 --derive 同色，聚焦即"正在算"
    ……（其余 token 同样格式列完，一个不漏）

    ## 字阶与字体角色

    整套按 1.25 等比，从正文 18px 两头推。等比是因为这一课的内容层级只有三层
    （主张 / 支撑 / 刻度），比例太密会让三层塌成一层。

    `--fs-h1`    35px  页标题。每页只出现一次
    `--fs-h2`    28px  区块标题、比较表的列头
    `--fs-lead`  22px  导语、收束句、需要被读出来的那一句
    `--fs-body`  18px  正文
    `--fs-sec`   14px  次级成句说明、图注
    `--fs-label` 12px  控件标签、图例、提示
    `--fs-tick`  11px  纯数字刻度，只许放数字

    西文 `Source Serif 4`，中文 `Noto Serif CJK SC`，数字 `Source Serif 4` 的 tabular nums。
    中西混排时数字和西文标点归西文家族，中文标点归中文家族；两者 x-height 接近，
    不需要为中文单独调 font-size。标题用 400 字重不用 600——这套系统的强调靠字号不靠字重。

    ## 形与处理

    圆角只有两档：`0`（面板、分隔、轴、表格等所有结构元素）和 `3px`（仅按钮和输入控件，
    表示"可以按"）。出现 8px 以上的圆角就说明有人在造卡片。

    线宽三档：`1px`（`--rule` 色，所有分隔和边框）、`2px`（`--measure` 色，被测量的实体）、
    `3px`（`--derive` 色，推导出来的结果）。**线宽本身就是语义**，不许为了"好看"改线宽。

    间距节奏是 8 的倍数：8 / 16 / 24 / 40 / 64。同组 8–16，组间 24–40，区域间 64。

    边缘一律硬边，不用渐变淡出、不用模糊。

    ## 层次语言

    **留白节奏 + 线宽**，只此两样。

    主层：正文与主张，`--text`，四周留 40 以上。
    次层：支撑与说明，`--ink-2` + `--fs-sec`，紧贴主层 8–16，靠"贴得近"表示从属。
    背景层：轴、网格、刻度，`--rule` 的 1px 线，永远在最下，不与文字争。

    两个相邻层拉开距离的唯一手段是**留白翻倍**：次层与主层之间 16，主层与主层之间 40。
    不靠底色、不靠投影、不靠加粗。

    ## 类名录

    `.canvas-full`    整页单区版式｜一页只有一件事时用｜和 .k-* 组合
    `.split-2`        左右两区，比例 3:2｜左说明右图示｜和 .k-comparison 组合
    `.k-process`      阶段流程骨架｜有先后顺序时用｜内含 .step 和 .arw
    `.step`           一个阶段｜只放在 .k-process 里｜不要单独用作卡片
    `.arw`            阶段之间的箭头｜.step 之间必须有它，否则方向不可见
    `.panel`          读数与控件容器｜唯一许填色的容器｜内含 .big / .ctl
    `.panel.q`        同样边距但不填色｜画面上已经有一个 .panel 时用第二个
    `.big`            主读数｜一页最多一个｜内含 .num 和 .unit
    `.big.sm`         次读数｜同页有多个读数时，非主读数用它
    `.num` `.unit`    数字与单位｜必须成对｜.num 是 tabular nums，单位不跟着变宽
    ……（CSS 里的每一个类都照这个格式列完，一个不漏）

    ## 不许

    不要把圆角开到 8px 以上。这套系统的结构元素一律直角，圆角一大就变成浮起的卡片，
    而这张图纸上没有"浮起"这个概念。

    不要加 box-shadow 或任何形式的投影。纵深全部由留白节奏和线宽承担，
    多一种纵深语言就会和留白打架，读者不知道该信哪个。

    不要用底色区分区域。整页只有 `--bg` 一种底色，区域靠 1px 线和留白划分；
    加一块灰底看起来"清楚了"，实际是把留白节奏这条唯一的层次线索作废了。

    不要用加粗表示强调。强调靠字号跳档，字重全程 400——
    这套系统的字阶是等比的，跳一档就足够，加粗会让等比关系读不出来。

    不要给线换颜色来表示状态。线宽三档已经编码了语义（结构 / 实体 / 推导），
    再叠一层颜色语义，两套编码会互相覆盖。

    不要用红绿表示对错。`--derive` 是"算出来的"不是"对的"，
    这一课要读者判断推导是否成立，预先染上对错色就把判断替他做了。

    不要在正文里用 `--fs-label` 或 `--fs-tick`。那两档是给标签和刻度的，
    成句文字掉到 12px 以下，投影到教室后排就不可读。

    不要新建间距值。这五档之外的数字会打断节奏，而留白节奏正是这套系统的层次语言本身。

    ## 加新东西时

    任何新标题都是 `Noto Serif CJK SC` 400，从 `--fs-h1` / `--fs-h2` / `--fs-lead`
    里挑一档，不要发明新字号。

    任何新的分隔都是 1px 的 `--rule` 线，或者把留白提到下一档，二选一，不要两个一起上。

    任何新的容器都是 `.panel` 或 `.panel.q`，不要新建卡片类。

    任何新的读数都是 `.big` / `.big.sm` / `.big.lg` 加 `.num` + `.unit`，
    不要直接写 font-size。

    任何新的颜色需求，先回到调色板里找语义最接近的那一个；
    找不到说明这个元素的概念含义还没想清楚，不要调一个新 hex 出来。
