# 风格轻索引

40 项用户参考的入口。默认只把下表交给 Director；选中后 Read 对应 ID，一次取得详细资料、原参考图和中英字体声明。明确匹配名称/ID时直接预载详情。概览仅供人工浏览，不再默认进入模型输入。

每项详情提供首选字体、使用条件、构图、材质、配色结合和边界，不是 CSS 配方、固定页型或继承层。用户要求优先，允许组合及表外方向。
