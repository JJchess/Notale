神经元的两个可学习参数

权重改变证据力度，偏置平移触发门槛

保持输入与权重不变，只改偏置：每项输入证据都没变，但神经元更容易或更难被触发。

输入证据 × 对应权重
0.8×1.2=0.96
输入 x₁权重 w₁贡献
0.4×−0.5=−0.20
输入 x₂权重 w₂贡献
证据合计0.96 − 0.20 = 0.76
x、w 均保持不变
同一份证据，加上不同偏置
偏置 b = −0.40
0.76 − 0.40 = 0.36
偏置 b = +0.40
0.76 + 0.40 = 1.16
z = Σwᵢxᵢ + b

偏置直接加在证据合计上，不与任何输入相乘。

当前净输入
1.16
越过 z = 0，神经元进入触发侧

把 b 从 −0.40 调到 +0.40，相当于把整条触发边界平移 0.80。

权重 wwᵢxᵢ

决定每项输入证据放大、削弱还是反向。

输入变了，该项贡献也随 xᵢ 成比例变化。
偏置 bΣwᵢxᵢ + b

给所有输入组合加同一个平移量。

它不代表新的输入证据，只调节触发门槛的位置。
