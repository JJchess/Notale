# page-01 [标题页]
神经网络是怎么学会的：从一个神经元出发，追踪预测、误差与反向传播如何连成学习闭环。

# page-02 [目录页]
全套依次回答神经元怎样计算、误差怎样度量、梯度怎样指路、误差信号怎样反传，以及训练怎样真正发生。

# page-03 [标题页]
第一章：一个神经元怎样做预测——本章回答输入、权重、偏置和激活函数如何共同产生输出。

# page-04 [内容页·static]
把单个神经元理解为“先对输入加权汇总，再经过激活函数”的两步计算，而不是缩小版的生物神经元。

# page-05 [内容页·interactive]
让读者亲手改变输入对应的权重，观察每项贡献如何改变加权和，从而形成“权重决定在意什么”的直觉。

# page-06 [内容页·static]
对照偏置与权重的职责，理解偏置是在所有输入不变时平移触发门槛，而不是另一项输入证据。

# page-07 [内容页·interactive]
让读者移动加权和穿过激活函数，观察连续得分如何被压缩或截断为神经元的输出。

# page-08 [标题页]
第二章：模型怎么知道自己错了——本章回答目标值、预测值与损失函数如何把“差得多远”变成可优化的量。

# page-09 [内容页·static]
并列区分预测、目标与损失，明确损失不是新的答案，而是衡量当前答案与目标之间差距的标尺。

# page-10 [内容页·interactive]
让读者拖动预测值并观察损失曲线，亲自确认同样大小的方向偏差会怎样映射为不同程度的惩罚。

# page-11 [内容页·static]
从单个样本扩展到一批样本，理解训练目标通常是让总体损失下降，而不是把某一个例子记到完美。

# page-12 [标题页]
第三章：梯度怎样指路——本章回答局部斜率如何告诉参数该往哪边改，以及步子为何不能随便定。

# page-13 [内容页·static]
把梯度理解为“参数稍微改变时损失变化得多快、朝哪个方向变化”的局部信息，而不是直接给出的最佳参数。

# page-14 [内容页·interactive]
让读者在损失曲线上选择位置并试走一步，用即时结果建立沿负梯度方向下坡的几何直觉。

# page-15 [内容页·interactive]
让读者调节学习率，对照过小导致停滞、适中稳定下降与过大来回越界这三种训练轨迹。

# page-16 [标题页]
第四章：反向传播怎样分配责任——本章回答输出端的误差如何沿计算链返回，并为每个参数算出自己的梯度。

# page-17 [内容页·static]
沿一条短计算链拆开链式法则，理解总影响等于路径上各段局部影响相乘。

# page-18 [内容页·interactive]
让读者改变链中任一局部导数，观察它如何放大、削弱或截断传回更早参数的误差信号。

# page-19 [内容页·static]
在同一计算图中对照前向传播保存中间量与反向传播复用这些量，明确反向传播是在高效计算梯度而不是倒放预测。

# page-20 [内容页·interactive]
让读者为分叉网络判断各参数应承担多少误差，再用路径求和结果校正“谁影响大谁多负责”的直觉。

# page-21 [标题页]
第五章：一次训练怎样变成学会——本章回答前向、算损失、反向求梯度和更新参数如何循环成可观察的学习过程。

# page-22 [内容页·static]
按时间顺序串起一次训练步，明确数据流向前、误差信号向后、参数更新发生在梯度得到之后。

# page-23 [内容页·interactive]
让读者启动一个页内小网络的训练并暂停检查，观察决策边界、总体损失和参数如何在多轮更新中协同变化。

# page-24 [内容页·static]
对照欠拟合、过拟合与优化不稳定的表现，理解损失下降并不自动等于模型对新数据学得更好。

# page-25 [内容页·interactive]
让读者把打乱的关键环节重新排成学习闭环，并用“预测—比较—归责—更新”检验自己是否形成完整心智模型。
