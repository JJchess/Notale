讲义全篇终章收束

集成不是模型数量竞赛，
而是对误差结构的设计

多模型简单堆叠无法消除系统偏见。真正的泛化飞跃，始终源自三条正交途径：用独立抽样打碎方差、用序列残差咬合偏差、用元学习探索异构决策空间的互补边界。

PATH 01 PARALLEL
Bagging 扰动方差

自助抽样与随机子空间解耦个体相关度，使基学习器误差在均值化中相互抵消。

Target: Var[f̄] → ρσ² + (1-ρ)σ²/M
PATH 02 SEQUENTIAL
Boosting 攻坚偏差

沿损失函数负梯度逐级对齐残差，迫使弱学习器将注意力锁定在前序失败区。

Target: F_m(x) = F_{m-1}(x) + γ_m h_m(x)
PATH 03 STACKED
Stacking 空间仲裁

借助交叉验证预测概率构造次级特征，由元分类器仲裁异构模型的信任权重。

Target: ŷ = g(f_1(x), f_2(x), ..., f_K(x))

核心范式：Bagging / Boosting / Stacking
目标准则：结构化误差抵消
