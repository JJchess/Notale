Bagging 的并行训练与预测汇总

基学习器互不依赖、可全量并行构建；最终通过等权投票或算术平均抵消单模型方差

并行无依赖架构管线 时间复杂度随核心数线性缩减

每个基学习器仅在自身的自助采样集上独立拟合，推断期全量输出并发送入汇总裁决器

决策合成数学形式

H(x) = mode { h_1(x), h_2(x), ..., h_B(x) }
对于多分类问题，全体基学习器采取绝对多数或相对多数投票，各模型地位均等，不设衰减加权。

方差缩减机制：若各单模型预测误差相关系数为 ρ，方差为 σ²，则集成方差为 ρσ² + (1-ρ)σ²/B。当 B 增加时第二项趋向于零，极大减小过拟合波动。
