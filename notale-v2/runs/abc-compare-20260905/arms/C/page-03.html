集成学习的全景图：三种误差拆解范式

集成并非单一范式，而是依据对个体偏差与方差的诊断，通过空间拓扑与信息传递来重组误差结构。

Bagging 体系

Bootstrap Aggregating / 随机森林
并行独立 · 均值化
目标：强行打碎方差 (Var) Var(f̄) ≈ ρσ² + (1-ρ)σ²/T
基学习器要求 高方差强模型（深层决策树）
多样性构造 Bootstrap 样本扰动 + 随机特征切分
工业界代表 Random Forest, Extra Trees

Boosting 体系

AdaBoost / GBDT / XGBoost
串行接力 · 残差拟合
目标：逐步削减偏差 (Bias) F_m(x) = F_{m-1}(x) + γ_m h_m(x)
基学习器要求 高偏差弱模型（单层决策树桩/浅层树）
核心演进逻辑 前后强依赖；后继专攻前序错误样本或负梯度
工业界代表 LightGBM, XGBoost, CatBoost

Stacking 体系

Stacked Generalization / 二层融合
分层异质 · 元学习
目标：多视角互补 ŷ = g(h₁(x), h₂(x), h₃(x))
基学习器要求 异质多元体系（保证假设空间互补）
结合策略 次级模型学习如何对初级预测赋权（非人工固定）
工业界代表 Kaggle/天池竞技冲榜、AutoML 自动集成
本质共性 集成的灵魂是“多样性与互补性”：Bagging 用随机性换低相关性，Boosting 用递进残差逼近真实分布，Stacking 用二层元学习调度专家模型。
