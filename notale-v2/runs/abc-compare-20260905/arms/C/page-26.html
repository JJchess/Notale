集成方法没有绝对优胜者：样本噪声、单模型偏差、基模型相关度与算力预算的联合约束决定了最优方案。

典型场景:
任务与数据环境参数 实时计算预期误差
1. 数据噪声强度 (Noise Variance) 0.25
高噪声增加不可约误差，严重惩罚强拟合算法（如 Boosting 的过拟合倾向）。
2. 单学习器偏差 (Base Model Bias) 0.30
基学习器结构简单造成的系统性欠拟合，Bagging 无法压缩偏差，而 Boosting 针对性削减。
3. 基模型相关度 (Error Correlation ρ) 0.45
相关度越低（模型异构或样本多样），平均与 Stacking 二层融合获得的方差消除增益越显著。
4. 算力/延迟预算 (Compute Budget) 60 FLOPs
算力受限时，耗费多折交叉验证的 Stacking 或深层迭代 Boosting 性能被强力截断。
