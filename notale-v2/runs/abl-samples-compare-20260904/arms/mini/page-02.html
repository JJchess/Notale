集成学习的基本结构

单模型易受样本噪声或特定假设限制而发生局部误判。集成学习通过基学习器多样化、差异化预测输出与确定性聚合规则，将多个弱判断收拢为高稳健度的最终输出。

测试样本场景：
输入样本 x 输入层
特征 x₁: 0.42
特征 x₂: 0.58
真实标签: 类别 1
同一输入向量 x 完整分发给全部成员基模型，由各模型按各自参数独立推断。
基学习器集群 { h_m } Stage 1
基学习器 h₁ 轴对齐决策树
划分规则: if x₁ > 0.45 then C1
采用阶梯正交切分面，易受局部样本扰动影响。
基学习器 h₂ 逻辑回归分类
判别函数: σ(w₁x₁ + w₂x₂ + b)
全局平滑线性超平面，偏置稍大但方差较低。

核空间加权: sign(Σ αᵢyᵢK(xᵢ, x))
依据样本邻域密度弯曲界面，对复杂边界响应敏锐。

基学习器的独立性与多样性

若各基学习器的错误完全重合，集成将毫无增益。差异来源于不同算法偏置、样本抽样分布或特征子空间扰动。

个体误差的分散与容错

单个模型无需在整空间达到完美精度。只要成员在大多数区域保持微弱优势，各成员的局部错误便可相互抵消。

聚合规则的确定性约束

根据任务类型选取硬投票、后验概率加权平均或堆叠元模型，将异质信息无损折算为全局最高置信结论。
