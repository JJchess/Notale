Stacking 的两层结构

基模型预测转为元特征，组合策略不再人工拍板，而是让元模型通过监督训练自动求得最佳拟合权重

传统规则：等权投票 / 简单平均
Stacking：元学习器自适应回归/分类
双层数据流拓扑 (Level-0 → Level-1)
切换样本：
元学习器：从数据中习得的信任权重

元模型通过观察“哪些基模型在哪些特征区间更准”，经由 Ridge 拟合出针对性系数，而非简单平均。

基模型 (Level-0) 输入特征 (z) 习得权重 (w) 贡献项 (w × z)

M₃ (Logistic) 0.45 +0.07 +0.032
偏置常数 b: +0.012
元模型拟合算式: 0.353 + 0.464 + 0.032 + 0.012 = 0.861
ŷ* = 0.42·z₁ + 0.51·z₂ + 0.07·z₃ + 0.012
核心区别：固定融合 vs 学习融合
固定规则 (Voting / Avg) 对所有样本赋予相等或人工指定的固定权重。当基模型弱点暴露时，无法自动屏蔽错误。
Stacking (元学习器) 以基模型预测为自变量进行二次拟合，自动识别各基模型的优势域与互补关系。
