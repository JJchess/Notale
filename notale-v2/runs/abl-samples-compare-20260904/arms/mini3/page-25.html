集成范式抉择：高方差、高偏差与异质互补

根据基学习器的主要瓶颈与多样性来源对号入座：不同集成方法改变预测分布的数学机制截然不同。

当前面对的核心瓶颈： 全部横向对照

Bagging

优先解决高方差

独立并行采样，利用大数定律均化单模型扰动。

基学习器要求 强而敏感（高方差），如未剪枝深决策树
多样性来源 有放回重采样 + 特征随机子空间（随机森林）
数学收益机制 方差降为 ρσ² + (1-ρ)σ²/B，偏差基本不变
工程特点 高度天然并行，对少量离群噪声鲁棒
典型采用场景
特征维度高、单模型极易过拟合；需同时输出袋外估计（OOB）与特征重要度。

Boosting

逐步降低偏差

串行前向加法迭代，新模型专门拟合前序残差或错分样本。

基学习器要求 弱而稳定（高偏差），如深度 3~6 的浅树桩
多样性来源 动态样本分布（AdaBoost）或梯度伪残差（GBDT）
数学收益机制 在前向阶段持续压降偏差；过拟合风险随轮数递增
工程特点 串行依赖强；极度依赖步长收缩（学习率）防过拟合
典型采用场景
表格结构化数据竞赛基准；追求极高精度，且已做足异常值与噪声清洗。

Stacking

异质模型优势互补

训练元学习器，发现不同算法归纳偏置之间的互补区域。

基学习器要求 彼此异质且能力均衡，来自不同数学原理
多样性来源 不同算法假说的空间划分差异（树 vs 凸边界 vs 超平面）
数学收益机制 学习模型预测误差的正交性，由元模型动态加权分派
工程特点 必须用 K 折交叉折外预测（OOF） 构建元特征
典型采用场景
多种模型性能接近但各有所长，追求极致指标且计算预算充足（多阶段管线）。
工程选型诊断准则：
单模型过拟合严重 / 方差主导 ➔ Bagging / 随机森林
单模型欠拟合 / 偏差主导且噪声低 ➔ GBDT / XGBoost / LightGBM
多种不同类模型均已调优 ➔ K 折折外 Stacking
