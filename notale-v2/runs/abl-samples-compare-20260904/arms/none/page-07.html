Bootstrap 重采样：从同一训练集生成多份有重叠但不相同的样本

通过从大小为 N 的原始数据集中进行“有放回抽样”N 次，Bagging 让每个基学习器在保留总体分布的同时感知到不同的局部样本组合。

数学期望与重叠度分析

极限分布定理
单个样本在 N 次抽样中始终未被选中的概率：
P(未入选) = ( 1 − 1 N )N → limN→∞ (1 − 1/N)N = 1/e ≈ 36.8%
无论原始样本量 N 有多大，每个子集天然只覆盖约 63.2% 的独特样本，剩下的 36.8% 未被选中，构成天然的“袋外数据 (OOB)”。
