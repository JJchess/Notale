袋外评估（OOB）：无需独立测试集的无偏性能估计

在容量为 N 的自助采样中，每个样本约有 36.8% 的概率未被抽中；利用这些天然保留的模型子集，无需额外划分验证集即可完成对集成的评估。

袋外概率的极限推导 N → ∞
单次抽取未被选中的概率： 1 - 1/N
N 次有放回抽样均未抽中的概率： P = (1 - 1/N)ᴺ
当样本容量 N 充分大时取极限： lim (1 - 1/N)ᴺ = 1/e ≈ 36.8%

这意味着在森林规模足够时，约 37% 的样本会作为各基分类器的独立检验样本，从而构筑起无需留出集的无偏交叉检验机制。
