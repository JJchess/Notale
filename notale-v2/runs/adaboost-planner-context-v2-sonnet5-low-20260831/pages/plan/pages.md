本套无需图池

# page-01 [标题页]
封面：《AdaBoosting算法》——本套讲义讲清弱分类器如何通过样本重新加权被串成一个强分类器，面向学过概率与线性代数、会写 Python 但没学过集成学习的本科生。

# page-02 [标题页]
第一章：一个分类器不够用——本章回答为什么要把多个"很弱"的分类器组合起来，而不是找一个更强的分类器。

# page-03 [内容页]
用一个具体的二维散点分类问题引出"弱分类器"的定义：只比随机猜稍好一点的简单规则（例如一条竖线或横线切分），让读者看到单条切分线永远切不干净这批点。

# page-04 [交互页]
读者在同一批二维散点上，用滑杆或点选移动一条简单的分割线（垂直/水平/斜线三选一），观察分类错误率如何随线的位置变化，亲手找到"最好也就这样了"的单个弱分类器。

# page-05 [内容页]
讲解集成学习的直觉：多个弱分类器如果各自在不同样本上犯错、彼此错误不完全重合，把它们的判断汇总起来准确率能超过任何单一分类器；用简单多数投票的小例子说明"独立的弱"叠加成"强"。

# page-06 [标题页]
第二章：错误如何指导下一步——本章回答 AdaBoost 具体怎样决定"下一个弱分类器该多在意哪些样本"。

# page-07 [内容页]
讲解样本权重的概念：每个训练样本从相同权重出发，AdaBoost 训练完一个弱分类器后会根据该分类器在每个样本上对不对，调高被分错样本的权重、调低分对样本的权重，让下一个弱分类器被迫更关注难例。

# page-08 [交互页]
在同一批散点上分步演示：先用初始等权重训练出第一个弱分类器，标出被它分错的点，读者点击"进入下一轮"看这些点的权重（用点的大小或深浅表示）被放大，再触发在新权重下训练出的第二个弱分类器，直观看到分割线位置的变化。

# page-09 [内容页]
讲解弱分类器权重（"话语权"）alpha 的计算方式：分类器的整体错误率越低，它在最终投票里获得的话语权越大；错误率恰好为一半时话语权趋于零，错误率很低时话语权很大，建立"错误率与话语权"之间单调的直觉对应关系，不要求记忆具体公式的推导过程。

# page-10 [交互页]
读者通过滑杆调节一个假设弱分类器的错误率数值，实时看到对应话语权数值和一条错误率—话语权曲线上的位置同步变化，体会错误率过半时话语权为何应该是负的（该分类器反过来用更有信息量）。

# page-11 [标题页]
第三章：完整跑一遍算法——本章回答把权重更新、弱分类器训练、话语权计算串起来后，AdaBoost 的完整流程是什么样子。

# page-12 [内容页]
用图文并置的方式完整走一遍 AdaBoost 的算法流程：初始化等权重、循环训练弱分类器并计算其错误率与话语权、更新样本权重并归一化、多轮之后把所有弱分类器按各自话语权做加权投票得到最终强分类器，让读者看到一张完整的流程全貌。

# page-13 [交互页]
在同一批散点数据上，读者通过"训练下一轮"按钮逐轮驱动完整的 AdaBoost 流程（每轮同时展示新弱分类器的分割线、样本权重的变化、当前轮的话语权数值），并实时叠加显示当前所有弱分类器加权投票后的整体分类边界如何随轮数增加变得越来越贴合真实分类。

# page-14 [内容页]
讲解为什么加权投票得到的整体边界会比任何单个弱分类器都复杂、都准：每个弱分类器只负责切出简单的一刀，但不同轮次的分割线因为聚焦在不同的困难样本上而互补，叠加后可以拼出弯曲、分段的决策边界。

# page-15 [标题页]
第四章：动手实现与验证——本章回答如何用代码从零实现 AdaBoost，并检验它训练误差如何随轮数下降。

# page-16 [交互页]
读者在页内直接阅读并运行一段 AdaBoost 的核心 Python 代码（权重初始化、单轮弱分类器训练、权重更新、投票组合），可以修改弱分类器数量等参数后重新运行，观察右侧同步刷新的训练误差曲线随弱分类器数量增加而下降的过程。

# page-17 [交互页]
读者调整同一份代码里的训练轮数或数据噪声比例并重新运行，对比观察训练误差持续下降但在噪声较高或轮数过多时代码是否出现过拟合的迹象，引出"AdaBoost 也不是轮数越多越好"的边界意识。

全套收束：回顾从"单个弱分类器"到"样本重新加权"到"按话语权加权投票"再到"代码验证误差下降"的完整链条，呼应封面提出的问题。
