本套无需图池

# page-01 [标题页]
封面：本套讲义标题与总览——AdaBoost：一群弱分类器如何投票成为强分类器，60分钟课程脊线预告各章。

# page-02 [内容页]
提出本章问题：单个简单分类器（如一条阈值线）为什么常常不够用——展示一个线性不可分的小数据集，让"弱"这件事变得可见。

# page-03 [内容页]
讲解"弱分类器"的定义：只要求比随机猜略好，用决策树桩（单一特征、单一阈值）作为贯穿全课的具体弱分类器例子。

# page-04 [交互页]
交互调整一个决策树桩的阈值和方向，观察它在给定小数据集上的分类结果和错误率如何变化——建立"弱分类器有参数、有错误率"的手感。

# page-05 [标题页]
章节分节：第一章回答了"弱在哪里"，第二章将回答——如果一个弱分类器不够，能不能把很多个组合起来？怎么组合？

# page-06 [内容页]
讲解集成的直觉：多个弱分类器加权投票为什么可能强于单个——引入"加权多数表决"的概念，尚不涉及权重如何来。

# page-07 [内容页]
讲解AdaBoost的核心机制第一部分：样本权重。说明为什么要给每个训练样本一个权重，以及"分错的样本权重会变大"这一核心思想。

# page-08 [内容页]
讲解AdaBoost的核心机制第二部分：分类器权重alpha。说明每个弱分类器在最终投票中的话语权由它自身的错误率决定，错误率越低话语权越大，并展示alpha与错误率的函数关系。

# page-09 [交互页]
交互操作alpha的计算：给定一个弱分类器的加权错误率，让读者拖动/输入错误率观察alpha如何变化，包括错误率超过0.5时alpha会怎样。

# page-10 [内容页]
讲解AdaBoost完整算法流程：初始化等权、循环（训练弱分类器→计算错误率→计算alpha→更新样本权重→归一化）、最终加权投票，给出算法的整体骨架。

# page-11 [交互页]
逐步交互执行AdaBoost：在一个可视化的小数据集上，读者一步步点击推进"训练第t个弱分类器→看哪些点分错→看权重如何被放大→看新的加权分布"，串起第7-10页讲过的每个环节。

# page-12 [交互页]
延续逐步执行：继续到第二轮、第三轮弱分类器的训练，让读者亲眼看到样本权重的分布随轮次迁移（之前分对的点权重变小、持续分错的点权重持续变大）。

# page-13 [内容页]
讲解多个弱分类器如何合成最终的强分类器：展示各轮决策树桩按各自alpha加权叠加后形成的组合决策边界，对比单个弱分类器与组合结果的分类效果。

# page-14 [标题页]
章节分节：第二章讲完了AdaBoost算法本身如何运作，第三章要回答——这样反复给错误加权，会不会训练集刷高了但换一批数据就不准了？

# page-15 [内容页]
讲解AdaBoost与过拟合的关系：说明训练误差理论上随轮数增加而指数下降，但测试误差在很多情况下却能保持稳定甚至继续下降，引出"margin"这一解释视角。

# page-16 [交互页]
交互演示：调节AdaBoost的迭代轮数，同时观察训练误差曲线和测试误差曲线的走势差异，以及决策边界随轮数变得多复杂。

# page-17 [内容页]
讲解AdaBoost对噪声和异常点的敏感性：展示当训练集中存在一两个标签错误的异常点时，AdaBoost会持续给它们加大权重，导致后续弱分类器被"带偏"。

# page-18 [交互页]
交互实验：读者手动给数据集中指定一个点翻转标签（制造异常点），观察AdaBoost的训练过程和最终决策边界受到怎样的干扰，与无异常点时对比。

# page-19 [标题页]
章节分节：第三章看到了AdaBoost的强健处与软肋，第四章把它放进更大的图景——它和其他集成方法有什么关系，什么时候该用它。

# page-20 [内容页]
讲解AdaBoost与Bagging（如随机森林）的对比：串行加权训练 vs 并行独立训练，样本权重的自适应调整 vs 随机重采样，各自更适合的场景。

# page-21 [交互页]
代码练习：在一个真实的小数据集上，读者调用现成接口分别训练AdaBoost和一个单一决策树/随机森林，比较三者的准确率和决策边界，用代码亲手验证前面讲过的结论。

# page-22 [内容页]
课程小结：用一张回顾AdaBoost核心流程与关键概念（弱分类器、样本权重、alpha、加权投票、过拟合与噪声敏感性）的图谱，串联全课六章脉络。

# page-23 [标题页]
封底：本套讲义收束，回顾AdaBoost这一思想——"关注错误、按贡献授权"如何贯穿整个算法，并提示可继续探索的方向（如Gradient Boosting）。
