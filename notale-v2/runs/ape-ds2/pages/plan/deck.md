# 《从人猿到太空人》 90 分钟互动讲义 · 总规划

## 0. 这套讲义的主线

一句话主张：从东非的脚印到月球的脚印，是同一条演化之路——一个物种通过身体、火、语言与文化的层层累积，最终拥有了离开母星的能力。

分章表：

| 章 | 页 | 这一章要让读者信什么 |
|---|---|---|
| 第 0 章 开场 | 01–03 | 这不是一堂「人类进化史」课，而是一段从脚印到脚印的旅程 |
| 第 1 章 深时 | 04–09 | 演化需要的时间远超个体直觉，人类只是地球史的最后一瞬 |
| 第 2 章 猿的身体 | 10–16 | 今天身体的每一项特征，都是演化给出的权衡 |
| 第 3 章 火与认知 | 17–22 | 工具、火与协作把能量和计划性引入演化，知识开始积累 |
| 第 4 章 语言与累积文化 | 23–27 | 符号与模仿让知识跨代累积，文化从此有了自己的复制方式 |
| 第 5 章 文明加速度 | 28–34 | 从农业到信息，文化演进的速度一次次跃升 |
| 第 6 章 太空时代 | 35–44 | 离开地球需要理解引力、掌握能量、组织千万人协作 |
| 第 7 章 回望 | 45–50 | 我们还带着演化史的身体，站在开放的未来路口 |

无交互（只承担开场/推进/过渡/收束）：01 02 03 21 50

## 3. 数字口径

全套统一数值，页面一律从 `Lec.K` / `Lec.P` 取，不要写死：

- 地球年龄 46 亿年 → `Lec.K.EARTH_AGE_YEARS`
- 生命起源 38 亿年前 → `Lec.K.FIRST_LIFE_YEARS_AGO`
- 恐龙灭绝 6600 万年前 → `Lec.K.DINOSAURS_EXTINCT_YEARS_AGO`
- 人猿分叉 约 700 万年前 → `Lec.K.HOMININS_SPLIT_YEARS_AGO`（讲解文本用「约」）
- 智人 20 万年前 → `Lec.K.HOMO_SAPIENS_YEARS_AGO`
- 太空时代起点 1957 年 → `Lec.K.SPACE_AGE_START_YEAR`（统一以斯普特尼克为起点）
- 光速、秒/年、光年、月球距离、比邻星距离、宇宙年龄 → 对应 `Lec.K` 常量
- 地球史压缩到一年/一天的比例 → 一律用 `Lec.P.earthFraction()`，各页不得自行近似
- 逃逸速度 → `Lec.P.escapeVelocity()`；近地轨道速度 → `Lec.P.orbitalVelocity(r)`；讲解文本可写「约 11.2 km/s」「约 7.9 km/s」作为约数
- 宇宙年龄 138 亿年 → `Lec.K.UNIVERSE_AGE_YEARS`（p06 数量级滑杆用到）

`Lec.K` 未提供、本套统一取值，页面写在自身常量区并注释「全套口径」：

- 已知最早石器（Lomekwi 3）约 330 万年前（p17）
- 系统性用火证据（Wonderwerk 洞穴）约 100 万年前（p18）
- 南方古猿脑容量约 400 毫升；智人脑容量约 1400 毫升（p13）
- 有文字的历史约 5000 年（p05）
- 邓巴数 150（p24）
- 国际空间站轨道高度约 400 km（p41；轨道速度用 `Lec.P.orbitalVelocity` 计算，不写死）
- 阿波罗 11 号登月：1969 年 7 月 20 日（p40）
- 最早的双足行走证据（Laetoli 脚印）366 万年前（p03）
