# page-01 · 开场：提出主张 · **10 秒**

## 知识结构：generalization

这一页只做一件事：第一次提出课名与主张。骨架要显式化的关系是「主张 ← 两端支撑」——一句主张（我们身体里住着猿，脚步已经踏上月球）被放在一根横轴上：左端是「人猿」（身体这一端），右端是「太空人」（脚印这一端），一根细线把两端连成同一条路。这是全课主线（从东非的脚印到月球的脚印）的第一次登场，本页只建立雏形，不给证据。

显式化靠空间对齐：两个端点词分别锚定在贯穿线的左右两端，主张句落在贯穿线正下方。读者的一瞥按「左—右—中」的顺序读——先看到两个端点分居两端，再被中间的主张句收拢成同一个过程。不做箭头、不做因果链、不做时间轴：10 秒只够建立一个「两端 + 一条路」的图形。贯穿线只承担「同一条路」的象征，不是时间轴，不标注任何年代、不按比例。

## 表征形式

静态焦点页（focus），只播一次入场动画，之后完全静止；读者是听众，不需要做任何操作。选择这种形式是因为读者需要在 10 秒内建立起「人猿 → 太空人 = 同一条路」的心象：一次空间并置加一次沿线的运动，三秒就能完成这个心象，不需要任何证据。

- kicker（顶部居中，SHORT-CAPS 感）：`第 0 章 · 开场 — APEMAN – SPACEMAN`
- 主标题（页面唯一焦点，最大字号，拉开字距横贯视宽）：`从人猿到太空人`
- 贯穿线：主标题下方约一行处，一条极细的水平光线，从「人猿」下方延伸到「太空人」右缘之外；右端尽头有一颗小圆点（沙金色）——月球。这是本页唯一的图形元素。
- 主张句（贯穿线正下方居中）：`我们身体里住着猿，脚步已经踏上月球。`
- 页脚小字（可选，极低透明度）：`一段从脚印到脚印的旅程`
- 背景：近黑的深蓝到黑的径向渐变；无粒子、无纹理、无其他元素。唯一的暖色是贯穿线右端的月球圆点与 kicker 文字。

入场动画（约 2.5–3 s，只播一次，详见「媒体」）：一个亮点从贯穿线左端出发，沿光线滑到右端，落定成月球圆点；同时 kicker、主标题、主张句依次淡入。动画把「从人猿到太空人」这个标题本身演了一遍。

## 主张与两端

画面上的全部内容就是三层文字加一条线。

| 层级 | 文本 | 作用 |
|---|---|---|
| kicker | 第 0 章 · 开场 — APEMAN – SPACEMAN | 交代这是开场页；英文全大写、字距拉开、用强调色 |
| 主标题 | 从人猿到太空人 | 课名；拉开字距使「人猿」「太空人」两个词自然落在视宽两端 |
| 贯穿线 + 圆点 | （无文字） | 「同一条路」的图形化：线的左端是身体，右端是月球 |
| 主张句 | 我们身体里住着猿，脚步已经踏上月球。 | 把课名说透：身体携带猿的遗产，脚步已经离开母星 |
| 页脚小字 | 一段从脚印到脚印的旅程 | 全课主线的预告；可与主张句合并显示或省略 |

- 「人猿」与「太空人」是主张的两端，分别对应「身体」（演化留下的容器）与「脚印」（离开母星的能力）；主张句把它们并置成同一条路的两端。
- 本页不出现任何数值：没有年代、距离、百分比、任务名；所有数据性内容自 p03 起才出现，本页常量区为空。

## 必须点出来的一到三句

一句（10 秒只够一句落地）：

- 我们身体里住着猿，脚步已经踏上月球——这两个端点属于同一条路。

引导句（口头过渡到 p02，不进画面）：

- 这条路怎么走通，下一页先看路线。

## 交互（只有这一个）

无 —— 这一页只承担开场。没有控件、没有可操作对象；唯一的动效是一次性入场动画，播放后页面静止，等教师开口。

## 不许碰

- 不讲任何证据（p03 起）：不出现化石名、遗址名、年代数字、任务名——Laetoli、阿波罗、Lomekwi、Wonderwerk 等一律不出现；「月球」只以光点象征，不出现月面、登月器或宇航员形象（p39–p40 才进入任务史）。
- 不出现脚印的图形、照片或图标：p03 的揭示是「两个相隔 366 万年的脚印几乎一模一样」，本页若用图像泄底，会提前拆掉那个钩子；「脚步/脚印」只作为词存在于主张句中。
- 不出现地球史压缩的视觉比喻（那是 p04–p06 的领域）。
- 不出现任何谱系、分支或生命树图形（p07、p45 的领域）。
- 不出现身体机制内容（骨盆、双足行走、脑容量等，p10 起）。
- 不承担路线图：七站预览是 p02 的事，本页不列举任何章名。

## 媒体

入场动画为自建动效（DOM 元素 + gsap），无外部素材、无出处标注。

动画内容：一个亮点（直径约 2px 的暖色光点）从贯穿线左端出发，沿光线滑向右端，约 2 s，缓动为先匀加速、末段缓出；到达右端后扩大并落定为月球圆点（直径约 6–8px，沙金色）。同时三层文字按 kicker → 主标题 → 主张句的顺序淡入，总时长控制在 3 s 内，之后页面完全静止，留约 7 s 给阅读与教师开口。这段动画不是装饰：它把「从人猿到太空人」在 3 秒内演了一遍，观众在听到主张句之前，已经用眼睛走完了这条路的雏形。

## 版面提示

屏幕按 16:9 通栏处理，不使用内容列限宽（页面无卡片）。kicker 距顶部约 8% 视高，居中。主标题字号约为视宽的 6–7%，字距拉开使「从」字左缘和「人」字右缘分别落在约 10% 与 90% 视宽处——即「人猿」与「太空人」两个词恰好卡在贯穿线的两端。贯穿线距主标题基线约 1 行，左端对齐「人猿」下缘，右端超出「太空人」右缘约 2% 视宽，月球圆点即在此处。主张句字号约为标题的四分之一到五分之一，距贯穿线约 2 行，居中；页脚小字贴底居中。
