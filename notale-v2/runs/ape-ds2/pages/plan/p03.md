# page-03 · 两个脚印 · **50 秒**

## 知识结构：comparison

这一页要显式化的是「同」与「异」的双重关系：**两枚脚印的形态几乎相同，但它们所在的整个世界完全不同**。

具体靠左右两栏的并置：左栏是 366 万年前 Laetoli 的脚印，右栏是 1969 年月球上的脚印。两栏各有一张脚印照片/轮廓，下方各有一列标注。左右结构本身让「形态相同」先被看见，然后通过中间一条从地面延伸到月面的时间轴线，把「世界已变」拉开。

两个脚印放在同一高度、同一视觉尺寸上，让观察者第一眼得到「一模一样」的判断；随后视线上移到各自背后的小图（地面草原／月球静海），反差立刻出现。

## 表征形式

静态平行对照，无动画、无交互。

页面主体是左右分栏（split-lr）。左栏和右栏各有一张脚印照片的俯视影像，照片周围留白，下方对齐放置几行短标注：时间、地点、留下它的人。两栏之间是一条竖直的虚线时间轴，从下方 366 万年前一直延伸到上方 1969 年，轴上一个点标着「1969」，另一个点标着「距今 366 万年」。虚线的存在不是为了精确度量，而是让「隔着长长的时间几乎一模一样」这个感觉落下来。

学习者需要建立的心理表征是：**同一个身体，不同的世界**——脚掌的轮廓是连续演化的遗产，而地面已经从草原变成了月球。

## 两个脚印的对照

两栏各含一张真实照片或精确轮廓图，加上下面五个字段。所有数值从页面自身常量区取，常量区注释「全套口径」。

左栏——Laetoli 脚印：

| 字段 | 内容 |
|---|---|
| 时间 | `P03.LAETOLI_YEARS_AGO` 年前（常量值 3.66e6，即约 366 万年前） |
| 地点 | 坦桑尼亚 Laetoli |
| 留下它的人 | 南方古猿（直立行走的早期人科） |
| 地面 | 火山灰，后来变成凝灰岩 |
| 它意味着 | 已知最早的双足行走证据之一 |

右栏——月球脚印：

| 字段 | 内容 |
|---|---|
| 时间 | `P03.MOON_LANDING_YEAR` 年（常量值 1969，取自阿波罗 11 号） |
| 地点 | 月球静海 |
| 留下它的人 | 智人（阿波罗 11 号宇航员） |
| 地面 | 月壤（月尘与碎岩） |
| 它意味着 | 人类第一次把脚印留在另一颗天体上 |

两栏之间不出现任何步态、足弓或骨盆的说明图——那些全部留给 p11。

另注：Laetoli 脚印的“366 万年”在数字口径里是「本套统一取值，页面写在自身常量区」。因此页面用：

```js
const P03 = {
  LAETOLI_YEARS_AGO: 3.66e6,   // 全套口径：Laetoli 脚印
  MOON_LANDING_YEAR: 1969      // 全套口径：阿波罗 11 号
};
```

页面上显示为「约 366 万年前」和「1969」，不要写死阿拉伯数字在文案里，一律从这个常量读取。

## 必须点出来的一到三句

- 两枚脚印，相隔 366 万年，形状几乎一样——身体没有大变。
- 但一枚踩在草原的火山灰里，一枚踩在月球的尘埃上——世界已经天翻地覆。
- 从东非的脚印到月球上的脚印，是同一条演化之路。

## 交互（只有这一个）

无 —— 这一页只承担开场推进，把读者从“人类进化史”的预期带到“从脚印到脚印”的旅程上。

## 不许碰

- 不讲双足行走的机制：足弓如何承重、骨盆如何倾斜、步态周期、能量消耗对比——全部留给 p11。
- 不讲任何演化证据的细节（例如地层、年代如何测得），那是第 1 章的事。
- 不引入“火、语言、文化”等后续章节的概念，这一页只让两个脚印自己说话。
- 不出现其他脚印（现代人类脚印、动物脚印等），避免稀释核心对照。

## 必用skill

无。

## 媒体

需要两张真实照片/影像，因为“两枚脚印几乎一模一样”只有看到实物证据才成立，示意图无法承载证据感：

- 左栏：Laetoli 脚印化石的俯拍照片（通常为黑白或灰褐色，有清晰的足印轮廓）。出处信息放入 `<img title="…">`。
- 右栏：阿波罗 11 号宇航员在月球上留下的脚印特写照片（著名的巴兹·奥尔德林脚印照，白色背景，深色靴印）。出处信息放入 `<img title="…">`。

两张照片都裁剪成近乎正圆或圆角方框，视觉尺寸一致，背景不喧宾夺主。

## 版面提示

split-lr 默认排法的基础上，做两点限定：

- 两栏照片的渲染宽度完全一致，均占该栏宽度的 82% 左右，横向居中。
- 中间的时间轴线占用约 3% 的栏间距，轴上有两个刻度点，分别对齐左右两栏照片的中心位置——左栏照片中心对应下方刻度（366 万年），右栏照片中心对应上方刻度（1969）。上方刻度旁可加一行极小字“同年 7 月 20 日”，但也可省略，依实际空间定。
