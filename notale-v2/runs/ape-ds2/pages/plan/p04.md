# page-04 · 把地球史压进一年 · **135 秒**

kicker：深时 · 压缩年历  
主标题：把地球史，压进一年

## 知识结构：process
要把「46 亿年里事件怎样一步一步走向现代」这层关系显式化。实现的载体是一条从 1月1日 到 12月31日 的水平压缩年历：左端是地球形成，右端是现在，所有事件按真实时间比例落在轴上，不人为等距。节点之间的空白长度就是真实时间长度；节点越靠右，代表越接近现在。整页是一个单一的「沿时间前进」过程，读者拖动扫描线从年初走到年末，事件按顺序被点亮。

## 表征形式
交互时间轴。全屏水平年历条是视觉主体，按月份刻度分成 12 段。五个事件点按坐标放在轴上，平时是暗色光点；扫描线是一道竖直光带，拖动它穿过整年。顶部有浮动读数区，显示当前压缩年月日时分和对应的真实距今。事件标签通过细引线拉出，避免年末密集处互相遮挡。没有 3D，没有分支，只有一条从远古走向今天的线。

## 压缩年历上的五个节点
所有节点在轴上的 0–1 坐标一律用 `Lec.P.earthFraction()` 换算，页面不得自行用除法近似。预期位置只用于人工自测，不作为数据源。

| 节点 | 坐标来源 | 预期渲染位置（自测用） |
|---|---|---|
| 地球形成 | 年历左端，0 | 1月1日 00:00 |
| 最早生命 | `Lec.P.earthFraction(Lec.K.FIRST_LIFE_YEARS_AGO)` | 约 3月5日 |
| 恐龙灭绝 | `Lec.P.earthFraction(Lec.K.DINOSAURS_EXTINCT_YEARS_AGO)` | 约 12月26日 |
| 人猿分叉 | `Lec.P.earthFraction(Lec.K.HOMININS_SPLIT_YEARS_AGO)` | 约 12月31日 10:40 |
| 智人出现 | `Lec.P.earthFraction(Lec.K.HOMO_SAPIENS_YEARS_AGO)` | 12月31日 23:37 |

节点标签上的年代由对应 `Lec.K` 常量动态格式化，不写死。人猿分叉在讲解文本中加「约」。地球形成作为起点，不需要调用函数，直接锚在左端 0。

### 真实年代读数
拖动时顶部显示两个读数：

- 压缩年历日期：由 `fraction` 换算。局部辅助函数 `calendarDate(f)` 负责格式化；内部按「压缩年 = 365 天」处理，这个 365 只是压缩年历的表示常数，写成页面局部常量并注释，不作为科学口径复用。
- 真实距今：`yearsAgo = (1 - fraction) * Lec.K.EARTH_AGE_YEARS`。`fraction = 0` 显示「46 亿年前」，`fraction = 1` 显示「现在」。

## 必须点出来的两句
1. 把地球史压进一年，智人直到 12月31日23:37 才出现。
2. 拖动年历时，绝大多数月份里没有任何「我们」的标记——演化需要的时间，远超人一生的尺度。

## 交互（只有这个）
压缩年历拖动。

- 全屏年历条是唯一舞台；读者按住并拖动扫描线来移动它。
- 扫描线位置映射为 `fraction = clamp((pointerX - stripLeft) / stripWidth, 0, 1)`，线性映射。
- 事件点在扫描线经过之前是暗色光点，经过之后亮起并让标签在引线末端显现；已经过的标签保持可见。这个「必须拖过去才看见」的规则让读者亲历整年。
- 扫描线身后留下一道极淡的光迹，表示「已经过的时间」；前方保持原样。
- 没有自动播放、没有按钮、没有第二个交互装置。拖动是唯一动作。
- 当扫描线到达 12月31日23:37 附近时，智人节点亮起并显示脚印标记，这是整页的收束瞬间。

## 不许碰
不讲任何地层年代命名：不出现寒武纪、侏罗纪、白垩纪等纪名，也不出现冥古宙、太古宙、显生宙等宙名。所有节点只用日常语言：地球形成、最早生命、恐龙灭绝、人猿分叉、智人。不展开演化树的分类，不解释事件机制；这些事件在 p04 只是年历上的刻度，不是讲述对象。
