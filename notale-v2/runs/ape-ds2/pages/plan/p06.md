# page-06 · 时间尺度 · **145 秒**

kicker: 深时  
主标题: 从一次心跳到地球年龄

## 知识结构：process

这一页把「从短到长的时间跨度」显式化为一条有方向的**数量级轴**：每一格代表 10 倍时间，箭头从当下可感知的尺度（一次心跳）指向深时尺度（地球年龄）。这条轴本身就是一个过程——读者沿轴推进，目睹同一根时间标尺从秒级延伸到亿年级，最终发现地球年龄远超人一生所能体会的范围。显式化的手段是**对数刻度的水平轴**：指数线性排列，事件点按其对数值分布，游标代表当前读数。

## 表征形式

动态交互。一条水平对数轴，横轴为 `log10(秒)`，范围从 10⁰ 秒到 10¹⁸ 秒。轴上预先放置五个事件点，每个事件点带标签和数值。读者拖动滑杆时，一个游标沿轴移动，页面顶部同步显示当前值的两种单位（秒、年）。事件点始终可见，游标经过时高亮。

## 数量级标尺上的五个事件

| 事件 | 数值（秒） | 来源与算法 |
|---|---|---|
| 一次心跳 | 约 10⁰ s | 教学近似：约 1 秒。页面自身常量区定义 `HEARTBEAT_SECONDS = 1`，注释「全套口径：教学近似」 |
| 人的一生 | 约 80 × 年长秒数 | 教学近似：取 80 年。秒数由页面当场计算：`80 * SECONDS_PER_YEAR` |
| 有文字的历史 | 约 5000 × 年长秒数 | 全套口径：约 5000 年。秒数 = `5000 * SECONDS_PER_YEAR` |
| 地球年龄 | `Lec.K.EARTH_AGE_YEARS` × 年长秒数 | 从 `Lec.K.EARTH_AGE_YEARS` 取年数，乘以 `SECONDS_PER_YEAR` |
| 宇宙年龄 | `Lec.K.UNIVERSE_AGE_YEARS` × 年长秒数 | 从 `Lec.K.UNIVERSE_AGE_YEARS` 取年数，乘以 `SECONDS_PER_YEAR` |

页面自身常量区统一定义：

```js
const SECONDS_PER_YEAR = 365.25 * 24 * 60 * 60; // 全套口径：年长秒数
const HEARTBEAT_SECONDS = 1;                    // 全套口径：教学近似
```

滑杆范围：指数 0–18，即 `1e0` 到 `1e18` 秒。所有事件点的位置由 `log10(seconds)` 计算，页面不得写死。

## 必须点出来的一到三句

- 从一次心跳到地球年龄，时间跨度相差约 17 个数量级。
- 人的一生、文明史在深时尺度上都是瞬间——演化需要的时间，远超人一生的直觉。

## 交互（只有这一个）

**数量级滑杆**

读者拖动一个水平滑杆，指数从 0 变化到 18。滑杆位置对应 `10^index` 秒，游标沿对数轴移动；页面顶部读数分别显示「秒」和「年」（用科学计数法或人类可读单位，例如 `1.45e17 s ≈ 4.6e9 yr`）。轴上五个事件点固定显示，当游标越过某一点时该点高亮，并在游标旁弹出一个小标签说明「这里是 XX」。滑杆上还可以用细刻度标记 10⁰、10³、10⁶、10⁹、10¹²、10¹⁵、10¹⁸ 秒的位置，帮助定位。

读者应当形成的直觉：滑杆从左侧起步时，刻度尚能对应心跳、呼吸等熟悉的时间；继续向右，人类一生、文字史只占据轴末端极短的一小段，而地球年龄几乎占据了最后两格。整个过程中，读者直接看见「一生」与「地球年龄」之间隔着巨大的空白。
