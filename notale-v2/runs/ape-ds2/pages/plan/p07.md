# page-07 · 生命树末端 · **130 秒**

kicker：`DEEP TIME · 生命树`  
主标题：末端一小枝

## 知识结构：classification

这一页要把「演化不是一条上升的阶梯，而是一棵分叉的树」显式化。骨架用主干分支：根是最后共同祖先，第一层分出细菌、古菌、真核生物三大域；真核生物之下再沿多细胞 → 动物 → 脊椎动物 → 四足动物 → 哺乳类 → 灵长类 → 人类逐级嵌套。缩放改变的是当前可见的层级深度：全景看到整棵树的庞杂，越放大越接近末端，最终停在「人类」这一小枝上。

光合作用、登陆、恐龙灭绝这类事件不当作树干，而是作为侧枝标签挂在对应分支上，不干扰层级骨架。

## 表征形式

动态交互，全屏 2D 树图。

一棵从左侧根向右侧现代生长的层级树铺满画布；横轴对应地质时间（约 38 亿年前 → 今），纵轴把不同分支散开。初始为全景，只有最粗的几支可见；读者滚轮或双指缩放时，层级逐步加深，节点标签淡入。树由 d3 依据本页数据生成，节点是发光圆点，连线是细枝，并额外绘制少量不标注名称的装饰性小枝，用来传递「整棵树极大」的感受。不使用 3D。

## 层级里的各项

树节点数据是一个数组，每个节点包含 `id`、`label`、`parent`、`type`（`branch` 或 `event`）、`timeYearsAgo`。时间一律取自 `Lec.K` 或本页常量 `PAGE`，页面运行时不得写死。

## 必须点出来的一到三句

- 生命树已经长到 38 亿年，「人类」只是最末端的一小枝。
- 光合作用、真核细胞、多细胞、登陆、恐龙、哺乳类，都早已在人类之前排好了位置。

## 交互（只有这一个）

生命树缩放。

读者用滚轮或双指在生命树上缩放。初始视野是整棵树的远景，只能看到三大域级别的轮廓；越放大，分支越清晰，节点标签逐级出现。点击任意带名称的分支节点，画面平滑跳转到该分支并放大一级；右下角有「回到全景」按钮。左下角显示当前层级名，如「全景 / 真核生物 / 动物 / 哺乳类」。

当读者一路放大到末端「人类」时，标签显示「人类 —— 约 700 万年前；智人 20 万年前」。再拉回全景，人类消失在一片枝叶之中。由此形成的直觉是：在生命史面前，人类出现得极晚、占据的枝极细、位置极其靠边。

## 不许碰

- 不讲人类身体结构：不出现骨骼、骨盆、脑容量、双足、手、无毛、汗腺等任何解剖学特征。
- 不展开人科内部谱系：不画直立人、尼安德特人、南方古猿等分支；「人类」只作为一个末端叶出现。
- 不进入后续章节的机制内容：不讲为什么能站立、手如何用、火如何改变营养、文化如何加速。本页只回答「人类在整棵生命树中的位置」这一个问题。
