# page-08 · 46 亿年叠成一柱 · **110 秒**

kicker 用 `DEEP TIME`。主标题为「46 亿年叠成一柱」——「叠」字直接指向本页唯一的动作，也暗示结果：一柱堆完，文明不见了。

## 知识结构

enumeration 要把「六个连续演化时段」从一组并列的条目，变成一组**可见的比例关系**。显式化靠两条：

1. **同一根时间轴**。六个时段严格按年份差等比绘制，共用一根竖直的柱，总高固定。读者不看数字也知道哪段厚、哪段薄。
2. **三级放大**。当线性比例下文明段连一个像素都占不到时，「看不见」本身就是这条骨架要显式化的东西——通过三幅取景视图（全柱 / 近 6600 万年 / 近 20 万年），把「要放大多少次，文明才从不可见变成一根线」做成一次可见的递进。

六个时段是**前后相接、互不重叠**的连续段；它们之间只有先后关系，没有因果箭头。

## 表征形式

交互 + 静态对照，两段式。

前半程是交互：六个长度真实的时间块放在右侧块库里，读者逐块拖到左侧柱上，柱子即时按新比例重排。后半程是静态结果：六块全部叠完，柱旁展开三幅取景视图，同柱三次放大，第三幅里文明段终于是一根可辨的细线。

三幅取景视图用技术图纸式的引线标注：细线从段界引出，标段名与时间范围（`technical-wireframe-info-layout`）。同一时段在三幅视图中保持同一颜色，让读者能在不同尺度间追踪同一段。

## 六个时段

连续六段，从地球诞生排到「今天」，边界全部取自 `Lec.K`，页面不写死任何年份。每段的名称、边界、时长算法：

| 段 | 名称 | 起（年前） | 止（年前） | 时长算法 |
|---|---|---|---|---|
| 1 | 地球诞生到生命出现 | `Lec.K.EARTH_AGE_YEARS` | `Lec.K.FIRST_LIFE_YEARS_AGO` | `EARTH_AGE_YEARS − FIRST_LIFE_YEARS_AGO` |
| 2 | 生命演化到恐龙时代结束 | `Lec.K.FIRST_LIFE_YEARS_AGO` | `Lec.K.DINOSAURS_EXTINCT_YEARS_AGO` | `FIRST_LIFE_YEARS_AGO − DINOSAURS_EXTINCT_YEARS_AGO` |
| 3 | 恐龙之后到人猿分叉 | `Lec.K.DINOSAURS_EXTINCT_YEARS_AGO` | `Lec.K.HOMININS_SPLIT_YEARS_AGO` | `DINOSAURS_EXTINCT_YEARS_AGO − HOMININS_SPLIT_YEARS_AGO` |
| 4 | 人科演化到智人出现 | `Lec.K.HOMININS_SPLIT_YEARS_AGO` | `Lec.K.HOMO_SAPIENS_YEARS_AGO` | `HOMININS_SPLIT_YEARS_AGO − HOMO_SAPIENS_YEARS_AGO` |
| 5 | 智人到文字出现之前 | `Lec.K.HOMO_SAPIENS_YEARS_AGO` | `PAGE.WRITTEN_HISTORY_YEARS_AGO` | `HOMO_SAPIENS_YEARS_AGO − WRITTEN_HISTORY_YEARS_AGO` |
| 6 | 有文字的历史至今 | `PAGE.WRITTEN_HISTORY_YEARS_AGO` | 0 | `WRITTEN_HISTORY_YEARS_AGO` |

页面自身常量区，注释「全套口径」：

```js
const PAGE = {
  // 全套口径：有文字的历史约 5000 年（p05 统一取值）
  WRITTEN_HISTORY_YEARS_AGO: 5000,
```

页面上显示的边界标签：`46 亿年前`、`38 亿年前`、`6600 万年前`、`约 700 万年前`、`20 万年前`、`5000 年前`、`今天`。`约` 只加在人猿分叉一处，与整套口径一致。

### 堆出来的比例

各段占全柱比例（供实现者确认布局，页面不得写死，由地块高度函数实时计算）：

1. 约 17.4%
2. 约 81.2%
3. 约 1.28%
4. 约 0.15%
5. 约 0.0042%
6. 约 0.0000011%

第 3 段起只剩柱顶一条细线；第 5、6 段在线性全柱下完全不可见——这正是本页要读者亲手体验到的。

### 三幅取景视图的边界

| 视图 | 显示范围（年前） | 文明段可见性 |
|---|---|---|
| A 全柱 | `EARTH_AGE_YEARS` → 0 | 不可见 |
| B 近 6600 万年 | `DINOSAURS_EXTINCT_YEARS_AGO` → 0 | 不可见（约 0.0076%） |
| C 近 20 万年 | `HOMO_SAPIENS_YEARS_AGO` → 0 | 终于可见：`WRITTEN_HISTORY_YEARS_AGO / HOMO_SAPIENS_YEARS_AGO` ≈ 2.5%，一根细线 |

三幅视图的放大倍数由视图范围与柱子显示高度当场计算，不写死。体验弧线是：读者在 A、B 里找不到文明，在 C 里才找到——而且要顺着引线标注才能找到。

## 必须点出来的一到三句

第 1 章收束页，两句：

1. 把演化各阶段按真实比例堆在一起，文明薄得像一层灰尘。
2. 前面每一秒的铺垫，都在为最后一瞬积蓄可能——这就是「深时」的分量。

第二句承接第 1 章「深时」主题，但不涉及任何具体事件因果，只是把「时间长」与「文明出现」接起来。

## 交互（只有这一个）：时间块堆叠

- **读者动什么**：从右侧块库拖起一个时间块（块的长条长度 = 该段真实时长，所以「文明」块是一条几乎看不见的细线），放入左侧柱子。六块逐次放入，顺序自由。
- **看到什么变**：柱子总高固定。每放入一块，所有已有块按新比例同步缩放重排，段界标签出现。放第 1、2 块时柱子有明显变化；放第 3 块起柱顶几乎看不出变化；放最后一块时，柱顶多了一条不可见的界线，只有标签更新。
- **形成什么直觉**：不是「文明占 0.0000011%」这个数字，而是「我亲手把文明放上去，它消失了」。比例带来的震撼来自操作本身，不来自读数。
- **完成态**：六块全部放上后，柱子右侧展开三幅取景视图（triptych），静态呈现三次放大的结果，第三幅标注出文明那根细线。

实现要点：拖拽用 pointer events 自实现，不需要物理引擎；放入判定为柱顶区域。重排动画用 GSAP 时间线，`power2.inOut`，时长 0.6–0.8 秒，保证多块同步缩放不跳变。超长宽比的细块（第 5、6 段）在块库中要保留真实比例，允许细到只显示一条带颜色的 1px 线。

## 不许碰

- **不讲事件因果**。6600 万年前只作为第 2、3 段的时间界线出现；不解释恐龙为什么消失，不把「哺乳动物崛起」写成撞击的结果，不用「因此、所以、于是、腾出舞台」这类因果连词连接任何两个时段。时段之间只是先后关系。
- **不复现「压缩成年历 / 时钟 / 数量级」的视觉或措辞**（硬约定 p04–p06）。本页只有「按比例堆叠」和「放大取景」，没有年历、钟面、滑杆。
- **不展开生命演化顺序的机制**（已属 p07）。六个边界之外的演化过程一概不进入本页。
- **不讲双足行走、脑容量、能量代谢等身体细节**（p10 起）。

## 版面提示

triptych 在本页不是三个平行主题，而是同一根柱子的三次放大。版面分上下两区：

- **上部约 60% 高**：交互区。左侧为堆叠柱（约 70vh 显示高），右侧为块库，六个块纵向排列，每块标注段名与起止年份。
- **下部约 40% 高**：三幅取景视图并排（A / B / C），各列用引线标注段界与名称。三幅视图共享同一套时段配色——时段颜色跨视图不变，读者才能在三个尺度间认出同一段。

时段配色建议按尺度感知选：前两段用低饱和的大地色（占据视觉主体），第 3、4 段用中明度灰蓝，第 5、6 段用高亮强调色——文明这根细线必须在第三幅视图里成为唯一的亮色。
