# page-10 · 当森林让出空地 · **110 秒**

> kicker：第 2 章 · 猿的身体
> 页表一句话（页脚锚句）：东非气候变化让森林成片退去，我们的祖先开始用两脚站在开阔地上。

## 知识结构：process

这一页要把「环境变化 → 行为变化」这条因果链显式化。链上每一环都是一个「因为……所以……」：裂谷抬升 → 气候变干 → 森林破碎 → 资源被开阔地隔开 → 地面穿行成为日常 → 双足站立。

显式化的具体手段：

- 右栏是一条纵向因果链：六个事件从上到下由箭头串联；每根箭头标一个「连接问题」，即上一步推出下一步的理由。
- 左栏是同一因果链的「前后态」：起点是连续森林，终点是开阔草地和草地上的脚印；滑块拖动时，系统连续补出中间态，让「破碎」「隔开」「穿行」这些动词长在景观里。
- 左右两栏由同一个滑块进程 u 绑定：u 同时决定景观状态和右栏高亮到第几步，因此「因果链」和「景观演变」是一个进程的两个视图。

## 表征形式

交互为主。主画面是一幅 2D 分层插画式景观（本页不在 3D 白名单，硬约定），由底部滑块连续驱动；右栏因果链随同一滑块逐步点亮。

学习者需要的心理表征是「时间的压力」：几百万年的气候渐变，把祖先一点一点推到开阔地上。为此，滑块必须横跨整段「约 1000 万年前 → 366 万年前」，而不是只在几个离散点上切换——拖过全程这个动作本身，让「渐变」和「漫长」变成身体经验，而不是一句叙述。

## 六个事件

每个事件包含：右栏文本、左栏对应景观状态、其后的箭头连接问题。u 为滑块位置（0 = 左端，1 = 右端）。

**事件一 · 裂谷抬升**（u: 0.00–0.12）
- 右栏文本：「地壳拉伸，东非抬升，降雨减少」
- 景观：连续林冠覆盖画面，远处高地轮廓刚浮现；色调湿润蓝绿。
- ↓ 连接问题：抬升如何让降雨减少？

**事件二 · 气候变干**（u: 0.12–0.25）
- 右栏文本：「旱季拉长，森林开始撑不住」
- 景观：树冠变疏，林下出现光斑，云量减少。
- ↓ 连接问题：变干为什么让森林成片垮掉？

**事件三 · 森林碎成孤岛**（u: 0.25–uSplit）
- 右栏文本：「连续林冠退成片片孤岛」
- 景观：树群分裂，草地从林缝间连成片，林缘后退。
- ↓ 连接问题：森林碎了，食物和水源被什么隔开？

**事件四 · 开阔地隔开资源**（u: uSplit–0.70）
- 右栏文本：「食物、水、栖身的树，散落各处」
- 景观：稀树草原格局成形，孤树立于草地中央，祖先剪影第一次出现在地面边缘。滑块越过 uSplit 时，剪影从树上移到地面边缘，时间轴同时弹出「约 700 万年前 · 人猿分叉」锚点。
- ↓ 连接问题：要走到下一片林子，中间是什么？

**事件五 · 地面穿行成为日常**（u: 0.70–0.90）
- 右栏文本：「从一片林子到另一片，地面是唯一的路」
- 景观：祖先剪影在齐腰草丛中行进，站姿趋直。
- ↓ 连接问题：为什么在地面上站着走？——力学答案由 p11 回答，这里只留问题。

**事件六 · 双足站立 · 脚印**（u: 0.90–1.00）
- 右栏文本：「366 万年前，Laetoli 的脚印把答案封存」
- 景观：祖先以双足站姿立于开阔草地，前景地面浮现一排脚印（视觉呼应 p03 开场）；色调干热金黄。
- 终点：因果链合拢，回到开场那一幕。

### 公式与常数

页面一律运行时取值，不写死数字。数值来源分「Lec.K 已有」「全套口径」「本页口径」三类。

- `LAETOLI_FOOTPRINTS_YEARS_AGO = 366 × 10000`（366 万年前）——全套口径，写入本页常量区，与 p03 共用。
- `P10_T_START_YEARS_AGO = 10_000_000`（约 1000 万年前）——本页口径，滑块左端，东非变干叙事起点；若 Lec.K 未来提供同名常量，优先取 Lec.K。
- `P10_T_END_YEARS_AGO = LAETOLI_FOOTPRINTS_YEARS_AGO`（366 万年前）——滑块右端。
- `timeAt(u) = P10_T_START_YEARS_AGO + u × (P10_T_END_YEARS_AGO − P10_T_START_YEARS_AGO)`，u ∈ [0,1]，单位：年前——页面上唯一的连续时间读数，由页面当场算。
- 显示格式：`formatMa(u)` → 「x.x 百万年前」（timeAt(u)/1e6，一位小数，用于滑块读数）；`formatWan(y)` → 「xxx 万年前」（y/1e4，整数，用于锚点标签）。
- `uSplit = (P10_T_START_YEARS_AGO − Lec.K.HOMININS_SPLIT_YEARS_AGO) / (P10_T_START_YEARS_AGO − P10_T_END_YEARS_AGO)`（≈0.47）——「约 700 万年前 · 人猿分叉」锚点在滑块上的位置，从 Lec.K 当场计算，不许手写 0.47。
- `STEP_EDGES = [0, 0.12, 0.25, uSplit, 0.70, 0.90, 1.00]`——六个事件的阈值，本页 UI 常量。
- 景观内部参数（不显示数值，由 u 驱动）：`forestDensity(u)` 锚点 0→0.9、uSplit→0.5、1→0.1；`grassCover(u)` 锚点 0→0.2、uSplit→0.5、1→0.9；`skyTint(u)` 从湿润蓝绿到干热金黄做色相插值；`figureState(u)` 0→树上、uSplit→地面边缘、0.8→草地行进、1→双足站立；`footprintOpacity(u)` 在 u<0.9 时为 0，到 u=1 渐显为 1。

## 必须点出来的一到三句

- 东非的气候不是突变，而是几百万年的渐变——森林在这段时间里退成孤岛，开阔地成为主角。
- 祖先不是「决定」站起来，而是被环境一步步放到了开阔地上；双足站立是那个世界的日常姿态。
- 到 366 万年前，这个姿态已经稳定到能留下脚印——这套身体为什么划算、又付出什么代价，下一页讲。

## 交互（只有这一个）

**环境迁徙滑块**（页表指定，唯一交互）。

- 读者动什么：拖动页面底部的水平滑块，或点击时间轴任意位置，控制「观察时刻」u ∈ [0,1]，物理跨度对应约 1000 万年前 → 366 万年前。页面载入时 u = 0（约 1000 万年前，连续森林）。
- 看到什么变：
  - 左栏景观随 u 连续变化：树冠密度、树的分布、草地高度与颜色、天空色调、远处高地的清晰度、祖先剪影的位置与姿态（树上 → 地面边缘 → 草地行进 → 双足站立）、前景脚印的浮现。
  - 右栏六步：当前步骤高亮，已过步骤降饱和保留，未到步骤虚线显示；当前箭头的连接问题只在此时显示。
  - 滑块读数：「x.x 百万年前」随拖动连续更新；两个锚点标签固定在轴上——「约 700 万年前 · 人猿分叉」「366 万年前 · Laetoli 脚印」。越过 uSplit 时，剪影从树上移到地面边缘，强调分叉这一时刻。
  - u = 1 时，场景定格在开阔草地与脚印，与 p03 开场画面形成同构。
- 从中该形成什么直觉：几百万年是被气候一点一点「拖」过去的；祖先的双足站立是这个漫长过程里被环境放上地面的日常，不是一次有意的发明。滑块的连续拖动保证「渐变感」——没有一个瞬间是森林突然消失。

辅助（属于同一交互的延伸，不算第二个交互）：滑块右端外侧放一枚小按钮「播一遍」，把 u 从 0 平滑推到 1，在每个事件阈值处停顿约 0.6 秒，用于课堂演示；u 的 tween 用 gsap-core 实现。

## 不许碰

- **双足行走的力学（p11 专属）**：本页只呈现「森林退去、人站到开阔地上」这一环境与行为的变迁；不出现质心、省力、看得远、散热、脊柱、骨盆等任何力学解释或代价分析，也不对站姿作「为什么这样更优」的说明——那是 p11 的入口。
- **谱系树（p45 专属）**：人猿分叉只作时间锚点，不画分支图、不展开人科谱系；uSplit 之后的剪影代表「我们这一支」，但画面不出现另一支。
- **手与工具（p12、p17 专属）**：祖先剪影不带工具，不特写手部，不出现任何抓握分析。
- **3D 表现**：本页一律 2D，硬约定。

## 媒体

- 插画（全页主场景）：东非裂谷—稀树草原景观，作为左栏唯一主画面。
  - 分层：天空（云 / 薄雾）、远山高地、中景树群、前景草地、祖先剪影、脚印层。
  - 为什么用插画而非示意图：气候带来的「世界变了」是必须被感觉到的氛围；只有连续插画能把湿润密林到干热稀树草原的渐变表现得既可信又有情绪，真实照片只能定格一个时间点，无法承载 600 万年的过渡。
  - 处理：页面以分层 SVG/Canvas 图元实时驱动各层参数（密度、透明度、色相）；插画只提供造型与配色锚点，不作为静态位图。
- 祖先剪形规范（三姿态）：树上攀附 / 地面行进（略带弓身）/ 双足站立。剪影风格，无五官，不带装备；只指示行为变化，不承担任何解剖说明。
- 出处与许可：全部为原创生成插画 / 矢量，无外部来源；如需页脚署名，用极小字「原创生成插画」即可。
