# page-13 · 脑容量时间线 · **135 秒**

kicker：猿的身体  
主标题：400 → 1400：脑容量的三倍半扩张

## 知识结构：generalization

这一页要把「多个离散化石证据 → 一个趋势概括」的关系显式化：四个古人类物种的脑容量数据点按年代沿同一条时间轴排列，每一个点是一行账目；四行并排时，从约 400 mL 到约 1400 mL 的增长一目了然。左上角用一个计算出的「≈3.5×」比值把四行收拢成一句概括：这是演化史上最剧烈的器官扩张之一。

显式化的机制是对齐的行列：时间轴统一时间参照系，账本行统一物种与容量，两个坐标把离散点压成一条趋势线。

## 表征形式

交互式时间线 + ledger 版式。静态基础是宽幅账本：顶部一条从「约 700 万年前」到「今天」的水平时间轴，四个数据点以实心圆点落在轴上，点间用虚线连接（虚线表示推测的连续趋势，实心点表示化石实测）；下方是四行对齐的账目，每行有物种名、距今时间、脑容量。

动态层是读者控制的扫描线：一根垂直扫描线沿时间轴移动，经过数据点时点亮对应账行，右上角大数字显示当前脑容量（数据点之间为线性插值，并在虚线区标出「推测段」）。

## 四条支撑

四行账目，按时间从古到今排列，每行是一个独立的化石证据点：

1. 南方古猿 —— 距今约 `AUSTRALOPITHECUS_YEARS_AGO` 年，脑容量约 `AUSTRALOPITHECUS_BRAIN_ML` mL。
2. 能人 —— 距今约 `HOMO_HABILIS_YEARS_AGO` 年，脑容量约 `HOMO_HABILIS_BRAIN_ML` mL。
3. 直立人 —— 距今约 `HOMO_ERECTUS_YEARS_AGO` 年，脑容量约 `HOMO_ERECTUS_BRAIN_ML` mL。
4. 智人 —— 距今约 `Lec.K.HOMO_SAPIENS_YEARS_AGO` 年，脑容量约 `HOMO_SAPIENS_BRAIN_ML` mL。

时间轴起点 `Lec.K.HOMININS_SPLIT_YEARS_AGO` 处放一个灰色分叉标记，标注「人科与黑猩猩谱系分开」，不设具体数据点；从分叉到南方古猿之间的约 300 万年用浅灰渐变表示「早期线索稀疏」。

### 物种数据

页面常量区（注明「全套口径」）：

- `AUSTRALOPITHECUS_BRAIN_ML = 400`（本套指定）
- `HOMO_SAPIENS_BRAIN_ML = 1400`（本套指定）
- `AUSTRALOPITHECUS_YEARS_AGO = 4_000_000`（约数，页面常量）
- `HOMO_HABILIS_BRAIN_ML = 600`（近似，页面常量）
- `HOMO_HABILIS_YEARS_AGO = 2_000_000`（约数，页面常量）
- `HOMO_ERECTUS_BRAIN_ML = 900`（近似，页面常量）
- `HOMO_ERECTUS_YEARS_AGO = 1_000_000`（约数，页面常量）
- `SPLIT_YEARS_AGO = Lec.K.HOMININS_SPLIT_YEARS_AGO`
- `HOMO_SAPIENS_YEARS_AGO = Lec.K.HOMO_SAPIENS_YEARS_AGO`

页面计算并显示：`RATIO = HOMO_SAPIENS_BRAIN_ML / AUSTRALOPITHECUS_BRAIN_ML`（约 3.5×），不在代码里写死 3.5。

## 必须点出来的一到三句

1. 七百万年，脑容量从约 400 mL 涨到约 1400 mL——接近三倍半。
2. 它不是一条匀速上升：早期很长一段保持低平，陡峭的扩张集中在最近的约两百万年。
3. 这是演化史上最剧烈的器官扩张之一。

## 交互（只有这一个）

脑容量时间线：读者拖动时间轴下方的滑块，或按播放键让扫描线自动前进。

- 读者动什么：滑块左右移动，或点播放/暂停。
- 看到什么变：垂直扫描线沿时间轴扫过；扫描线到达某个数据点时，下方对应账行被点亮；右上角的大数字更新为当前脑容量（数据点之间按线性插值，虚线区同时出现「推测」提示）；已扫过的趋势线逐渐显形。
- 该形成什么直觉：脑容量不是恒定速率增长，而是「平台—陡升」的阶梯式上升；从 400 到 1400 不是小调整，是器官层面的三倍级扩张。
