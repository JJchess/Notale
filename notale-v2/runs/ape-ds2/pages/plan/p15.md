# page-15 · 散热收支 · **110 秒**

**kicker:** `BODY / COOLING` · **主标题:** 散热：无毛、汗腺、长腿如何造就耐力之王

## 知识结构：process

这一页显式化的是“产热—散热”的因果链：奔跑产生热，热排不掉则体温上升，跨过临界线则身体停摆；无毛、汗腺、长腿分别从“散热端”和“产热端”拦截失速，使体温稳定在临界线下，奔跑因此可以持续。

不是单线顺序，而是带分支的因果链：

- 主轴：产热 → 升温 → 过界（失控路径）
- 两条修正边：无毛+汗腺（散热端拦截）、长腿（产热端拦截）
- 结果：散热 ≥ 产热 → 稳态 → 奔跑持续

页面上用箭头把这一步一步接起来，箭头旁标注“于是”“否则”“只要”等连接词，让因果方向不被看反。

## 表征形式

动态 + 交互。整页 2D，`split-lr` 左右分栏：

- 左栏：散热模拟器。一片烈日下的草原横断面，一个跑步者从左侧跑向右侧；上方有核心体温计和体温-时间曲线，曲线向右生长。
- 右栏：六张因果 step 卡，箭头串联，随模拟状态点亮对应步骤。

左右联动：体温上升时右栏第 2 步高亮；汗液蒸发时第 4 步高亮；体温稳定时第 6 步高亮。

## 六个 step

| # | step | 页面文字 | 箭头连接 |
|---|---|---|---|
| 1 | 产热 | 肌肉奔跑时产生大量热 | → 于是 |
| 2 | 升温 | 热量排不掉，核心温度上升 | → 否则 |
| 3 | 过界 | 逼近 40°C，身体强制停机 | 分支：被 4、5 拦下 |
| 4 | 蒸发 | 汗液在无毛皮肤上直接蒸发，带走热量 | 散热端拦截 |
| 5 | 省热 | 长腿步频低，同样速度下产热更少 | 产热端拦截 |
| 6 | 稳态 | 散热 ≥ 产热，体温稳住，奔跑持续 | → 回到 1，形成回路 |

### 真实数值与公式

以下常量在页面常量区定义，注释为“本页口径”；若全套后续纳入 `Lec.K`，则改从 `Lec.K` 读取。

| 常量 | 值 | 用途 |
|---|---|---|
| `P15.INITIAL_CORE_TEMP` | 37.0 °C | 体温曲线起点 |
| `P15.OVERHEAT_CORE_TEMP` | 40.0 °C | 红色过界线 |
| `P15.FULL_SWEAT_TEMP` | 39.0 °C | 汗腺满负荷启动温度 |
| `P15.RUNNING_HEAT` | 1000 W | 中等速度奔跑产热 |
| `P15.LATENT_HEAT_WATER` | 2400 kJ/L | 每升汗蒸发带走的热量 |
| `P15.SWEAT_RATE_DENSE` | 1.5 L/h | 密集汗腺最大汗率 |
| `P15.SWEAT_RATE_SPARSE` | 0.3 L/h | 稀疏汗腺最大汗率 |
| `P15.FUR_COOLING_MULT` | 无毛 1.0 / 厚毛 0.35 | 毛层阻碍蒸发 |
| `P15.LEG_HEAT_MULT` | 长腿 0.85 / 短腿 1.25 | 步频与产热 |
| `P15.BODY_HEAT_CAPACITY` | 245000 J/K | 约 70kg 人体热容 |
| `P15.COURSE_DISTANCE` | 10 km | 模拟路线长度 |
| `P15.RUNNING_SPEED` | 12 km/h | 模拟匀速 |
| `P15.TIME_COMPRESSION` | 1 现实秒 = 5 模拟分钟 | 演示节奏 |

模型由页面当场计算，不写死曲线：

- `sweat_drive = clamp((T - P15.INITIAL_CORE_TEMP) / (P15.FULL_SWEAT_TEMP - P15.INITIAL_CORE_TEMP), 0, 1)`
- `sweat_rate = 所选汗腺最大汗率 × sweat_drive`
- `cooling_W = sweat_rate × P15.LATENT_HEAT_WATER / 3.6 × 所选毛层系数`
- `heat_W = P15.RUNNING_HEAT × 所选腿长系数`
- `dT = (heat_W − cooling_W) × dt / P15.BODY_HEAT_CAPACITY`

## 必须点出来的一到三句

- 无毛、汗腺、长腿——人类可能靠散热能力成为动物界的耐力之王：不是跑得比谁都快，而是能在热浪里跑得比谁都久。
- 散热是一条收支链：产热减去散热，剩下来的就是体温上升；奔跑能否继续，取决于那个差值能否压在 40°C 之前变成零。

## 交互（只有这一个）

**散热模拟器。**

读者动什么：

- 选择预设：“人类体质”（无毛、密集汗腺、长腿）或“典型兽类”（厚毛、稀疏汗腺、短腿）。
- 也可以手动拨三个开关：体毛（无毛/厚毛）、汗腺（密集/稀疏）、腿长（长/短）。
- 按下“开始奔跑”。

看到什么变：

- 跑步者沿草原路径从 0 km 跑向 10 km。
- 核心体温计和体温曲线同步移动；曲线碰到 40°C 红色虚线时，跑步者减速倒地，显示“过热，停在第 X km”。
- 曲线在 40°C 以下稳定下来时，跑步者跑完全程。
- 每次跑完，这条曲线淡化为背景参考线，下一次运行叠加新曲线，让读者直接看出单个开关的影响：厚毛使斜率更陡，稀疏汗腺使平台抬高，短腿使升温更快。

从中该形成什么直觉：

- 决定能跑多远的是“产热端”和“散热端”的差，不是单看哪一个特征。
- 无毛、汗腺、长腿不是三个孤立细节，而是同一道持续奔跑问题的三个解。
