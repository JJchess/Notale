# page-19 · 熟食的能量账本 · **120 秒**

kicker：`COOKING LEAP`  
主标题：熟食的能量账本

## 知识结构：comparison
这一页要显式化的不是静态的两栏对比，而是同一份食物在“生”与“熟”两个端点之间的**前后态因果链**：火候升高 → 可吸收能量上升 → 消化器官的能耗与体积下降 → 身体能拨给大脑的净能量变大。画面上用“生食 / 熟食”两栏夹住中央的火候轴，每一行指标由生端指向熟端的长箭头连接；底部再把三行变化汇总成一条“能量差额 → 大脑”的主干箭头，让“省下的能量去养大脑”成为可见的因果终点。

## 表征形式
动态交互：一个 2D 灶台剖面，同一块食物横在火苗上方。读者拖动火候滑杆（0–100），食物视觉从生变熟，右侧四行数值同步变化。需要建立的心理表征是：火是一个装在身体外面的消化器官——它不把能量造出来，而是把原本锁在食物里、身体难以取用的能量释放出来，同时减轻消化系统的负担，于是净能量增加。用“同一块食物随火候连续渐变”来实现，比两张静态图更能建立连续因果感。

## 生食 vs 熟食：四行对比表
比较对象是同一份食物的生、熟两端。以一份固定总能量为基准，数值都是相对单位。页面用 `doneness`（0–1，由滑杆换算）在生、熟端点间线性插值。

- 基准：`P19.MEAL_TOTAL_UNITS = 100`（一份食物的总化学能，相对单位）
- 生食端点（`doneness = 0`）：
  - 可吸收能量：`P19.RAW_ABSORB_UNITS = 65`
  - 消化器官耗能：`P19.RAW_DIGEST_UNITS = 15`
  - 净能量：`P19.RAW_NET_UNITS = P19.RAW_ABSORB_UNITS - P19.RAW_DIGEST_UNITS = 50`
  - 消化器官相对大小：`1.0`（以生食状态为基准）
- 熟食端点（`doneness = 1`）：
  - 可吸收能量：`P19.COOKED_ABSORB_UNITS = 90`
  - 消化器官耗能：`P19.COOKED_DIGEST_UNITS = 5`
  - 净能量：`P19.COOKED_NET_UNITS = P19.COOKED_ABSORB_UNITS - P19.COOKED_DIGEST_UNITS = 85`
  - 消化器官相对大小：`0.6`

实时计算：
- `absorb = lerp(P19.RAW_ABSORB_UNITS, P19.COOKED_ABSORB_UNITS, doneness)`
- `digest = lerp(P19.RAW_DIGEST_UNITS, P19.COOKED_DIGEST_UNITS, doneness)`
- `net = absorb - digest`
- `gut_scale = lerp(1.0, 0.6, doneness)`

以上四个常量是本页模型参数（示意），不是 `Lec.K` 的全套统一实数。它们用于表现方向与量级差，不是精确实验测量值；页面上用一小行“示意模型”标注。

## 必须点出来的一到三句
1. 熟食没有给食物添加能量，它让身体从同一份食物里多拿到约 35 单位的净能量。
2. 消化器官因此可以变小，维护它的成本降下来，省下的能量才能拨给大脑。
3. 火的本质是一个装在身体外面的消化器官——它替身体先做了一部分消化。

## 交互（只有这一个）
**生熟食对比灶**：读者拖动画面上唯一一根滑杆（火候 0–100）。
- 动：火候值增加，灶上食物由生变熟——颜色变深、质地变软、冒出一缕热气。
- 变：右侧四行数值实时更新：`absorb` 上升、`digest` 下降、`net` 上升、消化器官图标缩小。
- 升成的直觉：火候越高，食物越容易被身体取用，消化系统越省力，净能量越多；底部一条“净能量差额”的箭头把增加的净能量引向一个简笔大脑图标，大脑图标随之变亮，让“多出来的能量去养大脑”被直接看见。

不做成小游戏——没有目标、输赢、重置，只有一根滑杆和一个即时反馈的能量账本。

## 不许碰
- 不讲火的考古证据：不出现灰烬层、Wonderwerk 洞穴、烤焦种子、“约 100 万年前”等任何时间、地点、地层细节。
- 不跨入 p14 的代谢能量口径：不重复“大脑占体重 2%、消耗 20%”等数字，也不展开基础代谢率；这里只讲“省下来的能量流向大脑”这一条通路。
- 不讲具体营养化学（淀粉糊化、蛋白质变性机制）——只停留在能量提取率和消化成本的层面。
- 不延伸熟食与围猎、社会分工的关联（p20 职责）。
- 不给出“熟食必然导致大脑增大”的强因果断言；用“省下的能量养活了不断膨胀的大脑”的表述，保留演化解释的开放性。
