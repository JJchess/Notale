# page-20 · 把羚羊赶进死角 · **135 秒**

kicker：语言之前

## 知识结构：process

这一页要显式化一层关系：**一次围猎是一串前后态的变化，而这串变化在执行开始前就已经被三条预先画好的路线决定了**。真正的因果发生在“画路线”这一步，而不是跑动之中。

显式化手段：

- 三条彩色路线在执行前全部画在棋盘上；执行中不可修改——读者直接看到「计划先于动作」。
- 一条共享时间轴同时推进三个猎人与猎物，强调所有角色共用同一个时钟、互不交谈。
- 回放时，猎物每次转向的瞬间，从最近的猎人向猎物画一根细箭头，把「是哪一个位置逼出了这次转向」显式化。
- 棋盘底部一条六阶段 stepper（定位→计划→发动→驱赶→转向→兜住）随执行逐盏点亮，给出过程的前后态。

## 表征形式

交互模拟 + 动态回放。2D 俯视网格棋盘（canvas-full；全套约定本页用 2D，不上三维）。

棋盘即全部画面：9×8 网格，三面岩壁、底部中央留两格小门的「布袋」地形。三枚猎人棋子和一枚羚羊棋子都用平面矢量形（人形剪影 + 羚羊剪影），保持棋盘游戏的抽象感，不用写实场景。执行前棋子静止、路线以同色虚线显示；执行中棋子在格心间同步移动；结束后进入回放，叠加压力箭头与角色标注。

## 围猎的六个事件

每个事件是棋盘上的一档状态，也是底部 stepper 的一档：

1. **定位** — 羚羊在 (4,4)，三猎人分别在 (4,6)、(2,4)、(6,4)；画面上的规则只有一句：「三个人，不能说话，把羚羊赶进死角。」
2. **计划** — 读者为三人各画一条路线；三条彩色虚线同时出现在棋盘上。预判、分工与共享意图全部发生在这一步。
3. **发动** — 时间轴开始走动；三猎人沿各自路线同时出发。执行中不能追加任何指令。
4. **驱赶** — 中央路线的猎人逼近，羚羊背离威胁；回放时出现第一根压力箭头。
5. **转向** — 底部门洞与两侧被依次封死，羚羊每次想换方向都被最近的猎人逼回；每一根回放箭头标注一次被迫转向。
6. **兜住** — 羚羊被逼进角落、无可走格，场景静止 0.6 s，结果横幅出现「兜住了」。

### 棋盘参数

本页不使用 `Lec.K` / `Lec.P`——没有跨页共享数值。下列参数全部写在页面常量区，注释「本页交互参数」。若开发期模拟显示「演示路线」无法必胜，只允许微调标了「可调」的项，锁定后在注释里记录校准值。

| 参数 | 值 / 算法 | 单位与说明 |
|---|---|---|
| `GRID_COLS` | 9 | 列数，x: 0–8 |
| `GRID_ROWS` | 8 | 行数，y: 0–7（y 向下增大） |
| `CELL_SIZE` | `floor(min(W/9, H/8) × 0.86)` | 运行时由画布像素计算，不写死 |
| 岩壁格 | 见下「岩壁集合」 | 不可通行 |
| 门洞（可走） | (4,7)、(5,7) | 布袋唯一出口；羚羊踩上任一格即「逃了」 |
| 羚羊起始 | (4,4) | 场地中央 |
| 猎人 A 起始 | (4,6) | 门洞正上方，天然驱赶位 |
| 猎人 B 起始 | (2,4) | 左侧，天然左合围位 |
| 猎人 C 起始 | (6,4) | 右侧，天然右合围位 |
| `HUNTER_OPEN_PACE` | 0.55 | s/格，开阔地 |
| `PREY_OPEN_PACE` | 0.50 | s/格，开阔地；羚羊比猎人快约 10%，直线追必失败 |
| `PREY_DECISION_S` | 0.3 | s，羚羊决策间隔 |
| `THREAT_RADIUS` | 2.0 | 格，猎人在此距离内才算「被追」（可调） |
| `HOME_WEIGHT` | 1.2 | 羚羊向下逃的偏好权重，`score = dist_to_nearest_hunter_after_step + HOME_WEIGHT × y`（可调） |
| `MAX_WAYPOINTS` | 4 | 每名猎人最多路线点，可为 0 |
| `HUNT_TIMEOUT_S` | 25 | s，超时判「拖久了」 |
| `SETTLE_S` | 0.6 | s，猎物无可走格后维持该时长即判定捕获 |

岩壁集合（运行时由常量数组生成，不可走）：

```
y=0:  (0,0)…(8,0)                      # 上墙（坡坎/绝壁）
x=0:  (0,1)…(0,7)                      # 左墙
x=8:  (8,1)…(8,7)                      # 右墙
y=7:  (0,7)(1,7)(2,7)(3,7)(6,7)(7,7)(8,7)   # 底墙，只留 (4,7)(5,7) 门洞
```

羚羊行为规则（目标算法，开发期照此实现并校准）：

- 每 `PREY_DECISION_S` 决策一次（或每次抵达格心时）。
- 候选格 = 8 邻域中可走、非岩壁、无猎人占据的格；候选为空则原地不动。
- 无猎人在 `THREAT_RADIUS` 内：默认朝下（y 增大）走；正下方不可走则取「最接近正下方」的可走格。
- 有猎人在 `THREAT_RADIUS` 内：对候选格打分 `dist_to_nearest_hunter_after_step + HOME_WEIGHT × y`，取最高分；并列按顺时针固定顺序取第一个（东→东南→南→西南→西→西北→北→东北）。
- 若最高分不高于当前格得分，仍取最高分候选格——这是「被逼进角落」的机制。

结果判定：

| 结果 | 条件 |
|---|---|
| 逃了 | 羚羊到达 (4,7) 或 (5,7) |
| 兜住了 | 羚羊候选格为空，且该状态保持 `SETTLE_S` |
| 拖久了 | 超过 `HUNT_TIMEOUT_S` |

### 演示路线（默认装载）

页面提供「演示」按钮，装载一条已跑通的合围路线，让课堂先看一遍机制。结构目标是：**先封门、再驱赶、最后在左上角合拢**，终点站位为羚羊 (1,1)，A (1,2)、B (2,1)、C (2,2)，羚羊四面皆堵。开发期必须以行为模拟实际跑通并锁定；若不通，只调 `THREAT_RADIUS`、`HOME_WEIGHT` 或路线点，保持「三线合拢进角落」的结构不变。

## 必须点出来的一到三句

1. 围猎在跑动之前就已经完成了——三条路线画完，结局就定了；抓住羚羊的是封死的路线，不是速度。
2. 驱赶、左合围、右合围这些分工不是谁在下命令，是从站位和路线里长出来的；三个人共用同一份可见的计划，就是语言之前的「共享意图」。
3. 语言不是合作的起点，它只是把早已存在的合作说出口。

（第三句留给 p23 去接，本页不展开语言结构。）

## 交互（只有这一个）

协同狩猎棋盘 —— 路线规划。

- **读者动什么**：点选猎人 A/B/C（棋子或右上角色块），再点可走格为这名猎人添加路线点（最多 `MAX_WAYPOINTS` 个）；点已有路线点删除。三条路线画完后按「运行」；「演示」装载示例路线，「清空」重来。
- **看到什么变**：执行前，路线以猎人同色虚线即时出现在棋盘上；执行中，四枚棋子在格间同步移动，底部六阶段 stepper 逐档点亮；结束后中央横幅给出 «兜住了» / «逃了» / «拖久了» 之一，并为三条路线标注角色：驱赶线、左合围线、右合围线。
- **回看**：横幅出现「回看」；回放中羚羊每次转向的瞬间，从最近猎人指向羚羊画一根细箭头，把「这次转向是被谁逼的」显示出来；失败时给一句指向性提示（如「看看门洞谁没守住」）。
- **该形成的直觉**：先有唯一一份共同计划，才有默契的合围；分工出于站位；封路胜过追逐。执行中不能改路线，正是「没有语言」的规则化表达——能改的只有发起前的那份计划。
- **重试**：失败后棋盘保留已画路线，读者调整任一猎人路线即可重跑。

135 秒课堂节奏（教师侧参考）：15s 读规则一句 → 25s 播「演示」路线一次 → 45s 全班决定改一条路线（如左合围晚一步），跑第二次 → 30s 点出三条线的角色与「共享意图」→ 20s 落三句收束。

## 不许碰

- 不讲语言结构：不出现词汇、语序、发音、语法；解说只说「不用说话」，不解释语言如何运作（p23）。
- 不出现具体工具名与工具图形：猎人徒手，只有身体与路线；p17 的石器、p18 的火与 p19 的烹饪不得入画。
- 不进入 p24 的社会规模：不出现群体大小、邓巴数、脑容量与社会生活的关系。
- 不展开 p29 的城市分工：分工只发生在三名猎人的临时站位上，不类比工匠、士兵、祭司。
- 不借用其余小游戏的数值系统：无能量配给（p14）、无角度/力度（p17）、无速度选择（p36）、无动量守恒（p38）；本页唯一操作是画路线。
- 不把「围猎成功」画成宰杀或烹煮：画面与结果止于「兜住了」，羚羊形象不流血。

## 版面提示

- 棋盘占满画布（canvas-full）：9×8 网格居中，四周留出顶栏、底带与安全边距。
- 左上角半透明信息卡：kicker、标题、一行规则「三个人，不能说话，把羚羊赶进死角。」；右上角三枚猎人色块（A/B/C，与路线同色，取主题色板中区分度最高的三色）。
- 底部固定高度（约 64px）时间轴带：左侧六阶段 stepper，右侧按钮 [演示｜清空｜运行]。
- 结果横幅为中央浮层，不遮棋盘四角；「回看」按钮附在横幅内。
- 棋子用简单矢量形，尺寸约 0.7 倍格宽；路线为 2px 虚线加小圆点路线点，颜色与猎人一致。
