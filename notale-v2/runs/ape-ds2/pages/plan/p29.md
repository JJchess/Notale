# page-29 · 不种地的人 · **110 秒**

- KICKER：`城市 · 分工`
- 主标题：不种地的人

## 知识结构：enumeration

这一页要把「剩余粮食 → 不种地的人 → 城市分工」的因果链，显式化为四项并列的职业角色。城市不是一张总览图，而是由四张各自独立的卡片依次放上去才成形的：工匠、士兵、祭司、书吏。四者之间没有从属关系，共同占据一片聚落，聚落才升级为城市。

## 表征形式

交互式放置板。中央是一片空聚落，左侧是四张等待被放置的职业卡片，底部是一条「剩余粮食」计量条。随着卡片被拖入聚落，对应区域点亮为一座建筑，计量条同步缩短一格。全部放完后，聚落整体收束为一座城市并出现标题。整个动作发生在 110 秒内，读者只需要完成「放下卡片、看着城市成立」这一个认知动作。

## 并列的各项

四张职业卡片，按枚举关系并排陈列，每张包含：名称、剪影、该职业为城市提供的功能、放置后对应的建筑。

| 职业 | 功能 | 对应建筑 |
|---|---|---|
| 工匠 | 制造工具、器物 | 作坊 |
| 士兵 | 保护聚落、维持安全 | 营房 |
| 祭司 | 主持仪式、连接神与秩序 | 神庙 |
| 书吏 | 记账、计数、传递命令 | 书吏房 |

书吏卡片只写「记账、计数、传递命令」，不出现任何书写工具、字体、符号或介质细节；那一整块都留给 p30。

本页演示常量，写在页面自身常量区并注释「本页演示参数，非史实」：

- `DEMO_SURPLUS_UNITS = 4`：农业剩余总量，用抽象「份」表示，不映射任何历史估算
- `COST_PER_ROLE = 1`：每放置一个职业消耗一份剩余
- 全部放置完毕后，剩余归零，聚落成为城市

画面中的数值一律从这两个常量取，不写死。

## 必须点出来的一到三句

1. 剩余粮食把人从土地中解放出来——这是城市分工的起点。
2. 工匠、士兵、祭司、书吏彼此不同、彼此独立，却一起构成了城市。
3. 城市一旦成立，文明演化的速度就换挡了。

## 交互（只有这一个）

**城市放置板。**

读者从左侧职业卡池中拖出任意一张卡片，放到右侧聚落的空位上。每放下一张：
- 该职业的卡片从卡池移到聚落对应区域；
- 聚落中亮起一座对应建筑；
- 底部剩余粮食计量条减去一格。
当四张卡片全部放完，剩余粮食归零，聚落整体被一圈光晕包住，上方浮现大字「城市」，并显示一句收束语：「农业剩余养活了不种地的人，城市因此出现。」

读者可以点击重置按钮，将全部卡片退回卡池、建筑熄灭、剩余粮食恢复，重新放置一遍。

这个交互要让读者形成的直觉是：每一类不种地的人都要靠一份剩余粮食来「养」，城市不是凭空出现的，而是由农业盈余一块一块换来的。
