# page-30 · 外部记忆 · **100 秒**

- kicker：`EXTERNAL MEMORY`
- 主标题：文字：把知识搬进介质

## 知识结构：classification

这一页要把「知识存放在哪里」显式化成三个层级，让「搬进介质」这个动作有一个可以看见的落点：

1. **个体记忆层**——知识在一个人脑中，寿命以「一生」计；
2. **外部介质层**——知识被写成字形、刻进介质，寿命以「千年」计；
3. **跨代累积层**——知识离开原初的书写者之后，仍能被后世读取、继续传递。

三栏 triptych 正好对应这三层：左栏是记忆层，中栏是介质层，右栏是累积层。三层之间用一条贯穿底部的时间轴箭头连接，箭头方向即「记忆 → 介质 → 后世」，每一层的属性行（承载者 / 寿命单位 / 是否独立于人）上下对齐，让「从记忆到介质」这件事变成一次可见的层级下沉。

## 表征形式

交互 + 动态时间轴。主场景是一张三联桌：左栏站着一位书写者（简笔剪影），脑中有一个想法气泡；中栏是一块龟甲/刻辞板，读者把象形字形拖进刻槽，完成一次「刻下」；右栏出现千年后的读者，辨认出同一段字形。底部时间轴在交互完成后自左向右推进。

核心心理表征：让读者亲眼看到同一条知识，在左栏随人淡出、在中栏被刻进介质、在右栏被千年之后的人读出。知识本身没有变，变的是它所在的层级。

## 层级里的各项

### 三层结构的填充

**左栏 · 个体记忆层**
- 一个人物剪影（简笔，浅灰色），面向中栏。
- 头顶气泡内：一幅小示意图，画面上方一个太阳、一个月亮，或直接写现代字「日月」。
- 属性标签：`承载者：一个人的大脑`　`寿命：一生`

**中栏 · 外部介质层（交互区）**
- 一块龟甲轮廓（浅棕底、深棕裂纹），上方有两个并排的刻槽。
- 刻槽下方是字素托盘，放 4 个字形牌：
  - 「日」：外圆内一点；
  - 「月」：月牙弧；
  - 「山」：三峰；
  - 「水」：波浪线。
- 字形采用高度象形的简化甲骨文风格，不附现代字标注；唯一文字提示是：「把『日』与『月』刻下来。」
- 两个字形就位后，字形颜色由浅赭变深赭，像被刻入龟甲。
- 属性标签：`承载者：龟甲`　`寿命：千年`

**右栏 · 跨代累积层**
- 一个现代读者剪影（与左栏同款人物，浅灰色），手持放大镜，面向中栏。
- 龟甲记录以较小尺寸重现，旁边浮现现代字「日月」。
- 属性标签：`承载者：一代代后人`　`寿命：持续累积`

### 时间轴上的事件

- 事件 1：**刻下**——读者完成拼配，字形落进刻槽。
- 事件 2：**一生之后**——左栏人物与气泡淡出，原知识在脑中消失。
- 事件 3：**约3300年后**——右栏读者出现，读出龟甲上的字形。

### 公式与常数

页面自身常量区：

## 必须点出来的一到三句

1. 知识放在脑子里，寿命跟着人走；写在介质上，寿命就不再受个人限制。
2. 今天的人还能认出三千多年前的字，不是因为记忆好，而是因为有人把它刻了下来。

## 交互（只有这一个）

**文字拼配桌**

- 读者动什么：从字素托盘中，把代表「日」和「月」的两个字形拖到龟甲的两个刻槽里。选错的字形会滑回托盘并轻微抖动，不惩罚，可重试。
- 看到什么变：
  1. 两个字形都就位后，字形从浅赭变深赭，像被刻入龟甲；
  2. 底部时间轴自动推进：左栏人物和记忆气泡淡出；
  3. 龟甲表面出现细微风化裂纹；
  4. 右栏现代读者出现，读出龟甲，并浮现现代字「日月」和「约3300年前」。
- 从中该形成什么直觉：同一个知识，放在大脑里会随人消失；刻进介质，就获得独立于人的寿命。把字形「拼配」到介质上，正是从记忆层搬到介质层的那个动作。
- 完成态之后提供「再来一次」重置按钮，恢复托盘、刻槽与时间轴初始状态。
