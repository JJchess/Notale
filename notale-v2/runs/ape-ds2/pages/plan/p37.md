# page-37 · 质量比计算器 · **115 秒**

## 知识结构：process

这一页要显式化的是「剥离链」：满箭起飞 → 一级烧完并抛弃 → 二级烧完并抛弃 → 三级烧完并抛弃 → 只剩有效载荷继续飞。链条上每一段都必须把下一段整个抬起来，所以越靠上面的段越细小，越靠下面的段越庞大。页面靠「每一段烧完后剩余质量骤减」这组减法事件，让读者看见有效载荷不是火箭的“货”，而是层层燃料烧尽后剩下的那一点残余。

## 表征形式

交互式账本。主视觉是一组按质量线性绘制的横条，五段叠成火箭轮廓：一级、二级、三级、有效载荷，旁边列出对应账目行的数值。有效载荷条只有约 1.6% 宽，几乎看不见——这是有意为之，靠视觉逼出「原来火箭几乎全在运燃料」的直觉。叠加在账本上的是一次「剥离播放」：三级逐段淡出，剩余质量逐级跳小。

## 剥离链上的五个事件

默认以土星五号 / 阿波罗 11 号为基准（有效载荷 = `Lec.K.SATURN_V_TLI_PAYLOAD_T`）。

| 事件 | 本段质量 | 剩余质量 | 占起飞质量 | 账本批注 |
|---|---|---|---|---|
| 满箭起飞 | — | `SATURN_V_LAUNCH_MASS_T` = 2850 t | 100% | 起飞 |
| 一级烧完并抛弃 | `SATURN_V_STAGE_1_T` = 2235 t | 615 t | 约 78% | 最大的一段，几乎全是燃料 |
| 二级烧完并抛弃 | `SATURN_V_STAGE_2_T` = 471 t | 144 t | 约 16.5% | 烧完，再扔 |
| 三级烧完并抛弃 | `SATURN_V_STAGE_3_T` = 99 t | 45 t | 约 3.5% | 仍然烧完就扔 |
| 有效载荷飞往月球 | — | 45 t | 约 1.6% | 这就是你要送的东西 |

拖滑杆时，本段质量、剩余质量、条长全部按质量比重新缩放，事件顺序不变。

### 公式与常数

这一页的常量都写在页面自身常量区，并标注「全套口径」：

- `Lec.K.SATURN_V_LAUNCH_MASS_T` = 2850（吨；土星五号起飞质量）
- `Lec.K.SATURN_V_TLI_PAYLOAD_T` = 45（吨；地月转移有效载荷）
- `Lec.K.SATURN_V_STAGE_1_T` = 2235（吨；一级总质量）
- `Lec.K.SATURN_V_STAGE_2_T` = 471（吨；二级总质量）
- `Lec.K.SATURN_V_STAGE_3_T` = 99（吨；三级总质量）
- `Lec.K.SATURN_V_FUEL_FRACTION` = 0.93（约；整箭燃料占起飞质量的约数，只作标注用）

派生函数写进 `Lec.P`，页面不写死：

- `Lec.P.saturnVMassRatio()` = `SATURN_V_LAUNCH_MASS_T / SATURN_V_TLI_PAYLOAD_T`，约 63.3
- `Lec.P.scaledStageT(payloadT, stageKey)` = `payloadT * saturnVMassRatio() * (SATURN_V_STAGE_X_T / SATURN_V_LAUNCH_MASS_T)`
- `Lec.P.remainingAfterStage(payloadT, stageKey)` = `scaledTotalT - 已抛弃各级质量之和`
- `Lec.P.payloadFraction()` = `1 / saturnVMassRatio()`，约 1.6%

滑杆输入 `payloadT` 在 0.001 t（1 kg）到 50 t 之间；总质量 = `payloadT * saturnVMassRatio()`。

## 必须点出来的一到三句

收束主张，两句：

1. 火箭大，不是因为它装得多，而是因为它要搬运自己的燃料——按土星五号的比例，每 1 克有效载荷，约需 63 克整枚火箭。
2. 看剥离链：2850 → 615 → 144 → 45，最后真正前往月球的只有约 1.6%。

## 交互（只有这一个）

「质量比计算器」：一条对数滑杆 + 五个预设钮 + 一个剥离播放键。

- 读者动什么：拖滑杆选择有效载荷质量，或点预设钮（1 kg、1 t、3 t、15 t、45 t）。默认停在 45 t。
- 看到什么变：五段账目行里的本段质量、剩余质量、条长、下方「质量比约 63 : 1」徽章即时重算；有效载荷占比始终显示约 1.6%。
- 形成什么直觉：有效载荷在整条质量里永远只是一小条；目标越大，底下每一级都被迫成倍变大——每一克都要用一整套火箭去换。
- 点「剥离」播放：一级、二级、三级按顺序淡出，剩余质量数字逐级跳小，最后只剩有效载荷那一条。播放完可再拖滑杆，整条链按新比例重排。

滑杆映射：`payloadT = 10^(-3 + 4.699 * x)`，其中 `x ∈ [0,1]`；`x=0` 时 1 kg，`x=1` 时约 50 t。

## 不许碰

- 不讲喷气推进原理（p38）：页面上只允许「燃料烧掉、火箭前进」这一层日常语言，不出现动量守恒、反作用力、排气速度、比冲。
- 不计算轨道速度与逃逸速度（p35–p36）：这一页只问质量，不问速度。
- 不进任务史与登月剖面（p39–p40）：土星五号只作为质量比例的现实载体，不展开它的成本、型号、历史脉络。
- 不引入以 e 为底的火箭方程或任何对数公式；用「质量比约 63 : 1」的倍数直觉代替。

## 版面提示

- 版式 ledger：左列是数字账目，右列是条带，二者共用同一垂直轴线，行与行对齐。
- 条长一律按质量线性绘制；45 t 有效载荷条在屏幕上约 1.6% 宽，用引线加放大圈把它指出来，但不要改变它的实际长度。
- 燃料段用暖深色，结构段用冷灰，有效载荷用整套讲义的主色；三种颜色全页不变。
- 滑杆与剥离播放键放在账本底部，横跨全宽，作为控制条整体出现。
