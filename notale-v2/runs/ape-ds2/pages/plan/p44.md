# page-44 · 光速巡航杆 · **110 秒**

KICKER: DEEP-SPACE SCALE  
TITLE: 光速巡航：最近的恒星也要 4.2 年

## 知识结构：process

这一页要显式化的关系是：**距离的逐级跨越 → 光程时间的量级跳变**。巡航过程被组织成一条单向不可逆的路径：从地球出发 → 越过月球 → 越过太阳 → 穿过无人区 → 抵达比邻星。路径上的每一个里程碑都对应一个“光速要走多久”的读数，读数的单位从秒跳到分钟、再跳到年。

具体靠什么显式化：一个由“巡航杆”驱动的飞行过程。光点位置 = 当前时间 × 光速，右侧视野随飞行距离自动缩放，让各个里程碑依次被「越过」。读者看到的不是一张静态对比图，而是“正在飞过去”的经过，每个里程碑被越过的那一刻，读数才亮起。

## 表征形式

动态交互。右侧为巡航视野（星场 + 光点 + 里程碑标记），左侧为巡航杆与控制区。这个关系不能靠静态图完成：学习者需要亲身推动杆，感受「镜头从近地尺度一路拉到星际尺度」的时间体感。静态图只能给数字，给不了“飞了很久很久仍然什么都没有”的荒凉感。

## 巡航里程碑

三个里程碑外加一个对比读数。所有光程时间由页面运行时计算，不写死数字。

### 里程碑 1 · 月球

- 数据：月球平均距离 `MOON_DISTANCE_KM`（自身常量区，注释「全套口径」；若 `Lec.K` 已提供同名常量则优先用 `Lec.K`）
- 光程：`MOON_DISTANCE_KM / Lec.K.SPEED_OF_LIGHT` → 约 1.3 秒
- 画面：近地视野，月球从前方快速逼近并被掠过
- 读数：`1.3 光秒`

### 里程碑 2 · 太阳

- 数据：日地平均距离 `AU_KM`（自身常量区，注释「全套口径」；1 AU = 1.496 × 10⁸ km）
- 光程：`AU_KM / Lec.K.SPEED_OF_LIGHT` → 约 499 秒 ≈ 8.3 分钟
- 画面：镜头拉远，太阳出现在侧前方，地球缩为一个亮点，随后被甩在身后
- 读数：`8.3 光分`

### 里程碑 3 · 比邻星

- 数据：比邻星距离 `PROXIMA_CENTAURI_LY`（自身常量区，注释「全套口径」；取 4.2 ly；若 `Lec.K` 已提供则优先用 `Lec.K`）
- 光程：`PROXIMA_CENTAURI_LY * SECONDS_PER_YEAR` → 约 4.2 年
- 画面：太阳系缩小为星尘中的一点，随后是漫长的虚空；最后一颗暗红矮星在视野中央缓缓靠近
- 读数：`4.2 光年`

### 对比读数 · 离开太阳系比离开地球难多少

- 算法：`proxima_seconds / moon_seconds`
  - `moon_seconds = MOON_DISTANCE_KM / Lec.K.SPEED_OF_LIGHT`
  - `proxima_seconds = PROXIMA_CENTAURI_LY * SECONDS_PER_YEAR`
- 单位统一为秒后相除，得到无单位的倍数
- 显示：`约 1 亿倍`（实际值在 10⁸ 量级，由页面实时算出，显示时保留一位有效数字即可）

## 必须点出来的一到三句

1. 即使以光速飞行，到最近的恒星也要 4.2 年——光子在太阳系内用「秒」和「分钟」计量，一旦进入星际空间就要用「年」计量。
2. 地球到月球的光程只有约 1.3 秒，到比邻星却要约 4.2 年，后者是前者的约一亿倍——离开太阳系比离开地球难的不是一点点。

## 交互（只有这一个）

**光速巡航杆。**

- 读者动什么：拖动左侧一根竖直的「巡航杆」（油门杆造型），控制巡航时间 t 从 0 推进到 4.2 年。
- 看到什么变：右侧视野中的光点从地球出发向外飞行；经过月球时月球标记亮起，显示「1.3 光秒」；继续推进，镜头自动拉远，太阳标记亮起，显示「8.3 光分」；再继续，视野急剧拉远，太阳系缩成一个亮点，背景星场出现，光点在一片近乎空无的黑暗中缓慢移动，时间读数切换到「年」；最终抵达比邻星，标记亮起，显示「4.2 光年」。
- 从中该形成什么直觉：距离的每一次量级跨越，都让光速从「瞬间」变成「漫长」；太阳系之外不是另一段旅程，而是完全不同的尺度深渊。

滑杆行程映射到飞行时间时使用对数刻度：近地段的秒级过程占据足够滑杆行程，星际段的年际过程在后半段展开。所有读数仍显示真实数值；滑杆刻度上可标注「秒」、「分」、「年」三个手感区间。

## 不许碰

- 不讲引力、弯曲时空、轨道、逃逸速度、火箭方程、推力、动量守恒——这些分别属于 p35–p38。
- 不提“怎么飞出去”的技术手段（化学燃料、离子推进、太阳帆等），只保留“以光速飞行”这个思想实验本身。
- 不讨论近地轨道、月球轨道或任何轨道速度数值。
- 不扩展到星际旅行工程、系外行星适居性或未来殖民——那些属于 p49。
