# page-48 · 足迹覆盖 · **100 秒**

**kicker**：`FOOTPRINT LAYERS`  
**主标题**：脚印铺满地球

## 知识结构：process

要显式化的关系：人类活动从地理上的局部事件，累积成覆盖大气、地表与海洋的全球层。

这一页靠「足迹叠加层」显式化它。右栏是一张暗色 2D 世界地图，初始只有东非一个小光点——那是 Laetoli 的第一枚脚印，回指 p03。随后三组足迹以「层」为单位依次叠加：地表层印在陆地上，大气层悬浮在陆地上空，海洋层沉入海区并沿洋流漂移。层与层之间靠「过去 → 现在」的时间箭头连接：每叠加一层，足迹密度和覆盖范围都单调上升。前后态是对比的核心：干净的暗色地球 → 被三层足迹半透明覆盖的地球。

具体骨架是一种「前后态 + 累积箭头」的过程结构：前态（只有少量脚印）→ 三组足迹逐层叠加 → 后态（足迹覆盖三种介质）。左栏三层条目的排列顺序就是叠加顺序，也是历史上人类影响扩大的顺序：地表 → 大气 → 海洋。

## 表征形式

静态地图 + 动态交互的复合表征。

右栏是一张 2D 等距圆柱投影世界地图，大陆轮廓线极细、低对比，刻意弱化国界。初始状态只有东非一个微弱亮印。三组足迹层分别用不同颜色和形态的半透明脚印图章粒子表示：

- 地表层：暖橙色脚印粒子，密集铺在农业区、城市带、牧场与采矿区，陆地上密度由改造强度决定；
- 大气层：青白色脚印粒子悬浮于陆地上空，形成一片流动的薄雾，浓度由 CO₂ 排放分布决定；
- 海洋层：蓝绿色脚印粒子沿海流路径与主要渔场分布，带轻微漂移。

粒子密度由该层数值驱动，数值高的区域粒子更密。交互激活某一层时，该层粒子从稀疏到密集地扩散淡入；已激活层保持可见。三层全部叠加后，地图几乎被足迹覆盖，只剩冰盖、沙漠、远洋深部等少数区域保持暗色。

地图是平面 2D，不旋转、不做成球体，保证 p43「从太空看地球」的视觉主体唯一性。

## 三层足迹

左栏自上而下三个条目，按叠加顺序排列，也是人类影响全球的先后顺序。每个条目显示：名称、起始时间戳、一到两个关键数值。

### 第 1 层 · 地表足迹
约 1 万年前（农业与定居）起形成规模。

- 无冰陆地改造比例：`Lec.K.MODIFIED_LAND_FRACTION`（约 0.5，画面上写「约 50% 的无冰陆地已被改造」）
- 人工物体总质量与全球干生物量相当：`Lec.K.ANTHROPOGENIC_MASS_TONNES` ≈ 1.1×10¹² t，`Lec.K.GLOBAL_BIOMASS_TONNES` ≈ 1.0×10¹² t（2020 年前后发生交叉，画面写「约 1.1 太吨 vs 约 1.0 太吨」）

### 第 2 层 · 大气足迹
18 世纪中叶（工业革命）起。

- 大气 CO₂ 浓度：`Lec.K.CO2_PPM_PREINDUSTRIAL` ≈ 280 ppm → `Lec.K.CO2_PPM_CURRENT` ≈ 420 ppm（画面写「约 420 ppm，比工业革命前高约 50%」）
- 全球地表均温较 1850–1900 年基线升高：`Lec.K.GLOBAL_WARMING_DEGC` ≈ 1.2 °C

### 第 3 层 · 海洋足迹
20 世纪中叶起。

- 海洋塑料存量：`Lec.K.OCEAN_PLASTIC_TONNES` ≈ 1.7×10⁸ t；年新增入海量：`Lec.K.ANNUAL_PLASTIC_INPUT_TONNES` ≈ 1.1×10⁷ t/a
- 表层海水 pH 较工业革命前下降：`Lec.K.OCEAN_PH_DROP` ≈ 0.1（画面写「pH 下降约 0.1」）

### 数值口径（全套口径）

以上所有数值均从 `Lec.K` 取，不在页面任何地方写死。若 `Lec.K` 中未提供，这些常量属于本套统一取值，页面写在自身常量区并注释「全套口径」：`Lec.K.MODIFIED_LAND_FRACTION`、`Lec.K.ANTHROPOGENIC_MASS_TONNES`、`Lec.K.GLOBAL_BIOMASS_TONNES`、`Lec.K.CO2_PPM_PREINDUSTRIAL`、`Lec.K.CO2_PPM_CURRENT`、`Lec.K.GLOBAL_WARMING_DEGC`、`Lec.K.OCEAN_PLASTIC_TONNES`、`Lec.K.ANNUAL_PLASTIC_INPUT_TONNES`、`Lec.K.OCEAN_PH_DROP`。数值近似到上面给出的量级即可，页面实际显示时用「约」字。

## 交互（只有这一个）

读者动什么：左栏三个足迹层条目可点击；也可以点一个「依次叠加」按钮，按地表 → 大气 → 海洋的顺序自动播放三层。

看到什么变：点击某一层后，右栏地图上对应介质区域出现该层的脚印粒子群，粒子从稀疏到密集扩散淡入；已激活层保持可见，随后激活的层叠加其上。右栏底部有一条「已叠加 1/3 层 → 2/3 层 → 3/3 层」的状态计数。三层都激活后，地图上的足迹覆盖达到最大密度，只有冰盖、沙漠、远洋深部保持暗色。

形成什么直觉：人类足迹是分层的、可累积的、可用数值度量的；三层加在一起，才构成「覆盖全球」的完整图景。单看任何一层都不足以理解人类已经成为全球尺度的力量。
