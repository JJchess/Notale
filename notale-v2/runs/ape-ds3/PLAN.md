# 《Apeman – Spaceman》 90 分钟互动讲义 · 总规划

## 0. 这套讲义的主线

主张：**一个从树上下来的物种，刚刚开始离开地球。想看清自己站在哪里，得同时握住两把尺子——深时，和光速。**

| 章 | 页 | 这一章要让读者信什么 |
|---|---|---|
| 开场 | 01–02 | 从树上到月面，是同一个物种的故事；这门课把这条线重走一遍。 |
| 一 深时 | 03–12 | 地球 45.4 亿年，人类的一切只占最后一瞬；深时必须换一把尺子才能感受。 |
| 二 演化 | 13–23 | 智人是一棵几乎枯死的树上唯一幸存的一枝；文明只是智人史的最后一截。 |
| 三 逃离 | 24–31 | 离开地球首先要赢过重力；火箭的庞大与轨道之难都是引力井的代价。 |
| 四 光速 | 32–42 | 宇宙的尺子是光；距离把星际旅行从工程问题变成文明尺度的问题。 |
| 五 回望 | 43–50 | 两把尺子叠起来——这个物种的位置，既在深时的最后一秒，也在光速的起点。 |

无交互（只承担开场/推进/过渡/收束）：01 02 03 13 24 32 43 47 50

### 形式与媒体去重

- 真实照片（web-media-getter）只出现在 p30、p34、p44、p47：阿波罗、太阳系天体、地出、暗淡蓝点。这四页的 `必用skill` 已写。
- 生成插画（make-illustration）只出现在 p01、p06、p09、p12、p40、p46：意象背景、纪的生态、哺乳动物支系、夜地球倒计时、0.999c 飞船意象、长线旅程。p06/p09 只做氛围与识别色，不做科教写实。
- 时间轴/滑轨/拨盘类交互分布在 p04、p05、p11、p12、p15、p36、p38、p45、p46——每条轴的实体与单位不同（地球小时段、生命史、换算轮盘、12 月 31 日、谱系百万年、光年、星系直径、双尺、文明长线）；不许两页共用同一组数据刻度。
- 真实算法模拟器分布在 p07（撞击分镜，碎屑按简单物理抛撒）、p21（群体遗传）、p25（引力势场）、p27（弹道积分）、p29（轨道积分）、p33（路程-时间换算）。六个模拟器各跑各的算法，不共用状态。
- 随机只出现在 p21，用 seedrandom 固定种子，保证每次打开同一局面。
- echarts 只出现在 p10、p22、p31、p40，一律 `renderer:'svg'`，字阶按库说明里的地板执行。
- gsap 只出现在 p07、p19、p23、p33、p46，职责分别为：撞击序列、迁徙路线扫描、加速条带、光速绕行、长线扫描。
- 唯一「赢/输」小游戏是 p27；p48 是唯一作答页；p49 是唯一自测页；同一 game-loop 不跨页。
- 天体/距离的数字全部从 `Lec.K` / `Lec.P` 取，页面里不出现写死的距离值。

### 全课不碰（超纲围栏）

- 不引入相对论时间膨胀与双生子佯谬（p40 只到「光速是上限」）。
- 不做燃料化学、不推导齐奥尔科夫斯基方程（p28 只给质量比例）。
- 不讨论外星生命是否存在（p48 只讨论「收到信号要不要回复」，不回答「有没有」）。
- 不涉及具体考古遗址的发掘史与具体化石的命名故事。

## 3. 数字口径

- 地球年龄 45.4 亿年：`EARTH_AGE_YEARS`；p04/p11/p12 的压缩年历换算一律走 `earthTimelinePercent` / `universeTimelinePercent`。
- 全课只出现一套生命史节点：`EARLIEST_LIFE_YEARS`、`DINOSAUR_EXTINCTION_YEARS`、`HOMO_SAPIENS_YEARS`、`AGRICULTURE_START_YEARS`、`INDUSTRIAL_REVOLUTION_YEARS`、`SPACE_AGE_START_CE`——各页只取自己那一段，不许改写口径。
- 光速用 `SPEED_OF_LIGHT_KMPS`；任何「光跑完 X 要多久」都用 `lightTravelTimeSeconds` / `lightTravelTimeMinutes` / `lightTravelTimeHours`。
- 天体距离统一从 `Lec.K` 取：`EARTH_MOON_KM`、`EARTH_SUN_KM`、`NEAREST_STAR_LY`（4.24 光年）、`MILKY_WAY_LY`（10 万光年）、`OBSERVABLE_UNIVERSE_LY`（930 亿光年）。单位换算一律走 `kmToLy` / `lyToKm` / `kmToAU` / `auToKm` 等 `Lec.P`，页面不许自己写换算系数。
- 引力读数统一：`EARTH_GRAVITY_MPS2`、`MOON_GRAVITY_MPS2`、`MARS_GRAVITY_MPS2`；体重用 `weightOnBody`，逃逸用 `EARTH_ESCAPE_VELOCITY_KMPS`。
- 星际旅行时间：p31、p40、p41 可能算同一个数，必须都从 `travelTimeYears` / `speedFromFractionOfLight` 取，三页结果一致。
- 随机：p21 的群体模拟用 `seedrandom('page-21')` 固定种子。
- 所有页面展示的数字都来自 `Lec.K` / `Lec.P`；讲解词里的数字与页面读数必须在允许扰动下恒真，出现不一致即为缺陷。
