# page-06 · 纪的标签盘 · **120 秒**

## 知识结构：classification

这一页要把「地球史被分成若干纪」这件事显式化，并让读者直观地看到**恐龙所处的那一段横跨了 1.6 亿年，远大于智人所在的那一小截**。骨架是：一个按时间顺序排列的纪序列，每一个纪对应一个标签格；恐龙统治的纪被点亮、拉出，显示其持续时间，并与智人存在时长（仅 30 万年）并排对照，形成「一格很长 / 一格极短」的视觉层级。

靠什么显式化：一排按时间顺序排列的标签格，其中恐龙所在的三个纪（三叠纪、侏罗纪、白垩纪）被合并高亮为一个长条；长条右侧紧贴一个极窄的标签代表智人存在时间。长条与窄条的宽度比直接对应 1.6 亿年 ∶ 30 万年 ≈ 500 ∶ 1。标签盘上的刻度轴固定为地球显生宙以来的时间，越靠右越接近现在。

## 表征形式

静态为主，交互为辅。静态部分承担主要认知负载：一排标签格，宽度按真实时长比例排布，恐龙统治段明显占据压倒性宽度。交互部分承担「点选」动作：读者点击任意一个纪的标签，该纪名称放大并显示其起止时间与持续时间；每次点选后，页面上方的一句话读数随之更新。页面中央始终保留「恐龙统治 1.6 亿年」与「智人存在 30 万年」的固定对照条。交互的意义是让读者主动把注意力从一个标签移到另一个标签，形成「每一个纪都很长，但恐龙那一截特别长」的对比直觉，而不是记住某个具体数值。

## 纪的标签盘 · 数据项

### 标签盘上的纪序列

标签盘按时间顺序排列，从老到新，覆盖显生宙的主要纪。每一格显示：纪的名称、起止时间（百万年前）。

| 标签 | 开始时间（百万年前） | 结束时间（百万年前） |
|---|---|---|
| 寒武纪 | 541 | 485 |
| 奥陶纪 | 485 | 443 |
| 志留纪 | 443 | 419 |
| 泥盆纪 | 419 | 359 |
| 石炭纪 | 359 | 299 |
| 二叠纪 | 299 | 252 |
| 三叠纪 | 252 | 201 |
| 侏罗纪 | 201 | 145 |
| 白垩纪 | 145 | 66 |
| 古近纪 | 66 | 23 |
| 新近纪 | 23 | 2.6 |
| 第四纪 | 2.6 | 0 |

以上起止时间来自 `Lec.K` 中的 `GEOLOGICAL_PERIODS` 常量。页面构建时按此数据生成标签，格子宽度由 `geologicalPeriodWidth(startMyr, endMyr)` 计算，比例基于「该纪时长 / 显生宙总时长」；若 `Lec.K` 里没有直接提供 `GEOLOGICAL_PERIODS`，则页面应在 `Lec.K` 中查找等效常量并以注释标明，**不得在页面代码中写死上述表格数值**。

恐龙统治段的起止：`DINOSAUR_APPEARANCE_MYR = 252`（三叠纪开始），`DINOSAUR_EXTINCTION_MYR = 66`（白垩纪结束）。经历 186 百万年，但 252–66 的区间横跨三叠纪、侏罗纪、白垩纪三个纪；其中恐龙作为优势动物群的实际统治跨度采用 1.6 亿年口径，取自 `DINOSAUR_RULE_YEARS`（= 160,000,000 年）。页面标注「恐龙统治约 1.6 亿年」。

智人存在时间：`HOMO_SAPIENS_YEARS` = 300,000 年。换算成百万年：`HOMO_SAPIENS_MYR = 0.3`。宽度计算：`dinosaurRuleWidthRatio = DINOSAUR_RULE_YEARS / EARTH_PHANEROZOIC_YEARS`；`homoSapiensWidthRatio = HOMO_SAPIENS_YEARS / EARTH_PHANEROZOIC_YEARS`。其中 `EARTH_PHANEROZOIC_YEARS` 取显生宙起点距今 541 百万年 = 541,000,000 年。

### 固定对照条

页面中央固定一条横贯的对照带，左端标注「恐龙统治」并显示其时长，右端紧贴一个极窄的标签，标注「智人存在 30 万年」。宽度的渲染方式：

- 恐龙统治段宽：`DINOSAUR_RULE_YEARS` 在整条时间带上的比例
- 智人段宽：`HOMO_SAPIENS_YEARS` 在同一时间带上的比例

对照条上方的读数文案：「恐龙统治地球约 1.6 亿年，是智人存在时间的约 500 倍。」

倍数的精确计算走 `Lec.P` 的除法：`DINOSAUR_RULE_YEARS / HOMO_SAPIENS_YEARS`，页面不写死「500」。

新增交互时的读数更新规则：读者点击任何非恐龙纪的标签，上方读数变为该纪的「名称 + 起止 + 持续时长（百万年）」；当读者点回恐龙段（或初始状态），读数恢复为上述固定文案。

## 必须点出来的一到三句

1. 恐龙统治地球约 1.6 亿年——是智人存在时间的约 500 倍。
2. 把地球史看成一条带子时，属于恐龙的那一段宽得几乎占满视野，而属于人类的那一段窄到几乎看不见。

## 交互

**纪的标签盘**

读者操作：在显生宙纪序列中点击任意一个纪的标签。

看到什么变：
- 被点击的标签放大、亮度提升，显示该纪名称、起止时间（百万年前）和持续时间（百万年）
- 页面顶部的读数文案切换为对应内容；当点击恐龙统治覆盖的三叠纪 / 侏罗纪 / 白垩纪中任一者时，整个恐龙段高亮并显示「恐龙统治约 1.6 亿年」，读数回到固定文案
- 页面中央的固定对照条始终保留，不随点击改变；它是整页不变的基准线

应形成的直觉：无论点哪一个纪，持续时间都是以千万年甚至亿年为单位的；恐龙统治那一整段尤其长，而智人的 30 万年在这根时间尺上是一条几乎看不见的细线。交互的目的是通过「逐个点、逐个感受」建立相对比例感，而不是记忆某个纪的具体年代。

交互用标签点击实现，不需要拖拽或连续滑轨。点击态切换用 `gsap-core` 的快速 color/scale 过渡即可（0.2s），不做翻页或卡片翻转。

## 不许碰

- 不讲灭绝机制（陨石撞击、火山、气候剧变等）——那属于 p07 的撞击分镜台
- 不讲恐龙与哺乳动物的演化关系、哺乳动物在恐龙之后如何辐射——那属于 p08 与 p09
- 不讲具体恐龙物种的形态、习性、分类（如霸王龙、三角龙等）——这一页只处理时间尺度，不做古生物知识展示
- 不讲智人演化史的任何内容——只允许把智人存在时长作为一个数值与恐龙做对比

## 必用skill

`make-illustration` 需要一个恐龙剪影/轮廓的插画作为时间带左端的图示。该插图只做氛围与识别色，不做科教写实。

## 媒体

生成插画一张：恐龙侧影剪影，深色背景上的单色或双色轮廓，放在时间带恐龙统治段的左端或上方，作为「统治」的视觉锚点。插画不包含具体物种特征细节（不追求霸王龙或腕龙的可识别性），只给一个普通的蜥脚类/兽脚类轮廓，用大比例暗示「巨大、长时间统治」。识别色：侏罗纪标签格与恐龙剪影统一使用同一种暖色，使读者一眼把剪影与那一大段纵向关联。插画用途是氛围与直觉提示，不承担知识信息。

剪影插画文件由 `make-illustration` 按此描述生成，嵌入时使用 `<img title="恐龙统治地球约1.6亿年" alt="恐龙剪影">`。出处与许可不上主画面，只进 `<img title>` 或页脚极小字。

## 版面提示

- 主布局为三栏：左栏是恐龙剪影 + 对照条说明，中栏是固定对照条（宽 100%，占据视觉重心），右栏是纪的标签盘（垂直排列，从上到下按时间顺序）
- 固定对照条必须水平贯穿页面的主要内容区，标签盘与它共用同一条时间刻度轴
- 三栏宽度比建议 1 ∶ 2 ∶ 1.2；标签盘可滚动，但初始视口显示最近 6 个纪（白垩纪、侏罗纪、三叠纪在上方，向下延伸到更早的纪），确保恐龙段和智人段同时出现在第一屏
- 移动端降级：标签盘改为水平滑动，对照条纵向堆叠但保持比例宽度，恐龙段与智人段仍并排可见
