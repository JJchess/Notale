# page-10 · 冰期旋钮 · **110 秒**

kicker：深时 · 冰期  
主标题：冷热之间，从未停摆

## 知识结构：process

这一页要显式化的关系是：**智人演化的整个时期，地球不是停在某个固定气候里，而是在冷热之间反复摆动**。为了把“摆动”变成可感知的过程，页面用一条沿时间轴左右展开的温度距平曲线，把多个冰期–间冰期旋回排在同一根轴上；读者通过旋钮沿时间轴移动，能看到自己落在曲线的哪个位置、处在旋回中的哪个阶段。过程由四个阶段构成一个可重复的环：间冰期暖峰 → 变冷期 → 盛冰期冷谷 → 变暖期 → 回到间冰期。曲线本身是这一过程的直观形状，阶段标签把连续波形切成可命名的环节。

## 表征形式

交互 + 动态。主体是一张 ECharts SVG 面积图（`renderer:'svg'`）：横轴为“距今多少年”，纵轴为“全球平均温度距平（°C）”，一条上下起伏的曲线从左到右贯穿整个时间窗。曲线的动态不是自己播放，而是由旋钮驱动：读者转动旋钮时，一个高亮标记沿曲线移动，随之更新当前时间、温度距平和阶段名称。这样读者不是“看一张静止的图”，而是亲手扫过整段时期，形成“这里确实一直在冷热之间来回”的直觉。

## 旋回里的阶段

一个完整的冷热摆动不是“冰期/间冰期”两个状态，而是四个阶段：

1. **间冰期**——暖峰，温度相对高。
2. **变冷期**——曲线向下，从暖峰滑向冷谷。
3. **盛冰期**——冷谷，温度相对低。
4. **变暖期**——曲线向上，从冷谷爬回暖峰。

阶段由 `Lec.P.glacialStageFor(currentPoint, series)` 根据当前位置的温度值和前一段时间的方向自动判定，页面不自己设置温度阈值。阶段标签与颜色也由该函数返回；当前标记落在哪个阶段，左栏就高亮哪个阶段。

### 真实数值

- 时间窗起点：`startYearsAgo = Lec.K.HOMO_SAPIENS_YEARS`（智人演化的整个时期）。
- 时间窗终点：`endYearsAgo = Lec.K.PRESENT_YEARS_AGO`（即 0）。
- 温度序列：`series = Lec.P.glacialTemperatureSeries(startYearsAgo, endYearsAgo, Lec.K.PALEOCLIMATE_RESOLUTION_YEARS)`，按固定间隔输出 `{ yearsAgo, tempAnomalyC }`；`tempAnomalyC` 参考基线为 1950–2000 年全球平均温度。
- 当前读数显示三项：
  - `currentYearsAgo`，用 `Lec.P.formatYearsAgo` 格式化为“距今 X.X 万年”。
  - `currentTempAnomalyC`，用 `Lec.P.formatTemp` 格式化为“−X.X °C”。
  - `currentStage = Lec.P.glacialStageFor(currentPoint, series)`，返回阶段 id 和中文短标签。
- 坐标轴刻度不写死：横轴刻度用 `Lec.P.timeAxisTicks`，纵轴刻度用 `Lec.P.temperatureAxisTicks`，格式分别用 `Lec.P.formatYearsAgo` 与 `Lec.P.formatTemp`。

## 必须点出来的一到三句

- 智人演化的整个时期，地球一直在冷热之间摆动。
- 所谓“冰期”和“间冰期”只是这个连续摆动中的两个片段，不是两个固定的世界。

## 交互（只有这一个）

**冰期旋钮**。读者转动一个圆形旋钮（拖拽或滚轮）来控制时间标记在温度曲线上的位置。旋钮角度从 `-150°` 到 `+150°` 线性映射到时间窗：`currentYearsAgo = round((1 - (angle - minAngle) / (maxAngle - minAngle)) * startYearsAgo)`；逆时针转回更早，顺时针转回今天。转动过程中：

- 曲线上的高亮标记沿时间轴移动；
- 左栏的“距今年数”“温度距平”“阶段名称”随当前位置更新；
- 阶段图例中当前阶段点亮。

读者应从中形成的直觉是：时间是一个可以来回扫过的连续轴，不管停在哪个位置，都能看到自己正处在冷热曲线中的某一段；快速扫过时曲线反复穿越冷暖区，冷暖方向随时可能反转。

## 不许碰

不讨论人类演化的任何内容：智人起源、人科谱系、迁徙路线、工具与火、脑容量、双足行走、尼安德特人等全部留到 p14 起展开。页面只把“智人演化的时期”当作一个已知的时间窗名称来使用，不解释智人是什么、从哪来、怎么变的。
