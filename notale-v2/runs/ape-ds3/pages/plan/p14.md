# page-14 · 一棵几乎枯死的树 · **130 秒**

**kicker**：演化 · 谱系
**主标题**：一棵几乎枯死的树
**副标题**：人科不是阶梯，是一棵不断分叉、几乎全部枯死的树。

## 知识结构：classification

这一页要把「人科」这个分类单元内部的层级关系显式化：科 → 亚科 → 属，并且在每个末端同时挂一个「现存 / 灭绝」的状态。

层级关系用一棵横向树状图承载：根在左，是「人科」；向右展开出两个亚科，再展开出属；每一个分叉点都表示一次「从这一支再分出去」。选择树状图而不是行列表格，是因为学习者需要建立的表征是「亲缘关系像树枝一样不断分叉，而不是一条通向人的梯子」。绿点与灰枝同时编码「现在还活着」与「已经枯死」，是因为本页要建立的第二个表征是「大多数分支在到达今天之前就断了」。两个关系在同一张画面上同时成立，分类层级与枯 / 活状态不分离。

## 表征形式

静态 + 交互。静态成分：树的主干、根节点、图例、主标题与底部计数器；交互成分：点击节点逐层展开 / 收起，悬停叶节点高亮从根到该叶的路径。

视觉上用「枯木」隐喻：存活末端是一枚绿色光点，灭绝分支是一段灰色断枝；断枝的断口朝向右上方，让人一眼看出「这枝没有走到今天」。学习者需要亲自把树干点开，才能体会到分叉不是预先画好的装饰，而是谱系本身的形状。树由 d3 根据层级数据计算绘制，不使用真实照片，也不生成插画。

### 树节点与计数

- 层级常量从 `Lec.K.HOMINIDAE_TREE` 读取；若当前 `Lec.K` 尚无此常量，按本页层级数据注册到该常量后读取。页面不在模板里写死分类名称。
- 状态由每个节点的 `status` 字段给出：`extant`（现存）或 `extinct`（灭绝）。中间节点不带状态。
- 底部计数器「现存 4 属」是对树数据的遍历结果：数出深度为 2 且 `status === 'extant'` 的节点数。页面不得手写数字 4。
- 两个「灰枝丛」是视觉聚合节点，不是分类单元；它们不携带物种名、不携带年代、不携带任何分岔细节。灰枝条数是构图参数（每个灰枝丛 4–6 条断枝），目的是让「枯枝多于活枝」的观感成立，不能把它当作精确物种计数来读。

## 必须点出来的一到三句

1. 人科不是一条通向智人的阶梯，而是一棵不断分叉的树。
2. 这棵树上的枝大多在到达今天之前就断了，智人只是唯一活到最后的那根细枝。
3. 今天的黑猩猩、大猩猩、红毛猩猩不是我们的祖先，而是与我们走散已久、同样活到今天的旁支。

## 交互（只有这一个）

**谱系树展开**。读者动的是「展开」本身：初始画面只有一条光秃的主干，根节点标注「人科」；页面提示「点击，让这棵树继续长」。点击主干，分裂出猩猩亚科与人亚科；点击任一亚科，再分裂出该亚科下的属与灰枝丛。所有带子节点的节点都可再次点击，在展开 / 收起之间切换。

读者看到什么变：每次点击，从父节点处长出新的分支，d3 transition 让新枝从父节点向外生长约 300ms；灰枝丛以灰色断续短线出现，现存属以绿色亮线通向末端；展开过程中，页面右下角的计数器更新为「现存 4 属」（由遍历结果得出）。悬停任一现存叶节点（例如「人属」）时，从根到该叶的整条路径保持饱和，其余分支降为低透明度，移开恢复。点击灰枝丛不会展开，而是弹出一个极小的提示：「化石近亲留到下一页展开」。

读者该形成的直觉：树越点越多，几乎每多一层都会多出几条断掉的路；能走到今天的只有四根绿色细枝。这一交互是层级展开，不是时间推进——时间轴与分岔先后留给 p15 的滑块。

## 不许碰

- 人亚科内部分岔全部留给 p15：不出现任何已灭绝人亚科化石属 / 种的名字（包括但不限于南方古猿、傍人、能人、直立人、尼安德特人、丹尼索瓦人），不画它们彼此之间的亲缘关系，也不显示它们在演化上的相对位置；人亚科下的化石近亲只允许一个聚合灰枝，并标注「p15 展开」。
- 不展开「人属」内部：人属节点是叶子，不显示人属的已灭绝种。
- 不标注任何分化年代或持续时间；本页没有时间轴，也没有沿时间滑动的控件。
- 不把现存四个属排成一条水平链；任何实现方式都不能让读者把黑猩猩 / 大猩猩 / 猩猩读成「人的祖先序列」。
- 不解释灭绝机制；本页只呈现枯 / 活的分布，不回答为什么枯死。
- 树根停在人科；根部可以用一行极小字「灵长目 → 人科」做上下文定位，但不展开任何灵长目其它分支。

## 必用skill

d3-viz（配 d3 库）

## 版面提示

- 用 d3.tree（或 d3.cluster）做横向布局：根在左，末端在右；整棵树适配 canvas-full，全部展开后必须一屏放下，不滚动、不平移。
- 默认只渲染主干；节点展开 / 收起用 d3 transition，不用 gsap。
- 灰枝丛使用自定义节点渲染，不用默认圆点：画成灰色断开短线，末端带不规则断口；绿枝用连续亮线通向末端，使「大多数分支是断的」在整棵树上一眼成立。
- 叶节点标签排两行：第一行中文名，第二行拉丁名 + 状态；状态图标（绿点 = 现存，灰叉 = 灭绝）放在叶子左侧。
- 右下角放计数器：大号「现存 4 属」，下一行小字「其余分支都已经走到尽头」。
- 固定图例在画布一角：绿点 = 现在还活着；灰枝 = 已经灭绝；虚线框 + 锁 = 后面的页面展开。
- 提供「全部展开」「收回主干」两个文本按钮；点击热区不小于 32×32px，支持触屏。

## 存疑

共享部分的概念归属写着 p14 承担「灵长目与人亚科谱系（全树）」；但页表第 14 行的交互与「一句话」只到「人科」。本页按页表行为准，树根设为人科，仅在根部保留「灵长目 → 人科」的定位提示。如果讲义意图是在这一页真正展开整棵灵长目树，p14 的 130 秒和「不许碰」都需要重做，建议另行规划。
