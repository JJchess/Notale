# page-27 · 逃逸速度发射台 · **145 秒**

kicker：`逃离`
主标题：`快到永远掉不回来`

## 知识结构：process

这页要显式化一层关系：**初速度 → 持续减速 → 两种终态**。关键不是记住一个速度阈值，而是看见“会不会掉回来”不是由一瞬间的推力决定，而是由初速度带来的运动状态能否在引力持续减速下保持非零速度。

实现方式：主画布运行一个垂直发射模拟器。玩家以不同初速度发射后，每次发射在“速度-高度”坐标系上留下一条轨迹。速度不足的轨迹会在速度降到 0 后反向（回落）；速度足够的轨迹则持续上升且速度始终大于 0，并趋近一个非零极限。多次发射后，轨迹线自然分成两支，正中就是逃逸边界。这个由读者亲手制造出来的分支，就是 process 的“箭头”。

## 表征形式

动态 + 交互。全屏 canvas（canvas-full）呈现 2D 侧视场景：地面在底部，太空在上方。玩家设定初速度、按下发射，火箭垂直向上运动；模拟按平方反比引力积分，实时的速度与高度以小型仪表显示。前几次的轨迹以半透明曲线叠加保留，形成分支图。用“自己试出来”的方式建立表征，而不是用定义直接告知。

## 发射过程的两类轨迹与临界线

- 速度滑杆给出的初速度 `v0`（km/s），单位统一走 `Lec.P`。
- 实时速度 `v(t)`：模拟器积分得到，显示为“当前速度”，单位 km/s。
- 实时高度 `h(t)`：离地高度，单位 km。
- 逃逸速度基准 `v_esc = Lec.K.EARTH_ESCAPE_VELOCITY_KMPS`。
- 滑杆范围：`0` 到 `maxSliderSpeed`，其中 `maxSliderSpeed = Lec.P.sliderBound(v_esc)`；若该辅助函数不存在，则用 `v_esc * 1.4` 当场算出。
- 速度-高度轨迹：每发射一次画一条曲线。失败的曲线用暖色，成功的用冷色；图例放在画布角落。

### 公式与常数

- 地表重力加速度：`Lec.K.EARTH_GRAVITY_MPS2`。
- 等效行星半径（供平方反比模拟用）：`R_eff = (v_esc^2) / (2 * g0)`，单位换算走 `Lec.P`。若 `Lec.K` 已有 `EARTH_RADIUS_KM`，则优先使用该常量。
- 任一高度处的重力加速度：`g(h) = g0 * (R_eff / (R_eff + h))^2`，方向始终指向地表。
- 发射后不再施加推力；物体只受引力作用。当 `h <= 0` 且速度向下时，视为落回地面。
- 当物体持续上升且速度不再小于某个正误差阈值，或当 `h` 超过 `Lec.P.farEnoughAltitude(v_esc)` 时，判定为逃逸成功。

（真实数值一律以 `Lec.K` / `Lec.P` 为准，页面内不写死数字。）

## 必须点出来的一到三句

- 逃逸速度不是“快”，是“快到永远掉不回来”。
- 速度不够，引力会把它一点一点停下来，然后拽回来；速度够了，引力只能让它变慢，却永远留不住它。
- 地球这道门槛，就是 `Lec.K.EARTH_ESCAPE_VELOCITY_KMPS` 显示的那个数。

## 交互（只有这一个）

发射小游戏。

读者操作：拖动速度滑杆设置初速度，按下“发射”。火箭从地面垂直上升，实时速度与高度可见。如果初速度低于逃逸速度：火箭上升过程中速度逐渐减小到 0，然后反向加速下落，最后撞击地面，标记为“掉回来了”；如果初速度达到或超过逃逸速度：火箭持续远离，速度下降到某个正值后不再下降，标记为“逃逸成功——它永远不会回来”。成功一次后，滑杆上出现一条临界线，标出逃逸速度位置。

重复发射时，每次的轨迹线叠加在同一个速度-高度坐标里，让玩家看到“速度不够的轨迹都弯回来，速度够的轨迹都往外走”。画面提供“重来”按钮，可清空轨迹和结果，再试一轮。

胜负条件：成功逃逸为赢，落回地表为输。核心动作只有一个：设定初速度并发射。通过反复试错，玩家应形成直觉：“掉不掉得回来”取决于初速度是否高到让引力无法在有限时间内把速度减到零。

- 不切换到月球、火星等其他天体；本页只在地球表面发射。
- 不涉及发动机推力；发射后不再加速，只靠初速度滑行。
- 不引入相对论、光速上限（那是第四、五章的事）。
