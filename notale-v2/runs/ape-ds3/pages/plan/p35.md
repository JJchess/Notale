# page-35 · 太阳系巡游 · **130 秒**

kicker：光速 · 太阳系尺度

## 知识结构：process

这一页要把“光从太阳出发，按光行时依次到达太阳系各行星”这一层关系显式化。具体靠一条从左到右的光行时轴：横轴不是公里，而是“光行时”（0 → 约 4.2 小时）；太阳锚定在左端 0 点，每一颗行星按其真实光行时落在轴上。读者拖动时间滑块，光脉冲沿轴右移，经过哪颗行星，哪颗就发光并显示自己的光行时。方向是单向的：太阳 → 水星 → 金星 → 地球 → 火星 → 木星 → 土星 → 天王星 → 海王星。这样“距离远 = 光走得久”被直接操作了一遍。

## 表征形式

交互 + 静态混排。主体是一个 canvas-full 的 konva 场景：深空深色背景，一条贯穿画布的光行时轴，八颗行星停靠点，一个可拖拽的光脉冲滑块。行星用圆形标记，光脉冲用一条竖直光带或光球表示。滑块位置映射到时间，光脉冲的 x 坐标 = `time / totalTime * axisWidth`。时间读数在轴上方实时显示“光已走 X 小时 X 分”。行星标签默认只显示行星名和 AU 距离；当光脉冲到达或经过时，该行星上方浮出光行时卡片。

## 八个停靠点

以下表格是核对用的真实数值（轨道半长轴近似值）。页面实现时**不得写死任何数字**，一律从 `Lec.K` / `Lec.P` 取：行星轨道距离从 `Lec.K` 对应的行星轨道常量取（如 `MERCURY_SUN_AU`、`VENUS_SUN_AU` 等；若 `Lec.K` 给出的是公里值，则直接使用），公里值经 `auToKm` / `kmToAU` 换算统一口径；光行时一律经 `lightTravelTimeMinutes` / `lightTravelTimeHours` 计算。光行时轴的总时长取海王星的光行时，由最终光源自动得出。

| 停靠点 | 轨道半长轴 (AU) | 光行时（约） | 在轴上的位置 |
|---|---|---|---|
| 太阳 | 0 | 0 | 左端起点 |
| 水星 | 0.387 | 3.2 分钟 | `lightTravelTimeMinutes(auToKm(MERCURY_SUN_AU)) / totalTime` |
| 金星 | 0.723 | 6.0 分钟 | `lightTravelTimeMinutes(auToKm(VENUS_SUN_AU)) / totalTime` |
| 地球 | 1 | 8.3 分钟 | `lightTravelTimeMinutes(auToKm(EARTH_SUN_AU)) / totalTime` |
| 火星 | 1.524 | 12.7 分钟 | `lightTravelTimeMinutes(auToKm(MARS_SUN_AU)) / totalTime` |
| 木星 | 5.203 | 43.3 分钟 | `lightTravelTimeMinutes(auToKm(JUPITER_SUN_AU)) / totalTime` |
| 土星 | 9.537 | 79.3 分钟 | `lightTravelTimeMinutes(auToKm(SATURN_SUN_AU)) / totalTime` |
| 天王星 | 19.191 | 159.4 分钟 | `lightTravelTimeMinutes(auToKm(URANUS_SUN_AU)) / totalTime` |
| 海王星 | 30.07 | 249.8 分钟 | 右端终点，`totalTime` |

说明：轴上的 x 位置不是用 AU 线性映射，而是用光行时映射。这样每一站之间的间隔直接反映“光要多走多久”，避免内侧行星在视觉上挤成一团。地球的 8.3 分钟和海王星的 4.2 小时是页面必须露出的两个读数。

## 必须点出来的一到三句

- 光从太阳到地球要 8 分钟，到海王星要 4 小时——太阳系大到光也要走这么久。
- 我们所有的探测器，到今天都还在这个“后院”里。

## 交互（只有这一个）

**太阳系巡游**：读者在画布底部的滑轨上拖动一个光脉冲标记，标记沿光行时轴从 0 移向海王星。随着标记移动：

- 标记经过的路径上留下一条淡淡的光迹；
- 当标记逼近某颗行星的 x 位置时，该行星高亮，并在行星上方浮现本页唯一的新读数——“光到达这里用了 X 分/小时”；
- 轴顶部的时间读数持续变化，格式为“X 小时 X 分”；
- 当标记被拖到最右端（海王星），时间读数稳定在约 4 小时 10 分，同时画面末端出现一句文字：“全部探测器都还在这个后院”，并保持到本页结束。

读者从拖拽中应形成的直觉：行星越远，光行时越长；太阳系不是一瞬能看遍的，单是在太阳系内部，光也已经有可感的“通信延迟”。教师可以拖动滑块逐站经过，也可以直接跳到“地球”和“海王星”对比两端读数。

## 不许碰

- **不讲最近恒星（p36）**：不出现比邻星、4.24 光年、任何太阳系以外的天体；不做“与恒星相比”的比较。
- 不引入光速数值本身（p33 已展开）；本页只用光速的推论“行时”。
- 不讨论探测器的具体名称、发射年份、速度或距离数据；只保留“后院”的断言。
- 不涉及轨道力学、引力加速、逃逸速度等（p25–p29 的事）。
- 不使用任何写死的距离值；所有数值从 `Lec.K` / `Lec.P` 取。
