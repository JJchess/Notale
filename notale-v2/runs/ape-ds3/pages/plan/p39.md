# page-39 · 十倍之外 · **130 秒**

kicker：`COSMIC SCALE`

## 知识结构：enumeration

这一页把“可观测宇宙的巨大”显式化为六个并列的栈层，而不是一条连续的距离轴。每一层都是对上一层视野的一次十倍放大；上一层看到的所有内容，在下一层里收缩成中心的一个小点。并列关系靠画布左侧一条竖直栈列表（六层名称+跨度，当前层高亮）显式化，嵌套关系靠每次缩放时“旧点云向中心收拢、新点云向外浮现”的动画显式化。

## 表征形式

动态+交互。全屏 canvas 是主体：当前层显示一批代表星系/星系团的光点分布；每进入下一层，上一层的点云缩成中心一个小亮斑，新的更大尺度点云从中心向外展开。读者需要形成的心理表征是：宇宙尺度不是线性排列的数字，而是每乘一次十，上一层的全部疆域就小到可以被忽略。

## 并列的栈层

六层，顺序固定。所有距离值从 `Lec` 取，页面不写死任何光年数字；中间层级的跨度由 `Lec.K.ANDROMEDA_DISTANCE_LY` 乘以 10 的幂当场计算。

- 第 0 层：本星系群。跨度 = `Lec.K.ANDROMEDA_DISTANCE_LY`（约 2.5×10⁶ 光年，即 p38 那个“最近的巨大星系”的尺度）。画面上：中心一团亮光，周围几个离散亮点。
- 第 1 层：星系团集合。跨度 = `Lec.K.ANDROMEDA_DISTANCE_LY × 10¹`。画面上：第 0 层整体缩成中心一个点，周围出现几十个光点。
- 第 2 层：超星系团。跨度 = `Lec.K.ANDROMEDA_DISTANCE_LY × 10²`。画面上：点群开始聚成几个明显的团块。
- 第 3 层：大尺度纤维。跨度 = `Lec.K.ANDROMEDA_DISTANCE_LY × 10³`。画面上：团块连成线状、串状。
- 第 4 层：宇宙网。跨度 = `Lec.K.ANDROMEDA_DISTANCE_LY × 10⁴`。画面上：纤维与空洞的网状结构弥散到整个视野。
- 第 5 层：可观测宇宙。跨度 = `Lec.K.OBSERVABLE_UNIVERSE_LY`（约 9.3×10¹⁰ 光年；到顶，不再乘 10）。画面上：整个视野充满均匀光雾，星系总数标注为 `Lec.K.OBSERVABLE_UNIVERSE_GALAXIES`（约 2×10¹²，显示为“约 2 万亿个星系”；若常量表未收录，按此值在 `Lec.K` 补齐）。

所有跨度的单位统一为光年；如需换算成公里或 AU，一律走 `Lec.P.lyToKm` / `Lec.P.lyToAU`，页面不自行写换算系数。中间层级的星系数量不做精确声明，只用点云密度变化暗示数量级。

## 必须点出来的一到三句

1. 从 250 万光年到可观测宇宙的边界，要连续放大好几个十倍。
2. 可观测宇宙直径约 930 亿光年，里面大约有 2 万亿个星系。
3. 每一层十倍，都让上一层的整个视野变成一个小点。

## 交互（只有这一个）

十倍缩放栈。初始在第 0 层。读者按下“+10×”按钮（或点击画布右缘、滚动）时，当前层所有光点以约 1 秒的动画向中心收缩，同时下一层的新光点从中心向外浮现；视野跨度标注、层级名和左侧栈列表的高亮同步切换。按“−10×”可回退。到第 5 层后，“+10×”按钮变成不可用的“到顶”态，但读者可以回退重看。通过这个操作，读者应形成直觉：每次放大十倍，之前整个可见范围都会缩成一个点；这个操作在宇宙尺度上能重复很多次，最后 2 万亿个星系只是填满整个视野的雾。

## 不许碰

不解释可观测宇宙为什么是 930 亿光年。不引入光速有限、视界、宇宙膨胀、宇宙年龄；不讨论超光速旅行或光速上限的推论（那是 p40）。这一页只呈现“可观测宇宙有多大”，不给原因。

## 必用skill

无——这一页不需要列出的任何技法文档；点云、缩放过渡和栈列表用 Canvas 2D、CSS transition 与少量原生 JavaScript 即可，不引入外部库。

## 版面提示

全屏画布为底；左侧固定一条竖向栈列表（六层名称+跨度），当前层高亮；右下角放置“+10× / −10×”按钮，到顶时主按钮变为禁用态；画布中心留出点云动画区，不被控件遮住。
