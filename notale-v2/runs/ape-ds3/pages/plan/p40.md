# page-40 · 光速限速牌 · **130 秒**

## 知识结构：process

把「旋钮给的倍率 → 实际速度 → 旅行时间 → 光速地板」这条链显式化。

箭头关系是：

- 旋钮给出 `f`（光速的百分数）
- `speedFromFractionOfLight(f)` 把 `f` 变成真实速度
- 固定距离 `NEAREST_STAR_LY` 除以速度，得到单程旅行年数
- 当 `f → 1`，旅行年数贴着 `D / c` 的下限，但永远到不了更低

这条链画成一张曲线图：横轴是速度倍率，纵轴是到比邻星的旅行年数。曲线是 `t(f) = D / (f·c)`，下方还有一条水平的渐近线 `y = D/c`，用来表示「光速地板」。

## 表征形式

交互 + 动态，版式 `split-lr`。

- 左栏：飞船速度旋钮，旁边是一艘正在星空中飞行的飞船插画；旋钮越往右，背景星迹拉得越长、动得越快。
- 右栏：`echarts` 画出的速度—时间曲线，旋钮值对应曲线上的一个当前点，拖动旋钮时这个点沿曲线滑动。

学习者应该从画面中获得的表征是：**速度是输入，时间是被决定的结果；不管旋钮怎么拧，时间总有一条拧不穿的地板。**

## 速度-时间曲线上的三个量

| 量 | 取值 / 来源 |
|---|---|
| 目标距离 `D` | `NEAREST_STAR_LY`（`Lec.K`，4.24 光年） |
| 光速 `c` | `SPEED_OF_LIGHT_KMPS`（`Lec.K`） |
| 旋钮读数 `f` | 0.10 – 0.999，无量纲 |
| 实际速度 `v` | `speedFromFractionOfLight(f)`，单位 km/s，`Lec.P` |
| 单程旅行时间 `t` | `travelTimeYears(D, f)`，单位 年，`Lec.P` |

### 真实数值（供校验，页面由 `Lec` 当场计算，不写死）

| `f` | `travelTimeYears(NEAREST_STAR_LY, f)` |
|---|---|
| 0.100 | ≈ 42.4 年 |
| 0.900 | ≈ 4.71 年 |
| 0.990 | ≈ 4.28 年 |
| 0.999 | ≈ 4.24 年 |

所有轴刻度、标签、读数和曲线上的点都由上述函数生成，页面内不出现硬编码距离值。

## 必须点出来的一到三句

- 速度再接近光速，也不会把光行时变成零：到最近的恒星，99.9% 光速下也要约 4.24 年。
- 把目标放到几十光年外，这个下限就是几十年——而且这是光速给的地板，与飞船性能无关。
- 光速是宇宙的限速牌：星际问题的第一性不是「我们还不够快」，而是「宇宙的尺子本身有上限」。

## 交互（只有这一个）

**飞船速度旋钮。**

读者旋转旋钮，`f` 从 0.10c 连续变化到 0.999c。随之变化的有：

- 左栏速度读数：显示 `f` 的百分数和 `speedFromFractionOfLight(f)` 的 km/s 值；
- 右栏曲线上的当前点：沿 `travelTimeYears(D, f)` 曲线移动；
- 飞船插画背景：星迹随速度增大而拉长、加速，形成「越来越逼近光速」的动态感受。

要形成的直觉：旋钮一开始向右拧，时间掉得很快；越靠近 0.999c，再拧同样幅度，省下的时间越少——因为曲线已经贴到 `D/c = 4.24 年` 的水平渐近线上。**光速不是一道可以超的限速牌，而是时间本身的底线。**

## 不许碰

- 不讲「看得远=看得早」：不出现望远镜、红移、光行时回望；那是 p42 的事。
- 不引入相对论时间膨胀与双生子佯谬：这一页只显示地球参考系下的旅行时间，不讲船员时间、不讲年龄差。
- 不做推进可行性讨论：不出现燃料、比冲、离子引擎、核聚变；旋钮只表示「假设能达到这个速度」。
- 不展开 p41 的任务简报：化学火箭到比邻星要 6 万年、文明尺度问题，留到 p41。
- 页面数字一律从 `Lec.K` / `Lec.P` 取，不写死距离和换算系数。

## 存疑

表里硬字段「即使 99.9% 光速，星际旅行也要几十年起步」与 `NEAREST_STAR_LY = 4.24` 叠加后，`travelTimeYears(4.24, 0.999) ≈ 4.24` 年，不是几十年。本页按表内字段执行，把「几十年」理解为「几十光年外目标的下限」；若原意是最近的恒星，建议把这句话改成「几年起步」，或把目标改成几十光年外的恒星系并补一个 `Lec.K` 常量。
