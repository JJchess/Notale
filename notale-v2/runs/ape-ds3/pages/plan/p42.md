# page-42 · 光行时相册 · **115 秒**

Kicker：第四章 · 光速

## 知识结构：process

这一页要显式化的因果链是：**天体越远 → 光离开它越早 → 光到达你越晚 → 你看到的影像越旧。**

实现方式是一条固定的四段链路，右侧相册条目为链路上的样本。三个相册条目共用这条链路，只有中间“光在空间中飞行”的长度与耗时不同；链路末端的“成像”文字随之改变。箭头连接的是“距离”和“时间”之间的因果关系，而不是一个连续运动过程。

## 表征形式

静态框架 + 点击切换的交互，采用 `split-lr` 左右分栏：

- 左栏：固定的四段链路图，用箭头串联，只变化中段标签与末端结果文字。
- 右栏：三个可点击的相册条目，每个条目用极简 CSS 图形（月牙、圆日、星点）表示，不用真实照片、不用生成插画。

不做连续动画：本页的核心不是“光在飞”，而是“每一张影像都带着一个出发时间戳”，静态翻相册比动画更贴近这个动作。

## 三个天体样本与一条链路

### 链路四段

1. **发出**：天体在某时刻发出光。
2. **飞行**：光以有限速度穿过天体到观察者之间的距离；耗时由光行时决定。
3. **抵达**：光落入眼睛或望远镜。
4. **成像**：视觉或感光元件记录的是光出发时刻的天体，不是“现在”的天体。

三个样本改变的是第 2 段：距离不同 → 飞行耗时不同 → 第 4 段显示出的“过去时刻”不同。

### 天体样本（按距离从近到远）

- **月球**
  - 距离：`EARTH_MOON_KM`，页面显示由该常量格式化，约 38 万 km。
  - 光行时：`Lec.P.lightTravelTimeSeconds(EARTH_MOON_KM)`，显示约 1.3 秒。
  - 末端文字：“你看到的月亮，是 1.3 秒前的月亮。”

- **太阳**
  - 距离：`EARTH_SUN_KM`，页面显示由该常量格式化，约 1.5 亿 km。
  - 光行时：`Lec.P.lightTravelTimeMinutes(EARTH_SUN_KM)`，显示约 8.3 分钟。
  - 末端文字：“你看到的太阳，是 8.3 分钟前的太阳。”

- **比邻星**
  - 距离：`NEAREST_STAR_LY`（4.24 光年），页面直接显示该常量。
  - 光行时：1 光年即光走 1 年，因此光行时年数直接取 `NEAREST_STAR_LY`，显示约 4.24 年。
  - 末端文字：“你看到的比邻星，是 4.24 年前的比邻星。”

所有数值必须从 `Lec.K` / `Lec.P` 取，页面上不出现写死的距离值或时间值；格式化展示由页面按常量的数值完成。

## 必须点出来的一到三句

1. 你看到的每一个天体，都是光把它“当时”的样子送到的。
2. 距离越远，那束光出发得越早，所以你是在看越早的过去。
3. 望远镜不是看现在的工具，而是一台时间机器。

## 交互（只有这一个）

**光行时相册。**

读者在右栏点击一个相册条目：月球、太阳或比邻星。

点击后，左栏链路的中段立刻更新为该条目的距离与光行时；链路末端的“成像”文字变成“你看到的是它 X 之前的样子”；页面上的示意小图与时间戳同步切换。

通过来回点击三个条目，读者应该形成的直觉是：**看这个动作本身不需要花时间，但光从天体到眼睛要走一段路；这条路越长，你翻开的相册页就越早。**

本交互只做点击切换，不设滑杆、不做连续播放、不做“现在 vs 过去”的动画叠化。

## 不许碰

不进入 p45 的双尺度叠加收束：页面里不出现“两把尺子”、不把深时与光速并置、不总结“这个物种站在哪里”。

这一页只讲“看 = 回望过去”，不延伸到人类在深时中的位置，也不引入 p45 要承担的位置判断。

不引入 `Lec.K` 之外的新天体距离；不自行写木星、仙女座等距离；页面不写死任何数字。

不使用真实照片（`web-media-getter`）、不使用生成插画（`make-illustration`），避免与全套媒体分配冲突。
