# page-45 · 双尺定位 · **145 秒**

## 知识结构：generalization

这一页要把「这个物种站在哪里」显式化为两个极端：时间坐标上，人类挤在深时尺的最后一瞬；空间坐标上，人类困在光速尺的原点附近。页面用两条横向对齐的尺子并置——上尺为深时尺（0%＝地球形成 → 100%＝今天），下尺为光速尺（0＝地球 → 100%＝最近的恒星）——并通过同一个「事件放置」动作，把关键事件放到各自尺子的正确比例位置。学习者会看到：智人事件在深时尺上几乎贴到右缘，而比邻星在光速尺上远在右缘、人类足迹只能贴在左缘。两条尺子形成「末端 vs 开端」的镜像关系，这就是要显式化的通用结构：同一个物种，用两把不同的尺子量，都会落在边缘。

## 表征形式

交互 + 静态。两把尺子始终横贯页面，作为被对照的固定舞台；互动发生在中央的事件台上。读者从事件台拖出事件卡，放到对应尺子上，松手后卡片自动滑移到正确比例位置并落下一个数值标注。整个页面不靠大段文字，而是靠上下两条尺上「事件扎堆的位置」形成心理表征：上尺的事件堆在末端，下尺的事件堆在开端。

## 两把尺子上的事件与位置

两把尺子都是线性比例，位置全部由 `Lec` 当场计算，页面不写死任何数字。

- 深时尺：左端＝地球形成（0%），右端＝今天（100%）。任何距今年份 `yearsAgo` 映射到位置一律用 `earthTimelinePercent(yearsAgo)`。
  - 最早生命：`EARLIEST_LIFE_YEARS` → `earthTimelinePercent(EARLIEST_LIFE_YEARS)`，约 23% 处。
  - 恐龙灭绝：`DINOSAUR_EXTINCTION_YEARS` → `earthTimelinePercent(DINOSAUR_EXTINCTION_YEARS)`，约 98.5% 处。
  - 智人出现：`HOMO_SAPIENS_YEARS` → `earthTimelinePercent(HOMO_SAPIENS_YEARS)`，约 99.99% 处，视觉上几乎贴到右端。
  - 右端固定一个不可拖动的「今天」标记，作为此刻的位置。
- 光速尺：左端＝地球（0），右端＝最近的恒星，距离取 `NEAREST_STAR_LY`。任何距离 `ly` 映射到位置的比例 = `ly / NEAREST_STAR_LY`。
  - 月球：`kmToLy(EARTH_MOON_KM)` → 位置约 1.5e-8?（实际值由 `kmToLy(EARTH_MOON_KM) / NEAREST_STAR_LY` 计算），标签显示 `lightTravelTimeSeconds(EARTH_MOON_KM)` 秒。
  - 太阳：`kmToLy(EARTH_SUN_KM)` → 位置约 4e-6（实际值由 `kmToLy(EARTH_SUN_KM) / NEAREST_STAR_LY` 计算），标签显示 `lightTravelTimeMinutes(EARTH_SUN_KM)` 分钟。
  - 比邻星：`NEAREST_STAR_LY` → 位置 1.0，标签显示 `NEAREST_STAR_LY` 光年。
  - 左端固定一个不可拖动的「人类足迹」标记，标注「人类至今的活动范围」，不显示数值；它贴在原点，与右端比邻星形成距离上的悬殊。
  - 月球与太阳在视觉上都会紧贴左端，两枚标记允许做很小的上下错位让两者都能被看见，但水平坐标必须按真实比例计算，不改变相对顺序。

事件台分两区：深时区三张卡（最早生命、恐龙灭绝、智人出现），光速区三张卡（月球、太阳、比邻星）。卡面只写事件名，数值在放置后显示在尺子标注上。

## 必须点出来的一到三句

- 人类在深时尺上占的是最后一秒；在光速尺上占的是连第一厘米都不到的地方。
- 两把尺子叠起来，这个物种的位置不是中心，而是两个极端——时间上刚出现，空间上还没走出去。
- 位置，就是要看你用什么尺子量。

## 交互（只有这一个）

双尺事件放置器。读者从事件台拖出任意一张事件卡，放到对应尺子上（不需要对准精确位置），松手后卡片以约 300ms 的缓动动画飞向由上述公式算出的正确位置，并在卡下弹出细刻度线和数值标签。已放置的卡片可以再次拖动重访。六张卡全部放置后，两把尺子的对比自动完成：深时尺的事件堆在右端，光速尺的月球与太阳堆在左端、比邻星在右端。此时页面在两条尺子之间浮出收束台词「最后一秒 vs 第一寸」。只放置部分卡片也允许，页面不需要「全部完成」才继续。
