# 页面构建契约 CONTRACT.md

> 适用对象：独立构建单页的 agent。  
> 读者背景：大学一年级通识课学生，文理兼有，不假定微积分或生物学基础。  
> 使用场景：课堂授课教师带领讲解 + 课后学生独自复习。  
> 语言分寸：用词平实，必要的术语要在首次出现时用一句话解释；说明句控制在 30 字以内；提示语用鼓励、亲切的口吻（如“试试看”“你会看到”），避免命令式。

---

## 1. 你的工作范围

你只负责**一个文件**：`page-XX.html`（XX 是你的页号）。  
- 绝不读取、修改、参考其他 `page-*.html`。  
- 所有共享资源（CSS、JS、库）已经放在 `assets/` 下，你只需引用，不需复制或修改。  
- 交付时只交这一个 HTML 文件，不写文档、不写测试、不写总结。

---

## 2. HTML 骨架 —— 必须照抄，只能改三处

每页的骨架已经由 harness 建好，你的 HTML 文件必须严格使用以下模板，**只替换**页号、标题和正文内容。

```html
<!doctype html>
<html lang="zh">
<head>
  <meta charset="utf-8">
  <link rel="stylesheet" href="assets/base.css">
  <link rel="stylesheet" href="assets/theme.css">
</head>
<body data-page="NN" data-total="TT">
  <div id="stage"></div>
  <script src="assets/base.js"></script>
  <script src="assets/lec.js"></script>
</body>
</html>
```

- `data-page="NN"`：替换为你的页号（两位数，如 `"07"`）。
- `data-total="TT"`：替换为总页数（如 `"40"`）。
- **`<div id="stage"></div>` 内部**：你只往这里添加内容，不要动其他任何元素。
- 页眉、页脚、页码由 `Lec.mount()` 自动生成，你**绝对不能**自己再写一套，也不能修改它们的类名。
- 所有样式（颜色、字体、间距）从 `theme.css` 取，**不要自创一套**。

---

## 3. 版面预算（硬上限，超了必须拆页，严禁缩字号）

- **正文总字数** ≤ 280 字（含段落文字、列表项正文，不含标签、刻度、图注）。
- **控件数量**（按钮、滑块、输入框等可交互元素）≤ 6 个。
- **文本元素总数**（DOM 中的文本节点，包含正文、标签、刻度、图例、读数等）≤ 80 个。
  - 注意：刻度、图例、标签通常占 80% 以上，单纯缩减正文用处不大，要减少重复元素、合并读数、利用库的自动抽稀。
- **超限处理**：如果任何一个数字超标，必须拆分页面，**绝不允许通过缩小字号、压缩间距来硬塞**。

---

## 4. 字号与行高的硬地板

- 纯数字刻度：≥ 12px
- 控件标签、图例、非成句的说明文字：≥ 14px
- 正文（成句的文字）：≥ 16px
- 行高：≥ 1.35

**为什么这么定？**  
画布尺寸 1600×900，在常见的 1366×768 屏幕上，浏览器全屏时缩放系数约为 0.853（= 1366/1600）。此时 16px 的字实际显示约 13.6px，已经接近阅读舒适度下限；12px 的字实际显示 10.2px，勉强可辨。低于这些值，学生将无法看清内容。

**你必须用 `theme.css` 中定义的字号 token**：  
- `--fs-h1` (34px) 全页主标题  
- `--fs-h2` (22px) 区块小标题  
- `--fs-lead` (19px) 导语/强调正文  
- `--fs-body` (18px) 默认正文  
- `--fs-sec` (16px) 次级说明、表格正文、图注正文  
- `--fs-label` (15px) 控件标签、图例、操作提示  
- `--fs-tick` (13px) 纯数字刻度  

不要自己写 `font-size`，用这些 token。如果内容需要更小，请重新设计，而不是私自调小。

## 5. 数字与文本 —— 不许写死，一律从 `Lec` 取

- 所有页面上的标题、导语、正文文本，通过 `Lec.mount({ index, kicker, title, take })` 注入，你不能在 HTML 里硬编码标题或正文。
- 任何涉及数字的展示（如统计数据、阈值、参数）必须从 `Lec` 提供的数据中读取，**绝不能写死在页面里**，否则课程内容更新时页面会变成错误信息。

## 6. 底盘机制（CHASSIS.md 的转述，必须遵守）

以下内容从 `assets/CHASSIS.md` 原样转达，不可改写。

### 6.1 画布与缩放
- 页面内容放在 `#stage` 内，`base.css` 和 `base.js` 联合将 `#stage` 缩放以适配窗口。**你不需要写任何缩放代码**。
- 逻辑尺寸：`Deck.W` = 1600，`Deck.H` = 900。
- 缩放比 `Deck.s` 会自动写入 CSS 变量 `--s`，你可以用 `calc(var(--s) * 某个px值)` 做响应式调整，但**不要自己算缩放**。

### 6.2 Canvas 必须走 Deck 的适配
- 所有 `<canvas>` 元素适应高分屏和缩放，**必须使用**：
  - `Deck.fit(canvas)` 返回 2D 上下文，已设置好 `setTransform`。
  - `Deck.autofit(canvas, drawFn)` 自动处理首次绘制和缩放变化时的重绘。
- **禁止**自己写 `devicePixelRatio` 换算，**禁止**自己操作 canvas 的 `width`/`height`/`style`。

### 6.3 指针坐标换算
- 因为有 `transform: scale()`，`event.offsetX/Y` 是错的，**必须用 `Deck.pt(element, event)`** 获取相对于画布的逻辑坐标。
- 该方法兼容触摸事件，且内部已处理画布与 CSS 尺寸的比值。
- **禁止**自己用 `getBoundingClientRect` 计算。

### 6.4 动画循环
- 动画循环**必须用 `Deck.loop(fn, options)`**，它会：
  - 在系统要求减少动态（reduced-motion）时只执行一帧，而不跑循环。
  - 标签页隐藏时自动暂停，回来时不会跳帧。
- 如果你需要动画在 reduced-motion 下停在某个特定时刻，使用 `options.still` 指定时间（秒）。
- **禁止**自己调用 `requestAnimationFrame` 写循环。

### 6.5 从 CSS 取色
- Canvas 里不能写 `var()`，要用 `Deck.rgb(name)` 或 `Deck.rgba(name, alpha)` 获取颜色值。
- 例如：`Deck.rgba('--text', 0.8)` 会返回 `'rgba(230,230,230,0.8)'`。
- **禁止**自己硬编码颜色，或从样式表里解析。

### 6.6 布局铁律
- **禁止**在 `#stage` 内使用 `position: fixed`。缩放容器中 `fixed` 参照视口，会脱离画布，造成重叠。
- 默认使用 **flex 布局**，不要无脑用 grid。只有真正需要二维对齐（如矩阵、维度表）时再用 grid。
- 需要靠计算坐标才能对齐的元素，说明结构错了：**改结构，不要算坐标**。拖拽用 `transform: translate` 偏移，不要改 `left/top`；刻度与滑块对不齐，拆成上下两个区块，不要用绝对定位去凑。

### 6.7 不要覆盖底盘或主题的类
- 绝对不要用 JavaScript 去 `classList.remove` 掉 `base.css` 或 `theme.css` 提供的类（如 `lec-header`、`min0`、`cv-fill` 等），它们负责页面结构（如避开页眉页脚），删除会导致内容被遮挡或重叠。
- 不要修改这些类的定位属性。

## 7. 库：能用现有库就不许自己写

列表见 `assets/lib/LIBS.md`。你要做的事：

1. 先查表：“要做的事” → 对应的库。  
2. 如果库能满足，**必须用库**，绝不允许从底层手写（例如用 echarts 画折线图，而不是自己调 canvas 画线）。  
3. 库的引用方式：每个库的 `<script>` 标签已给出，直接从 `assets/lib/` 引用，**不要用 CDN**。  
4. 版本号见 `LIBS.md` 的精确版本表，**不要自己去压缩文件里找版本**（找不到，且浪费时间）。  
5. 加载顺序：按 `LIBS.md` 里的说明，例如 `three.js` 之后才能引 `globe.gl`，`gsap` 之后才能引 `ScrollTrigger`。

**几条自动失效的坑，必须避免：**

- **echarts 必须加 `renderer: 'svg'`**，否则所有文字进入 canvas 位图，字号自检看不见，相当于没做字号检查。  
- **katex 基准字号必须 ≥20px**，因为嵌套分式会缩小到 0.847 倍，两层嵌套后跌破 12px。  
- **随机生成数据必须用 `seedrandom` 并指定种子**，确保每次打开页面数据一致，讲解内容才不落空。

## 8. 交互标准

### 8.1 真交互 vs 装饰
- **真交互**：用户的操作（点击、拖拽、滑动、输入）会改变页面呈现的数据、图形或状态，并且这种改变是实时的、可逆的。
- **装饰**：自动播放的动画、静止的插图、没有操作反馈的图形。装饰不能替代教学内容的解释，只能作为辅助。

### 8.2 键盘可达
- 所有可交互控件（按钮、滑块、输入框）必须能通过 Tab 键聚焦，且焦点样式明显（`theme.css` 提供了 `--focus` 颜色）。
- 拖拽类交互（如用 Konva 实现）必须提供键盘替代（如方向键移动），或者用 `aria-label` 说明操作方式，并确保读屏器能读取。

### 8.3 动画与 reduced-motion
- 所有动画必须使用 `Deck.loop`，它会在系统 reduced-motion 开启时只画一帧。
- 如果动画的第一帧无法传达信息，用 `options.still` 指定一个能传达信息的静帧时间。
- 纯装饰性动画（如背景动画）在 reduced-motion 下应完全静止。

## 10. 完工前自检

在 `pages/` 目录下运行：

```bash
python3 assets/selfcheck.py page-XX.html
```

它会用 1600×900 视口无头渲染，报告：
- JS 报错
- 资源加载失败（404）
- 元素超出画布边界
- 元素被裁剪
- 字号最小值、中位数（会检查所有 DOM 文字，但 canvas 里的文字查不到，所以 echarts 必须用 svg 渲染）
- 密度：画面占用比、文本块数、容器数、文字叠压处、占比不足 1% 的小容器

**判据**（必须全部通过）：
- 0 个 JS 错误
- 0 个资源加载失败
- 0 个超出画布的元素
- 0 个被裁剪的元素（允许 `katex-mathml` 产生的隐藏裁剪，selfcheck 已排除）
- 字号最小值 ≥ 12px（刻度档），中位数 ≥ 15px（标签档）
- 文本块数 ≤ 80，且文字叠压为 0
- 画面占用比在 30%~70% 之间（太挤或太空都算问题）

如果任何一项不达标，**立即修改，直到干净为止**。  
想查看交互后的状态，用 `--after "一段 JS"` 模拟操作（可多次使用）。
