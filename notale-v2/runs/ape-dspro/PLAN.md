# 《Apeman – Spaceman》 90 分钟互动讲义 · 总规划

## 0. 这套讲义的主线

**主张：**人类从石器到空间站，本质上是在做同一件事——把身体的功能一件一件外包出去。每一次外包都解放了一种能力，也退化了一种本能。猿人用石头当拳头，宇航员用舱外服当皮肤，我们是同一根链条的两端。

| 章 | 页 | 这一章要让读者信什么 |
|---|---|---|
| 一：拳头之外 | 01–09 | 工具不是手的延伸，而是手的替代。替代的同时，手就忘了怎么当拳头。 |
| 二：声音之外 | 10–16 | 文字和通信把语言从身体里拽出来，放到体外，跨越了时间和距离。 |
| 三：皮肤之外 | 17–24 | 从衣服到空间站，壳一层层加厚，身体越来越不需要直接触碰世界。 |
| 四：大脑之外 | 25–33 | 记忆、计算、决策，一样一样搬出去。石板 → 印刷术 → 计算机 → 云端。 |
| 五：重力之外 | 34–40 | 脱离地球引力是最后的外包——连身体本身都要被重新设计。 |

无交互（只承担开场/推进/过渡/收束）：01 02 10 17 25 33 34 40

**重复形式管控：**

- 物理模拟（Matter.js）：仅 p05 和 p22 使用。p05 模拟石头砸坚果，p22 模拟手套捏鸡蛋。机制不同，不共用代码。
- 3D 场景（Three.js）：p12（声场衰减）、p20（壳层结构）、p23（舱外服手套）、p35（空间站轨道）、p38（外骨骼）。五个场景各自独立，不共享模型。
- 神经网络训练（mlp.js）：仅 p29 使用。不得在其他页出现。
- 拖拽交互（Konva.js）：p04（石器时间轴）、p13（符号对应）、p28（决策树）、p32（天平）、p38（力传递路径）。各页独立实现。
- 三栏对照（triptych）：p14（三种文字介质）、p21（三种极端壳）、p30（三种导航方式）、p37（三种骨骼）。同版式不同数据。
