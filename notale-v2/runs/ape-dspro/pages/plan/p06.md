# page-06 · 工具使用的谱系 · **110 秒**

## 知识结构：enumeration
这一页把“工具使用”这个性状在演化树上的分布显式化。骨架是**主干分支**：左侧是一棵简化的演化谱系树，节点代表物种或类群，右侧是选中节点对应的工具使用行为卡片。关系是“有这个性状 / 没有这个性状”——每个节点被标记为 `uses_tools: true/false`，点击节点时右侧卡片显示该物种的具体工具行为（如果有）。

学习者看到的是：工具使用这个性状在演化树上散布得很广，但绝大多数物种只停留在“用现成物件”这个层级。人类那个节点旁边标的不只是 `true`，而是 `system`——这是整棵树里唯一一个 `system`。

## 表征形式
交互式谱系树（静态渲染 + 点选高亮）。节点默认全部显示，颜色区分“会用工具 / 不会用工具 / 人类”。点击节点后右侧卡片切换内容，同时该节点到人类的路径高亮，显示“距离”。

## 并列的各项

### 物种数据
以 `Lec.P` 函数 `getToolUseSpecies()` 返回的数组为准。每个条目包含：

| 字段 | 说明 |
|---|---|
| `id` | 物种标识符 |
| `commonName` | 中文通用名 |
| `scientificName` | 学名（小字，不强制阅读） |
| `usesTools` | `true` / `false` |
| `toolBehaviors` | 数组，字符串列表，如 `["用树枝钓白蚁", "用石头砸坚果"]` |
| `isHuman` | `true` 仅一个节点 |
| `toolSystemLevel` | `"none"` / `"object"` / `"modified"` / `"system"`——仅人类为 `"system"` |

谱系树上至少包含以下节点（具体拓扑由 `Lec.P.getTreeTopology()` 返回）：

- 人类（*Homo sapiens*）—— `usesTools: true`, `toolSystemLevel: "system"`
- 黑猩猩（*Pan troglodytes*）—— `usesTools: true`, `toolSystemLevel: "modified"`
- 倭黑猩猩（*Pan paniscus*）—— `usesTools: true`, `toolSystemLevel: "object"`
- 红毛猩猩（*Pongo* spp.）—— `usesTools: true`, `toolSystemLevel: "object"`
- 猕猴（*Macaca* spp.）—— `usesTools: true`, `toolSystemLevel: "object"`
- 新喀鸦（*Corvus moneduloides*）—— `usesTools: true`, `toolSystemLevel: "modified"`
- 海獭（*Enhydra lutris*）—— `usesTools: true`, `toolSystemLevel: "object"`
- 大象（*Elephas* / *Loxodonta*）—— `usesTools: true`, `toolSystemLevel: "object"`
- 章鱼（*Amphioctopus marginatus*）—— `usesTools: true`, `toolSystemLevel: "object"`
- 鳄鱼（*Crocodylus* spp.）—— `usesTools: true`, `toolSystemLevel: "object"`
- 非工具使用对照节点（至少 5 个，如蛙类、蛇类、鸽类、鹿类、猫科）—— `usesTools: false`, `toolSystemLevel: "none"`

物种总数 `Lec.K.TOOL_SPECIES` + 10（含非工具使用者），总数约 20 个节点。

### 常数
`Lec.K.TOOL_SPECIES` = 10（已知会使用工具的物种，除人类外）

## 必须点出来的两句
1. **用工具不是人类的专利，但把工具做成系统，只有人类。**  
2. 树上每一个亮起来的点都在说同一件事：手能抓东西、脑子能算因果，工具就会冒出来。但「系统」——把工具做得只差一个工具就能做下一个工具——只出现了一次。

## 交互（只有这一个）
**点选谱系树。**  
读者点击左侧谱系树上的任意节点，右侧卡片切换为该物种的工具使用行为详情。如果该物种 `usesTools: false`，卡片显示“该物种不制造也不使用工具”。如果 `usesTools: true`，卡片列出 `toolBehaviors` 数组中的每一项，并在下方显示 `toolSystemLevel` 的可视化指示器（四个刻度：无 / 物件 / 加工 / 系统，当前刻度高亮）。

点击人类节点时，`toolSystemLevel: "system"` 刻度亮起，卡片底部出现一句话：“系统意味着：工具造工具，工具修工具，工具设计工具。”

从任意节点到人类节点的演化路径用橙色线条高亮，路径长度显示在人类节点旁（单位：百万年，由 `Lec.P.getDivergenceTime(nodeId)` 计算）。
