# page-08 · 递进外包 · **100 秒**

## 知识结构：generalization

**骨架：** 层级间的递进 —— 四个外包层级，从左到右排列，每一层比前一层多一层中介，手离世界远一步。

**显式化的关系：** 外包层级与直接性的反比关系。通过空间距离和传输延迟两个维度对齐：

- 手（零点，无中介）
- 石头（一层中介，手持工具）
- 锤子（两层中介，手持复合工具）
- 机械臂（三层中介，手持遥控设备）

**递进线索：** 每个层级增加一个"传输层"——手到世界的距离增加，力/触觉的反馈延迟增加，自由度反向变化。

## 表征形式

**动态 + 交互：** 四个层级作为四个可见的视觉对象，从左到右排列。每个层级包含：
- 一个代表"手"的节点（位置固定在同一水平线上）
- 一个代表"世界"的节点（位置随层级增加而远离手节点）
- 连接它们的箭头或线条，层级越深，线条越长，颜色越冷（从暖橙到冷蓝）
- 每条线上标注中介物的名称和数量

**心理表征目标：** 让学习者看到"外包"不是抽象概念，而是物理距离的增加——每加一层，手和世界之间就多了一个东西，反馈就慢一拍。

## 层级间的递进：四个层级

### 层级一：手（基准）

**手节点 → 世界节点：** 零距离，直接接触。
- 传输介质：皮肤、肌肉、骨骼
- 延迟：0 ms（即时触觉反馈）
- 力反馈：完整（你能感觉到每一个纹理）
- 自由度：27（手指 + 手腕 + 手臂的完整活动范围）
- 从 `Lec.P.G` 和手部解剖学数据计算自由度：拇指 5，食指 4，中指 4，无名指 4，小指 4，手腕 3，前臂旋转 2，肘部 1，总计 27

### 层级二：石头（一层外包）

**手节点 → 石头节点 → 世界节点：** 手握住石头，石头触碰世界。
- 中介物：1 层（石头）
- 传输路径：手 → 石头 → 目标
- 延迟：~5 ms（振动通过石头传导的时间，根据石头材质和密度估算）
- 力反馈：部分损失（你感觉到石头的振动，但感觉不到被砸物体的纹理）
- 自由度：减少到约 15-18（手指被约束在握持姿势，手腕和手臂仍可活动）
- 视觉状态：左边一级，手-世界距离明显短于其他层级

### 层级三：锤子（两层外包）

**手节点 → 锤柄节点 → 锤头节点 → 世界节点：** 手握住锤柄，锤头打击目标。
- 中介物：2 层（锤柄 + 锤头）
- 传输路径：手 → 锤柄 → 锤头 → 目标
- 延迟：~10-15 ms（力学振动通过木柄和铁头传导的时间）
- 力反馈：进一步损失（你感觉到反冲力，但锤头与目标接触的细节消失了）
- 自由度：减少到约 10-12（手腕被锁定在挥锤轴上，手指被柄的粗细决定）
- 视觉状态：左二，手-世界距离明显大于石头

### 层级四：机械臂（三层外包）

**手节点 → 控制器节点 → 传动节点 → 机械爪节点 → 世界节点：** 手操作控制器，电信号驱动机械臂，机械爪抓取目标。
- 中介物：3 层（控制器 + 传动系统 + 机械爪）
- 传输路径：手 → 控制器 → 信号传输 → 马达 → 机械爪 → 目标
- 延迟：~50-100 ms（电信号 + 机械响应时间，不涉及现代工业，仅指基本原理）
- 力反馈：几乎完全丧失（你只能看到机械爪抓没抓住，手感觉不到任何东西）
- 自由度：可以扩展（机械爪可以有超出手指的活动范围），但手本身的自由度被限制在控制器上（约 3-5 个自由度：摇杆 x/y + 按钮）
- 视觉状态：左三，手-世界距离最大，连接线最长，颜色最冷

### 视觉递进参数

- 手节点位置：对所有层级，手在画面左侧，坐标固定 `(x_hand, y_hand)`
- 世界节点位置：随层级增加向右偏移，步长相等
  - 层级一：`x_world = x_hand + 60px`
  - 层级二：`x_world = x_hand + 140px`
  - 层级三：`x_world = x_hand + 220px`
  - 层级四：`x_world = x_hand + 320px`
- 连接线颜色渐变：`#FF6B35`（层级一，暖橙）→ `#F7931E`（层级二）→ `#5B8BD4`（层级三）→ `#2C5F8A`（层级四，冷蓝）
- 连接线粗细：从 4px（层级一）递减到 1px（层级四），象征直接性的减弱
- 中介物节点：连接线上用圆点标记，每个圆点代表一个中介层，层级二有 1 个圆点，层级三有 2 个，层级四有 3 个

## 必须点出来的三句

1. 每加一层，手就离世界远一步。外包越多，手越自由，也越脆弱。（核心主张）
2. 你看：手碰到石头，石头碰到目标——这是一层。手握住锤柄，锤头砸向目标——这是两层。一层一层叠上去，手和世界之间塞满了东西。
3. 机械臂能抓起人抓不起的东西，但你的手感觉不到任何东西。外包给了你力量，拿走了触觉。

## 交互：渐进式对比

**canvas-full 交互设计：**

**初始状态：** 四个层级全部可见，但层级二、三、四的连接线是虚线，世界节点是半透明灰色，表示它们尚未被激活。

**读者操作：** 点击任意一个非激活层级，或者按空格键逐级推进。

**推进过程：**
1. 第一次点击/空格：层级二（石头）激活。连接线从虚线变为实线，世界节点从灰色变为白色，手节点和世界节点之间出现一个中介圆点（石头），延迟标注 "~5 ms" 淡入。
2. 第二次点击/空格：层级三（锤子）激活。两个中介圆点出现，延迟标注 "~10-15 ms" 淡入，连接线变细，颜色变冷。
3. 第三次点击/空格：层级四（机械臂）激活。三个中介圆点出现，延迟标注 "~50-100 ms" 淡入，连接线最细，颜色最冷。

**在每次推进的瞬间，已激活的层级保持可见，但会在视觉上后退一步（缩小或降低不透明度），让新激活的层级成为焦点。**

**读者应该形成的直觉：** 这不是"变好"或"变坏"，而是"变远"。每点击一次，你看到手和世界之间多了一个东西，反馈慢了一拍，但手能做的事也在变化。自由度和反馈是同一枚硬币的两面。

**回退：** 按 Backspace 键可以让最近激活的层级回到虚线状态，读者可以反复对比。

## 不许碰

- 不讲现代工业（p09 负责）：机械臂的描述限制在"手操作控制器，控制器驱动机械爪"这个基本概念，不涉及液压系统、伺服电机、数控编程、工业机器人型号等具体工业技术。
- 不讲能量守恒公式：虽然 p05 可以提，但这一页的焦点是"外包层级"的结构，不是力的计算。
- 不讲工具演化序列（p04 负责）：这一页只展示四个层级的结构关系，不展开石器从砍砸器到细石器的历史过程。
- 不涉及具体的机械臂型号、品牌、应用场景：保持抽象，只讲"手 → 控制器 → 机械爪"的基本原理。
