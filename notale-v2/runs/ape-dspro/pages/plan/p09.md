# page-09 · 手的外包之后 · **80 秒**

这一页显式化的关系是**「第一章的结论 → 外包序列的下一环」**。
具体靠三件事完成：
- 回顾第一章走过的路径：手 → 石头 → 工具系统 → 外包递增
- 把这条路径压缩成一条可迁移的陈述：外包一旦开始，就不会停在一个器官上
- 用一个箭头或过渡标记指向第二章：下一个被搬出身体的是声音

## 表征形式
静态。stage-cards 版式，三张卡片从左到右排列，对应「起点 → 现在 → 下一步」。
学习者需要在这一页形成的心理表征是**外包的连锁性**——不是工具箱越来越满，而是一个器官接一个器官被替代的必然链条。

## 三张卡片的内容

### 卡片一：起点
- 标签：**`300 万年前`**
- 图示：一只手握住一块粗糙石头（示意，不是照片）
- 正文：猿人用石头当拳头。手还在，但打击的功能已经搬到了石头上。

### 卡片二：现在
- 标签：**`第一章回顾`**
- 图示：同一只手，但旁边依次叠着石头、锤子、机械臂，手离最远那层越来越远
- 正文：石头变薄、变轻、变锋利。每一次改进，手需要出的力就少一点。外包越多，手越自由，也越脆弱。

### 卡片三：下一步
- 标签：**`第二章预告`**
- 图示：一只手放在喉咙前，声波从嘴里发出，但旁边有一个箭头指向一张刻有符号的泥板
- 正文：手的外包是第一个。下一个被外包的器官，是喉咙。声音离开身体，变成符号。

## 必须点出来的收束主张

**收束一句：** 手的外包是开始，不是结束。下一个被外包的是声音。

**过渡一句：** 石头替了拳头，符号替了声音——外包的逻辑一旦启动，就不会只停在一个器官上。
