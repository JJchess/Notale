# page-11 · 声音波形对比 · **110 秒**

## 知识结构：comparison
这一页靠**对齐的波形图**显式化「三种声音产生方式在物理特性上的差异」。
三条波形纵轴对齐（时间轴），横轴共用（振幅），让读者一眼看到：
- 说话：复杂包络，不规则周期
- 敲击：陡峭起振、快速衰减、无周期
- 哨声：平滑正弦、稳定频率、持续能量

对比维度：**产生机制、波形特征、持续时间、能量消耗、方向性、是否可叠加**。

## 表征形式
交互式对比——三条波形不是静态截图，而是读者点击/悬停时播放的实时波形动画，让读者**感到**声音的时间性：它出现、占据空间、然后消失。

## 波形维度表

| 维度 | 说话（人声） | 敲击（木棍敲树） | 哨声（手指哨） |
|---|---|---|---|
| 产生机制 | 声带振动 + 口腔共鸣 | 固体碰撞，瞬态激励 | 空腔共振，气流激发 |
| 波形特征 | 复杂谐波，不规则包络 | 单脉冲或短脉冲串，指数衰减 | 准正弦波，稳定频率 |
| 持续时间（典型值） | 200–3000 ms | 10–200 ms | 500–5000 ms |
| 峰值频率 | 100–400 Hz（基频），谐波到 3 kHz | 宽带，峰值依材质 | 800–2000 Hz，窄带 |
| 方向性 | 全向为主，高频有指向性 | 全向 | 较强指向性 |
| 能量消耗 | 中等（持续气流） | 高（瞬时冲击力） | 低（压缩气流，小开口） |
| 可叠加性 | 不能（一个人只能说一句话） | 可叠加（多人同时敲） | 可叠加（多人同时吹） |
| 信息承载 | 极高（语言信息） | 低（信号强度、节奏） | 中等（频率变化可编码） |

## 必须点出来的三句

1. 声音是身体能制造的最轻的工具：不消耗材料，不留下痕迹，说完就消失。
2. 说话、敲击、哨声——三种声音，三种波形，对应三种不同的信息策略：复杂信息靠声带，紧急信号靠撞击，远距离呼唤靠哨声。
3. 声音的轻，是它的优势，也是它的极限：它只能活在当下，没有副本，没有地址。

## 交互

**声音波形对比：说话 vs 敲击 vs 哨声**

- 版式：`split-lr`，左栏三个触发按钮（说话/敲击/哨声，带图标），右栏实时波形显示区。
- 读者动什么：
  - 点击左栏任一按钮，触发对应的声音样本播放，同时右栏实时绘制该声音的波形（用 Web Audio API 的 `AnalyserNode` 获取时域数据，或用预录波形数据驱动动画）。
  - 可以同时叠加两个或三个声音，波形叠加显示（用不同颜色区分），让读者看到叠加后的波形是什么样子。
- 看到什么变：
  - 波形从左侧实时滚入，振幅随时间衰减（敲击）或持续（哨声、说话）。
  - 叠加模式下，波形颜色混合，峰值处出现干涉图案。
- 从中该形成什么直觉：
  - 声音是**时间里的存在**，它没有静态形态，只有波动。
  - 不同的声音产生方式，消耗不同的能量，适合不同的信号任务。
  - 声音可以被叠加，但不能被「保存」——这是它和文字的根本区别（本页不展开文字，只埋下这个直觉）。

## 必用skill
webgl-3d-object, animejs

注：`webgl-3d-object` 用于渲染一个可旋转的抽象「声源」模型（三个声源位置不同，展示方向性），`animejs` 用于波形动画的时序控制（敲击衰减曲线、哨声持续振荡、说话不规则包络）。Web Audio API 的 `AnalyserNode` 是浏览器原生能力，不需要额外 skill。
