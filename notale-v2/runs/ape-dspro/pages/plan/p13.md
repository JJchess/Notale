# page-13 · 凝固声音 · **130 秒**

**kicker:** `第二章 · 声音之外`

**主标题:** 把会消失的振动变成不会消失的划痕

## 知识结构：process
这一页显式化的关系是**从连续声波到离散符号的映射过程**——口语是时间轴上的振动，文字是空间平面上的刻痕，两者之间需要建立一一对应。

具体靠三个状态来显式化：
- **状态 A（初始）：** 上方是口语词汇的波形动画（声音在时间中），下方是散落的刻痕符号（符号在空间中），两者尚未连接。
- **状态 B（交互中）：** 读者拖拽符号到对应词汇上，在尝试中建立映射。拖拽过程本身就是“把时间中的东西拽到空间里”的隐喻。
- **状态 C（完成）：** 所有符号归位，波形消失，文字浮现——声音被“凝固”成可视的、持久的符号系统。

## 表征形式
动态 + 交互。上方口语词汇用波形动画表现声音的瞬时性（振幅随时间衰减，暗示“说完就消失”），下方刻痕符号用粗粝的、不完美的视觉质感（模拟刻划在泥板或骨片上的痕迹），形成“流动 vs 固定”的对比。读者拖拽的过程是这一页的核心表征——**把声音拽进空间里**。

## 六个 step：从口语词到刻痕符号

这一页展示六个口语词汇与六个刻痕符号的对应建立过程。口语词选日常可感知的实体名词，刻痕符号用象形或指事的视觉逻辑。

### 口语词（六个）
| 口语词 | 词形 | 语义 | 波形特征 |
|---|---|---|---|
| “ku-ri” | `ku-ri` | 石头 | 短促、低频，两个音节等长 |
| “ma-ra” | `ma-ra` | 水 | 连续、平滑，音节间有滑动 |
| “ta-pa” | `ta-pa` | 手 | 爆破音起始，尖峰波形 |
| “si-lu” | `si-lu` | 太阳 | 高频、渐强，第二个音节拖长 |
| “bur-gu” | `bur-gu` | 食物 | 低沉、含混，两个音节粘连 |
| “en-zu” | `en-zu` | 人 | 鼻音起始，波形柔和 |

### 刻痕符号（六个，初始态为散落卡片）
| 符号 | 视觉描述 | 对应口语词 | 象形/指事逻辑 |
|---|---|---|---|
| ‖⋮ | 两条竖线，中间三个点 | ku-ri（石头） | 竖线=石壁，点=石上的斑点 |
| ≈ | 两条平行波浪线 | ma-ra（水） | 水面波纹 |
| ✋ | 五指张开的手掌轮廓 | ta-pa（手） | 手的直接象形 |
| ⊙ | 圆圈，中心一点 | si-lu（太阳） | 日轮+中心光点 |
| ⊕ | 圆圈，内十字 | bur-gu（食物） | 分割的圆=可分配的食物 |
| 𐂂 | 简化的直立人形，头+躯干+两腿 | en-zu（人） | 人的直接象形 |

### 箭头上的连接问题：为什么是这些符号？
每个符号与其对应口语词之间有一个**视觉可辨识的关联**——要么是直接象形（手、人、太阳），要么是指事/隐喻（水=波纹、石头=纹理、食物=可分割的圆）。这种关联让“一一对应”不是任意约定，而是有直观逻辑可循，帮助读者理解早期文字（象形文字、指事文字）的起源逻辑。

## 必须点出来的三句
1. 口语说完就消散在空气里，但刻痕留在泥板上，明天还能看。
2. 文字不是“记录声音”，而是给每个声音找一个**能留在空间里的替身**。
3. 一旦声音有了替身，你就不需要和说话的人同时在场——这是信息第一次脱离身体。

## 交互（只有这一个）
**拖拽：把口语词汇变成刻痕符号，建立一一对应**

### 读者动什么
- 画面下方有六个散落的刻痕符号卡片（初始位置随机但有间隔，避免重叠）。
- 画面上方有六个口语词汇卡片，每个卡片右侧有一个虚线框的“符号槽”。
- 读者从下方拖拽一个符号卡片，放到某个口语词卡片旁边的符号槽中。
- 松手时：
  - **如果对应正确**（符号匹配该口语词）：符号卡片“嵌入”槽中，有轻微的锁定动画（微微放大→缩回→稳定），该口语词的波形动画停止，波形被替换为符号的静态图像，文字形式的口语词标注浮现（如 `ku-ri → ‖⋮`）。
  - **如果对应错误**：符号卡片弹回原位，符号槽短暂闪烁红色，口语词波形短暂抖动。不惩罚，允许重试。
- 所有六个匹配完成后，画面整体过渡：所有波形消失，六个“口语词 → 符号”的对应关系以铭文碑的形式排列展示，标题“文字：声音的凝固”浮现。

### 看到什么变
- 初始：波形在动（声音是活的、在时间中），符号散落（尚未有意义）。
- 匹配中：正确归位的符号让对应波形停止——**声音被“关掉”**，符号接管。
- 完成后：波形全部消失，只剩静态的符号和文字标注——**声音完全凝固为文字**。

### 从中该形成什么直觉
拖拽这个动作本身就是隐喻：把流动的声音从时间轴里拽出来，钉在空间的平面上。匹配成功时波形停止，强化“凝固”的直觉——文字不是记录声音，而是终结声音的流动，用空间换时间。

### 交互实现提示
- 拖拽使用 Konva.js（符合页表约定：p13 使用 Konva.js 实现拖拽）。
- 符号卡片有轻微的重力感和惯性（拖拽时跟随指针，松手时有缓动），但不需要物理模拟（Matter.js 仅用于 p05 和 p22）。
- 匹配判断用简单的符号 ID 与槽 ID 比对，不需要模糊匹配。
- 波形动画用 Canvas 或 SVG 绘制，跟随口语词卡片位置，匹配成功后渐隐消失。

## 不许碰
不讲拼音字母——这一页的符号是**象形/指事层面的刻痕符号**，不是表音符号。不涉及任何字母系统、音节文字、辅音音素文字。不讨论楔形文字或甲骨文的具体历史（那是 p14 的内容）。不讨论文字如何演变为表音系统（那是 p14 的边界）。

## 必用skill
konva-js-drag（拖拽符号卡片需要 Konva.js 的拖拽事件、命中检测、动画缓动），animation-systems（波形停止、符号嵌入、整体过渡需要统一的动画节奏管理），css-alpha-masking（波形渐隐消失可使用 alpha 遮罩实现柔和过渡）

## 版面提示
使用 stage-cards 版式，但卡片排列需要支持上下分区：上方六个口语词卡片（横向排列，两行三列或一行六列均可，确保不拥挤），下方六个符号卡片（散落但等距）。中间留出足够的拖拽操作空间（至少 200px 高度）。完成态时过渡为铭文碑式排列（六行，每行一个对应关系，居中展示）。
