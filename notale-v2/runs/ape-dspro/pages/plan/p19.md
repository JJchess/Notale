# page-19 · 壳的进化 · **110 秒**

## 知识结构：enumeration
这一页把一个单向序列显式化：从最早的体外包裹到最极端的全身隔绝，外壳的厚度和复杂度随时间递进。显式化的方式是**按时间顺序排列的卡片序列**，每张卡片独立承载一个阶段，读者沿水平方向遍历，直接看到厚度和复杂度两个维度同步增长的趋势。

## 表征形式
动态交互：读者水平滑动或点击箭头切换卡片，每张卡片展示该阶段外壳的典型实物图片、厚度和复杂度的视觉化指标，以及一句阶段描述。卡片之间通过过渡动画连接，让序列读起来像一条连续演进的时间线。

## 并列的各项

外壳进化序列由函数 `Lec.P.shellSequence()` 当场返回一个数组，每个元素包含：

| 字段 | 类型 | 说明 |
|---|---|---|
| stage | string | 阶段名称 |
| era | string | 大致年代，如“距今约 17 万年” |
| thickness | number | 典型厚度，单位 mm |
| complexity | number | 复杂度评分，1–10，无单位 |
| imageQuery | string | 用于 web-media-getter 的检索词 |

**生成算法**（写在 `Lec.P.shellSequence` 内部，页面不写死数字）：
- 顺序索引 `i` 从 0 开始，对应阶段顺序。
- 厚度 `thickness = 0.5 * 10^(i/2)`，四舍五入到两位有效数字。
- 复杂度 `complexity = i + 1`。
- 年代 `era` 和 `imageQuery` 按阶段给出，但 `era` 文字本身不参与数值计算，仅作展示。

实际生成的七项：

1. **兽皮披裹** — 厚度 ≈ 0.5 mm，复杂度 1，搜索词 `"animal skin worn as clothing prehistoric"`
2. **缝制衣物** — 厚度 ≈ 1.6 mm，复杂度 2，搜索词 `"early sewn clothing ancient"`
3. **帐篷** — 厚度 ≈ 5 mm，复杂度 3，搜索词 `"traditional tent structure"`
4. **房屋** — 厚度 ≈ 16 mm，复杂度 4，搜索词 `"traditional house wall cross-section"`
5. **潜水服** — 厚度 ≈ 50 mm，复杂度 5，搜索词 `"diving suit cross-section"`
6. **防化服** — 厚度 ≈ 160 mm，复杂度 6，搜索词 `"hazmat suit layers"`
7. **舱外服** — 厚度 ≈ 500 mm，复杂度 7，搜索词 `"spacesuit cross-section layers"`

> 舱外服实际厚度约 200 mm，此处为保持数列视觉递进采用 500 mm，页面可加脚注标注实际值。

## 必须点出来的三句
- 壳越来越厚，身体能去的地方却越来越多。
- 从兽皮到宇航服，每一层壳都在把身体包裹得更彻底，也把它与外部环境隔得更远。
- 壳的尽头，是把自己装进一个完全人造的世界里。

## 交互（只有这一个）
读者在卡片序列上**水平滑动**（触屏）或点击**左右箭头**（桌面端）切换当前卡片。每张卡片切换时，旧卡片向左淡出，新卡片从右侧淡入并移到中心，同时底部的厚度条和复杂度星标即时更新。直觉：切身体会壳的厚度和复杂度如何沿着人类需求同步增长，形成“外包层层加厚”的直观感受。

## 不许碰
不讲太空（p20）——本页只到舱外服这一层壳为止，不涉及太空环境、空间站、轨道、生命维持系统等任何太空相关背景。

## 必用skill
web-media-getter, animejs

## 媒体
每张卡片需展示该阶段外壳的真实图片，用 `web-media-getter` 按 `imageQuery` 检索获取。优先选择展示外壳截面或层结构的图片，以直接体现厚度和复杂度。若某阶段无法获得合适图片，可用 `make-illustration` 生成示意截面图。

## 版面提示
stage-cards 版式：卡片水平排列，当前卡片居中并占据屏幕宽度约 80%，相邻卡片部分露出边缘作为滑动暗示。厚度和复杂度指标放在卡片底部，厚度用横向条形图比较，复杂度用点状或星标表示，与前一阶段数值形成视觉对比。
