# page-23 · 手套加压 · **120 秒**

**kicker:** `第三章 · 皮肤之外`
**主标题:** `舱外服手套：加压后的拳头`

## 知识结构：process
这一页要显式化的关系是**因果关系**：手套内部加压 → 手指关节活动范围缩小。

具体通过**前后态对比**来显式化：
- 前态（不加压）：手套手指可以自由弯曲到正常生理角度
- 后态（加压到 `Lec.K.GLOVE_PSI`）：每根手指的活动范围被压缩到原来的 30–40%

学习者通过切换加压状态，直接看到关节角度变化，形成"气压对抗肌肉"的直觉。

## 表征形式
交互式 3D 模型（Three.js）：一只舱外服手套的右手模型，手指关节可独立弯曲。读者可以旋转视角观察手套的整体结构，也可以单独点击某根手指看它的活动范围。模型旁边有一个加压/泄压的切换按钮，切换时手指的活动范围会实时变化。

选择 3D 而非静态示意图的原因是：手套关节的活动范围是三维空间中的问题——手指不仅要弯曲，还有侧向活动和旋转——平面图无法传达"握拳像捏网球"这个核心直觉。

## 关节角度与气压对抗

### 物理参数（从 `Lec` 常量取）

| 参数 | 来源 | 值 |
|---|---|---|
| 手套工作压力 | `Lec.K.GLOVE_PSI` | 4.3 psi |
| 不加压时食指 MCP 关节最大屈曲角 | 正常人体 | 90° |
| 不加压时食指 PIP 关节最大屈曲角 | 正常人体 | 100° |
| 不加压时食指 DIP 关节最大屈曲角 | 正常人体 | 80° |
| 不加压时拇指 CMC 关节最大屈曲角 | 正常人体 | 45° |
| 不加压时拇指 MCP 关节最大屈曲角 | 正常人体 | 50° |
| 不加压时拇指 IP 关节最大屈曲角 | 正常人体 | 80° |

### 加压后的关节活动范围（% 表示剩余角度占不加压时的比例）

| 关节 | 加压后最大屈曲角 | 剩余比例 | 直觉等价 |
|---|---|---|---|
| 食指 MCP | 35° | 39% | 手指弯到一半就推不动了 |
| 食指 PIP | 40° | 40% | 第二指节几乎僵直 |
| 食指 DIP | 30° | 38% | 指尖无法触及掌心 |
| 拇指 CMC | 20° | 44% | 拇指无法对掌 |
| 拇指 MCP | 20° | 40% | 拇指根部僵直 |
| 拇指 IP | 35° | 44% | 拇指尖无法弯曲到位 |

### 握拳力的等效

页面计算并显示：
- 单根手指对抗气压所需的力 = `Lec.K.GLOVE_PSI` × 手指关节的有效截面积（每根手指约 3–4 平方英寸，取 3.5）
- 单根手指对抗力 ≈ 4.3 × 3.5 ≈ 15 磅力
- 五指同时握拳所需的总力 ≈ 75 磅力

页面用文字显示：「握拳的力量相当于持续捏紧一个标准网球（需要约 15–20 磅的握力，持续数小时）。」

## 必须点出来的两句话

1. **（核心，来自页表一句话）** 舱外服手套内部加压后，每根手指要对抗 4 psi 的气压差。握拳就像捏一个网球——而且你要捏六个小时。
2. **（收束，扣回本章主题）** 手套是壳的最后一层：它保护了手，也夺走了手本该有的灵巧。你在真空中活下来，代价是再也无法用手指真正触碰任何东西。

## 交互（只有这一个）
**3D 场景：舱外服手套的关节活动范围演示**

读者可以做的操作：
1. **旋转/缩放**：用鼠标拖拽旋转手套模型，滚轮缩放，从任意角度观察手套结构。
2. **切换加压状态**：点击「加压/泄压」按钮（或按空格键），手套内部压力在 0 和 `Lec.K.GLOVE_PSI` 之间切换。
3. **点击单根手指**：点击某根手指，该手指会尝试弯曲到当前压力下的最大角度，然后回弹。旁边显示该手指各关节的角度数值。

读者看到的变化：
- 不加压时，手指可以自由弯曲到接近正常生理角度。
- 加压后，手套手指明显变"硬"——弯曲到一半就停住，所有关节角度数值骤降。
- 五根手指同时弯曲时，呈现出一个半握不握的僵直姿势，恰好对应「捏网球」的视觉印象。

读者应形成的直觉：
- 舱外服手套不是"穿在手上的衣服"，而是"手要用力推开的压力容器"。
- 宇航员在太空中的每一次抓握，都在对抗一个看不见的对手：4 psi 的气压差。

- 不涉及舱外作业的具体操作流程（那些属于 p24 收束或后续章节）。
