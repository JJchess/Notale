# page-31 · 认知外包清单 · **130 秒**

## 知识结构：enumeration
这一页把「外包」这个抽象概念显式化为一组**可逐项审视的并列项**。读者面对的不是一个论点，而是一张清单——每一项都回答同一个问题：「这个认知功能，现在还在不在我脑子里？」

结构是**左右两列对齐**：左列是「已外包」，右列是「尚未外包」。每一项包含三个层次：
- 功能名称（一行）
- 外包载体 / 仍留在体内的位置（一行，小字）
- 代价提示（一行，极简，不展开）

两列之间用一根竖线隔开，形成视觉上的天平：左列越长，右列越短。读者盯着这张清单时，自然形成的问题就是：「右列剩下那几项，什么时候也会被搬走？」——但这一页不回答这个问题，只负责把清单摊开。

## 表征形式
**静态骨架 + 动态逐项浮现**。页面初始时清单不可见，只有标题和一句引导语。教师点击「展开清单」后，每一项从左到右、从上到下依次出现（左列先填满，再填右列），每项的载体说明和代价提示在功能名称出现后 0.5 秒淡入。这种逐项浮现的节奏模拟「盘点」这个动作——读者不是一次性看到结论，而是跟着一项一项数过去，数到右列时自然产生「还剩这些」的体感。

## 已外包 vs 尚未外包：并列的各项

### 左列：已外包

| 功能 | 外包载体 | 代价提示 |
|---|---|---|
| 记忆 | 笔记、硬盘、云端 | 你自己能记住几个电话号码？ |
| 计算 | 算盘、计算器、计算机 | 两位数乘两位数，你还会笔算吗？ |
| 导航 | 纸质地图、GPS、手机导航 | 海马体活跃度下降（见 p30）。你不认路了。 |
| 决策 | 推荐算法、评分系统 | 「猜你喜欢」替你做了选择。 |
| 社交 | 朋友圈、点赞、转发 | 面对面交谈时，你在看手机。 |
| 写作 | 文字处理器的拼写检查、语法纠错 | 手写一封信，你会写错几个字？ |
| 时间感知 | 钟表、日历提醒、倒计时 | 不看手机，你能准确估计过了几分钟吗？ |

### 右列：尚未外包

| 功能 | 仍留在体内的位置 | 为什么还没搬走 |
|---|---|---|
| 意识 | 全脑，无单一定位 | 我们还不知道意识是什么。 |
| 创造力 | 前额叶与默认模式网络的交互 | 把两个无关的东西连在一起——AI 做得来，但不知道为什么要连。 |
| 情感理解 | 边缘系统、岛叶 | 你哭的时候，手机不会递纸巾。 |
| 直觉 | 基底神经节、小脑 | 学了十年开车，刹车时你不需要想。 |
| 身体感知 | 本体感觉、前庭系统 | 闭上眼睛，你知道自己的手指在哪。 |

### 数值口径
- `Lec.K.MEMORY_SPAN` = 7（短时记忆容量，米勒定律，用于左列「记忆」项的代价提示语境：不外包时你只能记住 7±2 个组块）
- `Lec.P.G` = 9.81（重力加速度，用于右列「身体感知」项的提示语境：前庭系统是为 1g 校准的，p35–36 会展开）

## 收束主张
这一页需要两句，因为清单摊开后需要收拢，但又不能越界预测未来。

**第一句（紧接清单下方）：**「外包不是坏事——每一项外包都让你能做更多的事。但清单右列是提醒：你还有一部分自己，留在身体里。」

**第二句（页脚，极小字，替代通常的页码）：**「右列会一直这么短吗？那是下一章的事。」

## 交互
**列表**——点击每一项已外包功能（左列）时，该项的「代价提示」高亮 3 秒，同时右列中与它最相关的未外包项微微闪烁，提示读者注意这对关系。例如：点击「记忆」，右列的「意识」闪烁——因为记忆外包让我们不再需要记住，但意识仍然依赖记忆来构建自我叙事。这种连线不是逻辑论证，而是视觉启发，帮助读者形成「外包是有代价的」这个直觉。

点击右列项时，不做任何反应——右列是「还没搬走」的部分，不需要交互，保持静默以强化其「残留」感。

## 不许碰
- 不讲未来预测（p32 会展开天平隐喻，那里才讨论代价的量化方向）
- 不讲任何一项外包的「如何工作」——记忆机制在 p26，计算在 p27，决策在 p28–29，导航在 p30，此处只列清单
- 不出现「量子」「奇点」「上传意识」等词汇
- 不对右列中任何一项做「很快也会外包」的暗示

## 必用skill
frontend-design, theme-factory

## 版面提示
split-lr 的默认排法不够用：这一页需要**两列不等宽**——左列占 55%，右列占 40%，中间 5% 留给分隔竖线。左列比右列宽，因为左列有七项，右列只有五项，且右列的项目需要留白来强化「空旷」感。清单上方是标题和引导语，清单下方是收束句，页脚是第二句收束。
