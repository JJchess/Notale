# page-33 · 外包的尽头 · **60 秒**

## 知识结构：generalization
这一页要显式化的是**外包的递进与闭合**——从第一章到第四章，外包的器官一层层向外推，推到大脑这一步时，似乎已经到头了。但真正的尽头不是大脑，而是身体本身还绑在重力上。这一页靠**聚焦渐隐**来显式化：画面中心是身体轮廓，周围是四层外包的图标（手→声音→皮肤→大脑），它们依次亮起后，重力那一层以半透明状态出现，暗示“还在路上”。

## 表征形式
静态但有过渡的视觉呈现：一个居中的人体轮廓线稿，四层已完成的器官外包以同心圆或涟漪状分布在外围，每一层用一个小图标和一个词表示。页面加载时，四层已经完成渐显；重力层（第五章）以半透明状态从外围缓慢靠近，但尚未完全进入画面——60 秒内读者的注意力落在“四层已完成，下一层在路上”这个关系上。

## 递进层次
- **手**（第一章）—— 图标：石斧 / 握石的手 → 已完成
- **声音**（第二章）—— 图标：声波 / 文字符号 → 已完成
- **皮肤**（第三章）—— 图标：衣服 / 壳 → 已完成
- **大脑**（第四章）—— 图标：芯片 / 云 → 刚完成
- **重力**（第五章）—— 图标：地球 / 轨道 → 半透明，正在靠近

四层已完成的图标依次排列在身体轮廓周围，从近到远（手最近，大脑最远）。重力图标在更远处，透明度 0.3，缓慢向身体方向移动，但不抵达。

## 收束主张
**两句：**

> 手、声音、皮肤、大脑——四层外包完成之后，身体还是身体。它还需要重力，需要空气，需要一颗能踩的地面。

> 外包的最后一层，是身体本身。那是第五章要讲的事。

## 不许碰
- 不讲太空生理（骨骼钙流失、体液重新分布、肌肉萎缩等，那是 p35 的内容）
- 不讲重力环境的具体参数（轨道高度、失重机制，那是 p34–p35 的内容）
- 不展开外包的代价量化（那是 p32 的天平做的事）
- 画面上的重力图标只作为“下一章的预告”存在，不解释、不标注数据
