# page-39 · 猿人 / 宇航员 · **130 秒**

## 知识结构：generalization

这一页通过**并置对比**显式化一个共同逻辑：两种身体、两种环境、两种外包层，但结构完全同构。骨架是两列并置，中间用一根隐形的对称轴对齐——左侧猿人面对草原的挑战，右侧宇航员面对真空的挑战，每一行对应同一种身体局限。

显式化的关系是：**不同的环境 → 相同的身体局限 → 不同的外包层 → 相同的逻辑**。读者通过空格键切换两种视角，看到的是同一个结构的两面，而不是两个独立的故事。

## 表征形式

交互式并置对比。画面初始展示猿人身体与环境挑战，按空格键切换到宇航员。切换不是简单的画面替换，而是**同一副骨架上的皮肤替换**——身体结构、环境威胁、外包层，三个层级同时翻面，让读者直接看到对应关系。

## 两条支撑

### 猿人状态

**环境威胁：**草原上的热量流失、掠食者、食物获取困难。身体裸露，皮肤直接暴露在温差、风、紫外线下。牙齿和指甲作为武器效率极低，奔跑速度不足以追上猎物或逃脱。

**身体局限：**皮肤保温能力有限（无毛发的裸露皮肤），咬合力不足以咬碎大型骨骼，消化系统无法处理生肉中的细菌和寄生虫，夜间视力不足以警戒。

**外包层：**石头（拳头的外包）→ 切割、砸碎、投掷。兽皮（皮肤的外包）→ 保温、防风。火（消化系统的外包）→ 预消化食物，杀灭病菌。群体协作（个体力量的外包）→ 围猎、警戒。

**数值：**人类演化时间跨度 `Lec.K.SPAN` = 3,000,000 年。最早石器出现 `Lec.K.FIRST_TOOL` = 3,300,000 年前。人类工具使用物种数 `Lec.K.TOOL_SPECIES` = 10（除人类外）。

### 宇航员状态

**环境威胁：**真空（体液沸腾）、极端温差（+120°C 到 -160°C）、微流星体、宇宙辐射、缺氧。身体完全不能直接接触环境，裸露一秒即致命。

**身体局限：**肺不能处理无氧环境，皮肤不能承受气压差，骨骼在 `Lec.K.BONE_LOSS` = 1.5% / 月的失重下流失钙质，肌肉萎缩，前庭系统在微重力下混乱。

**外包层：**舱外服（皮肤的完全外包）→ 加压、供氧、温控、防辐射。空间站（大气层的外包）→ 人造生态系统。机械臂（手的外包）→ 舱外作业。地面控制中心（大脑的外包）→ 决策支持。

**数值：**舱外服手套气压 `Lec.K.GLOVE_PSI` = 4.3 psi。空间站轨道高度 `Lec.K.ISS_ALT` = 408 km。地球重力加速度 `Lec.P.G` = 9.81 m/s²。骨骼钙流失率 `Lec.K.BONE_LOSS` = 1.5% / 月。

### 共同逻辑

**问题 → 身体局限 → 外包层**，三种元素在两侧完全对应：

| 维度 | 猿人 | 宇航员 |
|---|---|---|
| 环境 | 草原（温差、掠食者） | 真空（辐射、缺氧） |
| 皮肤局限 | 保温不足 | 不能承压 |
| 皮肤外包 | 兽皮 | 舱外服 |
| 手局限 | 握力不足、无切割面 | 不能直接操作 |
| 手外包 | 石器 | 机械臂、手套 |
| 消化/代谢局限 | 生食消化效率低 | 失重下钙流失 |
| 代谢外包 | 火（预消化） | 生命维持系统 |
| 脑局限 | 个体经验有限 | 实时决策受限 |
| 脑外包 | 群体协作、语言 | 地面控制、AI |

画面上，空格键切换时，对应行高亮，数值翻转，但结构位置不变。

## 必须点出来的三句

**收束主张：**

猿人用石头应对草原，宇航员用舱外服应对真空——看起来差了三百万年，实际上做的是一模一样的事：身体不够用，就加一层。

**环境句：**

草原和真空，一个是太暴露，一个是太虚空。但身体的问题是一样的：它不能直接待在那里。

**结尾句：**

外包不是人类发明的策略，外包就是人类。从石头到空间站，我们一直在做同一件事——把身体留在安全的地方，把功能送到危险的地方去。

## 交互

**空格键切换「猿人 / 宇航员」两种身体。**

读者按下空格键，画面在两套身体与环境之间瞬时切换。切换时，**身体结构**（皮肤、骨骼、肌肉、器官）从一个形态翻转为另一个，**环境威胁**（热浪、风声、掠食者轮廓 → 真空、辐射粒子、空间站轨道）同时替换，**外包层**（石器、兽皮、火 → 舱外服、机械臂、生命维持系统）在身体外部叠加或消失。

切换不是渐变，而是**硬切**——中间加一帧全黑过渡（约 200ms），模拟"眨眼看另一种现实"的感觉。切换后，画面停留 2 秒静默展示，让读者对比。

读者应该形成的直觉：**身体面临的挑战变了，但外包的逻辑没变。** 两种状态不是前后关系，而是同一个结构在不同环境下的实例化。空格键不是"进化"，是"翻面"——翻过来看到的是同一枚硬币的另一面。

## 存疑

表里给的版式是 `focus`，但这一页的交互（空格键切换两种身体）本质上是**并置对比**——需要两套视觉素材同时存在，只是通过切换来展示对应关系。`focus` 版式通常用于单一视觉锚点，不适合承载"两种状态、一套结构"的对比。建议在实现时采用 `split-lr` 或双状态切换的 `focus` 变体，让两侧结构位置固定，只替换皮肤和数值，而非完全依赖 `focus` 的单点构图。
