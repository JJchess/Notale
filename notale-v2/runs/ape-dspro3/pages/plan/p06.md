# page-06 · 演化树时间线 · **120 秒**

## 知识结构：process
这一页要显式化**下肢演化是一棵多分支的树，不是一条单向阶梯**。具体通过：
- 一个可滑动的时间轴（横轴），从约 7 Ma 前到现代
- 在时间轴上出现多个分支节点和侧枝，而不是一条主干直线
- 每个分支点代表一个关键适应事件（干旱化、草原扩张、直立行走、耐力奔跑等）
- 灭绝的侧枝和存活至今的支系用不同视觉语言区分
- 读者滑动时间轴时，分支树动态生长，分支事件按时间顺序出现

## 表征形式
动态交互：一棵从 7 Ma 向现代伸展的演化树，树枝在时间轴上向右生长，读者拖动时间轴滑块时，树逐段展开。灭绝支系逐渐变灰并终止，存活支系保持亮色延续到现代。背景用 `make-illustration` 生成开阔草原环境的插画，随着时间推移景观从森林过渡到草原。

## 演化树分支与时间轴事件

### 时间轴上的关键节点（滑动出现）

时间轴尺度：7 Ma 前 至 0 Ma（现代），横轴从左到右。

| 时间（Ma前） | 事件 | 分支特征 |
|---|---|---|
| ~7.0 | 人猿共同祖先（与黑猩猩支系分离） | 主干起点，树根 |
| ~4.4 | 地猿始祖种（Ardipithecus ramidus） | 第一分支，盆骨显示仍能攀爬，但已能直立行走 |
| ~4.0–3.0 | 南方古猿属（Australopithecus）多样化 | 多分支辐射：阿法种、非洲种、源泉种；骨盆和股骨已适应直立行走，但仍保留长臂 |
| ~3.2 | 露西（AL 288-1，阿法种） | 从 `Lec.P.getHominidData('australopithecus')` 获取数据标注 |
| ~2.8 | 人属（Homo）起源 | 从南方古猿支系中分出新分支，脑容量开始增大 |
| ~2.5 | 能人（Homo habilis） | 脑容量更大，但下肢比例仍接近南方古猿 |
| ~2.0 | 傍人属（Paranthropus）侧枝 | 粗壮型南方古猿分支，咀嚼适应，**灭绝侧枝**，约 1.2 Ma 消失 |
| ~1.8 | 直立人（Homo erectus） | 长腿、足弓完整、完全适应地面直立行走和奔跑；从 `Lec.P.getHominidData('erectus')` 获取数据 |
| ~1.0 | 尼安德特人支系分离 | 从海德堡人分支，适应寒冷气候 |
| ~0.3 | 智人（Homo sapiens）出现 | 现代人骨骼比例，耐力奔跑优化；从 `Lec.P.getHominidData('sapiens')` 获取数据 |
| ~0.04 | 尼安德特人灭绝 | **灭绝侧枝**，但部分基因流入现代人 |

### 环境驱动因素（标注在时间轴下方）

| 时间（Ma前） | 环境事件 | 对下肢演化的影响 |
|---|---|---|
| ~8–5 | 东非大裂谷形成，森林退缩 | 森林栖息地破碎化 |
| ~5–3 | 全球变冷变干，C4草原扩张 | 开阔环境选择压力，直立行走优势增加 |
| ~2.6 | 北半球冰期开始 | 气候波动加剧，推动迁徙和耐力适应 |
| ~1.8 | 草原进一步扩张 | 直立人完全适应开阔地形奔跑 |

这些环境事件从 `Lec.P` 获取，页面上以环境图标或色带标注在时间轴下方，不与分支线重叠。

### 分支逻辑

- 主干在 ~7 Ma 处起始
- 每出现一个分支事件，从主干或上一级分支点向右上方/右下方分出
- 灭绝支系在时间轴上终止，节点变灰，支线末端截断
- 存活支系（智人）一直延伸到现代（0 Ma），颜色最亮
- 分支角度反映适应差异程度（差异越大，角度越大）

## 必须点出来的三句

1. 下肢演化不是一条"从猿到人"的直线，而是一棵多分支的树，多数分支已经灭绝。
2. 开阔环境的扩张是推动直立行走和奔跑适应的关键力量，不是某个物种"决定"走向草原。
3. 我们（智人）是这棵树上唯一存活至今的支系，但我们的身体里保留着数百万年演化树的分支遗产。

## 交互（只有这一个）
**滑动时间线看演化树分支**：读者拖动时间轴上的滑块（或触摸/拖拽时间轴本身），演化树从 7 Ma 向现代方向逐步生长。每到一个分支事件的阈值，对应分支从主干或上级分支点生长出来，同时环境事件标注在下方渐显。灭绝支系在到达其终止时间点后逐渐变灰并截断。读者可以前后滑动，看到树如何在不同时间点呈现不同形态。从中形成的直觉：演化是分支式多样化的，环境变化驱动了适应，多数分支已经消失，线性进步叙事是错误的。

## 不许碰
- 不讲具体基因（如 FOXP2、MYH16 等）
- 不讲分子演化速率、序列比对
- 不讲脑容量与其他性状的因果关系（留给 p08）
- 不涉及工具制造、文化演化

## 必用skill
d3-viz, make-illustration

## 媒体
需要一张生成插画作为演化树展开时的背景：从 7 Ma 到现代的东非景观渐变——左侧（远古）为茂密森林，向右（现代）逐渐过渡为开阔草原，色调从深绿过渡到干燥的金色和褐色。这张图位于演化树后方，提供环境背景，比纯示意图更能让读者直观感受"开阔环境"这一选择压力。

## 版面提示
版式为 `canvas-full`，演化树占据整个画布，时间轴在画布底部，环境事件标注在时间轴下方，不侵入树的分支区域。分支节点上的物种名称以小标签形式出现，滑块在底部居中。
