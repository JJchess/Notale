# page-14 · 追逐与散热 · **150 秒**

**kicker**：FOCUS · 热适应奔跑  
**主标题**：为什么猎物先倒下？

## 知识结构：process
这一页要显式化的是**持续奔跑中的能量消耗-体温上升-散热限制的反馈链**：追踪者不是跑得比猎物快，而是跑得比猎物久。六个事件沿时间轴展开，读者通过调整步频和步幅，看到热量不断累积，散热系统在临界点起作用——猎物因散热能力差而先倒下，追踪者因散热系统优越而能持续。

## 表征形式
动态：一个侧视的奔跑场景，追踪者（人类体型）和猎物（羚羊体型）在开阔地面上移动，追踪者上方有体温指示条，猎物上方有同样的体温指示条。读者调整步频和步幅，追踪者的奔跑速度、能量消耗速率、体温上升速率实时变化。猎物以恒定速度奔跑，其体温上升速率固定且散热能力差，最终会先达到临界体温而倒下。

## 六个事件
1. **初始状态**：追踪者与猎物同向奔跑，猎物在前方约20米处，两者体温均为正常值（37°C）。
2. **调整步频**：读者拖动步频滑块（120–180步/分钟），步频越高，追踪者速度越快，能量消耗速率越大，体温上升越快。
3. **调整步幅**：读者拖动步幅滑块（0.8–1.5米），步幅越大，追踪者速度越快，但能量消耗速率非线性增长（大步幅效率低）。
4. **体温上升**：追踪者体温随能量消耗线性上升，但散热系统（出汗、呼吸）以恒定速率带走热量（`Lec.P.sweatCoolingRate()`），净升温速率 = 产热速率 − 散热速率。
5. **猎物临界**：猎物体温上升速率固定（散热能力差，`Lec.P.preyHeatRate()`），约在奔跑开始后90–120秒达到临界体温（42°C），猎物倒下。
6. **追踪者胜出**：追踪者因散热系统优越，在相同时间内体温维持低于临界值，持续奔跑直到猎物倒下。若追踪者步频步幅过高导致自身体温先达临界，则失败。

## 公式与常数
- 追踪者奔跑速度：`v = stepFrequency * stepLength`（m/s）
- 追踪者能量消耗速率：`Lec.P.runningPower(speed)` 返回瓦特（W），基于速度计算代谢功率
- 追踪者产热速率：`heatProduction = runningPower * (1 - efficiency)`，其中 `efficiency = 0.25`（肌肉效率25%，其余75%转化为热）
- 追踪者散热速率：`Lec.P.sweatCoolingRate()` 返回瓦特（W），典型值约600–800 W（人类最大蒸发散热能力）
- 追踪者体温变化：`ΔT = (heatProduction - coolingRate) / (bodyMass * specificHeat) * Δt`，其中 `specificHeat = 3500 J/(kg·°C)`，`bodyMass = Lec.K.ASTRONAUT_MASS`（70 kg）
- 猎物产热速率：`Lec.P.preyHeatRate()` 返回瓦特（W），猎物散热能力差，净值约为追踪者的1.5倍
- 猎物体温变化：`ΔT_prey = preyHeatRate / (preyMass * specificHeat) * Δt`，`preyMass = 40` kg（羚羊体型）
- 临界体温：`Lec.K.CRITICAL_TEMPERATURE` = 42°C
- 初始体温：`Lec.K.NORMAL_TEMPERATURE` = 37°C
- 奔跑时间：从开始到一方体温达临界值，或猎物倒下

## 必须点出来的三句
1. 持久奔跑的关键不是速度，而是散热——人类演化出了哺乳动物中最优秀的蒸发冷却系统。
2. 猎物跑得很快，但它们的散热系统跟不上持续产热，所以先倒下。
3. 每当你调整步频和步幅，你都在权衡速度与热量积累：跑得更快，体温升得更快，但散热能力是固定的。

## 交互（只有这一个）
读者拖动两个滑块——**步频**（120–180步/分钟）和**步幅**（0.8–1.5米）——实时看到追踪者奔跑速度变化、两个体温指示条上升、猎物在固定速度下体温上升更快。当猎物体温达到42°C，猎物倒下，追踪者胜出；若追踪者体温先达到42°C，追踪者失败倒地。读者从中形成的直觉：**散热能力决定了持久奔跑的胜负，而非瞬间速度**。

## 媒体
需要一张非洲草原上人类奔跑狩猎的实景照片（如桑族人持久狩猎），放在场景背景中作为视觉锚点，让读者看到“这不是抽象模拟，而是真实发生过的事”。图片出处标注在 `title` 属性中。

## 版面提示
canvas-full 版式，由 pixijs-2d 绘制整个场景：开阔的非洲草原背景（浅黄色调，远处有稀树），两个奔跑角色（追踪者人形，猎物羚羊形），两条体温指示条（红色渐变，从绿到红），两个滑块在画面底部控制步频和步幅。matterjs 处理追踪者的奔跑物理（身体起伏、步频步幅影响速度），pixijs-2d 渲染粒子效果（汗水蒸发、尘土飞扬）。
