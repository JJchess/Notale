# page-20 · 跳高角度 · **150 秒**

## 知识结构：process
六个 step，按时间顺序展开：从「推铅球」到「跳高」的直觉迁移 → 45° 的惯性思维 → 人体解剖约束介入 → 最佳角度落在 40–42° → 初速度与角度不是独立变量 → 感悟：人体的最佳不是抛物线的最佳。

显式化方式：一条横轴是起跳角度（35°–50°），三条曲线在同一画面上叠加——纯抛物线理论高度、实际人体可达高度（初速度随角度变化）、以及差值曲线。

## 表征形式
动态交互。读者拖拽一个双滑块（角度 + 初速度），上方 canvas 实时渲染跳高运动员的质心轨迹，三条曲线同步更新当前角度对应的点。初速度滑块不是完全自由的——它受一条预设的「力量-角度」曲线约束，体现人体在浅角度能爆发出更大初速度、在陡角度初速度下降的生理事实。

## 六个 step

### step 1：推铅球的直觉
推铅球最佳角度接近 45°，因为抛射点与落点在同一高度，且初速度不随角度变化。这是学完 p09/p10/p16 后读者已有的心理模型。

### step 2：跳高的第一直觉
把铅球模型迁移到跳高——质心从地面起跳，越过横杆时质心在杆上方，落点与起跳点有水平距离。仅按抛物线算，45° 仍然接近最优。

### step 3：人体不是铅球
人体起跳时质心已有初始高度（约 1.0 m，`Lec.P.getHominidData('sapiens').hipHeight` 或从 `Lec.K` 取典型值），且落点时质心可低于横杆（背越式）。这使最优角度比 45° 略低，约 43°–44°。

### step 4：初速度不是常数
关键转折：人体肌肉-骨骼系统在浅角度（35°–40°）能产生更大的腿部伸展初速度，在陡角度（>45°）初速度显著下降。原因是膝、踝关节力矩随角度变化。这一约束来自 p19 的力量-速度关系。

### step 5：两条曲线相交
理论最优（仅考虑几何）在 43°–44°，但初速度随角度递减的生理曲线使实际最优左移到 40°–42°。画面上两条曲线（理论高度 × 角度、实际高度 × 角度）的峰值点错开，差值曲线标出 40°–42° 区间。

### step 6：感悟
最佳跳高角度不是 45°，不是纯物理决定的，而是「人体能在这个角度上输出最大初速度」的那个点——约 40°–42°。

## 公式与常数

所有数值通过 `Lec.K` 或 `Lec.P` 获取，页面不硬编码。

- 地球重力加速度：`Lec.K.EARTH_GRAVITY`（9.8 m/s²）
- 人体起跳质心初始高度：`Lec.K.HUMAN_JUMP_TAKEOFF_CM_HEIGHT`（若常量表有）或 `Lec.P.getHominidData('sapiens').hipHeight`（约 1.0 m）
- 人体垂直跳跃初速度典型值：`Lec.K.HUMAN_JUMP_INITIAL_VELOCITY`（≈ 2.5 m/s，对应 90° 垂直跳）
- 横杆高度（可调，默认 2.0 m）：`Lec.K.HIGH_JUMP_BAR_DEFAULT_HEIGHT`
- 角度-初速度衰减曲线：`Lec.P.velocityAtAngle(angleDeg)` 返回该角度下人体可输出的最大初速度（基于 p19 的力量-速度数据拟合），算法在 `Lec.P` 中实现，本页调用即可。

**抛物线高度计算**（理论线）：
```
h_theory(angle, v0) = (v0² * sin²(angle)) / (2 * Lec.K.EARTH_GRAVITY)
```

**实际可达高度**（生理线）：
```
h_actual(angle) = h_theory(angle, Lec.P.velocityAtAngle(angle))
```

**横杆越过条件**（简化）：质心轨迹最高点 ≥ 横杆高度 + 质心与杆的最小间距（约 0.1 m，背越式补偿）。

## 必须点出来的三句

1. 抛体运动教我们 45° 最优——但那是铅球，不是人体。
2. 你的腿在浅角度能蹬出更大的初速度，所以最佳跳高角度落在 40°–42°。
3. 人体的最佳，不是抛物线的最佳——是「你能在这个角度上输出最大力量」的那个点。

## 交互（只有这一个）
**拖拽双滑块，看轨迹与曲线同步变化。**

- **角度滑块**（35°–50°，步长 0.5°）：读者拖动时，上方 canvas 中的跳高运动员质心轨迹实时重绘。起跳点固定，落点随角度变化。横杆高度固定。
- **初速度滑块**（1.5–3.5 m/s，步长 0.05 m/s）：读者拖动时，轨迹高度变化。但初速度滑块有**软上限**——当角度增大时，滑块的最大值自动降低，由 `Lec.P.velocityAtAngle(angle)` 约束。读者会感受到：角度越陡，能用的初速度越小。
- **三条曲线**：在当前角度位置显示一个竖线标记，三条曲线上的对应点高亮。
  - 理论线（灰虚线）：用当前初速度的满值，`v0_max` 不变，纯抛物线最优在 43°–44°。
  - 实际线（橙实线）：用 `Lec.P.velocityAtAngle(angle)` 的实际初速度，最优在 40°–42°。
  - 差值线（蓝虚线）：实际线减理论线，负值区显示生理代价。
- **直觉形成**：读者拖动角度时，看到实际线在 40°–42° 区间达到峰值，而理论线峰在 43°–44°；差值线在 >45° 时急剧下降，因为初速度衰减严重。

## 不许碰
- 不讲撑杆跳（撑杆是外加储能，不属人体自身跳跃）。
- 不讲空气阻力（p17 已证明影响 <2%）。
- 不讲背越式与俯卧式的技术细节（只提质心可低于横杆这一几何事实）。
- 不讲具体运动员数据或纪录（那是 p28 的职责）。
- 不讲训练如何改变力量-角度曲线（那是 p19 的延伸，本页用已建立的力量-速度关系）。
