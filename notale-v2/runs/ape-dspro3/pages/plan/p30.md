# page-30 · 微重力中的身体本能 · **120 秒**

## 知识结构：process
这一页显式化的是**从重力依赖到视觉依赖的转变**：
地球上 → 进入微重力 → 身体尝试走路（失败）→ 本能切换到手臂爬行 → 形成新的移动模式。

靠六个有序的事件来显式化：
1. 宇航员进入微重力环境
2. 身体试图用腿走路，脚无法着地
3. 身体开始漂移，失去方向感
4. 手臂本能地抓握扶手、舱壁
5. 上肢替代下肢成为主要移动器官
6. 形成稳定的手臂爬行模式

箭头上的连接问题是：**为什么腿不工作了？** 因为重力消失后，脚与地面的摩擦力消失，下肢的蹬地动作无法产生推进力，而上肢的抓握能力在任意方向上都有效。

## 表征形式
动态视频 + 交互标记。视频是真实 ISS 舱内宇航员移动的录像，学习者看到的是真实的身体在微重力下的行为，而不是抽象图解。标记点让学习者暂停、回看、识别关键动作转换，形成"身体在紧急情况下会自己找到解决方案"的心理表征。

## 六个事件：从走路到爬行的本能切换

1. **进入微重力**：宇航员从舱门进入 ISS 主舱段，身体开始漂浮。
   - 视频片段：舱门打开，宇航员推入舱内。
   - 标记点：时间戳 `t_entry`，标注"重力消失的瞬间"。

2. **尝试走路**：宇航员试图用脚接触舱壁，但脚无法稳定着地，身体弹开。
   - 视频片段：脚接触舱壁，身体被推开，没有产生有效的移动。
   - 标记点：时间戳 `t_attempt_walk`，标注"脚无法获取摩擦力"。

3. **身体漂移**：宇航员在没有约束的情况下，身体开始缓慢旋转或漂移。
   - 视频片段：身体横移，手臂张开但没有抓住任何东西。
   - 标记点：时间戳 `t_drift`，标注"方向感依赖视觉而非重力"。

4. **手臂本能伸出**：宇航员伸手抓住最近的扶手、带子或舱壁突出物。
   - 视频片段：手迅速伸出，抓住扶手，身体停止漂移。
   - 标记点：时间戳 `t_grab`，标注"上肢本能启动"。

5. **手臂替代下肢**：宇航员开始用手臂拉拽身体，从一个扶手移到另一个扶手，腿悬空不参与移动。
   - 视频片段：连续抓握、拉动、松手、再抓握的动作序列。
   - 标记点：时间戳 `t_arm_locomotion`，标注"手臂成为主要移动器官"。

6. **稳定爬行模式**：宇航员熟练地用手臂在舱内移动，腿自然弯曲跟随，脚不接触任何表面。
   - 视频片段：流畅的手臂爬行，身体在三维空间中移动自如。
   - 标记点：时间戳 `t_stable`，标注"新运动模式建立"。

每个事件在视频时间轴上对应一个时间戳，构建时通过 `scrubbing` 或 `markers` 让学习者可以点击标记跳转到对应时刻。时间戳由视频元数据决定，页面不写死。

## 必须点出来的三句

1. 微重力下，脚失去摩擦力，腿无法产生推进力——走路失效。
2. 手臂本能地替代下肢：抓握在任何方向上都能提供锚点和推进力。
3. 这具身体没有为太空设计，但演化赋予的上肢灵活性让它意外地胜任。

## 交互（只有这一个）
**播放 ISS 宇航员移动视频，标记关键动作。**

- 读者动什么：在视频播放条上看到六个标记点，点击标记跳转到对应事件；也允许拖拽播放进度连续观看。
- 看到什么变：视频跳转到对应时间点，同时画面侧边出现该事件的文字标注和简短解释（解释文字来自上面的"六个事件"）。
- 从中该形成什么直觉：身体在重力消失后不是"坏了"，而是自动切换到另一种早已存在于演化遗产中的运动模式——手臂爬行。这不是学来的，是本能的。

## 不许碰
- 骨骼流失（那是 p31 的内容）
- 肌肉萎缩（那是 p32 的内容）
- 微重力下的生理机制（钙流失、骨密度下降等）
- 长期适应的任何内容
- 不讨论宇航员训练如何改变运动模式，只聚焦本能反应

## 必用skill
web-media-getter, lottie-animations

## 媒体
需要一段 ISS 宇航员在舱内移动的真实视频，时长约 30–45 秒，包含从进入微重力到稳定手臂爬行的完整过程。NASA 或 ESA 公开的 ISS 舱内活动录像符合要求，例如宇航员在 Node 1 或 Destiny 实验室舱段内移动的片段。

真实视频比动画更好，因为：
- 学习者需要看到真实的人体在真实微重力下的行为，而不是动画模拟的理想化版本
- 手臂抓握的时机、身体漂移的速度、腿的悬空姿态，这些细节在动画中容易被简化或失真
- 真实视频传递了"这真的发生了"的认知冲击，动画无法替代

视频来源建议：NASA Image and Video Library 或 ESA Video Archive，搜索关键词 "ISS crew movement" 或 "astronaut moving in microgravity"，选择 CC 许可或公共领域素材。

## 版面提示
canvas-full 版式：视频占据画面主要区域，时间轴在底部，六个标记点沿时间轴分布，点击标记时对应的文字标注出现在视频画面侧边（不遮挡主体）。标记点使用小球或菱形标记，颜色与 ISS 舱内环境形成对比（如橙色或亮绿）。
