# page-35 · 宇航服跳跃高度—重力切换 · **120 秒**

kicker: `GRAVITY SWITCH`
主标题: **穿上宇航服，在月球上能跳多高？**

## 知识结构：process
这一页显式化的关系是**重力加速度 g → 跳跃高度 h**，在“穿着宇航服”这一固定质量条件下。学习者通过切换不同重力场景，观察跳跃高度的实时变化，建立“重力越小跳得越高，且宇航服质量会压低初速度但不会抵消低重力优势”的直觉。核心过程是：选定重力值 → 系统用合并质量重新计算初速度 → 计算跳跃高度 → 画面更新。

## 表征形式
动态交互式图表。左栏为重力场景选择器与当前参数读数，右栏为动态的跳跃高度对比示意图（人物从地面起跳的示意动画 + 高度柱状图）。重力切换时，人物跳跃动画的幅度和柱状图的高度同步变化，让学生直接看到 g 变小则 h 变大的反比关系。

## 重力场景与跳跃高度数据
本页涉及三个重力场景，所有数值从 `Lec` 获取，不得硬编码。

### 场景列表
- 地球：`Lec.K.EARTH_GRAVITY` = 9.8 m/s²
- 月球：`Lec.K.MOON_GRAVITY` = 1.62 m/s²
- 火星：`Lec.K.MARS_GRAVITY` = 3.7 m/s²

### 合并质量计算
总出舱活动质量 `Lec.K.TOTAL_EVA_MASS` = 200 kg（宇航员身体质量 `Lec.K.ASTRONAUT_MASS` ≈ 70 kg + 宇航服质量 `Lec.K.EVA_SUIT_MASS` ≈ 130 kg）。

穿着宇航服时，跳跃初速度会因质量增加而降低。设裸露身体在地球上的跳跃初速度为 `Lec.K.HUMAN_JUMP_INITIAL_VELOCITY` ≈ 2.5 m/s，则穿着宇航服时的初速度 v₀_suited 按动能守恒推算：v₀_suited = v₀_naked × sqrt(m_body / m_total)。页面需当场计算，公式为：
```
v0_suited = Lec.K.HUMAN_JUMP_INITIAL_VELOCITY * Math.sqrt(Lec.K.ASTRONAUT_MASS / Lec.K.TOTAL_EVA_MASS)
```

### 各场景跳跃高度
使用 `Lec.P.jumpHeightFromVelocity(v0_suited, gravity)` 计算：
- 地球：`Lec.P.jumpHeightFromVelocity(v0_suited, Lec.K.EARTH_GRAVITY)`
- 月球：`Lec.P.jumpHeightFromVelocity(v0_suited, Lec.K.MOON_GRAVITY)`
- 火星：`Lec.P.jumpHeightFromVelocity(v0_suited, Lec.K.MARS_GRAVITY)`

其中月球高度约 1.5 m（验证表里“一句话”的数值），火星高度约 0.66 m，地球高度约 0.04 m。

## 必须点出来的两句
- 在月球上，即使穿着 130 kg 的宇航服，跳跃高度仍可达约 1.5 m——是地球上裸露跳跃的近四倍。
- 宇航服质量会压低初速度，但低重力的优势远大于质量带来的损失。

## 交互（只有这一个）
**切换不同重力，观察宇航服跳跃高度。** 读者在左栏点选或拖拽重力场景（地球 / 月球 / 火星），右栏的人物跳跃动画和高度柱状图实时更新。动画中的人物从半蹲状态起跳，上升到对应高度后落下，柱状图同步伸缩并显示数值。从中该形成的直觉：重力加速度是跳跃高度的主导因素，宇航服质量会降低绝对高度，但低重力环境下仍远超地球表现。
