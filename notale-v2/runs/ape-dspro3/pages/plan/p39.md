# page-39 · 三维跳跃空间 · **120 秒**

## 知识结构：process
这一页显式化的是**跳跃高度作为三维参数空间中的函数**：初速度、重力、宇航服质量三个独立变量同时变化时，跳跃高度如何响应。学习者通过拖拽三个滑块改变输入，看到三维曲面上的一个点移动，从而理解“跳跃高度不是单一数字，而是一个由多个参数决定的面”。

具体靠一个三维坐标系来显式化：X 轴为初速度、Z 轴为重力加速度、Y 轴为跳跃高度，表面上通过颜色区分宇航服质量的影响。拖拽任意滑块，高亮球沿曲面移动，同时在曲面上留下一条对应二维切片的轨迹线。

## 表征形式
动态、可交互的三维曲面图。学习者需要建立的心理表征是“跳跃高度是一个曲面，由初速度和重力共同决定，而宇航服质量会把这个曲面整体向下平移”——三个参数不是孤立的，而是共同定义了一个三维空间中的函数形状。

## 三维参数空间中的点集

### 三条轴与取值范围
- **X 轴（初速度 v₀）**：0.5–4.0 m/s，刻度间隔 0.5 m/s。默认值取 `Lec.K.HUMAN_JUMP_INITIAL_VELOCITY`（≈2.5 m/s）。页面显示时标注该值的来源常量名。
- **Z 轴（重力加速度 g）**：0.5–10.0 m/s²，刻度间隔 0.5 m/s²。默认值取 `Lec.K.EARTH_GRAVITY`（9.8 m/s²）。页面显示时标注该值的来源常量名。
- **Y 轴（跳跃高度 h）**：由 X 和 Z 通过 `Lec.P.jumpHeightFromVelocity(v0, gravity)` 实时计算，单位为 m。Y 轴范围随当前曲面动态调整，确保高亮球始终可见。
- **宇航服质量 m_suit**：作为颜色维度叠加在曲面上，取值 0 到 `Lec.K.EVA_SUIT_MASS`（≈130 kg），步长 10 kg，通过一个独立滑块控制。默认值取 `Lec.K.EVA_SUIT_MASS`。页面显示时标注该值的来源常量名。

### 曲面计算公式
跳跃高度曲面由以下公式定义，页面通过 `Lec.P` 实时计算，不得硬编码：
```
h = Lec.P.jumpHeightFromVelocity(v0, gravity) - (m_suit / Lec.K.ASTRONAUT_MASS) * offsetTerm
```
其中 `offsetTerm` 为一个经验修正值，反映宇航服质量对初速度的削弱效应，算法为：
```
offsetTerm = 0.01 * m_suit / Lec.K.EVA_SUIT_MASS
```
（当 m_suit = 0 时，offsetTerm = 0；当 m_suit = Lec.K.EVA_SUIT_MASS 时，offsetTerm = 0.01 m。这个值很小，但乘以质量比后会在曲面上产生可见的向下偏移。）

### 曲面上的高亮球与轨迹线
- 三个滑块分别控制 v₀、g、m_suit，曲面上的一个红色球体实时移动到对应坐标 (v₀, h, g)。
- 当用户拖拽 v₀ 或 g 滑块时，在曲面上画出一条高亮线，对应“固定 m_suit 不变，只改变 v₀ 和 g”的二维切片。
- 当用户拖拽 m_suit 滑块时，曲面整体沿 Y 轴向下平移，同时颜色渐变（冷色→暖色），高亮球随之移动。

## 必须点出来的两句话
1. 跳跃高度由初速度和重力共同决定，是一个曲面，不是单一数字——换一个星球、换一件宇航服，你就在这个曲面上的不同位置。
2. 宇航服质量会把整个曲面往下压，但压低幅度很小——在低重力星球上，质量增加带来的损失远小于重力降低带来的收益。

## 交互（只有这一个）
**拖拽初速度、质量、重力，看三维跳跃空间。**

- 读者动什么：三个水平滑块，分别标有“初速度 v₀ (m/s)”“宇航服质量 m_suit (kg)”“重力加速度 g (m/s²)”，横跨页面底部。滑块初始位置对应默认值。右侧附带一个“重置”按钮，点击后所有滑块回到默认值、视角复位。
- 看到什么变：三维曲面在 canvas 中实时更新，红色高亮球沿曲面移动；曲面颜色随 m_suit 变化（从蓝色到橙色渐变）；一条半透明的轨迹线留在曲面上，显示当前参数组合下的二维切片路径。
- 从中该形成什么直觉：跳跃高度是三个参数共同决定的连续函数，不是一个固定值。初速度越大、重力越小、宇航服质量越轻，跳得越高——但三者之间存在权衡，读者可以自己“玩”出来，例如在低重力下即使穿很重的宇航服，仍然跳得比地球上高。

## 不许碰
不讲推导（p40 才会给出简化公式）。这一页只展示三维曲面和参数拖拽的结果，不解释公式如何从 `h = v₀²/(2g)` 变形而来，不出现“转移公式”的代数推导过程，不讨论“如果质量不变则 h₂ = (g₁/g₂) × h₁”（那是 p40 的内容）。页面上可以展示曲面由 `Lec.P.jumpHeightFromVelocity` 计算，但不展开函数内部逻辑。

## 媒体
需要一张生成插画：一位宇航员穿着现代宇航服，站在低重力星球表面（背景为灰白色地表、远处有环形山），正准备向上跳跃，身体微微下蹲、双臂后摆，动作瞬间定格。插画放在三维曲面下方或右侧作为视觉锚点，让读者在看到“m_suit 滑块”和“曲面下移”时，能立刻联想到“这就是穿着宇航服在低重力下跳跃的场景”。真实照片无法同时展示参数空间和跳跃动作，而插画可以把宇航服质量、跳跃姿态、低重力地表三个要素合成在一个画面中，比示意图或照片更能帮助读者建立“参数调整对应真实场景”的心理连接。

## 版面提示
- 三维曲面占据 canvas 主体（约占页面 70% 面积），使用 `canvas-full` 版式，背景为深色以突出曲面和高亮球。
- 三个滑块并排置于页面底部，横跨整个宽度，左侧标注参数名和当前值，右侧为“重置”按钮。
- 插画放在 canvas 右下角，半透明叠加或作为小卡片嵌入，尺寸不超过 canvas 的 1/4，不遮挡曲面上的高亮球。
