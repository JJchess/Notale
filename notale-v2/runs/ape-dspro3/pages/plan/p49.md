# page-49 · 低重力翻跟头 · **100 秒**

## 知识结构：process
这一页显式化的是**角动量守恒与视觉参照的冲突**：人体在低重力下旋转时，角动量守恒让旋转持续，但视觉参照（地面、天空、地平线）与地球经验完全不同，导致方向感丧失。通过六个事件展示：初始跳起 → 收拢身体加速旋转 → 角动量守恒维持旋转 → 视觉参照混乱 → 姿态调整尝试 → 最终稳定。事件之间的箭头是因果链，每个箭头上挂着一个物理量变化（转动惯量、角速度、姿态角）和一个感知量变化（视觉参照匹配度）。

## 表征形式
动态交互：全屏canvas模拟低重力环境，一个人形角色在空中翻转，身体姿态（四肢收拢/伸展）由读者拖拽控制，转动惯量实时变化，角速度随之自动调整以保持角动量守恒。背景是低重力星球的简化地面和天空，提供视觉参照。

## 六个事件
1. **初始跳起**：角色从地面跳起，初始角速度≈0.5 rad/s，姿态为四肢微张，转动惯量I₀（对应 `Lec.K` 中人体站立转动惯量，身体质量取 `Lec.K.ASTRONAUT_MASS` ≈ 70 kg，人体等效半径约0.3 m，I₀ ≈ 70 × 0.3² = 6.3 kg·m²，由 `Lec.P` 计算）。重力取 `Lec.K.MOON_GRAVITY` = 1.62 m/s²。

2. **收拢身体加速旋转**：读者拖拽滑块将四肢向内收拢，转动惯量从I₀降至I_min（约2.5 kg·m²，对应四肢紧贴身体的姿态），角速度从ω₀升至ω₀ × (I₀/I_min) ≈ 0.5 × 2.52 = 1.26 rad/s。角动量 L = I₀ω₀ = 3.15 kg·m²/s 保持恒定。

3. **角动量守恒维持旋转**：在空中飞行期间（飞行时间由 `Lec.P.jumpHeightFromVelocity` 和月球重力反推，典型初速度2.5 m/s，飞行时间约2 × 2.5/1.62 ≈ 3.1 s），角色持续旋转，角动量守恒确保角速度只随转动惯量变化，不因重力而改变。

4. **视觉参照混乱**：背景画面显示地面和天空交替出现，旋转频率约0.2 Hz（对应1.26 rad/s）。画面上叠加一个**方向感指标**：角色当前“上方”与重力方向的夹角，以及这一夹角的变化率。夹角变化率与旋转同频，视觉参照匹配度（0-1，由 `Lec.P` 根据夹角与预期值的偏差计算）持续波动。

5. **姿态调整尝试**：读者拖拽四肢伸展，转动惯量回升至I₀，角速度降至0.5 rad/s，旋转减慢。但方向感指标显示，即使旋转减慢，视觉参照的混乱仍持续，因为身体已经失去对“上”的稳定感知。

6. **最终稳定**：角色落地（模拟落地瞬间的冲击，由 `Lec.P` 计算落地速度），姿态恢复站立。画面上对比：落地时的实际姿态与预想姿态的偏差（以角度偏差度量，典型值可达30°-60°），说明视觉参照混乱导致的方向迷失。

## 公式与常数
- **角动量守恒**：L = Iω = 常数，I为转动惯量，ω为角速度。转动惯量变化通过 `Lec.P` 函数 `Lec.P.momentOfInertia(bodyMass, radius, limbExtension)` 计算，其中 `limbExtension` 为0-1的归一化参数（读者拖拽的滑块值）。
- **角速度更新**：ω_new = L / I_new，每次I变化时实时计算，L由初始状态锁定。
- **视觉参照匹配度**：`Lec.P.visualReferenceMatch(actualUpAngle, expectedUpAngle, tolerance)` 返回0-1，tolerance取30°（正常人类可接受的方向偏差范围）。
- **飞行时间**：`Lec.P.flightTime(v0, gravity)` 返回2v₀/g，v₀取 `Lec.K.HUMAN_JUMP_INITIAL_VELOCITY` ≈ 2.5 m/s。
- **重力**：`Lec.K.MOON_GRAVITY` = 1.62 m/s²。
- **身体质量**：`Lec.K.ASTRONAUT_MASS` ≈ 70 kg。
- **转动惯量范围**：I_min ≈ 2.5 kg·m²（四肢紧贴），I_0 ≈ 6.3 kg·m²（四肢微张），I_max ≈ 12.5 kg·m²（四肢完全伸展），由 `Lec.P` 根据质量分布计算。

## 必须点出来的三句
1. **角动量守恒让身体一旦开始旋转就不会自己停下，低重力让旋转持续更久，但旋转本身不是问题。**
2. **问题在于方向：地面和天空的交替出现让大脑失去“上”的参照，身体的本能反应与重力方向脱节。**
3. **低重力下的运动需要重新学习视觉参照，演化没有为我们准备这份感知，但训练可以弥补。**

## 交互（只有这一个）
**模拟低重力下翻跟头，调整身体姿态**：
- 读者拖拽一个**身体姿态滑块**（0 = 四肢完全伸展，1 = 四肢紧贴身体），控制角色的转动惯量。
- 角色在月球重力环境下飞行，角速度根据角动量守恒实时变化：收拢身体 → 转得快，伸展身体 → 转得慢。
- 画面上同时显示**方向感指标**：一个箭头指向角色认定的“上方”，与实际重力方向对比，偏差越大，箭头颜色越红（从绿色到红色渐变）。
- 读者从中形成的直觉：**低重力下，身体旋转遵循物理规律，但方向感会被视觉参照的快速变化打乱，收拢身体加速旋转会让方向迷失更严重，伸展身体可以减缓旋转但无法恢复方向感。**
