# 页面构建契约

## 1. 文件边界

- 只创建或修改分配给你的 `pages/page-NN.html`。
- 不读、不改、不复制任何其他 `page-*.html`。
- 共享依据只有 `CONTRACT.md`、`PLAN.md`、`assets/theme.css`、`assets/lec.js`；底盘接口另读 `assets/CHASSIS.md`，不得转抄。
- 需要技法且 Skill 清单已有对应文档时，先用 `Skill` 读取，再写页面。
- 每页必须自包含；通过 `file://` 直接打开即可显示和交互；资源只用相对路径，禁止 CDN、网络请求和运行时下载。
- 只交付该 HTML；不新增说明、测试、总结或其他文件。

## 2. 固定 HTML 骨架

照抄以下结构。只替换 `NN`、`TT`、页面元信息、所需本地库和 `#stage` 内正文；页面脚本必须放在全部依赖之后。

```html
<!doctype html>
<html lang="zh">
<head>
  <meta charset="utf-8">
  <link rel="stylesheet" href="assets/base.css">
  <link rel="stylesheet" href="assets/theme.css">
  <!-- 仅在需要时引入库的 CSS -->
</head>
<body data-page="NN" data-total="TT">
  <div id="stage">
    <!-- 本页正文只放这里 -->
  </div>
  <script src="assets/base.js"></script>
  <script src="assets/lec.js"></script>
  <!-- 仅在需要时引入本地库；依赖库在前 -->
  <script>
    Lec.mount({
      index: NN,
      kicker: "栏目",
      title: "本页标题",
      take: "一句带走的话"
    });
    // 本页逻辑
  </script>
</body>
</html>
```

- 全套固定为 `TT=48`。
- `Lec.mount()` 只调用一次。
- 页眉、页脚、主区由 `Lec.mount()` 生成；不得自行生成、改名或复制 `.lec-header`、`.lec-footer`、`.lec-main`、`.lec-header-inner`、`.lec-kicker`、`.lec-title`、`.lec-subtitle`、`.lec-progress`、`.lec-footer-inner`、`.lec-take`、`#main`。
- 页面只往 `#stage` 添加内容。页眉页脚外观及占位由 `theme.css` 决定；内容区高度按其中两条带的高度计算，不得覆盖这些结构的样式。
- 不删除底盘或主题类，包括 `lec-root`、`lec-page`、`min0`、`cv-fill`；不覆盖其定位、缩放、溢出或尺寸职责。
- 禁止 `position: fixed`；需要定位时用正常流、flex，必要时用相对容器内的 `position: absolute`。
- 默认使用 flex。只有矩阵、维度表等确需二维对齐时才用 grid。
- 需要计算坐标才能排版时，先改结构。拖拽位移用 `transform`，不改 `left/top`；刻度、滑块、标签拆成稳定区块，不靠绝对坐标凑齐。

## 3. 受众与语言

- 读者是大学一年级通识课学生，文理混合；不得假定微积分、生物学或专业术语基础。
- 首次出现的必要术语必须就地用一句白话解释；非必要术语删除。
- 先说现象或问题，再给概念；公式旁必须说明每个符号表示什么以及结果如何读。
- 不以“显然”“容易知道”“大家都懂”跳步。
- 单个说明句不超过 32 个汉字；连续说明不超过 3 句，之后用图、步骤或交互承接。
- 提示语使用直接、平等、可操作的口气，如“拖动滑块，观察曲线”；禁止幼儿化、训诫式或含糊指令。
- 页面必须同时适合教师课堂讲解和学生课后独立重看：关键结论不能只靠教师口头补充，操作后必须有可见反馈和一句解释。
- `take` 只写一个可独立理解的核心结论，不写口号。

## 4. 版面与密度预算

设计画布固定为 `1600 × 900`。

每页必须同时满足：

- 正文汉字及标点总量：80–260 字；标题、刻度、按钮文字和代码不计入。
- 可操作控件：1–6 个；同一组选项按每个可聚焦操作项计数。
- 页面文本块总数：20–70 个；包括标题、正文、刻度、图例、图注、标签、按钮、输入提示和读数。
- 画面占用比：≥45%。
- 核心教学区域不超过 3 个；主视觉只能有 1 个。
- 同屏长期显示的独立读数不超过 8 个。
- 正文超过 260 字、控件超过 6 个或文本块超过 70 个时，必须报告“本页预算超限”，停止用缩字、密排、裁切或隐藏来塞入；应删减内容或要求拆页。
- 文本块少于 20 或占用比低于 45%时，不得靠放大字号、增加装饰或拉大空隙补足；必须展开过程、增加有效维度或补充必要解释。
- 不为达到下限添加无教学作用的图标、背景粒子、重复结论或虚假控件。

## 5. 字号与主题

- 数字刻度：≥12px。
- 带词句的刻度、标签、图例、图注：≥14px。
- 正文、按钮、输入提示、tooltip、读数说明：≥16px。
- KaTeX 基准字号：≥20px。
- 正文行高：≥1.35。
- 这些是设计坐标中的下限。1600 宽舞台在 1366 宽屏上按 `1366/1600≈0.854` 整体缩放，屏幕实际字号约为设计字号的 85%；因此不得再降低设计字号。
- 所有颜色、字体、阴影、圆角、边框、间距和层级从 `assets/theme.css` 的变量及现有类取得；禁止另建配色、字体体系或全局 reset。
- 页面局部 CSS只能描述本页结构和图形，不得覆盖 `body`、底盘、页眉页脚或主题类的职责。
- 对比度不能只靠颜色表达；状态至少再用文字、形状、线型或图案之一表示。

## 6. 数字与计算

- 页面展示的事实数值、输入初值、推导结果、百分比、单位换算、时间、距离、能量及进度一律由 `Lec` 函数计算并格式化，禁止把计算结果直接写死在 HTML、SVG、canvas 标签或说明句中。
- 页号与总页数也从当前页配置传入 `Lec.mount()`，进度使用 `Lec.progressFraction` 或 `Lec.progressPercent`。
- 只允许写入公式所需的原始参数；凡 `Lec` 已提供对应函数，必须调用，不得重复实现。
- 展示值与交互计算必须来自同一数据源；状态变化后同步更新文字、图形和结论。
- 禁止假数据、预录结果、预先画好的“计算过程”冒充实时计算。
- 随机数据必须引入 `seedrandom.min.js` 并使用固定种子，种子建议为页面号；禁止 `Math.random()`。

## 7. 底盘、canvas 与动画

底盘全部接口先读 `assets/CHASSIS.md`。

- canvas 尺寸与高分屏适配一律使用 `Deck.fit` 或 `Deck.autofit`。
- 指针坐标一律使用 `Deck.pt`。
- 动画循环一律使用 `Deck.loop`。
- canvas 取色一律使用 `Deck.rgb` 或 `Deck.rgba`。
- 禁止自行实现 `devicePixelRatio` 缩放、`getBoundingClientRect` 坐标换算或 `requestAnimationFrame` 主循环。
- canvas 的 CSS 显示尺寸、内部缓冲尺寸和逻辑坐标必须在舞台缩放及窗口变化后保持一致；不得用仅适合当前屏幕的固定像素缓冲。
- 使用 Konva 时让其处理指针换算，不再叠加 `Deck.pt`；场景标签优先用 DOM 覆盖层，避免 `Konva.Text`。确需 `Konva.Text` 时显式满足字号下限。
- 每个动画必须检测 `prefers-reduced-motion: reduce`：停止持续运动，直接显示稳定终态或改为用户触发的单步变化。
- 动画不得承载唯一信息；暂停后仍能读懂。
- 页面失焦、元素不可见或被销毁时停止无意义计算。
- 所有鼠标交互必须有键盘等价操作。原生控件优先；自定义控件需可聚焦，支持 Enter/Space 或方向键，具有可见焦点和准确的 `aria-label`。
- 拖拽必须另有键盘微调或按钮替代；反馈不得只在 hover 时出现。

## 8. 库使用

动手前先查 `assets/lib/LIBS.md`；版本以该文件为准，禁止去压缩库内查版本。已有库能完成的呈现工作，不得从底层重写：

- 常规坐标轴、刻度、图例、折线、柱、散点、面积、饼、热力：ECharts。
- 可拖拽、需命中检测的二维场景：Konva。
- 三维：Three。
- 下落、碰撞、摆动、堆叠、约束：Matter。
- 节点连线、数据驱动矢量图：D3。
- 成千上万元素同时运动：PixiJS。
- 分步动画：anime.js；精确时间线：GSAP。
- 数学公式：KaTeX。
- 矩阵运算：ml-matrix。
- 页面实时训练小型二分类网络：`mlp.js`；真实图片卷积、预训练模型或 GPU 大矩阵才用 TensorFlow.js。

引用规则：

- 只引用实际使用的库，路径为 `assets/lib/xxx`，不得复制库。
- 库放在 `base.js`、`lec.js`之后、本页脚本之前。
- 依赖顺序必须满足：Three→Globe/Vanta；GSAP→ScrollTrigger。
- KaTeX 必须同时引入 `katex.min.css` 与 `katex.min.js`。
- ECharts 必须 `echarts.init(el, null, {renderer:'svg'})`；数字刻度≥12px，带词刻度、轴名、图例≥14px，tooltip及正文类文字≥16px。
- TensorFlow.js 每步必须置于 `tf.tidy()` 或显式 `dispose()`；用 `tf.memory().numTensors`确认张量数不持续增长。
- 库只负责呈现不等于可伪造计算；交互背后的物理量、计数、训练或积分必须真实执行。

## 9. 交互标准

真交互必须同时满足：

1. 用户可改变一个有教学意义的变量、状态、步骤或视角。
2. 图形或模型依据输入重新计算，而非只切换预制图片。
3. 反馈在 100ms 内出现；重计算较慢时显示明确状态。
4. 页面就地说明“变了什么、为什么”。
5. 重置后恢复确定的初始状态。
6. 在允许输入范围内，标题、说明和结论始终为真。

仅有 hover 发光、按钮波纹、背景跟随指针、自动播放、装饰粒子、翻卡片看同一句话，不算真交互。装饰不得占用控件预算，不得抢占主视觉，不得在 reduced-motion 下持续运动。

## 10. 完工自检

在 `pages/` 目录执行：

`python3 assets/selfcheck.py page-NN.html`

对每个控件的初态、边界值、重置态和至少一个中间态，再用：

`python3 assets/selfcheck.py page-NN.html --after "<触发交互的 JS>"`

交付前必须全部满足：

- 无 JS 异常、控制台错误、资源加载失败和外部请求。
- 无元素超出 1600×900、被裁切或非预期遮挡。
- 无文字叠压；焦点、tooltip、读数和交互后新增内容均不重叠。
- 字号最低值符合各档下限，正文行高≥1.35。
- 画面占用比≥45%，文本块为20–70个，无占比不足1%的无意义小容器。
- 1366×768 缩放下指针、拖拽、tooltip和canvas命中位置正确。
- 键盘可完成全部操作，焦点清晰，重置有效。
- reduced-motion 分支可用。
- 所有展示数字与计算一致；固定种子下每次打开结果相同。
- 所有交互边界输入均无 NaN、Infinity、失控动画或错误结论。

自检只报告、不修复。发现任一问题即修改本页并重跑，直到所有初态和交互态报告干净为止。
