# page-04 · 人类该放进哪一层？ · **125 秒**

## 照这个写
`Lec.mount({index: 4, kicker: "CLASSIFY THE HUMAN", title: "人类该放进哪一层？", take: "“人、猿、猴”不是三级台阶，人类属于大型类人猿的一支。"});`

## 知识结构：classification
把“从猴到猿再到人”的错误并列改成集合嵌套：最外层“灵长类”，内含“猴类”和“类人猿”；“类人猿”内含“小型类人猿”和“大型类人猿”；人类卡最终进入“大型类人猿”。层级容器始终可见，不用箭头暗示升级。

## 表征形式
动态交互的 stage-cards：底部物种卡拖入中央嵌套集合。集合采用可容纳的分层框，而非三张并排等级牌；右侧仅显示当前归类路径。

## 层级里的各项

| 卡片或集合 | 归属路径 | 画面标签 |
|---|---|---|
| 灵长类 | 最外层集合 | 灵长类 |
| 猴类 | 灵长类 ＞ 猴类 | 猕猴 |
| 类人猿 | 灵长类 ＞ 类人猿 | 类人猿 |
| 小型类人猿 | 灵长类 ＞ 类人猿 ＞ 小型类人猿 | 长臂猿 |
| 大型类人猿 | 灵长类 ＞ 类人猿 ＞ 大型类人猿 | 红毛猩猩、 gorilla、黑猩猩、人类 |
| 人类卡 | 灵长类 ＞ 类人猿 ＞ 大型类人猿 | 人类 Homo sapiens |

## 必须点出来的一句
“人类”不是排在“猿”之后的新等级；在生物分类上，人类就在大型类人猿之中。

## 交互（只有这一个）
读者拖动六张物种卡进入嵌套集合，归类路径随落点点亮，形成“类别可以一层套一层，人类没有跳出猿类”的直觉。

做对了立刻看到什么：卡片吸附进对应区域，强调色描边闪亮一次，右侧接通完整路径。  
做错了立刻看到什么：卡片左右轻抖后回弹；提示“这个落点把并列类别当成了上下级，再看它位于‘类人猿’的哪一层。”  
做到哪儿了怎么知道：顶部显示“已归类 3 / 6”，对应六个小格逐个由暗转亮。  
做完了怎么收：所有卡片淡化为背景，只保留“人类 ＞ 大型类人猿 ＞ 类人猿 ＞ 灵长类”的发光嵌套路径与核心句；提供“重新归类”按钮一键复位。

## 场景构图
使用“分叉后重新连结的谱系线”和“从个体延伸到协作网络的发光节点”母题，但只表达分类包含关系。深暗标本室般的舞台中央悬浮三层青绿色嵌套框，边缘像科学标注板；六张物种卡沿底部弧形托盘排开。人类卡使用强调色边缘，但尺寸与其他卡一致，避免视觉上成为顶点。

## 动效
入场：外层集合先从暗处显影，内层框由外向内依次展开，物种卡随后从底部错峰上滑。  
反馈：正确时吸附、描边脉冲并沿归类路径流过一道光；错误时短促抖动、落点边框转暗红后回弹。

## 不许碰
不出现“约 600万—700 万年前”等共同祖先年代，不画祖先节点，不解释人类与黑猩猩何时分开，也不讨论“人由今天的黑猩猩变来”的误解；这些留给 p06。不得把分类集合画成从低到高的台阶。
