# page-10 · 演化没有终点 · **112 秒**

## 照这个写
`Lec.mount({index: 10, kicker: "DEFINE EVOLUTION", title: "演化没有终点", take: "演化只描述群体中可遗传差异随世代改变，不承诺进步或目的。"});`

## 知识结构：classification
用对齐的六行陈述把说法分入“符合定义”或“偷加了进步／目的”两类。分类依据固定显示在双列上方：左列“群体差异、可遗传、跨世代改变”；右列“更高级、为了、必然、需要”。

## 表征形式
交互式分类台账。六条陈述居中逐条出现，学习者点击左右类别；已判断项留在对应列中，形成一张可回看的定义边界表。

## 层级里的各项

| 陈述 | 正确分类 | 判定反馈 |
|---|---|---|
| 一个群体中某些可遗传差异，经过多代后变得更常见。 | 符合定义 | 描述了群体中可遗传差异随世代改变。 |
| 个体为了适应环境，在一生中进化出需要的特征。 | 偷加目的 | 个体一生中的改变不等于群体跨世代演化，“为了需要”还预设了目的。 |
| 演化可能使某特征更适合当时环境，也可能在环境改变后成为负担。 | 符合定义 | 适合度取决于具体环境，不等于永久进步。 |
| 演化最终会把生物变得越来越复杂、越来越高级。 | 偷加进步 | 演化没有预设的复杂化方向或等级终点。 |
| 若群体中可遗传差异的比例跨世代改变，就发生了演化。 | 符合定义 | 这是本页采用的操作性表述。 |
| 人类出现是演化早已设定好的目标。 | 偷加目的 | 演化过程不预先指向人类或任何终点。 |

## 必须点出来的一到三句
演化描述的是群体跨世代发生的变化，不是个体“努力改变”。  
“更适合某个环境”不等于“更高级”，演化也没有预定目标。

## 交互（只有这一个）
读者为每条陈述点击“符合定义”或“偷加进步／目的”，看到陈述归入双列台账，由此建立演化定义的边界。

- 做对了立刻看到什么：卡片吸附进所选列，强调色描边亮起，显示对应判定反馈。
- 做错了立刻看到什么：卡片水平抖动后留在中央；提示原话为表中对应反馈，末尾追加“请换一类”。
- 做到哪儿了怎么知道：顶部显示“已判断 3 / 6”，六枚细线节点随完成逐枚点亮。
- 做完了怎么收：两列之间浮现“改变 ≠ 进步；过程 ≠ 目的”，页脚 take 同步高亮；提供“重新判断”一键清空并回到第一条。

## 场景构图
使用“分叉后重新连结的谱系线”母题：深暗背景上，一条青绿色谱系线从页底进入，在分类台账下方分成两路；它不是生物分支图，而是把六条判断结果导向两类定义边界。中央是窄长陈述托盘，左右为深色台账列；当前卡片与进度节点使用强调色，其他结构保持主色相。

## 动效
- 入场：分类依据先由上向下显现，谱系线随后从页底生长并分流，六张卡片依次从中央后方轻微上移入场。
- 反馈：正确时卡片沿谱系线滑入并短促发光；错误时原位抖动两次，错误关键词以强调色闪现一次。
