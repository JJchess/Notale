# CONTRACT.md

## 1. 工作边界

- 只创建或修改分配给你的 `pages/page-NN.html`。
- 不读取、不搜索、不比较任何其他 `page-*.html`。
- 只读取本契约、`PLAN.md`、`assets/theme.css`、`assets/lec.js`、所需技法文档，以及下文明确指向的共享文档。
- 底盘接口只读 `assets/CHASSIS.md`，不得把其内容复制进页面或其他文件。
- 不修改共享资源，不新增文档、测试、总结或无关资源。
- 最终只交付这一个 HTML 文件。

## 2. 固定 HTML 骨架

保留以下节点、属性和加载顺序。只替换 `NN`、可见标题和 `#stage` 内正文；确有需要时，仅可加入本地库引用、页内样式和页内脚本。

    <!doctype html>
    <html lang="zh">
    <head>
      <meta charset="utf-8">
      <link rel="stylesheet" href="assets/base.css">
      <link rel="stylesheet" href="assets/theme.css">
    </head>
    <body data-page="NN" data-total="48">
      <div id="stage"></div>
      <script src="assets/base.js"></script>
      <script src="assets/lec.js"></script>
    </body>
    </html>

- 骨架里只有空的 `#stage`，没有统一页眉、页脚或 `mount()`；不得自行加入全套固定框架。
- 标题位置、组件组合和页面结构按本页内容决定。
- 所有页面必须保留 `#stage`，不得改名、替换或移出 `body`。
- 页面必须可从 `file://` 直接打开并完整显示、计算和交互；资源只用相对路径，不用 CDN。
- 库脚本放在 `base.js`、`lec.js` 之后、页面脚本之前；有依赖的库严格按依赖顺序加载。
- 只引用实际使用的库。

## 3. 画布与布局

- 设计画布固定为 `1600 × 900`。
- `#stage` 是 flex 列。放入其中的每个顶层区域必须有固定高度或明确 `flex` 份额；主内容区必须 `flex:1`。
- 顶层区域不得仅靠内容自然取高，不得在底部留下无归属死空间。
- 默认使用 flex；只有矩阵、维度表等确需二维对齐时才用 grid。
- 一次性尺寸可写内联样式，不为一次性对象发明类名。
- 需要计算坐标才能对齐时，先改结构：拖拽以 `transform` 偏移并保留正常流位置；刻度、滑块拆成相邻区块，不用 `left/top` 凑齐。
- 禁止在缩放舞台内使用 `position:fixed`；需要固定在容器内时使用 `position:absolute`。
- 不得删除 `base.css` 或主题提供的类，不得 `classList.remove()` 移除 `min0`、`cv-fill`、`no-pan` 等类，也不得覆盖这些类的定位属性。
- 页面画面占用比必须 `≥45%`。
- 占用不足时增加真实的信息层次、维度或过程，不得靠放大字号、拉大间距或添加纯装饰撑满。

## 4. 内容与密度预算

以下均为硬限制：

- 正文说明文字：每页最多 `320` 个汉字；标题、短标签、刻度和按钮文字不计入。
- 单个说明段最多 `90` 个汉字，单句最多 `45` 个汉字。
- 可操作控件最多 `6` 个；同组单选项按各自一个控件计。
- 页面文本块总数必须为 `20–70` 个，包含标题、正文、标签、图注、刻度、图例、按钮、读数和提示。
- 不得用 canvas 文字规避文本块统计。
- 超过预算时必须删减、合并或拆页，并明确判定“本页超预算”；禁止缩字号、压行高、减字距或强塞。
- 文本块不足时补足有教学价值的结构、对照、步骤、读数或解释，不加重复标签和装饰文字。
- 图例、刻度和读数应去重；常规图表让库自动抽稀刻度。

## 5. 字号与可读性

所有最终渲染文字必须满足：

- 纯数字刻度：`≥12px`。
- 标签、图注、图例、带词句的刻度：`≥14px`。
- 正文、提示、按钮、输入说明、tooltip：`≥16px`。
- 正文行高：`≥1.35`。
- KaTeX 基准字号统一 `≥20px`。
- 禁止依靠浏览器缩小、CSS transform 缩小文字或负字距规避限制。

`1600×900` 舞台在 `1366×768` 屏幕上的等比系数约为 `min(1366/1600,768/900)≈0.853`。因此设计字号会在课堂常见屏幕上缩至约 `85%`；以上地板按设计坐标检查，不得再下调。

## 6. 受众与语言

- 受众是大学一年级通识课学生，文理混合。
- 不假定微积分、生物学或专业工程背景。
- 首次出现的必要术语必须就地用一句通俗中文展开；未解释的缩写、符号和专业黑话不得出现。
- 先讲可观察现象或问题，再给名称、关系或模型。
- 公式必须同时给出符号含义和一句自然语言解释；不得只放公式。
- 不要求学生凭空完成专业推导；交互任务应能通过观察、比较、拖动或选择完成。
- 页面供教师课堂带讲，也供学生课后独立重看：关键结论必须留在页面上，不能只依赖教师口述或动画瞬间。
- 提示语使用直接、平等的口气，如“拖动并观察”“比较两次结果”；不用考试式威吓、幼儿化口吻或含糊的“点这里看看”。
- 说明句一次只表达一个动作或因果关系。

## 7. 主题与数据

- 所有颜色、字体、圆角、阴影、边框和间距从 `theme.css` 的 token 与现有骨架类中选取。
- 不自创配色、字体体系、间距体系或另一套组件外观。
- `theme.css` 是可拼装的 token 和骨架类，不是固定页面框架。
- 所有教学数据、物理常量、计算输入、结果和页面可见数字必须来自 `Lec.K` 或 `Lec.P`，不得在 HTML、CSS 文案或页面脚本中写死。
- 页码、画布尺寸、字号、布局尺寸、数组索引和库配置等非教学数值不受上一条限制。
- `assets/lec.js` 只提供 `Lec.K` 与 `Lec.P`，不提供版面。
- 计算必须真实执行；不得用假数据、预录动画或写死结果冒充计算。
- 随机数据必须引用 `seedrandom.min.js` 并使用固定种子，种子建议含页号；同页每次打开结果必须一致。

## 8. 库与技法

动手前先按任务查 `assets/lib/LIBS.md`。已有库能完成的呈现工作，禁止从底层重写：

| 任务 | 必用库 |
|---|---|
| 坐标轴、刻度、图例、折线、柱、散点、面积、饼、热力 | ECharts |
| 可拖拽、需命中检测的二维场景 | Konva |
| 三维场景 | Three.js |
| 三维地球 | Three.js 后加载 globe.gl |
| 下落、碰撞、摆动、堆叠、物理约束 | Matter.js |
| 节点连线、数据驱动矢量图形 | D3 |
| 成千上万元素同时运动 | PixiJS |
| 分步动画、路径、形变 | anime.js |
| 多动画时间线 | GSAP |
| 滚动绑定动画 | GSAP 后加载 ScrollTrigger |
| 数学公式 | KaTeX |
| 矩阵运算 | ml-matrix |
| 页面实时训练小型二分类网络 | `mlp.js` |
| 预训练模型、真图片卷积或 GPU 大矩阵 | TensorFlow.js |

- 版本只以 `assets/lib/LIBS.md` 为准，不读取压缩库文件查版本。
- 库一律用 `assets/lib/xxx.js` 本地相对路径。
- ECharts 必须以 `echarts.init(el,null,{renderer:'svg'})` 初始化，并显式设置：全局文字 `≥16px`，纯数字刻度 `≥12px`，带词刻度、轴名、图例 `≥14px`，tooltip `≥16px`。
- Konva 主要绘图形；标签优先用绝对定位的 DOM 叠加。确实必须随图形变换的短文字才可用 `Konva.Text`，并显式设置合规字号。
- KaTeX 必须同时引用 `assets/lib/katex.min.css` 与 `assets/lib/katex.min.js`，基准字号 `≥20px`。
- 小型逐帧训练使用 `mlp.js`，不得用 TensorFlow.js 替代，也不得重写一套网络训练器。
- 使用 TensorFlow.js 时，每步必须置于 `tf.tidy()` 中或手动 `dispose()`，并确认 `tf.memory().numTensors` 不持续增长。
- 清单中存在对应技法文档时，必须先用 `Skill` 读取再编码；没有对应文档时才自行实现。

## 9. Canvas、缩放与动画

- 原生 canvas 一律使用 `Deck.fit` 或 `Deck.autofit` 适配 CSS 尺寸、舞台缩放和高分屏。
- 原生 canvas 指针坐标一律使用 `Deck.pt`。
- 动画循环一律使用 `Deck.loop`。
- canvas 取色一律使用 `Deck.rgb` 或 `Deck.rgba`。
- 禁止自行实现 `devicePixelRatio` 缩放、`getBoundingClientRect()` 指针换算或 `requestAnimationFrame()` 主循环。
- 使用 Konva 时使用其舞台指针接口，不重复进行坐标换算。
- canvas 内不得承担主要正文、图例或说明；必要短标注也必须显式满足字号地板。
- 动画必须提供 `prefers-reduced-motion: reduce` 分支：停止持续运动和自动循环，直接显示稳定且有意义的最终状态；交互触发的状态变化仍须可见。
- 页面隐藏、组件卸载或重置后，不得残留重复循环、计时器或事件监听。

## 10. 交互标准

真交互必须同时满足：

- 用户可通过拖动、点击、选择、输入或键盘操作改变模型输入或状态。
- 页面根据输入重新计算真实结果。
- 视觉结果、数值读数或解释至少有一项立即更新，且变化与输入有可解释关系。
- 有明确操作提示、当前状态和重置方式。
- 允许扰动范围内，页面上的解释始终成立。

以下不算真交互：

- 仅 hover 发光、倾斜、视差、淡入或粒子跟随。
- 点击后只播放预录动画。
- 控件能动但不改变计算、结论或可观察结果。
- 自动循环而用户不能改变条件。

键盘可达要求：

- 所有可点击或拖动操作必须有原生控件或等价键盘入口。
- 自定义控件必须可聚焦，具有适当 `role`、可读名称和当前值。
- Enter/Space 可激活按钮；方向键可调整连续或离散值。
- 焦点样式必须清晰，不得移除。
- 状态不能只靠颜色区分；同时使用文字、形状、位置或纹理。

## 11. 完工自检

在 `pages/` 目录运行：

    python3 assets/selfcheck.py page-NN.html

对每个按钮、拖拽终点、极值输入、重置状态和动画结束状态，使用一个或多个：

    python3 assets/selfcheck.py page-NN.html --after "<触发该状态的 JS>"

必须逐项达到：

- 无 JavaScript 错误。
- 无资源加载失败或外部网络请求。
- 无元素超出 `1600×900`。
- 无元素被裁切。
- 无文字叠压。
- 字号和行高全部达到地板。
- 画面占用比 `≥45%`。
- 文本块总数为 `20–70`。
- 无占比不足 `1%` 且无必要的小容器。
- 初始状态与所有测试后的交互状态均干净。
- 鼠标、键盘、重置及 reduced-motion 分支均可用。
- 随机结果可复现，计算结果与 `Lec` 一致。

任何一项失败都必须修改 HTML 后重新运行；重复到所有初始与交互状态报告干净为止。
