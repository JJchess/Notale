# 页面构建契约

## 1. 工作边界

- 只创建或修改分配给你的 `pages/page-NN.html`。
- 不读取、搜索、复制、比较或修改任何其他 `page-*.html`。
- 可读取且必须遵守：`CONTRACT.md`、`PLAN.md`、`assets/theme.css`、`assets/lec.js`。
- 使用底盘前读取 `assets/CHASSIS.md`；不得把其内容复制进页面或本文档。
- 需要库时先读 `assets/lib/LIBS.md`；版本以该文件为准，不去压缩库文件中查。
- 技法清单中有对应项时，先用 `Skill` 读取对应技法文档再动手；没有对应项才自行实现。
- 每页必须自包含，可由 `file://` 直接打开；全部资源使用相对路径，禁止 CDN、网络请求和运行时下载。
- 不新建说明文档、测试文件、总结或无关资源。

## 2. 固定 HTML 骨架

保留以下骨架，只改 `NN`、页面标题和 `#stage` 内正文；按需增加已批准库的引用与本页脚本。不得删除、调序或替换底盘和主题引用。

    <!doctype html>
    <html lang="zh">
    <head>
      <meta charset="utf-8">
      <link rel="stylesheet" href="assets/base.css">
      <link rel="stylesheet" href="assets/theme.css">
    </head>
    <body data-page="NN" data-total="51">
      <div id="stage"></div>
      <script src="assets/base.js"></script>
      <script src="assets/lec.js"></script>
    </body>
    </html>

- 骨架只有空的 `#stage`，没有固定页眉、页脚或 `mount()`。
- 标题位置、组件组合和页面布局由本页内容决定；不得另造全套页面框架。
- 所有可见内容必须放入 `#stage`。
- `#stage` 是 flex 列。其顶层区域必须给固定高度或 `flex` 份额，主内容区必须 `flex:1`；禁止让所有顶层区域仅按内容取高。
- 一次性尺寸可写内联样式，不为一次性元素发明类名。
- 禁止 `position:fixed`；需要定位时用正常流、flex，或相对内容容器的 `position:absolute`。
- 默认使用 flex。只有矩阵、维度表等确需二维对齐时使用 grid。
- 需要计算坐标才能对齐时必须改结构：拖拽用 `transform` 偏移并保留正常流位置；不得靠修改 `left/top` 凑对齐。
- 不得删除 `base.css` 或主题提供的类，包括 `min0`、`cv-fill`、`no-pan`；不得覆盖这些类的定位和尺寸职责。

## 3. 受众与文字

- 面向大学一年级通识课学生，文理混合；不得假定微积分、生物学或专业工程背景。
- 页面须同时适合教师带讲和学生课后独立重看。
- 首次出现的专业术语必须用一句普通话解释；必要符号须就近说明含义和单位。
- 先给直观结论，再给机制或计算；不得用术语替代解释。
- 说明句每句不超过 40 个汉字；提示语使用直接、平和的命令式，如“拖动滑块观察变化”，不用卖萌、责备或含糊口令。
- 正文指标题之外的完整说明句、结论和操作提示，总计不超过 260 个汉字。
- 控件不超过 6 个；一组互斥选项按每个可操作项分别计数。
- 页面文本元素总数必须为 20–70 个，包含标题、正文、按钮、控件标签、读数、图注、坐标刻度、轴名、图例及画布内文字。
- 超过任一预算时，删减、合并或拆页；若本页计划无法在预算内成立，明确报告超限并停止，不得缩字号、压行高或遮藏文本硬塞。

## 4. 版面与字号

- 设计画布固定为 1600×900。
- 画面占用比必须 ≥45%；低于即不合格。不得靠放大字号、加装饰或拉大间距充数，应增加有教学意义的结构、维度或过程。
- 纯数字刻度字号 ≥12px。
- 标签、图注、轴名、图例、含词句的刻度字号 ≥14px。
- 正文、提示、控件文字、tooltip 字号 ≥16px。
- 正文行高 ≥1.35。
- KaTeX 基准字号统一 ≥20px。
- 上述字号均指 1600×900 舞台中的 CSS 逻辑字号。1366×768 屏幕缩放系数为 `min(1366/1600, 768/900)≈0.853`，即约 0.85；舞台文字在常见课堂屏上还会缩小，因此不得突破字号地板。
- 所有颜色、字体、圆角、阴影和间距取自 `theme.css` 的变量、token 或骨架类；不得自创调色板、字体体系或另一套间距尺度。
- 文本必须保留足够对比度，不得把关键信息只编码为颜色。

## 5. 数字与计算

- 所有展示的科学常量、事实数值、换算值、示例结果和交互读数必须来自 `Lec.K` 或 `Lec.P` 的实时计算，不得把结果写死在 HTML、CSS、SVG、图表数据或说明句中。
- 页码、布局尺寸、动画时长、库配置和离散控件索引不属于教学数值，可按实现需要填写。
- 单位必须就近显示；转换单位时调用对应 `Lec.P`。
- 交互改变输入后，相关读数、图形和结论必须由同一计算状态同步更新。
- 随机样本、随机点或抽样必须引用 `seedrandom.min.js` 并使用固定种子，建议种子含页号；禁止 `Math.random()`。
- 不得以预录动画、假数据或写死数字冒充计算。

## 6. 库与加载

凡 `assets/lib/` 已有库能完成的呈现工作，禁止从底层重写：

| 任务 | 必用库 |
|---|---|
| 常规坐标轴、刻度、图例、折线、柱、散点、面积、饼、热力图 | ECharts |
| 可拖拽、需命中检测的二维场景 | Konva |
| 三维场景 | Three.js |
| 下落、碰撞、摆动、堆叠、约束 | Matter.js |
| 节点连线、数据驱动矢量图形 | D3 |
| 成千上万元素同时运动 | PixiJS |
| 分步或形变动画 | anime.js |
| 多动画时间线编排 | GSAP |
| 数学公式 | KaTeX |
| 矩阵运算 | ml-matrix |
| 页面实时训练小型二分类网络 | `mlp.js` |

- 库直接以 `<script src="assets/lib/xxx.js"></script>` 引入；不用的库不引。
- CSS 库放在 `<head>` 中主题之后；脚本库放在 `base.js`、`lec.js` 之后、本页初始化脚本之前。
- 依赖顺序固定：Three.js 在 globe.gl 或 Vanta 前；GSAP 在 ScrollTrigger 前。
- API 版本只按 `assets/lib/LIBS.md` 编写。
- ECharts 必须 `echarts.init(el, null, {renderer:'svg'})`，并显式设置全局文字 ≥16px、标签和图例 ≥14px、纯数字刻度 ≥12px；禁止默认 canvas renderer。
- Konva 用于图形、拖拽和命中检测。场景标签优先使用绝对定位的 DOM；必须随图形变换的短标注才可用 `Konva.Text`，并显式满足字号下限。
- KaTeX 必须同时引用 `assets/lib/katex.min.css` 和 `assets/lib/katex.min.js`，不得替换 CSS。
- 小型逐帧神经网络训练使用 `mlp.js`，不得用 tf.js 或 ml-matrix 重写。只有预训练模型、真实图片卷积或 GPU 级大矩阵才使用 tf.js；每步须 `tf.tidy()` 或显式 `dispose()`，并确认 `tf.memory().numTensors` 不持续增长。
- 已有库只替代呈现层；交互背后的物理量、模型状态和统计结果必须真实计算。

## 7. Canvas、缩放与动画

- 原生 canvas 一律用 `Deck.fit` 或 `Deck.autofit` 适配 CSS 尺寸、舞台缩放和高分屏。
- 原生 canvas 指针坐标一律用 `Deck.pt`。
- 动画循环一律用 `Deck.loop`。
- canvas 取主题色一律用 `Deck.rgb` 或 `Deck.rgba`。
- 禁止自行实现 `devicePixelRatio` 缩放、`getBoundingClientRect()` 指针换算或 `requestAnimationFrame` 主循环。
- 使用 Konva 时采用其舞台指针坐标，不重复换算。
- Canvas 内不得承载可由 DOM、SVG 或库文本实现的主要说明；不可避免的 canvas 文字也必须显式满足字号下限。
- 监听 `prefers-reduced-motion: reduce`。该分支必须停止持续运动、自动旋转、闪烁和非必要补间，直接显示稳定终态；交互计算仍可使用。
- 页面离开、重置或动画停止时必须清理循环、计时器和监听器。

## 8. 交互标准与无障碍

- 真交互必须同时满足：用户可改变输入或状态；页面执行真实计算或状态推进；图形或读数产生可验证的对应变化。
- 仅有 hover、淡入、视差、倾斜、发光、自动播放或点击后只改颜色，均属装饰，不算交互。
- 交互须提供明确任务、即时反馈和重置方式；重置后回到确定的初始状态。
- 所有指针操作必须有键盘等价方式。控件使用原生 `button`、`input`、`select`；自定义可操作元素须可聚焦，具备语义角色、可读名称，并响应 Enter/Space 或方向键。
- 焦点样式必须可见；不得以仅拖拽作为唯一操作路径。
- 动态读数应使用可读标签；需要播报的最终结果使用适度的 `aria-live`，不得逐帧播报。
- 颜色差异之外还须使用形状、位置、线型或文字区分状态。

## 9. 完工自检

在 `pages/` 目录运行：

    python3 assets/selfcheck.py page-NN.html

有交互状态时，使用一个或多个：

    python3 assets/selfcheck.py page-NN.html --after "<触发交互的 JS>"

必须检查初始态、至少一个主要交互态、极值态和重置态。全部满足后才可交付：

- 无 JavaScript 报错、控制台异常、资源加载失败或外部请求。
- `file://` 直接打开时内容和交互完整。
- 无超出 1600×900、被裁切、遮挡或文字叠压。
- 字号、行高和 KaTeX 字号全部达标。
- 画面占用比 ≥45%。
- 文本块总数为 20–70。
- 无占比不足 1% 且无教学意义的小容器。
- 1366×768 缩放下指针命中、tooltip、拖拽和键盘操作正确。
- reduced-motion 分支稳定可用。
- 所有展示数字与当前输入一致，随机结果可复现。
- 控件数和正文字数未超预算。

自检只报告、不修复。发现任何问题必须修改该 HTML 后重跑，直到所有状态报告干净；不得以“工具盲区”“课堂上看不见”或隐藏元素规避。
