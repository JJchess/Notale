# 页面构建契约

## 1. 工作边界

- 只创建或修改 `pages/page-NN.html`；不得创建资源、文档、测试或其他文件。
- 不得读取、引用、复制或比较任何 `page-*.html`。
- 只读 `PLAN.md`、本契约、`assets/theme.css`、`assets/lec.js`，以及本契约明确指向的 `assets/CHASSIS.md`、`assets/lib/LIBS.md` 和对应技法文档。
- 页面必须自包含，使用相对路径，直接以 `file://` 打开即可显示并交互；禁止 CDN、网络请求和静态服务器依赖。
- 页号、标题、教学目标和内容以 `PLAN.md` 为准，不擅自改题、跨页补课或重复相邻页内容。

## 2. HTML 骨架

照抄以下骨架。只替换 `NN`、`#stage` 内的本页内容，并按需在标记处加入本地库和本页脚本；其他标签、顺序和资源不得删除、移动或改名。

```html
<!doctype html>
<html lang="zh">
<head>
  <meta charset="utf-8">
  <link rel="stylesheet" href="assets/base.css">
  <link rel="stylesheet" href="assets/theme.css">
</head>
<body data-page="NN" data-total="50">
  <div id="stage">
    <!-- 本页标题、正文、图形与控件 -->
  </div>
  <script src="assets/base.js"></script>
  <script src="assets/lec.js"></script>
  <!-- 按需引用 assets/lib/ 中的库；依赖在前 -->
  <!-- 本页脚本放最后 -->
</body>
</html>
```

- 骨架只有空的 `#stage`，没有统一页眉、页脚或 `mount()`；不得自行补一套固定框架。
- 标题位置、区域组成和组件布局按本页内容决定。
- `#stage` 必须保留。它是 flex 列；每个顶层区域必须有固定高度或 `flex` 份额，主内容区必须 `flex:1`。禁止所有顶层区域都按内容取高。
- 一次性尺寸可写内联；不要为单个元素发明类名。
- 不得删除底盘或主题提供的类，不得 `classList.remove()` 掉 `min0`、`cv-fill`、`no-pan` 等类，也不得覆盖其定位属性。
- 缩放舞台内禁止 `position:fixed`；需固定在容器内时用 `position:absolute`。
- 默认使用 flex。只有矩阵、维度表等确需二维对齐时使用 grid。
- 需要计算坐标才能对齐时必须改结构：拖拽用 `transform` 并保留正常流位置；刻度与控件拆成相邻区块，禁止用 `left/top` 凑齐。

## 3. 版面与内容预算

以下为硬限制，按最终渲染结果计数：

- 画布：1600×900。
- 画面占用比：≥45%。
- 文本块总数：20–70 个，包含标题、正文、标签、刻度、图例、按钮文字、输入标签和读数。
- 正文：≤300 个汉字，标题、短标签、刻度和公式不计；超出必须删减或拆页。
- 可操作控件：≤6 个；同组单选项、滑块、按钮分别逐个计数。
- 单句原则上≤35个汉字；一段只表达一个动作或结论。
- 不得靠放大字号、拉大空隙或添加无教学作用的装饰达到占用比。
- 内容不足时增加一层结构、一个比较维度或展开过程；仍不足则报告本页内容不足，不得注水。
- 超过任一上限时必须报告超限并停止硬塞；解决方式是删减、合并读数、抽稀刻度或拆页，禁止缩字号。

## 4. 字号地板

按浏览器最终计算字号检查：

- 纯数字刻度：≥12px。
- 标签、图注、图例、带词句的刻度：≥14px。
- 正文、提示、按钮、输入文字、tooltip：≥16px。
- 正文行高：≥1.35。
- KaTeX 基准字号：≥20px。
- 禁止用缩放、嵌套变换或画进位图绕过字号检查。

舞台以 1600×900 设计；1366×768 屏幕的等比缩放系数为 `min(1366/1600,768/900)≈0.853`，约0.85。字号地板按缩放前的舞台计算字号执行，以保证课堂常见屏幕缩放后仍可读。

## 5. 受众与语言

- 面向大学一年级通识课学生，文理混合；不得假定微积分、生物学或专业工程背景。
- 首次出现的术语必须用一句日常语言解释；缩写首次出现时写全称和中文含义。
- 公式必须同时说明每个符号代表什么，以及结果回答什么问题。
- 不只给结论；至少给出可观察的因果、比较或步骤。
- 教师课堂讲授优先：标题和图形先传达主线，文字用于指路，不写论文式长段落。
- 学生课后可独立重看：必要条件、操作方法、读图方式和结论必须在页内闭合。
- 提示语使用直接、平等的动作口吻，如“拖动后比较”“按空格暂停”；禁止卖萌、责备、考试式恐吓和含糊的“点这里看看”。
- 不用未解释的专业隐喻；不可避免的先修概念必须当页展开。

## 6. 主题与数据

- 所有颜色、字体、圆角、阴影和间距从 `assets/theme.css` 的 token 或现有类取得；禁止另建配色、字体体系或间距标尺。
- 不得用内联颜色、任意十六进制色或自行声明字体族。
- 底盘接口只读 `assets/CHASSIS.md`，不得把其内容抄入页面或本契约。
- `assets/lec.js` 只提供 `Lec.K` 和 `Lec.P`，不提供版面。
- 页面展示、计算、刻度、初值、范围和结论中的学科数字必须来自 `Lec.K(...)`、`Lec.P(...)` 或由其结果计算得到；禁止在 HTML、文案或脚本中写死学科数值。
- 单位转换优先使用对应 `Lec.P` 函数。格式化只在显示端进行，不得把格式化后的字符串拿回计算。
- 交互改变参数后必须重新计算真实结果；禁止预录结果、假数据或用固定数字冒充计算。
- 随机数据必须引用 `seedrandom.min.js`，使用稳定种子，建议种子含页号；禁止 `Math.random()`。

## 7. 库与技法

动手前先读 `assets/lib/LIBS.md`。已有库能完成的呈现工作，禁止从底层重写：

| 任务 | 必用库 |
|---|---|
| 常规坐标轴、刻度、图例、折线、柱、散点、面积、饼、热力 | ECharts |
| 可拖拽、需命中检测的二维场景 | Konva |
| 三维场景 | Three.js |
| 三维地球 | Three.js 后加载 globe.gl |
| 下落、碰撞、摆动、堆叠、约束 | Matter.js |
| 节点连线、数据驱动矢量图形 | D3 |
| 大量元素同时运动 | PixiJS |
| 分步、路径或形变动画 | anime.js |
| 多动画时间线 | GSAP |
| 滚动绑定动画 | GSAP 后加载 ScrollTrigger |
| 数学公式 | KaTeX |
| 矩阵运算 | ml-matrix |
| 页面内实时训练小型二分类网络 | `mlp.js` |
| 预训练模型、真图卷积或大型 GPU 矩阵 | TensorFlow.js |

- 库直接用 `<script src="assets/lib/xxx.js"></script>`；KaTeX 还必须在 `<head>` 引用 `assets/lib/katex.min.css`。
- 加载顺序：`base.js`、`lec.js`、依赖库、依赖其全局对象的扩展库、本页脚本。Three 在 globe.gl/Vanta 前；GSAP 在 ScrollTrigger 前。
- 版本以 `assets/lib/LIBS.md` 为唯一依据；禁止读压缩库文件查版本。
- 禁止下载、复制库或引入 CDN。
- ECharts 必须 `echarts.init(el,null,{renderer:'svg'})`，并显式设置全局正文≥16px、标签和图例≥14px、纯数字刻度≥12px。
- Konva 图形可用 canvas；普通文字标签必须用绝对定位的 DOM 叠加。只有必须随图形变换的短标注可用 `Konva.Text`，且显式设置合格字号。
- TensorFlow.js 每步必须 `tf.tidy()` 或手动 `dispose()`，并检查 `tf.memory().numTensors` 不持续增长；小型逐帧网络不得用 TensorFlow.js 替代 `mlp.js`。
- 清单中有对应技法文档时，必须先用 `Skill` 读取再编码；没有对应文档才可自行实现。

## 8. Canvas、缩放与输入

- 自建 canvas 一律使用 `Deck.fit` 或 `Deck.autofit` 适配 CSS 尺寸、设备像素比和舞台缩放。
- 自建 canvas 的指针坐标一律使用 `Deck.pt`；禁止自行用 `getBoundingClientRect()`、`devicePixelRatio` 或视口坐标换算。
- 动画循环一律使用 `Deck.loop`；禁止直接写 `requestAnimationFrame` 循环。
- Canvas 取色一律使用 `Deck.rgb` 或 `Deck.rgba`；禁止复制主题色值。
- 库内部管理的 canvas 使用库自身尺寸与指针机制；不得再套一层自制换算。Konva 使用 `stage.getPointerPosition()`。
- 容器尺寸变化后必须调用库的 resize 机制；ECharts、Three、Konva 等不得只按首次尺寸初始化。
- 所有连续动画都必须检测 `prefers-reduced-motion:reduce`：停止循环并显示可理解的静态状态；必要反馈改为瞬时更新。
- 页面隐藏或组件销毁时停止循环、计时器和监听器。

## 9. 交互标准

真交互必须同时满足：

1. 用户可通过指针或键盘改变一个有教学意义的参数、状态、选择或过程阶段；
2. 页面据此进行真实计算或状态更新；
3. 图形与读数同步变化；
4. 页面给出可观察、可比较的结果；
5. 有明确初始状态，复杂交互提供重置。

以下不算真交互：自动播放、纯装饰粒子、hover 发光、倾斜卡片、只展开原有文字、无状态跳动、点击后播放预录动画。

- 原生按钮、输入框优先；自制控件必须可聚焦，提供语义角色、可读名称和当前值。
- 所有指针操作必须有键盘等价操作；Enter/Space 可激活，方向键可调整连续值。
- 焦点样式必须可见，不得只靠颜色表达状态。
- 拖拽不得是唯一操作方式；同时提供键盘调整或等价控件。
- 动态关键读数使用合适的 `aria-live`，避免每帧播报。

## 10. 完工自检

在 `pages/` 目录运行：

`python3 assets/selfcheck.py page-NN.html`

对每个按钮、滑块端点、拖拽边界、重置、动画暂停和主要状态，再用：

`python3 assets/selfcheck.py page-NN.html --after "<触发该状态的 JS>"`

交付前必须满足：

- JS 报错：0。
- 资源加载失败：0。
- 超出画布、被裁元素：0。
- 非预期文字叠压：0。
- 字号全部达到本契约地板。
- 画面占用比≥45%。
- 文本块20–70个。
- 占比不足1%的无意义小容器：0。
- 初始状态和所有主要交互状态均通过。
- 1366×768 等比缩放下，指针命中、tooltip、拖拽和读数更新正确。
- reduced-motion、键盘操作和重置均可用。
- 随机结果可复现，所有教学数字可追溯到 `Lec`。

自检只报告、不修复。发现任何问题必须修改本页并重新运行，直到全部干净。
