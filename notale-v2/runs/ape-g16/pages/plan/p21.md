## 知识结构：process

中央只放一条从左向右的测量链：同一物体经过个人读数、基准校准、带单位记录、重复测量，最终成为可交接结果；箭头显式表示后一步如何控制前一步的误差，原始态与校准态前后对照。

使用 `.k-process`、`.step`、`.arw`、`.axis`；当前校准段用 `data-state="current"`，已完成段用 `data-state="past"`。控件与读数使用 `.panel`、`.big.sm`、`.num`、`.unit`、`.ctl`、`.hint`、`.btn`、`.btns`、`.tag.trace`、`.tag.active`。

采用母题 3“刻度尺”：贯穿主轴就是带细刻度的测量尺。原始读数用赭石，当前校准对象与收敛结果用薄荷青，背景保持深夜蓝黑；不增加第二套构图。

## 表征形式

交互式校准仪器。四名虚拟测量者共享同一根物体与一根已知为 `100.0 cm` 的基准棒；读数点在同一数轴上由分散逐步收敛，保留原始读数作为淡色轨迹。

## 五个 step

| step | 画面文字 | 画面上的值 |
|---|---|---|
| 1 同一对象 | 待测物体 | 真实长度暂不显示 |
| 2 个人读数 | A / B / C / D | `111.5 / 123.9 / 115.1 / 129.7 cm` |
| 3 对照基准 | 基准实际长度；各尺读数 | `100.0 cm`；`93.0 / 103.0 / 96.0 / 108.0 cm` |
| 4 校准并记录 | 校准系数；修正结果 | `1.0753 / 0.9709 / 1.0417 / 0.9259`；`119.9 / 120.3 / 119.9 / 120.1 cm` |
| 5 重复与交接 | 三轮结果；极差 | 固定种子 `p21-measurement-v1`；极差由 `18.2 cm` 收敛到约 `0.4 cm` |

## 必须点出来的一到三句

同一个对象产生不同数字，不一定是谁“看错了”，也可能是尺不同。共同基准、明确单位和可重复记录，才使个人经验成为别人可以复核的知识。

## 交互（只有这一个）

学习者分别拖动 A–D 的校准系数，范围 `0.9000–1.1000`，默认均为 `1.0000`；每次拖动都同步改变该测量者的基准修正值、物体修正值、数轴位置与总体极差。目标是让四把尺测基准时均落入 `100.0±0.2 cm`；达成后启用“重复测量”，用固定种子生成三轮微小波动并显示收敛带。未达成时只标出各尺距基准还差多少，不用红色判错。“复位”恢复原始读数、系数与随机序列。

## 交给下一页的问题

记录让结果得以传播，但一句话能从“看见了”走到“它导致了”吗？

## 动效

入场：五个 step 沿主轴依次从左进入，四个原始读数点最后落到分散位置。  
反馈：校准时对应点沿数轴平滑移动；全部进入容差后，收敛带薄荷青脉冲一次并展开三轮记录。

## 核对

- A：`111.5×100/93 = 119.89 cm`
- D：`129.7×100/108 = 120.09 cm`
- 原始极差：`129.7−111.5 = 18.2 cm`；校准后显示约 `0.4 cm`
