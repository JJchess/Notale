## 知识结构：classification

用一个总框“阻力”包含三类输入：环境条件“空气密度”、运动条件“速度²”、外形条件“阻力系数 × 迎风面积”；每类内部并列三个可选项，薄荷青标出当前归属，底部只汇合为一个阻力读数。使用 `.k-classification`、`.box`、`.bt`、`.lv`、`.it`；控件用 `.btns`、`.btn`、`.panel`，结果用 `.big`、`.num`、`.unit`，操作提示用 `.hint`。

视觉采用母题 2“固定高度的地平线”和母题 3“刻度尺”：高度类卡片中的地平线向上压缩为三层密度带，速度与面积仍作为同一嵌套结构内的刻度，不另设第二套图表。暗夜蓝底、赭石表示空气层与物体轮廓，薄荷青仅标当前选项和结果连线。

## 表征形式

交互式阻力计算任务。三组离散选择比连续滑块更适合比较数量级；D3 依据选择更新密度带厚度、速度刻度和三类输入汇合后的阻力读数。

| 上位类 | 选项 | 画面值 |

| 环境：高度 → 空气密度 | 平流层 | `30 km → 0.0184 kg/m³` |
| 运动：速度² | 较慢 | `250 m/s` |

| 外形：姿态 | 横展 | `Cd 1.00；面积 3.0 m²` |

## 必须点出来的一到三句

速度翻倍，其他条件不变，阻力变为四倍。高空空气更稀薄，但足够高的速度仍会产生显著阻力。

## 交互（只有这一个）

读者分别点击高度、速度和姿态三组按钮；默认 `10 km / 1000 m/s / 巡航`。每次选择后，当前项转为薄荷青，三条汇合线同步改变粗细，`.big` 实时显示阻力的 `N` 或 `kN`，旁边换算为等效吨重。引导读者固定两项、只改变一项，观察密度近似线性影响、速度按平方放大、迎风面积扩大阻力。点击“复位”恢复默认组合；无正确答案与评分。

## 交给下一页的问题

即使穿过稠密大气，速度继续增加会通向两种不同结果：绕行，还是彻底逃逸？

## 动效

入场：总框先显现，三类输入自上而下依次挂入，汇合线最后点亮默认读数。  
反馈：按钮切换后，旧线缩回、新线伸向结果；数字在 300 ms 内滚动到新值，不闪烁对错色。

## 不许碰

不解释激波、马赫锥、再入烧蚀、气动加热或空气热化学；不把离散密度值包装成完整标准大气模型，也不延伸到真实火箭阻力损失账本。

## 核对

核对（`Lec.P.dragForce` 结果）：

- `1.225, 250, 0.60, 1.5` → `34,453 N ≈ 34.5 kN`
- `0.4135, 1000, 0.60, 1.5` → `186,075 N ≈ 186 kN`
- `0.0184, 2000, 0.30, 1.0` → `11,040 N ≈ 11.0 kN`
