# 页面构建契约

## 1. 文件边界

- 只创建或修改分配给你的 `page-NN.html`。
- 不读取、搜索、复制、比较或修改任何其他 `page-*.html`。
- 可读取且必须遵守：`PLAN.md`、本文件、`assets/theme.css`、`assets/lec.js`、`assets/CHASSIS.md`、`assets/lib/LIBS.md`及任务对应的 Skill 技法文档。
- 不修改 `assets/`、共享文件或其他页面，不新增公共资源。
- 页面必须自包含；通过 `file://` 直接打开即可显示和交互。资源只用相对路径，禁止 CDN、网络请求和运行时下载。

## 2. 固定 HTML 骨架

照抄以下骨架。只把 `NN` 改为两位页号、保持 `TT` 为 `50`，并只向 `#stage` 内加入本页标题、正文、组件、局部样式、所需库引用和脚本；其余节点、顺序、引用均不得删除、改名或移动。

    <!doctype html>
    <html lang="zh">
    <head>
      <meta charset="utf-8">
      <link rel="stylesheet" href="assets/base.css">
      <link rel="stylesheet" href="assets/theme.css">
    </head>
    <body data-page="NN" data-total="50">
      <div id="stage"></div>
      <script src="assets/base.js"></script>
      <script src="assets/lec.js"></script>
    </body>
    </html>

- 骨架只有空的 `#stage`，没有统一页眉、页脚或 `mount()`。标题位置、区域组合和组件布局按本页内容决定。
- 库标签可放入 `#stage`，必须先于本页脚本；本页初始化代码用 `DOMContentLoaded`，确保 `base.js`、`lec.js` 已加载。
- `assets/lec.js` 只提供 `Lec.K` 与 `Lec.P`，不提供版面。
- 底盘接口只去读 `assets/CHASSIS.md`，不得在本文件或页面中复制其说明。

## 3. 内容与版面预算

以下为硬上限或硬区间，按最终渲染结果计算：

- 解释性正文：80–220 个汉字；标题、短标签、刻度、按钮文字和数值读数不计。
- 可操作控件：最多 6 个；同一组选项中的每个按钮、滑块、输入框、开关均各算 1 个。
- 页面文本块总数：20–70 个，包含标题、段落、标签、图注、刻度、图例、控件文字、读数及 SVG 文字。
- 画面占用比：不得低于 45%。
- 每页最多引入 3 个需要解释的新术语。

超出预算时删减、合并或拆页；内容不足时增加有教学意义的结构、比较维度或过程。不得靠缩小字号、扩大装饰、拉大间距或制造空容器过闸。若 `PLAN.md` 的单页要求无法在预算内完成，明确报告“版面预算超限”，不得压缩后强交。

## 4. 字号与可读性

按最终计算字号检查：

- 纯数字刻度：≥12px。
- 带词句的刻度、标签、图注、图例、单位、短标注：≥14px。
- 正文、按钮、输入文字、提示、读数说明：≥16px。
- 正文行高：≥1.35。
- KaTeX 基准字号统一 ≥20px。
- 禁止通过 `transform: scale()`、`zoom`、SVG 缩放或 canvas 内缩放绕过字号下限。
- 1600×900 舞台在 1366×768 屏幕上的缩放约为 `min(1366/1600,768/900)=0.853`，即约 0.85；字号下限是在舞台逻辑尺寸中保留课堂投影可读性的底线，不得再主动压小。
- canvas 不承载正文或常规标签。必须随图形变换的极短内部标注才可画入 canvas，并显式满足对应字号；其余文字用 DOM 覆盖层。

## 5. 视觉与布局

- 所有颜色、字体、圆角、阴影、边框和间距从 `theme.css` 的 token、变量及已有骨架类取用；不得另造配色、字体体系或间距标尺。
- 一次性尺寸可写内联样式，不为单个元素发明类名。
- `#stage` 是 flex 列。其顶层区域必须给固定高度或 `flex` 份额，主内容区必须 `flex:1`；禁止所有顶层区域都按内容自然取高。
- 默认使用 flex。只有矩阵、维度表等确需二维对齐时才使用 grid。
- 需要计算坐标才能对齐时先改结构。拖拽用 `transform` 偏移并保留正常流位置；禁止靠反复计算 `left/top` 拼布局。
- 禁止在缩放舞台内使用 `position:fixed`；固定覆盖层使用内容容器内的 `position:absolute`。
- 不得移除 `base.css` 或主题提供的类，不得 `classList.remove()` 掉 `min0`、`cv-fill`、`no-pan` 等类，也不得覆盖这些类的定位属性。
- 不得出现越界、裁切、文字叠压、遮住控件或占比不足 1% 的无意义小容器。

## 6. 数字与计算

- 所有教学内容中的常量、输入值、单位换算、推导值、读数和结果一律取自 `Lec.K` 或由 `Lec.P` 实时计算；页面不得写死结果数字。
- 页号、CSS 几何尺寸、动画时长、数组索引及库 API 配置不属于教学数字。
- 若所需科学量可由现有 `Lec.P` 组合得到，必须组合计算，不得复制公式后另写一份。
- 显示值可以格式化、四舍五入，但底层状态保留未舍入结果；说明文字必须在允许的交互范围内始终成立。
- 禁止假数据、预录结果或仅改变文字而不改变计算状态的伪模拟。
- 随机数据必须引入 `seedrandom.min.js` 并使用固定种子；同页每次打开得到相同数据。

## 7. 库与加载

动手前先查 `assets/lib/LIBS.md`。已有库能完成的呈现工作，禁止从底层重写：

| 任务 | 必用库 |
|---|---|
| 坐标轴、刻度、图例及常规折线/柱/散点/面积/饼/热力图 | ECharts |
| 可拖拽、命中检测、分组变换的二维场景 | Konva |
| 三维场景 | Three.js |
| 三维地球、球面点线区块 | Three.js 后加载 globe.gl |
| 下落、碰撞、摆动、堆叠、约束 | Matter.js |
| 节点连线、数据驱动矢量图形 | D3 |
| 成千上万元素同时运动 | PixiJS |
| 分步、路径、形变动画 | anime.js |
| 多动画时间线 | GSAP |
| 滚动绑定动画 | GSAP 后加载 ScrollTrigger |
| 数学公式 | KaTeX |
| 矩阵运算 | ml-matrix |
| 页面实时训练小型二分类网络 | `mlp.js` |
| 预训练模型、真实图像卷积或大型 GPU 矩阵 | TensorFlow.js |

- 引用格式为 `<script src="assets/lib/文件名"></script>`；KaTeX 还必须引用 `assets/lib/katex.min.css`。
- 依赖库在前、插件在后、本页脚本最后。Three.js 必须先于 globe.gl 或 Vanta；GSAP 必须先于 ScrollTrigger。
- 版本只按 `assets/lib/LIBS.md`，禁止读取压缩库查版本。
- 不需要的库不得加载。确需清单外库时仅可放在 `pages/` 下本地引用，不得用 CDN。
- ECharts 必须 `echarts.init(el,null,{renderer:'svg'})`，并显式设置全局、坐标、图例、tooltip 字号；不得用默认 canvas renderer。
- Konva 图形可用，常规文字标签必须用 DOM 叠加；不得依赖默认 12px 的 `Konva.Text`。
- KaTeX 必须同时加载预置 CSS，使用 `throwOnError:false`。
- TensorFlow.js 每步必须使用 `tf.tidy()` 或手动 `dispose()`，并确认 `tf.memory().numTensors` 不持续增长。
- 库只负责呈现不替代真实计算。计算可用 `Lec`、`mlp.js`、`ml-matrix` 或本页算法，但不得用预录动画冒充。

## 8. Canvas、缩放与动画

- 自管 canvas 一律使用 `Deck.fit` 或 `Deck.autofit` 做高分屏与舞台缩放适配。
- 自管 canvas 的指针坐标一律通过 `Deck.pt` 换算。
- 动画循环一律通过 `Deck.loop`；禁止自行写 `requestAnimationFrame` 循环。
- canvas 取色一律使用 `Deck.rgb` 或 `Deck.rgba`；禁止另写主题颜色。
- 禁止自行实现 `devicePixelRatio` 缩放或 `getBoundingClientRect()` 指针换算。
- Konva 内部 canvas 使用其舞台尺寸和 `stage.getPointerPosition()`，不得再做第二次坐标换算。
- canvas、SVG、Three、ECharts 和 Konva 的逻辑尺寸必须随容器变化重新适配；禁止只在首次加载时读取尺寸。
- 必须提供 `prefers-reduced-motion: reduce` 分支：取消连续漂移、自动旋转、闪烁和非必要过渡；过程动画改为立即到达稳定终态。该分支仍须完整显示信息和结果。
- 页面离开、组件销毁或重新初始化时停止循环并释放监听器、renderer、图表实例和物理引擎资源。

## 9. 交互标准

- 真交互必须满足：用户动作改变模型状态；画面或读数依据该状态重新计算；反馈可见且与输入连续对应。
- 拖动后只位移装饰、点击后只播放预设动画、hover 只发光、按钮只切换预写文案，均不算真交互。
- `PLAN.md` 要求交互时，至少有一个控件改变关键变量，并同步改变可视化及一个可核对的结果或解释。
- 所有交互必须有明确初态、当前状态和重置方式；重置恢复完全相同的初始结果。
- 优先使用原生 `button`、`input`、`select`。自定义可操作元素必须有合适的 `role`、`tabindex`、可见焦点和状态属性。
- 指针操作必须提供键盘等价操作：Tab 可达，Enter/Space 可激活，滑块或拖拽状态可用方向键调整。
- 控件必须有可见标签；变化中的关键读数使用合适的 `aria-live`，但不得高频刷屏。
- 点击目标不得仅靠颜色区分状态；焦点、选中、禁用状态均需有文字、形状或边框差异。

## 10. 受众与讲授语言

- 面向无古人类学、航天工程和编程基础的大学通识课学生。
- 首次出现的专门术语必须立即用一句日常语言解释；不得用另一个未解释术语定义它。
- 单句原则上不超过 32 个汉字；一个提示只要求一个动作。
- 先写可观察现象，再给术语、数字或机制；公式旁必须说明变量含义和结论如何读。
- 不展示代码、API 名、实现细节或“程序正在计算”等面向开发者的文字。
- 提示语使用直接、平等的课堂口吻，如“拖动并观察”“比较两种结果”；禁止幼儿化、命令训斥、考试腔和空泛口号。
- 页面既要支持教师带讲，也要让学生课后独立重看：关键图必须有就近标签，交互必须有一句操作提示，结论不得只靠口头补充。
- 内容始终服务于“从走出森林到迈向星空”的主线：肉体与石器适应地球极端环境，对照科技系统支持人在真空中生存。只做与本页 `PLAN.md` 目标有关的联系，不强塞跨页背景。

## 11. 技法文档

- 开工前检查 Skill 清单；存在对应技法文档时，必须先用 `Skill` 读取再实现。
- 已有技法的布局、动画、图表、三维、拖拽或无障碍方案不得另起炉灶。
- 清单无对应项时才可自行实现，并仍须遵守库优先、主题、字号、预算和底盘条款。

## 12. 完工自检

在 `pages/` 目录运行：

    python3 assets/selfcheck.py page-NN.html

对每种按钮、滑块端点、拖拽终态、重置态和 reduced-motion 态，使用一个或多个：

    python3 assets/selfcheck.py page-NN.html --after "<触发状态的 JS>"

交付前必须同时满足：

- JS 报错为 0。
- 加载失败、网络请求和缺失资源为 0。
- 超出画布、被裁元素、文字叠压为 0。
- 字号全部达到对应下限，正文行高 ≥1.35。
- 画面占用比 ≥45%。
- 文本块为 20–70 个。
- 无占比不足 1% 的无意义小容器。
- 初态及所有可达状态均无控件遮挡、标签错位、读数溢出或交互失效。
- 键盘可完成全部关键操作，重置可复现初态。
- 随机结果可复现；动画在 reduced-motion 下进入稳定终态。
- ECharts 使用 SVG renderer；自管 canvas 使用 Deck 接口；教学数字均来自 `Lec`。

发现任何问题就修改页面并重新运行，直到所有状态报告干净；不得带已知警告交付。

## 13. 交付

只交付 `page-NN.html`。不新增说明文档、测试文件、截图、总结、变更记录或其他文件。
