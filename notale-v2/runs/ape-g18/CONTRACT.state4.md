## 1. 这堂课在讲什么（你那一页必须服务于这个主张）

- 全课主张：人类并不是先拥有“适应一切的身体”才走出森林、迈向星空，而是不断把生存能力从身体扩展到工具、文化与维持微环境的技术系统中。

| 章 | 页 | 这一章要让读者信什么 |
|---|---|---|
| I 从一口空气开始 | 01–05 | 猿人与太空人面对的是同一个问题：怎样让脆弱生命跨过环境门槛 |
| II 身体走出森林 | 06–17 | 早期人族的身体变化不是笔直升级，而是在波动环境中形成的拼接式适应 |
| III 石头成为体外器官 | 18–27 | 工具、火、协作与文化传递，把个体无法积累的能力保存到群体之外 |
| IV 用技术随身携带地球 | 28–39 | 太空人的身体没有适应真空；航天技术把可居住环境包在身体周围 |
| V 两条进化通道 | 40–50 | 生物进化改变身体，文化技术改变选择压力；走向星空需要两者共同受约束 |

- 证据链：E1 远古环境不是稳定背景；气候、资源与地形的波动筛选了能移动、散热、取食并调整行为的身体组合。E2 石器、火、协作和教学把生存能力移到身体之外，使文化积累成为比个体学习更快的适应通道。E3 真空、微重力和辐射并未使太空人迅速“进化”；现代航天依靠压力边界与生命保障系统暂时替身体适应。E4 太空生存不是某件装备的胜利，而是资源闭环、冗余、维护和风险权衡组成的系统工程。E5 从走出森林到迈向星空，人类持续改变环境与选择压力；未来的“进化”会是身体、文化和技术的共同反馈。
- 你的页面只讲自己 `pNN.md` 写的东西；其中标明的“不许碰”是别页的任务，重复会让 `{minutes}` 分钟塌掉。01、03、06、18、28、40、48、50 只承担开场、推进、过渡或收束，不加交互。

## 2. 颜色语义（全套 50 页统一，不得挪用）

- 读者会在 50 页里不被告知地学会以下对应；出现相关概念必须用绑定色，与之无关的元素只能用主题灰阶。

| CSS token / 色相 | 只代表 |
|---|---|
| `--bg` / `#0B0F12` 深炭黑 | 生命边界之外的未知与全页低亮度背景 |
| `--ochre` / `#C56A32` 赭石 | 身体、化石、地层、生物进化的慢通道 |
| `--cyan` / `#45D6E8` 电青 | 当前操作对象、压力边界、流动方向、即时反馈 |
| `theme.css` 中性灰阶 token | 其余文字、容器、辅助线和非语义装饰 |

- 母题也保持语义不变：洞穴口、皮肤、舱壁、宇航服用青色闭合“压力边界”；赭色脚印逐渐转成青色轨道弧；身体／工具双秤追问适应在体内还是体外；远古沉积层转为航天任务时间轴；水、氧、热、废物画成闭合或泄漏的生命保障环。标题正文用投影清晰的无衬线体，年代和工程读数用等宽体，化石学名才用局部衬线斜体；证据用写实照片，关系用科学示意图，生成插画只补无法拍摄的远古场景或抽象生理过程。
- 禁止浅色学术纸张和白底照片墙；禁止高饱和蓝紫科幻界面；禁止全套羊皮纸、洞穴壁画和手绘纹理。它们会分别削弱投影、预设“太空更先进”或造成上下半场风格断裂。

## 3. 知识结构——骨架约定

- 不要用“左右两栏”“卡片网格”这类容器思路搭页面；容器不是关系。先确定 `pNN.md` 指定的知识骨架，再让关系占据主画面。

| 骨架 | 必须让读者一眼看见的关系 | 硬要求 | 什么样就算失败 |
|---|---|---|---|
| `process` | 起点、变化方向、阶段与结果 | 阶段沿同一视觉路径连接，箭头或状态变化可见 | 只是把三个块并排放着，不算 process |
| `comparison` | 同一指标下的差异与共同点 | 对象共享基线、尺度、指标和视觉编码 | 两边各画各的图、各用各的比例尺 = 失败 |
| `classification` | 上位概念、分支及归属 | 层级、分组边界和归属线索同时可见 | 平铺的同级项，不算 classification |
| `generalization` | 核心主张及证据如何支撑它 | 主张最重，证据次之，连接关系明确 | 主张和支撑一样重，不算 generalization |

- `theme.css` 的 `.k-*` 原语只是起点，接口见 `assets/CHASSIS.md`。能用 SVG、canvas 或库把同层关系画得更清楚就画；硬要求是关系在画面中可见，不能要求读者读完几个块后自行拼接。

## 4. 交互的规矩

- 同一个关系只用一种交互讲透：禁止给同一变量同时安排滑块、滚轮和拖拽；禁止图表与模拟重复同一结论。没有交互要求的页面不要硬加，不直接服务理解的效果删除。
- 所有教学常量、初值、范围、比较值和显示结果必须取自 `Lec.K`、经 `Lec.P` 当场计算；`pNN.md` 给出公式与常量。正文写了科学数字却未引用对应 `Lec` 数据，或动画预录、数据伪造、结果写死，均属可指认违约。随机必须引 `assets/lib/seedrandom.min.js`，并用 `new Math.seedrandom('page-NN')`；同页每次打开结果一致。
- 加载后的静止首屏必须已经能讲，不能出现大片“—”“等待操作”或空模型；交互只负责再进一步。动画用 `Deck.loop(fn,{still:t})` 指定有信息的定格时刻。有交互必须就近放一句 `.hint`，明确动作和目标，字号不低于 14px。

## 5. 技术契约

- harness 已建好骨架，只向 `#stage` 添加内容；不得改 `data-page`、`data-total` 或底盘结构：

    <!doctype html>
    <html lang="zh">
    <head>
      <meta charset="utf-8">
      <link rel="stylesheet" href="assets/base.css">
      <link rel="stylesheet" href="assets/theme.css">
    </head>
    <body data-page="NN" data-total="50">
      <div id="stage"></div>
      <script src="assets/base.js"></script>
      <script src="assets/lec.js"></script>
    </body>
    </html>

- `data-page` 必须为两位补零，`data-total="50"`；画布固定 1600×900，不得滚动。`#stage` 已是 flex 列：顶层区域必须给固定高度或 flex 份额，主内容区用 `flex:1`，禁止顶层区域按内容取高。装不下就删短内容，绝不缩字号、行高或间距硬塞。字号只用主题 token：正文≥16px，控件标签、图例、图注、提示≥14px，纯数字刻度≥12px，多行行高≥1.35。颜色、字体、圆角、阴影、间距只用主题变量和现有类；canvas 颜色只经 `Deck.rgb()` / `Deck.rgba()`。一次性尺寸可写内联，不为单元素造类。
- 默认 flex，只有矩阵或维度表才用 grid。不得移除 `min0`、`cv-fill`、`no-pan`，不得覆盖其定位；缩放画布内禁止 `position:fixed`，固定叠层用相对容器内的 `absolute`。库能做就不得底层重写：常规图表用 ECharts，必须 `echarts.init(el,null,{renderer:'svg'})`，全局字号16、轴标签14、图例14；可拖拽命中二维场景用 Konva，文字以 DOM 叠加；节点连线与数据驱动矢量图用 D3；三维用 Three；碰撞、摆动、堆叠用 Matter；上万元素运动用 Pixi；时间线用 GSAP；公式用 KaTeX 并同时引 CSS，基准≥20px；矩阵用 ml-matrix；实时小网络用 `mlp.js`，真实图像卷积或大型 GPU 矩阵才用 tf.js，循环须 `tf.tidy()` 或释放张量。手写 canvas 只画库覆盖不到的自定义图形。版本和引用方式只查 `assets/lib/LIBS.md`。页面必须可由 `file://` 直接运行，只用 `pages/` 下相对路径，禁止 CDN。

## 6. 图片

- 只用 `assets/img/` 已有素材；文件名、适用页和 `title` 文本以 `assets/img/IMG.md`、`pNN.md` 为准，不下载、不生成、不替换。
- 生成插画右下角已有“AI生成”角标，该区域不得压文字、控件或图形。深色底上的照片直接放，不加白框；图片框只用主题圆角 token，并设 `overflow:hidden`。
- 出处和许可不印在主画面，只逐字写进 `<img title="…">`；教学画面不得自造来源缩写或版权脚注。

## 7. 文字风格

- 面向大学通识课、文理混合，不假定古人类学、航天工程或编程基础。术语首次出现即用一句短话解释；说明因果时每句只推进一步，提示语直接说“拖动……比较……”，不使用专业软件口令。
- 用教师带讲、学生课后也能独立重看的口吻；短句，少从句。禁止“如图所示”“我们可以看到”“接下来我们将探讨”和 AI 式元评论。每个数字给可感换算；不确定结论标“这一步目前有争议”等限定，不把假设写成定论。
- 收束句写读者应带走的一句话；下一问写交给下一页的钩子。两句不得改写成本页摘要，也不得提前回答下一页。

## 8. 自检

- 写完在 `pages/` 运行：`python3 assets/selfcheck.py page-NN.html`。必须达到 0 个 JS 报错、0 个资源加载失败、0 个超出画布、0 个被裁切，最小字号≥12px。
- 有交互再运行 `python3 assets/selfcheck.py page-NN.html --after "<触发交互的 JS>"`；操作后的极值状态也必须不溢出、不遮挡、不产生无效读数。
- 改到检查干净再交付。交付物只有 `page-NN.html`；不写测试或报告，不修改 `assets/` 下任何文件。

## 9. 版面密度与常见坑

- `#stage` 内由区块分配高度；主区里的块不要写死 px 高度，确需固定的图片框除外。画面占用低于45%视为排空：收紧错误的 flex 或扩大有效图框，不加装饰、不放大字号、不拉空间；高于85%视为过挤：删减内容，不缩字号。
- 一页不得出现两块以上大面积空白。关系图、证据、读数和文字应形成一个视觉重心；照片不加白框，所有图片框统一圆角并裁切。
- canvas 一律用 `Deck.fit()` / `Deck.autofit()`，动画一律用 `Deck.loop()`；拖动区域加 `.no-pan`。手写 canvas 的指针坐标必须用 `Deck.pt(el,e)`，禁止使用在缩放舞台中会算错的 `offsetX` / `offsetY`。
