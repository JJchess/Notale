## 知识结构：classification

**所有部件必须围绕同一个人体轮廓，按“贴身层—压力层—外防护层—背负系统”由内向外嵌套；职责标签必须连回所属部件。**

**禁止把六项职责画成六件并列装备；通信、供氧等并不都是织物“层”，背包系统必须与服装层级归入同一套宇航服系统。**

用 `.k-classification` 表达“整套系统包含组件、组件承担职责”的归属；中心照片与拆出部件构成唯一 focus；局部 `.box` 只框定四个上位组件，避免退化成信息卡墙。

## 表征形式

交互式技术拆解板：中央真实 EMU 照片，四组部件沿轮廓向外错开，以 SVG 路由线连接嵌套标签。无需图表库；这不是数值关系图。点击或键盘选择部件时，以换 `.active` class 控制分离位移、连线和说明显隐；不要用 canvas，以保留文字可访问性。

## 层级里的各项

| 上位组件 | 具体部件 | 画面职责 |
|---|---|---|
| 贴身层 | 液冷通风服、水管网络 | 移走代谢热与湿气，帮助热控 |
| 压力层 | 气密囊、约束层、密封接头 | 维持约 **29.6 kPa** 工作压力并限制鼓胀 |
| 外防护层 | 多层隔热材料、外罩 | 隔热，抵御微流星体与表面磨损 |
| 背负系统 PLSS | 氧气、风机、CO₂ 去除、冷却回路、电源 | 供氧、循环气体、清除 CO₂、排热与供电 |
| 操作接口 | 轴承关节、手套、头盔、通信帽 | 允许有限活动、观察、通信 |
| 整套系统 | 完整 EMU | 质量约 **145 kg**；微重力中仍具有同样惯性 |

数值写死，不做动态计算；页面短出处写“NASA EMU documentation”。

## 交互（只有这一个）

学习者依次点击“贴身层、压力层、外防护层、PLSS、操作接口”；所选组件从人体轮廓向外分离，所属职责连线点亮，其余保持低亮。点“合拢”恢复完整宇航服，点“全部拆开”同时展示五组归属。交互无评分；目标是看出一项装备同时维持多种生命条件，而非找到唯一拆解顺序。再次点击当前组件或按“复位”回到完整状态。

## 不许碰

不讲加压手套如何降低灵巧度、拧接头的耗时、疲劳或 EVA 维修竞赛；这些全部留给 p37。不得把约 145 kg 说成微重力中的“重量”，也不得暗示宇航服只是防寒、防辐射的外壳。
