# 《Ape-men 与 Spacemen：极端环境中的生存进化》 90 分钟互动讲义 · 总规划

## 0. 这套讲义的主线

人类扩展生存边界的主导方式，经历了从身体缓慢适应、到文化累积、再到用技术构造“体外生理系统”的转变，但三个阶段始终受同一组环境约束、代价与失败风险支配。

| 章 | 页 | 这一章要让读者信什么 |
|---|---|---|
| 一、先定义“活得下去” | 01–04 | 比较猿人与太空人之前，必须先把生存理解为环境压力、身体能力与外部工具共同决定的包络。 |
| 二、走出森林 | 05–12 | 早期人族不是沿阶梯变成现代人，而是在波动环境中以镶嵌方式获得双足行走等适应。 |
| 三、把适应移到身体之外 | 13–23 | 石器、火、合作与文化传递把生存能力外置，并显著加快了适应新环境的速度。 |
| 四、用同一框架跨越时空 | 24–28 | 基因、文化与工程技术速度不同，却都能用“约束—方案—代价—筛选”分析。 |
| 五、在真空中携带一个小地球 | 29–43 | 太空人的生存依赖压力、氧气、散热、辐射防护和废物处理组成的耦合系统。 |
| 六、从森林到星空 | 44–45 | 技术扩大了可居住范围，却没有取消人体边界，只是把边界转化为系统工程问题。 |

- **E1**：极端环境不会自动产生“更高级”的生命；它只设置约束，能否生存取决于身体、行为和工具共同形成的生存包络。
- **E2**：早期人族的身体演化是分支式、镶嵌式适应；双足行走等特征带来收益，也同时产生新的代价。
- **E3**：石器、火、合作与跨代学习把部分适应移到身体之外，使人类能以远快于遗传演化的速度改变生存策略。
- **E4**：太空环境移除了压力、可呼吸空气、对流散热和正常重力等人体默认条件，生存必须依靠定量耦合的生命支持系统。
- **E5**：航天技术可视为“体外生理系统”；它扩大生存包络，但增加质量、能量、维护和单点失效等新代价。

## 0.5 视觉世界

- **现实参照：自然史博物馆的比较证据展板。** 化石、器物、脚印与航天装备都以“证据本体＋尺度＋简短标签”呈现，适合大学课堂远距离投影，也能限制跨学科页面的识字量。
- **形状语言：**
  1. 证据本体置于直角薄框内，框外保留至少画面宽度 4% 的留白，使照片与推论明确分离。
  2. 环境约束用连续实线边界，身体能力用人体轮廓，外部技术用可拆卸矩形模块，不依赖颜色也能辨认。
  3. 因果关系只用单向直箭头；虚线仅表示假说、不确定连接或尚未闭合的生命支持回路。
  4. 卡片采用 4px 小圆角、无浮夸投影；只有可拖动物体带 3px 下投影，方便后排学生识别操作对象。
  5. 比较页由中央共用尺度分区，左右对象不得各用一套比例，避免把视觉差异误当作数量差异。
- **底色：暖明底色 `#F4F0E6`。** 接近博物馆标签纸，在普通教室投影亮度下比纯白减少眩光，并保持黑字和照片边缘清晰。
- **主色相：深青色 `#245B63`，唯一代表“可维持生命的包络或闭合回路”。** 猿人与太空人的可生存区域使用同一语义，帮助文理混合受众跨章节迁移框架。
- **强调色：橙红色 `#D85B35`，只用于当前讲解焦点、超限值或正在拖动的变量。** 高亮面积控制在单页 8% 以内，确保投影环境中注意点明确而不替代结构编码。
- **字体：衬线使用 Noto Serif SC，仅承担历史年代、证据引文和章节题签；无衬线使用 Noto Sans SC，承担标题、正文、标签与按钮；等宽使用 IBM Plex Mono，承担单位、传感器读数和计算结果。** 三类文字分别对应历史证据、课堂解释和工程读数，降低跨学科切换成本。
- **材质：线性为主。** 环境边界、身体轮廓和生命支持回路采用粗线图，真实化石、石器与航天装备照片仅在需要证据本体时嵌入，保证远距离可读。
- **母题：**
  1. 从森林地平线延伸为地球弧面的连续水平线。
  2. 脚印逐渐变为航天靴印的尺度标记。
  3. 围绕人体的“生存包络”轮廓。
  4. 石器碎片与航天器模块共享的可拆卸组件框。
  5. 从开放箭头逐步闭合的空气、水与热量回路。

被否决的整体方向：

- **否决“电影海报式原始人对决宇航员”。** 强逆光、巨大人物和戏剧化星空会把证据降为装饰，并强化“原始—高级”的线性进步叙事，不适合通识课纠正误解。
- **否决“全黑航天 HUD”。** 教室投影会吞掉暗部细线，密集数字界面也要求过多工程识字量，使上半场自然史材料被迫套入不合语义的控制台外观。
- **否决“儿童绘本式手绘演化阶梯”。** 它容易把多个并存的人族支系画成单一路线，并削弱化石、遗址和航天数据作为证据的地位。

## 0.6 对这个受众的取舍

- **能用：** 百分比、比例、数量级、折线图、日常呼吸与保温经验，以及“预算有限、顾此失彼”的直觉。
- **不用：** 系统分类学细目、颅骨测量术语、群体遗传推导、轨道微分方程、火箭分级设计和任何编程语法。
- **换算：** 压力换成海平面大气压比例，能量换成人体静息功率或电热水壶，速度换成每秒跨越的足球场，质量换成饮用水桶，时间换成课堂、一天或一代人。
- **争议：** 烹饪对脑演化的因果强度必须标为假说；最早石器与可控用火的年代必须区分“发现年代”“分类归属”和“学界共识强度”。
