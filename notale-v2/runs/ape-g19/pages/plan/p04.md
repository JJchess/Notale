# page-04 · 谁把条件拉回可生存区？ · **125 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `SURVIVAL ENVELOPE` |
| 主标题 | 环境施加负荷，身体与工具共同决定能否承受 |
| 收束句 | 危险条件不是死亡判决：当身体耐受与工具补偿覆盖环境负荷，生存包络才成立。 |
| 下一问 | 走出森林的“猿人”，是一支依次前进的队伍，还是许多并存的支系？ |

## 知识结构：process

**关系不变量：** 全画布只设一条 `0–100` 教学指数基线；环境负荷先进入，身体现有耐受与工具补偿随后抵扣，末端显示同尺度的生存余量或超限值，四者必须由单向直箭头连续相连。

**禁止画法：** 不得把环境、身体、工具拆成三张互不对齐的独立卡片，也不得画成“恶劣环境直接指向死亡”的单箭头。

**共享原语：** `.k-process` 承担“负荷进入—能力抵扣—结果判定”的主链；`.tech-module` 将工具画成可拆卸补偿模块；`.life-loop` 只包围抵扣后不超限的范围，超限段改用焦点色。整条骨架横向铺入 `.canvas-full`。

## 表征形式

交互式二维操纵台：顶部为共享刻度与三条对齐滑杆，中部以人体轮廓和可拆卸工具模块显示两类能力，底部输出一条实时伸缩的包络及判定句。

使用原生 DOM＋SVG；关系只有共享线性尺度、矩形区段与轮廓，不引入图表库。所有长度按同一线性比例映射到 `0–100`，刻度数字使用等宽字体。`input` 事件重新计算区段端点、更新 SVG 属性与文本，并切换 `is-viable` / `is-over` class。

## 三项教学指数

| 项目 | 画面标签 | 范围 / 默认 | 画面解释 |
|---|---|---:|---|
| 环境负荷 `E` | 环境要求身体承受 | `0–100 / 75` | 越高表示该单一约束越难满足 |
| 身体耐受 `B` | 身体已有能力 | `0–100 / 35` | 当下身体可直接覆盖的部分 |
| 工具补偿 `T` | 外部工具补上 | `0–100 / 20` | 行为或器物提供的额外支持 |
| 判定 | 生存余量 | `M = B + T − E` | `M ≥ 0` 显示“包络成立”；否则显示“超限 |M|” |

刻度旁固定写：`教学指数｜只比较同一种约束，不是物理单位`。默认状态输出：`超限 20`。身体与工具覆盖段可相接，但不得堆叠遮挡；超过环境负荷的部分继续向右形成“余量”。

## 交互

学习者分别拖动三个滑杆，环境边界、身体覆盖段、工具模块宽度及末端读数立即变化。默认 `75 / 35 / 20`；快捷按钮为“默认失衡”“加入工具 `75 / 35 / 45`”“环境缓和 `50 / 35 / 20`”。

当 `B + T < E`，缺口用橙红色标出并显示“仍在包络外”；当 `B + T ≥ E`，连续深青包络闭合并显示“进入可生存范围”。这是观察仪器，不设置唯一正确位置；再次拖动或按“默认失衡”即可重新开始。

## 动效

滑杆变化后，覆盖段端点沿水平轴在 `180ms` 内移动；工具模块比身体段晚 `60ms` 到位。跨越零点时，包络线用 `220ms` 闭合或打开，判定文字仅做一次 `80ms` 淡入，不闪烁、不循环。

## 核对

| 参数 `E / B / T` | 期望结果 |
|---|---|
| `75 / 35 / 20` | `M = -20`，显示“超限 20” |
| `75 / 35 / 45` | `M = 5`，显示“生存余量 5” |
| `50 / 35 / 20` | `M = 5`，显示“生存余量 5” |

## 不许碰

不解释身体能力如何通过遗传变化形成，也不出现突变、等位基因或群体频率；自然选择机制归 p20。本页指数不得跨供氧、温度、资源等不同约束相加，也不得暗示任何工具能补偿所有环境问题。
