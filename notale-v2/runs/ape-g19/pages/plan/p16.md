## 知识结构：process

1. **关系不变量**：固定食物毛收益从左侧进入，依次穿过“搜索—受伤—竞争—携带”四张等宽卡，右侧得到净收益；四项成本必须使用同一条 `0–5` 筹码尺度。
2. **禁止画法**：不得把四项成本拆成互不相连、各自缩放的优缺点卡片，否则无法看出成本会沿取食过程累加。
3. **共享原语**：`.k-process` 以 `.step` 和 `.arw` 串起单向成本链；`.stage-cards` 承载四张同基线阶段卡；末端 `.panel` 只显示毛收益、总成本与净收益，不另建第二套图形。

## 表征形式

交互式“成本筹码链”：每张阶段卡显示成本名称、原因短句、`0–5` 横向刻度和当前筹码数，末端即时做减法。原生 DOM＋SVG 足够，便于保持卡片、箭头和共享刻度清晰；不引入图表库。策略按钮与滑杆更新统一状态对象，再以 `textContent`、CSS 自定义属性和焦点 class 重绘数值、条长及最高成本项。

## 四段风险账

页面注明：`筹码是课堂比较指数，不是考古测量值。`

| 画面项 | 空手处理 | 现场找石打片 | 预先携带石片 |
|---|---:|---:|---:|
| 食物毛收益 | 12 | 12 | 12 |
| 搜索 | 2 | `2 + S` | 2 |
| 受伤 | 4 | 2 | 2 |
| 竞争 | `min(5, C + 1)` | `max(1, C − 1)` | `max(1, C − 1)` |
| 携带 | 0 | 0 | `D` |
| 净收益 | `12 − 四项成本之和` | 同左 | 同左 |

四卡短句依次为：“寻找食物或可用石材”“处理时割伤、砸伤或接近危险来源”“处理越久，越可能失去食物”“工具随身移动也消耗体力与空间”。

## 交互

- 策略按钮：`空手处理 / 现场找石打片 / 预先携带石片`，默认“空手处理”。
- `石材搜索成本 S`：`0–4`，步长 `1`，默认 `2`；只影响现场打片。
- `竞争压力 C`：`0–4`，步长 `1`，默认 `3`。
- `携带距离 D`：`0–4`，步长 `1`，默认 `2`；只影响携带石片。
- 任一操作后，四卡筹码、总成本、净收益及底部三策略净收益标签立即更新；当前最高成本用 `.focus` 标记，正净收益轮廓使用 `.life-loop`。
- 这是观察仪器，不判定唯一正确策略；“复位”恢复默认参数。

## 动效

切换策略时，成本筹码沿箭头从左至右依次更新，每卡 `180 ms`、错开 `70 ms`；末端净收益在最后一卡后 `120 ms` 跳变。滑杆连续拖动时不播放入场动画，只即时更新。

## 核对

| 参数 | 空手 / 现场打片 / 携带石片净收益 |
|---|---|
| `S=2, C=3, D=2` | `2 / 4 / 4` |
| `S=4, C=3, D=1` | `2 / 2 / 5` |
| `S=0, C=3, D=4` | `2 / 6 / 2` |
