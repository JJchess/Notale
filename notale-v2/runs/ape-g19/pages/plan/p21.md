## 知识结构：process

1. **关系不变量**：两代人必须沿同一条从左向右的轮次轴排列；同代接触、代际教学桥与累计掌握人数连续相连，共用 `0–24 人`尺度。
2. **禁止画法**：不得把两代拆成互不对齐的独立卡片，也不得画成猿人逐级变现代人的演化阶梯。
3. **共享原语**：`.canvas-full.k-process` 承载“第一代扩散→代际传授→第二代扩散”；`.step` 表示每轮接触，`.arw` 只画传播方向，`.hypothesis` 标示未成功的教学尝试。

## 表征形式

交互式二维技能传播沙盘：上下两条各含 24 人的点阵，中间以代际教学桥连接；下方累计折线与点阵共享轮次轴和人数尺度。

使用 D3 原生 SVG，线性轮次轴；人点至少 18 px，掌握技能用 `--life` 实心，未掌握为空心，当前新学会者短暂使用 `--focus`。状态变化通过重新绑定节点数据并调用 transition；不得使用力导向布局，位置按固定点阵锁定。

## 沙盘口径

| 项目 | 画面文字 / 值 |
|---|---|
| 第一代人数 | `24 人` |
| 第二代人数 | `24 人` |
| 初始示范者 | 默认 `2 人`；可选 `1–4 人` |
| 模仿成功率 | 默认 `60%`；范围 `0%–100%`，步长 `10%` |
| 代际教师 | 默认 `3 人`；范围 `1–6 人` |
| 同代学习期 | 每代 `6 轮接触` |
| 图例 | `已掌握技能`、`尚未掌握`、`本轮新学会`、`尝试未成功` |
| 模型注记 | `教学模型：用于观察传播机制，不是史前人口估计` |
| 随机口径 | 固定种子 `21021`；复位后同参数得到同一结果 |

每轮先将已掌握者与未掌握者分别按固定种子洗牌，再一对一配对；每名教师至多尝试一次，成功概率取滑杆值。本轮新学会者从下一轮起才能教学，技能不会在模拟中丢失。第一代结束后，按固定顺序选取设定数量的已掌握者，各向第二代一名不同成员尝试教学；第二代随后运行同样六轮。

## 交互

学生调节“初始示范者”“模仿成功率”“代际教师”，点击`推进一轮`或`自动播放`。每轮立即更新教学连线、新掌握者、两代累计人数与顶部读数 `已掌握 __ / 48`；拖动参数后自动复位到第 0 轮。

应观察到：少数示范者可通过重复模仿形成同代扩散；代际桥若未传过去，第二代无法自行扩散。提供`复位同一种子`，不设置唯一正确状态或胜负反馈。

## 动效

每轮教学箭头由教师指向学习者，时长 `350 ms`；成功者在箭头抵达后延迟 `120 ms` 由空心变为橙红，再于 `450 ms` 后转为深青。失败箭头以虚线淡出。自动播放每轮间隔 `900 ms`，两代之间停顿 `700 ms`。

## 核对

| 参数 | 期望结果 |
|---|---|
| 成功率 `0%`、初始示范者 `2`、教师 `3` | 第一代始终 `2/24`；第二代始终 `0/24` |
| 成功率 `100%`、初始示范者 `2`、教师 `3` | 第一代第 4 轮达到 `24/24`；第二代经代际桥为 `3/24`，第 3 轮达到 `24/24` |
| 任意参数 | 各代累计人数单调不减，且始终处于 `0–24` |

## 不许碰

不在本页并排量化生理、文化与遗传三种时间尺度，该比较归 p22；不重讲等位基因频率或自然选择模型，归 p20。也不把传播速度解释为“更高级”或必然成功。
