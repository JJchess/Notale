## 知识结构：comparison

**关系不变量：** 上区并列呈现同一测试片的“全日照参照”与“当前暴露状态”，下区共用一条 `0–400 K` 温标和同一组材料参数；吸收箭头、放热箭头与平衡温度必须逐列对齐。

**禁止画法：** 不得把日照画成“高温”、阴影画成“低温”两张无共同尺度的情绪插画，也不得添加空气对流箭头。

**共享原语：** `.k-comparison` 负责两状态同基线比较；`.env-boundary` 圈定无对流的真空边界；`.diff` 标出两列吸收通量与平衡温度之差。骨架落入 `.split-tb`：上半为能量箭头对照，下半为共享温标、读数与控件。

## 表征形式

交互式二维热收支比较仪。原生 DOM＋SVG 比图表库更合适：箭头宽度直接编码通量，温标位置编码温度，避免把两个状态误读为时间序列。

SVG 使用共享线性温标 `0–400 K`；所有功率密度以 `W/m²` 显示，温度同时显示 `K` 与 `°C`。状态改变时调用 `Lec.P.radiativeEquilibrium(...)`，随后重新绘制箭头宽度、温标标记并更新读数；阴影输入为零时切换专用提示 class。

## 热平衡仪内容

| 画面项 | 写入内容 |
|---|---|
| 测试对象 | 理想灰体薄板；吸收面积／发射面积 `0.50` |
| 全日照入射 | `1361 W/m²` |
| 表面反照率 | 默认 `0.30`，可调 |
| 发射率 | `0.90`，固定 |
| 吸收关系 | `吸收 = 入射 × (1 − 反照率) × 0.50` |
| 放热关系 | `放热 = εσT⁴` |
| 平衡条件 | `吸收 = 放热` |
| 常量 | `σ = 5.670374419×10⁻⁸ W·m⁻²·K⁻⁴` |
| 真空标签 | `对流：0` |
| 阴影提示 | `太阳输入为 0；测试片仍会向外辐射，因而继续冷却。` |
| 模型边界 | `未计地球红外、舱体反射与内部发热；0 K 只是零输入模型极限。` |
| 来源 | NASA Total Solar Irradiance observations；页面短标 `NASA TSI` |

## 交互

“日照暴露”滑杆范围 `0%–100%`、步长 `1%`、默认 `100%`；快捷按钮“全日照”设为 `100%`，“进入阴影”设为 `0%`。被测列入射通量为 `1361 × 暴露比例 W/m²`，参照列始终保持全日照。

“反照率”滑杆范围 `0.00–0.80`、步长 `0.01`、默认 `0.30`，同时作用于两列。立即更新吸收箭头、理想平衡温度和两列温差。学生应看到：遮阴会立即切断太阳吸热，却不会切断物体自身放热；平衡温度按四次方根变化，并不与日照比例线性同步。

阴影状态的温标落在 `0 K` 时显示“模型极限”，不得把它标成现实航天器阴影温度。按钮“恢复默认”回到暴露 `100%`、反照率 `0.30`。

## 核对

调用 `Lec.P.radiativeEquilibrium(incidentFluxWPerM2, albedo, emissivity, absorptionToEmissionAreaRatio)`：

- `1361, 0.30, 0.90, 0.50` → 约 `310.8 K`，即 `37.7 °C`。
- `680.5, 0.30, 0.90, 0.50` → 约 `261.4 K`，即 `−11.8 °C`。
- `1361, 0.70, 0.90, 0.50` → 约 `251.5 K`，即 `−21.7 °C`。
