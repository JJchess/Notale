# 《Apeman – Spaceman：从会直立的猿到离开地球的人》90 分钟互动讲义 · 总规划

## 0. 这套讲义的主线

人类并非因为摆脱了生物限制才走向太空，而是靠身体、合作、知识与机器层层接力，把有限的猿类能力延伸到地球之外。

无交互（只承担开场/推进/过渡/收束）：01 07 16 25 34 43 48

| 章 | 页 | 这一章要让读者信什么 |
|---|---|---|
| 一、先把尺度摆正 | 01–06 | 从古人类到航天员不是直线升级，而是发生在多重时间尺度上的连续转变 |
| 二、一副猿类身体 | 07–15 | 直立、手、脑与耐力各有代价，没有任何单一特征独自“造成人类” |
| 三、群体成为技术 | 16–24 | 火、语言、教学与分工把个体经验变成可跨代累积的集体能力 |
| 四、机器延伸身体 | 25–33 | 火箭不是力量更大的跳跃，而是用能量、速度和质量交换轨道 |
| 五、太空重新暴露限制 | 34–42 | 离开地球不会取消生物需求，反而把重力、辐射、延迟和生态依赖放大 |
| 六、谁成为“太空人” | 43–48 | 走向太空既是工程选择，也是关于风险、资源、公平与未来身份的公共选择 |
