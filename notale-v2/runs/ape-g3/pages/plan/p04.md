# page-04 · 分枝，而非阶梯 · **115 秒**

**Kicker：BRANCHING HOMININS**

**主标题：人类演化不是一列依次升级的队伍**

## 知识结构：classification

用“共同祖先 → 多次分枝 → 多条并存支系 → 仅部分延续至今”的主干—分支骨架，把谱系关系分成四类并显式化：

- **共同祖先节点**：表示两个或多个支系从共享祖先分开，不把现生黑猩猩画成人类祖先。
- **人族内部支系**：从共同祖先后的简化主干继续分枝，包含南方古猿类、傍人类与人属等教学层级。
- **旁支与并存支系**：分枝可在相近时段并存；旁支不是“失败的低级阶段”，也不必通向智人。
- **延续状态**：叶节点区分“已经灭绝”与“延续至今”，但不按高低、先进或聪明程度排序。

D3 根据结构化节点与父子关系计算树布局；连线只表达共享祖先和分枝关系。横向位置表达大致时间方向，纵向位置仅用于展开分枝、避免重叠，不表达价值或能力排名。

## 表征形式

交互式 D3 分枝谱系，嵌入 stage-cards：

- 中央主舞台是一株从左向右展开的简化谱系“灌木”，不出现阶梯、上升箭头或人物进步队列。
- 初始态只强调共同祖先、人族分枝和现生智人所在末端；其余支系降低亮度但保持可见，先让学生看到“不止一条线”。
- 点选任一节点或支系后，该节点、最近共同祖先、相邻并存支系和通向叶节点的路径分别高亮。
- 舞台旁的卡片同步解释当前对象属于“共同祖先”“旁支”“并存支系”还是“延续至今的叶节点”。
- 切换选择时使用短促的路径描边与卡片替换，不让树重新生长或改变布局，避免把动画先后误读为真实演化顺序。
- 时间位置仅作区间级提示；存在争议或无法确定直接祖先关系的节点用虚线轮廓和“关系简化”标签表示。

## 层级里的各项

### 共同祖先层

- **人族与黑猩猩支系的共同祖先**
  - 显示年代区间，不显示单一年份。
  - 区间两端分别读取：
    - `Lec.K.homininChimpSplitMinYearsAgo`
    - `Lec.K.homininChimpSplitMaxYearsAgo`
  - 页面用 `Lec.P.formatNumber()` 格式化为“约 ×× 万年前—×× 万年前”。
  - 节点文案明确：“这是推定的共同祖先位置，不是现生黑猩猩变成人的起点。”

### 人族分枝层

- **早期人族**
  - 作为共同祖先之后、后续多个支系之前的教学汇总节点。
  - 不赋予单一物种名称，不显示未经 `Lec` 提供的具体年代。
  - 卡片说明：“化石证据呈碎片状，节点代表简化关系，不代表完整名单。”

- **南方古猿类**
  - 作为多个后续分枝附近的教学层级，不画成必然直通智人的单线台阶。
  - 代表节点使用“阿法南方古猿”。

- **傍人类**
  - 画为独立旁支并以叶节点结束。
  - 不写“退化”“失败”或“低级”，只标“已灭绝的近缘支系”。

- **人属**
  - 画为继续发生多次分枝的层级。
  - 至少包含一个不通向智人的灭绝叶节点，以及智人叶节点；具体连线使用课程内置的 `page04Phylogeny` 结构化关系，不在页面脚本临时推断直接祖先。

### 代表物种节点

- **阿法南方古猿**
  - 年代区间读取：
    - `Lec.K.afarensisStartYearsAgo`
    - `Lec.K.afarensisEndYearsAgo`
  - 用 `Lec.P.formatNumber()` 格式化显示，单位为“万年前”。
  - 卡片标签：“南方古猿类代表”“不是一切后续人类的确定直系祖先”。

- **智人**
  - 出现时间读取 `Lec.K.homoSapiensAgeYears`。
  - 用 `Lec.P.formatNumber()` 格式化显示为“当前证据支持约 ×× 万年前出现”。
  - 状态标签：“延续至今的一个叶节点”，不使用“最高级”“最终形态”。

- **其他灭绝人属代表**
  - 名称与父子关系读取 `Lec.K.page04Phylogeny.nodes`。
  - 若课程常量未提供可靠年代，主画面不显示年份。
  - 状态统一从节点字段读取为“已灭绝”，不以颜色深浅表达优劣。

### 关系类别

点选后，卡片顶部只出现以下一种关系标签：

- **共同祖先**：多个支系共享的分叉点。
- **旁支**：与智人共享更早祖先，但不通向智人叶节点。
- **并存支系**：存在时间区间重叠，不能排列成先后接棒。
- **延续叶节点**：目前仍存在的末端支系；“仍存在”不等于“演化程度更高”。

“并存”仅在两个节点都具有课程常量中的时间区间时计算。区间重叠算法为：

`latestEnd <= earliestStart`

实际实现统一调用 `Lec.P.rangesOverlap(rangeA, rangeB)`；若该函数尚未提供，构建时加入同名页面共享函数，不在界面写死判断结果。

### 谱系位置与显示数值

- 时间方向统一使用“距今”，左侧较早、右侧接近现在。
- 节点横坐标统一调用 `Lec.P.timelineFraction()`，最老边界取 `Lec.K.homininChimpSplitMaxYearsAgo`，最近边界为距今零年。
- 所有百分比位置通过 `Lec.P.timelinePercent()` 生成，不在 CSS 或数据对象中写死。
- 页面可见年代均由对应 `Lec.K` 常量读取，再经 `Lec.P.formatNumber()` 格式化。
- 纵向分枝位置由 `d3.tree()` 或 `d3.cluster()` 根据层级现场计算，不显示为数值。
- 页面不显示脑容量、脑身比、智力分数、工具复杂度排名或任何能力分值。
- 除页标题中的页码与既定停留时长外，主画面不出现手写数字。

## 必须点出来的一到三句

人类演化像不断分枝、部分重叠又大量终止的灌木，不是猿依次升级成人的梯子。

现生黑猩猩不是我们的祖先；人类与黑猩猩支系共享更早的共同祖先。

智人只是延续至今的一条叶端，不是整棵谱系预先设定的终点。

## 交互（只有这一个）

**点选分枝谱系。**

- 学生点击节点、叶端或连线形成的支系；键盘用户可用 Tab 聚焦节点并以 Enter 或 Space 选择。
- 选择后，D3 高亮：
  1. 当前节点；
  2. 它与智人的最近共同祖先；
  3. 从共同祖先分别通向当前节点与智人的两条路径；
  4. 与当前对象存在时间重叠且有可靠区间的支系。
- 右侧 stage-card 同步显示对象名称、所属层级、关系类别、延续状态，以及有 `Lec` 来源时才出现的年代区间。
- 点击“阿法南方古猿”时，学生看到它位于分枝网络中，而不是被放在通往智人的固定台阶上。
- 点击灭绝旁支时，学生看到路径在叶端停止，但树的其他支系继续延伸。
- 点击智人时，学生看到它只是多个叶端之一；视觉强调落在共享分叉点，而非智人节点本身。
- 点击人族与黑猩猩支系的共同祖先时，两条后续支系同时高亮，以纠正“现生猿变成人”的误解。
- 页面不设置胜负、计时、拖拽、缩放或自由改线；交互只用于比较分枝关系。
- 目标直觉：物种之间的关系应沿树回溯到共同祖先理解，不能按外形或年代排成一条进步序列。

## 不许碰

- 不用脑容量解释某一支系为何出现、延续或灭绝。
- 不展示脑容量数值、颅骨容量对比、脑身比、神经组织指标或智力排名；这些属于 p11–p12。
- 不把树的右侧、上方、较亮颜色或现生状态解释为“更先进”。
- 不把阿法南方古猿或任何简化节点写成已经确定的唯一直接祖先。
- 不把现生黑猩猩放在人类谱系主干上，也不写成“没有进化的人类祖先”。
- 不扩展直立行走的骨骼机制、能耗优势或分娩权衡；这些属于 p08–p10。
- 不讲完整古人类物种名录、化石发现史、基因交流细节或具体谱系争议。
- 不重复 p03 的时间尺度压缩任务；本页年代只用于定位分枝与识别并存。
- 不把灭绝写成能力不足，也不把延续至今写成自然选择的终极目标。
- 不再画第二棵完整谱系，不提供“阶梯版”作为可切换视图，以免错误图式成为记忆主画面。

## 必用skill

d3-viz, theme-factory, design-taste-frontend

## 版面提示

使用 stage-cards 的“中央树舞台＋右侧解释卡”结构：

- 中央约四分之三宽度放 D3 分枝树，保证分叉点、连线和叶节点是第一视觉对象。
- 右侧约四分之一宽度固定一张解释卡，内容随选择替换，不叠加多张卡片。
- 树的时间方向保持从左到右；不得使用自下而上的“攀升”构图。
- 共同祖先节点使用骨白，灭绝叶端使用低饱和氧化橙，延续叶端使用轨道蓝；颜色只编码关系状态，并配套文字与线型，不单靠颜色传达。
- 可点击节点的视觉直径与命中区分离：图形保持克制，命中区满足触控操作；聚焦态必须有清晰外圈。
- 移动端改为树在上、单卡在下，保持同一棵树横向可读，不改成纵向升级路线。
