# page-24 · 集体放大器 · **105 秒**

**Kicker：COLLECTIVE AMPLIFIER**

**主标题：最强的适应，是让能力继续累积**

## 知识结构：generalization

把 p17–p23 的具体机制归纳为一条主干关系：

**个人获得经验 → 群体保留、传递、纠错并协作运用 → 下一代从更高起点继续改进**

页面用中央“集体放大器”显式化这层关系。四条支撑围绕同一主干排列，每条支撑对应一个旋钮：

1. **保留**使成果不随个人消失；
2. **传递**使不在场者也能获得步骤；
3. **纠错**使复制不只重复，还能筛掉失败；
4. **协作**使不同人的局部能力组成共同成果。

四条支撑不是四个独立器官，也不按固定历史阶段依次出现；它们共同决定群体经验能否跨人、跨时段继续累积。输入端始终是“一个人的有限经验”，输出端始终是“下一轮可继续改进的共同起点”。

## 表征形式

交互式动态因果图。

画面中央是一台抽象的四层放大器，不画成真实机器剖面。左侧输入为单个个体完成的一次尝试，中央四层分别表现保留、传递、纠错、协作，右侧输出为多代叠加后的共同成果。

四个旋钮改变对应层的连通程度；主干上的信号、记录片、纠错标记与协作节点随之增减。最终输出不显示虚构的精确倍数，只以三种定性状态呈现：

- **难以累积**
- **能够延续**
- **持续改进**

默认状态为四层均处于中档，便于教师先逐一削弱，再让学生恢复完整链条。

## 四条支撑

### 1. 保留：经验没有随个人消失

对应 p17、p22。

- 石器方案可以留下可复用的形状与操作结果。
- 图像、文字和数字把部分记忆移到个人大脑之外。
- 旋钮降低时，左侧每轮尝试结束后，大部分成果淡出；下一轮接近从头开始。
- 旋钮提高时，上一轮成果以“可调用记录片”进入下一轮。

画面标签：

- 低档：**成果易消失**
- 中档：**留下结果**
- 高档：**留下结果与步骤**

### 2. 传递：不在眼前的信息可以到达别人

对应 p20、p21。

- 语言可以传递对象、顺序和条件。
- 模仿能复制可见结果，教学还能指出关键步骤。
- 旋钮降低时，信息在个体之间传递时缺失步骤，主干出现断口。
- 旋钮提高时，结果、步骤和纠错提示能一起抵达下一位学习者。

画面标签：

- 低档：**只能看结果**
- 中档：**能传步骤**
- 高档：**能解释条件**

### 3. 纠错：群体不只复制，还会比较和修正

对应 p17、p21、p23。

- 累积需要识别哪些改动有效，而不是把所有变化都保留下来。
- 教学提供纠错规则；测量、质疑与复现帮助群体检查结论。
- 旋钮降低时，成功与失败方案一起进入输出，错误沿主干继续传播。
- 旋钮提高时，失败尝试仍被看见，但会留下“为何失败”的标记，成为下一轮改进依据。

画面标签：

- 低档：**错误照样复制**
- 中档：**能发现偏差**
- 高档：**能复查并修正**

### 4. 协作：不同人的局部能力可以接成共同成果

对应 p18、p19、p23。

- 火带来的共享空间、合作育儿与更长学习期，为多人参与和代际传递提供条件。
- 分工让测量、制作、记录、质疑和复现不必由一个人独自完成。
- 旋钮降低时，多个节点各自产出但彼此不连接。
- 旋钮提高时，不同角色的产出汇入同一主干，并被下一轮共同调用。

画面标签：

- 低档：**各自为战**
- 中档：**交换成果**
- 高档：**分工并接力**

四个旋钮均不显示百分比、人数、代数或能力倍数。本页不引入可核验的定量数值，也不使用写死数字；所有状态均为定性机制演示。

## 收束主张

人类最强的适应不是某件器官，而是让群体能力持续累积。

个人仍然有限；改变尺度的是经验能够被保留、传递、纠错，并由不同的人继续接力。

任何一层变弱，累积都可能停滞；四层相互接通，后来者才不必每次从头开始。

## 交互（只有这一个）

读者调整中央放大器的四个旋钮：**保留、传递、纠错、协作**。

每次调整只同步改变三处反馈：

1. 主干中有多少内容能穿过该层；
2. 输出端处于“难以累积 / 能够延续 / 持续改进”哪种状态；
3. 一句紧贴当前薄弱层的因果反馈，例如“成果留下了，但关键步骤没有传到下一位学习者”。

交互不设胜负、计时、分数或隐藏最优解。四层均调高时，输出端形成稳定但仍可继续扩展的主干，并出现收束句；任一层调低时，画面明确显示累积在哪一处中断，而不是把结果解释成个人能力不足。

教师带讲建议节奏：

- 先把“保留”调低：追问“如果每代都要从头来，会发生什么？”
- 再恢复保留、调低“纠错”：追问“能传下去，是否等于会进步？”
- 最后让学生共同调整四层：观察持续累积需要的是单项极强，还是机制接通。

键盘操作必须与指针等价：Tab 聚焦旋钮，方向键切换低、中、高档；状态变化通过可见文字和 `aria-live` 同步播报。旋钮之外不设置第二种可操作控件。

## 不许碰

- 不解释火箭、轨道、推进剂、质量比、速度、能量预算或任何机器的物理边界；这些属于 p26–p33。
- 不把“集体放大器”写成真实机械装置，也不暗示文化累积可以无限、无成本增长。
- 不新增语言起源年代、文字史、火的考古年代或人类谱系证据。
- 不重复 p17 的石器改造玩法、p20 的通信游戏、p21 的双组实验、p22 的跨代记忆流程或 p23 的角色分配任务。
- 不把某一项机制宣布为文化累积的唯一原因。
- 不把群体能力等同于群体共识；质疑、失败和分歧仍是纠错过程的一部分。
- 不将现代科研制度投射为所有时代、所有社会都采用的唯一组织方式。
- 不进入航天职业准入、资源公平、任务伦理或未来目标选择；这些属于 p44–p47。
- 不引入新的演化器官、身体结构或生物学适应证据。
- 不使用“更高级民族”“落后文化”或单线文明等级作为累积能力的例证。
