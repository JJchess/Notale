# page-37 · 失重反应分系统 · **110 秒**

**Kicker：MICROGRAVITY · SYSTEM MATCH**

**主标题：同样是失重，不是同一套身体反应**

## 知识结构：classification

把“失重后身体不舒服”拆成四条并列的生理系统分支：体液分布、前庭与平衡、肌肉、骨骼。每条分支下对齐放置两张表现卡，并在配对后显露“表现—主要系统—原因”的归属关系。

分类骨架不是按严重程度或出现先后排序，也不把所有变化归为笼统的“身体变弱”。卡片归入的是最直接相关的主要系统；反馈同时提醒各系统会相互影响，分类不等于彼此隔绝。

## 表征形式

交互式四分支诊断台。上方是待判断的表现卡，中部是四个有固定图标与颜色编码的系统槽位，下方是当前选中卡的简短诊断依据。

初始状态只显示表现，不显示系统名称中的解释文字；学生完成一次放置后，槽位展开原因。全部正确后，四列收拢成一张人体系统总览，显出“同一环境输入，多套系统响应”的结构。

不使用写实人体剖面，不播放装饰性失重动画；重点是形成可复述的分类表征。

## 层级里的各项

### 体液分布

**系统提示：** 地面上重力参与维持体液的上下分布；进入轨道微重力环境后，体液会更多移向头胸部。

- **头面部胀满感**
  - 卡面线索：脸部显得浮肿，头部有发胀感。
  - 配对依据：首先指向体液向上半身重新分布，而不是骨骼或肌肉损伤。
- **鼻塞样不适**
  - 卡面线索：没有普通感冒线索，却出现鼻腔充血般的感觉。
  - 配对依据：可由头部附近体液分布改变引起。

### 前庭与平衡

**系统提示：** 内耳前庭、视觉和身体感觉原本共同判断“哪边是下”；微重力会打乱这些线索之间的对应关系。

- **转头时眩晕或方向感混乱**
  - 卡面线索：眼睛看到的运动与内耳提供的方向信息暂时不一致。
  - 配对依据：主要属于平衡与空间定向系统的重新校准。
- **恶心与空间运动不适**
  - 卡面线索：刚进入微重力环境时更明显，不能简单解释为消化系统出了问题。
  - 配对依据：主要关联感觉线索冲突与前庭适应；反馈注明恶心也可能有多重影响因素。

### 肌肉

**系统提示：** 日常站立和行走会持续调用抗重力肌；承重需求减少后，这些肌肉受到的使用刺激也会减少。

- **重新承重时腿部乏力**
  - 卡面线索：返回有重力环境后，站立或行走需要重新适应。
  - 配对依据：主要指向肌肉力量与控制能力的变化。
- **维持姿势更容易疲劳**
  - 卡面线索：尤其涉及原本长期对抗重力的躯干和下肢肌群。
  - 配对依据：主要属于肌肉去适应，不归入体液重新分布。

### 骨骼

**系统提示：** 骨组织会响应日常机械负荷；承重刺激减少时，骨的重建平衡会改变。

- **骨矿物质减少**
  - 卡面线索：通常依靠测量发现，不一定立即产生主观不适。
  - 配对依据：这是骨组织变化的可测表现，不等同于肌肉乏力。
- **骨代谢相关的尿钙增加**
  - 卡面线索：属于检测指标，不是航天员凭感觉直接报告的症状。
  - 配对依据：与骨组织释放矿物质有关，主要归入骨骼系统。

页面不显示骨量、肌肉变化率、持续时间、阈值或个体风险百分比；这些卡片只承担系统归类。若界面需要统计完成状态，使用“待判断 / 已归类 / 需要复核 / 分类完成”等文字，不显示写死的计数或百分比。

## 必须点出来的一到三句

体液、平衡、肌肉和骨骼的变化来自不同生理系统，不能用一个笼统的“失重症状”解释全部反应。

同一表现可能受到多个系统影响；这里配对的是最直接相关的主要系统，而不是宣称身体各部分彼此独立。

## 交互（只有这一个）

学生逐张拖动或点选表现卡，将其放入体液分布、前庭与平衡、肌肉、骨骼四个槽位。

- 放置正确：卡片锁入槽位，展开一句因果依据，并高亮该系统的抽象人体区域。
- 放置错误：卡片返回待判断区，不直接揭晓答案；提示学生比较“体液位置改变、方向信息冲突、使用负荷减少、骨重建改变”四类机制。
- 同一张卡连续需要复核时：显示两项候选机制，让学生根据线索再次选择，不采用扣分或倒计时。
- 全部归类完成：四个槽位并列亮起，显示“同一微重力环境 → 多系统响应”，并提供“重新诊断”按钮。
- 支持拖拽、点击后选槽、键盘选择与确认；颜色之外同时使用系统图标和文字标签。

学生应形成的直觉是：看到一种失重表现时，先问“哪个系统的正常输入或负荷改变了”，而不是把所有反应混成一种疾病。

- 不提供个人诊断、治疗方案、药物建议或“正常／异常”的医学阈值。
- 不把卡片结果包装成疾病检测，也不根据操作结果评价学生或真实个体的健康状态。
- 不重复 p36 的骨量与肌肉随时间变化范围，不展示变化率、任务时长曲线或训练对照。
- 不提前讨论 p38 的人工重力设计与参数权衡。
- 不把微重力称为完全没有重力，也不重新展开 p35 的月球、火星与轨道环境比较。
- 不声称每位航天员都会出现相同表现、相同严重程度或相同恢复过程。
