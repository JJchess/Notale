# page-04 · 一天里的人类史 · **130 秒**

**Kicker：DEEP TIME / ONE DAY**

**主标题：如果人类史只有一天，航天发生在最后一瞬**

## 知识结构：process

把“约 700 万年前至参考年”显式化为一条不可逆的时间进程：最早人族量级 → 露西 → 最早期人属化石记录 → 较稳妥的控制用火证据 → 智人 → 农业 → 首次载人航天 → 首次登月 → 参考年。

骨架使用同一组事件的前后态：

- **展开态**：事件沿线性长卷分布，卷轴长度强调历史跨度。
- **压缩态**：长卷持续缩短，所有事件保持原有线性比例和先后顺序。
- **一天态**：长卷收束为从午夜到次日午夜的一日时间尺；每个事件以时钟位置重新标注。
- **末秒放大态**：只放大接近午夜的局部，显示农业与航天事件为何挤在最后极短区间。

事件之间用单向主轴和连续压缩箭头连接；不得把间距做成等距站点，也不得通过动画延迟暗示各阶段持续时间相同。

## 表征形式

全屏固定画布上的交互式线性时间长卷。D3根据统一年代数据计算所有事件的位置；GSAP ScrollTrigger把读者的纵向滚动映射为单一压缩进度。

主表征始终是同一条线性时间轴，不切换为对数轴。画面通过缩放、标签避让和末端局部放大，使学习者看到：越接近参考年，事件越拥挤；航天史映射到一天后只能占据午夜前的最后一瞬。

压缩过程中保留一条从长卷起点到终点的连续基线，避免读者把末秒放大误解为另一条时间轴。

## 八个事件

1. **人族早期时间量级**
   - 年代：约 `Lec.K.homininEarliestYearsAgo` 年前。
   - 证据标记：调用 `Lec.K.evidenceLabels`，显示“有支持但仍争议”。
   - 作用：作为这一天的午夜起点，不显示为确定的单一“第一位祖先”。

2. **露西**
   - 年代：约 `Lec.K.australopithecusLucyYearsAgo` 年前。
   - 一日位置：由 `Lec.P.timelineFraction(...)` 计算。
   - 标签只写名称与年代，不展开骨盆、步态或其他身体特征。

3. **目前已知最早期人属化石记录**
   - 年代：约 `Lec.K.genusHomoEarliestYearsAgo` 年前。
   - 固定措辞：“目前已知化石记录约”。
   - 一日位置：由 `Lec.P.timelineFraction(...)` 计算。

4. **较稳妥的控制用火证据量级**
   - 年代：约 `Lec.K.controlledFireEvidenceYearsAgo` 年前。
   - 证据标记：调用 `Lec.K.evidenceLabels`，显示“较确定”。
   - 不展示更早争议证据的单点年代，也不讨论烹饪效应。

5. **智人目前已知早期记录**
   - 年代：约 `Lec.K.homoSapiensEarliestYearsAgo` 年前。
   - 一日位置：由 `Lec.P.timelineFraction(...)` 计算。
   - 不把该节点写成演化终点或“现代人突然出现”。

6. **农业在不同地区出现**
   - 年代：约 `Lec.K.agricultureYearsAgo` 年前。
   - 标签须附“不同地区并非同时发生”。
   - 一日位置：由 `Lec.P.timelineFraction(...)` 计算。

7. **首次载人航天**
   - 公元年份：`Lec.K.firstHumanSpaceflightYear`。
   - 距参考年的时间：调用 `Lec.P.yearsAgo(Lec.K.firstHumanSpaceflightYear, Lec.K.courseReferenceYear)`。
   - 一日位置：将所得距今年数送入统一线性换算。
   - 末秒放大态中显示事件名称、年份和对应的一日时刻。

8. **首次登月**
   - 公元年份：`Lec.K.firstMoonLandingYear`。
   - 距参考年的时间：调用 `Lec.P.yearsAgo(Lec.K.firstMoonLandingYear, Lec.K.courseReferenceYear)`。
   - 一日位置：将所得距今年数送入统一线性换算。
   - 不扩展任务过程、技术细节或航天史名单。

### 一日位置与显示算法

- 全轴跨度：
  `spanYears = Lec.K.homininEarliestYearsAgo`
- 距今型事件的已逝时间：
  `elapsedYears = spanYears - eventYearsAgo`
- 公元年份事件先换算：
  `eventYearsAgo = Lec.P.yearsAgo(eventYear, Lec.K.courseReferenceYear)`
- 在线性长卷中的位置：
  `fraction = Lec.P.timelineFraction(elapsedYears, 0, spanYears)`
- 一天总秒数：
  `daySeconds = Lec.P.daysToSeconds(1)`
- 映射到一天后的时刻：
  `clockSeconds = fraction × daySeconds`
- 从午夜到事件的显示时刻由 `clockSeconds` 分解为时、分、秒；所有分量先经 `Lec.P.finite(...)` 和 `Lec.P.clamp(...)`。
- 距次日午夜的剩余时间：
  `remainingSeconds = daySeconds - clockSeconds`
- 航天时代在一天中所占时长：
  先用 `Lec.P.yearsAgo(...)` 求首次载人航天至参考年的年数，再除以 `spanYears`，乘以 `daySeconds`。
- 数值显示统一调用 `Lec.P.formatNumber(...)` 与 `Lec.P.formatDuration(...)`；不足以稳定显示到整秒时保留必要的小数位，不用“约零秒”代替。
- 页面显示的参考终点年份来自 `Lec.K.courseReferenceYear`，不得读取浏览器当前年份。
- 所有“约×年前”、公元年份、一日时刻、距午夜时长与比例均由上述常量和函数实时生成，不在页面文本或动画关键帧中写死。

## 必须点出来的一到三句

把约 700 万年压成一天，农业已经接近午夜，载人航天只落在最后一瞬。

技术变化可以在极短历史时间内重塑生活环境，但这不等于身体也以同样速度完成了生物演化。

## 交互（只有这一个）

**压缩人类史长卷。**

读者向下滚动，控制同一条长卷从完全展开逐步压缩为一天；滚动位置就是压缩进度，不设置第二个滑块、按钮或独立探索模式。

- 开始时，画面显示完整长卷和八个按线性比例定位的事件。
- 滚动推进时，卷轴水平尺度连续缩小，事件位置同步重算，标签自动避让；事件不能跳格或重新排序。
- 接近压缩终点时，画面出现一日时钟标尺，事件标签从“距今年数”平滑过渡为“一天中的时刻”。
- 最终停在午夜前的局部放大：农业、首次载人航天、首次登月与参考年仍保持真实比例；主轴全貌以细线留在背景中，标出放大窗口来自何处。
- 读者应形成的直觉：一天并没有被平均分段，绝大多数可见历史占据前面的漫长时间，而航天时代被挤压到最后一瞬。
- 键盘操作以方向键或 Page Up/Page Down推进同一压缩进度；开启减少动态效果时，改为几个连续静态关键态，但仍使用同一线性计算结果。

## 不许碰

- 不讲骨盆、脊柱、下肢、脑、手、牙齿、童年或其他具体人体变化；这些留给 p13–22。
- 不解释自然选择的条件、机制或跨代模拟；这些留给 p07–08。
- 不把事件排成“越来越高级”的进步阶梯，不使用“终于成为真正的人”之类表述。
- 不展开人类谱系分叉，也不罗列物种名单；名称与谱系边界留给 p05–06。
- 不展开火、农业或航天技术的因果影响，只把它们作为时间定位点。
- 不重复 p03 的生物演化与航天史双尺度比较，也不引入对数时间轴；本页唯一职责是把同一段人类史线性压缩成一天。
- 不用视觉上等距的节点代替真实比例，不为可读性擅自移动事件位置；标签可以避让，锚点不可以移动。
- 不把约 700 万年前写成无争议的精确起点，不把智人节点写成演化终点。
- 不把农业写成全球同时发生，不把首次载人航天或首次登月写成整个航天史的唯一起点。

## 版面提示

采用 `canvas-full`：全屏画布固定在视口内，滚动距离只用于驱动压缩进度。

- 左上角放 kicker 与主标题，压缩开始后缩为不遮挡主轴的紧凑标题栏。
- 中央主轴占据主要视野；展开态为横向长卷，压缩态逐渐收束至完整的一日标尺。
- 右上角只显示当前压缩状态：“长卷”“压缩中”“一天”“午夜前放大”，不显示百分比进度。
- 底部保留当前映射说明：“约 700 万年 → 一天”，两端数值均由 `Lec` 实时生成。
- 末秒放大必须以嵌套窗口覆盖在完整一日轴上，并用连接线标明来源区间，不能直接替换全轴。
- 事件锚点、刻度与放大窗口由D3绘制；标题、证据标签和无障碍文本使用HTML叠层。
