# page-08 · 群体变了，个体没有升级 · **140 秒**

**Kicker：SELECTION ACROSS GENERATIONS**

**主标题：自然选择改写群体比例**

## 知识结构：process

把“已有差异如何经过繁殖逐代改变群体比例”显式化为六个前后相接的 step：

**初始群体 → 环境筛选 → 繁殖机会不同 → 后代继承 → 新一代形成 → 比例跨代累积**

左侧 PixiJS 群体画布呈现每代的个体与繁殖结果；右侧固定显示六步主干、当前步骤和性状比例。运行时只高亮正在发生的一步，并用箭头把亲代、成功繁殖者和后代对应起来，避免把代际变化误读为同一个体变形。

## 表征形式

交互式动态群体模拟。

每个个体用同形、不同色阶的小型标记表示一个连续性状；个体在一代之内颜色不变。进入下一代时，旧群体整体淡出，新出生的一代从成功繁殖者的位置附近生成。右侧比例条按代更新，保留上一代细线作为前态，使学习者同时形成两种表征：

- 个体层：同一个体不会因环境需要而改变性状。
- 群体层：不同性状留下后代的机会不同，若差异可遗传，比例会跨代移动。

## 六个 step

### 1. 初始群体已有差异

从课程级随机种子与页面子种子生成初始群体：

- 随机源：`seedrandom(Lec.K.populationSimulationSeed + ':p08-selection')`
- 群体规模：读取 `Lec.K.populationSimulationSize`
- 可切换规模：读取该常量提供的 `100、500、2000` 情景，不在页面组件内另写数值
- 每个个体的抽象性状值：由固定种子生成后，经 `Lec.P.finite(...)` 检查，再由 `Lec.P.clamp(...)` 限制在页面性状轴范围
- 初始性状分布只表示“群体中存在可遗传差异”，不映射具体人类基因、肤色、智力或真实疾病

画面标注：“差异先存在，环境没有现场制造需要的性状。”

### 2. 环境形成筛选条件

学习者拖动右侧“环境偏向”控制杆，使环境更有利于性状轴的一端或保持中性。

每个个体与环境的匹配程度按页面当场计算：

- `distance = abs(trait - environmentTarget)`
- `match = Lec.P.clamp(1 - distance / traitRange, 0, 1)`
- 中性环境时，所有性状获得相同的基线繁殖权重
- 偏向环境时，繁殖权重由 `match` 单调映射并归一化
- 所有中间值先经 `Lec.P.finite(...)`，不得显示无穷值或非法比例

画面只称“教学模型中的环境偏向”，不暗示现实环境只有单一压力。

### 3. 个体繁殖机会不同

运行一代时，模拟按归一化繁殖权重抽取亲代。被抽中的个体出现短暂光环和连线；未被抽中不显示为“失败者”或“低等个体”。

当代画面显示：

- 当前群体数：取模拟数组长度，经 `Lec.P.formatNumber(...)`
- 各性状区间的亲代数：由模拟当场计数，经 `Lec.P.formatNumber(...)`
- 各区间被抽中为亲代的比例：`Lec.P.percent(selectedCount / groupCount)`
- 分母为零时由 `Lec.P.ratio(...)` 或统一比例保护逻辑阻止误导显示

标注：“选择表现为繁殖差异，不是环境命令个体改变。”

### 4. 后代继承亲代性状

每个后代从被抽中的亲代继承抽象性状。为保持本页只解释选择，默认不加入突变按钮，也不调用 `Lec.K.mutationRateTeaching`。

后代性状允许加入固定、很小的教学噪声以避免完全复制的机械感，但该噪声必须：

- 由同一页面种子生成
- 不被标为真实突变率
- 不改变性状均值移动的主要方向
- 可由“严格继承”开关关闭
- 经 `Lec.P.finite(...)` 与 `Lec.P.clamp(...)` 处理

若实现无法清楚区分“抽象遗传变异”与突变，则采用严格复制，不添加噪声。

### 5. 新一代替换亲代

后代数量补足当前人口规模情景后，整批替换亲代，代数加一。不得让原个体在画布上直接变色或伸缩成更匹配的性状。

显示值：

- 当前代数：模拟状态中的整数，经 `Lec.P.formatNumber(...)`
- 教学换算年数：`generationCount × Lec.K.humanGenerationYears`
- 年数格式：`Lec.P.formatDuration(...)`
- 默认每代年数读取 `Lec.K.humanGenerationYears`
- 敏感性范围读取该常量规定的 `20–30 年`教学范围，不写成所有历史人群的固定世代长度

动画必须有清楚的“亲代退出—后代进入”断点。

### 6. 比例跨代累积

每一代结束后计算性状轴各区间的数量与比例，并把当前代加入右侧短历史轨迹。

显示值：

- 各性状区间数量：模拟数组计数，使用 `Lec.P.formatNumber(...)`
- 各性状区间比例：`Lec.P.percent(binCount / populationCount)`
- 群体性状均值：`sum(trait) / populationCount`，经 `Lec.P.finite(...)` 后使用 `Lec.P.formatNumber(...)`
- 相对初始代的比例变化：`Lec.P.percent(currentShare - initialShare)`；界面明确标为“百分点变化”时，按统一百分比格式输出，不把百分点误写为增长率
- 当前模拟人口规模：读取 `Lec.K.populationSimulationSize` 的所选情景
- 随机序列：课程种子 `Lec.K.populationSimulationSeed` 与子种子 `p08-selection`
- 重置后回到完全相同的初始群体；“换一次随机样本”显式更换页面种子并显示种子短码

历史轨迹只保留本次运行所需的短窗口，不延伸为人类演化时间轴。

## 必须点出来的一到三句

自然选择改变的是群体中性状的比例，不是个体为了适应环境而按需升级。

环境筛选已有的可遗传差异；差异只有通过繁殖并跨越多代，才会累积成群体变化。

## 交互（只有这一个）

**繁殖群体模拟器**

学习者先拖动“环境偏向”，再点击“繁殖一代”或按住“连续繁殖”。点击运行前，必须先预测下一阶段群体比例会“向左移动、基本不变或向右移动”。

运行时依次看到：

1. 群体中原有的性状差异；
2. 不同性状获得不同繁殖权重；
3. 部分个体被抽中为亲代；
4. 后代继承亲代性状；
5. 后代整批替换亲代；
6. 右侧比例条与历史轨迹更新。

反馈只判断预测方向是否与实际模拟结果一致，不设积分榜。单代可能因随机抽样偏离预测；连续若干代后再判断总体方向，并提示小群体波动通常更明显。学习者应形成的直觉是：**个体保持原性状，变化发生在代与代之间的群体构成中。**

控制项限于：

- 环境偏向
- 繁殖一代／连续繁殖
- 暂停
- 重置同一种子
- 更换种子
- 群体规模情景
- 预测方向

所有控件共同服务于同一个模拟器，不拆成第二个交互。

## 不许碰

- 不讲模仿、教学、语言、规范、制度或其他文化传播机制；这些属于 p24–30。
- 不把个体一生中的锻炼、学习、生理调节或获得性改变画成遗传给后代。
- 不展开基因、DNA、显隐性、等位基因、基因组突变率等分子细节。
- 不把环境写成主动挑选、奖励或命令个体，也不使用“为了生存所以进化出”之类目的论表达。
- 不把模拟中的抽象性状对应为真实族群价值、智力、文明程度或“高等／低等”。
- 不声称一次运行就是现实预测；固定种子只用于课堂复现。
- 不展开随机漂变的正式定义；只提示有限群体会有抽样波动，为理解模拟结果服务。
- 不进入火星多代演化、基因交流、突变率或物种形成；这些属于 p47、p49。
- 不重复 p07 对自然选择必要条件的完整定义，只把那些条件投入运行。

## 版面提示

采用 `split-lr`。

左侧约占主内容区三分之二：PixiJS 群体画布，上方为环境偏向控制，下方为运行、暂停、重置与换种子。亲代始终位于上半区，后代在代际切换时从下半区生成，随后接管画布，强化前后态。

右侧约占三分之一：六步竖向流程主干。当前步骤高亮，其余步骤保持可读但降亮度；流程下方放性状比例条、上一代轮廓线和短历史轨迹。预测控件位于运行按钮之前，避免学生先看结果再作答。

左右之间只保留一组从“繁殖机会不同”指向“新一代比例”的方向箭头；不得用个体变形箭头连接同一标记的前后状态。
