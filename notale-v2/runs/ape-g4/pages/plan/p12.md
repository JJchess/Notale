# page-12 · 不是一个第一特征 · **40 秒**

## 知识结构：enumeration
把下一章的身体变化显式化为六个并列观察面：行走结构、运动方式、脑与能量、手与抓握、饮食与成长、合作网络。

画面采用横向主干与六条等权分支：六项沿同一基线排列，不设置起点、终点、王冠或高低层级；分支之间以少量双向细线标出“彼此牵制”，避免读成六个互不相关的器官清单。主干末端只指向本章的问题：“这些变化怎样共同形成一组折中？”

## 表征形式
静态技术线框信息板。

中央是一具不写实的人体轮廓，仅作空间索引；六个观察项从对应区域拆出，放入等宽标注模块。身体轮廓与模块之间使用细引线，模块之间使用克制的双向连接线。所有模块同时呈现，不按顺序播放，不制造“先有某特征、再导致其他特征”的时间暗示。

## 并列的各项
- **行走结构**  
  对应骨盆、脊柱与下肢。标注词：`支撑 / 平衡 / 受力`。只预告结构关系，不解释具体形态与因果。

- **运动方式**  
  对应步行、奔跑与散热。标注词：`重心 / 步态 / 耐力`。只提出运动是全身协调问题，不展开步态动力学或耐力起源。

- **脑与能量**  
  对应脑的能力、能耗与发育成本。标注词：`连接 / 能量 / 成本`。不显示脑容量数值，不把脑大小写成智力排名。

- **手与抓握**  
  对应手指、肌肉、感觉与练习。标注词：`力量握 / 精细握 / 反馈`。只预告身体协作，不进入工具制作与文化累积。

- **饮食与成长**  
  对应牙齿提供的饮食线索，以及漫长童年的照料与学习窗口。标注词：`食物线索 / 发育 / 照料`。不讲火、烹饪、农业或固定食谱。

- **合作网络**  
  对应共享注意、分工与共同解决问题。标注词：`共享注意 / 分工 / 网络`。只把合作列为身体与行为共同运作的观察面，不展开语言、制度或知识外置。

- **项间连接**  
  用双向细线连接“行走结构—运动方式”“脑与能量—饮食与成长”“手与抓握—合作网络”；线旁统一标注“约束 ↔ 机会”。这些连接只表达相互影响，不声明单向因果或唯一解释。

画面不出现定量数值、年代、比例或排名，因此本页不调用 `Lec.K` 常量或 `Lec.P` 计算函数。

## 必须点出来的一到三句
**Kicker：BODY AS A SYSTEM**

**主标题：不是一个“第一特征”**

接下来不找哪个特征单独创造了人类，而看行走、运动、脑、手、饮食、成长与合作如何彼此牵制。  
人的身体不是完美零件的集合，而是一组共同工作的折中。

## 不许碰
- 不讲衣物、住所、容器、火、烹饪、工具文化、语言、文字、制度等文化外置适应；这些留给 p24–30。
