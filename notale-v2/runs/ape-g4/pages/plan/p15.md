# page-15 · 跑得久，是否因为更会散热？ · **115 秒**

**Kicker：BODY × HEAT**

## 知识结构：comparison

把“支持协同的证据”与“不能推出单一起因的限制”并排显式化。

上半屏采用对齐的四行 × 两列比较表：每一行左侧呈现一种可能支持直立、出汗与耐力活动协同的关系，右侧紧贴该证据能支持到哪里、不能支持什么。行间保持严格对齐，避免把多个相关性串成单向因果链。

下半屏用同一赛程中的两种环境前后态作动态比较：学习者只改变活动强度与散热条件，同时观察“产热”“可散热能力”“热量缺口”三项如何分离。比较重点不是哪种身体“更先进”，而是同一套身体特征在不同环境中是否形成可行组合。

## 表征形式

交互式比较页。

上半屏是静态证据—限制对照表；下半屏是可调参数的跑步散热赛。比赛画面不模拟完整人体生理，而以两个并行热量账本表示：

- 左账本：活动产生、需要排出的热量。
- 右账本：当前温度、湿度、风速和出汗能力下可带走的热量。
- 中央赛道：仅把账本结果转译为“可持续推进”“热量正在积累”“需要降速或改善散热”三种状态。

所有结果持续标注“教学简化模型”，不把模拟胜负当作演化历史证据。

## 四行 × 两列

| 比较维度 | 支持“可能协同” | 不能据此推出 |
|---|---|---|
| 姿势与受热 | 直立姿势可能减少正午时段直接朝向高位太阳的体表面积，并让身体更多区域接触较高处的气流。 | 不能推出直立行走“就是为了散热”而出现；姿势还受移动、取食、观察和受力等多重约束。 |
| 体表与蒸发 | 较强的全身出汗能力与相对较少的体毛，有利于通过汗液蒸发带走热量。 | 出汗不保证一定有效；高湿度、低风速、缺水和汗液未蒸发都会削弱收益。 |
| 活动方式 | 在适宜环境、配速和补水条件下，持续散热可能帮助人类维持较长时间的中低强度活动。 | 不能把“能耐力活动”改写成所有早期人类都以长跑狩猎为主，也不能把现代运动表现直接投射到全部古人群。 |
| 证据性质 | 比较生理学、人体热平衡实验、解剖特征与部分民族志案例可共同支持协同假说。 | 软组织很少直接保存，行为也不易化石化；这些证据不能锁定一个时间点、一个场景或一个公认的单一起因。 |

证据标签统一调用 `Lec.K.evidenceLabels`：

- 姿势改变受热与气流：`有支持但仍争议`
- 出汗蒸发可带走热量：`较确定`
- 耐力活动在演化中所占角色：`有支持但仍争议`
- 单一起因叙事：不授予证据标签，显示“证据不足以唯一判定”

### 散热赛的量与算法

页面所有可见数字均由 `Lec` 提供或现场计算，不写死在组件文本中。

**参考人物**

- 参考体质量：`Lec.K.bodyMassReferenceKg`，显示单位 `kg`。
- 参考重力：如界面需要把质量换算为近地表重量，只调用 `Lec.P.weight(Lec.K.bodyMassReferenceKg, Lec.K.standardGravityMS2)`，显示单位 `N`；默认主画面不显示重量，避免偏离热平衡主题。

**交互参数**

新增页级常量对象 `Lec.K.p15HeatRaceScenarios`，所有默认值、最小值、最大值和步长均从该对象读取：

- 活动强度：单位 `W/kg`。
- 空气温度：单位 `°C`；内部计算先由 `Lec.P.p15CelsiusToKelvin(...)` 转为 `K`。
- 相对湿度：内部保存为 `0–1` 比例，显示调用 `Lec.P.percent(...)`。
- 风速：单位 `m/s`。
- 有效出汗率：单位 `L/h`。
- 赛程时长：单位 `min`，显示调用 `Lec.P.formatDuration(...)`。
- 配速：单位 `min/km`；赛程距离由时间与配速现场计算，显示单位 `km`。
- “干热有风”“湿热少风”两个情景预设的全部参数也存入 `Lec.K.p15HeatRaceScenarios`，按钮不得把数值写在标签中。

**产热账本**

- 活动代谢功率由 `Lec.P.p15MetabolicPower(activityWPerKg, bodyMassKg)` 计算，输出单位 `W`。
- 需要排出的热功率由 `Lec.P.p15HeatProduction(metabolicPowerW, externalMechanicalPowerW)` 计算，输出单位 `W`。
- 本页不从食物热量反推产热，也不调用脑能耗数据。

**散热账本**

- 饱和水汽压由 `Lec.P.p15SaturationVaporPressure(airTemperatureK)` 计算，输出单位 `Pa`。
- 空气水汽压由 `Lec.P.p15AmbientVaporPressure(saturationVaporPressurePa, relativeHumidityRatio)` 计算，输出单位 `Pa`。
- 汗液全部蒸发时的理论上限由 `Lec.P.p15SweatEvaporationPower(sweatRateLPerHour, Lec.K.waterDensityKgM3, Lec.K.p15WaterLatentHeatJPerKg)` 计算，输出单位 `W`。
- 环境允许的有效蒸发比例由 `Lec.P.p15EvaporationEfficiency(airTemperatureK, relativeHumidityRatio, windSpeedMPerS)` 计算；该函数必须返回 `0–1`，并经 `Lec.P.finite(...)` 与 `Lec.P.clamp(...)` 处理。
- 有效蒸发散热由 `Lec.P.p15EffectiveEvaporativeCooling(theoreticalEvaporationW, evaporationEfficiency)` 计算，输出单位 `W`。
- 对流与辐射散热合并为教学项，由 `Lec.P.p15DryHeatExchange(bodyMassKg, airTemperatureK, windSpeedMPerS)` 估算，输出单位 `W`；当环境热于模型皮肤温度时允许显示为负值，表示环境向身体传热。
- 总散热能力由 `Lec.P.p15TotalCooling(evaporativeCoolingW, dryHeatExchangeW)` 计算，输出单位 `W`。

`Lec.K.p15WaterLatentHeatJPerKg`、模型皮肤温度、体表面积估算参数和各换热系数只服务于本页，必须集中定义在 `Lec.K.p15HeatModel`；界面注明这些是教学近似参数，不显示为跨环境不变的人体常数。

**比赛反馈**

- 热量缺口由 `Lec.P.p15HeatGap(heatProductionW, totalCoolingW)` 计算，单位 `W`。
- 赛程累计净热量由 `Lec.P.p15AccumulatedHeat(heatGapW, durationSeconds)` 计算，单位 `kJ`；时间先调用 `Lec.P.minutesToSeconds(...)`，若全套未提供该函数，则调用 `Lec.P.hoursToSeconds(durationMinutes / Lec.K.p15MinutesPerHour)`。
- 距离由 `Lec.P.p15Distance(durationMinutes, paceMinutesPerKm)` 计算，单位 `km`。
- 所有功率、时间、距离和累计热量调用 `Lec.P.formatNumber(...)` 或 `Lec.P.formatDuration(...)` 控制有效位数。
- 状态阈值全部来自 `Lec.K.p15HeatModel.statusThresholdsW`，由 `Lec.P.p15HeatStatus(heatGapW, thresholds)` 返回：
  - `可持续推进`
  - `热量正在积累`
  - `需要降速或改善散热`

状态只描述当前模型中的热账本，不显示核心体温、脱水百分比、医疗诊断或安全运动建议。

## 必须点出来的一到三句

直立、出汗和耐力活动可能形成相互支持的组合，但不存在单一公认起因。

散热能力不是身体的固定“等级”：温度、湿度、风、补水与活动强度一变，同一副身体的结果也会改变。

## 交互（只有这一个）

**调节跑步散热赛**

学习者先选择“干热有风”或“湿热少风”作为环境，再调节活动强度；高级控件允许展开空气温度、相对湿度、风速、有效出汗率、赛程时长与配速。

每次调节同步改变：

1. 赛道中人物的推进状态，不用速度快慢直接代表优劣。
2. 产热与总散热两条对齐功率条，统一使用 `W`。
3. 热量缺口与赛程累计净热量。
4. 证据表中“出汗不保证一定有效”一格的高亮程度。

目标是在指定赛程内找到至少一组“可持续推进”的参数组合；成功条件由 `Lec.P.p15HeatStatus(...)` 与完成距离共同判断。若热量持续积累，不判定人物“失败”，而提示学习者尝试降强度、增风或降低湿度，并明确现实中的天气通常不能由跑者控制。

重置恢复当前情景预设；切换情景时保留学习者的活动强度，便于比较同一活动在不同散热环境中的结果。

应形成的直觉：耐力表现来自身体特征、行为策略与环境条件的配合；模拟能说明协同机制，却不能反推出该组合在演化史中只有一个起因。

## 不许碰

- 不讲脑容量、脑能耗、脑扩张或“耐力活动促进大脑变大”；这些属于 p17–18。
- 不把耐力跑假说写成定论，不宣称长跑狩猎是直立、少毛或出汗能力出现的唯一原因。
- 不写“人类为跑步而演化”“身体为了散热而站起来”等目的论句式。
- 不把现代运动员数据当作早期人类的直接测量。
- 不扩展 p13 的骨盆、脊柱与下肢结构，也不重复 p14 的步态重心机制。
- 不提供中暑阈值、核心体温预测、个体运动处方或医疗安全建议。
- 不比较族群、性别或地域人群的“耐热优劣”，不把训练与环境适应差异解释成固定等级。
- 不让小游戏结果充当演化起因的证明。
