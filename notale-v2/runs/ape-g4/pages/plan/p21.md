# page-21 · 长大得慢，学得更久 · **120 秒**

**Kicker：** `LIFE HISTORY TRADE-OFF`

## 知识结构：comparison

把“较短依赖期”与“较长依赖期”放在同一年龄轴上比较，显式呈现生命周期中的折中，而不是把漫长童年解释成单向优势。

骨架采用对齐的两列、四行：

- 两列：较短依赖期教学模型 / 较长依赖期教学模型。
- 四行：独立获取资源、照料需求、学习窗口、风险暴露。
- 左侧主图用两组对齐曲线表示前两项如何随年龄改变；右侧维度表同步比较后两项及累计结果。
- 曲线与表格共享同一条年龄轴和同一个可调参数，突出“学习窗口延长”与“照料成本增加”同时发生。

## 表征形式

交互式生命周期比较图，使用 ECharts，`renderer: 'svg'`。

左侧为主图：

- 横轴：年龄，单位为年。
- 纵轴：相对水平，范围为 `0–1`，不冒充可直接测量的统一生理量。
- 实线表示“独立获取资源能力”。
- 半透明面积表示“仍需他人支持的程度”。
- 淡色横向区带表示“可持续学习窗口”。
- 固定保留一条较短依赖期基线；学生调整较长依赖期曲线，与基线即时对照。
- 不画身高、脑容量或学校阶段，避免把多个不同过程压成一条“成长速度”。

右侧为四行 × 两列的维度表，并在底部放置唯一控件“依赖期长度”。表格随曲线更新，但不设置得分、胜负或最优值。

## 四行 × 两列

| 比较维度 | 较短依赖期教学模型 | 较长依赖期教学模型 |
|---|---|---|
| 独立获取资源 | 较早接近稳定水平 | 较晚接近稳定水平 |
| 照料需求 | 较早下降，累计支持较少 | 较晚下降，累计支持较多 |
| 学习窗口 | 较早收窄 | 保持开放更久 |
| 风险暴露 | 照料者负担期较短 | 更依赖照料者、食物与群体稳定 |

表格底部并列显示两个由曲线计算的模型结果：

- `累计照料需求`：支持需求曲线下的面积，单位为“相对支持年”。
- `学习窗口长度`：学习窗口高于阈值的持续时间，单位为年。

二者只用于比较同一教学模型中的情景，不标注为真实人群的实测总成本或真实学习能力。

### 成长曲线参数与算法

页面新增并统一从以下 `Lec` 项读取：

- `Lec.K.p21AgeAxisStartYears = 0`：横轴起点，画面显示 `0 岁`。
- `Lec.K.p21AgeAxisEndYears = 25`：横轴终点，画面显示 `25 岁`。
- `Lec.K.p21AgeStepYears = 0.25`：曲线采样步长，不在主画面显示。
- `Lec.K.p21ShortDependencyYears = 8`：较短依赖期教学基线，图例与刻度提示显示 `8 年`。
- `Lec.K.p21LongDependencyDefaultYears = 16`：较长依赖期默认值，控件显示 `16 年`。
- `Lec.K.p21LongDependencyRangeYears = [10, 20]`：滑块两端显示 `10 年`、`20 年`。
- `Lec.K.p21LongDependencyStepYears = 1`：滑块步长，当前值显示为整数年。
- `Lec.K.p21TransitionWidthYears = 2`：能力增长与支持下降的平滑过渡宽度；不在主画面显示。
- `Lec.K.p21LearningWindowThreshold = 0.5`：计算学习窗口长度的模型阈值；不在主画面显示。
- `Lec.K.p21RelativeScaleMin = 0`、`Lec.K.p21RelativeScaleMax = 1`：纵轴显示 `0`、`0.5`、`1.0`，分别标注“低”“中”“高”。
- `Lec.K.p21ChartSampleCount`：由  
  `Math.floor((ageEnd - ageStart) / ageStep) + 1`  
  当场计算，不写死。

对任一依赖期参数 `d`，年龄为 `a`：

- 独立获取资源能力：  
  `Lec.P.p21IndependentCapacity(a, d, transitionWidth)`  
  使用限制在 `0–1` 的平滑 S 形函数，中心点为 `d`。
- 照料需求：  
  `Lec.P.p21CareNeed(a, d, transitionWidth)`  
  计算为 `1 - independentCapacity`，再经 `Lec.P.clamp(..., 0, 1)`。
- 学习窗口：  
  `Lec.P.p21LearningOpportunity(a, d)`  
  返回教学模型中的相对开放度；依赖期延长时，窗口收窄点随 `d` 后移，但峰值不得随意增高。
- 累计照料需求：  
  `Lec.P.p21CurveArea(careSeries, ageStep)`  
  用梯形积分计算，输出单位为“相对支持年”；显示值经 `Lec.P.formatNumber(value, 1)`。
- 学习窗口长度：  
  `Lec.P.p21DurationAboveThreshold(learningSeries, threshold, ageStep)`  
  输出年，显示值经 `Lec.P.formatNumber(value, 1)`。
- 两情景差值：  
  `Lec.P.p21Difference(longValue, shortValue)`，先经 `Lec.P.finite` 检查；显示为 `+x.x 年` 或 `+x.x 相对支持年`。
- 所有滑块输入先经  
  `Lec.P.clamp(value, rangeMin, rangeMax)`  
  与 `Lec.P.finite(value)` 处理。

图下注明：

“曲线是用来观察折中的教学模型，不是所有儿童或所有社会的统一成长表。”

## 必须点出来的一到三句

人类漫长童年增加照料成本，也延长了学习窗口。

“长大得慢”不是单纯缺陷或单纯优势：它只有在持续照料、合作供给和安全关系中，才可能转化为更多学习机会。

## 交互（只有这一个）

**调整成长曲线**

学生拖动“依赖期长度”滑块，在 `Lec.K.p21LongDependencyRangeYears` 内改变较长依赖期曲线的转折年龄。

拖动时同步发生三项变化：

1. “独立获取资源能力”曲线的上升段向左或向右移动。
2. “照料需求”面积缩小或扩大。
3. 右侧表格中的“累计照料需求”和“学习窗口长度”重新计算，并与固定的较短依赖期基线显示差值。

学生应形成的直觉是：把独立生活推迟，会同时扩大照料投入与可用于学习的时间；不存在只增加收益、不增加依赖的免费调整。

控件默认停在 `Lec.K.p21LongDependencyDefaultYears`。提供“恢复默认”按钮，但不增加第二个可调参数。键盘左右方向键按 `Lec.K.p21LongDependencyStepYears` 调整，图表更新通过 `aria-live="polite"` 宣读当前依赖期及两项结果。

## 不许碰

- 不讲学校、学制、入学年龄、考试或现代教育制度。
- 不把“童年结束”绑定到毕业、就业或法定成年。
- 不宣称存在适用于所有文化、历史时期和个体的唯一童年长度。
- 不把学习窗口理解为过期后不能学习；这里只比较相对开放时间，不讨论成年人学习能力。
- 不把漫长童年说成单独造就人类，也不与脑容量、语言或文化累积竞争“第一特征”。
- 不展开知识如何跨代保存、模仿和修正；文化累积留给 p27。
- 不把照料只归于母亲或核心家庭；统一使用“照料者与合作群体”。
- 不把教学模型的“相对支持年”写成现实家庭的时间、金钱或热量成本。
- 不将较长依赖期评价为必然更先进、更聪明或更优越。
