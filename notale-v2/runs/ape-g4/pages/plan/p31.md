# page-31 · 驯化的回路 · **115 秒**

**Kicker：** `DOMESTICATION LOOP`  
**主标题：** 你在选择作物，作物也在重排你的生活

## 知识结构：process

把“驯化”显式化为一个带反馈的六步循环，而不是人类对其他物种的一次性改造：

**野生差异 → 人为留种 → 性状比例改变 → 收获方式改变 → 定居投入增加 → 下一轮选择条件改变**

左侧实验区运行前四步；右侧生活回路将收获结果转换为储存需求、劳动安排、食物来源集中度与定居依赖，再用回箭头连回下一季的留种条件。

每季结束后，主箭头逐段点亮；至少完成两季才显示闭合的反馈箭头，避免把单代筛选误画成已经完成的驯化。

## 表征形式

交互式动态过程模型。

左侧用 PixiJS 呈现一块抽象谷物田：每株植物只编码三个教学性状——籽粒大小、成熟同步度、脱落难易。学习者从本季收获中选择留种，下一季种群按留种样本重新生成。

右侧不是第二个游戏，而是同一过程的反馈面板：以四条随季节更新的水平轨道显示收获集中度、储存需求、劳动集中度与食物来源多样性。轨道变化由左侧种群结果直接计算。

所有植株、籽粒和村落图标均为抽象模型符号，不用写实复原图，不暗示某一地区存在唯一农业起源路线。

## 六个 step

1. **野生差异**  
   初始种群中的籽粒大小、成熟时间和自然脱落倾向存在差异。差异由固定种子生成，不把个体排列预设成“原始—进步”等级。

2. **采集本季收获**  
   成熟植株进入可采集状态；成熟不同步或容易提前脱落的植株更可能错过采集窗口。

3. **选择留种**  
   学习者只能从实际收获到的籽粒中留种，可偏向“大籽粒”“同期成熟”或“不易脱落”，也可维持混合选择。

4. **生成下一季**  
   下一季性状从留种样本分布中抽样，并叠加教学模型中的遗传变异与随机波动。页面强调这是简化的性状模拟，不对应单个真实基因。

5. **生活安排改变**  
   收获越集中，短期劳动峰值和储存需求越高；食物来源越集中，对该作物及其生长地点的依赖越强。

6. **反馈到下一轮**  
   已投入的田地、储存设施和季节性劳动，使学习者下一季更可能继续选择适合集中种植与收获的性状。人类改变种群，改变后的种群又重排人的时间、地点与资源投入。

### 实验参数与画面数值

- **农业出现的时间量级：** 画面注记显示“约 `Lec.K.agricultureYearsAgo` 年前”；格式由 `Lec.P.formatNumber(...)` 生成，并附“不同地区并非同时发生”。
- **模拟随机种子：** 使用课程级 `Lec.K.populationSimulationSeed` 派生页面子种子 `p31-domestication`；种子编号可在实验设置中显示，但不得作为历史数据解读。
- **实验季数：** 当前季显示为“第 n 季”，`n` 来自模拟状态 `seasonIndex`；最大季数来自 `Lec.K.p31DomesticationScenario.maxSeasons`。
- **每季植株数：** 来自 `Lec.K.p31DomesticationScenario.populationSize`，单位“株”；不得直接复用现实人口参数。
- **可留种数量：** 来自 `Lec.K.p31DomesticationScenario.seedQuota`，单位“粒”；若按比例设置，则由当季可收获数乘 `seedQuotaFraction` 后取整。
- **籽粒大小：** 使用无量纲教学性状 `grainSizeTrait`，页面显示为相对初始种群均值的百分比：  
  `Lec.P.percent(currentMean / initialMean - 1)`。
- **成熟同步度：** 计算为采集窗口内成熟植株数除以本季植株总数：  
  `Lec.P.percent(harvestWindowCount / populationSize)`。
- **不易脱落比例：** 采集时仍保留籽粒的植株数除以成熟植株数：  
  `Lec.P.percent(retainedSeedCount / maturePlantCount)`。
- **本季可收获量：** 所有成功采集籽粒的模型数量之和，单位“粒”；由模拟当场累计，不换算为真实质量。
- **性状多样性：** 三个性状分别标准化后计算离散度，再取配置权重的加权均值；显示为相对初始季的百分比：  
  `Lec.P.percent(currentDiversity / initialDiversity)`。
- **收获集中度：** 采集窗口内收获量除以全季收获量：  
  `Lec.P.percent(windowYield / totalYield)`。
- **储存需求：** 本季收获量减去即时消耗情景量，再除以本季收获量：  
  `Lec.P.percent((totalYield - immediateUse) / totalYield)`；`immediateUse` 来自 `Lec.K.p31DomesticationScenario.immediateUseFraction`。
- **劳动集中度：** 采集窗口内所需劳动单位除以全季劳动单位：  
  `Lec.P.percent(windowLabor / totalLabor)`；劳动权重来自 `Lec.K.p31DomesticationScenario.laborWeights`，明确标为教学参数。
- **食物来源多样性：** 由作物来源与其他来源的份额计算归一化多样性指数；份额来自当前实验状态与 `Lec.K.p31DomesticationScenario.otherFoodSources`，输出经 `Lec.P.percent(...)`。
- **定居依赖：** 由田地投入、储存投入和食物来源集中度按配置权重合成：  
  `Lec.P.clamp(weightedDependency, 0, 1)`，再由 `Lec.P.percent(...)` 显示。
- **证据标签：** “农业在多地独立发生、时间不同”使用 `Lec.K.evidenceLabels` 中“较确定”；具体性状与生活反馈的概括使用“有支持但仍争议”；模拟产生的单次结果标为“模型推测”。
- 所有除法先经 `Lec.P.ratio(...)` 处理零分母；所有输入先经 `Lec.P.finite(...)` 与 `Lec.P.clamp(...)` 检查；显示值统一由 `Lec.P.formatNumber(...)` 控制有效位数。
- `Lec.K.p31DomesticationScenario` 中的种群规模、季数、采集窗口、留种配额、性状变异、劳动权重与生活反馈权重必须集中配置；主画面不得散落字面数字。

## 必须点出来的一到三句

人类通过反复采集和留种，逐代改变了其他物种中性状的比例。

但这不是单向控制：更集中、可储存的收获也会重排人的劳动、饮食来源和定居投入。

## 交互（只有这一个）

**驯化选择实验**

学习者每季在左侧田地中框选留种植株，或使用“偏大籽粒”“偏同期成熟”“偏不易脱落”“混合留种”四种选择策略；留种配额固定，不能把所有植株都保留。

点击“进入下一季”后：

- PixiJS 重新生成下一季种群；
- 三项性状分布平滑过渡；
- 主过程箭头推进一步；
- 右侧四条生活反馈轨道同步变化；
- 被强化的收益与代价同时高亮，不给单一“最佳品种”评分。

实验目标是在最大季数内，让学习者亲手形成可辨认的跨季性状偏移，并成功闭合“留种—收获—生活安排—下一轮留种”的反馈回路。完成条件是连续多个季节出现方向一致的性状变化，同时右侧至少一项生活安排发生可见改变；若只运行一季、随机留种未形成趋势或耗尽季数，则提示“尚不足以判断，重置或换种子再试”，不把随机结果判为错误知识。

提供：

- **重置同一种子：** 完全复现实验；
- **换种子：** 从课程级种子派生新的显式子种子；
- **自动播放下一季：** 只重复当前留种策略，不替学习者选择目标；
- **查看前后态：** 叠加初始季与当前季的性状分布；
- **暂停动画：** 保留最终状态，满足课后重看与减少动态效果需求。

学习者应形成的直觉是：驯化来自许多轮有偏留种的累积；选择改变物种群体后，人类自己的生活条件也随之改变，并反馈到下一轮选择。

## 不许碰

- 不出现 CRISPR、基因编辑、胚胎编辑、定向改写 DNA 或“设计物种”等现代主动基因改造内容；这些只属于 p48。
- 不把驯化画成单次发明、单一地点起源或必然通向现代农业的直线。
- 不把作物性状变化解释为个体“为了被人种植而主动改变”；只表现群体中既有差异经过多轮留种后比例改变。
- 不扩展城市高密度接触、传染网络与资源中断风险；这些属于 p32。
- 不重新讲自然选择的完整必要条件或运行跨代自然选择模拟；这里只调用 p07–08 已建立的原则，聚焦人为选择与生活反馈。
- 不把模型中的无量纲性状、劳动单位、季数或单次随机结果冒充考古测量值。
- 不宣称定居只由农业造成，也不宣称农业必然减少饮食多样性；右侧只展示可调情景中的依赖与折中。
- 不列举或背诵全球驯化物种清单；本页只完成一个反馈过程。
