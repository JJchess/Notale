# page-46 · 恢复不是逆向演化 · **115 秒**

**Kicker：** `THREE CLOCKS`  
**主标题：** 回到地球，身体把变化放回哪只时钟？

## 知识结构：classification

把“宇航员返地后的变化”按发生层级归入三只时钟：

- **短时生理调节**：同一个体内，体液、平衡感觉等系统重新适应重力环境。
- **个体生命期重塑**：同一个体内，骨、肌肉等组织在重新承重和训练后恢复；可能较慢，也可能不完全。
- **多代演化**：需要跨代群体证据；本页案例不能归入这一类。

骨架以三列并排的 triptych 显式化。每列顶部是一只速度不同的时钟，中部是分类投放区，底部固定显示判据。卡片归位后用“原变化 → 返地后状态”的前后态连接线呈现恢复方向；第三列保持为空，并显示“本页没有跨代证据”。

## 表征形式

交互式三联分类台，使用 Konva 绘制可拖拽卡片、投放区、时钟指针和前后态连线。

心理表征重点不是记忆具体恢复期限，而是把变化放回正确层级：同一个人的身体在不同环境中调节或重塑，不等于群体跨世代演化。三只时钟始终同时可见，避免把“恢复较慢”误判为“演化”。

## 层级里的各项

### 短时生理调节

判据文案：

- 发生在同一个体内。
- 环境改变后，调节方向可以再次改变。
- “可逆”不等于立即完成，也不等于人人完全相同。

归位卡片：

- **体液重新分布**  
  飞行中：微重力下体液分布改变。  
  返地后：重力再次影响体液分布，循环系统重新调节。

- **站立时的循环调节**  
  飞行中：长期不必持续对抗由头到脚的重力方向。  
  返地后：站立时可能暂时不适，需要重新适应直立状态。

- **平衡与方向感**  
  飞行中：视觉、前庭觉与身体感觉在微重力中重新配合。  
  返地后：旧的重力线索重新出现，感觉系统再次校准。

### 个体生命期重塑

判据文案：

- 仍发生在同一个体内。
- 组织会响应负荷、活动与训练。
- 恢复可以是部分可逆，程度和速度存在个体差异。

归位卡片：

- **抗重力肌群的力量与耐力**  
  飞行中：日常承重刺激减少。  
  返地后：重新承重和训练可促使功能恢复，但不保证立刻或完全回到出发前状态。

- **承重部位的骨组织**  
  飞行中：维持骨组织的机械刺激减少。  
  返地后：重新负重可推动重塑；恢复可能较慢或不完全。

- **动作控制**  
  飞行中：推、拉、转身和移动采用适合微重力的动作策略。  
  返地后：走路、转身和接住身体重量需要重新协调。

### 多代演化

判据文案：

- 判断单位必须是跨许多代的群体，而不是一名宇航员。
- 返地后的体液、平衡、骨肌和动作变化都不能放入此列。
- 本页只把边界标出，不展开遗传、选择或繁殖差异。

空列提示：

- **本页没有可归入此时钟的证据。**
- **个人恢复不是“逆向演化”。**

### 画面数值与生成口径

主画面不显示恢复天数、周数、月数、百分比或统一恢复率，避免把个体差异写成固定期限。

页面状态中出现的卡片总数、已归位数和剩余数均由卡片配置数组与当前分类状态即时计算，不写死：

- `total = recoveryCards.length`
- `placed = recoveryCards.filter(card => card.zoneId !== null).length`
- `remaining = total - placed`
- 完成度调用 `Lec.P.ratio(placed, total)`；分母异常时由统一函数阻止显示。
- 所有交互坐标和时钟指针进度先经 `Lec.P.finite(...)` 与 `Lec.P.clamp(...)` 检查。

完成反馈只显示“已归位”“再检查”“归位完成”等文字，不在主画面显示分数或百分比。

## 必须点出来的一到三句

宇航员回到地球后的恢复不是“逆向演化”，而是同一个体发生的可逆或部分可逆生理变化。

恢复得慢、恢复不完全，也不会自动把它变成跨代演化。

## 交互（只有这一个）

**三时钟归位**

读者拖动六张返地变化卡，放入“短时生理调节”“个体生命期重塑”或“多代演化”三列。

拖动时：

- 卡片上的飞行中状态保持可见。
- 接近投放区时，该列底部的分类判据高亮。
- 放入正确列后，卡片展开返地后状态，并绘出“飞行中 → 返地后”的前后态连线。
- 放入错误列后，卡片弹回，只提示应检查的判据，不直接报出答案。
- 如果把任一卡片放入“多代演化”，第三列暂停时钟并提示：“这是同一个人的变化；跨代证据在哪里？”

胜利条件：

- 所有卡片正确归入前两列。
- “多代演化”列保持为空。
- 完成后两列时钟继续运行，第三列显示“需要跨代证据”，中央浮现结论：“恢复 ≠ 逆向演化”。

提供“重新归位”按钮，清空投放状态并恢复卡片初始顺序。键盘用户可聚焦卡片，以方向键选择列、确认键投放；屏幕阅读器同步播报卡片、目标列、判据和结果。

## 不许碰

- 不解释可遗传差异、自然选择、繁殖差异、基因频率或群体如何跨代改变；这些属于 p47。
- 不建立宇航员后代模型，也不讨论太空环境是否会选择某种遗传性状。
- 不使用“退化”“逆向演化”“身体按需升级”等表述描述返地变化。
- 不给骨、肌肉、平衡或体液恢复规定统一期限、统一百分比或保证完全恢复。
- 不扩展运动处方、康复方案、药物或临床建议。
- 不把本页案例归因于个人意志、坚强程度或训练态度。
- 不回答太空人是否会成为新物种；该问题留给 p49。
