# page-47 · 许多代之后 · **105 秒**

- kicker：`MANY GENERATIONS`
- 主标题：什么条件下，火星群体才会真的演化？

## 知识结构：process

把“环境压力出现”到“群体性状比例改变”的跨代过程显式化，而不是只展示起点和终点。

画面以从左向右循环推进的六步主干呈现；每完成一代，最后一步的群体回接第一步：

**建立群体 → 产生可遗传差异 → 经历环境条件 → 繁殖机会出现差异 → 后代继承并重组 → 多代累积后比较分布**

每一步在画布中有固定站位和短标签；运行时用移动个体、亲代—后代连线和分布曲线同步显示前后态。主干下方始终保留“第 0 代”基线，避免把单代波动误认成长期趋势。

## 表征形式

动态交互的二维群体模型。

中央 PixiJS 画布显示抽象个体，每个个体是一枚小圆点；横向位置表示抽象性状值，颜色只编码同一性状由低到高，不编码身份、价值或“先进程度”。繁殖时，少量亲代—后代连线短暂出现；代际切换后旧个体淡出，新一代进入。

画布上方是六步流程带，下方是同步更新的性状分布：

- 灰色轮廓：第 0 代分布。
- 高亮轮廓：当前代分布。
- 中位线：当前代群体中位数。
- 半透明带：多次重复运行的变化范围。
- 右侧状态框：当前代数、群体规模、种子、性状变化量，以及当前结果应标为“较确定”还是“模型推测”。

动画只表现代际替换，不把个体画成在一生中主动改变性状。

## 六个 step

### 1. 建立群体

按所选群体规模生成第 0 代个体。每个个体获得一个抽象性状值，页面称为“性状 A”，副标签为“假想的低氧耐受相关性状”；它不是某个已知单基因，也不代表现实火星居民必然面对的选择方向。

初始性状由页面模型常量 `Lec.K.p47TraitInitialDistribution` 定义，并由固定子种子生成。画面显示第 0 代分布，作为之后所有变化的基线。

### 2. 产生可遗传差异

为每个个体生成可传给后代的性状差异。后代性状由亲代值、重组扰动和抽象突变项共同计算：

`offspringTrait = clamp(parentContribution + recombinationNoise + mutationEffect)`

- 突变概率取 `Lec.K.mutationRateTeaching`。
- 扰动和突变效应范围取 `Lec.K.p47InheritanceModel`。
- 所有随机抽样由 seedrandom 和页面子种子 `p47-mars` 驱动。
- 所有输入先经 `Lec.P.finite(...)` 与 `Lec.P.clamp(...)`。

页面明确标注：“突变率是抽象性状模型参数，不对应整个人类基因组突变率。”

### 3. 经历环境条件

加载一个假想的火星居住舱情景。环境不命令个体改变，只使不同性状的个体获得不同的预期繁殖权重。

环境压力强度取 `Lec.K.p47SelectionPressureScenarios`；其含义仅是模型中的弱、中、强差异，不换算为现实氧分压、疾病率或死亡率。

### 4. 繁殖机会出现差异

按个体性状和环境压力计算相对繁殖权重，再进行加权抽样。权重影响被抽为亲代的概率，不保证任何一个体一定留下后代。

当选择压力关闭时，各性状的预期繁殖权重相同，群体仍可能因随机抽样产生漂变。页面不把随机漂变称为适应。

### 5. 后代继承并重组

从抽中的亲代生成下一代，维持当前情景设定的群体规模。若启用外来交流，则按 `Lec.K.geneFlowScenarios` 替换相应比例的后代；外来个体的性状分布取 `Lec.K.p47IncomingPopulationDistribution`。

开放、低交流、完全隔离只作为群体变化参数，不在本页讨论是否形成新物种。

### 6. 多代累积后比较分布

每一代结束后计算当前分布与第 0 代分布的差异，并更新曲线。主读数是群体中位性状的变化量；辅助读数是重复运行范围，用来揭示有限群体中的随机波动。

只有变化方向跨多代持续、且在重复运行中稳定出现时，状态框才显示“持续的群体改变”；单次短暂偏移显示“可能是随机波动”。

所有结论标签均取 `Lec.K.evidenceLabels`，本模型的现实外推固定标为“模型推测”。

### 模型中出现的数值

- 停留时间：**105 秒**，来自本页规格，不进入模拟计算。
- 群体规模：**100、500、2000 个体**，来自 `Lec.K.populationSimulationSize` 的可选档位；默认显示 **500 个体**。
- 模拟代数：**10²、10³、10⁴ 代**，来自 `Lec.K.speciationGenerationScenarios`；本页只把它们用于观察累积速度，不显示“形成新物种”的倒计时。
- 默认一代：**25 年**，来自 `Lec.K.humanGenerationYears`。
- 代长敏感性范围：**20–30 年/代**，来自 `Lec.K.humanGenerationYears` 的敏感性配置。
- 对应年份：由“代数 × 所选代长”当场计算，先用 `Lec.P.yearsToSeconds(...)` 统一换算，再用 `Lec.P.formatDuration(...)` 显示；不写死结果。
- 外来交流档位：**开放、低交流、完全隔离**，来自 `Lec.K.geneFlowScenarios`；具体比例读取该常量，不在页面代码中另写。
- 抽象突变率：来自 `Lec.K.mutationRateTeaching`，以 `Lec.P.percent(...)` 显示。
- 性状坐标范围与初始分布参数：来自页面常量 `Lec.K.p47TraitInitialDistribution`；刻度使用“模型单位”，由 `Lec.P.formatNumber(...)` 显示。
- 选择压力档位及相对繁殖权重：来自页面常量 `Lec.K.p47SelectionPressureScenarios`；比例由 `Lec.P.ratio(...)`、百分数由 `Lec.P.percent(...)` 生成。
- 当前代数、当前中位数、相对第 0 代的变化量：由模拟状态实时计算，经 `Lec.P.finite(...)` 检查后用 `Lec.P.formatNumber(...)` 显示。
- 重复运行次数及结果带所用分位点：来自页面常量 `Lec.K.p47ReplicateRuns` 与 `Lec.K.p47ResultBandQuantiles`，不得写死在组件中。
- 默认随机种子：课程级 `Lec.K.populationSimulationSeed` 与页面子种子 `p47-mars` 组合生成；画面显示格式化后的种子标识，不显示未处理的内部哈希值。
- 用户换种子后的编号：由 seedrandom 状态派生，经 `Lec.P.formatNumber(...)` 显示。

## 必须点出来的一到三句

只有可遗传差异持续影响繁殖，并经历许多代，群体才会发生演化改变。

环境不会让个体按需升级；它改变的是不同差异被传到下一代的机会。

有限群体会随机波动，所以一次模拟结果不是对未来火星人的预测。

## 交互（只有这一个）

**多代火星群体模型**

学习者的目标是在同一模型中找出“持续定向改变”出现所需的条件，并把它与短期波动区分开。

1. 先选择群体规模、模拟代数、环境压力、可遗传性和外来交流档位。
2. 按“繁殖一代”可逐代观察六步流程；按“运行到终点”则加速播放关键代际。
3. 学习者看到个体被抽为亲代、后代继承差异、当前分布相对第 0 代逐步移动。
4. 关闭可遗传性时，即使环境压力存在，跨代定向变化不能稳定累积。
5. 关闭繁殖差异时，分布仍会波动，但重复运行的方向不稳定。
6. 同时存在可遗传差异与持续繁殖差异，并运行许多代时，模型才判定为“持续的群体改变”。
7. “换种子”保持所有参数不变，只改变随机序列；学习者可观察小群体比大群体更易漂移。
8. “重置”恢复第 0 代与课程默认种子。

完成条件不是把性状推到最高，而是至少运行三组对照：

- 有遗传、无繁殖差异。
- 无遗传、有繁殖差异。
- 有遗传、有繁殖差异。

三组完成后，界面点亮流程中的必要连接，并反馈：“决定演化的不是个体是否改变，而是哪些差异跨代留下得更多。”

## 不许碰

- 不讲主动基因编辑、胚胎编辑、基因治疗、设计婴儿或任何具体编辑技术；这些留给 p48。
- 不提出应当改造人类基因，也不把某种性状描述为更高级、更纯或更有价值。
- 不讨论火星群体是否已经或何时会成为新物种；不以外形、性状均值或隔离档位直接判定物种，相关判据留给 p49。
- 不把抽象性状 A 对应到某个真实单基因，不宣称低氧耐受一定会成为火星上的主要选择方向。
- 不把火星地表画成人体可直接生存的环境；模型环境明确是“假想居住舱中的长期条件”。
- 不把单代个体变化、训练效果、宇航员返航恢复或发育可塑性称为演化。
- 不把随机漂变误写成环境适应，也不把单次模拟轨迹写成预测。
- 不重新讲解 p07–08 的完整自然选择定义；只调用“可遗传差异—繁殖差异—多代累积”原则。

## 版面提示

采用 `canvas-full`：六步流程带占顶部约一行，PixiJS 群体画布占中央主体，下方叠放第 0 代与当前代分布；参数控制集中在左下，状态与对照任务集中在右下。

主视觉必须是“旧分布留在原位、当前分布跨代移动”的前后态，不使用火星风景、宇航员肖像或 DNA 双螺旋作为主图。控制区不得遮挡群体动画；加速运行时仍保留六步当前站位和代数读数。
