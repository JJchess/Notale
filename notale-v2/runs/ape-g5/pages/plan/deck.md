# 《从猿人到太空人：身体、文化与宇宙边界》90 分钟互动讲义 · 总规划

## 0. 这套讲义的主线

人类并非沿着一架通往“更高级”的梯子走进太空，而是以演化塑造的身体、文化积累的工具和共同承担的风险，把一种地球动物暂时延伸到地球之外。

| 一、先拆掉“猿人变太空人”的直线图 | 01–06 | “猿人—太空人”不是低等到高等的进步阶梯，而是需要从时间、谱系和尺度重新理解的问题。 |
| 二、一副为地球生活拼成的身体 | 07–14 | 直立行走、手、脑、食物与合作共同塑造了人类，但每项能力都有成本，没有单一“制胜升级”。 |
| 三、真正加速的是文化累积 | 15–22 | 个体身体改变很慢，语言、教学、工具和群体协作却能跨代保存解决方案。 |
| 四、离开地面为什么如此困难 | 23–31 | 太空飞行不是“飞得更高”，而是用速度持续错过地面，并为每一点速度支付急剧增长的质量代价。 |

| 六、成为“太空人”意味着什么 | 40–48 | 长期太空生存不是英雄个人的升级，而是生理适应、工程选择、社会制度与伦理边界的共同问题。 |
