# page-07 · 受力链，不是“站直” · **135 秒**

Kicker：`EARTH-BUILT BODY`

主标题：双足行走，重排了全身的受力路径

## 知识结构：process

用一条自下而上的受力主干显式化关系：

地面反作用力 → 足部承接 → 膝与股骨传递 → 骨盆支撑 → 脊柱调节 → 头部平衡

这不是演化年代顺序，也不是“猿逐渐挺直”的前后等级图，而是一次双足支撑中，力如何沿身体向上传递的过程。主画面以同一具概念化人体骨架为中心；姿态改变时，受力箭头、关节高亮和身体重心投影同步更新。

## 表征形式

全屏交互式三维骨架。

学习者可环绕查看骨架，并通过同一个姿态控制环，让模型在“四肢分担支撑”与“双足承重姿态”之间连续变化。画面始终保留地面、足底支撑区、身体重心投影和自下而上的受力链。

骨架不是物种复原，也不表现某个祖先“变成”现代人；它是用于比较支撑方式的概念模型。动态只服务于观察承重点、关节排列和受力路径如何一起变化。

## 箭头上的六段受力链

- **地面 → 足部**  
  地面对支撑点产生向上的反作用。双足姿态下，主要支撑区收拢到两足下方；四肢分担时，支撑区扩展到前后肢之间。地面显示半透明支撑多边形，不显示虚构的精确压力数值。

- **足部 → 小腿**  
  足部不是单纯的“底座”，而是承接地面作用并把力传向踝与小腿。双足承重时，高亮足跟至前足的传力方向；不在本页展开足弓形成史或跑步机制。

- **小腿 → 膝**  
  膝关节需要在承重时保持可控排列。姿态变化时，用关节环和箭头偏折显示：关节不只是把身体“撑直”，还要让力继续向上传递。

- **膝 → 股骨 → 骨盆**  
  股骨向身体中线靠拢，使膝更接近身体重心下方。正面视角最清楚地显示这一关系；不用“腿更高级”或“结构更完美”描述。

- **骨盆 → 脊柱**  
  骨盆承接躯干重量并连接下肢；脊柱曲线帮助躯干在双足支撑时维持平衡。侧面视角中同时显示骨盆方向、脊柱轮廓与重心垂线。

- **脊柱 → 头部**  
  头部需要在躯干上方保持平衡，不能只靠“把背挺直”解释。高亮颅骨与脊柱连接处，但不展开物种鉴定或颅底测量细节。

画面不出现测量数值、角度、年代、身高、质量或力值；本页只有定性受力示意，因此不调用或写死任何数值。箭头长度与亮度只编码当前承重路径是否集中，不冒充真实生物力学测量。

## 必须点出来的一句

双足行走改变的是从足部、膝、骨盆到脊柱和头部的整条受力链，而不是简单地让猿“站直”。

## 交互（只有这一个）

**转动骨架姿态。**

学习者拖动骨架旁的环形姿态控制器；左右拖动改变支撑姿态，上下拖动改变观察仰俯角，直接拖拽骨架空白处则环绕查看。它们共同属于“转动骨架姿态”这一核心动作，不另设第二个任务。

姿态变化时实时联动：

- 四肢分担支撑时，地面支撑区向前后展开，受力箭头分流，躯干前倾。
- 转向双足承重时，支撑区收拢到两足，重心投影进入足间，受力链依次沿足、膝、股骨、骨盆、脊柱到头部亮起。
- 若重心投影落到支撑区外，骨架以琥珀色提示“需要额外支撑”，不播放摔倒动画。
- 到达双足承重端点时，反馈显示：“不是只转直躯干：下肢、骨盆、脊柱与头部必须共同重排。”
- 任意中间姿态显示当前最关键的连接问题，如“膝是否位于重心下方”或“躯干重量由哪里承接”。

提供“重置姿态”入口，恢复默认的中间比较位置与正侧之间的三分之四视角。键盘可用方向键逐步调整姿态与视角，`Home` 重置；控制器具有可读标签、当前状态文本和清晰焦点样式。开启减少动态偏好时取消惯性旋转与平滑过渡，状态直接切换。

学习目标是形成“整条受力链协同改变”的直觉，而不是寻找一个最直、最高或最像现代人的获胜姿态。

## 不许碰

- 不讲拇指、抓握、手部精细操作或手的“解放”；这些内容归 p09。
- 不把前肢不再承担主要支撑直接推导为工具制造或文明出现。
- 不比较双足与四足步态的能耗、速度或长距离效率；这些内容归 p08。
- 不展开耐力跑、狩猎或散热假说；耐力跑完整假说不在本页处理。
- 不把骨架姿态排列成“弯腰猿 → 挺直人”的演化阶梯，也不暗示现生猿类是人的祖先。
- 不宣称双足行走处处更优，不用“升级”“更先进”“完美设计”等措辞。
- 不在本页加入人类演化物种名录、年代、谱系证据或单一成因解释。
- 不把概念化受力箭头描述成临床诊断、真实关节载荷或精确生物力学计算。

## 版面提示

采用 `canvas-full`：骨架占画面中央约三分之二高度，地面与支撑区完整可见。标题与核心主张固定在左上；姿态控制环固定在右下；六段受力链标签沿骨架两侧疏排，以细引线连接对应部位。

默认镜头为正面与侧面之间的三分之四视角，使股骨向中线靠拢、骨盆支撑和脊柱曲线能够同时辨认。标签随镜头自动避让，但不跟随骨架剧烈漂移；当前受力段高亮，其余标签降为低对比度。
