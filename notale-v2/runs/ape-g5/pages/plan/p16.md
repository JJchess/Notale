# page-16 · 把不在场带进讨论 · **145 秒**

Kicker：`SHARED SYMBOLS`

主标题：符号让不在场的事进入共同讨论

## 知识结构：classification

把“符号可以谈什么”分成四类，并用对齐的行列显式化分类依据：

- 主干：群体共享的符号表达
- 第一支：眼前报告——对象或行动就在当前场景中
- 第二支：计划——对象或事件不在眼前，位于别处或未来
- 第三支：规则——表达群体约定的“可以、必须、不得”
- 第四支：假设——表达尚未发生的条件与可能结果

四类始终按同样的三列对齐：

1. 讨论对象是否在眼前
2. 符号组合承担什么功能
3. 一条可由词典组合出的消息

“眼前报告”作为基线；其余三类共同显示符号如何超出此时此地，但不暗示四类是语言演化的先后阶段。

## 表征形式

交互式左右分栏。

左栏是一部小型“共享信号词典”：每个符号由抽象字形、中文释义和可拖动状态组成。字形与含义没有天然相似性，强调意义来自群体约定。

右栏是四条对齐的分类轨道。每条轨道包含情境、待填消息槽和分类反馈。学习者从左栏取符号，组合出能回应情境的消息；完成后，该消息落入对应类别，并点亮“眼前 / 不在场”“计划 / 规则 / 假设”等分类依据。

所有变化由操作直接触发，不使用自动播放的叙事动画。

## 层级里的各项

### 共享信号词典

词典使用抽象符号，不使用水滴、帐篷等直接描画含义的图标：

| 抽象符号 | 共享释义 | 可进入的组合 |
|---|---|---|
| `△` | 水源 | 眼前报告、计划 |
| `○` | 此处 | 眼前报告 |
| `⌁` | 有 | 眼前报告 |
| `⊙` | 明日 | 计划 |
| `→` | 前往 | 计划 |
| `□` | 营地 | 规则、假设 |
| `☾` | 夜间 | 规则 |
| `⊘` | 不得离开 | 规则 |
| `◇` | 如果 | 假设 |
| `≋` | 风暴 | 假设 |
| `∴` | 那么 | 假设 |
| `↩` | 留在 | 假设 |

每个符号必须同时提供可见中文释义与屏幕阅读器名称；不能只靠形状辨认。颜色只标记操作状态，不编码词义类别。

### 四类符号表达

| 类别 | 分类依据 | 情境 | 目标组合 | 即时反馈 |
|---|---|---|---|---|
| 眼前报告 | 对象在当前场景中 | 大家已经看见营地旁的水源 | `此处＋有＋水源` | “这条消息报告眼前情况；指向对象就在此时此地。” |
| 计划 | 指向未来行动或别处对象 | 群体要约定第二天去取水 | `明日＋前往＋水源` | “符号把明日和别处的水源带进当前讨论，群体可以提前协调行动。” |
| 规则 | 指向群体共同遵守的约定 | 群体需要规定夜间不能独自离营 | `夜间＋不得离开＋营地` | “这条消息不是描述眼前事实，而是在建立可共同执行的规则。” |
| 假设 | 指向尚未发生的条件和结果 | 群体要讨论风暴可能到来时怎么办 | `如果＋风暴＋那么＋留在＋营地` | “群体正在讨论一个可能不发生的情境，并为它预先安排结果。” |

四条目标组合中的中文释义只从词典状态读取，不另建一份隐藏文本常量。

### 页面数值口径

画面不出现定量数值、年代、概率或语言起源时间，因此本页不调用 `Lec.K` 或 `Lec.P`。交互中的完成进度以四个无数字状态点表示，不显示百分比或倒计时。

## 必须点出来的一到三句

符号不只替眼前事物贴标签；共享的符号还能把别处、未来、规则和未发生的可能带进当前讨论。

因此，群体可以在行动之前共同计划，在事件发生之前讨论“如果”。

## 交互（只有这一个）

**组合信号词典**

学习者依次处理右栏四个情境，从左栏词典拖动或键盘选取符号，放入当前消息槽并排列成组合。

每放入一个符号，系统立即执行三层反馈：

- 合法但位置不对：槽位保留，标出需要调整的局部，不清空整句。
- 符号不适用于当前情境：退回词典，并说明当前情境需要的是地点、时间、规则词或条件词中的哪一类。
- 组合完成：消息槽连接到对应分类轨道，显示“对象是否在眼前”和“表达功能”两项判断。

四类完成后，右栏把“计划、规则、假设”收拢到“不受眼前场景限制”这一共同分支；“眼前报告”保留为对照。最终反馈为：“同一部共享词典，通过不同组合，可以讨论事实、未来行动、共同约定和可能情境。”

核心直觉：符号的力量不只来自单个符号指什么，也来自群体共享词义并把符号组合起来，由此共同处理不在眼前的对象与事件。

重置入口固定在词典下方，恢复四条未完成轨道和全部符号。支持鼠标、触摸与键盘：Tab 聚焦符号或槽位，Enter/Space 拿起与放下，方向键调整顺序，Escape 取消当前拿取。焦点、正确、待调整三种状态必须同时使用轮廓或文字提示，不能只用颜色区分。

## 不许碰

- 不给语言设定唯一诞生时间、地点、物种或单一突变事件。
- 不展示“手势—叫声—词语—现代语言”的线性起源阶梯。
- 不声称符号表达只存在于人类，也不在本页比较动物交流能力；相关能力组合已由 p12 承担。
- 不把四类表达写成语言演化的四个先后阶段，它们只是本页用于理解符号功能的分类。
- 不展开语法、词法、语言家族、文字起源或语言学术语体系。
- 不讨论教学、纠错与高保真传递，留给 p18。
- 不把“共享词典”直接扩展成完整文化累积机制；本页只说明符号如何突破眼前场景。

## 版面提示

采用 `split-lr`，左栏约占页面宽度的三分之一，固定显示共享词典与重置入口；右栏约占三分之二，纵向排列四条分类轨道。

右栏四条轨道必须共享列线，依次对齐“情境—消息槽—分类依据—反馈”，让分类差异可横向扫读。当前轨道保持完整亮度，其余轨道降低对比但仍可读；完成后的轨道不折叠，便于教师最后同时比较四类。
