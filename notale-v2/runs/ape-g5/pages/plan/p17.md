# page-17 · 成品不会告诉你怎么做 · **138 秒**

- Kicker：`COPYING THE PROCESS`
- 主标题：**同一件石器，为什么看见了还做不出来？**

## 知识结构：comparison

把“只看成品”与“同时获得过程信息”两种复制条件显式并列。两列使用同一目标、同一组动作和同一评分规则，只改变可见信息，避免把成绩差异误归因于任务难度。

比较骨架为对齐的四行 × 两列：

1. **可见信息**：成品轮廓 / 成品轮廓＋动作过程。
2. **学习者操作**：推测动作及顺序 / 根据过程线索重排动作。
3. **复制结果**：完成度、错序数、无效动作数。
4. **可迁移信息**：知道“做成什么” / 同时知道“从哪里、按什么顺序、怎样做”。

两列挑战结束后用一条从“结果信息”指向“过程信息”的横向箭头收束：增加的不是一件新成品，而是生成成品所需的中间关系。

## 表征形式

交互式双阶段比较。

中央舞台展示一个经过简化的石核侧视图、目标成品轮廓和可排序的敲击动作卡。第一阶段只显示目标成品；第二阶段保持目标与动作卡不变，额外显示敲击点、先后顺序和每一步产生的轮廓变化。

完成每个阶段后冻结其结果，左右并排保留，形成可直接扫读的前后对照。轮廓变化使用离散状态，不模拟真实断裂物理；重点是复制信息，不是训练打制技术。

## 四行 × 两列

| 比较维度 | 只看成品 | 看见过程 |
|---|---|---|
| 可见信息 | 最终轮廓、剩余敲击次数 | 最终轮廓、敲击点、动作方向、步骤顺序、每步后的中间轮廓 |
| 要完成的任务 | 从动作卡中推测并排列生成顺序 | 根据过程线索排列同一组动作卡 |
| 即时反馈 | 显示轮廓重合度、错序数、无效动作数；不提前揭示正确过程 | 使用相同指标，并在每一步指出该动作与过程线索是否吻合 |
| 复制中保留下来的内容 | 主要保留“结果像什么” | 同时保留“结果像什么”与“结果怎样生成” |

### 挑战对象与动作卡

- 目标是一个明确标注为“教学用简化石片模型”的轮廓，不对应具体考古类型、年代或文化。
- 石核包含 `Lec.K.PAGE17_ACTION_COUNT` 个可作用区域。
- 动作卡共 `Lec.K.PAGE17_ACTION_COUNT` 张；每张编码：
  - 敲击区域；
  - 动作方向；
  - 相对力度档位；
  - 与其他动作的先后约束。
- 两阶段调用完全相同的目标状态与动作集合；第二阶段不得换成更简单的目标。
- 正确过程由 `Lec.K.PAGE17_CANONICAL_SEQUENCE` 提供，页面不得在第一阶段完成前暴露该序列。
- 每执行一张动作卡，页面通过 `Lec.P.page17ApplyAction(currentState, action)` 计算新的离散轮廓状态。
- 最终轮廓重合度由 `Lec.P.page17ShapeMatch(resultState, targetState)` 计算，再用 `Lec.P.percent` 格式化。
- 错序数由 `Lec.P.page17OrderErrors(attemptSequence, Lec.K.PAGE17_CANONICAL_SEQUENCE)` 计算。
- 无效动作数由 `Lec.P.page17IneffectiveActions(attemptSequence)` 计算。
- 两阶段成绩差异由 `Lec.P.page17ScoreDifference(processScore, productOnlyScore)` 计算；百分比继续用 `Lec.P.percent`，不手写比例。
- 所有输入在计算前经 `Lec.P.finiteNumber` 与 `Lec.P.clamp` 处理。

### 页面时序

页面可见的时间与数量全部从 `Lec` 读取：

- 第一阶段限时：`Lec.K.PAGE17_PRODUCT_ONLY_TIME_S` 秒。
- 第二阶段限时：`Lec.K.PAGE17_PROCESS_VISIBLE_TIME_S` 秒。
- 倒计时显示由 `Lec.P.page17RemainingTime(startTime, now, limitSeconds)` 实时计算。
- 总动作卡数显示读取 `Lec.K.PAGE17_ACTION_COUNT`。
- 当前步骤显示为“步骤 n / 总步数”；`n` 由当前已执行动作数组长度计算，总步数读取 `Lec.K.PAGE17_ACTION_COUNT`。
- 本页总停留提示读取 `Lec.K.PAGE17_DWELL_TIME_S`，其值与页表规定的 138 秒一致，不在组件内另写字面量。
- 建议课堂节奏由页面状态机控制：简短读题、第一阶段、第二阶段、结果比较、主张收束；各段时长均读取 `Lec.K.PAGE17_*_TIME_S` 系列常量，合计通过 `Lec.P.page17TotalDuration` 校验为 `Lec.K.PAGE17_DWELL_TIME_S`。

## 必须点出来的一到三句

**只看成品很难复现工艺；过程信息决定复制的保真度。**

相似的最终外形可能来自不同尝试，而敲击点、顺序和中间状态会显著缩小需要猜测的范围。

## 交互（只有这一个）

**复刻石器挑战**

1. 学习者进入“只看成品”阶段，只能看到目标轮廓和一组未排序动作卡。
2. 学习者拖拽动作卡形成顺序，或选中卡片后用方向键移动、按 Enter 执行；每次执行后石核轮廓立即变化。
3. 页面实时显示剩余时间、已执行步骤和最终结果，但第一阶段只反馈“更接近 / 更偏离目标”，不泄露正确步骤。
4. 提交或倒计时结束后，页面保存第一阶段的轮廓重合度、错序数和无效动作数。
5. 学习者进入“看见过程”阶段，使用同一组动作卡重新复刻；舞台额外显示当前敲击点、方向提示、步骤编号及中间轮廓。
6. 每放置一张卡，页面立即标示其是否符合当前过程线索，并同步更新结果轮廓。
7. 第二阶段结束后，两次结果并排显示，突出变化最大的指标；反馈文字根据实际结果生成：
   - 第二阶段更准确：指出过程信息减少了哪些猜测。
   - 两阶段相同：指出本次已成功推断，但成品本身仍未显式携带步骤。
   - 第二阶段更差：提示过程信息只有被正确读取和执行时才提高保真度，不把预设结论伪装成个人成绩。
8. “重置挑战”恢复两阶段初始状态、计时器和卡片顺序；不随机更换目标，保证教师演示可复现。
9. 所有拖拽均提供等价键盘操作；焦点状态明确，动作卡带序号与文字标签，轮廓变化同时用文字播报，不只依赖颜色。
10. `prefers-reduced-motion` 下取消卡片飞入和轮廓补间，直接切换离散状态，不影响计时、反馈与评分。

学习者应形成的直觉：成品提供目标约束，过程信息提供生成路径；复制保真度取决于两者是否都能被传递。

## 不许碰

- 不讲现代工业标准化、互换零件、公差、流水线、质量管理或技术文档体系；这些属于 p20 的现代分工与部件封装。
- 不把挑战做成石器年代、文化名称或考古类型测验。
- 不声称页面中的简化敲击模型能够真实复原古代打制技术。
- 不提前展开示范、纠错、共享注意如何降低代际损失；这些机制留给 p18。
- 不讨论群体规模、多人汇聚创新或网络效应；留给 p19。
- 不把“看见过程”直接等同于完整教学；本页只比较可用过程信息的有无。
- 不将第一阶段失败解释为个人能力不足，也不把第二阶段成绩提升表述成人类独有能力。

## 版面提示

采用 `stage-cards`：

- 上方为 kicker、主标题和一句任务说明。
- 中部约占主要视野，放置石核舞台；目标轮廓固定在舞台右上角，当前结果与目标始终能同时查看。
- 下方为横向动作卡托盘，拖拽目的区明确显示顺序槽位。
- 第一阶段结束后，舞台收缩为左侧结果卡；第二阶段舞台在右侧展开。结束时形成严格对齐的两张结果卡，而不是用轮播替换前一次结果。
- 两张结果卡底部按同一顺序显示“可见信息、轮廓重合度、错序、无效动作”，便于逐行比较。
- 过程线索只在右列出现，并用连接线指向对应动作与轮廓变化；不得用装饰性碎屑遮挡石核边缘。
