# page-37 · 生态不是一只密封罐 · **140 秒**

- Kicker：`CLOSED ≠ SELF-SUSTAINING`
- 主标题：封闭，只是边界；稳定，才是任务

## 知识结构：generalization

用“四条支撑汇成一个总判断”的骨架，把封闭生态系统的稳定条件显式化：

1. **物质要循环**：生产者吸收可用养分，消费者取食，分解者把废物重新变成可用养分；画面以闭合箭头连接三个生物功能区和两个物质储库。
2. **能量要持续输入**：光从系统边界之外单向进入，经过生物活动后以不可再利用的形式散出；画面以穿过瓶壁的单向能量带表示，不画成闭环。
3. **生物量会波动且有延迟**：生产者、消费者和分解者不会同步响应；画面以三条错峰起伏的动态带表示。
4. **稳定来自协同管理**：调高单一环节不能保证稳定，只有物质周转、能量输入和生物波动同时处于可承受范围，系统才能持续。

四条支撑在生态瓶中央汇成总判断：“封闭”描述边界，“稳定”描述系统能否在波动中继续运行。

## 表征形式

交互式二维生态瓶，占据 `canvas-full` 主画面。

透明瓶体内部不是写实景观，而是一张可直接读取的系统图：

- 顶部：穿过瓶壁的光能输入带。
- 中部：生产者、消费者、分解者三个功能群，以不同形态的粒子群表示。
- 底部：可用养分库与待分解物质库。
- 闭合箭头：物质在储库和功能群之间迁移。
- 单向箭头：能量进入并散出。
- 右侧窄栏：三条随模拟时间滚动的生物量带，以及稳定度读数。
- 瓶体中央：唯一的二维“生态调节柄”；横向控制能量输入，纵向控制分解周转能力。

动态必须服务于因果读取：移动调节柄后，先改变光或分解速率，再经过可见延迟影响生产者、消费者与物质储库。不得用纯装饰气泡冒充循环。

## 四条支撑

### 物质循环

- **生产者区**：消耗“可用养分”，形成生产者生物量。
- **消费者区**：从生产者取得物质，形成消费者生物量，同时产生待分解物质。
- **分解者区**：消耗待分解物质，将其中一部分转回可用养分。
- **可用养分库**：低于安全范围时，生产者增长受限。
- **待分解物质库**：超过安全范围时，表示分解能力跟不上物质产生速度。
- 物质粒子只能在瓶内各区之间迁移，不得穿过瓶壁消失或凭空增加。
- 页面明确标注：“物质在系统内转移，不等于每一环都自动平衡。”

### 能量输入

- 光能从瓶外进入，不参与瓶内物质总量守恒。
- 能量输入过低时，生产者首先下降，随后消费者下降。
- 能量输入过高时，生产者可能短期上升，但会加快养分消耗和待分解物质积累，不给出“越亮越稳定”的反馈。
- 能量带离开系统时只显示“散出”，不画成返回光源的循环箭头。
- 页面明确标注：“物质可以周转，能量必须持续流过。”

### 生物波动

- 生产者对能量输入最先响应。
- 消费者响应滞后于生产者。
- 分解者响应滞后于待分解物质的积累。
- 任一功能群接近下限时，其承担的系统功能同步减弱，可能触发连锁变化。
- 正常状态允许小幅波动；稳定不等于三条动态带完全变成直线。
- 波动加剧时，用振幅扩大和相位错开表达，不使用随机灾难事件。

### 稳定判断

稳定度由最近一个观察窗口内的四项共同决定：

- 可用养分是否持续落在安全范围内。
- 待分解物质是否持续落在安全范围内。
- 三个功能群是否都高于功能下限。
- 各功能群的波动幅度是否保持在可恢复范围内。

稳定状态分为：

- **失衡**：至少一个关键储库或功能群越过临界范围。
- **脆弱**：当前读数尚未越界，但趋势正在扩大或持续逼近边界。
- **稳定波动**：各项在观察窗口内保持于可恢复范围，允许周期性起伏。

不得把某一瞬间的高生物量判为成功；必须经过完整观察窗口后才能显示“稳定波动”。

### 模型参数与画面读数

这是无量纲教学模型，不声称预测真实生态舱。所有页面参数先注册到 `Lec.K`，所有状态更新与读数通过 `Lec.P` 计算，组件内不得出现裸数字。

画面显示：

- **模拟时间**：单位 `day`，由 `Lec.P.ecosystemElapsedDays` 根据累计时间步计算。
- **能量输入**：单位 `% of model input range`，由 `Lec.P.percent` 转换生态调节柄横向值。
- **分解周转能力**：单位 `% of model capacity range`，由 `Lec.P.percent` 转换生态调节柄纵向值。
- **生产者生物量**：单位 `% of model carrying range`，由 `Lec.P.ecosystemNormalizedBiomass` 与 `Lec.P.percent` 计算。
- **消费者生物量**：单位 `% of model carrying range`，由 `Lec.P.ecosystemNormalizedBiomass` 与 `Lec.P.percent` 计算。
- **分解者生物量**：单位 `% of model carrying range`，由 `Lec.P.ecosystemNormalizedBiomass` 与 `Lec.P.percent` 计算。
- **可用养分库**：单位 `% of total model matter`，由 `Lec.P.ecosystemMatterFraction` 与 `Lec.P.percent` 计算。
- **待分解物质库**：单位 `% of total model matter`，由 `Lec.P.ecosystemMatterFraction` 与 `Lec.P.percent` 计算。
- **稳定度**：单位 `%`，由 `Lec.P.ecosystemStabilityScore` 计算后交给 `Lec.P.percent` 格式化。
- **观察窗口进度**：单位 `%`，由已完成步数与 `Lec.K.PAGE37_OBSERVATION_STEPS` 的比值经 `Lec.P.fraction`、`Lec.P.percent` 计算。

页面专用常量全部进入 `Lec.K`：

- `Lec.K.PAGE37_INITIAL_STATE`
- `Lec.K.PAGE37_DEFAULT_ENERGY_INPUT`
- `Lec.K.PAGE37_DEFAULT_DECOMPOSITION_CAPACITY`
- `Lec.K.PAGE37_TIME_STEP_DAYS`
- `Lec.K.PAGE37_OBSERVATION_STEPS`
- `Lec.K.PAGE37_MATTER_TOTAL`
- `Lec.K.PAGE37_FUNCTIONAL_LOWER_BOUNDS`
- `Lec.K.PAGE37_RESERVOIR_SAFE_RANGES`
- `Lec.K.PAGE37_RECOVERABLE_VARIATION_LIMIT`
- `Lec.K.PAGE37_CONTROL_MIN`
- `Lec.K.PAGE37_CONTROL_MAX`

页面专用计算统一封装为：

- `Lec.P.ecosystemStep(state, controls, constants)`：按固定时间步更新三个功能群与两个物质储库。
- `Lec.P.ecosystemMatterTotal(state)`：核对瓶内模型物质总量，结果应与 `Lec.K.PAGE37_MATTER_TOTAL` 一致。
- `Lec.P.ecosystemMatterFraction(value, total)`：计算物质储库占比。
- `Lec.P.ecosystemNormalizedBiomass(value, range)`：计算功能群相对模型承载范围的位置。
- `Lec.P.ecosystemVariation(history, window)`：计算观察窗口内的波动幅度。
- `Lec.P.ecosystemStabilityScore(history, safeRanges)`：综合储库越界、功能下限与波动幅度，返回有限的归一化值。
- `Lec.P.ecosystemStatus(score, trend, bounds)`：返回“失衡 / 脆弱 / 稳定波动”。
- 所有调节柄输入先经 `Lec.P.finiteNumber` 和 `Lec.P.clamp`；异常状态回退到 `Lec.K.PAGE37_INITIAL_STATE`。

初始值、阈值、时间步和更新系数不显示为真实生态学测量值；界面固定标注“无量纲教学模型”。

## 必须点出来的一到三句

- 封闭生态系统需要同时管理物质循环、能量输入与生物波动。
- 物质可以在瓶内周转，能量却必须持续流过；任何一个功能群掉出可恢复范围，都可能影响整个循环。
- 稳定不是静止，也不是把某一项调到最大，而是在波动中仍能维持关键功能。

## 交互（只有这一个）

**稳住生态瓶**：读者只操作瓶体中央的二维生态调节柄。

- 左右移动改变能量输入；上下移动改变分解周转能力。
- 指针拖拽、触控拖拽和键盘方向键操作同一个调节柄，不再设置第二组滑块。
- 调节后，生态瓶连续运行：光能带先改变，生产者随后响应，消费者与分解者延迟变化，两个物质储库同步重新分配。
- 右侧动态带和稳定度实时更新；状态文字说明当前主要瓶颈，例如“能量不足”“待分解物质正在积累”“消费者下降滞后出现”。
- 调节柄进入可维持区域后，必须完成一个观察窗口，才显示“稳定波动”；短暂穿过该区域不算成功。
- 成功反馈不是停止动画，而是在瓶壁上形成持续的稳定光环，并显示“系统仍在波动，但关键功能保持在可恢复范围”。
- 失衡时不立即判负或锁死，允许继续调节并观察恢复过程。
- “重置”恢复 `Lec.K.PAGE37_INITIAL_STATE`、默认调节位置、初始观察窗口和默认运行速度。
- 键盘操作：方向键微调，`Shift + 方向键`较大步调整，`Home`恢复默认位置，按钮可用 `Enter` 或空格触发。
- 调节柄具有可读名称、当前横纵值和状态说明；动态反馈置于 `aria-live="polite"`。
- `prefers-reduced-motion` 下保留状态计算与折线更新，降低粒子迁移速度并取消闪烁和脉冲。

读者应形成的直觉是：不存在一个“全部调高”的答案；生态稳定要求能量供给、物质周转能力和生物响应速度彼此匹配。
