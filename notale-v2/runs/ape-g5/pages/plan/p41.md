# page-41 · 转出一小片“重力” · **115 秒**

**Kicker：** `ROTATION / ARTIFICIAL GRAVITY`

**主标题：** 选多大的环，转多快？

## 知识结构：process

把“选择环体参数”到“形成类似重力的体验”的因果链显式化，使用一条持续更新的六步箭头链：

**选择半径 → 选择转速 → 换算角速度 → 计算向心加速度 → 与标准重力比较 → 判断工程规模与人体感受**

画面中央的旋转舱、下方参数图与右侧结果卡同步对应这六步。学习者每次选择一组半径与转速，后四步立即重算并高亮变化来源；不播放预设结论动画。

## 表征形式

交互式三维旋转舱与二维参数图并置。

- 中央为可调半径的三维环形舱，固定斜俯视镜头；舱环按所选转速连续旋转。
- 环上放置一个简化乘员标记，头朝旋转轴、脚朝环外侧；一根由轴心指向脚端的箭头表示所需的向心加速度方向。
- 环体直径随半径按统一比例变化；旋转动画的视觉速度随 rpm 变化，但设显示速度上限，避免高转速造成闪烁或眩晕。数值计算不受动画限速影响。
- 下方使用 ECharts，`renderer: 'svg'`，绘制“半径—转速”参数图：横轴为半径 `m`，纵轴为转速 `rpm`，等加速度曲线分别由页面情境常量生成；当前选择显示为唯一高亮点。
- 右侧结果卡依次显示角速度、加速度、标准重力倍数，以及一句定性体验提示。
- 主要心理表征是：同一目标加速度并不对应唯一设计；半径变小通常需要转得更快，半径变大则意味着更大的结构。

## 六个 step

### 1. 选择环半径

- 显示值：环半径，单位 `m`。
- 来源：页面情境常量 `Lec.K.PAGE41_RING_RADIUS_OPTIONS_M`。
- 默认值：`Lec.K.PAGE41_DEFAULT_RING_RADIUS_M`。
- 输入后先用 `Lec.P.finiteNumber` 检查，再用 `Lec.P.positive` 保证为正数，并以选项数组的最小值、最大值通过 `Lec.P.clamp` 限制范围。
- 三维环的几何尺寸、图表横坐标和结果卡中的半径均读取同一个状态值，不分别写死。

### 2. 选择旋转速度

- 显示值：转速，单位 `rpm`，即每分钟转数。
- 来源：页面情境常量 `Lec.K.PAGE41_ROTATION_RATE_OPTIONS_RPM`。
- 默认值：`Lec.K.PAGE41_DEFAULT_ROTATION_RATE_RPM`。
- 输入后依次经过 `Lec.P.finiteNumber`、`Lec.P.positive` 与 `Lec.P.clamp`。
- 环体旋转周期当场计算：
  - `periodSeconds = 60 / rpm`
  - 页面中的 `60` 不直接进入组件，读取 `Lec.K.SECONDS_PER_MINUTE`。
- 周期显示单位为 `s/圈`，只作转速的自然语言翻译，不增加第二个可操作量。

### 3. 换算角速度

页面显示关系式：

\[
\omega=\operatorname{rad}\left(\frac{\mathrm{rpm}\times360^\circ}{60}\right)
\]

- `degreesPerSecond = rpm × Lec.K.DEGREES_PER_TURN / Lec.K.SECONDS_PER_MINUTE`
- `omegaRadPerSecond = Lec.P.degreesToRadians(degreesPerSecond)`
- 显示值：角速度，单位 `rad/s`。
- KaTeX 基准字号 `20px`。
- 公式旁文字：“先把每分钟转数换成每秒转过的弧度。”
- 不推导弧度定义，不展开角位置、角加速度或微积分。

### 4. 计算向心加速度

页面显示核心关系式：

\[
a=\omega^2r
\]

- `accelerationMps2 = omegaRadPerSecond × omegaRadPerSecond × radiusM`
- 计算封装为页面函数 `Lec.P.page41ArtificialGravity(radiusM, rpm)`，返回：
  - `omegaRadPerSecond`
  - `accelerationMps2`
  - `gravityFraction`
  - `periodSeconds`
- 显示值：加速度，单位 `m/s²`。
- 公式旁文字：“转得越快，转速的影响会被平方；环越大，同一转速下加速度也越大。”
- 分母不存在时仍须检查异常输入；任何非有限结果回退到页面默认组合。

### 5. 与地球标准重力比较

- 基准值：`Lec.K.STANDARD_GRAVITY`，单位 `m/s²`。
- 重力倍数：
  - `gravityFraction = Lec.P.ratio(accelerationMps2, Lec.K.STANDARD_GRAVITY)`
- 百分比：
  - `gravityPercent = Lec.P.percent(accelerationMps2, Lec.K.STANDARD_GRAVITY)`
- 主读数显示为 `g` 的倍数，辅助读数显示为标准重力百分比；两者均由计算结果格式化，不写死示例答案。
- 当前点在参数图上移动时，同一目标加速度曲线用于揭示可替代关系：
  - 给定目标倍数 `targetG` 与半径 `r`，先算 `targetAcceleration = targetG × Lec.K.STANDARD_GRAVITY`
  - `omega = sqrt(targetAcceleration / r)`
  - `rpm = omega × Lec.K.SECONDS_PER_MINUTE / Lec.P.degreesToRadians(Lec.K.DEGREES_PER_TURN)`
- 目标曲线取值来自 `Lec.K.PAGE41_TARGET_GRAVITY_FRACTIONS`。

### 6. 判断设计代价与体验

结果卡根据当前组合生成两条同步反馈：

- **工程规模：** 半径增加时，环体直径 `diameterM = radiusM × Lec.K.DIAMETER_RADIUS_FACTOR` 随之增加；显示单位 `m`。只指出“更大的半径意味着更大的结构”，不估算材料、质量、成本或整座空间城市。
- **人体感受：** 页面计算头脚加速度差的教学指标。乘员参考身高读取 `Lec.K.PAGE41_CREW_REFERENCE_HEIGHT_M`：
  - `footRadiusM = radiusM`
  - `headRadiusM = Lec.P.positive(radiusM - crewHeightM)`
  - `footAcceleration = omega² × footRadiusM`
  - `headAcceleration = omega² × headRadiusM`
  - `headFootDifference = footAcceleration - headAcceleration`
  - `headFootDifferencePercent = Lec.P.percent(headFootDifference, footAcceleration)`
- 只作相对提示：“环越小，头脚所处半径的相对差异越明显；需要更高转速时，转头或走动也更容易产生不同于地面的旋转感。”
- 不设置医学舒适阈值，不把某个组合标成对所有人绝对安全或舒适。

## 必须点出来的一到三句

旋转可以制造类似承重的体验，但不是把重力“打开”了。

同样的目标加速度，可以用较小而较快的环，也可以用较大而较慢的环；前者加重旋转体验，后者扩大工程规模。

## 交互（只有这一个）

**选择人工重力环。**

读者在同一控制组中选择环半径与转速，视为一次完整的“环方案选择”，不是两个独立小游戏。

每次选择后同时发生：

1. 三维环改变尺寸与旋转速度。
2. 乘员脚端的加速度箭头改变长度。
3. 参数图中的当前点移动到对应半径与 rpm。
4. 角速度、`m/s²`、`g` 倍数、环体直径和头脚差异即时重算。
5. 反馈句指出当前变化主要来自“半径改变”“转速改变”或两者共同改变。

交互要形成的直觉是：人工重力方案没有脱离取舍的单一旋钮；想获得相近的加速度，小环必须更快，大环则必须付出结构尺寸。

操作方式：

- 指针：点击半径选项与转速选项。
- 键盘：`Tab` 进入控制组，方向键切换选项，`Enter` 或空格确认。
- 当前选项使用文字、形状与颜色共同标记，不只依赖颜色。
- “重置”恢复 `Lec.K.PAGE41_DEFAULT_RING_RADIUS_M` 与 `Lec.K.PAGE41_DEFAULT_ROTATION_RATE_RPM`。
- 切换 `prefers-reduced-motion` 时停止连续旋转，以分段角度和运动方向箭头表达转速；所有计算与图表反馈保留。
- 不允许自由拖拽三维镜头，避免与“选择人工重力环”的核心动作竞争。

## 不许碰

- 不推导完整旋转动力学，不使用微积分，不讲角动量、转动惯量、结构应力或旋转稳定性方程。
- 不扩展为整座空间城市设计，不配置居住区、轴毂、辐条、农业区、材料或建造成本。
- 不把向心加速度说成真正新增的引力场；措辞限定为“类似重力的承重体验”或“人工重力效果”。
- 不给统一的人体舒适、安全或适应阈值，不作医学诊断。
- 不展开运动时的科里奥利效应公式；只允许用一句定性反馈说明转头或走动可能产生不同于地面的旋转感。
- 不比较改变行为或改变身体的其他适应路径，那是 p40 的总分类职责。
- 不提前进入风险承担、治理、不可逆性或同意问题，留给 p42–p44。
