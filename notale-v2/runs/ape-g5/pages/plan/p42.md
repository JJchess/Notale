# page-42 · 风险由谁承担 · **110 秒**

**Kicker：RISK LEDGER**

**主标题：同一次任务，风险可能记在不同人的账上**

## 知识结构：classification

把“航天风险”按主要承担者分成三个并列分支：**自愿承担、由他人承担、跨代承担**。分类依据不是风险发生在何处、由什么设备引起，而是“后果主要落到谁身上，以及承担者是否参与了当前任务的选择”。

页面用三本对齐的风险账簿显式化分类：

- **自愿承担**：当前参与者在知情并可表达意愿的前提下承担。
- **由他人承担**：后果落到未参与该项任务选择的同时代他人身上。
- **跨代承担**：当前选择把风险、依赖或处置负担留给未来的人。

三类保持并列，不画成从轻到重的等级。账簿底部共同指向一句判断：“分类先回答谁承担，不回答任务是否值得做。”

## 表征形式

交互式三栏 ledger。上方是待分配的任务风险条目，下方是三本并列账簿；每本账簿都有承担者标签、判别问题和已分入条目。

拖入条目后立即显示一条因果链：

**当前选择 → 暴露于后果的人 → 风险类别**

完成全部分配后，三栏同时保留，让学生看到同一次航天任务可以在三本账上各有记录，而不能用“船员自愿”概括全部风险。

## 层级里的各项

### 自愿承担

判别问题：**承担后果的人，是否也是当前知情选择参与任务的人？**

- **舱外作业受伤**  
  承担者：执行任务并接受相关风险的船员。  
  反馈链：舱外作业安排 → 执行者暴露于受伤风险 → 自愿承担。
- **长期任务中的个人健康风险**  
  承担者：知情参加任务的当前乘员。  
  反馈链：参加长期任务 → 当前乘员承受健康影响 → 自愿承担。

页面同时提示：“自愿”只描述承担关系，不等于风险已经合理，也不等于可以把一切责任推给个人。

### 由他人承担

判别问题：**后果是否落到未参与这项任务选择的同时代人身上？**

- **发射残骸落入有人活动区域**  
  承担者：未参与发射决策的地面居民。  
  反馈链：发射与残骸处置 → 地面居民暴露于损害 → 由他人承担。
- **任务事故需要外部救援资源**  
  承担者：救援人员及被调配公共资源所影响的人。  
  反馈链：任务事故 → 外部人员与资源承受附加风险 → 由他人承担。

页面提示：“由他人承担”不表示一定禁止任务，而是不能把这些后果遗漏在船员风险之外。

### 跨代承担

判别问题：**当前选择是否把风险或持续义务留给尚未参与选择的未来人群？**

- **长期轨道碎片增加未来碰撞风险**  
  承担者：未来使用轨道的人及未来清理者。  
  反馈链：当前遗留碎片 → 未来任务承受碰撞与清理负担 → 跨代承担。
- **定居系统让后代长期依赖单一生命保障设施**  
  承担者：出生并生活在该系统中的后代。  
  反馈链：当前定居设计 → 后代继承系统依赖与故障风险 → 跨代承担。

页面提示：“未来可能受益”不能自动抵消未来被迫承担的风险；本页只把承担者识别出来。

### 页面计数

每本账簿显示“已分配条目数”，不预置写死数值。计数由当前拖放状态即时计算：

`categoryCount = 当前 categoryId 对应的风险条目数量`

总进度由页面当场计算：

`assignedCount = 已进入任一账簿的条目数量`

`totalCount = 风险条目数组长度`

页面显示格式为“已归账 `assignedCount / totalCount`”。异常或重复归属时，以每个条目当前唯一的 `categoryId` 为准；重置后全部条目的 `categoryId` 回到未分配状态。本页不调用额外 `Lec.K` 常量或 `Lec.P` 数值函数。

## 必须点出来的两句

航天风险可分为自愿承担、由他人承担和跨代承担，三者不能混为一谈。

船员愿意冒险，只能说明其中一部分风险由谁承担，不能替地面他人或未来世代作出同一份选择。

## 交互（只有这一个）

**分配任务风险**

学生把六张风险条目拖入三本账簿。拖动时，目标账簿高亮并读出其判别问题；放下后立即出现承担者与因果链反馈。

- 分配正确：条目留在账簿中，显示“看承担者，不看风险来自哪种技术”的对应解释。
- 分配不符：条目回到待分区，并指出被忽略的承担者，例如“执行者自愿，但这张卡描述的主要后果落在未参与决策的地面居民身上。”
- 全部分配后：不显示分数或胜负，只展开三栏总账，并高亮“同一次任务可同时产生三类风险”。

键盘操作：Tab 聚焦风险条目；Enter 或 Space 拿起；方向键切换三本账簿；Enter 放下；Escape 取消。每次状态变化通过 `aria-live` 宣告条目名称、目标类别和反馈。

提供“重置风险账”入口，恢复全部条目到待分区并清空计数。拖放与键盘操作调用同一状态更新函数，不设置第二种交互。

## 不许碰

- 不提出或教授“越不可逆、越影响未同意者，就应设置越高证据与正当性门槛”；该判断标准留给 p44。
- 不把三类风险排列成轻重等级，也不声称某一类天然可接受或不可接受。
- 不讨论由谁投票、专家是否拥有最终权力、船员自治与任务效率如何取舍；治理制度比较留给 p43。
- 不展开基因改变、胚系干预或后代身体改造案例。
- 不用“自愿参加”替代对组织责任、外部影响和跨代负担的识别。
- 不给事故概率、伤亡率或殖民人口阈值；本页只分类承担者，不计算风险大小。
- 不把价值分类包装成工程计算或物理定律。
