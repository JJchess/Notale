# page-45 · 繁衍瓶颈：随机不等于适应 · **65 秒**

**Kicker：RANDOM DRIFT**

**主标题：少数个体留下后，谁消失可能只是抽样结果**

## 知识结构：process

把“原始群体 → 瓶颈抽样 → 小群体繁衍 → 多样性结果”这一前后过程显式化。

画面用从左到右的四代繁衍网络表示过程：每一列是一代，节点代表个体，连线代表其来源；同色节点表示共享同一初始遗传标记。抽样后没有后代的颜色逐列消失，偶然被多次抽中的颜色扩张。列顶对齐显示“保留的标记种类”，让学习者同时看到繁衍关系和多样性变化，而不是把末代比例误读为能力排名。

## 表征形式

交互式 D3 繁衍网络。

初始群体中的每个遗传标记使用等量、等大小节点，不赋予健康、能力或适应度差异。点击后按固定种子完成一次瓶颈与后续繁衍抽样，连线短暂依次亮起，随后稳定为可检查的四列网络。

颜色只编码遗传标记类别；节点大小恒定，不编码“强弱”。消失的标记在上一列保留低亮度，后续列不再出现。末列旁以简短计数显示多样性变化。

## 四个 step

### Step 1｜原始群体

- 建立一个教学用原始群体，每名个体携带一个可追踪的中性遗传标记。
- 初始个体数取 `Lec.K.PAGE45_SOURCE_POPULATION`，单位为“个体”。
- 初始标记种类数取 `Lec.K.PAGE45_INITIAL_VARIANT_COUNT`，单位为“种”。
- 各标记的初始个体数由页面算法均匀分配：先计算整数商，再把余数依次分给前若干标记；不得写死每种标记的数量。
- 画面标签显示：
  - `原始群体：{sourcePopulation} 个体`
  - `遗传标记：{initialVariantCount} 种`
- 这些标记是中性的教学标签，不表示真实基因、族群身份、疾病风险或能力差异。

### Step 2｜瓶颈抽样

- 从原始群体中无放回抽取少量个体，组成瓶颈后的繁衍群体。
- 抽样人数取 `Lec.K.PAGE45_BOTTLENECK_POPULATION`，单位为“个体”。
- 随机数生成器必须由 `Math.seedrandom(currentSeed)` 创建；首次试验的 `currentSeed` 必须为 `'page-45'`。
- 使用 Fisher–Yates 洗牌后截取前 `bottleneckPopulation` 个个体，不得调用未注入种子的 `Math.random()`。
- 瓶颈后保留的标记种类数由页面当场计算：对抽中个体的标记 ID 去重后取集合大小。
- 保留比例使用 `Lec.P.fraction(retainedVariantCount, initialVariantCount)`；百分比显示使用 `Lec.P.percent(...)`。
- 画面标签显示：
  - `瓶颈后：{bottleneckPopulation} 个体`
  - `仍有：{retainedVariantCount} 种标记`
  - `保留初始多样性的 {retainedPercent}%`
- 百分比按 `Lec.P.percent` 的统一规则格式化，不手写比例换算。

### Step 3｜小群体繁衍

- 从瓶颈群体开始生成后续两代，代数取 `Lec.K.PAGE45_DESCENDANT_GENERATIONS`，单位为“代”。
- 每一代目标人数取 `Lec.K.PAGE45_DESCENDANT_POPULATION`，单位为“个体”。
- 每名后代从上一代个体中有放回随机抽取一个来源节点，并继承该节点的中性标记。
- 所有来源节点被抽中的概率相同；本页模型不设置生存优势、繁殖优势、突变、迁移或配偶选择。
- 每代标记种类数通过对该代节点标记 ID 去重计算。
- 相邻两代之间绘制来源连线；同一来源被多次抽中时形成分支，没有后代的来源不再向右连接。
- 列标题按页面生成的代序显示，不写死代号；序号来自后代数组索引格式化。

### Step 4｜多样性结果

- 末代个体数由生成后的节点数组长度计算，单位为“个体”。
- 末代标记种类数由末代标记 ID 去重计算，单位为“种”。
- 末代相对初始的多样性保留比例使用：
  - `Lec.P.fraction(finalVariantCount, initialVariantCount)`
  - `Lec.P.percent(...)`
- 末代各标记所占比例使用：
  - `Lec.P.fraction(variantCount, finalPopulation)`
  - `Lec.P.percent(...)`
- 结果区只突出：
  - `初始 {initialVariantCount} 种 → 末代 {finalVariantCount} 种`
  - `有 {lostVariantCount} 种未延续`
- `lostVariantCount` 由 `initialVariantCount - finalVariantCount` 当场计算。
- 若某一标记比例上升，反馈写作“这次被抽中的后代更多”；不得写作“它更优秀”或“它更适应”。

### 教学参数与数值来源

页面需在共享 `Lec.K` 中提供以下教学模拟常量，不得在组件内写死：

- `Lec.K.PAGE45_SOURCE_POPULATION`
- `Lec.K.PAGE45_INITIAL_VARIANT_COUNT`
- `Lec.K.PAGE45_BOTTLENECK_POPULATION`
- `Lec.K.PAGE45_DESCENDANT_GENERATIONS`
- `Lec.K.PAGE45_DESCENDANT_POPULATION`

这些数值必须标注为“用于观察随机抽样的简化情境”，不得称为殖民方案、最低人口、推荐人口或现实预测。

所有输入值先用 `Lec.P.finiteNumber` 检查，再用 `Lec.P.positive` 保证为正值；人数与代数转为整数。比例分母为零时不计算百分比，并回退到页面默认教学参数。

## 必须点出来的一到三句

小群体中的随机性会迅速改变遗传多样性，结果不等同于“更适应”。

某种标记在这次模拟中增多，只说明它的携带者被随机抽中得更多；重做一次试验，结果可能不同。

## 交互（只有这一个）

**繁衍瓶颈抽样**

- 主按钮为“开始抽样”。按下后，页面一次完成“瓶颈抽样 → 后续繁衍”，网络从左向右更新，并实时重算每代保留的标记种类与末代比例。
- 首次运行使用 `Math.seedrandom('page-45')`，保证教师与学生看到相同结果。
- “重置”清空网络并回到同一种子 `'page-45'`；再次开始必须复现完全相同的节点、连线和计数。
- “下一次试验”显式推进试验序号，并以算法生成新种子：`'page-45-' + trialIndex`；随后重新运行同一套抽样流程。试验序号来自页面状态，不作为科学数据解释。
- 每次试验后即时反馈：
  - 若末代标记种类减少：“一些标记没有延续，但模拟没有给任何标记设置优势。”
  - 若某标记比例明显上升：“它在这次抽样中留下了更多后代，不代表更适应。”
  - 若结果与上次不同：“规则没有改变，随机抽样本身就能产生不同结果。”
- 键盘操作：
  - `Tab` 可依次到达“开始抽样／下一次试验”“重置”和网络节点。
  - `Enter`、`Space` 触发按钮。
  - 节点获得焦点时显示其代次、中性标记和来源节点；信息同时写入可读文本，不只依赖颜色或 tooltip。
- 减少动态效果偏好开启时，取消连线逐段亮起，只呈现抽样前后态和即时计数。
- 交互要形成的直觉：相同规则、相同初始组成，仅随机抽样就可能让某些标记扩张、缩小或消失。

## 不许碰

- 不给出真实太空殖民、世代飞船或孤立种群所需的最低人口、推荐人口或安全阈值。
- 不把本页教学参数外推为现实工程结论；不使用“足够繁衍”“可持续人口”等措辞。
- 不把颜色、节点数量或末代占比解释为适应度、优劣、进步、健康或智力。
- 不引入自然选择模拟；所有标记在抽样中概率相同，不设置环境压力或差异繁殖成功率。
- 不展开近亲繁殖、遗传病风险、突变率、基因编辑、优生学或现实族群差异。
- 不把一次随机结果称为预测；必须允许重置复现，并允许“下一次试验”展示不同随机结果。
- 不复用 p19 的知识贡献者编码；本页节点只代表个体，连线只代表繁衍来源。

## 版面提示

按钮固定在网络下方同一操作区，不把“下一次试验”做成第二种交互。颜色之外同时使用短标记符号和可访问文本区分遗传标记；节点不得因占比变化而改变大小。
