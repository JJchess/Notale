# page-02 · 接力赛，还是分叉史？ · **120 秒**

**Kicker：BREAK THE LINE**

**主标题：这六幅图，真的只能排成一条线吗？**

## 知识结构：comparison

把同一组六幅人类图像放进两个对齐的解释框架中比较：

- 上行「进化队列」：单一方向箭头串起全部图像，暗示前者变成后者、旧者依次消失。
- 下行「分支历史」：主干分叉、横向重叠、部分支路终止，表达共同祖先后的分化、多个群体共存以及多数支系灭绝。
- 两行按三个维度逐列对齐：关系形状、时间关系、结局。学生拖动的是同一组六张卡，变化的是组织方式及其产生的解释。

## 表征形式

交互式舞台卡片。

中央是由 `konva.min.js` 绘制的卡片舞台，六张等尺寸人物图像卡可拖动。舞台先显示单行六槽的教科书式队列；卡片全部放入后，队列箭头自动转化为分叉线、重叠带和终止标记，六张卡移动到分支布局。

图像只作为匿名的古人类群体示意，不标物种名、年代或“原始—高级”等级。转化动画必须保持卡片身份不变，让学生看见：证据对象没有改变，解释框架改变了。

## 维度表

| 比较维度 | 进化队列 | 分支历史 |
|---|---|---|
| 关系形状 | 六张卡沿一根单向箭头首尾相接；卡片数由 `CARD_DEFS.length` 取得 | 同样数量的卡分布在主干与支路上；连线由 `RELATION_EDGES` 计算生成 |
| 时间关系 | 每张卡只占一个顺序位置，视觉上暗示严格先后 | 卡片纵向区间可重叠，表示多个群体可能在同一时期存在 |
| 结局 | 箭头只指向最后一张卡，暗示每一阶段都通向现代人 | 部分支路以终止符结束，只有部分支路延续；终止支路数由 `RELATION_EDGES.filter(edge => edge.terminal).length` 当场计算 |
| 容易造成的误读 | “前一个变成后一个”“演化有预定终点” | 共同祖先后出现分化；共存与灭绝都是历史的一部分 |

画面不显示任何真实年代、比例尺、物种数量或谱系节点。

所有可见数量均从页面状态计算：

- 卡片总数：`CARD_DEFS.length`，界面文案用 `Lec.P.finiteNumber()` 校验后显示。
- 已放置卡片数：`placedCardIds.size`，经 `Lec.P.finiteNumber()` 校验，并用 `Lec.P.clamp(value, 0, CARD_DEFS.length)` 限制。
- 布局完成度：`placedCardIds.size / CARD_DEFS.length`，经 `Lec.P.finiteNumber()` 校验、`Lec.P.clamp(value, 0, 1)` 限制；仅驱动进度条，不显示百分数。
- 支路终止数量：由 `RELATION_EDGES.filter(edge => edge.terminal).length` 计算；如进入辅助文本，先经 `Lec.P.finiteNumber()` 与 `Lec.P.round(value, 0)`。
- 所有卡片位置、槽位和连线坐标按舞台实际宽高与数组长度计算，不在页面逻辑中写死像素序号。

## 必须点出来的一到三句

教科书式进化队列把分支、共存和灭绝误画成了接力赛。

人类演化不是一列注定走向现代人的队伍，而是许多支路出现、重叠并终止的历史。

## 交互（只有这一个）

学生拖动六幅匿名人类图像，将它们排入舞台上的六个队列槽位；卡片可任意交换位置，不存在按“更像现代人”排序的正确答案。

全部卡片入槽后，系统不判定某个线性顺序获胜，而是立即播放一次框架转换：

- 单向长箭头拆成主干与支路。
- 部分卡片横向重叠，显示共存。
- 部分支路停止延伸，显示灭绝。
- 最后一张卡失去“终点领奖台”式强调，与其他卡保持同等尺寸。
- 反馈语显示：“你可以排出许多队列，但队列本身不是演化史。”

完成条件是六张卡均被放入槽位并看完框架转换；重置后卡片回到舞台边缘，但不提供“正确的直线答案”。拖拽、触控与键盘选择后移动必须等价，卡片不能只靠颜色区分。

学生应形成的直觉是：把图像排成一列很容易，但这种排列会自动制造单线进步与预定终点的含义；分支、共存和终止才是更合适的历史结构。

## 不许碰

- 不出现具体古人类物种名称、正式谱系节点、祖先—后代断言或分支年代；这些归 p07。
- 不把任何一幅图标为“缺失环节”“较低等”“更先进”“半猿半人”。
- 不要求学生依据外貌推断真实亲缘关系，也不把姿态由弯到直当作演化证据。
- 不讲化石定年、迁徙路线、双足力学、脑容量变化或现代人起源。
- 不使用“黑猩猩变成人”或“现生猿类是人类祖先”的表述。
- 分支布局只表达结构性反例，不冒充真实人类演化谱系图。

## 必用skill

mini-game, konva.min.js, make-illustration

## 媒体

生成六幅统一视角、统一比例、统一画法的匿名人类群体插画：人物均采用自然站姿，不按从佝偻到直立排列；体型、毛发、面部与服饰线索保持克制，不对应可识别的具体物种或文化阶段。

需要生成插画而非拼接真实复原图，因为本页比较的是“同一组图像被不同结构组织后产生的含义”，不是检验某个复原方案是否准确。六图必须使用透明背景，人物朝向不得共同制造单向行进感。

## 版面提示

采用 `stage-cards`：

- 顶部为 kicker、主标题和一句操作提示。
- 中部约占主要视野，初始是一条横向队列舞台；完成后在同一区域原位转化为分支舞台，不上下并列两个大型图，以免学生把注意力转向找图像差异。
- 底部固定三列微型比较条：「一条线 / 多条支路」「严格先后 / 可以共存」「都通向终点 / 多数支路终止」。
- 六张卡保持同尺寸、同边框、同视觉权重；不得让最右卡更亮、更高或占据中心领奖台。
- 分支线应从卡片之间的共同节点分开，不从一张人物卡直接“生出”另一张卡。
