# page-10 · 旧结构，新控制 · **120 秒**

**Kicker：HAND / CONTROL**

**主标题：人手不是突然出现的“工具附件”**

## 知识结构：comparison

把两层比较同时显式化：

1. **同一套继承结构，不同控制配置**：左右对齐呈现同一只三维手，骨骼数量、关节连接和五指基本布局保持不变；左侧使用受限的拇指对掌与手指独立控制，右侧由学生调整控制配置。
2. **两类抓握任务，不同能力要求**：同一配置依次面对“大物体整手抓握”和“小物体指尖捏持”，用接触区域、稳定性与所需挤压力进行逐行比较。

画面通过“左侧基准态—右侧改造态”的前后态对齐，以及下方四行比较表，让学生看见：变化不是凭空增加一只新手，而是在既有掌骨、指骨、关节和肌腱控制基础上改变可达位置与动作精度。

## 表征形式

交互式三维实体比较。

中心是一只可绕垂直轴小幅旋转、可缩放观察的三维右手；切换任务时，手分别抓住圆柱体和小珠。骨骼以半透明实体显示，肌腱作用只用沿手指走向的细线与关节高亮表示，不制作完整肌肉解剖。

左侧固定显示“继承的基本手型”，右侧实时显示学生调整后的手型。两只手使用同一镜头、同一物体位置和同一材质尺度，避免透视差异冒充能力差异。

抓握结果用三种非数字反馈表达：

- 接触点：实际接触处亮起。
- 稳定性：物体由“易滑落—勉强稳定—稳定”变化。
- 挤压力：手掌颜色由冷色向暖色变化，表示为弥补控制不足而增加的用力，不表示疼痛或损伤。

## 四行 × 两列

| 比较维度 | 继承结构保持不变 | 可形成更精细控制的变化 |
|---|---|---|
| 五指与关节 | 五指、掌骨、指骨和可弯曲关节构成共同的基本方案 | 不增加新手指，而是扩大已有拇指与其他手指有效相遇的范围 |
| 拇指对掌 | 拇指可以跨向掌面，但可达角度与接触位置受限 | 拇指旋转后，指腹更容易与食指或中指指腹相对 |
| 手指协同 | 多指共同弯曲适合包住较大物体 | 手指可更独立地调节弯曲程度与接触时机 |
| 抓握结果 | 整手抓握可以稳定，但小物体捏持容易滑落或依赖更大挤压力 | 指尖接触更集中，小物体的位置与方向更容易被细调 |

### 三维模型与计算口径

主画面不显示年代、长度、角度、百分比或分数，不出现写死数字。

模型内部采用无单位归一化坐标；所有比例从加载后的手部网格包围盒现场计算：

- 手掌参考尺度：`palmScale = boundingBox(palmMesh)`。
- 物体尺度：根据 `palmScale` 生成，圆柱体保持可被整手包握，小珠保持只能由指腹相对夹持；不在界面显示尺寸。
- 拇指对掌控制范围：从模型骨骼自身的安全关节约束读取，再经 `Lec.P.finiteNumber()` 校验、`Lec.P.clamp()` 限制。
- 手指独立控制量：交互输入经 `Lec.P.finiteNumber()` 校验、`Lec.P.clamp()` 限制，不显示数值刻度。
- 接触判定：用指腹碰撞体与目标物表面的最近距离计算；距离阈值由对应指腹碰撞体包围盒现场推导，不写死页面数值。
- 稳定性：比较目标物重心投影、接触点分布与接触法线；结果仅映射为“易滑落／勉强稳定／稳定”。
- 挤压力：根据维持目标物静止所需的总接触约束量映射为“较小／中等／较大”，只作课堂模型中的相对比较。
- 所有动画时长依据页面共享动效节奏变量生成；如需显示任何数值，必须先经 `Lec.P.finiteNumber()`、`Lec.P.clamp()` 与 `Lec.P.round()`，本页默认不显示。

三维模型旁常驻标注：“简化动作模型：展示结构与控制的关系，不复原某一古人类个体，也不模拟完整肌肉与触觉系统。”

## 必须点出来的一到三句

人手不是为了制造工具而突然出现的新器官；它沿用了灵长类手的基本结构，并在拇指对掌、手指独立控制和指腹接触上形成了更精细的动作能力。

## 交互（只有这一个）

学生“改造手掌抓握”：

1. 先在“大物体”与“小物体”两种任务间切换，观察固定基准手的抓握结果。
2. 拖动“拇指更能对掌”和“手指更能独立控制”两个无数字滑杆；右侧手掌随之实时改变姿态，左侧基准态保持不变。
3. 学生可拖拽物体轻微转动或抽离，观察接触点是否分散、物体是否滑落，以及手是否需要更大挤压力。
4. 两项控制都调到极端时不奖励“最大值”：过度对掌或过度独立会使大物体包握变差，以避免形成“某个特征越多越先进”的直觉。
5. “复原基准态”恢复初始手型；键盘可聚焦两个滑杆并用方向键调整，任务切换与复原均提供明确文本按钮。

学生应形成的直觉是：精细抓握来自既有结构中多个部位的协调与控制，不是增加一个孤立的“工具制造部件”；适合小物体精细捏持的配置，也不必在所有抓握任务中都占优势。

## 不许碰

- 不展示敲击石核、控制打击角度、预测断裂面、剥取石片或任何石器制造工序；这些只归 p14。
- 不把精细抓握直接等同于制造工具，也不声称某一种手型自动产生更高智力或文化。
- 不讲具体古人类物种的手部年代序列，不把模型标成某一物种的精确复原。
- 不使用“手为了工具而进化”“拇指越长越先进”或“现代人拥有完美的手”等目的论、阶梯式表述。
- 不把其他现生类人猿的手称为原始状态；左侧只是教学用受限控制配置，不代表任何现生物种或人类祖先。
- 不扩展到完整的镶嵌演化特征清单，综合归 p12。
