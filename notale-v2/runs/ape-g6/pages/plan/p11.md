# page-11 · 昂贵的大脑 · **135 秒**

- kicker：`BODY / ENERGY BUDGET`
- 主标题：大脑很昂贵，账要从全身一起算

## 知识结构：process

把“食物进入身体”到“大脑投入可能产生社会回报”的约束链显式化，而不是把脑容量变化画成独立上升趋势。

页面用一条可回流的六步主干呈现：

`摄取食物 → 消化并取得可用能量 → 支付身体基础成本 → 分配给脑部 → 承担其他身体代价 → 社会收益可能改善下一轮资源`

前五步用从左到右的粗细流带连接；第六步从右侧以虚线箭头回到第一步，表示社会收益可能影响合作取食、照料和信息共享，但不是必然成功的闭环。每次调整预算后，流带宽度、结余和警示状态同步更新。

强调这是帮助理解约束关系的相对量模型，不是对某个古人类每日代谢的复原，也不是身体有意识地“决定把能量给大脑”。

## 表征形式

交互式相对能量预算图。

左半区是 D3 绘制的六步能量流：流带宽度表示相对能量，节点显示当前状态，虚线回流表示潜在社会收益。右半区是 ECharts SVG 堆叠预算条，固定显示“进入预算、消化成本、身体维持、脑部投入、活动与成长、剩余缓冲”六项，并用一条需求线提示预算是否失衡。

学习者需要形成的心理表征是：脑部投入嵌在有限的全身预算中；提高它会挤压其他项目，只有食物质量、身体成本与可能的社会收益共同变化，预算才可能持续。

ECharts 必须以 `echarts.init(container, null, { renderer: 'svg' })` 初始化；D3 负责过程节点、流带与回流箭头，不另做第二张独立图表。

## 六个 step

### 1. 摄取食物

- 输入为本轮总能量预算，显示 `100 相对能量单位`。
- 数值来自 `Lec.K.P11_BUDGET_UNITS`，统一值为 `100`。
- “相对能量单位”只用于课堂模型，不显示为千卡或焦耳。
- 食物质量控制量显示为 `低 / 中 / 高`三级，不附年代或具体食谱。

### 2. 消化并取得可用能量

- 消化成本随食物质量变化：
  - 低质量：`30 相对能量单位`
  - 中等质量：`22 相对能量单位`
  - 高质量：`16 相对能量单位`
- 分别来自：
  - `Lec.K.P11_DIGESTION_COST_LOW`
  - `Lec.K.P11_DIGESTION_COST_MEDIUM`
  - `Lec.K.P11_DIGESTION_COST_HIGH`
- 可用能量由页面当场计算：

  `available = budget - digestionCost`

- 所有输入先经 `Lec.P.finiteNumber()` 校验，再用 `Lec.P.clamp(value, 0, budget)` 限制，显示值用 `Lec.P.round(value, 0)`。
- 页面标注：“质量较高”在本模型中仅表示单位摄取量更容易提供可用能量，不等于现代营养评价。

### 3. 支付身体基础成本

- 身体基础维持锁定为 `34 相对能量单位`，来自 `Lec.K.P11_BODY_MAINTENANCE_UNITS`。
- 该项代表维持体温、器官运作、组织修复等合并成本，不拆成器官清单。
- 扣除后余额当场计算：

  `allocatable = available - bodyMaintenance`

- 若余额小于 `0`，状态显示“基础成本未覆盖”，流程在此处变为警示色，后续分配仍可见但不计为可持续方案。

### 4. 分配给脑部

- 脑部投入滑杆范围为 `12–32 相对能量单位`：
  - 下限来自 `Lec.K.P11_BRAIN_UNITS_MIN`
  - 上限来自 `Lec.K.P11_BRAIN_UNITS_MAX`
- 初始值为 `20 相对能量单位`，来自 `Lec.K.P11_BRAIN_UNITS_DEFAULT`。
- 步长为 `1 相对能量单位`，来自 `Lec.K.P11_SLIDER_STEP_UNITS`。
- 滑杆值经：

  `brain = Lec.P.round(Lec.P.clamp(input, brainMin, brainMax), 0)`

- 页面不把滑杆称为“进化选择”或“身体决策”，而称为“调整模型中的脑部投入”。

### 5. 承担其他身体代价

- 活动、成长、生殖与储备合并为“其余身体需求”。
- 其当前可用量由页面计算：

  `otherBody = allocatable - brain`

- 稳定需求线为 `18 相对能量单位`，来自 `Lec.K.P11_OTHER_BODY_NEED_UNITS`。
- 缓冲线为 `6 相对能量单位`，来自 `Lec.K.P11_BUFFER_TARGET_UNITS`。
- 最终结余计算：

  `buffer = otherBody - otherBodyNeed`

- 三种状态：
  - `buffer < 0`：显示“挤压其他身体需求”
  - `0 ≤ buffer < bufferTarget`：显示“预算勉强平衡”
  - `buffer ≥ bufferTarget`：显示“保有缓冲”
- 阈值判断中的全部值先经 `Lec.P.finiteNumber()`；显示结果用 `Lec.P.round(value, 0)`。

### 6. 社会收益可能回流

- 当脑部投入不低于 `24 相对能量单位`且缓冲不为负时，点亮“潜在社会收益”回流箭头。
- 门槛来自 `Lec.K.P11_SOCIAL_RETURN_BRAIN_THRESHOLD`，统一值为 `24`。
- 回流只显示为 `可能改善资源获取`，不把它直接加回当前预算，也不显示虚构的能量收益量。
- 回流旁列出三个不带数值的可能渠道：
  - 更好地协调合作
  - 更长时间学习与照料
  - 更有效地共享信息
- 若脑部投入达到门槛但其他身体需求为负，回流箭头保持熄灭并提示：“潜在收益不能取消当下的身体成本。”
- 不把脑容量、智力、合作能力或社会复杂度画成一一对应关系。

## 必须点出来的一到三句

大脑昂贵；增加脑部投入不会凭空增加总预算，而会改变全身其他部分能得到多少。

食物质量、身体代价和可能的社会收益必须放在同一张账里考虑。

## 交互（只有这一个）

学生操作右侧的“脑部投入”滑杆，并可在同一预算器顶部切换食物质量的低、中、高档；两者共同属于一次“分配脑部能量预算”交互，不拆成第二个任务。

操作后同步看到：

- D3 流带在“消化成本—身体维持—脑部投入—其余身体需求”之间重新变宽或变窄；
- ECharts 堆叠预算条重新分配；
- 结余状态在“挤压其他身体需求 / 预算勉强平衡 / 保有缓冲”之间变化；
- 满足条件时，社会收益的虚线回流被点亮。

初始状态使用中等食物质量与默认脑部投入。页面给出短任务：“把脑部投入提高到社会收益门槛，同时不要让其他身体需求出现赤字。”

达成时只显示“这个组合在模型中可维持”，不显示胜利、最优解或“更高级”。学习者应形成的直觉是：较高脑部投入需要预算条件支持，并始终伴随全身权衡；它不是单变量推动的必然进步。

键盘可分别聚焦食物质量单选项和滑杆；滑杆支持方向键调整，并通过 `aria-live="polite"` 报读脑部投入、其余身体需求与当前状态。颜色变化必须同时配合文字和纹理，不以红绿作为唯一反馈。

## 不许碰

- 不讲控火或烹饪开始于哪个确定年代，不出现“某年起烹饪导致大脑变大”的时间线。
- 不把烹饪设为高质量食物的唯一来源；本页只使用抽象的食物质量档位。
- 不提前展开 p17 的生食、熟食或具体加工方式比较。
- 不宣称食物质量提高单独造成脑容量增长，也不把昂贵组织假说呈现为已经排除其他解释的定论。
- 不把脑部能量投入直接等同于智力、语言、技术或文化复杂度。
- 不讨论完整人属谱系、具体古人类脑容量排名或镶嵌特征总表。
- 不把相对能量单位冒充真实代谢测量，不显示千卡、瓦特或精确器官耗能百分比。
- 不把社会收益画成必然回报；回流必须使用“可能”“潜在”措辞。

## 版面提示

采用 `split-lr`，左侧约占画面 `58%`，右侧约占 `42%`；比例由 `Lec.K.P11_LEFT_PANEL_RATIO` 与 `Lec.K.P11_RIGHT_PANEL_RATIO` 提供，页面不得写死 CSS 百分比。

左侧六步过程按两行三列蛇形排列，以避免在窄屏上压缩标签：

`摄取食物 → 消化取得 → 身体基础成本`  
`社会收益 ← 其他身体代价 ← 脑部投入`

右侧上方放食物质量档位与脑部投入滑杆，下方放横向堆叠预算条和状态句。社会收益回流箭头跨过左侧外缘返回第一步，不穿过预算条。

窄屏改为单列：控制区在前，预算条居中，六步过程在后；步骤顺序与箭头语义不变。
