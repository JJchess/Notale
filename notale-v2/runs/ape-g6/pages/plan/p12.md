# page-12 · 不同步的身体 · **110 秒**

**Kicker：** `MOSAIC EVOLUTION`

**主标题：** 身体不是一次性变成“现代”的

## 知识结构：generalization

用一张对齐的“特征 × 代表性人类演化阶段”账本，把五类身体特征放在同一组列中比较。每一行都显示不同的变化节奏；勾选多行后，右侧总括区将这些错开的路径叠合为“镶嵌演化”。

骨架关系：

- 行：双足、手、脑、牙齿、成长节奏。
- 列：较早人族、南方古猿、早期人属、智人。
- 单元格：以“接近祖先状态 / 过渡组合 / 接近现生智人常见状态”三种文字与纹理编码呈现，不用高低等级、进度条或从暗到亮的“进步”隐喻。
- 总括：各行变化不同步，因此不存在某一格突然把整套身体切换为“现代人”。

“现代状态”只指现生智人的常见特征组合，不表示更高级、更完善或预定终点。

## 表征形式

交互式二维矩阵账本，由 D3 绑定数据并更新行高亮、列内状态和右侧汇总。

初始只显示各行名称与淡化的状态纹理；学生勾选某项后，该行展开为四个阶段的定性状态，并在右侧生成一条短句。全部勾选后，五行保持同时可见，让学生直接比较变化节奏，而不是逐张翻卡后依赖记忆。

颜色只区分状态，不表示优劣：

- 祖先性特征较多：冷灰斜线。
- 过渡或混合组合：琥珀交叉纹。
- 接近现生智人常见状态：青色点纹。
- 不确定或证据不足：空心虚线，并显示“证据有限”。

除颜色外必须同时使用文字和纹理，不能只靠色觉辨认。

## 五条支撑

页面数据建立为 `traits` 数组；画面上的支撑条数、已勾选条数和总数均由 `traits.length` 与当前选中项当场计算，不写死数字。

### 双足

- 较早人族：已有与双足活动相关的特征，但仍保留较强攀爬能力。
- 南方古猿：能够惯常双足行走，同时保留适于攀爬的上肢与肩部组合。
- 早期人属：地面双足移动的身体组合进一步改变。
- 智人：具有现生智人常见的骨盆、下肢与足部协同组合。
- 行末支撑句：双足相关变化较早出现，但不是一次完成，也没有等待大脑先达到现代状态。

### 手

- 较早人族：继承灵长类抓握结构，精细控制能力不能由单一骨骼特征判断。
- 南方古猿：手部同时保留攀爬相关特征与较精细操作的可能。
- 早期人属：手指比例与控制能力继续变化，但不存在突然出现的“工具专用手”。
- 智人：具有现生智人常见的拇指、指端与精细控制组合。
- 行末支撑句：手的变化发生在继承结构之上，与双足、脑和牙齿没有统一换挡时刻。

### 脑

- 较早人族：脑容量总体仍接近其他类人猿的范围。
- 南方古猿：已经惯常双足活动，但脑并未同步达到现生智人的常见状态。
- 早期人属：脑容量与脑组织方式经历长期、并不均匀的变化。
- 智人：具有现生智人的常见脑部组合，但个体脑大小不等同于智力等级。
- 行末支撑句：显著脑部变化晚于最早的双足相关变化，二者不能画成同步上升的阶梯。

### 牙齿

- 较早人族：犬齿与咀嚼结构已出现变化，但仍保留多种祖先性特征。
- 南方古猿：不同种类呈现不同的牙齿、颌骨与咀嚼组合。
- 早期人属：牙齿与面部结构继续变化，方向和速度并不完全一致。
- 智人：牙齿与颌面具有现生智人的常见组合。
- 行末支撑句：牙齿和颌面由饮食、发育与继承结构共同约束，不与脑或手同步变化。

### 成长节奏

- 较早人族：相关证据有限，不能仅凭成年骨骼可靠还原完整成长过程。
- 南方古猿：牙齿发育等证据提示成长节奏并非现生智人的完整模式。
- 早期人属：童年长度、成熟速度与生活史特征逐步改变，证据仍有不确定性。
- 智人：具有较长童年、较晚成熟和较长依赖期的常见生活史组合。
- 行末支撑句：较长成长与依赖期是逐步形成的，不是双足出现时随整套身体一同到位。

### 画面计数与来源

- “已查看 X / Y 项”：`X = selectedTraits.size`，`Y = traits.length`；均先经 `Lec.P.finiteNumber()` 校验，再以 `Lec.P.clamp(X, 0, traits.length)` 限制范围，最后用 `Lec.P.round(value, 0)` 显示。
- “变化节奏相同：X 项”：由页面比较各行状态序列后计算；本页数据结果应为零。显示值仍须经过 `Lec.P.finiteNumber()`、`Lec.P.clamp()` 与 `Lec.P.round()`，不得在界面文案中写死。
- 不显示年代、脑容量、牙齿尺寸或成熟年龄；本页只比较变化次序与组合，避免把近似证据包装成精确刻度。
- 行数、列数、勾选总数及完成比例全部从绑定数据计算，不在 HTML 文案中写死。

## 必须点出来的一到三句

双足、手、脑、牙齿和成长节奏并未同步抵达现生智人的常见状态。

所谓“现代身体”是一组在不同时间、以不同速度形成的特征组合，不是一次性的整套升级。

## 交互（只有这一个）

学生勾选“镶嵌特征”列表中的任一项，对应矩阵行随即展开，显示该特征跨四个代表性阶段的定性变化；再次取消勾选，行内容收起，但不改变其他行。

每勾选一项：

- 该行由淡化转为清晰，四个状态单元格依次显现。
- 右侧加入该行的一句支撑结论。
- 页脚计数更新为“已查看 X / Y 项”。
- 已展开的多行保持对齐，便于直接看出哪些特征较早变化、哪些较晚变化、哪些长期保留混合状态。

当所有项目均被勾选时，右侧总括区显示：

“没有两条路径构成完全同步的整套切换——这就是镶嵌演化。”

该完成态不是胜负，也不评分；目标是让学生通过同时展开并比较各行，形成“不同身体系统各自变化、最后组合在一起”的直觉。

键盘操作与指针操作等价：复选框可用 Tab 聚焦、空格切换；状态更新通过 `aria-live="polite"` 简短播报。若启用减少动态效果，取消依次显现，直接更新最终状态。

## 不许碰

- 不讲模仿、教学、语言、共享注意、外部记忆、文化棘轮或创新—传播—保留机制；这些属于 p18–21。
- 不把身体特征变化解释成文化累积的结果，也不从本页跳转到石器、火或语言能力。
- 不重新展开双足力学、双足起源假说、脚印证据、手掌抓握机制或大脑能量预算；这些分别已由 p06、p08、p09、p10、p11承担。
- 不制作第二棵人类谱系树，不详细讨论物种亲缘与共存关系；谱系结构属于 p07。
- 不把各列画成由低到高的进步阶梯，不使用“更先进”“更完善”“半人半猿”等表述。
- 不暗示所有特征都沿单一方向稳定变化；必须保留过渡组合、祖先性特征延续和证据不确定性。
- 不把“智人”当作演化目标；“现代状态”仅是与现生智人常见组合进行描述性比较。
