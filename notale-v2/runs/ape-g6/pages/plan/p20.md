# page-20 · 有限符号，无限关系 · **145 秒**

**Kicker：LANGUAGE / COMBINATION**

**主标题：有限符号，怎样说出没说过的关系？**

## 知识结构：classification

把“语言能力”显式分成两个层级，并用主干—分支结构呈现：

- 主干一：**可重复使用的有限单位**
  - 实体符号：人、物、地点。
  - 动作符号：给、拿、去、看。
  - 关系标记：谁做、对谁做、在哪里、何时发生。
- 主干二：**由单位组合出的关系类型**
  - 属性关系：谁／什么具有某种性质。
  - 动作关系：谁对谁做了什么。
  - 空间关系：谁／什么位于哪里。
  - 时间关系：某件事发生在另一件事之前或之后。
  - 嵌套关系：把一个已表达的关系作为另一个关系的一部分。

画面中央以“符号库存 → 组合槽 → 接收者理解”的横向主干连接两层分类。符号库存按类别分区；组合槽按关系角色对齐；提交后，接收者从多个候选情景中选出自己理解到的关系。分类的重点不是给词汇贴标签，而是让学生看到：同一批单位进入不同关系槽，会生成不同含义。

## 表征形式

交互式二维符号组合台，覆盖主要画布。

符号不是自然语言单词，而是颜色、图形和简短文字共同编码的卡片，避免把某一种语言的固定词序误当成语言的普遍本质。卡片拖入槽位后，以连线、角色标签和轻量动画显示“谁与谁建立了什么关系”。

提交表达后，右侧“接收者”自动选择一个候选情景：

- 若关系表达足够明确，接收者选中目标情景。
- 若只有词项堆叠而缺少关系标记，接收者在多个情景间犹豫。
- 若角色位置冲突，接收者选择另一幅情景。
- 若表达包含嵌套关系，画面将内层关系折叠成一个可复用的关系块，再接入外层关系。

## 层级里的各项

### 有限单位

页面内容配置全部置于 `Lec.P20`，不在组件中写死：

- `Lec.P20.entities`
  - 阿蓝
  - 阿橙
  - 石头
  - 果实
  - 山洞
  - 河边
- `Lec.P20.actions`
  - 给
  - 拿
  - 去
  - 看
- `Lec.P20.relationMarkers`
  - 行动者
  - 承受者／对象
  - 地点
  - 之前
  - 之后
- `Lec.P20.relationSlots`
  - 属性关系：实体—属性
  - 动作关系：行动者—动作—对象
  - 空间关系：实体／事件—地点
  - 时间关系：事件—之前／之后—事件
  - 嵌套关系：外层事件—对象槽中放入内层关系块

这些名称是教学用角色，不宣称所有语言都以相同词序或显式标记表达它们。

### 目标关系

目标题目来自 `Lec.P20.targets`，按由浅到深的顺序读取：

- 阿蓝拿果实。
- 阿橙拿石头。
- 阿蓝给阿橙果实。
- 阿橙在河边看阿蓝。
- 阿蓝去山洞，发生在阿橙拿果实之后。
- 阿橙看见“阿蓝给出果实”这一关系。

每个目标同时保存：

- `semanticGraph`：实体、动作及角色边构成的关系图。
- `acceptedForms`：可被系统接受的多种组合方式。
- `distractors`：复用相同符号、但角色或关系不同的候选情景。
- `feedbackKey`：对应“明确”“缺少关系”“角色互换”或“嵌套成功”的反馈。

判定比较的是关系图，不是唯一字符串或唯一词序。

### 页面数值与算法

主画面不显示倒计时、得分数字、符号总数或关卡编号，只用目标节点、状态灯和完成轨迹表达进度。

交互内部使用的数值全部从 `Lec` 取得：

- 当前目标索引：`Lec.P20.initialTargetIndex`。
- 允许误解次数：`Lec.P20.maxMisunderstandings`。
- 当前误解次数：由状态数组经 `Lec.P20.countMisunderstandings(state)` 当场计算。
- 已完成目标数：由 `Lec.P20.targets.filter(target => target.completed).length` 当场计算。
- 总目标数：由 `Lec.P20.targets.length` 当场计算。
- 进度比例：先以 `Lec.P.finiteNumber(completed / total)` 校验，再用 `Lec.P.clamp(value, Lec.P20.progressMin, Lec.P20.progressMax)` 限制。
- 卡片吸附距离、拖动边界、动画时长、反馈停留时长：分别读取 `Lec.P20.snapDistancePx`、`Lec.P20.dragBoundsPx`、`Lec.P20.motionDurationMs`、`Lec.P20.feedbackDurationMs`；单位为 `px` 与 `ms`。
- 所有需要显示的百分比若无障碍文本调用，先经 `Lec.P.finiteNumber()`、`Lec.P.clamp()`，再用 `Lec.P.round()`控制精度；默认视觉界面不显示百分比。

## 必须点出来的一到三句

语言的关键力量不只是拥有很多词，而是能用有限单位生成并共享新的关系。

同样几个符号，关系角色一变，表达的就可能是完全不同的事情。

## 交互（只有这一个）

学生拖动有限符号，把它们放进关系槽中，尝试让右侧接收者认出画面上给定的目标关系。

核心循环：

- 画布给出一个无文字目标情景。
- 学生从固定符号库存中拖卡组合，不增加新词。
- 学生按“传达”，接收者依据组合形成的关系图选择候选情景。
- 系统立即以连线叠加目标图与接收图：
  - 绿色实线表示关系成功共享。
  - 琥珀虚线表示符号齐全但关系不明确。
  - 红色交叉线表示行动者、对象、地点或时间关系被误解。
- 学生保留已有组合并调整，直到接收者选中目标情景。

形成的直觉：困难不在于“有没有对应的词”，而在于能否把有限单位组织成可被他人恢复的关系结构；已完成的关系还可以折叠为关系块，参与更大的组合。

胜负条件：

- **胜利**：完成 `Lec.P20.targets` 中全部目标，终局把本页用过的有限符号汇聚在左侧，把已传达的多种关系图展开在右侧。
- **失败**：累计误解达到 `Lec.P20.maxMisunderstandings`，接收端显示“符号收到了，关系没有被可靠恢复”，随后允许原地重试。
- **重置**：恢复 `Lec.P20.initialState()`，包括初始目标、卡片位置、误解状态和进度；本页不使用随机过程，也不设置“换一组”。

键盘操作必须与拖动等价：焦点选中卡片后，可在槽位间移动、放置、撤回并提交。颜色反馈同时配合线型、图标和文字，不以颜色作为唯一判据。

## 不许碰

- 不讲布罗卡区、韦尼克区、脑侧化或任何大脑语言区细节。
- 不推测语言的单一出现年代，也不判断某一种古人类是否拥有“完整现代语言”。
- 不把语言描绘成词汇数量排行榜。
- 不把某一种自然语言的主谓宾词序当作普遍语法。
- 不展开语音产生、发声器官、文字系统或学校教育。
- 不在本页综合创新、传播、保留的文化棘轮；该系统归 p21。
- 不把完成小游戏解释为真实语言学习、翻译或交流能力测验。

## 版面提示

采用 `canvas-full`：顶部仅保留 kicker、主标题和一句短任务提示；其余区域为连续工作台。

- 左侧窄栏：按“实体／动作／关系标记”分类的固定符号库存。
- 中央主区：目标情景与可伸缩关系槽，是唯一主要操作面。
- 右侧窄栏：接收者候选情景与理解反馈。
- 底部：只放“撤回”“传达”“重置”及无数字进度轨迹。
- 嵌套题出现时，中央关系槽向下展开内层，不切换页面、不弹出模态框。
- 符号类别靠形状与标题区分；角色关系靠连线和槽位标签区分，避免依赖大段说明文字。
