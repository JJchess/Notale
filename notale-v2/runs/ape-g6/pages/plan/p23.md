# page-23 · 一块地，两个账本 · **130 秒**

**Kicker：** `LAND / LIFE`  
**主标题：** 同一块地，养活更多人就一定过得更好吗？

## 知识结构：comparison

把“单位土地的供养能力”与“个体生活状况”这两个常被混为一谈的层次显式拆开。

上半区用左右对齐的两列比较“采集”与“种植”，四行维度保持同一顺序；下半区让学生配平投入比例，观察两套结果不会同步变好：

- 土地层：同样面积能够支持多少人口。
- 个体层：食物多样性、劳动负担与健康风险如何变化。
- 左列始终是“以采集为主”，右列始终是“以种植为主”。
- 每次调整只改变两种生计方式的比例，不把任一端标成“落后”或“先进”。

## 表征形式

交互式双层对照图。

上半区是四行 × 两列的比较矩阵：每行中央放共享维度名，两侧分别显示采集与种植的相对表现。下半区是 ECharts SVG 双向权衡图，共用同一横轴“种植投入占比”，但分成两个上下对齐的小图：

1. “单位土地供养能力”随种植投入总体上升。
2. “个体处境”拆为食物多样性、劳动负担、暴露风险三条响应，不与供养能力绑定为同方向变化。

所有曲线都是教学用的归一化关系模型，不冒充跨地区、跨时代的实测平均值。图旁持续显示“示意模型：结果受作物、气候、制度与人群差异影响”。

## 四行 × 两列

| 比较维度 | 以采集为主 | 以种植为主 |
|---|---|---|
| 单位土地供养能力 | 通常较低，需要更大活动范围 | 通常较高，可在较小范围支持更多人口 |
| 食物来源 | 来源可能更分散、随季节变化 | 主粮供应可增加，但可能更依赖少数作物 |
| 劳动组织 | 搜寻、移动与处理投入随环境波动 | 播种、除草、灌溉、收获与储存形成集中劳动 |
| 个体风险 | 面对季节短缺、迁移与采集失败 | 面对歉收、单一饮食、密集居住和重复劳动风险 |

矩阵措辞必须使用“通常”“可能”“在特定条件下”，不得把任一列写成人类社会的统一状态。这里比较的是生计组合产生的权衡，不是给所有采集者或农民贴固定标签。

### 页面数值与模型

- 年代锚点显示“约1.2万年前起”，来源为 `Lec.K.AGRICULTURE_EARLY_YEARS`；先经 `Lec.P.finiteNumber()` 校验，再换算为“万年前”，用 `Lec.P.round(value / 1e4, 1)` 显示。
- 年代完整表述为“约1.2万年前起，农业转型在多个地区发生”；不得显示单一起源点。
- 交互变量 `cropShare` 表示种植投入占全部生计投入的比例，内部范围为 `[0, 1]`，每次输入均经 `Lec.P.finiteNumber()` 与 `Lec.P.clamp(cropShare, 0, 1)`。
- 页面显示“采集投入”和“种植投入”，单位均为 `%`：
  - 种植投入：`Lec.P.round(cropShare × 100, 0)`。
  - 采集投入：`Lec.P.round((1 - cropShare) × 100, 0)`。
- 初始状态为两种投入相等：页面加载时由算法令 `cropShare = 1 / 2`，不在标记文本中写死显示值。
- ECharts 横轴显示种植投入占比，单位 `%`；采样点由区间 `[0,1]` 等距生成，标签用 `Lec.P.round(x × 100, 0)`。
- 纵轴统一写“相对水平”，不显示伪精确实测单位，也不把归一化值作为历史统计数字。
- 单位土地供养能力模型：`landSupport = 0.25 + 0.75 × cropShare`。
- 食物多样性模型：`dietDiversity = 0.75 - 0.35 × cropShare + 0.10 × cropShare × (1 - cropShare)`。
- 劳动负担模型：`laborBurden = 0.35 + 0.45 × cropShare + 0.10 × cropShare²`。
- 暴露风险模型：`exposureRisk = 0.30 + 0.25 × cropShare + 0.20 × cropShare²`。
- 四项模型输出均先经 `Lec.P.finiteNumber()`，再经 `Lec.P.clamp(value, 0, 1)`；仅用于决定柱长、曲线位置和“较低／中等／较高”标签，不直接显示小数。
- 质性标签按归一化结果当场计算：
  - `[0, 1/3)`：较低。
  - `[1/3, 2/3)`：中等。
  - `[2/3, 1]`：较高。
- 阈值由单位区间三等分算法生成，不在页面正文中显示阈值数字。
- ECharts 必须使用 `echarts.init(element, null, { renderer: 'svg' })`。
- tooltip只显示投入比例和质性结果，并固定附注“课堂示意关系，不是统一历史平均值”。

## 必须点出来的一到三句

农业可以提高单位土地可供养的人口，却未必立即改善个体健康、食物多样性或劳动负担。

“养活更多人”与“每个人过得更好”是两个不同的问题。

## 交互（只有这一个）

**配平采集与种植。**

学生拖动一条左右配平杆，改变固定总投入中“采集”与“种植”的比例。拖动时同步发生三类变化：

- 左右投入百分比更新。
- 上半区四行比较中，与当前组合更相关的词组提高亮度，但两列都不消失。
- 下半区 ECharts 的竖向游标移动，并更新单位土地供养能力、食物多样性、劳动负担与暴露风险的当前位置。

当种植投入提高时，供养能力图总体上升；个体处境的三项指标不会整齐地朝同一方向改善。学生应形成的直觉是：农业转型带来的是多维权衡，人口密度增加不能直接推出个体福利增加。

不设置胜负、最佳点、得分或“文明值”。拖到任一端都只显示该端的代价与收益，不出现庆祝动画。键盘左右键可逐档调整，`Home` 与 `End` 到达两端，屏幕阅读器播报当前两类投入比例及四项质性结果。

## 不许碰

- 不把农业叙述成发生于一个地点、一个民族或一个确定时刻的单一起点；只能写“约1.2万年前起在多个地区发生”。
- 不解释农业为何导致定居、储存、分工、疾病与权力的反馈网络，这些属于 p25。
- 不使用“农业革命之后人类从此进步”或“采集社会更原始”等阶梯式语言。
- 不宣称所有早期农民都更矮、更病弱或劳动时间必然更长；只能说明这些结果会因作物、环境、制度和证据样本而异。
- 不把本页归一化模型冒充考古统计、现代营养建议或跨社会通用定量结论。
- 不扩展农业的多个独立起源地区清单、具体作物驯化年代或国家兴衰。
- 不提前展开能量阶梯、工业化或火箭推进。
