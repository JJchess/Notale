# page-28 · 让解释接受淘汰 · **145 秒**

- Kicker：`SCIENCE / CORRECTION`
- 主标题：**好解释，要先冒被证据否定的风险**

## 知识结构：process

把科学纠错显式化为一条可反复运行的六步主干：

**提出问题 → 并列解释 → 公开预测 → 运行测量 → 对照淘汰 → 重复检验**

主画布始终保留这条从左向右的流程。当前步骤高亮，已完成步骤留下测量记录；“重复检验”以回环箭头返回“公开预测”，表示结论不是一次闯关后的永久真理。

每个候选解释占一行，行内依次对齐它的预测、测量结果、冲突次数与当前状态。学习者应看见：解释不是按权威、语气或最初支持者决定去留，而是被预先公开的预测与可重复测量共同约束。

## 表征形式

交互式二维黑箱实验台。

中央是一台虚构的“信号盒”：学习者可改变输入条件，盒子输出带少量测量波动的信号。左侧排列候选解释，右侧累积每次实验的预测—实测记录。底部是一条从“待检验”到“暂时保留／与证据冲突”的状态轨。

采用虚构装置而不使用真实自然现象，避免学生把注意力转向尚未学习的生物、化学或轨道知识；页面只训练预测、测量、纠错与重复的过程表征。

动态只服务于因果顺序：

- 锁定预测后，预测卡滑入不可修改区。
- 测量运行时，信号点在刻度带上出现，并保留误差范围。
- 结果与预测明显冲突时，对应解释行出现裂纹式标记，但不立即消失。
- 重复测量达到判定条件后，解释才移入“与证据冲突”区。
- 仍符合证据的解释标为“暂时保留”，不得显示“已证明”。

## 六个 step

### 提出问题

屏幕给出唯一问题：

> 信号盒的输出主要由哪个输入决定？

实验台提供三个可单独改变的输入：

- 光照强度
- 环境温度
- 按键次数

三者只是黑箱变量，不映射到具体自然定律。

### 并列解释

候选解释同时公开，初始地位相同：

- **解释甲：光照决定输出。**
- **解释乙：温度决定输出。**
- **解释丙：按键次数决定输出。**
- **解释丁：输出没有稳定关系，只是随机变化。**

每个解释必须给出方向明确、可比较的预测；不能只写“可能有关”。

### 公开预测

学习者先选择一个实验条件，再为每个仍在场的解释锁定预测：

- 输出升高
- 输出基本不变
- 输出降低
- 无稳定方向

锁定后本轮不得修改。所有预测同时显示在候选解释行内，形成“公开预测板”。

若学习者试图先测量再填写预测，运行按钮保持禁用，并提示：

> 先说会看到什么，证据才可能纠正你。

### 运行测量

每次只改变一个输入，其余输入保持基准状态。信号盒返回：

- 本次输入条件
- 输出测量值
- 测量波动范围
- 本轮种子内的实验序号

同一条件可重复运行。结果带有限波动，但真实生成规则在当前题组内保持不变。

### 对照淘汰

系统不替学生自动判决。学习者需把本轮结果拖到下列一种判断：

- 与预测相符
- 结果不足以区分
- 与预测冲突

提交后系统依据预测区间与测量区间检查判断，并给出即时反馈：

- 判断正确：记录进入证据栏。
- 把模糊结果当作支持：提示“这次测量不能区分这些解释”。
- 把单次异常当作淘汰：提示“先重复，确认冲突是否稳定”。
- 事后改预测：不允许覆盖原卡，只能新增“修订解释”。

解释只有在独立重复后持续冲突，才进入“与证据冲突”区。

### 重复检验

学习者必须对最有区分力的条件进行重复测量，并至少换用一种条件检查剩余解释。

达成胜利时，画面保留：

- 被证据淘汰的解释
- 修订过的解释
- 暂时保留的解释
- 全部预测与测量记录

最终按钮文案为：

> 暂时保留，并允许别人重做

不得出现“找到绝对真相”“证明科学家正确”等文案。

## 实验规则与页面数值

所有画面数值从 `Lec` 读取；页面初始化时先经 `Lec.P.finiteNumber()` 校验，交互输入经 `Lec.P.clamp()` 限制，显示值经 `Lec.P.round()` 处理。

页面新增并统一从以下页面级配置读取：

- `Lec.P28.INPUT_MIN = 0`：三个输入刻度的最小值；画面显示为 `0`，无单位，表示标准化输入。
- `Lec.P28.INPUT_MAX = 10`：三个输入刻度的最大值；画面显示为 `10`，无单位。
- `Lec.P28.INPUT_BASELINE = 5`：未被操纵输入的基准值；画面显示为 `5`，无单位。
- `Lec.P28.INPUT_STEP = 1`：滑杆每次变化量；画面显示为刻度间隔 `1`，无单位。
- `Lec.P28.OUTPUT_MIN = 0`：输出刻度下界；画面显示为 `0 信号单位`。
- `Lec.P28.OUTPUT_MAX = 100`：输出刻度上界；画面显示为 `100 信号单位`。
- `Lec.P28.OUTPUT_BASELINE = 50`：当前题组的输出中心基准；画面显示为 `50 信号单位`。
- `Lec.P28.NOISE_MAX = 4`：单次测量波动的绝对上限；画面显示为“波动不超过 ±4 信号单位”。
- `Lec.P28.PREDICTION_TOLERANCE = 8`：判定“基本不变”的预测容差；画面说明显示为“相对基准变化不超过 ±8 信号单位”。
- `Lec.P28.CONFLICT_REPEAT_TARGET = 3`：解释进入“与证据冲突”区前所需的连续冲突次数；画面显示为“需连续冲突 3 次”。
- `Lec.P28.DISTINCT_CONDITION_TARGET = 2`：胜利前至少使用的不同实验条件数；画面显示为“至少检验 2 种条件”。
- `Lec.P28.MAX_TRIALS = 9`：单局允许的最大测量次数；画面显示为“剩余测量次数：9”并随实验递减。
- `Lec.P28.HYPOTHESIS_COUNT = 4`：候选解释总数；用于生成解释行和进度文本“4 个候选解释”。
- `Lec.P28.RETAIN_TARGET = 1`：标准题组预期最终暂时保留的解释数；只用于胜负判定，不把保留状态写成证明。
- `Lec.P28.SEED = Lec.K.SIM_SEED_SCIENCE`：初始随机种子，统一值为 `"apeman-spaceman-p28"`；种子字符串不在主画面显示，只在调试信息与可复制实验记录中提供。

输出生成算法：

- 每个题组由种子确定一个真实主变量、响应方向和响应强度。
- 响应强度由伪随机数映射到 `Lec.P28.PREDICTION_TOLERANCE` 以上、且不超过输出量程四分之一的范围。
- 测量波动由 `seedrandom.min.js` 生成，映射到 `-Lec.P28.NOISE_MAX` 至 `+Lec.P28.NOISE_MAX`。
- 输出先计算“基准输出 + 主变量响应 + 测量波动”，再以 `Lec.P.clamp()` 限制在 `Lec.P28.OUTPUT_MIN` 与 `Lec.P28.OUTPUT_MAX` 之间。
- 画面输出值使用 `Lec.P.round(value, 0)`，单位统一为“信号单位”。
- “升高／降低／基本不变”的判定，以相对 `Lec.P28.OUTPUT_BASELINE` 的差值和 `Lec.P28.PREDICTION_TOLERANCE` 比较。
- 相同种子、相同实验操作顺序必须产生相同结果序列。

重置与换题：

- “重置本局”恢复 `Lec.K.SIM_SEED_SCIENCE` 对应的同一初始状态与同一结果序列。
- “换一组”才生成新种子；新种子由基础种子、换题计数和固定分隔符拼接后交给 `seedrandom.min.js`。
- 换题计数从 `Lec.P28.VARIANT_START_INDEX = 1` 读取，画面显示“题组 1”。
- 实验记录中的题组号、实验序号与各输入值都从当前状态读取，不在 DOM 文案中写死。

## 必须点出来的一到三句

- **科学的力量来自公开预测、测量、纠错和可重复，而不是科学家从不犯错。**
- 一次相符只能增加信心，稳定冲突却能迫使解释被淘汰或修订。
- 经受住本页检验的解释只能“暂时保留”，还必须允许别人按同样步骤重做。

## 交互（只有这一个）

**运行证据淘汰赛。**

学习者选择要改变的输入，先锁定各解释的公开预测，再运行测量、判断结果与预测的关系，并决定重复哪个实验。画面同步改变预测板、测量记录、冲突计数和候选解释状态。

游戏目标是在测量次数用尽前，用具有区分力且经过重复的证据淘汰不可靠解释，并把唯一仍符合现有结果的解释标为“暂时保留”。

胜利条件：

- 使用的不同实验条件达到 `Lec.P28.DISTINCT_CONDITION_TARGET`。
- 每个被淘汰解释的连续冲突次数达到 `Lec.P28.CONFLICT_REPEAT_TARGET`。
- 暂时保留的解释数等于 `Lec.P28.RETAIN_TARGET`。
- 所有实验都在测量前锁定预测。

失败条件：

- 测量次数达到 `Lec.P28.MAX_TRIALS`，仍有多个无法区分的解释。
- 学习者反复选择不能区分候选解释的条件，耗尽测量机会。
- 不把单次异常直接判作失败；系统将其标为“需要重复”。

失败反馈不公布正确操作序列，只指出缺失环节，如“预测没有区分解释”“冲突尚未重复”或“只改变了一个条件范围”。重置恢复固定种子；“换一组”才改变种子。

学生应形成的直觉是：好实验不是收集最多结果，而是让不同解释给出不同预测；好结论也不是永不出错，而是保留可检查的记录，并能在重复失败时被修订。

## 不许碰

- 不讲任何具体轨道计算、轨道速度、轨道形状、速度增量、质量比或火箭方程；这些内容归 p35–37。
- 不把本页黑箱数值包装成真实物理、生物或化学定律。
- 不把“多次相符”说成逻辑上的最终证明，也不把单次异常直接当作彻底证伪。
- 不把科学方法画成僵硬且永远同序的唯一流程；六步是本页用于显式化纠错关系的教学骨架，回环必须可见。
- 不加入科学史人物、著名实验或学科争论，以免把唯一的证据纠错小游戏变成人物知识测验。
- 不以“科学家更聪明”“权威已经确认”作为解释保留的理由。
- 不另设第二个问答、翻卡、拖拽配对或装饰性点击；所有操作都属于同一局证据淘汰赛。

## 必用skill

mini-game, seedrandom.min.js, frontend-design

## 版面提示

使用 `canvas-full` 单屏布局，不滚动完成主任务。

- 顶部：Kicker、主标题、剩余测量次数、重置与“换一组”。
- 中部左侧约三分之二：黑箱实验台、三个输入控制与输出刻度。
- 中部右侧约三分之一：四行候选解释，每行固定对齐“解释—公开预测—冲突记录—状态”。
- 底部：六步流程条与可横向展开的实验记录带。
- “公开预测”区与“测量结果”区必须在空间上分开；预测锁定后才允许结果进入画面。
- 状态不能只靠颜色区分；同时使用文字、图形和线型。暂时保留用实线框与“暂时保留”，冲突用断裂线与“与证据冲突”，尚不能区分用点线与“证据不足”。
- 主视觉记忆点是多行解释在重复证据后依次退出主干，而完整记录仍留在流程下方，不做被击碎后消失的简单淘汰动画。
