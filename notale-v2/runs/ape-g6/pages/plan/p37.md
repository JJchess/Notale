# page-37 · 质量比的陡坡 · **140 秒**

**Kicker：ORBITAL COST**  
**主标题：多要一点速度，为什么会多带这么多推进剂？**

## 知识结构：comparison

把“速度增量等量增加”与“质量比加速增长”并排显式化。

左侧用三档对齐配置呈现低、中、高速度增量：每档都使用同一喷气速度，因此唯一变化的是所需速度增量。右侧用同一坐标系中的质量比曲线呈现三档配置点，并用对齐读数显示质量比、理想推进剂比例和非推进剂余量。

核心比较关系：

- 速度增量：按相同的 `3000 m/s` 间隔增加。
- 质量比：不是按相同间隔增加，而是依次约为前一档的 `e` 倍。
- 推进剂比例：不断逼近初始质量的全部，留给结构、载荷和回收余量的空间迅速收窄。

## 表征形式

交互式左右分栏比较图。

左栏是“任务配置台”：固定喷气速度，拖动所需速度增量，并提供低、中、高三个对齐锚点。当前配置以一个由“推进剂”和“非推进剂质量”组成的纵向质量条显示。

右栏是 ECharts SVG 曲线图：

- 横轴：所需速度增量 `Δv`，单位 `km/s`。
- 纵轴：初始质量与燃尽后质量之比 `m₀/m₁`，无单位。
- 曲线：`massRatio = exp(deltaV / exhaustVelocity)`。
- 三个固定锚点始终可见，当前配置点随滑杆沿曲线移动。
- 当前点向两轴投射细虚线，使学生能同时读取输入和结果。
- 图下方同步显示推进剂比例与非推进剂比例。

公式使用 KaTeX 排版，基准字号不低于 `20px`：

`m_0 / m_1 = e^{\Delta v / v_e}`

并紧邻给出符号释义：

- `m₀`：点火前总质量。
- `m₁`：推进剂耗尽后的质量。
- `Δv`：任务要求火箭累计改变速度的能力。
- `vₑ`：示例发动机的有效喷气速度。

画面明确标注“理想化单级关系”，不把曲线称为真实任务质量预测。

## 三档速度增量 × 四项结果

所有显示值先经 `Lec.P.finiteNumber()` 校验，再经 `Lec.P.clamp()` 限制范围，并用 `Lec.P.round()` 控制精度。

统一喷气速度：

- `vₑ = Lec.K.ROCKET_EXHAUST_VELOCITY_DEMO_MPS`
- 页面显示为 `Lec.P.round(vₑ / 1000, 1) km/s`，即约 `3.0 km/s`。
- tooltip同时显示 `Lec.P.round(vₑ, 0) m/s`。

低速度增量配置：

- `Δv = Lec.K.ROCKET_DEMO_DV_LOW_MPS`
- 页面显示 `Lec.P.round(Δv / 1000, 1) km/s`，即约 `3.0 km/s`。
- 质量比由页面计算：`Math.exp(Δv / vₑ)`；显示 `Lec.P.round(massRatio, 2)`，即约 `2.72`。
- 理想推进剂比例由页面计算：`1 - 1 / massRatio`；显示 `Lec.P.round(propellantFraction * 100, 1)%`，即约 `63.2%`。
- 非推进剂比例由页面计算：`1 / massRatio`；显示 `Lec.P.round(nonPropellantFraction * 100, 1)%`，即约 `36.8%`。

中速度增量配置：

- `Δv = Lec.K.ROCKET_DEMO_DV_MEDIUM_MPS`
- 页面显示 `Lec.P.round(Δv / 1000, 1) km/s`，即约 `6.0 km/s`。
- 质量比由页面计算：`Math.exp(Δv / vₑ)`；显示 `Lec.P.round(massRatio, 2)`，即约 `7.39`。
- 理想推进剂比例由页面计算：`1 - 1 / massRatio`；显示 `Lec.P.round(propellantFraction * 100, 1)%`，即约 `86.5%`。
- 非推进剂比例由页面计算：`1 / massRatio`；显示 `Lec.P.round(nonPropellantFraction * 100, 1)%`，即约 `13.5%`。

高速度增量配置：

- `Δv = Lec.K.ROCKET_DEMO_DV_HIGH_MPS`
- 页面显示 `Lec.P.round(Δv / 1000, 1) km/s`，即约 `9.0 km/s`。
- 质量比由页面计算：`Math.exp(Δv / vₑ)`；显示 `Lec.P.round(massRatio, 2)`，即约 `20.09`。
- 理想推进剂比例由页面计算：`1 - 1 / massRatio`；显示 `Lec.P.round(propellantFraction * 100, 1)%`，即约 `95.0%`。
- 非推进剂比例由页面计算：`1 / massRatio`；显示 `Lec.P.round(nonPropellantFraction * 100, 1)%`，即约 `5.0%`。

曲线与控件数值：

- 滑杆下界取 `Lec.K.ROCKET_DEMO_DV_LOW_MPS`。
- 滑杆上界取 `Lec.K.ROCKET_DEMO_DV_HIGH_MPS`。
- 滑杆初始值取 `Lec.K.ROCKET_DEMO_DV_MEDIUM_MPS`。
- 滑杆步长由页面计算：  
  `(Lec.K.ROCKET_DEMO_DV_HIGH_MPS - Lec.K.ROCKET_DEMO_DV_LOW_MPS) / 60`，单位 `m/s`。
- 曲线采样点数由同一范围与步长计算，不在页面写死。
- 横轴显示范围由低、高速度增量常量确定，单位换算为 `km/s`。
- 纵轴下界由 `Math.exp(lowDeltaV / vₑ)` 计算，纵轴上界由 `Math.exp(highDeltaV / vₑ)` 计算；上界留白比例由图表布局配置处理，不作为教学数值显示。
- ECharts 初始化必须使用 `{ renderer: 'svg' }`。

质量条中的“非推进剂”只表示燃尽后剩余总质量，包含结构、发动机、载荷及其他未消耗质量；不得将其直接标成“载荷”。

## 必须点出来的一到三句

所需速度增量上升时，推进剂比例以越来越不友好的方式增长。

在这个统一示例中，速度增量从约 `3.0 km/s` 增至约 `9.0 km/s`，质量比却从约 `2.72` 墦升到约 `20.09`；难点不是只多准备相同的一份推进剂，而是推进剂本身也要被继续加速。

## 交互（只有这一个）

**配置质量比。**

学生拖动“所需速度增量”滑杆，或点击低、中、高三个锚点。喷气速度固定为 `Lec.K.ROCKET_EXHAUST_VELOCITY_DEMO_MPS`，避免同时改变两个变量而破坏比较。

拖动时同步发生：

- 当前点沿质量比曲线移动。
- 质量比读数实时更新。
- 质量条中的推进剂区扩大，非推进剂区缩小。
- 三档锚点保持不动，便于将当前值与统一基准比较。
- 跨过低、中、高常量对应位置时，相应配置行高亮，但不弹出新的任务或按钮。

学生应形成的直觉是：横轴上等距离增加的速度增量，在纵轴上造成越来越大的质量比变化；推进剂越多，需要被加速的初始质量也越大。

键盘必须可操作滑杆；左右方向键按计算出的步长调整，三个锚点均可聚焦并用 Enter 或 Space 选择。读数更新通过 `aria-live="polite"` 提供，但拖动过程中应节流，避免连续朗读。

## 不许碰

- 不使用微积分，不推导指数函数或火箭方程。
- 不从动量守恒重新讲反冲原理；该职责属于 p33。
- 不重新解释多级火箭如何抛弃空质量；该职责属于 p36。本页最多用一句旁注指出“现实工程会用多级等办法应对这一压力”。
- 不把理想推进剂比例误写成真实火箭的燃料占比，也不把非推进剂部分等同于有效载荷。
- 不绑定某一真实发动机、运载火箭或具体航天任务。
- 不加入轨道高度、轨道速度或逃逸速度的任务比较，避免重复 p34–35。
- 不讨论发射窗口、地球自转或轨道平面；这些属于 p38。
- 不把曲线结果冒充任务级预测。必须标注模型忽略大气阻力、地球非球形、重力损失、复杂姿态控制及发动机性能变化。
- 不允许学生调整喷气速度；本页只比较速度增量变化造成的质量比变化。

## 版面提示

采用 `split-lr`，左右宽度约为 `42% : 58%`。

左栏自上而下排列公式、固定喷气速度、速度增量滑杆、三个锚点和质量组成条；右栏以质量比曲线为主视觉，下方放三行对齐比较读数。

三档比较必须共享同一列宽与小数精度，让学生能纵向扫描：

`速度增量｜质量比｜推进剂比例｜非推进剂比例`

窄屏时改为上下排列，但配置台必须先于曲线出现；不得将公式、滑杆和曲线拆散到互不相邻的卡片中。
