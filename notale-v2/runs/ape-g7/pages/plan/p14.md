# page-14 · 膝盖为什么向中线靠 · **140 秒**

`BODY II / LOAD LINE`

## 知识结构：comparison
用左右对照显式比较“股骨近乎垂直”与“股骨向内倾斜”两种状态。两侧保持同一骨盆宽度、腿长与落脚点规则；贯穿髋—膝—足的力线、身体中线和重心投影同步更新，让差异只来自股骨角度。

## 表征形式
交互式三维骨骼力线示意。显示半透明骨盆、双侧股骨、膝与胫骨；正面视角为默认，允许小幅旋转确认空间关系。地面投影标出支撑脚与重心，动画以慢速单腿支撑循环呈现左右位移。

## 四行 × 两列
| 比较维度 | 近乎垂直 / 向内倾斜 |
|---|---|
| 膝的位置 | 更偏身体外侧 / 更靠近身体中线 |
| 支撑脚位置 | 需更向外接住身体 / 可更接近中线 |
| 重心投影 | 离支撑点较远 / 更接近支撑点 |
| 躯干路径 | 左右摆动较大 / 左右摆动较小 |

不需页面数值常量；角度状态、骨架尺寸与动画进度均由页面组件状态驱动，不写死教学数值。若资产库提供人体比例，读取对应 `Lec.K`；显示取整用 `Lec.P.roundTo`。

## 必须点出来的一句
股骨向内倾斜，使膝部靠近身体中线；单腿支撑时，重心不必靠大幅左右摆动才能移到支撑脚上方。

## 交互（只有这一个）
学习者切换“近乎垂直 / 向内倾斜”，也可拖动同一角度控制柄。骨骼、髋膝力线、支撑脚位置和重心轨迹即时联动；切换后自动播放一次同速步行对照。目标直觉是：角度改变的是膝与支撑线的几何关系，而不是把膝当作独立零件。

## 不许碰
不出现足弓、趾骨、大趾或足部推进机制；足仅画成无结构支撑块。不得延伸到肌肉力矩、能耗计算、分娩权衡或“单一结构决定双足行走”。不把任一角度称为绝对最佳，也不把示意力线冒充真实受力测量。
