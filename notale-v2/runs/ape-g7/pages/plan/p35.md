# page-35 · 一直下落，始终错过 · **130 秒**

Kicker：`ORBIT / FALLING`

## 知识结构：comparison
把“普通掷球”与“进入轨道”对齐比较：两者都受重力、都持续向地球下落；差别是前向位移是否快到让弯曲地面不断避开。画面保留两条同起点轨迹，并以指向地心的重力箭头显式呈现共同机制。

## 表征形式
交互式三维地球与切线发射场景。球的轨迹实时延伸，地球可缓慢自转但不可由学习者旋转，避免操作焦点偏离“掷球”。

## 四行 × 两列
| 比较维度 | 普通掷球 / 进入轨道 |
|---|---|
| 初始方向 | 都沿地表切线向前 |
| 重力 | 都持续拉向地心 |
| 地面关系 | 很快相交 / 曲面持续避开 |
| 结果 | 落地 / 绕行仍在下落 |

调用 `Lec.K`：地球平均半径、地球质量、近地轨道典型高度。调用 `Lec.P`：`orbitRadiusFromAltitude`、`circularOrbitVelocity`、`roundTo`。页面脚本不得另设地球或轨道常量。

## 必须点出来的一句
轨道不是重力被关闭，而是物体一边下落，一边快到持续错过地面。

## 交互（只有这一个）
学习者从地球边缘拖拽球确定切向“掷出”力度并释放；弱掷迅速撞地，达到目标区间时轨迹绕地球延续，成功条件为完成一圈。每次保留上一条轨迹作比较，并显示“仍受重力”反馈；提供重置。目标是从失败与成功轨迹中形成“轨道＝持续下落”的直觉，而不是记住速度数值。

## 不许碰
不出现逃逸速度、脱离地球或开放轨迹；不比较不同天体；不系统讲过慢、合适、过快对应的轨道变化，不展示更高轨道——这些分别留给 p38 与 p36。忽略大气阻力需标注为教学近似。
