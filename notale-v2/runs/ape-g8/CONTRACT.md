# 页面构建契约

本契约适用于全套 44 页。每页 agent 必须逐条执行；没有自由发挥的条款不得改写、替代或绕过。

## 1. 工作边界

- 只创建或修改分配给你的 `page-NN.html`。
- 不读取、搜索、比较或复制任何其他 `page-*.html`。
- 只可读取 `PLAN.md`、`CONTRACT.md`、`assets/theme.css`、`assets/lec.js`、`assets/CHASSIS.md`、`assets/lib/LIBS.md`，以及任务对应的 Skill 技法文档。
- 不修改共享文件，不新增资源、文档或测试，不下载依赖。
- 页面必须自包含；直接以 `file://` 打开即可显示并交互。所有资源使用相对路径，禁止 CDN、网络请求和外部字体。
- 只向 `#stage` 添加本页内容。页眉、页脚由 `Lec.mount()` 生成，外观和占位由 `theme.css` 负责。
- 不重复创建页眉或页脚，不改 `.lec-header`、`.lec-header-inner`、`.lec-act`、`.lec-title`、`.lec-subtitle`、`.lec-progress`、`.lec-footer`、`.lec-footer-inner`、`.lec-footnote` 的名称、结构或样式。
- 底盘接口只读 `assets/CHASSIS.md`，不得在页面或本契约的执行产物中另抄一份。

## 2. 固定骨架

使用下列骨架。只替换 `NN`、标题信息和 `#stage` 正文；按需加入本地库的 `<link>` 或 `<script>`，不得删除、改序或替换已有底盘与主题引用。

    <!doctype html>
    <html lang="zh">
    <head>
      <meta charset="utf-8">
      <link rel="stylesheet" href="assets/base.css">
      <link rel="stylesheet" href="assets/theme.css">
      <!-- 仅按需加入库的 CSS -->
    </head>
    <body data-page="NN" data-total="44">
      <div id="stage">
        <!-- 仅此处加入本页结构与样式 -->
      </div>
      <script src="assets/base.js"></script>
      <script src="assets/lec.js"></script>
      <!-- 仅按需加入库的 JS；依赖在前，页面代码在后 -->
      <script>
        Lec.mount({
          index: NN,
          kicker: "按 PLAN.md 填写",
          title: "按 PLAN.md 填写",
          take: "按 PLAN.md 填写"
        });
        // 本页代码
      </script>
    </body>
    </html>

`#stage` 的可用高度是 900px 减去主题中页眉、页脚的占位高度；实际值读取 `theme.css`，不得猜测或覆盖。

## 3. 受众与文字

- 读者是大学一年级通识课学生，文理背景混合；不得假定学过微积分、生物学或本专业术语。
- 首次出现的术语必须就地用普通话解释；不得用另一个未解释术语充当定义。
- 公式中的每个符号首次出现时标明含义；有量纲的数值必须带单位。
- 正文单句不超过 40 个汉字；一句只承担一个判断或动作。
- 正文总量不超过 320 个汉字，不含页眉页脚、刻度、单位和按钮短标签。
- 语言用于教师带讲，也必须支持学生独立重看：核心问题、操作后的变化和结论必须留在页面上，不能只靠口头补充。
- 提示语使用直接、平静的动作口吻，如“拖动并比较”“切换后观察”；不用考试口吻、卖关子、拟人化或幼儿化表达。
- 不以“显然”“容易知道”“大家都学过”跳过推理。
- 交互不能成为理解结论的唯一入口；初始状态必须呈现问题和基本含义。

## 4. 版面预算

画布逻辑尺寸固定为 `1600 × 900`。

- 正文：最多 320 个汉字。
- 可操作控件：最多 6 个。一个按钮、滑块、输入框、选择器、开关或可拖拽物各计 1 个。
- 页面文本块：20–70 个，含标题之外的正文、刻度、图例、图注、标签、控件文字、单位和读数；DOM 中独立呈现的一块文字计 1 个。
- 画面占用比必须 `≥45%`。
- 文本块超过 70、控件超过 6 或正文超过 320 字时，必须删减或拆页，并明确判定“超预算”；禁止缩字号、压行高、挤间距或叠放元素。
- 文本块少于 20 或占用比低于 45% 时，应展开真实过程、增加一个有教学意义的维度或调整页级规划；禁止用装饰、空卡片、大字号或虚增间距撑占用。
- 默认使用 flex。只有矩阵、维度表等确需二维对齐时才使用 grid。
- 需要计算坐标才能对齐时必须改结构。拖拽使用 `transform` 保留正常流位置，不通过持续改 `left/top` 排版。
- 禁止在缩放画布内使用 `position: fixed`；需要锚定时用相对内容容器的 `position: absolute`。
- 禁止卡片套卡片，禁止无教学信息的装饰容器。

## 5. 字号与主题

以下均为 1600×900 逻辑画布中的 CSS 计算字号：

- 纯数字刻度：`≥12px`。
- 带词句的刻度、标签、图例、图注、单位、按钮文字：`≥14px`。
- 正文、提示、读数和 tooltip：`≥16px`。
- KaTeX 基准字号：统一 `≥20px`。
- 所有文字行高：`≥1.35`。
- 禁止通过 `transform: scale()`、`zoom` 或 canvas 内缩放文字绕过字号下限。

1366×768 屏的舞台缩放系数约为 `min(1366/1600, 768/900)=0.853`。因此逻辑字号在常见课堂屏幕上还会缩至约 85%；不得再降低上述地板。

- 所有颜色、字体、阴影、圆角、边框和间距优先使用 `theme.css` 已有变量与类。
- 不自创整套色板、字体系统、页眉页脚或通用组件风格。
- 不覆盖底盘或主题类的定位属性。
- 不得通过 `classList.remove()` 删除 `lec-root`、`lec-page`、`min0`、`cv-fill` 或其他由 `base.css`、`theme.css` 提供的类。

## 6. 数字与计算

- 页面呈现的教学数字、读数、比例、物理量和计算结论必须由 `Lec.P` 对应函数实时得到，不得把结果写死在 HTML、CSS、标签或动画关键帧中。
- 页码、标题和摘要通过 `Lec.mount()` 设置。
- 计算输入只能来自 `PLAN.md`、用户控件或明确的数据集；显示值必须由同一份状态计算，不能另写一份近似文本。
- 不用预录动画、假数据或固定答案冒充计算。
- 随机样本、抽样、初始化点和随机动画必须引用 `seedrandom.min.js` 并使用固定种子；同一页面每次打开结果一致。
- 交互允许的所有状态下，页面陈述都必须成立。不能只验证初始状态。

## 7. 库与技法

动手前先按任务读取对应 Skill 技法文档，并查 `assets/lib/LIBS.md`。已有库能完成的呈现工作，禁止从底层重写：

| 呈现工作 | 必用库 |
|---|---|
| 坐标轴、刻度、图例、折线、柱、散点、面积、饼、热力图 | ECharts |
| 可拖拽、需命中检测的二维形状与分组 | Konva |
| 三维场景、结构、光照与材质 | Three.js |
| 三维地球、球面点线区块 | Three.js + globe.gl |
| 下落、碰撞、摆动、堆叠、约束 | Matter.js |
| 节点连线、数据绑定的矢量图形 | D3 |
| 成千上万元素同时运动 | PixiJS |
| 分步、路径、形变动画 | anime.js |
| 多动画时间线 | GSAP |
| 滚动绑定动画 | GSAP + ScrollTrigger |
| 矢量动画文件 | lottie-web |
| 伪三维插画 | Zdog |
| 指针倾斜 | vanilla-tilt |
| 进入视野淡入 | AOS |
| 数学公式 | KaTeX |
| 矩阵运算 | ml-matrix |
| 页面内实时训练小型二分类网络 | mlp.js |
| 预训练模型、真实图片卷积或 GPU 大矩阵 | TensorFlow.js |

- 库直接以 `<script src="assets/lib/xxx.js"></script>` 引用；KaTeX 同时引用 `assets/lib/katex.min.css`。
- 依赖必须在使用者之前加载：Three.js 在 globe.gl、Vanta 之前；GSAP 在 ScrollTrigger 之前；所有库在本页初始化代码之前。
- 版本只看 `assets/lib/LIBS.md`，不得扫描压缩文件猜版本。
- ECharts 必须使用 `echarts.init(el, null, {renderer:'svg'})`，并显式设置全局、坐标轴、图例和 tooltip 字号满足本契约。
- Konva 用于图形；普通标签使用绝对定位的 DOM 文字。必须使用 `Konva.Text` 时显式设置合规字号。
- KaTeX 使用本地 CSS 和 JS，`throwOnError:false`，基准字号不低于 20px。
- TensorFlow.js 的循环步骤必须用 `tf.tidy()` 或显式 `dispose()`；用 `tf.memory().numTensors` 验证张量数不持续增长。
- 库负责呈现不等于伪造计算；交互背后的训练、积分、计数和物理量必须真实计算。

## 8. Canvas、动画与输入

- 所有 canvas 尺寸适配必须使用 `Deck.fit` 或 `Deck.autofit`。
- 所有手写 canvas 指针坐标必须使用 `Deck.pt`。
- 所有逐帧动画必须使用 `Deck.loop`。
- canvas 取主题色必须使用 `Deck.rgb` 或 `Deck.rgba`。
- 禁止自行实现 `devicePixelRatio` 缩放、`getBoundingClientRect()` 坐标换算或 `requestAnimationFrame` 循环。
- Konva 使用其自身正确换算后的 `stage.getPointerPosition()`，不再叠加手写换算。
- resize 或舞台缩放后，绘图、命中区域、指针位置和 DOM 覆盖标签必须仍对齐。
- 必须处理 `prefers-reduced-motion: reduce`：停止自动循环和非必要过渡，直接显示稳定且可理解的状态；交互反馈仍可用。
- 所有点击、拖拽、滑块和切换操作必须可通过键盘完成。原生控件优先；自定义控件必须可聚焦，提供正确 role、名称、方向键/Enter/Space 行为及可见焦点。
- 不得把教学必要文字只画在 canvas 中；标签和读数优先使用 DOM。

## 9. 交互标准

真交互必须同时满足：

- 用户能通过点击、拖动、键盘、滑块或选择器改变模型输入或状态。
- 画面根据该状态实时重新计算，而非只播放预录序列。
- 至少一个可见结果、比较关系或因果反馈随操作改变。
- 控件状态、画面状态和文字读数来自同一数据源。
- 重置后回到确定的初始状态。

仅自动播放、悬停发光、视差、淡入、倾斜、粒子背景、按钮触发固定动画，均属装饰，不计为交互。装饰不得占用控件预算、遮挡内容或承担教学结论。

## 10. 完工自检

在 `pages/` 目录运行：

    python3 assets/selfcheck.py page-NN.html

对每个可操作控件和关键组合状态，再运行：

    python3 assets/selfcheck.py page-NN.html --after "<触发该状态的 JS>"

可重复添加 `--after` 覆盖初始态、边界值、拖拽后、重置后和动画运行后状态。

交付判据：

- JS 报错为 0。
- 资源加载失败为 0。
- 超出画布、被裁、文字叠压为 0。
- 占比不足 1% 的无意义小容器为 0。
- 画面占用比 `≥45%`。
- 文本块为 20–70 个。
- 正文、控件和文本总量不超预算。
- 最小字号及中位数报告符合各档地板。
- 初始态与所有关键交互态均满足以上条件。
- 1366×768 下无错位、遮挡、溢出，指针命中与视觉位置一致。
- reduced-motion 和纯键盘路径可完成核心操作。
- ECharts 文字可在 DOM 中检查；canvas/Konva 中不存在未核验的小字。
- 随机结果可复现；计算读数与文字结论一致。

任何一项不满足都必须修改 `page-NN.html` 后重跑，直到全部干净。
