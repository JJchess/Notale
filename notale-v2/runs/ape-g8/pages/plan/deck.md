# 《Apeman – Spaceman》90 分钟互动讲义 · 总规划

## 0. 这套讲义的主线

人类从猿类祖先走到太空，并不是沿着一条越来越高级的阶梯前进，而是在身体、工具、社会和环境之间不断把限制转移给下一层系统。

分章表：

| 章 | 页 | 这一章要让读者信什么 |
|---|---:|---|
| I. 先拆掉“进化阶梯” | 01–02 | 人类不是从“低等猿”直线升级而来，问题要从证据开始 |
| II. 身体先改变 | 03–10 | 直立行走是环境与身体共同塑造的解决方案，不是“突然变聪明” |
| III. 手、工具与大脑 | 11–18 | 人类能力来自身体、工具和学习的共同演化 |
| IV. 把能力传下去 | 19–27 | 单个人无法完成的人类能力，依靠社会学习与累积文化实现 |
| V. 从自然适应到人工环境 | 28–36 | 太空把人体的限制显性化，航天器是一个替身体承担环境适应的系统 |
| VI. Spaceman 仍然是 Apeman | 37–44 | 进入太空没有让人类脱离生物学，反而要求我们更准确地理解依赖关系 |

证据链：

E1  人类演化不是一条从猿到人的直线，而是有分叉、共存和消失的谱系

E2  直立行走比大脑显著膨大更早出现，身体姿态先改变了人与环境的关系

E3  双手、工具、食物加工和大脑之间形成了相互强化的反馈，但没有单一的“关键发明”

E4  语言、模仿、合作和累积文化，让群体能够继承单个人一生学不完的能力

E5  太空环境没有改变人类的生物本性，只是把重力、压力、辐射和资源循环这些限制集中暴露出来

## 3. 数字口径

- Laetoli 脚印年代统一写作 `3.66 Ma`，页面显示为“约 366 万年前”；不写成“现代人的脚印”。
- Homo sapiens 的出现统一写作“约 30 万年前”。
- Oldowan 石器的最早证据统一写作“约 260 万年前”。
- Homo erectus 的早期记录统一写作“约 190 万年前”。
- 农业出现统一写作“约 1.2 万年前”；不把它作为人类文化的起点。
- 地球标准重力统一取 `9.81 m/s²`。
- 月球重力统一取地球的 `0.165` 倍；火星重力统一取地球的 `0.378` 倍。
- 月球表面逃逸速度统一取 `2.38 km/s`，火星统一取 `5.03 km/s`，地球统一取 `11.2 km/s`。
- 国际空间站近地轨道高度统一取 `400 km`，轨道周期统一取 `90 min`。
- 地月平均距离统一取 `384,400 km`，光传播时间约 `1.28 s`。
- 日地平均距离统一取 `1 AU`，光传播时间约 `8 min 20 s`。
- 航天器舱内压力示例统一取 `101.3 kPa`；低压风险只用于说明系统约束，不做医学诊断。
- 人体氧气消耗示例只使用相对值或每分钟体积，不把示例值当作所有人的生理常数。
- 质量单位统一使用 `kg`；重量单位统一使用 `N`；禁止把“体重”与“质量”混用。
- 速度统一使用 `m/s`，需要日常直觉时再转换为 `km/h`。
- 时间内部计算统一使用秒；页面标题、读数和讲义注释可按需显示分钟、小时或天。
- 距离内部计算统一使用米；页面显示可按尺度转换为 `km`、`AU` 或光年。
- 面积、体积和资源容量必须分别使用 `m²`、`m³` 和 `L`，不得用“大小”代替。
- 轨道速度、轨道周期、自由落体距离、自由落体速度、重量、能量、压力、通信延迟统一从 `Lec.P` 调用。
- 所有随机抽样、随机点集和随机故障情境统一使用 `Math.seedrandom`，每页单独设置固定种子。
- 所有常规图表必须使用 `echarts.init(el, null, { renderer: 'svg' })`。
- 所有 ECharts 全局正文文字使用 `16px`；带词句的轴标签、图例和轴名使用至少 `14px`；纯数字刻度可使用 `12px`。
- 所有 KaTeX 公式统一引入 `assets/lib/katex.min.css` 和 `assets/lib/katex.min.js`；含分式和下标的公式基准字号至少 `20px`。
- 所有 Konva 场景只用 Konva 绘制图形；场景文字标签使用 DOM 绝对定位叠加，避免使用默认 `12px` 的 `Konva.Text`。
- 页面脚本从 `pages/` 相对引用 `assets/lib/xxx.js` 和 `assets/lec.js`；不使用 CDN。
- 交互必须在页面内实时计算状态；不使用预录动画伪装成模拟。
- 每页只保留页表中指定的一个交互入口；同一交互名称、同一目标机制和同一套控制逻辑不得跨页复用。
