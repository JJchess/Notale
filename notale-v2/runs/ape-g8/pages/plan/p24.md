# page-24 · 把做法留在环境里 · **140 秒**

`SHORT-CAPS`：CULTURE / REUSE

主标题：不只记住一次，而是让群体再次调用

## 知识结构：generalization

用“具体任务 → 外化操作板 → 可重复调用”的前后态显式化概括。上半屏是六张尚未组织的规则卡；下半屏是三个连续槽位，每个槽位固定显示“角色 / 工具 / 规则”。卡片全部归位后，具体文字淡出为通式：`谁负责 + 借助什么 + 在什么条件下怎么做 → 群体可重复调用`。

## 表征形式

交互式规则卡片排序。读者先把零散口头约定整理成可执行顺序，再看到它们被压缩成跨任务适用的通式。心理表征不是“记住六条规定”，而是认识外化结构如何让任务脱离某个人的即时记忆。

## 三条支撑

- 角色外化：把“谁来做”固定为可辨认的位置，换人后职责仍可接续。
- 工具外化：样板、标记与工具架保留动作标准，不必每次从头示范。
- 规则外化：用“当……就……”连接条件与动作，使群体在相同情形下重复响应。

页面不使用数值，不调用 `Lec.K` 或 `Lec.P`。

## 必须点出来的一到三句

规则、工具和角色一旦被放到脑外，群体就能反复调用同一种做法。被保存的不是某个人，而是一套可重新执行的关系。

## 交互（只有这一个）

读者拖动六张规则卡，为“共同制作并交接石片工具”排出两个连续回合；每个回合必须同时对齐角色、工具和条件动作。归位后，卡面中的具体称谓收束为同一套抽象结构，让读者形成“外化使做法可复用”的直觉。

做对了立刻看到什么：卡片吸附入槽，青绿描边点亮，角色、工具与规则之间的细线接通。

做错了立刻看到什么：卡片短促横向抖动并回弹；提示明确写“这条规则缺少对应角色”或“先放置它所引用的工具”。

做到哪儿了怎么知道：操作板右上持续显示“已就位 3 / 6”，空槽保留清晰轮廓。

做完了怎么收：六卡全部就位后，琥珀色连线贯通两个回合，具体卡面折叠成通式，出现“可再次调用”；右下提供单一重置图标，可恢复乱序重来。

## 场景构图

使用“手、石器与工具接口”和“环绕身体的环境参数刻度”母题。深炭黑背景像一张横向工作台：上半屏散放带磨损边缘的规则卡，旁边露出石片、样板和角色标记的扁平技术轮廓；下半屏是一条青绿色装配轨，六个槽位沿读取方向排列。完成时，轨道从具体工作台延伸为跨越两个回合的连续调用线。上下分屏保持同宽，主交互始终完整落在首屏。

## 动效

入场：工作台测量线先由左向右绘出，六张卡随后从上缘依次落入待排区，下方空槽最后显现。

反馈：正确卡吸附时轻微压下再回正，连线沿目标方向点亮；错误卡抖动后沿原拖动路径回弹，不改变其他卡位。

## 不许碰

不展开制度、法律、组织或国家的历史；不把规则外化解释为制度起源。不得重复 p20 的代际复制误差，也不得提前转入 p25 的个人记忆负荷对照。石片任务只作为排序载体，不新增石器技术知识。
