# page-36 · 把环境装进系统 · **50 秒**

Kicker：`ACT IV · SYSTEMS`

主标题：航天器把环境变成了一组必须持续管理的条件

## 知识结构：enumeration

用四条平行的“环境条件 → 管理方式 → 系统代价”横向链，把 p30–35 的内容收束为同一关系。四条严格对齐，不排优先级，也不画成先后流程；左侧共同指向人体边界，右侧共同汇入航天器系统。

## 表征形式

静态技术剖面信息图。左栏是被舱壁包围的人体轮廓与四条条件链，右栏是航天器剖面及对应管路、屏蔽层、散热面和通信链路。读者一眼看到：舱内的“正常环境”不是背景，而是系统持续工作的结果。

## 并列的各项

- 空气与压力 → 检测、供给、密封 → 质量、能量、维护
- 温度与废热 → 测量、输运、散热 → 功耗、散热面积、设备负担
- 辐射暴露 → 监测、屏蔽、缩短暴露 → 质量、任务约束
- 资源与信息 → 储存、循环、延迟决策 → 容量、损失、时间代价

## 收束主张

航天器没有消除人体对环境的依赖，而是把空气、温度、辐射、资源和信息条件变成可测量、可管理的系统。

每一种管理都要用质量、能量、时间或维护来付账。

## 场景构图

使用“从骨盆到轨道舱的连续轮廓线”“环绕身体的环境参数刻度”“地球弧线与生命支持管路”三条母题。左侧人体站在近黑舱体剖面内，青绿色参数刻度沿身体外缘竖排；四条细测量线越过中轴接入右侧航天器剖面。右侧管路、屏蔽层、散热面与通信天线各自接住一行，末端以琥珀黄小标记显示“质量 / 能量 / 时间 / 维护”。底部仅露出一段地球弧线，表明这些条件原本由地球环境隐性提供。
