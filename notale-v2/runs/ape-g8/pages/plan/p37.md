# page-37 · 身体没有随任务升级 · **144 秒**

**Kicker：** LIMIT → SUPPORT  
**主标题：** 每一种太空能力，都有支撑它的工程系统

## 知识结构：classification
把“太空能力”拆成三层对齐分类：身体限制 → 必须维持的条件 → 工程补偿。六组卡片归入“交换、保护、行动”三条主干；完成后的贯通连线明确能力来自整组关系，而非单件装备。

## 表征形式
交互式配对分类台。限制卡固定在人体轮廓周围，读者把工程补偿卡拖入对应空位；中间条件在正确配对后揭示，避免把任务做成术语对术语的死记。

## 层级里的各项
- 交换：持续呼吸 → 气体成分与压力 → 密闭加压、供氧与二氧化碳去除
- 交换：摄入并排出 → 水、食物与废物通路 → 储存、处理与回收系统
- 保护：体温调节范围有限 → 可控热交换 → 隔热、加热与散热系统
- 保护：组织会累积辐射损伤 → 降低暴露剂量 → 屏蔽、监测与任务时长控制
- 行动：失重下身体与物体不会自行定位 → 稳定支点 → 扶手、脚扣与约束装置
- 行动：缺少持续承重刺激 → 维持肌肉与骨骼负荷 → 阻力训练与运动设备

本页不显示计算读数，不调用 `Lec.K` 常量或 `Lec.P` 函数。

## 必须点出来的一到三句
宇航员能呼吸、工作和长期停留，不是因为身体摆脱了限制，而是工程系统持续补上这些限制。每一种“太空能力”，都能沿着身体限制追溯到它依赖的环境条件和支撑系统。

## 交互（只有这一个）
读者拖动六张工程补偿卡，与身体限制配对；正确后揭示中间条件并接通整条关系，从中形成“能力是身体与工程共同产物”的直觉。

做对了立刻看到什么：卡片吸附归位，琥珀描边转为青绿，限制、条件、补偿之间的管线依次点亮。  
做错了立刻看到什么：卡片短促横向抖动并回到托盘；提示明确指出错位原因，如“屏蔽降低辐射暴露，不能提供稳定支点”。  
做到哪儿了怎么知道：顶部显示六段式系统回路，已接通段数同步填亮，并标出“已完成 3 / 6”。  
做完了怎么收：六条管线汇入轨道舱轮廓，主张浮现；保留“重置”按钮，一键断开连线并洗回原始卡位。

## 场景构图
采用“从骨盆到轨道舱的连续轮廓线”“环绕身体的环境参数刻度”“生命支持管路”。中央是站立人体线稿，外圈切入轨道舱剖面；限制卡贴近对应身体区域，补偿卡列在舱壁模块架，三条分类主干像管路跨过二者。深炭黑舱内底色，青绿表示已建立的支撑，琥珀只标当前拖动目标。

## 动效
入场：人体轮廓先自下而上描出，舱体轮廓随后由两侧闭合，六张补偿卡沿舱壁依次滑入模块架。  
反馈：正确时能量脉冲沿连线从工程模块流向身体；错误时仅卡片与目标位抖动，背景和已完成关系保持静止。

## 不许碰
不讨论基因改造、植入物、赛博格、寿命延长或“改造人是否更优”等人体增强伦理；也不把任何补偿描述为彻底消除生理风险。伦理问题留到 p41，本页只分类现有人体限制与工程支撑。
