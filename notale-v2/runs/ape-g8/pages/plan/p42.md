# page-42 · 依赖没有消失 · **55 秒**

**Kicker：** SYNTHESIS  
**主标题：** Spaceman 把 Apeman 的依赖带进了太空

## 知识结构：generalization
用一张纵向总账把全套主线压缩为四条支撑。每行固定为“原有边界 → 转交给什么 → 仍依赖什么”，四行汇入底部同一条结论。E1 作为总账上方的前提：“这不是升级阶梯”；E2–E5 分别支撑身体、工具、文化与工程系统的连续扩展。

## 表征形式
静态 ledger。四行沿同一测量线严格对齐，读者可从上到下扫读，也可横向追踪“限制如何被转移”。不使用图表、照片或定量读数。

## 四条支撑
- 身体：直立改变了人与环境的接口 → 仍受身体结构与环境约束。
- 工具：动作被放大、固定并外置 → 仍需手、感知和学习来调用。
- 文化：技能越过个人寿命被群体保存 → 仍需模仿、合作、符号与纠正。
- 航天器：压力、氧气、温度、资源循环等条件被工程系统接管 → 人体依赖没有消失，只是延伸到更长的维护链。

底部结余栏只放总判断：“能力扩大，不等于依赖减少。”本页不出现数值，不调用 `Lec.K` 或 `Lec.P`。

## 收束主张
Spaceman 不是离开 Apeman，而是把 Apeman 的依赖关系扩展到工程系统。  
进入太空改变的是人与环境之间的接口，不是人的生物出身。
