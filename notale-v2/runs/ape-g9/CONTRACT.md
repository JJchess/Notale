# 页面构建契约

## 1. 文件边界

- 只修改分配给你的 `pages/page-NN.html`。
- 不创建、修改或删除其他文件；不写文档、测试、资源文件或总结。
- 绝不读取、搜索、比较、复制任何其他 `page-*.html`。
- 只读取任务提供的 `PLAN.md`、本契约、`assets/theme.css`、`assets/lec.js`，以及本契约明确指向的文档。
- 底盘接口只读 `assets/CHASSIS.md`，不得把其内容抄入页面或其他文件。
- 页面必须自包含；以 `file://` 直接打开即可显示和交互。所有资源使用 `pages/` 下的相对路径，禁止 CDN、网络请求和远程字体。

## 2. 固定骨架

现有骨架不得删除、改名、换序或重建。只在允许位置加入本页内容、必要的本地库和本页脚本：

    <!doctype html>
    <html lang="zh">
    <head>
      <meta charset="utf-8">
      <link rel="stylesheet" href="assets/base.css">
      <link rel="stylesheet" href="assets/theme.css">
    </head>
    <body data-page="NN" data-total="52">
      <div id="stage"></div>
      <script src="assets/base.js"></script>
      <script src="assets/lec.js"></script>
    </body>
    </html>

- 只改 `NN`、本页标题信息和本页正文；总页数固定为 `52`。
- 页面内容只能加入 `#stage`。不得在 `body` 其他位置建立页面内容。
- 必须调用 `Lec.mount({index, kicker, title, take})`；四项内容按 `PLAN.md`，`index` 与 `data-page` 一致。
- 页眉、页脚及 `#main` 由 `Lec.mount()` 生成，不得手写、复制、改名或再次生成。
- `theme.css` 负责页眉页脚的外观和占位。内容区高度是 `#stage` 扣除这两条带后的剩余空间；具体高度读 `theme.css`。
- 不得覆盖 `.lec-stage`、`.lec-main`、`.lec-header`、`.lec-footer` 及其子类的定位、高度、间距和外观。
- 不得删除或覆盖底盘、主题提供的结构类及定位属性，包括 `lec-root`、`lec-page`、`min0`、`cv-fill`。
- 缩放舞台内禁止 `position: fixed`；需要锚定时使用相对内容容器的 `position: absolute`。
- 默认使用 flex。只有矩阵、维度表等确需二维对齐时才用 grid。
- 需要计算坐标才能排齐的布局必须改结构：拖拽用 `transform`，不改 `left/top`；刻度、滑块分区排布，不用绝对定位凑齐。

## 3. 受众与文字

- 受众是文理兼有的大学一年级学生；不假定微积分、生物学或专业术语基础。
- 页面用于教师带讲，也必须支持学生课后独立重看。
- 首次出现的必要术语必须就地用一句话解释；不得用未解释术语定义另一个术语。
- 先写可观察的现象或问题，再给概念、关系或结论。不得从公式、缩写或学科黑话起笔。
- 正文使用短句；单句不超过 35 个汉字，连续说明不超过 3 句。
- 提示语直接说明动作及观察目标，如“拖动后观察……”“比较两侧……”。禁止卖萌、营销、考试训话和含糊的“试试看”。
- 不把教师口头讲解必需的信息藏在 hover 中；关键结论必须常显。
- 交互反馈必须让学生无需教师补充即可判断“改了什么、结果如何、为什么值得看”。
- 每页正文为 80–260 个汉字，指标题、说明句和结论，不含刻度、图例、按钮及数值。超过 260 字必须拆页或报告超限，禁止缩字硬塞。
- 页面文本块总数必须为 20–70 个，包含标题、正文、刻度、图例、标签、控件文字、读数和 tooltip。超出区间即不合格。
- 可操作控件最多 5 个；同一组单选项按每个可操作项计数。超过 5 个必须删减步骤或拆页。
- 画面占用比必须 ≥45%。低于 45% 时增加有教学作用的结构、维度或过程，不得靠放大字号、增加装饰或拉大空隙撑满。
- 内容过满时拆页；不得降低字号、压行高、遮挡、裁切或把文字画进 canvas 逃避检查。

## 4. 字号与排版

以下均指 1600×900 逻辑画布中的 CSS 字号：

- 纯数字刻度及极短刻度：≥12px。
- 标签、图例、图注、轴名、带词句的刻度：≥14px。
- 正文、提示、按钮文字、读数说明、tooltip：≥16px。
- KaTeX 基准字号：≥20px。
- 所有正文行高：≥1.35。
- 禁止通过 `transform: scale()`、`zoom`、SVG 缩放或 canvas 文字绕过字号下限。
- 1366×768 屏幕的舞台缩放约为 `min(1366/1600, 768/900) ≈ 0.85`；上述逻辑字号缩放后已接近可读下限，不得再压缩。
- 文本必须在容器内完整显示，不得与其他文本、控件或图形非预期重叠。

## 5. 主题与数值

- 颜色、字体、字号层级、线宽、圆角、阴影和间距必须取自 `theme.css` 的既有类或变量。
- 禁止自创配色、字体体系、页眉页脚样式或另一套设计令牌。
- 页面局部 CSS只允许完成本页结构、尺寸和状态，不得覆盖主题全局选择器。
- 所有可见的科学量、换算值、比例、百分比、时间、距离、速度、能量及派生结果必须由 `Lec.P` 计算并写入 DOM，不得在 HTML 或展示字符串中写死答案。
- 已知输入可作为有名称的源数据存在，但不得同时硬编码其计算结果；格式化使用 `Lec.P.roundTo` 或 `Lec.P.significant`。
- `Lec.P` 已提供的运算禁止重新实现。确无对应接口时可本地真实计算，但结果仍须运行时生成，不得用假数据、预录结果或固定动画冒充。
- 页码、总页数、CSS尺寸、数组索引和算法控制参数不属于教学数值。

## 6. 库与技法

动手前先按任务类型阅读 `assets/lib/LIBS.md`。已有库能完成的呈现工作，禁止从底层重写：

- 常规坐标轴、刻度、图例、折线、柱状、散点、面积、饼、热力图：`echarts`
- 可拖拽、需命中检测的二维场景：`konva`
- 三维场景：`three`
- 下落、碰撞、摆动、堆叠、约束：`matter`
- 节点连线、数据驱动矢量图：`d3`
- 成千上万元素同时运动：`pixi`
- 多动画时间线：`gsap`
- 数学公式：`katex`
- 矩阵运算：`ml-matrix`
- 页面实时训练小型二分类网络：`mlp.js`
- 预训练模型、真实图片卷积或 GPU 大矩阵：`tf.js`

- 库直接以 `<script src="assets/lib/xxx.js"></script>` 引入；KaTeX同时引入 `assets/lib/katex.min.css`。
- 依赖库先于扩展库：`three` 先于 `globe.gl`、`vanta`；`gsap` 先于 `ScrollTrigger`。库先于本页初始化脚本，`base.js` 先于 `lec.js`。
- 版本和 API 只按 `assets/lib/LIBS.md`；禁止检查压缩库文件中的版本。
- ECharts 必须 `echarts.init(el, null, {renderer:'svg'})`，并显式设置全局文字 ≥16px、纯数字刻度 ≥12px、轴名/图例/带词刻度 ≥14px、tooltip ≥16px。
- Konva 用于图形；普通文字使用绝对定位的 DOM 覆盖层。只有必须随图形变换的短标注可用 `Konva.Text`，且须显式满足字号下限。
- 随机数据必须引入 `seedrandom` 并使用固定、含页号的种子；禁止 `Math.random()`。
- 使用 TensorFlow.js 时每一步必须置于 `tf.tidy()` 或显式 `dispose()`，并确认 `tf.memory().numTensors` 不持续增长。
- 清单中存在对应技法文档时，必须先用 `Skill` 读取再实现；没有对应文档才自行实现。

## 7. Canvas、缩放与动画

- Canvas 一律用 `Deck.fit` 或 `Deck.autofit` 适配逻辑尺寸、高分屏及舞台缩放。
- 指针坐标一律用 `Deck.pt`；禁止自行用 `getBoundingClientRect()`、视口坐标或缩放系数换算。
- 动画循环一律用 `Deck.loop`；禁止直接建立 `requestAnimationFrame` 循环。
- Canvas 颜色一律用 `Deck.rgb` 或 `Deck.rgba`；禁止在绘图代码中另写颜色值。
- 禁止自行设置 `devicePixelRatio`、手动放大 backing store 或重复实现 resize 适配。
- 使用 Konva 时采用其舞台指针坐标，不再叠加一次人工换算。
- 动画必须监听 `prefers-reduced-motion: reduce`。该分支停止连续运动和非必要过渡，直接呈现稳定终态；核心内容和操作反馈不得消失。
- 页面失焦、隐藏或内容不再需要更新时必须暂停循环；恢复后不得出现时间跳变。
- Canvas 内不得承担正文、刻度、图例或关键标签；必须使用 DOM 或可检查的 SVG。确需 canvas 内短字时显式满足字号下限，并另设可访问名称。

## 8. 交互标准

- 真交互必须由学生输入改变模型参数、数据、视角、状态或过程，并立即产生可观察、可解释的结果。
- 拖动、点击、键盘操作后必须重新计算真实结果；禁止只切换预制图片、播放固定动画或改变装饰颜色。
- 纯 hover 光效、倾斜、视差、自动播放、淡入和跟随指针的装饰不算交互。
- 每页只保留一个主要交互问题；控件必须服务于该问题。
- 使用原生 `button`、`input`、`select` 等控件。禁止用无语义 `div` 冒充按钮。
- 所有操作必须可用键盘完成：Tab 可达、焦点清晰、Enter/Space 可触发；连续值支持方向键，拖拽对象必须提供等价键盘操作。
- 控件必须有可访问名称、可见状态及边界值；不可用状态必须真实 `disabled`。
- 状态变化不得只靠颜色表达；同时使用文字、数值、形状或位置。
- 重置操作必须恢复固定初态；随机页面重置后仍产生同种子同序列。
- 允许扰动范围内，页面说明和结论必须始终为真。

## 9. 完工自检

在 `pages/` 目录运行：

    python3 assets/selfcheck.py page-NN.html

必须逐项达到：

- 无 JavaScript 错误。
- 无资源加载失败和外部请求。
- 无元素超出 1600×900 画布。
- 无元素被非预期裁切。
- 无文字叠压、遮挡或溢出。
- 字号全部满足分档下限，正文中位数不得靠近 16px 下限来挤版。
- 画面占用比 ≥45%。
- 文本块总数 20–70。
- 无占比不足 1% 且无教学作用的小容器。
- 页眉、页脚、标题、内容区不互相侵占。
- 1366×768 约 0.85 缩放下，指针命中、tooltip、拖拽和文字仍正确。
- 键盘可遍历并完成全部操作。
- reduced-motion 分支无连续非必要动画，内容完整。
- 随机结果可复现，重置一致。
- 交互后的读数、图形和结论一致。

对每个关键交互状态使用：

    python3 assets/selfcheck.py page-NN.html --after "<触发该状态的 JS>"

滑块两端、重置后、主要按钮触发后、拖拽或训练后的关键状态都必须检查。出现任何报告项就修改页面并重新运行；必须改到初态和所有关键交互状态均干净为止。

## 10. 交付

只交付 `page-NN.html`。不得修改其他文件，不得新增文档、测试、截图、依赖或总结。
