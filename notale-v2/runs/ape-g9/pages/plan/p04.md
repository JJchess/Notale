# page-04 · 时间尺上的航天史 · **125 秒**

## 照这个写
`Lec.mount({index:4,kicker:'SCALE CHECK',title:'把航天史放回人体演化史',take:'载人航天史在人体演化史上只占近乎看不见的一小段。'});`

`const scroll = ScrollTrigger.create({trigger:'#main',start:'top top',end:'+=125%',pin:true,scrub:0.35});`
`const x = yearsAgo => Lec.P.lerp(Lec.P.timelineFraction(yearsAgo,Lec.K.timelineOldestYearsAgo),Lec.P.logTimelineFraction(yearsAgo,Lec.K.timelineMinimumYearsAgo,Lec.K.timelineOldestYearsAgo),compression);`
D3 使用单个响应式 `svg`，`viewBox:'0 0 1440 900'`；轴标签 `14px`，事件标签 `16px`，关键读数 `28px` 等宽体。

## 知识结构：comparison
同一组事件上下对齐在两把尺上：上方等距时间尺保留真实跨度，航天史挤成右端一线；下方压缩时间尺逐渐展开近期区间。垂直连线保持事件身份不变，让学生比较“实际持续时间”与“为了看清而改变的显示尺度”，而不是把压缩误认成历史加速。

## 表征形式
动态交互时间尺。拖柄连续改变线性位置与对数位置的插值；所有事件只沿横轴移动，顺序、年代和跨度不变。主画面不另设说明卡。

## 必须点出来的一句
压缩时间尺能让航天史变得可见，却不能让它在人体演化史中变长：两者相差约五个数量级。

## 交互（只有这一个）
读者把“等距 → 数量级”拖柄向右移动，看到近期事件被展开、远古区间被压缩，由此形成“可见宽度不等于真实持续时间”的直觉。

做对了立刻看到什么：拖到“数量级”端后吸附定位，1961—2025 黄色区段展开并发光一次，两端年份标签同时出现。

做错了立刻看到什么：在航天史区段仍窄于可读阈值时松手，拖柄轻微回弹，显示“还看不见 1961—2025：继续向右压缩较久远年代。”

做到哪儿了怎么知道：轨道下方固定显示三格进度“等距 / 折中 / 数量级”，已越过的格变为青绿色，当前格为黄色。

做完了怎么收：上下两把尺同时保留，垂直连线接通对应事件，中央出现数量级读数；右下角出现仅含重置图标的按钮，可恢复等距状态重做。

## 场景构图
使用“不断分叉又汇合的青绿色时间线”和“黄色约束线”。深色全屏像一张横向展开的观测台：青绿色时间线从左侧远古刻痕穿过全屏，在右端汇入极细的黄色航天史区段；上下两把尺占据中央主要视野，拖柄嵌在底部轨道。远古标签疏朗，右端标签在压缩前拥挤成一道亮缝，完成后才可辨认。

## 动效
入场：标题淡入后，等距尺从左向右生长，事件刻线依年代依次亮起，镜头视觉焦点最后停在最右端细缝。

反馈：拖动时事件沿轴平滑重排、垂直对应线同步拉伸；成功时黄色区段脉冲一次，未达阈值时拖柄水平抖动后回弹。

## 不许碰
不展示任何脑容量数值、物种脑容量比较或“脑越大越先进”的暗示；不排列直立、工具和现代体形的出现顺序；不把演化画成朝宇航员上升的阶梯。对数压缩只改变显示尺度，不得表现为演化速度或目标方向。
