# page-49 · 类比的边界 · **110 秒**

## 照这个写
`Lec.mount({index: 49, kicker: "ANALOGY AUDIT", title: "地球不是一艘更大的飞船", take: "“地球飞船”能凸显相互依赖，但会遮蔽开放生态、权力差异与自然演化。"});`

## 知识结构：classification
把类比中的判断分成“可沿用 / 须加边界 / 不可沿用”三类。六条判断纵向排成审计账本，右侧三个固定标注栏对齐；分类后立即显示该判断成立或失效的理由。

## 表征形式
交互式类比审计账本。读者逐行把标注章拖到判断旁，最终得到一张同时保留解释力与失效边界的分类表。

## 层级里的各项
| 判断 | 归类 | 显示的边界标注 |
|---|---|---|
| 生存依赖彼此连接的环境系统 | 可沿用 | 改变一环可能沿系统传到其他环 |
| 可用物质与环境承载能力并非无限 | 可沿用 | “有限”足以提醒约束，不等于舱体有固定库存表 |
| 地球是完全封闭的系统 | 须加边界 | 物质大体循环，但能量持续从外部进入并向外散失 |
| 生态循环像生命保障设备一样可被完整设计和控制 | 须加边界 | 生态系统会自组织、迁移和演化，边界也具有渗透性 |
| 全人类像同一舱组，拥有相同权限 | 不可沿用 | 决策权、资源控制与发言能力分布不均 |
| 环境变化会让所有人承担相同风险 | 不可沿用 | 收益、暴露、损失与适应能力并不平均 |

## 必须点出来的一到三句
“地球飞船”适合提醒我们：生存条件彼此相连，而且存在边界。  
但类比不是等同；一旦它抹去开放生态、自然演化和权力差异，就应停止沿用。

## 交互（只有这一个）
读者把“可沿用 / 须加边界 / 不可沿用”标注章拖到六条判断上；归类改变行末批注，使其形成“类比有用，但只能用到这里”的直觉。

做对了立刻看到什么：标注章吸附进对应栏，整行亮起青绿色细边，边界批注从右侧展开。  
做错了立刻看到什么：标注章横向抖动后回到原位，并显示“这条忽略了能量交换 / 自然演化 / 权力差异，请检查类比在哪一步失效”。  
做到哪儿了怎么知道：页脚固定显示“类比审计 3 / 6”，已完成行留下实心分类印记。  
做完了怎么收：六行压缩成三组并由黄色界线隔开，底部出现“保留解释力，也标出失效处”；提供“重置审计”按钮一键复原。

## 场景构图
使用母题“地球弧面上方的一层极薄亮线”和“黄色约束线”。深色基底上，底部地球弧面只露出薄亮边界；主体是一张跨越弧面上方的任务审计账本，六行由细青线贯通。右侧三枚分类章像操作台印章，黄色竖线标出类比从“须加边界”开始失真的位置。

## 动效
入场：地球弧面先从下方升起，账本横线随后由左向右绘出，六条判断依次淡入。  
反馈：正确时青光沿该行扫至批注；错误时印章短促抖动，相关边界词以黄色闪现一次。
