# 页面构建契约

## 1. 文件边界

- 只创建或修改分配给你的 `pages/page-NN.html`。
- 不读、不改、不复制任何其他 `page-*.html`。
- 可读且应按需读取：`PLAN.md`、`assets/theme.css`、`assets/lec.js`、`assets/CHASSIS.md`、`assets/lib/LIBS.md`及任务清单指定的技法文档。
- 不新建页面资源、文档、测试、说明或总结。页面专属 CSS 与 JS 写在本页 HTML 内。
- 最终只交付 `page-NN.html`。

## 2. 固定 HTML 骨架

保留以下骨架及加载顺序。只替换 `NN`、在 `#stage` 内写本页标题与正文；`data-total` 固定为 `45`。不得删除、改名或包裹 `#stage`。

    <!doctype html>
    <html lang="zh">
    <head>
      <meta charset="utf-8">
      <link rel="stylesheet" href="assets/base.css">
      <link rel="stylesheet" href="assets/theme.css">
    </head>
    <body data-page="NN" data-total="45">
      <div id="stage"></div>
      <script src="assets/base.js"></script>
      <script src="assets/lec.js"></script>
    </body>
    </html>

- 按需库的 CSS 放在 `theme.css` 之后；库脚本放在 `lec.js` 之后、本页脚本之前。
- 骨架只有空的 `#stage`：不预设页眉、页脚，不调用 `Lec.mount()`。标题位置、组件和布局由本页内容决定。
- `assets/lec.js`只提供 `Lec.K`与`Lec.P`，不提供版面。
- 每页必须自包含，使用相对路径；直接通过 `file://` 打开即可显示并完成交互。禁止 CDN、网络请求和运行时下载。
- 底盘接口只去读 `assets/CHASSIS.md`，不得在本契约或页面中复制一套底盘实现。

## 3. 受众与文字

- 面向大学一年级通识课学生，文理混合；不得假定微积分、生物学或专业工程背景。
- 新术语首次出现时立即用日常语言解释；同页不得堆叠未解释术语。
- 公式、图表和模型旁必须有一句口语化解释，说明“它表示什么”，不能只给符号。
- 单句原则上不超过 35 个汉字；一段只表达一个判断。避免论文腔、宣传腔和幼儿化口气。
- 提示语使用直接、可执行的课堂口气，如“拖动后观察变化”“比较两种结果”；不得只写“点击这里”“试试看”。
- 页面须支持教师带讲和学生独立重看：可见内容必须包含明确页题、核心判断及必要的操作提示或阅读顺序，不能依赖教师口头补全关键结论。
- 不用长段背景铺垫；结论、证据和操作对象应就近放置。

## 4. 版面与密度预算

以下均为硬限制，按最终可见状态计数：

- 可见说明性正文不超过 260 个汉字；不含页题、刻度、短标签和控件值。
- 可操作控件不超过 6 个；一个按钮、滑块、输入框、选择框或独立拖拽物各算一个。
- 页面文本元素总数为 20–70 个，包含标题、正文块、标签、图注、图例、刻度、控件文字、读数及 SVG 图表文字。
- 画面占用比必须 ≥45%。
- 超预算时删减、合并信息或拆页；不得缩字、压行高、制造拥挤。若本页计划本身无法满足，在 HTML 注释中写明 `BUDGET_EXCEEDED`及超出的项目，不得伪装达标。
- 太空时增加有教学意义的结构、维度或过程；禁止靠放大字号、装饰块或空白间距凑占用比。
- 太满时优先减少刻度、冗余图例、重复读数和控件；刻度交给库抽稀。

`#stage`是 flex 列。其顶层区域必须设置固定高度或 `flex`份额，主内容区使用 `flex:1`并允许收缩；禁止所有顶层区域都按内容取高。一次性尺寸可写内联样式，不为单次布局发明类名。

默认使用 flex。只有矩阵、维度表等确需二维对齐时才用 grid。需要计算坐标才能对齐时应改 DOM 结构：拖拽使用 `transform`并保留正常流位置，不靠修改 `left/top`；刻度与滑块拆成相邻区块，不用绝对坐标硬凑。

禁止在缩放舞台内使用 `position:fixed`；需覆盖时用相对容器内的 `position:absolute`。

## 5. 字号地板

以下是最终 CSS 计算字号的下限：

- 纯数字、单位很短的刻度：≥12px。
- 标签、图注、图例、带词句的刻度、轴名：≥14px。
- 正文、提示、控件文字、tooltip、读数解释：≥16px。
- 正文行高：≥1.35。
- KaTeX 基准字号统一 ≥20px。
- 不得用缩放、`transform`或画进 canvas 的方式绕过字号检查。

设计画布为 1600×900。1366×768 屏幕的缩放系数为 `min(1366/1600,768/900)≈0.853`，即约 0.85；因此逻辑画布上的 12px 到屏幕上已约为 10.2px，以上地板不得再降低。

## 6. 主题与底盘

- 颜色、字体、圆角、阴影、边框和间距只使用 `theme.css`提供的 token、变量及骨架类；不得自创另一套视觉系统，不得写任意颜色值或另引字体。
- 不得删除底盘或主题提供的类，包括但不限于 `lec-root`、`lec-page`、`min0`、`cv-fill`；不得覆盖这些类的定位和缩放职责。
- 页面 CSS只负责本页结构和必要状态，不重置全局元素，不覆盖底盘缩放机制。

## 7. 数字与计算

- 教学内容中的常量、输入值、派生值、读数、图表数据和结论数字一律来自 `Lec.K`或调用 `Lec.P`得到；页面不得写死数字冒充计算结果。
- 页号、ARIA序号、CSS尺寸、动画时长及库配置精度不属于教学数据，可按布局需要书写。
- 所有显示值从计算结果格式化；同一量只保留一个数据源，不在 HTML、图表和提示中各写一份。
- 交互改变输入后必须重新计算输出；禁止预录动画、假数据、固定答案或只替换文字。
- 需要随机样本时引入 `seedrandom.min.js`并使用固定种子，如页号种子；禁止使用无种子的 `Math.random()`。
- 小型实时二分类网络使用 `mlp.js`；矩阵原语使用 `ml-matrix`。只有预训练模型、真实图像卷积或确需 GPU 的大矩阵才使用 tf.js；使用 tf.js 时每步必须 `tf.tidy()`或显式 `dispose()`，并确认 `tf.memory().numTensors`不持续增长。

## 8. 库是强制复用项

动手前先按“要做的事”读取 `assets/lib/LIBS.md`。已有库能完成的呈现工作，禁止从底层重写：

| 呈现工作 | 必用库 |
|---|---|
| 常规坐标轴、刻度、图例、折线、柱、散点、面积、饼、热力 | ECharts |
| 可拖拽、可命中检测的二维场景 | Konva |
| 三维场景 | Three.js |
| 三维地球 | Three.js + globe.gl |
| 下落、碰撞、摆动、堆叠、物理约束 | Matter.js |
| 节点连线、数据绑定矢量图形 | D3 |
| 成千上万元素同时运动 | PixiJS |
| 分步动画、路径描绘、形变 | anime.js |
| 多动画时间线 | GSAP |
| 滚动绑定动画 | GSAP + ScrollTrigger |
| 数学公式 | KaTeX |
| 矩阵运算 | ml-matrix |

- 直接使用 `<script src="assets/lib/xxx.js"></script>`；禁止复制库、改库或使用 CDN。
- 依赖顺序：Three.js先于 globe.gl、Vanta；GSAP先于 ScrollTrigger；本页脚本最后。
- KaTeX必须同时引用 `assets/lib/katex.min.css`与`assets/lib/katex.min.js`。
- ECharts必须用 `echarts.init(el,null,{renderer:'svg'})`，并显式设置各类文字字号；禁止默认 canvas renderer。
- Konva负责图形、拖拽和命中检测；普通标签使用绝对定位的 DOM叠层，不用 `Konva.Text`。确需随图形变换的内部短标注才可用 `Konva.Text`，且显式设置合规字号。
- 库版本只按 `assets/lib/LIBS.md`记录使用，不去压缩库文件中查版本。
- 用不到的库不加载。

## 9. Canvas、缩放与动画

- 手写 canvas一律使用 `Deck.fit`或`Deck.autofit`适配 CSS尺寸、舞台缩放和高分屏。
- 手写 canvas指针坐标一律通过 `Deck.pt`换算。
- 动画循环一律使用 `Deck.loop`。
- canvas取色一律使用 `Deck.rgb`或`Deck.rgba`。
- 禁止自行实现 `devicePixelRatio`缩放、`getBoundingClientRect`坐标换算或`requestAnimationFrame`循环。
- 使用 Konva 时采用其舞台指针坐标，不再二次换算。
- 容器尺寸改变后，图表、Three、Konva及其他渲染器必须同步调整逻辑尺寸和输出尺寸；不得只拉伸位图。
- 所有动画必须提供 `prefers-reduced-motion:reduce`分支：停止连续运动和自动播放，直接呈现稳定关键状态；交互计算仍须可用。
- 页面隐藏、组件移除或重置时停止循环、监听器和计时器。

## 10. 真交互与可达性

- 除非 `PLAN.md`明确标为静态页，每页至少有一个真交互。
- 真交互必须由用户操作改变模型参数、数据、观察视角、步骤或选择，并立即产生可解释的视觉或数值反馈。
- hover发光、指针跟随、自动循环、装饰粒子、翻页按钮和无结果的点击不算真交互。
- 允许扰动的整个范围内，讲解和结论都必须成立；不得只在默认值正确。
- 所有原生控件必须有可见标签。自定义控件必须可聚焦，提供恰当 `role`、`aria-label`及状态。
- 鼠标拖拽必须有键盘等价操作：方向键调整，Enter或Space执行，必要时提供可聚焦的重置按钮。
- 焦点样式必须清晰且使用主题 token；不得移除 outline。
- 状态变化须以可见文字或 `aria-live`读数反馈，不能只靠颜色。
- 颜色编码必须同时配合形状、位置、线型或文字标签。

## 11. 技法文档

任务清单中存在对应技法文档时，先用 `Skill`读取再写代码；不得跳过后自行重做一套。清单中没有对应项时才自行实现。底盘接口另按 `assets/CHASSIS.md`执行。

## 12. 完工自检

在 `pages/`目录运行：

    python3 assets/selfcheck.py page-NN.html

对每个可达交互状态，再使用一个或多个：

    python3 assets/selfcheck.py page-NN.html --after "<触发该状态的 JS>"

必须逐项满足：

- JavaScript报错为 0。
- 资源加载失败为 0，外部请求为 0。
- 超出1600×900画布、被裁元素、文字叠压为 0。
- 字号及行高全部达到本契约地板。
- 画面占用比 ≥45%。
- 文本块为20–70个。
- 不存在无意义且占比不足1%的小容器。
- 初始态、最小值、最大值、重置态及关键分支均无错位、遮挡或错误结论。
- 键盘可完成主要交互；reduced-motion分支稳定可读。
- canvas、SVG、图表和DOM在缩放后对齐，指针命中位置正确。
- 随机结果可复现，所有读数与`Lec`计算一致。

任何一项不干净都必须修改页面并重跑；重复到所有状态干净为止。不得以“已知问题”、说明文字或交付总结代替修复。
