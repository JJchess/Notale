# page-36 · 距离改写任务 · **145 秒**

## 照这个写
`Lec.mount({index:36,kicker:"MISSION DISTANCE",title:"月球或火星：距离改写整套任务",take:"距离同时改变航行时间、通信延迟、补给机会和紧急返回能力。"})`

三维初始化：`Globe()(el).backgroundColor("#071018").showAtmosphere(true).atmosphereColor("#36D6C0").atmosphereAltitude(0.12).arcColor(() => "#36D6C0").arcStroke(0.55).arcDashLength(0.45).arcDashGap(0.18).arcDashAnimateTime(1800).pointOfView({lat:18,lng:-28,altitude:2.2},900)`。

任务距离采用非线性压缩；真实距离只显示于读数，不暗示天体尺寸或间距按比例。默认窗口 `月球基准`，约束 `通信`。数值经 `Lec.P.significantFigures(value,3)` 格式化。

## 知识结构：comparison
以月球任务、火星任务为两列，以航行、通信、补给、返回为四条对齐横行；切换窗口时，同一行两列同步更新。三维连线负责建立空间差异，固定行列负责防止读者只把它理解成“远一点”。

## 表征形式
交互式三维地球—月球—火星任务图。青色虚线表示当前可讨论路线，琥珀节点表示正在检验的约束；右下固定显示四行比较板，旋转视角不改变比较顺序。

## 四行 × 两列
| 任务维度 | 月球任务 | 火星任务 |
|---|---|---|
| 航行时间 | 约 3 天（教学任务情境） | 约 6–9 个月，随窗口与路线改变 |
| 往返信号延迟 | `Lec.P.roundTripSignalDelay(Lec.K.EARTH_MOON_MEAN_DISTANCE_M)` | `Lec.P.roundTripSignalDelay(selectedEarthMarsDistance)` |
| 补给机会 | 可按数日级航程规划；仍受发射与任务条件限制 | 途中不能即时补给，库存与预案须覆盖更长间隔 |
| 紧急返回 | 存在数日级返回方案的可能 | 不能把“立刻掉头回家”作为常规预案 |

窗口预设：`月球基准`使用 `Lec.K.EARTH_MOON_MEAN_DISTANCE_M`；`火星较近位置`、`火星较远位置`分别使用 `Lec.K.EARTH_MARS_DISTANCE_RANGE_M` 的下限、上限。

## 必须点出来的一句
月球与火星不是同一道任务题换了目的地：距离会同时重写时间、通信、补给和返回条件。

## 交互（只有这一个）
读者切换三个任务窗口，再点选“航行 / 通信 / 补给 / 返回”约束；天体位置、路线脉冲和对应比较行同步变化，从而形成“距离牵动整套系统”的直觉。

做对了立刻看到什么：查看某窗口下的约束后，对应横行青色描边发光，路线脉冲从地球抵达目标，检查位亮起。  
做错了立刻看到什么：若把火星窗口判成可即时通信或即时返回，选择回弹并显示“距离改变的是响应时间；请看往返延迟或返回行。”  
做到哪儿了怎么知道：顶部显示 `已比较 0/4 项`，每完成一项点亮一个四段环。  
做完了怎么收：四项全亮后，两条路线同时保留，四行由上至下扫亮并出现核心句；提供“重置比较”恢复默认窗口，不给目的地评分。

## 场景构图
使用“脚印逐渐变成轨道虚线的路径”“从地球边缘切出的青色弧面”“分叉而不封口的任务路径”。深蓝空间中，地球占画面左下近景，月球沿短弧悬于近侧；火星位于右上远景，切换窗口时沿暗淡轨道弧移动。两条任务虚线从地球分叉，底部嵌入半透明四行比较板；角落常驻“距离与尺寸已压缩”的比例警示。

## 动效
入场：地球先由暗处转入，月球与火星随后从景深中浮现，两条虚线从地球向外依次生长。  
反馈：正确检查时青色脉冲沿路线传播；错误判断时目标行横向轻抖两次，琥珀风险标记短促扩散后停住。

## 不许碰
不把月球或火星标成“更好”“更先进”或默认终点；不把工程约束转换成目的地价值排名。航行时间只作任务情境范围，不承诺具体任务架构；三维间距与天体尺寸不得冒充真实比例。
