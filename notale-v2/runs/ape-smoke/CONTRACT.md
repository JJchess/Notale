# CONTRACT.md —— 24 页共用构建契约

这份契约和 `PLAN.md`、`assets/theme.css`、`assets/lec.js` 是你唯一能看到的东西。
你看不到别的页面长什么样，别的 agent 也看不到你的。**凡是要求「所有页面看起来
是一套东西」的地方，全靠这份契约的字面规定，不靠默契。** 契约没写的，你可以自己
决定；契约写了的，不允许按自己的理解改一点点。

读者是大学一年级通识课学生，文理兼有，不假定学过微积分或生物学。场合是老师在
课堂上带着讲一遍，学生课后自己再看一遍。这意味着：

- 术语第一次出现要展开一句人话解释，不能假设读者认识「数量级」「突触」这类词的精确含义。
- 说明句要短、口语化、能读出声。一句话超过两行就该拆成两句。
- 提示语（hover、按钮上的字）用平实的陈述或邀请语气，不要用感叹号堆砌、不要用
  「快来试试！」这种营销腔。
- 不假设读者会主动探索——重要的交互要有一句静态文字先说清楚「这是什么、能做什么」，
  交互本身是印证和体验，不是唯一的信息来源。

## 1. 你只碰一个文件

你只写 `pages/page-NN.html`（NN 是你的页号）这一个文件。不读、不改任何其他
`page-*.html`；不改 `assets/theme.css`、`assets/lec.js`、`assets/base.css`、
`assets/base.js`；不新建这份契约之外要求的文件。如果你觉得需要一个额外的资源
（图片、字体、数据文件），自己放进 `pages/` 下用相对路径引用，但优先考虑能不能
用现有库和 `Lec` 现算出来，不要为了省事去外部拉资源。

## 2. HTML 骨架——照抄，只改三处

harness 已经建好骨架，你只在 `#stage` 里面添加内容。骨架长这样：

```html
<!doctype html>
<html lang="zh">
<head>
  <meta charset="utf-8">
  <link rel="stylesheet" href="assets/base.css">
  <link rel="stylesheet" href="assets/theme.css">
</head>
<body data-page="NN" data-total="TT">
  <div id="stage"></div>
  <script src="assets/base.js"></script>
  <script src="assets/lec.js"></script>
</body>
</html>
```

你能改的只有三处：`data-page`/`data-total` 里的页号页数（如果还没填好）、
`<title>`（如果骨架里没有就在 `<head>` 里加一个，取 `Lec.K.DECK_TITLE` 加你这页的
标题）、以及 `#stage` 内部的全部内容。不要删掉 `base.css`/`theme.css`/`base.js`/
`lec.js` 中的任何一行引用，也不要改变它们的加载顺序。你自己的 `<script>`、
`<style>`、库引用，一律加在 `#stage` 之后、`</body>` 之前，顺序见第 7 节。

`#stage` 是 1600×900 的逻辑画布，缩放由底盘自动处理，你不需要也不允许自己写
缩放逻辑。

## 3. 版面预算——硬上限，写死在这里

以下数字是**上限**，不是建议：

- 正文文字（讲解句、要点句，不含刻度/图例/坐标轴标签/按钮上的字）：**每页不超过
  180 字**（中文字符计数）。
- 控件数量（按钮、滑块、可拖拽物、输入框等一切可交互元素之和）：**不超过 6 个**。
- **页面上文本元素总数（selfcheck 报的「文本块数」口径）：不超过 70。**
  这个数包含每一个坐标刻度、每一条图例、每一个读数、每一个标签。经验值：一页
  中位数约 45 个，其中只有约 18% 是句子，剩下 82% 是刻度和标签——所以控制总数
  主要靠**减少刻度密度、合并读数、去掉冗余图例**，不是靠删你写的那几句话。

**超了怎么办：拆掉一部分内容，或让库自己抽稀刻度（echarts 的 `axisLabel.interval`
之类），不允许通过缩小字号把内容硬塞进画面。** 字号地板（见第 4 节）是不可谈判的，
预算和字号冲突时，永远是砍内容，不是砍字号。

---

## 4. 字号下限——不可谈判

分档地板：

| 档 | 内容 | 最小字号 |
|---|---|---|
| 刻度档 | 坐标轴上纯数字的刻度值 | **12px** |
| 标签档 | 图例、坐标轴名称、图注、按钮文字、任何带词句的短标注 | **14px** |
| 正文档 | 讲解句、要点句、说明文字 | **16px** |
| — | 所有正文行高 | **≥1.35** |

这些数字对应的是 1366×768 屏幕上的实际显示效果：舞台按 1600×900 设计，那块屏幕
上的缩放系数约 0.85，也就是你在 1600×900 逻辑坐标里写的字号，最终会乘 0.85 显示。
上面这张表已经是缩放后的地板——**你在代码里写的字号本身就要满足这张表**，不要
心算「反正会缩小所以我多写几 px」，`selfcheck.py` 量的是缩放后的真实渲染尺寸。

两个特别提醒（对应第 7 节两个库的已知坑）：

- **KaTeX 基准字号 ≥20px**，不是 16px。公式嵌套（分式带上下标）会把有效字号
  复利式压小，16px 基准下最深处只有 9.7px，直接破刻度档地板。
- **echarts 一律 `{renderer:'svg'}`**，默认 canvas 渲染器画出来的字不进 DOM，
  字号检查看不见，等于没检查过。

## 5. 主题——只取，不新造

所有颜色、字体、字号阶梯、间距单位，一律从 `assets/theme.css` 里已经定义好的
变量/类取用。你可以在自己的 `<style>` 里写布局（grid、flex、定位、尺寸），但
**颜色值、字体族、间距数值不允许在你的 CSS 里出现新的字面量**——如果 theme.css
里没有你想要的那个具体值，就近取一个已有变量，不要自己发明一个新色号或新字号。
这是保证 24 页放在一起像一套书、不是 24 种风格拼盘的唯一手段。

`base.css` 要求你（或者 theme.css 已经）给出三个 token：`--bg`、`--text`、
`--font-sans`；这些如果 theme.css 里已经定义，你不需要重复定义，直接使用即可。

canvas 里画东西取色不能写 `var(...)`（canvas 上下文认不出 CSS 变量），要用
`Deck.token(name)` / `Deck.rgb(name)` / `Deck.rgba(name, a)` 去读 theme.css 里
定义的变量，不允许在 canvas 绘图代码里写死十六进制色值。

## 6. 数字——只从 Lec 取，不写死

页面里出现的任何量级、年代、数量、比例，一律通过 `Lec.K`（常量）和 `Lec.P`
（函数，见下）取得，不允许在 HTML/JS 里写一个字面数字冒充这些量。

`Lec.K` 常量与 `Lec.P` 函数的完整清单见 `PLAN.md`/本契约开头列出的接口表，
不要在没查过这张表的情况下猜一个函数名或键名。如果你需要的量确实不在 `Lec` 里
（比如某个纯几何的中间量），可以自己用 JS 算，但**输入的原始物理量/生物量必须
来自 `Lec.K`**。

如果页面涉及随机生成的数据（抽样点、随机分布、噪声），必须用 `assets/lib/
seedrandom.min.js` 给一个固定种子（建议用页号做种子，如 `'page-07'`），保证
读者每次打开看到的数字序列一致。凡是讲解文字里写了具体数字，这个数字必须是
在给定种子下稳定复现的，不能是「大概率是这个数，但也可能不是」。

## 7. canvas / 交互的必守条款

以下机制由底盘（`assets/base.js`，全局对象 `Deck`）提供，**一律用它，不允许
自己重新实现**：

- **canvas 尺寸适配**：一律用 `Deck.fit(cv)` 或 `Deck.autofit(cv, draw)`。
  不允许自己写 `devicePixelRatio` 换算和 `canvas.width = ...`。
- **指针坐标换算**：一律用 `Deck.pt(el, e)` 把事件坐标转成舞台逻辑坐标。
  不允许自己用 `getBoundingClientRect()` 手算——外层有 `transform: scale()`，
  `e.offsetX` 在缩放舞台里是错的。Konva 场景例外：`stage.getPointerPosition()`
  自己内部走 `getBoundingClientRect`，天然扛缩放，不需要再套 `Deck.pt`。
- **动画循环**：一律用 `Deck.loop(fn, opt)`。它已经处理好 reduced-motion（见下）
  和标签页切换后台时的 dt 跳变，不允许自己写 `requestAnimationFrame` 循环。
- **reduced-motion 分支**：不用额外写判断——`Deck.loop` 在系统要求减少动态时
  自动只画一帧 `fn(opt.still || 0, 0)`。你需要做的是**在调用 `Deck.loop` 时
  传对 `opt.still`**：指定动画定格在哪一帧最能说明问题（通常是过程走完之后的
  终态，不是起始帧的空白状态）。
- **键盘可达**：所有可交互元素（按钮、滑块、可拖拽物）必须能用 Tab 聚焦、
  用 Enter/Space/方向键操作，不允许只支持鼠标/触摸事件。焦点态用 `--focus`
  变量对应的样式，不要隐藏浏览器默认焦点框而不给替代。
- canvas 取色一律走 `Deck.rgb`/`Deck.rgba`（见第 5 节）。
- 布局：grid/flex 的每一个分栏子项都要加 `.min0` 类；铺满容器的 `<canvas>`
  一律加 `.cv-fill` 类。这两条不是风格建议，是不加就会出可见 bug（内容被裁掉/
  canvas 显示成 300×150）的必守项。

`Deck` 完整接口（尺寸/缩放/canvas/指针/取色/动画/小工具）已经列在
`assets/base.js` 对应的说明里，不要重复发明，也不要为了绕开学习成本自己写一套
平行实现。

## 8. 库——凡是已有库能做的，不允许从底层重写

动手前先按下表核对，你要做的事十有八九已经有库：

| 要做的事 | 用哪个库 |
|---|---|
| 坐标轴/刻度/图例/折线/柱状/散点/面积/饼/热力 | `echarts`（**必须** `{renderer:'svg'}`） |
| 可拖拽、需要命中检测的二维场景 | `konva`（文字标签用 DOM 叠加，不用 `Konva.Text`，见下） |
| 三维场景/旋转结构/光照材质 | `three`（r160，`outputColorSpace`） |
| 三维地球 | `three` + `globe.gl` |
| 生成式动画背景 | `three` + `vanta.net` |
| 下落/碰撞/摆动/堆叠/拖拽/约束 | `matter` |
| 节点连线图、数据驱动的精确矢量图形 | `d3` |
| 成千上万元素同时运动 | `pixi` |
| 分步动画、依次出现、路径描绘 | `anime`（v3 旧 API，`anime({targets:...})`） |
| 多动画精确编排 | `gsap`（+ `ScrollTrigger` 若要绑定滚动） |
| 矢量动画文件播放 | `lottie` |
| 伪三维插画 | `zdog` |
| 指针跟随倾斜 | `vanilla-tilt` |
| 进入视野淡入 | `aos` |
| 数学公式排版 | `katex`（基准 ≥20px，见第 4 节） |
| 矩阵乘法/行列式/求逆/特征分解 | `ml-matrix` |
| 可复现随机 | `seedrandom` |
| 页面上实时训练小型二分类网络、画决策边界 | `mlp.js` |
| 加载预训练模型、真图片卷积、GPU 大矩阵 | `tf.min.js`（**不要**用它实时训练页面级小网络，见 LIBS.md 的实测对比） |

这条只管**呈现层**。呈现之下的**计算必须真算**：梯度下降真的要迭代、轨道积分
真的要积分、组合数真的要数、`Lec` 给的物理量真的要代入公式——不允许用预录动画、
写死的中间结果或臆造数据去冒充计算过程。

引用方式：库文件都在 `assets/lib/` 下，直接 `<script src="assets/lib/xxx.js">`
相对 `pages/` 引用，不用下载、不用 CDN、不用检查文件是否存在。版本号按
`assets/lib/LIBS.md` 上写的来，**不要去压缩后的库文件里查版本**——查不出来也是
白烧一次调用。多个库之间有加载顺序要求的（three → globe.gl / vanta，gsap →
ScrollTrigger，katex 的 css 要和 js 一起引）严格按 LIBS.md 里写的顺序。

几个必须记住的坑（都在第 4/6 节提过一次，这里合并强调一遍）：

- `echarts.init` 必须传 `{renderer:'svg'}`，否则文字进不了 DOM，字号检查形同没做。
- `Konva.Text` 默认 12px 且永远在 canvas 里，字号检查看不见；场景上所有**文字**
  用 DOM 元素绝对定位叠加，`Konva` 只画**图形**。
- KaTeX 基准字号 ≥20px。
- `tf.min.js` 每步要 `tf.tidy()` 或手动 `dispose()`，否则显存只增不减；这一页如果
  用得到 tf.js（大多数页面用不到），务必检查 `tf.memory().numTensors` 不随时间上涨。
- 一切随机生成的地方用 `seedrandom` 给定种子。

## 10. 什么算真交互，什么是装饰

**真交互**指：读者的操作会改变屏幕上呈现的信息，而这个变化背后有真实计算或真实
数据支撑。判据——去掉这个控件之后，页面传达的信息量会变少，或者读者验证/探索
某个论断的方式会消失。例如：拖动滑块改变网络学习率、真的重新训练几步并显示新的
决策边界；拖动时间轴、真的用 `Lec.P.compressToTimeline` 重算位置和文字；点击
按钮切换数据集、真的换一批 `seedrandom` 生成的样本重新计算统计量。

**装饰**指：视觉上会动、但不改变任何信息，或者“看起来能点”但只是切换一个已经
预先写好的静态状态（等价于两张图片来回切）。悬浮变色、进入视野淡入（`AOS`）、
背景粒子（`vanta`）都是允许存在的装饰，但**它们不能是这一页唯一的“交互”**——
每一页至少要有一个满足上面判据的真交互，交互前要有一句静态文字先说明它是什么、
怎么操作、期待看到什么变化（对应本契约开头「读者」那一节的要求）。

## 11. 完工前自检——改到干净为止

在 `pages/` 目录下跑：

```
python3 assets/selfcheck.py page-NN.html
```

它按 1600×900 真实渲染一遍，报：JS 报错、加载失败的资源、超出画布的元素、
被裁掉的元素、字号最小值与中位数、密度指标（画面占用比、容器数、文本块数、
文字叠压、占比不足 1% 的小容器）。

判据：

- **零 JS 报错，零加载失败资源。**
- **零超出画布、零被裁元素**（KaTeX 的 `.katex-mathml` 隐藏副本已被 selfcheck
  排除，不用管它报的那部分）。
- **字号最小值不低于第 4 节对应档位的地板。**
- **文本块数不超过第 3 节的 70 上限**，画面占用比不出现异常（明显过空或过满）。
- 如果页面有需要交互触发才能看到的状态，用 `--after "<一段 JS>"` 至少跑一遍
  触发后的截图检查，不能只看初始状态干净就算过关。

**只跑，不代替判断**——它只报告问题，不会替你改文件。发现问题就回去改这一个
`page-NN.html`，改完重新跑，直到上面几条全部满足为止。不允许把「减少检查项」
「放宽判据」当作让检查通过的手段，只允许改页面内容本身。
