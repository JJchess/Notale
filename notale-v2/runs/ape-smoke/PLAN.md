# 《Apeman, Spaceman：一粒沙与最杰出的产物》 90 分钟互动讲义 · 总规划

## 0. 这套讲义的主线

同一个人类，既是空间和时间尺度上几乎可以忽略的一粒尘埃，又是已知宇宙中组织复杂度最高的产物之一——这两句话说的不是矛盾的两件事，而是"位置"和"结构"这两个不同维度的事实；这堂课要让学生学会区分并同时持有这两个维度。

| 章 | 页 | 这一章要让读者信什么 |
|---|---|---|
| Ⅰ 开场 | 01–02 | 这门课要解决一个真实的悖论，不是修辞游戏 |
| Ⅱ 空间尺度 | 03–06 | 在空间上，人类的位置微不足道到超出直觉 |
| Ⅲ 时间尺度 | 07–09 | 在时间上，人类的历史短暂到超出直觉 |
| Ⅳ 物质视角 | 10–12 | 组成人的原子毫无特殊之处，和恒星、石头共用一张元素周期表 |
| Ⅴ 复杂性视角 | 13–16 | 同样普通的原子，被组织出了惊人的复杂程度——这才是"杰出"的真正来源 |
| Ⅵ 稀有性视角 | 17–19 | 这种复杂程度在宇宙中很可能极其罕见，罕见到接近"渺小"本身的分量 |
| Ⅶ 综合 | 20–22 | 两个视角同时为真，且这个框架可以用来衡量文明的未来 |
| Ⅷ 收束 | 23–24 | 六个视角收成一句话，带走的是框架而不是数据 |

### page-01 · 标题页
**章**：Ⅰ　**kicker**：`OPENING`
**标题**：`Apeman <em>与</em> Spaceman`
**take**：`同一个物种,能用两种完全相反的方式描述自己——这门课要说清楚为什么两者都对。`
**停留**：`1 分钟`

**内容**
- 全屏氛围背景，缓慢漂浮的尘埃粒子群，营造"漂浮在宇宙中"的沉浸感。

**采用的形式**：全屏背景氛围 + 大标题，无交互
理由：开场不需要认知加工，只需要在90分钟开始时把情绪和主题一次性立住。

**否决的形式**
- *交互式粒子拖拽*：开场阶段学生还没有任何背景知识可供组织，强行交互只会分散对主张本身的注意力。

**版式**：focus
**必用skill**：ambient-section-particles
**独占**：全课情绪基调的首次建立（尘埃氛围视觉母题的起点，后续 06/20/24 页延续但各自承担不同任务，见第2节）

### page-04 · 拖动这根尺子
**章**：Ⅱ　**kicker**：`SCALE · SPACE`
**标题**：`从普朗克长度拖到可观测宇宙`
**take**：`从普朗克长度到可观测宇宙的直径,中间跨越约60个十的次方——人类正好卡在中间偏"大"的位置。`
**停留**：`8 分钟`

**内容**
- 全幅对数刻度标尺，横跨 `Lec.K.LENGTH_PLANCK` 到 `Lec.K.D_OBSERVABLE_UNIVERSE`；一个可拖拽的指针。
- 拖动时用 `Lec.P.logScalePosition/logScaleValue` 做位置↔真实数值的换算；指针经过预设锚点（`SIZE_PROTON`、`SIZE_ATOM`、`SIZE_VIRUS`、`SIZE_BACTERIUM`、`SIZE_CELL_HUMAN`、`SIZE_ANT`、`HEIGHT_HUMAN_AVG`、`HEIGHT_EVEREST`、`D_EARTH`、`D_SUN`、`D_MILKYWAY`）时自动吸附，就近显示该物体的名字和小图标。
- 一个常驻读数框，显示 `Lec.P.humanScalePosition()` 给出的人类距两端各多少个数量级（`ordersFromPlanck`、`ordersFromUniverse`）。
- 学生需要亲手把指针从一端拖到另一端，感受"匀速拖动、数值指数级跳跃"的错位感。

**采用的形式**：全幅画布 + 可拖拽对数标尺，实时显示当前位置对应的真实物体和数量级
理由：这是本课最重要的空间直觉建构，必须让学生自己拖动感受跨越60个数量级是什么感觉，而不是静态展示一张图表。

**否决的形式**
- *静态图片列表*：无法让学生亲自体会log scale的"跳跃感"，只是看图不是体验。
- *echarts对数轴散点图*：轴上的刻度是抽象数字，不能直接呈现物体本身的图像/名字，削弱文字与图像的对应关系。

**版式**：canvas-full
**必用skill**：gsap-core, container-lines
**独占**：全课唯一的空间尺度对数标尺（`Lec.P.logScalePosition/logScaleValue`、`Lec.P.humanScalePosition`），后续页面只引用其结论，不重画标尺

**内容**

**必用skill**：gsap-core, d3-viz
