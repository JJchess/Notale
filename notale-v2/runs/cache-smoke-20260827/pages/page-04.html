一个神经元先乘权重，再加偏置

输入 点一个输入，送进神经元
参数 本页固定
权重 w = 0.7 偏置 b = −0.4

输入会更换；同一组参数会重复执行同样的两步。

一个神经元内部

观察数值沿同一条路径重算

从左到右：输入 → 乘权重 → 加偏置 → 总分
x = 2
先乘权重
2 × 0.7 = 1.4
x × w
再加偏置
1.4 + (−0.4) = 1.0
x × w + b
内部总分z = 1.0

w 决定输入被放大、缩小或反向；b 给总分整体挪一点。

神经元的内部总分，就是 输入 × 权重 + 偏置。
