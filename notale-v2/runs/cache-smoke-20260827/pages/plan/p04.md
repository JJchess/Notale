# page-04 · 神经元先算一笔账 · **90 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `ONE NEURON · 第一步` |
| 主标题 | 一个神经元先乘权重，再加偏置 |
| 收束句 | 神经元的内部总分，就是 `输入 × 权重 + 偏置`。 |
| 下一问 | 总分可以大于 1 或小于 0，怎样把它变成 0–1 的数？ |

## 知识结构：classification

关系不变量：`x` 必须归入“输入”，`w` 与 `b` 必须共同归入“参数”；右侧神经元内部固定嵌套“先乘 `x × w`、再加 `b`、得到总分 `z`”，各项沿同一水平基线从左向右相连。

共享原语：`.k-classification` 负责区分输入与参数，并把两类量归入同一个神经元计算；`.sample` 表示输入，`.param` 表示 `w`、`b`，`.neuron` 包含两步算术。它们落入 `.split-lr`：左侧选择输入并辨认对象类别，右侧展开神经元内部账本。

## 表征形式

交互式分步算术图：点击输入卡片后，一次输入脉冲依次经过乘法格、加法格，最终更新内部总分。

使用原生 DOM 与 SVG；对象数量少、关系固定，便于保持文本清晰、键盘可操作及箭头精确对齐，无需图表库。

## 一笔神经元账

| 画面对象 | 固定文字或值 | 默认试算 |
|---|---|---|
| 输入卡片 | `x = -2`、`x = -1`、`x = 0`、`x = 1`、`x = 2` | 选中 `x = 2` |
| 权重标签 | `权重 w = 0.7` | `2 × 0.7 = 1.4` |
| 偏置标签 | `偏置 b = -0.4` | `1.4 + (-0.4) = 1.0` |
| 乘法格 | `先乘权重` | `x × w` |
| 加法格 | `再加偏置` | `x × w + b` |
| 最终读数 | `内部总分 z` | `z = 1.0` |
| 左侧提示 | `点一个输入，送进神经元` | — |
| 右侧旁注 | `w 决定输入被放大、缩小或反向；b 给总分整体挪一点。` | — |

## 交互

学习者点击五张输入卡片之一；默认 `x=2`，`w=0.7`、`b=-0.4` 固定不可调。每次点击立即更新乘积、加法式和 `z`，并让当前计算路径加粗。

学生应观察到：同一组参数下，换一个输入会重新执行完全相同的两步算术；本页没有目标态或对错反馈。提供“重置本页”，恢复 `x=2` 及默认读数；输入卡片支持 Tab、方向键与 Enter。

## 动效

点击后，强调色脉冲从输入卡片向右移动：先行进至乘法格，240 ms；停留并显出乘积 160 ms；再行进至加法格与总分，240 ms。新出现的箭头短暂使用强调色，完成后恢复模型色；减少动态模式下取消位移，只按顺序切换高亮与读数。

## 核对

| 参数 | 期望乘积 | 期望总分 |
|---|---:|---:|
| `x=2, w=0.7, b=-0.4` | `1.4` | `1.0` |
| `x=-2, w=0.7, b=-0.4` | `-1.4` | `-1.8` |
| `x=0, w=0.7, b=-0.4` | `0.0` | `-0.4` |

显示值统一保留 1 位小数，避免把 `-0.0` 写入画面。

## 主工作流

build-interaction ← 输入脉冲必须驱动两步算术、路径高亮与读数同步更新

## 不许碰

不把内部总分解释成概率，不出现 S 形激活、0.5 阈值或 0–1 压缩；这些归 p05。不得引入误差、损失或参数更新方向；误差归 p07，自动寻找改动方向归 p09。
