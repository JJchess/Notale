# page-05 · 把总分压成概率 · **85 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `ACTIVATION · 激活` |
| 主标题 | 任意总分，都能被压进 0–1 |
| 收束句 | S 形激活把任意总分压到 0–1；总分为 0 时，输出正好是 0.5。 |
| 下一问 | 同一组参数遇到不同输入，会得到怎样不同的概率？ |

## 知识结构：process

**关系不变量：** 总分探针、S 形曲线交点、输出概率必须沿同一条读取链相连；交点到横纵轴的辅助线同步移动，纵轴始终使用统一的 0–1 尺度。

**共享原语：** `.k-process` 在 `.canvas-full` 中组织“总分 → 激活 → 概率”的单一主几何；`.path` 承担左到右的读取方向，`.panel` 固定右侧概率读数，避免数值随曲线移动而跳位。

## 表征形式

交互式 S 形曲线探针：学生拖动总分，曲线交点、辅助线、概率读数和口语化解释即时联动。

曲线与坐标轴使用 ECharts，单行激活式使用 KaTeX；读数与控件使用原生 DOM。

## 主工作流

build-interaction ← 让拖动总分与曲线位置、概率数值和直觉解释保持可逆且同步

## 曲线与读数

| 对象 | 画面文字或数值 |
|---|---|
| 单行短式 | `p=\frac{1}{1+e^{-z}}` |
| 横轴 | `内部总分 z`，刻度 `−8、−4、0、4、8` |
| 纵轴 | `输出概率 p`，刻度 `0、0.5、1` |
| 默认探针 | `z = 0` |
| 默认读数 | `p = 0.500` |
| 默认口语 | `100 次相似情况中，模型会押“是”约 50 次` |
| 左端提示 | `总分越负，输出越接近 0` |
| 右端提示 | `总分越正，输出越接近 1` |
| 0 点标注 | `0 → 0.5` |
| 局部标注 | `0 点最陡：局部变化率 0.25 / 总分` |
| 显示常量 | `SIGMOID_VALUE_AT_ZERO = 0.5`；`SIGMOID_MAX_SLOPE = 0.25` |

## 交互

学生拖动横轴探针或使用左右方向键调整 `z`；范围 `−8～8`，步长 `0.1`，默认 `0`。拖动时橙色探针沿横轴移动，主色交点贴着曲线移动，两条虚线分别投向 `z` 与 `p` 读数；右侧同时更新三位小数概率和“100 次中约押多少次”的整数表述。

探针经过 `z=0` 时短暂强调 `0 → 0.5`，用于建立中点直觉，不设置正确位置或闯关反馈。提供“重置本页”，恢复 `z=0`；刷新后同样回到该状态。
