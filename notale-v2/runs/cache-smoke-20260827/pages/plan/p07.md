# page-07 · 概率的代价 · **80 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `PREDICTION COST` |
| 主标题 | 给正确答案的概率越低，误差越大 |
| 收束句 | 交叉熵把“有多不相信正确答案”变成一个可比较的误差数字。 |
| 下一问 | 既然误差能量出来，亲手调参数能把它降下去吗？ |

## 知识结构：generalization

关系不变量：正确答案始终固定为 `1`；“给正确答案的概率”与“交叉熵误差”必须由同一探针联动，并与三个参照点共用同一横轴、纵轴和数值精度。上区给主张与一行短式，下区给完整关系曲线、探针和差距尺。

共享原语：`.k-generalization` 以“概率越低，误差越大”为主干，下接公式与三个参照读数；`.split-tb` 将结论依据置于上半区、可操作证据置于下半区；`.gap-ruler` 把当前误差同步翻译成可量读的差距高度。

## 表征形式

交互式定量关系图：横轴为给正确答案的概率，纵轴为每样本交叉熵误差；游标、数值读数和竖直差距尺同步变化。短式使用 KaTeX，曲线使用 ECharts SVG renderer。

## 主工作流

build-chart ← 准确呈现概率与交叉熵的非线性关系并联动探针读数

## 固定答案与参照读数

| 项目 | 画面文字或数值 | 用途 |
|---|---|---|
| 正确答案 | `t = 1` | 固定显示，不可操纵 |
| 一行短式 | `L=-\ln(p_{\text{正确}})` | KaTeX 显示 |
| 横轴 | 给正确答案的概率 `p正确`，`0.01–1.00` | 概率刻度 |
| 纵轴 | 交叉熵误差 `L`，`0–4.61` | 每样本误差 |
| 高概率参照 | `p正确=0.90 → L=0.105` | 常驻空心标记 |
| 一半概率参照 | `p正确=0.50 → L=0.693` | 常驻空心标记 |
| 低概率参照 | `p正确=0.10 → L=2.303` | 常驻空心标记 |
| 当前读数 | `给正确答案：50 次 / 100 次`；`误差：0.693` | 默认状态 |
| 端点保护 | `BCE_CLIP_EPSILON = 1e-12` | 仅实现计算，不印在画面 |

## 交互

学习者拖动“给正确答案的概率”滑块，范围 `0.01–1.00`、步长 `0.01`、默认 `0.50`；也可在曲线上移动探针。两种操作共享同一状态，立即更新曲线上的实心探针、`100 次中押正确多少次`、三位小数误差读数和差距尺斜纹高度。

键盘支持方向键单步调整；tooltip 同时朗读概率与误差。提供“重置本页”，恢复 `p正确=0.50`。不设置目标值、成功或失败反馈。

## 核对

| `p正确` | 期望 `-\ln(p正确)` |
|---:|---:|
| `0.90` | `0.1053605` |
| `0.50` | `0.6931472` |
| `0.10` | `2.3025851` |

计算时先将概率限制到 `[1e-12, 1-1e-12]`；画面统一显示三位小数。

## 不许碰

不比较参数左右轻推后的误差，不出现坡度、下降方向、导数或数值差分；这些归 p09。本页只建立预测概率与交叉熵代价的对应关系，不说明怎样修改 `w`、`b`。
