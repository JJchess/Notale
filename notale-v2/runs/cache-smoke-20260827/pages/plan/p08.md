## 知识结构：process

关系不变量：三张阶段卡从左到右连接为“固定样本—手调参数—比较误差”；四条样本始终同行，预测点与答案共用 0–1 标尺，起点误差与当前误差共用 0–4 标尺。

共享原语：`.k-process` 维持三阶段单向关系；`.knob` 把 `w`、`b` 明确为可改数字；`.gap-ruler` 在末卡同尺度呈现误差变化。骨架横向落入 stage-cards，中卡最宽，末卡保留实验记录行。

## 表征形式

交互式双旋钮实验：中卡同步显示四条样本的预测点，末卡显示平均误差差距尺、改前改后读数及调节历史。

四样本预测图与误差历史使用 ECharts SVG renderer；旋钮、读数和记录使用原生 DOM。

## 三阶段内容

| 阶段 | 画面文字 | 内容与数值 |
|---|---|---|
| ① 固定样本 | `答案不动` | `x = -2, -1, 1, 2`；`t = 0, 0, 1, 1` |
| ② 手调参数 | `只转这两个旋钮` | `w`、`b`；默认均为 `0.0` |
| ② 预测图 | `模型押给类别 1 的概率` | 横轴四个 `x`；纵轴 `0–1`；答案以黑色短横线标在 0 或 1，预测以主色圆点表示 |
| ③ 比较误差 | `四条样本的平均误差` | 起点 `0.693`；当前值实时计算；差值显示为 `本次变化 +0.000` 或 `−0.000` |
| ③ 记录 | `改前 → 改后` | `w: 0.0 → 当前值`；`b: 0.0 → 当前值`；`误差: 0.693 → 当前值` |
| ③ 历史图 | `每次停手后的误差` | 横轴“调节次数”，纵轴固定 `0–4`；不标最低点，不给推荐方向 |
| 操作提示 | `试着让误差低于起点；也可以故意转错方向。` | 达到 `w=1.0, b=0.0` 时当前误差约 `0.220`，不作为目标提示预先显示 |

实时计算入口：对每条样本计算 `p = sigmoid(wx+b)`，再取四条二元交叉熵的平均值；预测、平均误差与历史点均由 `Lec.P` 当场计算，不写死结果。

## 交互

学习者分别旋转 `w`、`b`，范围均为 `−2.0～2.0`，步长 `0.1`，默认 `0.0`；支持拖动、方向键和加减按钮。任一参数变化时，四个预测点、当前误差、差值、差距尺和记录行立即更新；松手或键盘操作结束后向历史图追加一点。

页面只报告“比上次高/低多少”，不提示下一次应转哪个旋钮或哪个方向。按钮文字为`重置本页`，恢复 `w=0`、`b=0`、四个预测均为 `0.5`，历史仅保留起点 `0.693`。
