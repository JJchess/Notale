## 知识结构：process

**关系不变量**：从左到右保持一条单向更新链：旧参数与坡度读数 → 乘上学习率 → 从旧参数中减去 → 新参数与新误差；各数值同行、等宽、同基线，正负号不可拆离对应数字。

**共享原语**：`.canvas-full.k-process` 承载整条单步链；`.knob` 表示固定学习率，`.change-row` 并列记录改前与改后，末端 `.gap-ruler` 用同一刻度比较两次误差。

## 表征形式

交互式单步更新仪器：学生先在两个方向中选择一步，再看到算式补全、参数移动和误差尺下降。使用原生 DOM 与 SVG；关系简单且需保证公式、按钮和读数可访问，无需图表库。唯一短式使用 KaTeX。

## 主工作流

build-interaction ← 让一次方向选择立即产生可核查的参数与误差变化

## 一笔更新记录

| 位置 | 画面文字 | 值与状态 |
|---|---|---|
| 已知参数 | `旧参数 w` | `0.00` |
| 固定参数 | `偏置 b` | `0.00`，本页不可调 |
| 方向读数 | `坡度` | `−0.75` 误差/权重单位 |
| 步长 | `学习率` | `0.40` |
| 单行公式 | `新参数 = 旧参数 − 学习率 × 坡度` | KaTeX：`w_{\text{新}}=w_{\text{旧}}-\eta\times\text{坡度}` |
| 候选一步 | `向左：w = −0.30` | 选择按钮 |
| 候选一步 | `向右：w = 0.30` | 选择按钮 |
| 改前读数 | `w = 0.00　误差 = 0.693` | 页面显示 |
| 改后读数 | `w = 0.30　误差 = 0.496` | 选对后显示 |
| 算术展开 | `0 − 0.40 × (−0.75) = 0.30` | 选对后补全 |
| 即时反馈 | `负坡度被减去，所以参数向右走。` | 选对后显示 |
| 反向反馈 | `这一步走向上坡：换另一边试试。` | 选左后显示 |

误差由固定样本 `x=(-2,-1,1,2)`、`t=(0,0,1,1)` 等权计算；交互状态以候选 `w`、固定 `b=0` 调用 `Lec.P` 的预测与平均 BCE 计算入口，页面不硬编码推导结果。

## 交互

初始只点亮 `w=0`、坡度 `−0.75` 和学习率 `0.40`；“向左一步”“向右一步”均可用鼠标、触控或键盘选择。选择后，参数标签移到对应候选值，末端立即重算平均误差并更新差距尺。

选右时锁定本次完成态，突出减号与负坡度相消，显示完整算术和“改前 → 改后”；选左时保留旧误差作基线，同时显示较高的新误差与换边提示，不自动替学生改选。提供“重置本页”，恢复未选择状态。

## 动效

选择后，新方向箭头从公式区向候选参数延伸，位移约 120 px、时长 240 ms；随后参数标签移动 220 ms，误差尺在 260 ms 内变到新高度，三段错开 80 ms。减少动态模式下直接切换终态并保留箭头与数值差异。
