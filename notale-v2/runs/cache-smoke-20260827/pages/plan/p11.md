# page-11 · 十步训练记录 · **75 秒**

## 照这个写

| 元素 | 文字 |
|---|---|

| 收束句 | 训练不是一次跳到答案，而是反复留下“预测—误差—更新”的可检查记录。 |
| 下一问 | 误差不断下降，是否代表一个神经元什么形状都能学会？ |

## 知识结构：generalization

关系不变量：十一次读数按训练步数 `0→10` 共用同一横轴和误差纵轴；当前一步的参数记录、差距尺与曲线点必须同步，且“改前 → 改后”同行显示。

共享原语：`.k-generalization` 以“重复小改会形成下降记录”为主张，向下连接操作与两项证据；`.ledger` 将问题、操作、读数纵向排列；`.change-row` 固定呈现每一步的权重变化。

## 表征形式

交互式训练账本：上段给固定条件，中段提供逐步与连续执行按钮，下段并列参数流水账、当前误差差距尺和十步折线图。

折线图使用 ECharts SVG renderer，适合整数步数轴、可核对 tooltip 与投影缩放；训练状态由页面运行时调用 `Lec.P` 的公开训练循环接口生成，不硬编码中间点。

## 十步实验口径

| 画面项目 | 内容 |
|---|---|
| 样本 | `x=(-2,-1,1,2)`，`t=(0,0,1,1)`；四条等权 |
| 初始状态 | `步 0 · w=0 · b=0 · 平均误差=0.693147` |
| 固定设置 | `学习率=0.4`；本页只更新 `w`，`b` 固定为 `0` |
| 单步动作 | `做预测 → 算四条样本的平均误差 → 更新 w` |
| 曲线横轴 | `训练步数`，整数 `0–10` |
| 曲线纵轴 | `平均误差`，显示范围 `0.10–0.72` |
| 当前读数 | `步 n`、`w`、`平均误差`，分别保留整数、6 位、6 位小数 |
| 账本行 | `w：改前值 → 改后值`；右侧补记 `误差：改前值 → 改后值` |
| 结束状态 | `已完成 10 次更新`，曲线保留全部 11 个点 |

## 交互

默认停在步 0。学习者可按“走一步”逐条追加记录，也可按“连走十步”从当前状态自动运行，最多到步 10；运行中两按钮暂时禁用。

每次更新后，当前曲线点、参数读数、差距尺斜纹高度和账本行同时变化；已走过的点与线使用 `--model`，正在新增的点及箭头短暂使用 `--accent`。到步 10 后显示“十步完成：误差比起点更低”，不设置猜题式成败。

“重置本页”恢复步 0、`w=0`、空账本和仅含起点的曲线；刷新结果相同。

## 动效

“连走十步”每步用 260 ms：先点亮“预测”，再依次点亮“误差”“更新”，三段各错开 70 ms；新曲线点从上一点沿右下方向连入，账本新增行垂直下移 12 px 后归位。减少动态模式下直接更新全部状态，仅保留当前点轮廓。

## 核对

| 状态 | 期望权重 `w` | 期望平均误差 |
|---|---:|---:|
| 步 0 | `0.000000` | `0.693147` |
| 步 1 | `0.300000` | `0.495870` |
| 步 2 | 约 `0.526849` | 约 `0.38151` |
| 步 10 | 约 `1.3944` | 约 `0.1406` |

实现时由 `Lec.P` 按 `count=10`、上述样本、初始参数与学习率当场计算；逐步执行十次与一次连续执行的最终结果必须一致。
