## 知识结构：comparison

**关系不变量**：上区把两个输入汇入同一神经元；下区并排放置“改前”和“拖动后”两个同尺度坐标面，坐标范围、原点和分类侧标记完全一致，只有参数与直线位置不同。

**共享原语**：`.k-comparison` 负责两幅坐标面的同尺度对照，并落入 `.split-tb` 下半区；`.param` 标出三个会随拖动变化的参数，`.cvbox` 承载可裁切的二维分界面。

## 表征形式

交互式二维分界实验：上区显示双输入汇入神经元及分界条件，下区左侧固定初态、右侧允许平移和旋转直线，并同步更新参数读数。

使用 Konva 处理直线、拖拽手柄、裁切与命中检测；标题、参数、轴名、区域标签和操作提示使用 DOM 覆盖层。

## 主工作流

build-interaction ← 让平移、旋转和参数读数共同证明“参数会变，分界仍是直线”

## 分界对照

| 画面对象 | 固定文字或数值 |
|---|---|
| 输入汇合 | `x₁ × w₁`、`x₂ × w₂`、`再加 b` |
| 分界条件 | `w₁x₁ + w₂x₂ + b = 0  →  概率 0.5` |
| 显示常量 | `概率分界 = 0.5`，取自 `SIGMOID_VALUE_AT_ZERO` |
| 左图标题 | `改前` |
| 左图参数 | `w₁ = 0.00　w₂ = 1.00　b = 0.00` |
| 右图标题 | `拖动后` |
| 右图参数 | `w₁`、`w₂`、`b` 实时显示，两位小数 |
| 两图坐标 | 横轴 `x₁`、纵轴 `x₂`，范围均为 `−3～3`，等比例方格 |
| 分界标签 | 直线上标 `概率 = 0.5` |
| 两侧标签 | `概率 ≥ 0.5`、`概率 < 0.5` |
| 操作提示 | `拖直线可平移；拖端点可旋转。观察：它会移动、转向，但不会弯。` |

## 交互

右图默认与左图相同，为水平线 `x₂=0`。拖动线身时只沿其垂直方向平移；拖动端点时绕线中心旋转。直线方向角限制为 `0°～180°`，中心到原点的有符号距离限制为 `−2.5～2.5`，确保分界始终可见。

内部用单位法向量表示参数：若直线方向角为 `θ`，则 `w₁=−sinθ`、`w₂=cosθ`；有符号距离为 `d` 时，`b=−d`。每次操作立即重画两侧浅色区域并更新三个参数；当前手柄使用强调色，松手后恢复模型色。

键盘聚焦线身后，方向键每次平移 `0.1`；聚焦旋转手柄后，左右键每次旋转 `5°`。提供“重置本页”，恢复水平线与初始参数；本实验没有正确位置或成功反馈。

## 核对

| 参数 | 期望分界 |
|---|---|
| `w₁=0, w₂=1, b=0` | `x₂=0`，水平穿过原点 |
| `w₁=1, w₂=0, b=0` | `x₁=0`，竖直穿过原点 |
| `w₁=0, w₂=1, b=−1` | `x₂=1`，水平上移 1 单位 |

## 不许碰

本页只确认二输入单神经元的 0.5 分界始终为直线，不展示或暗示多层网络怎样形成弯曲边界；隐藏特征组合与非直线分类归 p16。不要在本页使用异或四点检验，单直线在异或上的失败证据归 p15。
