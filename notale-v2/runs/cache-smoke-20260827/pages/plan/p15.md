## 知识结构：comparison

**关系不变量**：四个样本固定在同一坐标系、同一尺度和同一基线上；同一条直线把画布分成“预测 0”和“预测 1”两侧。右侧四行读数必须与四个点逐一对应，同时比较正确类别、当前预测和对错。

**共享原语**：`.k-comparison` 统领“同一条线下四个样本的结果比较”；`.cvbox` 承载占据主画面的二维挑战区；`.sample` 统一四个固定样本的形状，`.tag` 承担当前得分与历史最好成绩。整体落入 `.canvas-full`，挑战区约占宽度 72%，结果列约占 28%。

## 表征形式

交互式二维分类挑战：学生拖动、旋转一条直线，观察两侧预测区域、四点判定和得分同步变化。

使用 Konva 处理直线、端点手柄、拖拽与命中检测；所有标签、按钮和实时读数使用 DOM 覆盖，保证投影字号与键盘可达性。

## 四个样本与读数

| 样本 | 坐标 | 正确类别 | 画面标记 |
|---|---:|---:|---|
| A | `(-1, -1)` | `1` | 黑色方形，内写 `1` |
| B | `(-1, 1)` | `0` | 空心方形，内写 `0` |
| C | `(1, -1)` | `0` | 空心方形，内写 `0` |
| D | `(1, 1)` | `1` | 黑色方形，内写 `1` |

| 读数 | 画面文字 |
|---|---|
| 当前成绩 | `当前分对：2 / 4`，随操作更新 |
| 最好成绩 | `本轮最好：2 / 4`，只增不减 |
| 区域标签 | `预测 0`、`预测 1` |
| 初始提示 | `拖动直线或两端手柄，试着分对全部四点。` |
| 达到上限 | `3 / 4：只剩一个错点。你能让它也正确吗？` |
| 再次换错点 | `错点换了，但仍至少有一个。` |
| 揭示结论 | `这四点的一条直线分类上限是 3 / 4。` |

坐标范围固定为横纵轴 `-1.6～1.6`，只标 `-1、0、1`。正确类别不用主色；主色仅填充当前“预测 1”区域，并叠加稀疏斜纹，另一侧标为“预测 0”。

## 交互

默认直线为 `x=0`，初始分对 `2/4`。学生可拖动线身平移，拖动两个直径不小于 28 px 的端点旋转；直线始终延伸到绘图区边缘。键盘聚焦线身后，方向键平移，聚焦端点后方向键旋转；每次按键对应约 `0.05` 坐标单位或 `2°`。

每次变化立即重绘预测区域，并更新四行“正确类别 → 当前预测 → 对/错”、当前成绩与本轮最好。首次达到 `3/4` 时显示上限追问；此后若通过移动直线让另一个样本成为错点，显示“错点换了”反馈并揭示结论。不得出现 `4/4` 成功态。

提供按钮 `重置本页`，恢复 `x=0`、`2/4`、最好成绩 `2/4` 和未揭示状态。

## 核对

内部判定可用 `s=x·cosθ+y·sinθ-d`，`s≥0` 预测为 `1`，该公式不印在画面上。

- `θ=0°，d=0`：预测按左右分区，结果必须为 `2/4`。
- `θ=45°，d=1.4`：仅 `(1,1)` 预测为 `1`，结果必须为 `3/4`。
- 任意有效直线对四个固定样本的结果不得超过 `3/4`；边界穿过样本时统一按 `s≥0` 归入预测 `1`。

## 不许碰

不展示两个隐藏神经元如何拆分区域，也不画多条门或合成非直线边界；这些属于 p16。本页只检验单条直线在异或四点上的失败，不讲这些参数如何训练，训练方法归 p18。
