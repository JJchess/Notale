## 知识结构：comparison

关系不变量：三个学习率模型必须从相同参数、相同数据和相同样本顺序出发，训练步数同步；损失曲线同行并共享横轴、纵轴和零基线。左侧决策场只显示当前选中的一档，但步数与右侧对应行严格相连。

共享原语：`.k-comparison` 在 `.canvas-full` 中形成“左侧共同证据—右侧三档同行读数”的唯一主几何；`.cvbox` 承载实时决策场与曲线；`.btns` 将播放、单步和重置保持为一组实验控制。

## 表征形式

动态交互式训练控制台：左侧为二维样本、实时概率热力场和 `0.5` 决策边界，右侧为三档学习率的同步损失轨迹、准确率与训练步数。

训练使用本地 `mlp.js`；热力场用原生 Canvas，损失曲线使用 ECharts SVG renderer，控制与数值读数使用原生 DOM。

## 主工作流

build-chart ← 同步训练三个真实网络，并把参数变化转成可核对的边界、曲线和读数

## 训练配置

| 项目 | 画面文字或真实值 |
|---|---|
| 数据 | `200 个固定样本` |
| 数据生成 | 种子 `19019`；四个中心 `(-1,-1)、(-1,1)、(1,-1)、(1,1)` 各 50 点，横纵坐标分别加 `U(-0.45, 0.45)` 抖动；对角同类 |
| 类别图形 | 类别 0：空心方块；类别 1：实心圆点 |
| 网络 | `2 → 10 → 10 → 1` |
| 输出与误差 | sigmoid 输出；二元交叉熵 |
| 批量 | `16 样本 / 次更新` |
| 播放速度 | `12 次更新 / 动画帧` |
| 决策场 | `80 × 80` 网格；每 8 帧重算 |
| 判定 | 输出 `≥ 0.5` 记为类别 1 |
| 横纵范围 | `x₁、x₂：-1.6 至 1.6`，保持等比例 |
| 三档步长 | `慢 0.03`；`合适 0.3`；`过大 30` |
| 动态读数 | `更新次数`、`平均误差`、`准确率` |
| 行内提示 | `慢慢下降`；`形成四块区域`；`可能长期约 50%` |

三个网络使用相同的固定参数种子 `19020` 和相同批次顺序；这些种子只用于实现与复现，不作为主讲文字。

## 交互

默认停在更新次数 `0`，三档同时初始化但不自动播放。学习者可按“开始训练 / 暂停”“训练 1 帧”“重置网络”，并点选 `0.03`、`0.3`、`30` 查看对应决策场；当前档使用强调色外轮廓。

播放时三档同步接受相同批次，各自按学习率更新参数；损失曲线、准确率和步数立即变化，左侧边界按规定频率重画。鼠标或键盘聚焦任一曲线点时，显示该步的学习率、平均误差和准确率。

“重置网络”恢复相同初始参数、批次顺序和步数，不重新生成数据；刷新后同样回到统一初态。交互不设置胜负，目标是观察相同步数下三种步长造成的不同训练轨迹。

## 动效

每个训练帧只推进曲线端点和数值滚动；边界更新在 160 ms 内替换，不做粒子或生物电式回传。选档时左侧热力场交叉淡入 120 ms；减少动态偏好下取消过渡，但保留逐帧训练与暂停。

## 核对

1. 重置后：三档更新次数均为 `0`，初始参数、平均误差、准确率和决策场完全一致；数据点坐标始终不变。  
2. 连续播放 1 帧：每档完成 `12` 次参数更新，共读取 `12 × 16 = 192` 个样本位置；第 8 帧后每档恰完成一次新的 `80 × 80 = 6400` 点场预测。  
3. 固定种子验收至 240 帧：`0.3` 应形成四块分类区域且准确率至少 `0.90`；`0.03` 同步数下下降更慢；`30` 不得出现 `NaN/Infinity`，准确率应长期落在约 `0.45–0.55`，不得伪造成稳定收敛。

## 不许碰

不介绍 Adam、动量、学习率调度或其他优化器；本页只比较 `0.03、0.3、30` 三档步长。不要重新推导单次更新规则（归 p10）、训练循环概念（归 p11）或反向传播责任分配（归 p18）。
