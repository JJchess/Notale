## 1. 这堂课在讲什么

这堂课讲：一杯咖啡不是“某国咖啡”这个标签的结果，而是生长、采收、处理、烘焙、贸易与冲煮中一连串取舍的结果。改动一个环节，会同时改变风味、资源使用、成本、可售产量与产地收入。

I（01–03）让学生看见从种子到杯子的链条。  
II（04–07）说明产地名称不是风味公式；环境、品种、采收和处理条件共同作用。  
III（08–12）追踪果实变成可冲煮咖啡时的物料变化、筛选与损耗。  
IV（13–18）让学生调产地、处理法和烘焙度，比较风味、成本、收入与环境结果。  
V（19–22）要求评价时说明目标、约束、数据来源与不确定性。

证据链必须能支持四项结论：  
E1：风味起点是环境、品种与采后处理的组合。  
E2：果实到烘焙豆有连续筛选与损耗；处理和烘焙改变风味与可售产量。  
E3：杯价不等于产地收入；收入受产量、损耗、采购价、质量溢价与合同影响。  
E4：环境足迹分布在种植、加工、运输、烘焙、冲煮；重要环节取决于条件。

只做本页规定的任务。不许碰的内容由别页负责：不得提前讲完后页结论、重复前页互动、替后页下判断，或补写本页规格未要求的知识。

## 2. 颜色语义

| token / 色相 | 唯一含义 | 允许出现的位置 |
|---|---|---|
| `--bg` / 暖白 `#F6F1E7` | 纸张式阅读底面，无知识含义 | 页面背景、大留白区 |
| `--coffee` / 深咖啡棕 `#5A351F` | 可追溯的咖啡物料流 | 果实、豆、袋、杯，以及同一物料链的实线、箭头、路径 |
| `--amber` / 琥珀黄 `#F2A900` | 当前要操作、预测或教师指向的注意点 | 当前控件、待预测位置、单一讲授焦点、短暂状态提示 |
| 中性色 | 非语义结构与阅读层级 | 文字、边框、刻度、容器、背景分区、非咖啡物料图形 |

语义色不得挪作装饰、章节配色或随机分类色。圆角矩形只表示可选择环节；直角标签只表示测量值或证据。实线箭头表示物料流，虚线箭头表示价格或信息流。比较不以面积大小暗示未经计算的数量。

## 3. 知识结构——骨架约定

容器不是知识关系，不以“卡片网格”或“左右两栏”代替结构。

| 结构 | 必须直接看见的关系 | 最低几何要求 | 失败形态 |
|---|---|---|---|
| process | 先后、因果或状态推进 | 可见方向轴、箭头或连续路径 | 只有并排块 |
| comparison | 同一维度上的差异 | 同行、同尺度、同基线 | 两边各画各的 |
| classification | 上下位或部分—整体 | 嵌套、包含或明确缩进 | 同级平铺 |
| generalization | 主张与支撑 | 主张更重，支撑挂在同一主干 | 主张和证据同权 |

优先使用 `theme.css` 的 `.k-*` 原语组织流程、比较、分类和主张—证据关系；SVG、Canvas 或图表可替代这些原语。硬要求不是类名，而是关系必须在画面上成立、可被直接读出。每页保留至少一条宽留白带供教师口头解释。

## 4. 交互的规矩

- 同一个关系只使用一种主要交互路径，不用多个控件重复同一结论。
- 教学常量、范围、初值和结果来自 `Lec.K` / `Lec.P` 并当场计算；禁止预录结果、假数据或只改显示不改计算。
- 随机过程必须固定种子；首屏静止状态已包含可讲信息。
- 交互页必须给出明确操作提示。
- 滑块、切换和游标是观察仪器；没有目标态时不得编造对错。只有分拣、配对、拼装等本来有答案的任务才判定正确性。
- 未规划交互的页面不要添加装饰性操作。
- 01、03、07、12、22 无交互；不得加入可操作控件。
- 交互结果应同时保持可比较的风味、成本、产地收入或环境指标基线；不能把不同口径混在同一比较中。

## 5. 技术契约

固定骨架：

    <!doctype html>
    <html lang="zh">
    <head>
      <meta charset="utf-8">
      <link rel="stylesheet" href="assets/base.css">
      <link rel="stylesheet" href="assets/theme.css">
    </head>
    <body data-page="NN" data-total="22">
      <div id="stage"></div>
      <script src="assets/base.js"></script>
      <script src="assets/lec.js"></script>
    </body>
    </html>

- 只修改 `#stage` 内容；保留两位 `data-page` 和 `data-total`，不把页码显示给读者。
- 逻辑画布固定 1600 × 900，不得滚动。`#stage` 是 flex 列；顶层区块给固定高度或 flex 份额，主内容区使用 `flex:1`。
- 字号只用主题 token。正文与成句说明 ≥16px；控件标签、图例、图注和提示 ≥14px；纯数字刻度 ≥12px；多行文字行高 ≥1.35。
- 颜色、字体、圆角、阴影和共享组件取自主题接口。一次性尺寸可内联，不为单页尺寸造公共类。
- 不移除或覆盖 `.min0`、`.cv-fill`、`.no-pan` 的机制；缩放画布内禁止 `position:fixed`。
- 默认用 flex；只有真正二维对齐时用 grid。自包含运行，只引用 `pages/` 内相对路径，不用 CDN。
- 图表优先使用已安装库，不重复实现成熟能力。ECharts 必须使用 SVG renderer，并显式设置可读字号。
- Canvas 使用 `Deck.fit()` / `Deck.autofit()`；指针坐标使用 `Deck.pt()`；动画使用 `Deck.loop()`。
- 计算使用 `Lec.P`：`brewRecipe`、`coffeeMassFlow`、`extractionYield`、`lifeCycleFootprint`、`servingsFromCoffee`、`transportEmissions`、`waterFootprint`、`waterHeatingEnergy`；常量使用 `Lec.K`。

| 用途 | 库 |
|---|---|
| 常规坐标图表 | `echarts.min.js` |
| 拖拽与命中二维场景 | `konva.min.js` |
| 节点、连线、精确 SVG | `d3.min.js` |
| 物理运动与碰撞 | `matter.min.js` |
| 三维场景 | `three.min.js` |
| 分步或时间线动画 | `anime.min.js` / `gsap.min.js` |
| 可复现随机 | `seedrandom.min.js` |
| 数学公式 | `katex.min.css` + `katex.min.js` |
| 矩阵计算 | `ml-matrix.umd.js` |

ECharts 初始化必须为 `echarts.init(el, null, {renderer:'svg'})`；全局文字 ≥16px，带词句的轴标签、图例和轴名 ≥14px，纯数字刻度才可为 12px。Konva 图形可用 Canvas，场景文字优先用 DOM 叠层；若必须用 `Konva.Text`，显式设置字号。KaTeX 复杂分式或上下标公式基准字号 ≥20px。随机调用 `new Math.seedrandom('page-NN')` 或等价固定种子。

## 6. 图片

优先使用 `assets/img/IMG.md` 已登记素材，不重复下载或生成。按索引填写 `<img title="…">`；`title` 写素材所承担的证据或对象，不写空泛装饰词。出处和许可不进入主画面。生成插画的“AI生成”角标不得被内容遮挡。照片遵循主题既有边框、圆角和底图规则；照片只承载观察或证据，不把产地包装成旅行海报。

## 7. 文字风格

面向无农学、贸易、编程基础的大学生。术语首次出现时用短句解释；不堆叠未解释缩写、贸易行话或化学术语。讲课句短，优先“改动什么—看到什么—为什么有关”。

提示口吻直接、可操作：如“拖动处理法，比较两条结果线”“先预测，再看计算结果”。不用命令式羞辱、营销语或伪精确承诺。删除“如图所示”“接下来我们将”和评价教学设计的元评论。

关键数字给可感换算；例如质量、杯数、水量、距离或价格需说明比较口径。不确定结论明确标注数据来源、条件、范围或“示例估算”。收束句只给可带走的主张；下一问负责推进，不写本页摘要。

## 8. 自检

完成后用 `Check` 检查本页：JS 错误、资源失败、越界、裁切均为 0，字号符合分层地板。交互页必须覆盖每个主要状态，包括初值、范围端点、切换项、拖拽成功与失败状态。问题区域先用 `Look` 查看，再用 `Patch` 合并修复。

最终只交付本页 HTML，不改公共资源，不增加测试或报告文件。

## 9. 版面密度与常见坑

- 主内容用 flex 吃满剩余空间，不给普通内容块写死高度。
- 画面占用低于 45% 时，检查失控的 flex 空隙并放大有教学意义的关系；不要加装饰撑满。
- 画面占用高于 85% 时删减，或报告需要拆页；不缩字号、不压行高。
- 骨架和包裹层优先用线、缩进、路径和层级表达，不堆叠多层填色卡片。
- 每页至少保留一条宽留白带；不要用深色背景、热带风景、国旗、行情终端元素填充。
- 所有并列比较保持同一基线、同一单位和相同视觉权重；未经计算的量不得用面积、豆子数量或照片大小暗示。
- Canvas 交互区加 `.no-pan`；可操作元素与静态证据视觉上明确区分。
