# page-02 · 标签不等于风味 · **45 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `BLIND PREDICTION · 01` |
| 主标题 | 只看产地标签，你其实猜不准杯中风味 |
| 收束句 | “埃塞俄比亚”或“哥伦比亚”是信息的起点，不是风味的可靠答案。 |
| 下一问 | 如果国名不够，产地里还有哪些条件值得看？ |

## 知识结构：comparison

1. **关系不变量**：左右两张产地标签卡必须同宽、同高、同一组风味选项、同一投票基线；两边都通向同一句反馈。
2. **禁止画法**：不得把任一国家配上默认风味图标、风味雷达或更醒目的“代表性风味”，暗示标签本身能预测结果。
3. **共享原语**：`.split-lr` 承载左右并列猜测；`.k-comparison` 锁定两张等尺度标本卡与对齐选项；`.quiz`、`.opt`、`.fb` 让投票与共同反馈成为一条关系。

## 表征形式

交互式双栏盲猜投票：左、右各为一张直角批次标签，学生分别为两个标签选择自己预测的风味，或选择“不足以判断”。原生 DOM 更合适，无需图表库；用按钮的选中态与 `.fb` 更新反馈。键盘以 Tab 聚焦、Enter/Space 选择；每组使用 `role="radiogroup"`，选项使用原生 radio 输入与可见标签。选择后立即更新该栏反馈；两栏都作答后点亮底部共同结论。

## 主工作流

design-interaction ← 两个并列盲猜状态与不把刻板印象误作答案的即时反馈

## 不许碰

本页只制造“国名标签不足以预测风味”的认知冲突，不解释海拔、品种、采收或处理法为何会改变结果；变量来源归 p04–06。不得给两国贴固定风味、质量或价值等级。

## 两张盲猜标本卡

| 区域 | 画面文字 | 选项与状态 |
|---|---|---|
| 左卡标签 | `样本 A` / `产地标签：埃塞俄比亚` / `其余信息：未提供` | `花香、柑橘感`；`坚果、巧克力感`；`不足以判断` |
| 右卡标签 | `样本 B` / `产地标签：哥伦比亚` / `其余信息：未提供` | `花香、柑橘感`；`坚果、巧克力感`；`不足以判断` |
| 任一风味选择后的栏内反馈 | `这是一个猜测，不是由国名推出的结论。` | 显示于对应卡片底部 |
| 选择“不足以判断”后的栏内反馈 | `对：仅凭这一张标签，证据还不够。` | 显示于对应卡片底部 |
| 双栏完成后的共同反馈 | `两张标签都遗漏了决定原料可能性的关键信息。先别把国家名当成风味公式。` | 琥珀黄细线框，仅在双栏均已选择后出现 |
| 底部提示 | `先投票，再看结论。没有唯一“猜对”的风味。` | 初始可见 |

## 交互

默认两组均未选。学习者可在每张卡的三项中各选一项；改选立即替换该卡反馈，不记录分数、不判定风味猜测为对或错。两组均完成时显示共同反馈，并将主标题下的细短线由深咖啡棕切换为琥珀黄，形成“标签信息不足”的直觉。提供 `重新投票` 按钮：清空两组选择、隐藏共同反馈、焦点回到样本 A 的第一项。教师可邀请学生举手后统一点击任意选项演示；学生课后可独立完成。

## 动效

首次进入时左右标本卡从各自外侧平移 `16px` 并淡入，时长 `220ms`、错开 `80ms`；共同反馈从下方上移 `8px` 并淡入 `160ms`。`prefers-reduced-motion` 时直接显示终态。
