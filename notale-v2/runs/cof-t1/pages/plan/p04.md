# page-04 · 产地是一组条件 · **80 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `ORIGIN RECORD 01` |
| 主标题 | 产地不是国名标签，而是一组生长条件 |
| 收束句 | 同一个国名之下可以有不同的温度、降雨、海拔与品种组合。 |
| 下一问 | 在这些条件中，海拔改变的究竟是什么？ |

## 知识结构：classification

1. **关系不变量**：每个地图点必须连接到同规格的“生长条件记录卡”；四项条件始终按温度、降雨、海拔、品种的固定顺序并列，不把国名放在条件之上。
2. **禁止画法**：不得把国家轮廓涂成单一风味色块，或让地图面积、点大小暗示产量、品质或重要性。
3. **共享原语**：`.canvas-full` 容纳左侧示意地图、右侧嵌套记录卡与底部教师留白；`.k-classification` 用“国家／示例产区／条件记录”的缩进归属，说明国名只是记录入口；`.panel` 承载可切换的标本卡读数。

## 表征形式

交互式二维示意地图加条件记录卡，不绘制统计地图。原生 DOM + SVG 更合适：SVG 路径只提供大陆方位和四个可聚焦点位，避免伪精确边界；条件读数使用 DOM 更新。

地图点使用按钮语义，`aria-pressed` 标识当前样本；点选后切换记录卡文本、点位琥珀高亮和连接线。键盘 Tab 聚焦、Enter/Space 选择；无障碍替代为同内容的四个文本按钮。初始为“全部样本”，只显示四张缩略记录；减少动态效果时立即切换，不使用路径移动动画。

## 主工作流

design-interaction ← 将地图点选变成“国名—条件集合”的可逆观察，而非产地竞猜

## 不许碰

不解释日晒、水洗或其他处理法及其风味差异；处理法归 p09–10。不要宣称任何国家、海拔或品种天然“更好喝”；海拔条件的具体影响归 p05。

## 交互

学习者点选四个地图点，或用记录按钮切换。默认“全部样本”：四个点为深咖啡棕，右侧显示四张缩略卡，并提示“先比较条件，再猜结果”。

选中任一点后，该点及其到右侧卡片的实线连接变为琥珀黄；右侧展开该产区的四项条件，其他三项缩为仅国名与产区名的标签。底部同步出现句子：`“埃塞俄比亚”描述的是地点；这张卡描述的是这个示例农场可能面对的条件。`

再次点选当前点或按“查看全部样本”回到默认状态。没有正确答案；应形成的直觉是：国名相同不等于条件相同，条件相近也不等于最终杯中结果相同。

## 画面

暖白整页画布中央以一条从左至右的宽留白带分隔地图与记录卡，留白带下方保持空白，供教师指向并口头补充“同国也有微气候差异”。

左侧为低对比、无国旗无国界填色的世界方位线稿；四个点位只用编号 `01–04` 与短国名。右侧为一张展开的直角“批次条件记录卡”，四个条件按等高横行排列，数值用等宽字体。地图点至卡片的线只表达“此记录属于此地点”，不表达贸易或物料流。
