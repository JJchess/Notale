## 知识结构：comparison

1. **关系不变量**：左右两列必须共享四条水平对照行、同一行高与同一“通常而言”口径；中间的配对卡只能归入对应列。
2. **禁止画法**：不得把水洗和日晒画成前后相接的加工步骤，或用奖杯、星级暗示其中一种天然更优。
3. **共享原语**：`.split-lr` 承载两种处理法；`.k-comparison` 用对齐行呈现取舍；`.panel` 承载可移动的特征卡与即时反馈。

## 表征形式

交互式双列处理法对照表：左侧水洗、右侧日晒；每列以果实接触、杯中倾向、用水条件、干燥失败风险四行比较。原生 DOM 更适合短文本对齐、键盘配对与状态切换，不需图表库。每个特征卡通过 `setOption(process)` 写入 `washed` 或 `natural` 状态，立即更新列内琥珀边框、反馈句与底部收束句；支持点击选择后点击目标列，及拖放操作。

## 主工作流

design-interaction ← 让“配对”反馈的是条件性取舍，而非背诵处理法标签

## 不许碰

不讲浅、中、深烘如何改变酸甜、焦糖感、苦感或烘焙失重；这些归 p11。本页只比较处理阶段的取舍，不延伸到冲煮配方。

## 四行处理法对照

| 对照行 | 水洗 | 日晒 |
|---|---|---|
| 果实与种子的接触 | 果皮、果肉较早移除 | 果实与种子接触更久，再干燥 |
| 杯中常见倾向 | 较清晰、较洁净的风味轮廓 | 较突出的果香；发酵感风险也更高 |
| 加工条件 | 通常需要较多清洗用水；废水须处理 | 较少依赖清洗水；需要稳定天气与干燥空间 |
| 主要失败风险 | 清洗与发酵控制不当会留下异味 | 干燥太慢或不均，霉变与不良发酵风险上升 |

| 画面固定提示 | 文字 |
|---|---|
| 行首标签 | `通常倾向，不是每一批咖啡的保证` |
| 底部证据标签 | `结果受成熟度、天气、设备与管理共同影响` |
| 来源短标 | `ICO 加工资料；课堂比较模型` |
| 完整来源 | `International Coffee Organization，coffee processing materials；课堂整理。` |

## 交互

初始时四张琥珀描边特征卡置于两列之间：`较多清洗用水`、`果实接触更久`、`较洁净的风味轮廓`、`稳定干燥条件很关键`。学习者将卡配到“水洗”或“日晒”。

配对正确时，卡片吸附到相应列的对应行，显示该行的条件说明；配错时卡片回到中间并显示“这不是绝对标签：请看它依赖的是水，还是干燥条件。”四张完成后，中间出现“没有赢家：你正在比较不同约束下的选择。”点击 `重新配对` 恢复初始顺序；键盘可用 Tab 聚焦、Enter 选卡、方向键选列、Enter 放置。
