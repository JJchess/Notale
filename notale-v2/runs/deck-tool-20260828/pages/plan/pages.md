本套无需图池

# page-01
标题写“神经网络是怎么学会的？”，副题写“从一个神经元到反向传播”，开场要让学生相信“学习”不是机器突然理解，而是反复调小错误；用 `.focus` 放一条占据画面中心的粗过程线“猜一次 → 看差多少 → 调一点 → 再猜”，四步分别配简洁的神经元、靶心、旋钮和回环线图标，预测用模型蓝、误差与调节用注意橙、样本用数据绿，底部只留一句“30 分钟后，你能亲手让一个小网络学会分类”。静态首帧即可，不讲生物神经科学，也不讲大型语言模型，它们只在第 20 页迁移。

# page-02
标题写“先做一个三秒判断”，要暴露学生已有的“规则”直觉；左侧显示散点坐标图，横轴“学习小时数”，纵轴“睡眠小时数”，固定四个数据点为 (1,5) 未通过、(2,6) 未通过、(4,7) 通过、(5,6) 通过，图例明确“通过/未通过”，右侧 `.quiz` 问“新同学 (3,6.5) 会通过吗？”，提供“通过”“未通过”“信息不足”三个可点选项，点击只记录选中并显示反馈“你刚才也在做：看输入，给输出；接下来把这件事写成可调的机器”，不判定唯一正确答案；图用 SVG 或 D3 7.9.0，坐标和标签为 DOM，禁止 ECharts 以免这页的少量点被图表框架喧宾夺主。本页不解释边界怎么来的，那归第 7 页。

# page-03
标题写“一个神经元：先加权，再做决定”，要让读者看见单个神经元不是微型大脑而是一条算式；用 `.split`，右侧为大型线路图，两个输入“学习小时 x₁”“睡眠小时 x₂”分别经过标为“权重 w₁”“权重 w₂”的线，在求和圆点与“偏置 b”汇合，输出“分数 z”，左侧用 KaTeX（同时引入 CSS 与 JS，基准字号至少 24px）显示 `z=w_1x_1+w_2x_2+b`，并列出实际例子 `x₁=3, x₂=6.5, w₁=1, w₂=0.2, b=-4`，逐项算出 `z=3+1.3-4=0.3`。线路按输入到输出依次显现，但首帧已显示完整淡线；本页不加入激活函数，阈值归第 4 页。

# page-04
标题写“把分数压成 0 到 1”，要让学生接受 sigmoid 只是平滑的“开关”；用 `.compare`，左侧画硬阈值阶梯“z<0 输出 0，z≥0 输出 1”，右侧画 sigmoid 曲线并用 KaTeX 显示 `p=σ(z)=1/(1+e^{-z})`，在 `z=0.3` 处标出 `p≈0.574`，下方直白写“可读作：模型给出约 57.4% 的通过倾向，不等于真实概率保证”；提供一个 z 滑杆，范围 -6 到 6、步长 0.1，实时移动两图游标和 p 读数，复位到 0.3，图线用 SVG/D3，所有文字用 DOM。本页只形成平滑输出直觉，不推导指数函数，也不谈损失。

# page-05
标题写“权重决定‘看重什么’”，要靠操纵建立参数含义；使用 `.lab`，主区仍是“学习小时数—睡眠小时数”坐标，固定输入点为 (3,6.5)，控制区给 w₁、w₂ 两个滑杆，范围 -2 到 2、步长 0.1，偏置固定 b=-4，并实时显示 `z` 与 `p=σ(z)`；拖动某个权重时，对应输入连线同步变粗或变细，负权重改为虚线并显示“反向影响”，按“复位”回到 w₁=1、w₂=0.2。要明确写“权重大：这个输入对分数影响大；正负号：影响方向”，不把粗线直接说成重要性的因果证明，也不在本页改变偏置，偏置归第 6 页。

# page-06
标题写“偏置像一只整体平移旋钮”，要把偏置与权重区分开；用 `.split`，左侧坐标中显示直线 `w₁x₁+w₂x₂+b=0`，采用 w₁=1、w₂=-1，右侧只有 b 滑杆，范围 -4 到 4、步长 0.1，拖动时分类直线保持斜率不变而平行移动，并同步显示方程从 `x₁-x₂+b=0` 更新；固定三个样本 (2,5)、(4,3)、(6,5) 用数据绿点，线两侧淡标“输出偏 0”“输出偏 1”。底部结论写“权重转方向，偏置挪位置”，复位 b=0；不介绍二维边界的训练来源，那归第 7 页。

# page-07
标题写“一个神经元能画出一条分界线”，要把代数式与几何边界扣在一起；使用 `.board`，左侧用 SVG 展示方程 `w₁x₁+w₂x₂+b=0` 对应的直线，沿法向画权重箭头 `(w₁,w₂)`，右侧以 `.k-generalization` 强调主张“单个神经元只能做线性切分”，支撑写“线的一侧 z>0”“另一侧 z<0”“sigmoid 只把两侧变平滑”；提供三个按钮“转动 w”“移动 b”“恢复”，前两者触发一次清晰的预设变化而非自由滑杆，避免重复第 5、6 页的交互。本页不说好坏标准，错误度量从第 8 页开始。

# page-08
标题写“怎样知道猜得有多差？”，要让学生从单个样本看懂损失；用 `.focus` 放一个水平概率尺 0 到 1，目标固定为 `t=1` 的数据绿旗，模型预测游标可拖动，初始 `p=0.20`，旁边实时显示二分类交叉熵 `L=-[t\ln p+(1-t)\ln(1-p)]` 与当前 `L=-ln(0.20)≈1.609`；拖到 p=0.80 时显示 `L≈0.223`，p 限制在 0.01 到 0.99 以避免无穷，KaTeX 基准 24px。尺下写“目标为 1 时，越自信地猜 0，惩罚越大”，并有“目标切换 0/1”按钮与“复位”；不推导为什么选交叉熵，也不计算整批平均，那归第 9 页。

# page-09
标题写“训练目标：让一批样本的平均损失下降”，要从单例过渡到数据集；使用 `.k-comparison` 同行列出四个固定样本的目标与预测：A `t=1,p=0.8,L=0.223`，B `t=1,p=0.6,L=0.511`，C `t=0,p=0.3,L=0.357`，D `t=0,p=0.7,L=1.204`，底部用 KaTeX 算 `\bar L=(0.223+0.511+0.357+1.204)/4≈0.574`，并用注意橙圈出 D 是当前最大损失；点击任一行会在旁边概率尺上解释该行，但不改变数据。主张写“训练不是保证每题都对，而是寻找让平均损失更小的参数”，不讲参数如何移动，坡度归第 10 页。

# page-10
标题写“调哪边？先看坡度”，要用身体化的斜坡直觉引出梯度；用 `.lab`，主画面是损失随单一权重 w 变化的 U 形曲线，明确声明这是“为建立直觉的单参数示意”，当前位置 w=-1.5、损失 L=2.25，最低点 w=0、L=0，读数区显示局部斜率 `dL/dw=-3.0`；学生拖动 w，切线和斜率实时变化，点击“沿负梯度走一步”按 `w←w-η(dL/dw)`、η=0.2 更新一次，从 -1.5 到 -0.9，损失从 2.25 到 0.81，动画沿曲线移动，复位回 -1.5。KaTeX 公式基准 24px；不声称真实神经网络损失总是 U 形，学习率归第 11 页。

# page-11
标题写“步子太小、合适、太大”，要让学生亲眼看到学习率只控制更新幅度；使用 `.compare` 但分成三个同尺度小图，均从 w=-1.5 在 `L=w²` 上迭代 8 步，按钮选择 η=0.05、0.2、1.1 后点击“跑 8 步”，分别显示“慢慢靠近”“快速靠近”“来回越跳越远”，数值按 `w_{k+1}=w_k-2ηw_k` 实时计算而非预录；图下显示最终值：η=0.05 时 `w₈≈-0.646, L≈0.417`，η=0.2 时 `w₈≈-0.0252, L≈0.000635`，η=1.1 时 `w₈≈-6.450, L≈41.60`，并注明四舍五入。颜色只用模型蓝轨迹与注意橙当前点，不用红绿评价；本页不介绍多参数梯度，归第 12 页。

# page-12
标题写“参数很多时，梯度是一组方向提示”，要把一维坡度推广为向量而不增加线性代数负担；用 `.board`，左侧等高线图横轴 w₁、纵轴 w₂，当前位置 (-1.2,1.0)，显示梯度箭头 `∇L=(∂L/∂w₁,∂L/∂w₂)` 与相反方向的更新箭头，右侧用 KaTeX 写 `\mathbf w\leftarrow\mathbf w-\eta\nabla L`，并用日常语言分三行解释“每个参数各有一个坡度”“合在一起叫梯度”“沿反方向通常会下坡”；点击“走一步”让点沿预设二次损失 `L=w₁²+2w₂²` 的真实梯度、η=0.15 更新，所有数值现场计算，复位恢复初值。不推导偏导定义，链式法则归第 15 页。

# page-13
标题写“一个神经元做不到这道题”，要制造引入隐藏层的必要性；使用 `.split`，右侧呈现 XOR 四点：(-1,-1) 与 (1,1) 标为类别 1，(-1,1) 与 (1,-1) 标为类别 0，左侧问题写“能用一条直线把两类完全分开吗？”，提供“试画直线”交互：在图中拖动直线的角度与位置，每次实时显示准确数 `/4`，并有“我认为不可能”按钮；点击后系统以角度 0–179°、偏置范围覆盖点集的确定性枚举给出证据“最佳也只能分对 3/4”，而不是只宣告答案。结论写“一条直线不够，需要组合多条边界”，不在本页画完整多层网络，它归第 14 页。

# page-14
标题写“隐藏层：先造出中间特征”，要让学生看见多神经元的组合能力；用 `.flow`，上部是一张 2→2→1 网络线路图，输入 x₁、x₂ 连接两个隐藏神经元 h₁、h₂，再连接输出 p；点击 h₁ 时，右侧小坐标高亮它产生的半平面，点击 h₂ 显示另一半平面，点击“合起来”显示两者交叠形成可分的区域，线路与区域都现场由预设权重计算，标签明确“隐藏：不是人工命名的概念，只是网络内部的数值”；底部过程骨架写“输入 → 两个中间判断 → 组合输出”。本页只解释表达能力，不讨论这些权重怎样找到，反向传播从第 15 页开始。

# page-15
标题写“反向传播的核心：误差沿计算链往回分配”，要把术语落到链式法则而不做繁琐推导；使用 `.k-process` 横向展示前向链 `x → z=wx+b → p=σ(z) → L`，上方模型蓝箭头标“前向：算预测”，下方注意橙箭头反向依次标 `∂L/∂p`、`∂p/∂z`、`∂z/∂w`，中央用 KaTeX 显示 `∂L/∂w=(∂L/∂p)(∂p/∂z)(∂z/∂w)`；点击“前向”按从左到右逐站点亮，点击“反向”按从右到左点亮且在 w 旁出现“该调多少”，首帧仍保留完整静态路径，复位可重复。只要求读懂“局部影响相乘”，不要求手算 sigmoid 导数，具体数字归第 16 页。

# page-16
标题写“算一次：一条权重收到多少责备？”，要用可核验数字完成一次反传；用 `.board`，固定单样本 `x=2,t=1,w=0,b=0`，前向逐行显示 `z=wx+b=0`、`p=σ(0)=0.5`、交叉熵损失 `L=-ln(0.5)≈0.693`，反向利用 sigmoid 加交叉熵的简化结果显示 `∂L/∂z=p-t=-0.5`、`∂z/∂w=x=2`、所以 `∂L/∂w=-1`；取 η=0.1，更新 `w←0-0.1(-1)=0.1`，再次前向得到 `z=0.2,p≈0.550,L≈0.598`。提供“前向一次”“反向并更新”“复位”三按钮，必须按序启用，数字由公式现场计算；明确写“损失 0.693 → 0.598，方向有效”，不展开对 b 的同类计算。

# page-17
标题写“把整轮学习拼起来”，要让学生整合训练循环；使用 `.k-classification` 做可排序的四张大步骤条，初始顺序固定打乱为“更新参数、计算损失、输入样本并前向、反向计算梯度”，学生点击两张条目依次交换位置，点击“检查”后才显示反馈；正确顺序为“① 输入样本并前向 → ② 计算损失 → ③ 反向计算梯度 → ④ 更新参数”，随后出现回环箭头与“重复许多轮”，反馈解释每步输入输出，而非只报对错。选中态用注意橙，正确性用边框样式而非红绿；不训练真实网络，实时训练归第 18 页。

# page-18
标题写“现在，看一个小网络真的学会”，要用真实运行而非预录动画证明前述循环有效；使用 `.lab`，主画面为 XOR 数据集与实时决策边界热力场，调用 `assets/lib/seedrandom.min.js` 以种子 `page-18-xor` 生成 200 个带轻微抖动的训练点，并调用 `assets/lib/mlp.js` 创建 `sizes:[2,10,10,1], act:'tanh', lr:0.3, seed:18` 的网络；“训练”时每帧执行 12 次 `net.step(trainSet,16)`，每 8 帧用 `field(-1.3,-1.3,1.3,1.3,80,80)` 重算边界，右侧实时显示 epoch（定义为已处理样本数/200）、交叉熵 loss、准确率 acc 与小型 loss 折线，按钮有“训练/暂停”“单步”“重置”，重置同时 `net.reset()` 并清零历史，不更换数据。图例明确数据类别与模型预测区域，若 `net.diverged` 显示数值崩溃提示，同时准确率停在约 0.5 时只能说“尚未学会”，不能误称崩溃；不引用 TensorFlow.js。

# page-19
标题写“网络‘学会了’到底能说明什么？”，要建立训练集与新数据的区别；用 `.k-comparison` 同尺度比较“训练集：网络反复看过”与“验证集：训练时没看过”，数据仍由种子 `page-19-generalize` 确定性生成，两列各 100 个 XOR 抖动点，调用 mlp.js 在训练集上推进，实时同时显示 train acc 与 val acc；提供“正常数据”“验证集整体右移 0.6”两个按钮，后者只改变验证输入分布并重新评估，让学生看到决策边界不变而验证准确率可能下降，旁边结论写“损失下降说明适应了训练数据；对新数据仍好，才叫泛化”。不得预写某个固定最终准确率，读数以 `evaluate()` 实时结果为准；不展开过拟合、正则化术语清单。

# page-20
标题写“从一个神经元到反向传播：你已经走完这条链”，要完成迁移而非再塞新机制；使用 `.k-generalization`，主张为“神经网络学习 = 用数据定义误差，用反向传播求每个参数的调整方向，再反复更新”，支撑按层级挂出“神经元：加权和 + 激活”“隐藏层：组合出弯曲边界”“损失：把猜错变成可比较的数”“梯度下降：沿降低损失的方向走”“验证集：检查是否能面对新数据”；右下给一分钟出口题 `.quiz`：“如果损失没有下降，你会先检查哪三件事？”，选项为“数据与目标是否对应”“学习率是否合适”“前向与反向公式是否连对”“把网络名字换得更响亮”，允许多选，提交后前三项以结构边框标出并反馈“先检查数据、步长、计算链”；页脚式小字仅写“现实中的大模型规模更大、结构更复杂，但‘前向—损失—反向—更新’仍是核心训练循环”，不把生物神经元与人工神经元等同。
