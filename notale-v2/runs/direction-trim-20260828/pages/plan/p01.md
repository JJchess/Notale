# page-01

这一页要让读者相信：人工神经网络里那个被反复画成小圆圈的"神经元"，并不是凭空发明的抽象符号，而是对一件真实生物结构做的极度简化的工程翻版——这个信任是整套讲义视觉语言（线路图式的信号流动）成立的前提。画面左侧放一张真实的神经元显微照片（biological-neuron.jpg，压到低透明度作局部内容图，不是整页底图，右下角标注"锥体神经元染色显微图"），右侧用本讲义的标志画法画出对应的人工神经元：几个方形接线端子代表输入，细线汇入一个圆形节点，节点连一条输出线，线的粗细提示"权重有大小"。页面顶部 kicker 写"神经网络是怎么学会的"，主标题写"从一个神经元到反向传播"，下方导语写一句话："30 分钟看清楚：一个神经元怎么算数，一堆神经元怎么组成网络，网络又怎么知道该往哪个方向修正自己。"这一页不讲任何公式或数值，也不做任何交互，纯粹建立"生物神经元 → 人工神经元 → 后面会有一张信号线路图贯穿全程"的预期，具体计算留给下一页。
