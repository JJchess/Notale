# page-04

这一页要让读者相信：单个神经元只能画出一条直线（或一个平面）当分界线，有些问题——比如 XOR——用一条直线根本分不开，这正是"要叠多层"的动机。画面居中放一张二维散点图（.l-focus 内嵌坐标系，横轴 x₁、纵轴 x₂ 都是 0 或 1），四个点：(0,0)标"0"、(0,1)标"1"、(1,0)标"1"、(1,1)标"0"（这就是 XOR 真值表），点用形状区分类别（圆点=0，方点=1），不用红绿区分对错。图上叠一条可拖动的分界直线（由滑杆控制斜率和截距两个参数），读者拖动滑杆尝试把两类点分开，面板实时统计"当前分对的点数：X/4"。无论怎么拖，最多只能同时分对 3 个点，页面在读者尝试过后（比如拖动超过 5 次或点击"我试过了，分不开"按钮）显示提示："XOR 需要一条会拐弯的边界，单条直线做不到。"这一页不出现任何网络结构图，只用几何直觉说明局限，解决方案留给下一页。
