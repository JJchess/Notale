# page-12

这一页要让读者相信：反向传播从输出层开始，第一步要算的"误差信号"δ_out，其实就是链式法则里最外面那一环，可以直接代入第 6、7 页已经算出的数字得到确切结果。画面用纵向阶段堆叠承接第 10 页的推导手法：第一行写 dL/da_out = −(y−a_out) = −(1−0.6156) = −0.3844（对 L=½(y−a)² 求导的标准结果）；第二行写 da_out/dz_out = a_out(1−a_out) = 0.6156×0.3844 ≈ 0.2366；第三行用 .k-generalization 的 .claim 突出 δ_out = (dL/da_out)×(da_out/dz_out) ≈ −0.3844×0.2366 ≈ −0.0909；第四行接着算这个 δ_out 如何变成两条输入连线的梯度：∂L/∂w_out1 = δ_out×a_h1 = −0.0909×0.700 ≈ −0.0636，∂L/∂w_out2 = δ_out×a_h2 = −0.0909×0.438 ≈ −0.0398。交互沿用"下一步"逐行揭示，每揭示一行，第 11 页那张网络图的对应位置（用小号缩略图放在页面右上角作为持续参照）同步填入这个数值。这一页只处理输出层，隐藏层的梯度怎么从这里继续往前传，留给下一页。
