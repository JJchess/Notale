# page-13

这一页要让读者相信：误差信号往前一层传递时，需要"沿着权重原路乘回去、再乘上那一层自己的激活函数导数"，这正是链式法则在多层网络里的样子。画面延续第 12 页的纵向堆叠风格，直接给出承接算式：δ_h1 = δ_out×w_out1×a_h1(1−a_h1) = −0.0909×0.7×(0.700×0.300) = −0.0909×0.7×0.21 ≈ −0.01336；δ_h2 = δ_out×w_out2×a_h2(1−a_h2) = −0.0909×(−0.5)×(0.438×0.562) ≈ −0.0909×(−0.5)×0.2462 ≈ 0.01119；再算两个具体权重的梯度：∂L/∂w_h1_x1 = δ_h1×x1 = −0.01336×1 ≈ −0.01336，∂L/∂w_h1_x2 = δ_h1×x2 = −0.01336×0.5 ≈ −0.00668。页面顶部用一句 .lead 概括这一页的规律："越往前一层，δ 要多乘一次'这一层的权重'和'这一层的导数'——这就是'反向'两个字的来源。"交互仍是逐行揭示按钮，最后一行揭示后自动把第 11 页缩略图上左半部分（隐藏层的连线）补全成青色数值。这一页把标准例子的反向传播算到底，第 14 页开始讨论算出梯度之后怎么用。
