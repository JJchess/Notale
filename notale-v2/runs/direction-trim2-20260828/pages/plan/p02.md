# page-02
这一页要让读者相信：一个神经元只做三件很朴素的事——给每个输入乘一个权重、把它们加起来再加一个偏置、最后过一道"是否够大"的检验。画面用单焦点构图，主图区画一个神经元的接线细节：两个输入端标着 x1 和 x2，各自的导线上标着权重 w1、w2，汇入一个"Σ"求和节点，再接一个方框标注偏置 b，最后进入一个阶梯状的 ReLU 检验门，输出端标 y。当前具体数字是 x1=2、x2=-1、w1=0.5、w2=1.5、b=-0.2，于是加权和 z = 0.5×2 + 1.5×(-1) + (-0.2) = 1.0 − 1.5 − 0.2 = -0.7，因为 z 是负数，ReLU(z)=max(0, z) 给出输出 0。右侧注释轨放一个可拖动的滑块控制 x1，范围从 -3 到 5，拖动时 z 和输出的大读数实时重算，并高亮当前正在流动的那一段导线；当 x1 越过 3.4 时（因为此时 z 恰好等于 0），输出会从 0 跳变为正数，这个临界点在滑块上标出一个小刻度。复位按钮把 x1 拉回 2。这一页不讲激活函数为什么长这样，也不讲多个神经元怎么连起来，那是下两页的事。
