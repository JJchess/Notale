# page-03
这一页要让读者相信：如果每一层都只做线性变换，多叠几层其实等于没叠——曲线是靠激活函数的"弯折"才长出来的。画面用两栏对照构图，左栏标题「只叠线性层」，右栏标题「中间插一道 ReLU」。两栏共用同一组线性层：第一层 y1 = 2x + 1，第二层 y2 = 3y1 - 2。左栏直接展示：不加任何激活，两层合并等价于 y2 = 6x + 1，仍然是一条直线；取 x=-1 时，y2 = 6×(-1)+1 = -5。右栏在两层之间插入 ReLU：取同样 x=-1，先算 y1 = 2×(-1)+1 = -1，过 ReLU 后变成 0（因为 ReLU 把负数压平成 0），再算 y2 = 3×0-2 = -2。两栏在同一行用差值高亮标出：同一个输入 x=-1，不加激活得到 -5，加了 ReLU 得到 -2——多出来的这道"弯折"就是网络能学出曲线而不是永远只能学出直线的原因。这一页没有交互，只需要静态并排看清两条计算路径在同一个点上分岔。这一页不展开各种激活函数长什么样，那是下一页。
