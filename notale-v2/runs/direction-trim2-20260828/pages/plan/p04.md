# page-04
这一页要让读者相信：不同激活函数的差别主要在于"是否把输出压进一个有限区间"。画面用网格归类构图，把三种激活函数分成两组：左边一组贴着标签「压缩到有限区间」，框内并排放 sigmoid 和 tanh 两张曲线卡片；右边一组贴着标签「不压缩」，框内放 ReLU 一张曲线卡片。每张卡片上画出函数曲线，并标出三个参考点的数值：sigmoid 在 x=-2、0、2 时输出分别是 0.119、0.5、0.881；tanh 在同样三点输出分别是 -0.964、0、0.964；ReLU 在同样三点输出分别是 0、0、2。页面提供一个滑块，拖动 x 从 -3 到 3，三张卡片上各自出现一个跟随移动的圆点标记当前输出值，圆点旁的数字实时刷新，让读者亲眼看到 sigmoid 和 tanh 的曲线会在两端"贴住天花板和地板"，而 ReLU 在正半轴会一直往上走不封顶。复位把滑块拉回 x=0。这一页不讨论该用哪个函数训练效果更好，只讲"形状不同"这一件事。
