# page-05
这一页要让读者相信：把神经元一个接一个连起来，前向传播就是数字沿着导线一站一站往前算，没有更神秘的事。画面用横向过程构图，从左到右排三个阶段面板：「输入」「隐藏神经元」「输出神经元」，面板之间用蓝色箭头连接。具体数字：输入 x1=1、x2=2；隐藏神经元权重 w1=0.4、w2=-0.2、偏置 b=0.1，算出 z = 0.4×1 + (-0.2)×2 + 0.1 = 0.4 - 0.4 + 0.1 = 0.1，过 ReLU 后 a = 0.1；输出神经元只有一个权重 v=0.8 和偏置 c=-0.05，算出 z_out = 0.8×0.1 + (-0.05) = 0.08 - 0.05 = 0.03，这一层不加激活函数，最终输出就是 0.03。页面提供一个滑块控制 x1，范围 -2 到 2，拖动时三个阶段的读数依次重算，同时导线上有蓝色光点从左向右流动一遍，直观呈现"一次前向传播"是什么样子。复位把 x1 拉回 1。这一页不讲损失和训练，只讲信号怎么往前走。
