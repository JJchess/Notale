# page-07
这一页要让读者相信：要"调权重"，先得有一个数字能量出网络"错得有多远"，这个数字就是损失。画面用两栏对照构图，左栏是一张三行表格，每行是一个例子：预测值、目标值、差值、损失（损失取 0.5×差值²）。三行数据是——预测 0.7、目标 1、差值 0.3、损失 0.5×0.3²=0.045；预测 0.3、目标 1、差值 0.7、损失 0.5×0.7²=0.245；预测 0.95、目标 1、差值 0.05、损失 0.5×0.05²=0.00125。右栏放一个可拖动的滑块，控制第四个例子的预测值，范围 0 到 1，目标固定为 1，滑块旁的差值和损失读数实时重算，同时一个小型损失曲线上有个点跟着滑块左右移动。这一页要让读者亲手感受到：预测越接近目标损失越小，而且因为损失是差值的平方，差得越远损失涨得越快，不是匀速涨。复位把滑块拉回 0.5。这一页不讲损失曲线在权重空间里长什么样，那是下一页。
