# page-09
这一页要让读者相信：曲线在某一点的"斜率"直接告诉你该往哪个方向挪权重才能让损失变小。画面沿用上一页同样的抛物线 Loss(w) = 0.5×(5-2w)²，主图区在曲线上标一个可拖动的点，点上画出这一点的切线，切线的斜率公式是 dLoss/dw = -4×(5-2w)。具体数字：拖到 w=1 时，斜率 = -4×(5-2) = -12，是一个很陡的负数，箭头指向"增大 w"的方向，因为往这个方向走损失会变小；拖到 w=2.5 时，斜率 = -4×(5-5) = 0，切线变成水平，箭头消失，说明这里已经是最低点。滑块控制 w，范围 -1 到 4，拖动时切线角度和斜率读数实时重算，箭头方向随之翻转。复位把 w 拉回 1。这一页不讲怎么把"看斜率挪一步"变成一个可以重复执行的算法，那是下一页要做的事。
