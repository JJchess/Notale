# page-14
这一页要让读者相信：前向传播在一张真实的小网络上算起来，其实就是把加权求和和激活函数重复做三次。画面用单焦点构图，把上一页交接的那张网络画出来，输入是 x1=0.5、x2=0.8。隐藏神经元 A：z1 = 0.3×0.5 + (-0.6)×0.8 + 0.1 = 0.15 - 0.48 + 0.1 = -0.23，经过 sigmoid 得 a1 = 0.443。隐藏神经元 B：z2 = 0.7×0.5 + 0.2×0.8 + (-0.2) = 0.35 + 0.16 - 0.2 = 0.31，经过 sigmoid 得 a2 = 0.577。输出神经元：z_out = 0.5×0.443 + (-0.3)×0.577 + 0.2 = 0.221 - 0.173 + 0.2 = 0.248，经过 sigmoid 得预测 y_hat = 0.562。目标 t=1，损失 Loss = 0.5×(1-0.562)² = 0.096。页面提供一个「下一步」按钮，每点一次高亮导线上下一段正在算的部分并显示对应的中间数值，四次点击依次点亮 A、B、输出、损失四个阶段，数值本身不会变化，只是逐步揭示；复位回到第一阶段。这一页不涉及梯度，只把前向的九个数字和最终损失 0.096 立成后面两页要反复用的基准。
