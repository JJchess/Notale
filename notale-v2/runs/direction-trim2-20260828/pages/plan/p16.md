这一页要让读者相信：有了梯度之后，更新权重只是简单的减法，而且做完这一步损失确实会变小。画面用横向过程构图，三个阶段面板依次是「更新前」「应用更新」「更新后」。取学习率 0.5，更新公式是新权重 = 旧权重 - 0.5×对应梯度，用上两页算出的九个数字，得到：v1 从 0.5 变成 0.524，v2 从 -0.3 变成 -0.269，c 从 0.2 变成 0.254，w11 从 0.3 变成 0.303，w12 从 -0.6 变成 -0.595，b1 从 0.1 变成 0.107，w21 从 0.7 变成 0.698，w22 从 0.2 变成 0.197，b2 从 -0.2 变成 -0.204。用这九个新数字重新走一遍前向传播，得到新的预测 y_hat' = 0.583，新的损失 Loss' = 0.087，比更新前的 0.096 确实小了一点。页面只有一个「应用更新」按钮，点击后画面从"更新前"状态切换到"更新后"状态，九个权重和损失读数并排显示旧值和新值，差值用高亮标出；复位回到更新前状态。这一页把前向传播、损失、反向传播、更新这四步在数字上完整走了一圈，闭合了训练循环的第一次循环。
