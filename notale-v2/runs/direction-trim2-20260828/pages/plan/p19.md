# page-19
这一页要让读者相信：训练不是总能顺利收敛，几种常见的设置错误会让同一张网络学不动或者学坏掉。画面用两栏对照构图改造成三组预设按钮，沿用上一页同一个分类网络和数据。第一个预设「学习率过大（1.0）」：点击后损失读数在几轮训练里剧烈跳动，例如从 0.20 跳到 1.5，再跳到 0.05，再跳到 2.3，忽大忽小，边界线也跟着乱甩，不收敛。第二个预设「学习率过小（0.001）」：损失几乎不动，10 轮训练后只从 0.20 降到 0.199，边界线几乎看不出移动。第三个预设「初始权重太大导致饱和（初始权重设为 ±8）」：损失读数长时间停在接近 0.2 附近不再下降，同时旁边显示当前梯度大小接近 0.0003，说明 sigmoid 已经被推到曲线两端很平的区域，斜率几乎为零，梯度传不回去。作为对照，页面顶部保留一条"正常设置（学习率 0.05）"的基准读数——损失在同样轮数内从 0.20 降到大约 0.05——三个预设各自的表现都和这条基准并排对比。这一页不解释饱和背后更深的数学原因，只让读者认出这三种失败长什么样。
