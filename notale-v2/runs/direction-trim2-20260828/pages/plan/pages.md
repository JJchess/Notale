# page-01
这一页要让读者相信一件事：接下来三十分钟要拆开的"神经网络学习"，其实就是一张接线图在两个方向上跑电流。画面用开场构图：左侧堆叠 kicker「从一个神经元到反向传播」、主标题「神经网络是怎么学会的」、以及一句导语——"一个数字从输入走到输出，再有一个数字从输出走回输入，中间发生的事叫训练"；右侧占据大部分画面的是这套课的签名图形：几个圆形节点用直角折线连成一个小网络，导线上叠着两条流动的光点，一条是钴蓝色从左向右（正向信号），一条是琥珀色从右向左（反向梯度），两条线在同一批导线上朝相反方向缓慢流动，静态即可看清方向、若有动效也只是匀速流动不需要读者操作。页面底部用一行小字列出这三十分钟会经过的五个站点：单个神经元、损失怎么量出来、梯度下降、链式法则、反向传播。这一页不讲任何公式和数字，只立住"同一张图，两个方向"这一个印象，后面每一页都会回到这张图的某一部分。

# page-02
这一页要让读者相信：一个神经元只做三件很朴素的事——给每个输入乘一个权重、把它们加起来再加一个偏置、最后过一道"是否够大"的检验。画面用单焦点构图，主图区画一个神经元的接线细节：两个输入端标着 x1 和 x2，各自的导线上标着权重 w1、w2，汇入一个"Σ"求和节点，再接一个方框标注偏置 b，最后进入一个阶梯状的 ReLU 检验门，输出端标 y。当前具体数字是 x1=2、x2=-1、w1=0.5、w2=1.5、b=-0.2，于是加权和 z = 0.5×2 + 1.5×(-1) + (-0.2) = 1.0 − 1.5 − 0.2 = -0.7，因为 z 是负数，ReLU(z)=max(0, z) 给出输出 0。右侧注释轨放一个可拖动的滑块控制 x1，范围从 -3 到 5，拖动时 z 和输出的大读数实时重算，并高亮当前正在流动的那一段导线；当 x1 越过 3.4 时（因为此时 z 恰好等于 0），输出会从 0 跳变为正数，这个临界点在滑块上标出一个小刻度。复位按钮把 x1 拉回 2。这一页不讲激活函数为什么长这样，也不讲多个神经元怎么连起来，那是下两页的事。

# page-03
这一页要让读者相信：如果每一层都只做线性变换，多叠几层其实等于没叠——曲线是靠激活函数的"弯折"才长出来的。画面用两栏对照构图，左栏标题「只叠线性层」，右栏标题「中间插一道 ReLU」。两栏共用同一组线性层：第一层 y1 = 2x + 1，第二层 y2 = 3y1 - 2。左栏直接展示：不加任何激活，两层合并等价于 y2 = 6x + 1，仍然是一条直线；取 x=-1 时，y2 = 6×(-1)+1 = -5。右栏在两层之间插入 ReLU：取同样 x=-1，先算 y1 = 2×(-1)+1 = -1，过 ReLU 后变成 0（因为 ReLU 把负数压平成 0），再算 y2 = 3×0-2 = -2。两栏在同一行用差值高亮标出：同一个输入 x=-1，不加激活得到 -5，加了 ReLU 得到 -2——多出来的这道"弯折"就是网络能学出曲线而不是永远只能学出直线的原因。这一页没有交互，只需要静态并排看清两条计算路径在同一个点上分岔。这一页不展开各种激活函数长什么样，那是下一页。

# page-04
这一页要让读者相信：不同激活函数的差别主要在于"是否把输出压进一个有限区间"。画面用网格归类构图，把三种激活函数分成两组：左边一组贴着标签「压缩到有限区间」，框内并排放 sigmoid 和 tanh 两张曲线卡片；右边一组贴着标签「不压缩」，框内放 ReLU 一张曲线卡片。每张卡片上画出函数曲线，并标出三个参考点的数值：sigmoid 在 x=-2、0、2 时输出分别是 0.119、0.5、0.881；tanh 在同样三点输出分别是 -0.964、0、0.964；ReLU 在同样三点输出分别是 0、0、2。页面提供一个滑块，拖动 x 从 -3 到 3，三张卡片上各自出现一个跟随移动的圆点标记当前输出值，圆点旁的数字实时刷新，让读者亲眼看到 sigmoid 和 tanh 的曲线会在两端"贴住天花板和地板"，而 ReLU 在正半轴会一直往上走不封顶。复位把滑块拉回 x=0。这一页不讨论该用哪个函数训练效果更好，只讲"形状不同"这一件事。

# page-05
这一页要让读者相信：把神经元一个接一个连起来，前向传播就是数字沿着导线一站一站往前算，没有更神秘的事。画面用横向过程构图，从左到右排三个阶段面板：「输入」「隐藏神经元」「输出神经元」，面板之间用蓝色箭头连接。具体数字：输入 x1=1、x2=2；隐藏神经元权重 w1=0.4、w2=-0.2、偏置 b=0.1，算出 z = 0.4×1 + (-0.2)×2 + 0.1 = 0.4 - 0.4 + 0.1 = 0.1，过 ReLU 后 a = 0.1；输出神经元只有一个权重 v=0.8 和偏置 c=-0.05，算出 z_out = 0.8×0.1 + (-0.05) = 0.08 - 0.05 = 0.03，这一层不加激活函数，最终输出就是 0.03。页面提供一个滑块控制 x1，范围 -2 到 2，拖动时三个阶段的读数依次重算，同时导线上有蓝色光点从左向右流动一遍，直观呈现"一次前向传播"是什么样子。复位把 x1 拉回 1。这一页不讲损失和训练，只讲信号怎么往前走。

# page-06
这一页要让读者相信一件容易被忽略的事：训练从头到尾只会改动权重和偏置这些数字，绝不会改动神经元之间"谁连着谁"这张接线图本身。画面用概括构图：顶部是一条加粗描边的主张「训练只调整权重，不改变结构」，下方主干挂着三条支撑：连接方式（几个神经元、谁接谁）是人在设计网络时一次性定好的，训练开始前不会再变；训练刚开始时，所有权重和偏置都是随机的小数，网络还什么都不会；之后每一步训练做的事，只是把这些权重和偏置的数值往一个方向挪一点点。这一页是静态的，没有交互，也不出现具体数字，它的作用是在读者学会"怎么调"之前先说清楚"调的是什么"，避免后面几页把"训练"和"改架构"混在一起。这一页不讲权重具体怎么挪动，那从下一页开始才展开。

# page-07
这一页要让读者相信：要"调权重"，先得有一个数字能量出网络"错得有多远"，这个数字就是损失。画面用两栏对照构图，左栏是一张三行表格，每行是一个例子：预测值、目标值、差值、损失（损失取 0.5×差值²）。三行数据是——预测 0.7、目标 1、差值 0.3、损失 0.5×0.3²=0.045；预测 0.3、目标 1、差值 0.7、损失 0.5×0.7²=0.245；预测 0.95、目标 1、差值 0.05、损失 0.5×0.05²=0.00125。右栏放一个可拖动的滑块，控制第四个例子的预测值，范围 0 到 1，目标固定为 1，滑块旁的差值和损失读数实时重算，同时一个小型损失曲线上有个点跟着滑块左右移动。这一页要让读者亲手感受到：预测越接近目标损失越小，而且因为损失是差值的平方，差得越远损失涨得越快，不是匀速涨。复位把滑块拉回 0.5。这一页不讲损失曲线在权重空间里长什么样，那是下一页。

# page-08
这一页要让读者相信：如果把损失看成权重的函数，它会变成一条有确定形状的曲线，训练要找的就是这条曲线最低的那一点。画面用单焦点构图，取一个最简单的玩具设定：网络只有一个权重 w，输出 y_hat = w×x，其中 x=2、目标 t=5，于是损失 Loss(w) = 0.5×(5-2w)²，这是一条关于 w 的抛物线。主图区画出这条抛物线，横轴是 w，纵轴是损失。滑块控制 w，范围 -1 到 4，滑块每移动一步，画面上有一个点沿抛物线滑动，旁边的大读数实时显示当前损失值；几个参考点标出来：w=0 时损失 12.5，w=1 时损失 4.5，w=2.5 时损失恰好是 0（因为这时 w×x=5，正好等于目标）。右侧注释轨放一张缩小的静态示意图，标注"如果有两个权重，损失会变成一整片地形，中间凹下去的谷底就是最小值"，这张示意图不需要互动，只是把"一个权重的抛物线"这件事延伸到"多个权重的地形"这件事上，为后面训练一整个网络做铺垫。这一页不讲怎么找到谷底，那是接下来两页的事。

# page-09
这一页要让读者相信：曲线在某一点的"斜率"直接告诉你该往哪个方向挪权重才能让损失变小。画面沿用上一页同样的抛物线 Loss(w) = 0.5×(5-2w)²，主图区在曲线上标一个可拖动的点，点上画出这一点的切线，切线的斜率公式是 dLoss/dw = -4×(5-2w)。具体数字：拖到 w=1 时，斜率 = -4×(5-2) = -12，是一个很陡的负数，箭头指向"增大 w"的方向，因为往这个方向走损失会变小；拖到 w=2.5 时，斜率 = -4×(5-5) = 0，切线变成水平，箭头消失，说明这里已经是最低点。滑块控制 w，范围 -1 到 4，拖动时切线角度和斜率读数实时重算，箭头方向随之翻转。复位把 w 拉回 1。这一页不讲怎么把"看斜率挪一步"变成一个可以重复执行的算法，那是下一页要做的事。

# page-10
这一页要让读者相信：把"看斜率、往反方向挪一小步"重复做下去，就是梯度下降的全部内容。画面用横向过程构图，沿用同样的设定 Loss(w) = 0.5×(5-2w)²，学习率固定为 0.1，起点 w0=0。第一个阶段面板显示"当前 w"和"当前斜率"，后面跟着箭头连到下一个阶段"更新后的 w"。点击「下一步」按钮，每次按更新公式 w_new = w - 0.1×斜率 往前走一步，具体序列是：w0=0（斜率 -20，损失 12.5）→ w1=2.0（斜率 -4，损失 0.5）→ w2=2.4（斜率 -0.8，损失 0.02）→ w3=2.48（斜率 -0.16，损失约 0.0008）→ w4=2.496，越来越接近真正的最小点 w=2.5。每点一次按钮，当前阶段面板高亮，抛物线上的点向谷底靠近一格，损失读数同步下降。复位按钮把序列拉回 w0=0 重新开始。这一页不讨论学习率大小的影响，那是下一页专门对照的内容。

# page-11
这一页要让读者相信：学习率选得不合适，同一套梯度下降会走出完全不同的命运——太小会慢得难以忍受，太大会直接冲过头发散。画面用两栏对照构图改造成三组预设按钮，共用上一页同样的设定 Loss(w)=0.5×(5-2w)²、起点 w0=0。三个预设分别是「学习率 0.05（偏小）」「学习率 0.1（合适）」「学习率 0.3（偏大）」，点击预设按钮后画面显示各自前四步的 w 序列：0.05 时序列是 1.0、1.6、1.96、2.176，稳步但缓慢地靠近 2.5；0.1 时序列是 2.0、2.4、2.48、2.496，几步就已经很接近 2.5，和上一页的结果完全一致；0.3 时序列是 6.0、-2.4、9.36、-7.104，数值在正负之间越跳越远，完全没有靠近 2.5 的趋势。三条路径画在同一条数轴上，用不同的线型区分——偏小用点线、合适用实线、偏大用虚线，不用额外的颜色去区分这三种情况，靠线型和旁边的文字标签分辨。这一页不解释"为什么 0.3 会发散"背后的数学条件，只让读者从三条路径的形状里看出后果的差别。

# page-12
这一页要让读者相信：链式法则不是新发明的规则，而是"一层套一层的函数，导数也一层套一层地乘起来"这件事的正式说法。画面用公式居中构图，中央面板写出两个简单函数：f(x)=x²，g(x)=3x+1，以及它们的复合 h(x)=f(g(x))=(3x+1)²。取 x=1 时，先算内层 g(1)=3×1+1=4，再算外层 f(4)=16，所以 h(1)=16。链式法则给出的导数公式是 h'(x)=f'(g(x))×g'(x)=2×(3x+1)×3=6×(3x+1)，在 x=1 处等于 6×4=24。旁边一栏做直接验算：把 h(x) 展开成 9x²+6x+1，直接求导得到 h'(x)=18x+6，在 x=1 处同样等于 24——两条路算出同一个数，这就是链式法则成立的直接证据。页面提供一个滑块控制 x，范围 -2 到 2，拖动时两种算法的中间数值和最终导数同步刷新，始终保持相等。复位把 x 拉回 1。这一页不涉及神经网络里的具体权重，只把链式法则这一个数学工具立住。

# page-13
这一页要让读者相信：一旦网络里有好几个权重，"对每个权重分别算一次导数"会变得笨重，需要一种能把重复劳动省下来的系统方法——这就是反向传播要解决的问题。画面是静态的转场构图，中央画出接下来两页要用到的那张小网络的完整接线图：两个输入 x1、x2，接到两个隐藏神经元，隐藏神经元再接到一个输出神经元，图上标出这张网络一共有九个可调数字——隐藏神经元 A 的权重 w11=0.3、w12=-0.6、偏置 b1=0.1；隐藏神经元 B 的权重 w21=0.7、w22=0.2、偏置 b2=-0.2；输出神经元的权重 v1=0.5、v2=-0.3、偏置 c=0.2。图上用细线画出输出对这九个数字的依赖关系像树一样往回分叉，旁白写着：如果每个权重都从头单独算一遍导数，中间那些共享的计算会被重复算很多次；反向传播的诀窍是从输出往回走一次，把每一步算出的中间结果留下来，顺路分给所有权重。这一页不出现任何梯度数字，只把"为什么需要反向传播"和下两页要用的网络交接清楚。

# page-14
这一页要让读者相信：前向传播在一张真实的小网络上算起来，其实就是把加权求和和激活函数重复做三次。画面用单焦点构图，把上一页交接的那张网络画出来，输入是 x1=0.5、x2=0.8。隐藏神经元 A：z1 = 0.3×0.5 + (-0.6)×0.8 + 0.1 = 0.15 - 0.48 + 0.1 = -0.23，经过 sigmoid 得 a1 = 0.443。隐藏神经元 B：z2 = 0.7×0.5 + 0.2×0.8 + (-0.2) = 0.35 + 0.16 - 0.2 = 0.31，经过 sigmoid 得 a2 = 0.577。输出神经元：z_out = 0.5×0.443 + (-0.3)×0.577 + 0.2 = 0.221 - 0.173 + 0.2 = 0.248，经过 sigmoid 得预测 y_hat = 0.562。目标 t=1，损失 Loss = 0.5×(1-0.562)² = 0.096。页面提供一个「下一步」按钮，每点一次高亮导线上下一段正在算的部分并显示对应的中间数值，四次点击依次点亮 A、B、输出、损失四个阶段，数值本身不会变化，只是逐步揭示；复位回到第一阶段。这一页不涉及梯度，只把前向的九个数字和最终损失 0.096 立成后面两页要反复用的基准。

# page-15
这一页要让读者相信：反向传播就是把上一页算出的损失，沿着同一张接线图往回拆成每个权重该负多少责任。画面沿用上一页同一张网络，导线上流动的是琥珀色。第一步算输出层的误差信号：delta_out = (y_hat - t) × y_hat × (1 - y_hat) = (0.562-1) × 0.562 × 0.438 = -0.108。用它算输出层三个权重的梯度：dLoss/dv1 = delta_out × a1 = -0.108×0.443 = -0.048；dLoss/dv2 = delta_out × a2 = -0.108×0.577 = -0.062；dLoss/dc = delta_out = -0.108。再往回一层，算两个隐藏神经元各自的误差信号：delta_h1 = delta_out×v1×a1×(1-a1) = (-0.108×0.5)×(0.443×0.557) = -0.0133；delta_h2 = delta_out×v2×a2×(1-a2) = (-0.108×-0.3)×(0.577×0.423) = 0.0079。用它们算隐藏层六个数字的梯度：dLoss/dw11=-0.0067、dLoss/dw12=-0.0107、dLoss/db1=-0.0133、dLoss/dw21=0.0040、dLoss/dw22=0.0063、dLoss/db2=0.0079。页面提供「反向一步」按钮，每点一次沿琥珀色路径从输出往输入方向揭示下一组梯度数值，一共分四次点完（输出层、delta_h、隐藏层 A、隐藏层 B）；复位清空已揭示的梯度。这一页不做权重更新，只把九个梯度数字算齐，留给下一页去用。

# page-16
这一页要让读者相信：有了梯度之后，更新权重只是简单的减法，而且做完这一步损失确实会变小。画面用横向过程构图，三个阶段面板依次是「更新前」「应用更新」「更新后」。取学习率 0.5，更新公式是新权重 = 旧权重 - 0.5×对应梯度，用上两页算出的九个数字，得到：v1 从 0.5 变成 0.524，v2 从 -0.3 变成 -0.269，c 从 0.2 变成 0.254，w11 从 0.3 变成 0.303，w12 从 -0.6 变成 -0.595，b1 从 0.1 变成 0.107，w21 从 0.7 变成 0.698，w22 从 0.2 变成 0.197，b2 从 -0.2 变成 -0.204。用这九个新数字重新走一遍前向传播，得到新的预测 y_hat' = 0.583，新的损失 Loss' = 0.087，比更新前的 0.096 确实小了一点。页面只有一个「应用更新」按钮，点击后画面从"更新前"状态切换到"更新后"状态，九个权重和损失读数并排显示旧值和新值，差值用高亮标出；复位回到更新前状态。这一页把前向传播、损失、反向传播、更新这四步在数字上完整走了一圈，闭合了训练循环的第一次循环。

# page-17

这一页要让读者相信：训练不是总能顺利收敛，几种常见的设置错误会让同一张网络学不动或者学坏掉。画面用两栏对照构图改造成三组预设按钮，沿用上一页同一个分类网络和数据。第一个预设「学习率过大（1.0）」：点击后损失读数在几轮训练里剧烈跳动，例如从 0.20 跳到 1.5，再跳到 0.05，再跳到 2.3，忽大忽小，边界线也跟着乱甩，不收敛。第二个预设「学习率过小（0.001）」：损失几乎不动，10 轮训练后只从 0.20 降到 0.199，边界线几乎看不出移动。第三个预设「初始权重太大导致饱和（初始权重设为 ±8）」：损失读数长时间停在接近 0.2 附近不再下降，同时旁边显示当前梯度大小接近 0.0003，说明 sigmoid 已经被推到曲线两端很平的区域，斜率几乎为零，梯度传不回去。作为对照，页面顶部保留一条"正常设置（学习率 0.05）"的基准读数——损失在同样轮数内从 0.20 降到大约 0.05——三个预设各自的表现都和这条基准并排对比。这一页不解释饱和背后更深的数学原因，只让读者认出这三种失败长什么样。

这一页要把前面十九页收束成一句可以带走的话，并且指出这句话之外还有什么没讲。画面用收束构图，与开场呼应：主张一行加粗写着「学习 = 反复做（前向算、量误差、往回传、调一调）」，下方主干挂着五条支撑，逐条对应前面的页面——前向传播把输入沿着接线图算成一个预测数字；损失函数把预测和真实答案的差距压缩成一个数，差得越远这个数涨得越快；反向传播用链式法则把这个数字沿着同一张接线图往回拆，分给每一个权重和偏置；每个权重按照自己分到的梯度和学习率的大小挪一小步；把这一整圈重复很多轮，损失数值会持续下降，就像第十七页和第十八页里亲眼看到的那样。画面右侧保留开场那张双色流动接线图作为呼应，但不再需要文字解释。页面底部一行小字指出这堂课刻意没有展开的方向，供有兴趣的读者课后自己去查：更深的网络、卷积和其他结构、除了平方误差之外的损失函数、以及比"减去学习率乘梯度"更聪明的更新方法比如带惯性的优化器。这一页是静态的，没有交互，作为整套课的落点。
