Bagging：Bootstrap 自助采样与方差缩减

平均降低方差：Var(f̄) = ρσ² + (1-ρ)σ²/B

① 自助采样 (有放回)
② 并行拟合树模型
③ 均匀投票汇聚
样本量 N=12 ｜ 独有率 ≈ 63.2% (1 - 1/e)
基学习器 B = 3 棵独立深树 ｜ 各自高方差
方差对比：单树 σ² → 集成 0.42 σ²
未抽中样本占 36.8% 自然构成袋外数据（OOB），用于无偏泛化评估。
当相关系数 ρ=0.13, B=3 时：Var = 0.13σ² + 0.29σ² = 0.42σ²
Bagging，也就是 Bootstrap Aggregating 的缩写，是并行集成学习的基石。 这一页的核心机制包含三个关键环节： 首先是左侧的 Bootstrap 自助采样：从规模为 N 的原始训练集中进行 N 次有放回抽样。在数学上，当 N 趋近无穷大时，任何一个样本被抽中的概率是 1 减去 1/e，约等于 63.2%，剩下约 36.8% 的样本从未进入该子集，天然构成了袋外数据（Out-Of-Bag）。 其次是中间的并行训练：利用这些各不相同的采样集，独立训练 B 个高方差基学习器（通常是未经剪枝的深度决策树）。因为采样差异，每棵树拟合出的决策分界面形态各异。 最后是右侧的集成聚合：通过对多棵树的预测结果求简单平均或多数投票，多条分散的扰动路径最终汇聚成一条稳健的边界。公式 Var(f̄) = ρσ² + (1-ρ)σ²/B 揭示了其本质：平均操作消解了非共性的独立扰动，使整体方差大幅缩减，从而显著提升泛化能力。
