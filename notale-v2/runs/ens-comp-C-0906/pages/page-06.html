各位同学，今天我们正式进入 Bagging 与随机森林的机制拆解。 大家首先思考一个问题：在很多场景下，我们只有一份大小为 N 的真实训练数据，无法多次从真实世界采样。那怎么才能拥有多个互不相同的训练集来训练多个基学习器？ 答案就是屏幕上的核心方法：Bootstrap 自助采样。 它的规则非常简单且优美：面对容量为 N 的集合，我们每次随机抽一个记录下来，然后放回池中，重复执行 N 次。 因为是有放回抽样，某些样本会被重复抽中多次，比如子集 1 中的 x₂ 和 x₇；而另一些样本则一次也没被抽中，落在了集合之外。 从数学极限来看，当 N 足够大时，任意一个特定样本在 N 次抽取中始终未被选中的概率会收敛到 1/e，也就是大约 36.8%。 这意味着每个自助子集大约只覆盖了 63.2% 的原始样本，而剩下的 36.8% 就成了天然未被该学习器见过的“袋外样本”，我们后续会用它来做模型评估与泛化误差估计。
