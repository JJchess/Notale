集成有效的两个前提条件

仅当个体具备基础预测能力（优于随机猜测）且犯错互不相关时，多数表决才能产生指数级的错误抑制。

条件一：个体准确率需大于 0.5 p > 0.5 （基学习器具备基本能力）

当个体准确率 p > 0.5 时，集成规模 T 越大，多数表决整体错误率越趋近于 0；若 p < 0.5，集成反而加速走向完全错误。

孔多塞定理：若 ε < 0.5，则 lim_{T→∞} P_err = 0 指数收敛
条件二：基学习器误差具有多样性 Cov(E_i, E_j) ≈ 0 （多样性条件）

若所有个体模型对相同样本犯同一种错误，多数表决无法纠偏；唯有犯错位置错开，多数投票才能消解单兵错误。

误差分解：E = Ē - Ā （集成误差 = 平均个体误差 - 多样性度量） 多样性越大，集成增益越高
这一页我们来看集成学习发挥威力的两个底层数学前提。 首先是“个体必须优于随机猜测”。在二分类多数表决下，经典孔多塞定理告诉我们，当基学习器准确率 p > 0.5 时，集成的整体错误率会随着基学习器数量 T 呈指数级下降，迅速逼近 0。但注意，如果基学习器连随机猜测都不如（p < 0.5），那集成反而会走向灾难，迅速收敛到 100% 犯错。 第二个条件往往更难满足，那就是“多样性”：个体之间的错误不能高度相关。右侧的对比矩阵清晰地展示了这一点：如果 3 个学习器的错误完全同步，那投票毫无纠偏作用；只有当各个学习器的错误位置分散、互不重叠时，多数表决才能把局部的单兵错误全部消解掉。这也是后续 Bagging、Boosting 等一切集成算法所要解决的核心课题。
