Bootstrap 重采样：同一训练集构造有重叠子集

每次从包含 N 个样本的训练集 D 中有放回随机抽取 N 次，生成互有重叠的训练子集。

这一页我们讲解 Bagging 的基础基石：Bootstrap 重采样，也就是自助法采样。 假定我们手头只有这一个大小为 N 的原始训练集 D。我们如何为集成里的多棵决策树提供互不相同、但又真实有效的训练集？ 做法是从原始数据集中“有放回地随机抽样 N 次”。 大家观察：每次抽样产生的新子集大小依然是 N，但由于有放回，部分样本必然会被重复抽取两三次，而另一部分样本则完全没有被抽中。 在数学上，当样本量 N 足够大时，任何一个特定样本在某一轮重采样中始终未被抽中的概率收敛至 1/e，约等于 36.8%。 这约 36.8% 游离在当前训练子集之外的样本，称为“袋外数据（Out-of-Bag, OOB）”，这为后文的模型泛化评估留下了极有价值的独立验证集。
