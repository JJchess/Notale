机器学习概论 · 第八讲收束 误差分解与多样性约束

集成不是模型数量竞赛
而是对误差结构的设计

单模型的预测波动源于偏差、方差与不可约噪声的交织。Bagging 通过独立重抽样平抑方差，Boosting 沿着残差梯度步步消除偏差，Stacking 则在元学习层重构异质特征。集成算法的力量不是拼凑更多弱分类器，而是打破个体误差的正相关性。

误差流向与结构调控机制 Err = Bias² + Var + σ²
Bagging / RF 方差抑制 Var → Var/M
Boosting 偏差消除 Bias → 0
Stacking 空间重构 Cov(e_i, e_j) ↓
核心准则 多样性优先于单体纯准确率
结语：好的集成系统，使个体学习器的错误彼此抵消，而不是集体放大盲区。
