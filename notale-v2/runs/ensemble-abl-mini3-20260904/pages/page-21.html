Stacking 的两层结构：用数据学习如何组合模型

基模型的预测结果构成新特征空间（元特征）；元学习器通过自变量与真实标签的二次拟合，习得最优融合逻辑。

两层堆叠架构：从原始输入 X 到元特征 Z，再到最终预测 ŷ

结构本质：原始特征 X 经过各基模型映射为低维的元特征向量 Z；元模型不直接触碰高维原始属性，而是基于 Z 学习各基模型在何种预测模式下更值得信任。

本质区别 组合规则从「人为设定」变为「数据学习」

维度 Voting / Averaging Stacking (堆叠法)
组合方式 硬投票多数表决，或取平均值 (1/M)∑zₘ 由第二层模型拟合映射 g(z₁, …, zₘ)
权重确定 人工先验指定或等权重 基于训练误差与损失函数自动优化
模型协同 假设各基模型地位对等 自动抑制冗余/劣质模型，放大互补模型

数学表达 元学习器的输入与拟合目标

ŷ = g(z₁, z₂, …, zₘ)

以最常用的线性逻辑回归元学习器为例：

P(y=1|z) = σ(w₁·z₁ + w₂·z₂ + … + wₘ·zₘ + b)

权重向量 {w₁, …, wₘ} 与偏置 b 在训练数据上通过最小化损失直接优化求解。若某模型预测与真值相关性低或存在强多重共线性，其对应权重 w 自动被惩罚压低。

基模型多样性 异质模型（Heterogeneous）带来互补增益

Bagging 与 Boosting 通常只使用同质弱学习器（如决策树）。而 Stacking 最核心的优势在于联合不同算法家族（树模型 + 神经网络 + 线性/支持向量机）：

树模型: 擅长阶梯决策与类别变量
线性/SVM: 擅长全局线性平滑与高维间距
