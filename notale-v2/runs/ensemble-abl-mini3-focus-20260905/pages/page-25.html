集成范式选择：针对误差根源匹配组合机制

集成不是无目的堆砌模型：高方差依赖扰动平滑，残余误差依赖序列纠偏，异质强模型依赖加权融合。

Bagging 随机森林
优先解：高方差 / 易过拟合
基模型要求 高方差同质基学习器（充分生长的深决策树，单体容易拟合噪声）
多样性来源 Bootstrap 样本扰动 + 随机特征切分（相互降低单树相关性）
训练架构 完全并行；各基模型训练互不依赖，计算扩展性极高
适用场景 特征维数高、样本扰动敏感、单模型过拟合严重时
Boosting GBDT / XGBoost
优先解：欠拟合 / 残余高偏差
基模型要求 低方差、弱拟合力基模型（常用深度 3–6 的浅决策树桩，单体欠拟合）
多样性来源 序列重加权 / 负梯度拟合（每轮训练集目标强制转向前轮难分点）
训练架构 严格序列串行；后一棵树必须等待前序全体预测给出残差
适用场景 追求高精度上限、结构化表格数据、基模型表达力受限时
Stacking 多层堆叠
优先解：多架构模型优势互补
基模型要求 异质强学习器（决策树、神经网络、线性回归等具备不同假设空间）
多样性来源 模型架构差异与归纳偏置互补（不同算法在不同样本区域犯错）
训练架构 分层两阶段；必须严格使用 K 折交叉验证生成折外元特征（OOF）
适用场景 已有多种高性能单模型、需进一步压榨预测极值（如竞赛后期）
工程选型判定法则
树太深且不稳定？选 Bagging（靠平均压低方差） 浅树表达力不够、残差显著？选 Boosting（靠迭代消减偏差） 已有多架构成熟模型互不服输？选 Stacking（靠元学习器融合）
