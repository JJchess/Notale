Boosting 的序列结构：串行专注与针对性纠错

与 Bagging 的并行独立采样不同，Boosting 的每个新学习器专攻当前集成“尚未解好的残局”

结构范式：串行递进（Sequential） 目标：降低偏差（Bias）
Bagging：独立并行采样 并联基准
同权独立、各算各的
原始完整数据集 D N 个样本，权重相等 (1/N)
Bootstrap 1 ➔ 树 1 (h₁) ➔ 预测 ŷ₁
Bootstrap 2 ➔ 树 2 (h₂) ➔ 预测 ŷ₂
Bootstrap 3 ➔ 树 3 (h₃) ➔ 预测 ŷ₃
最终结果（简单投票/平均） H(x) = 1/T Σ hₜ(x)
并行特征：各基模型之间互不知晓、互不依赖。树 2 并不会因为树 1 在某些困难样本上判断失误就特别照顾它们。其核心力量在于平抑方差。
Boosting：递进链式纠错 序列结构
后一个学习器承接前者的残余误差
第 1 轮：h₁(x) 初始均权
当前样本关注度 所有点权重均等 w=0.10
弱分类器表现 单桩纵向划界，切分出 2 个误判点
传导给下一轮：增大 2 个失误点的权重，迫使下个模型重点关照。
第 2 轮：h₂(x) 重点纠偏
当前样本关注度 难样本权重放大（字号与圆盘增大）
弱分类器表现 横向换切，成功挽救上一轮的遗留错误
传导给下一轮：再次修正剩余 2 个交叉点权重，继续打补丁。
集成终态：H₃(x) 加权融合
加权合成判断 组合 h₁、h₂ 与 h₃ 决策面
最终集成表现 原本无法线性分割的样本全部正确区分
收敛成效：三个平庸弱分类器串行协作，构建出非线性复杂边界。
序列合成通式
H_m(x) = H_{m-1}(x) + α_m · h_m(x)
核心机理：每一个新学习器并不是从零开始单打独斗，而是作为补丁嵌入整体，专啃当前模型留下的硬骨头。
