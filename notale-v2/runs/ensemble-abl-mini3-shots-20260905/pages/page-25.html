集成范式的工程选择：按误差瓶颈与模型生态定架构

没有通用的最优集成法：Bagging 针对高方差深模型，Boosting 针对高偏差浅学习器，Stacking 针对异质模型优势互补。

Bagging 并行采样
主攻高方差 (Variance)
基模型要求 高方差 / 低偏差 (深树)
训练依赖 完全并行 / 无序
泛化机制 平均化削减扰动波动
典型代表 Random Forest
扰动样本与特征：对训练集有放回抽样 (Bootstrap)，随机森林进一步随机子集选特征，最大化基模型差异。
数学保证：
开箱稳定性高：几乎不需要精细调参，只要基学习器足够深且数量充分，不易发生过拟合。
Boosting 串行迭代
主攻高偏差 (Bias)
基模型要求 高偏差 / 低方差 (浅树)
训练依赖 严格串行 / 残差递推
泛化机制 梯度下降优化函数空间
典型代表 XGBoost / LightGBM
错误驱动递进：每个后继模型专门拟合前面所有模型的未解误差或损失函数的负梯度方向。
高精度天花板：基模型通常为深度仅 3~8 的弱回归树，通过大量精细累加，通常获得表格数据最高指标。
调参敏感度高：需谨慎配合学习率 、子采样率与树深度，防止过拟合或噪声敏感。
Stacking 分层元学习
主攻异质互补 (Heterogeneity)
基模型要求 异质架构 / 机制互补
训练依赖 K-Fold 折外特征构建
泛化机制 学习不同模型的置信边界
典型代表 Multi-model Stacking
机制异质性：组合不同归纳偏置（如树模型的轴对齐分割 + 神经网络的平滑非线性流形 + 线性模型的全局趋势）。
严格防泄漏：第一层基模型必须通过严密 K-Fold 生成 OOF (Out-of-Fold) 预测，元学习器绝不能看到训练集直接拟合的旧标签。
元学习器宜轻量：Meta-learner 通常采用有正则的线性回归或浅树，防止在折外特征上再次过拟合。
当前判定场景 Bagging / 随机森林
首选场景：特征维度高、单模型容易过拟合（高方差）、需要极高训练并行度与开箱可用性。 基模型推荐：充分生长的深度决策树（CART）。计算资源充沛时首选。
