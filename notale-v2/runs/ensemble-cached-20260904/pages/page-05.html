多数票与软投票的分歧模拟

考察 3 个基学习器对同一样本输出的置信度分布；观察硬投票与软投票何时得出截然相反的结论。

典型场景:

基学习器输出分布

类别 A 概率 P(A) 类别 B 概率 P(B)

硬投票 (多数决)

只看单票归属 argmax
多数票决策结果 -
得票统计：类别 A 0 票，类别 B 0 票

软投票 (概率平均)

保留连续置信度加权
期望置信度胜出 -
均值：P(A)=0.00，P(B)=0.00
发生分歧 硬投票选类别 A，但软投票裁定类别 B！

模型 1 与模型 2 虽然都投票支持类别 A，但优势微弱（各仅有 51% 置信度）；而模型 3 以 90% 的极高置信度坚定判定为类别 B。硬投票丢弃了 49% 与 10% 的置信度差异，使多数票产生假象；软投票综合全盘概率，纠正了盲目少数服从多数的偏差。

硬投票有效倾向
A 占 66.7% 票数
软投票综合期望
P(A) 均值 38.3%
硬投票票数：A: 2 票 vs B: 1 票 ➔ A 胜出
软投票均值：P(A) = (0.51 + 0.51 + 0.10) / 3 = 0.373 ➔ B (0.627) 胜出
