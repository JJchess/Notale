在 Bagging 和随机森林中，我们需要让各个基学习器看到“略有不同”的数据，否则完全相同的算法在完全相同的数据上只会产出完全相同的模型。 Bootstrap 重采样提供了一种优雅的数学方案：对于大小为 N 的数据集，每次有放回地抽取一个样本并重复 N 次。 因为是有放回的，一个样本单次未被抽中的概率是 1 - 1/N。当样本量 N 较大时，连续 N 次都未抽中的概率收敛至 1/e，约等于 36.8%。 这意味着每个自助子集平均只包含原始数据中约 63.2% 的不同样本，而剩下的 36.8% 就成了天然的“袋外测试样本”。这既为各个树带来了差异性，又催生了 OOB 验证机制。
