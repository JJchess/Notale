Bagging：并行训练高方差模型，以聚合抵消波动

各基学习器在不同重采样集上独立拟合，平均运算相互对冲特异扰动。

重采样 → 并行训练 → 聚合决策
单棵决策树拟合 (h_b) 高方差
各模型预测方差 Var(h_b) = σ²
Bagging 聚合输出 (H) 低方差
集成后预测方差 Var(H) ≈ (1/B)·σ²
在上一节中，我们了解了如何通过 Bootstrap 重采样，从原始样本集生成一组彼此有差异的子数据集。这一节我们来看 Bagging 的全景运行机制。 Bagging 的全称是 Bootstrap Aggregating。它的逻辑非常直观：第一步，基于重采样并行训练多个高方差模型，比如不剪枝的深层决策树；第二步，将所有模型的预测结果进行聚合，分类问题用多数投票，回归问题用简单算术平均。 为什么平均能起效？看右侧的对比：单棵树对训练集里的特定噪点极其敏感，预测曲线剧烈震荡；而当我们将多个独立扰动的模型平均时，正向偏差与负向偏差会在求和中彼此对冲，最终得到的集成预测曲线变得平滑而稳健。
