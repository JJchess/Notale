# page-08 [内容页]
Bagging 的核心机制：并行训练高方差模型，再以平均或投票降低预测波动

# page-09 [内容页]
方差下降的边界：基学习器越多且误差相关性越低，聚合收益越明显

# page-10 [内容页]

# page-15 [内容页]
Boosting 的顺序思想：后一个学习器专门补偿当前集成仍未解决的错误

# page-16 [内容页]
AdaBoost 的样本权重：误分类样本在下一轮获得更多关注，正确样本相对降权

AdaBoost 的模型权重：表现更好的弱分类器在最终加权投票中拥有更大影响

梯度提升的统一视角：每一轮拟合当前损失的负梯度，平方损失下表现为拟合残差

# page-20 [内容页]
学习率与树数的协同：较小步长通常需要更多弱学习器，并以计算换取更细致的拟合

# page-21 [内容页]

# page-26 [内容页]
选择集成方法：高方差树优先考虑随机森林，系统性误差可考虑提升，异质模型可考虑投票或堆叠

# page-27 [内容页]
