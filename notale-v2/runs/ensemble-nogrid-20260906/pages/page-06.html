Bootstrap 重采样：每个基学习器看到同一训练集的不同有放回样本

N 次有放回抽样：约 63.2% 样本被选中，约 36.8% 未被选中

原始训练集 D N = 8

未被抽中概率极限：
lim (1 − 1/N)ᴺ = 1/e ≈ 36.8%
Bootstrap 抽样即“有放回抽样”。对于包含 N 个样本的数据集，每次抽取一个样本并放回，重复抽取 N 次构成新子集。 数学上，某个特定样本在 N 次抽取中一次也没被抽中的概率是 (1 - 1/N)^N。当 N 趋向无穷大时，这个概率极限为 1/e，约等于 36.8%。 这意味着每个基模型只看到了大约 63.2% 的去重样本，且部分样本被赋予了 2 次甚至 3 次的高频权重；剩下的 36.8% 样本完全没有参与该模型的训练，被称为“袋外样本（OOB）”。 这种天然的样本分布扰动，使得即使采用完全相同的学习算法，各个基模型也能学到互不相同的决策视角。
