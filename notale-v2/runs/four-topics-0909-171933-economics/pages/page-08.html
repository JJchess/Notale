价格弹性与总收益法则

|E_d| = (%ΔQ) / (%ΔP)　|　TR = P × Q
需求曲线 P(Q) 与总收益 TR(Q) 纵向对齐
P = 100 - Q
TR = P × Q
富有弹性 |E_d| > 1
提价 → TR 下降；降价 → TR 上升
单位弹性 |E_d| = 1
中点 (P=50, Q=50)，TR 达极大值 2500
缺乏弹性 |E_d| < 1
提价 → TR 上升；降价 → TR 下降
代数关系推导
MR = dTR/dQ = P(1 - 1/|E_d|)
当 |E_d| = 1 时 MR = 0，收益取得极值。
这一页讲价格弹性与总收益之间的严格代数关系。 线性需求曲线 P = 100 - Q 的斜率处处恒定，但弹性沿直线变化：上半段富有弹性，下半段缺乏弹性，正中点恰好为单位弹性。 下方的总收益曲线 TR = P * Q 呈现倒抛物线，顶点精准对应需求曲线的单位弹性中点 P = 50, Q = 50。 富有弹性区降价刺激销量带来的增收超过单价降幅，总收益上升；缺乏弹性区降价销量增长迟钝，总收益下降。 因此边际收益 MR = P(1 - 1/|E_d|)，当 |E_d| = 1 时边际收益为零，总收益达到最大值 2500。
