法向量 w 指向 z > 0 正类半空间；增大 b 将边界朝 -w 平移。
各位同学请看，单个神经元的最核心数学本质，就是在输入空间画出一条超平面。在二维输入 x1、x2 下，这个超平面就是直线 w1*x1 + w2*x2 + b = 0。大家拖动权重 w1 和 w2 可以直观看到，法向量的方向决定了直线的倾斜角度；而拖动偏置 b，整条分界线在保持角度不变的情况下平行推移。如果把偏置设为 0，无论权重怎么变，分界线都一定死死穿过原点。正是因为单神经元只能切出一根直挺挺的线，它面对异或等非线性空间时才会无能为力，这正是我们下一节多层感知机隐层协同折叠的起点。
