隐层非线性映射：特征空间的几何折叠

激活函数弯曲输入空间，将线性不可分的对角样本重构为线性可分的高维表征

h = σ(W₁x + b₁)
输入空间 (x₁, x₂) 线性不可分
对角同类分布破坏凸分离性，单条线无法切分。
隐层映射
h₁ = ReLU(x₁ + x₂ - 1)
h₂ = ReLU(x₁ + x₂ - 0.5)
隐层空间 (h₁, h₂) 重构后线性可分
折叠至单侧后，单平面即可完全分割。
在上一页我们看到，单层感知机面对异或问题无能为力，因为异或在二维平面上是线性不可分的。 本页展示了多层感知机的核心奥秘：引入非线性激活函数的隐层。 我们可以将隐层视为一种特征空间变换。这里举了一个具体的参数设定：第一个隐层神经元计算 ReLU(x1 + x2 - 1)，第二个隐层神经元计算 ReLU(x1 + x2 - 0.5)。 看右边的隐层空间：由于 ReLU 激活函数的截断与非线性折叠作用，原本处于异或两端的两个类1样本 (1,0) 和 (0,1)，被同时映射并折叠到了隐层空间的同一点 (0, 0.5)。 而类0的 (0,0) 和 (1,1) 则分别落在 (0,0) 与 (1,1.5)。此时，在这两个坐标之间，一条最普通的线性超平面就能完美将类0与类1切分开。这就是深层网络强大表征能力的几何本质。
