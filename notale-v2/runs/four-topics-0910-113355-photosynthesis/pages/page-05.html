光反应：类囊体膜上的能量与电子级联

水裂解放氧提供初始电子，质子梯度驱动 ATP 与 NADPH 生成

2H₂O + 2NADP⁺ + 3ADP + 3Pi → O₂ + 2NADPH + 3ATP

阶段 1：光裂解水，产生氧气与初始电子
① 水裂解与供能 PS Ⅱ

P680 吸收光能激发夺取电子，水在腔侧裂解产生初始电子与氧气。

2H₂O → 4H⁺ + 4e⁻ + O₂↑
② 电子链与跨膜梯度 Cyt b₆f

电子经 PQ 与 Cyt b₆f 传递释放能量，逆浓度将 H⁺ 泵入类囊体腔建立势能。

腔内 H⁺ 积累 · 跨膜 ΔpH ≈ 3
③ 终端受体形成还原力 PS Ⅰ / FNR

电子到达 PSⅠ 再次被光激发，经 FNR 还原酶生成高能还原剂 NADPH。

NADP⁺ + 2e⁻ + H⁺ → NADPH
④ 化学渗透驱动 ATP ATP 合成酶

腔内质子顺梯度经 F₀ 通道冲向基质，带动 F₁ 机械旋转合成高能 ATP。

ADP + Pi + 质子势 → ATP
各位同学，今天我们深入类囊体膜的微观分子工厂——光反应阶段。 请大家看中央的核心结构：这是镶嵌在类囊体双层磷脂分子上的四组蛋白机器。 第一步，水的光解。在光系统Ⅱ中，P680 吸收光能激发失去电子，极高电位的反应中心裂解水分子，不仅释放出生命的氧气，还产生最初的质子与电子。 第二步，电子传递链。电子经由 PQ 和细胞色素 b6f，能量被用来将基质里的氢离子泵进类囊体腔，腔内 pH 降到 5 左右，形成强烈的跨膜质子势。 第三步，光系统Ⅰ吸收光能把电子提升到更高能级，在 FNR 酶的作用下加氢还原 NADP⁺，生成富能还原剂 NADPH。 第四步，米切尔化学渗透假说证实，腔内高浓度的质子顺浓度差冲出 ATP 合成酶，驱动分子马达旋转生成 ATP。 这就是光反应的终极产物：ATP 与 NADPH，它们将被输送至叶绿体基质，为接下来的暗反应提供能量与还原驱动。
