Bootstrap 重采样：从同一训练集构造彼此不同的有放回样本集

每次有放回抽取 N 个样本，约 63.2% 被抽中，剩余 36.8% 未被选中形成袋外样本（OOB）。

理论未抽中概率 36.8% (1 - 1/N)ᴺ → 1/e
当前三个子集平均覆盖率 63.3%
袋外样本比例 36.7%
在这一页中，我们要理解 Bagging 的第一步：如何用有限的原始数据培养出一组“各不相同”的模型。 如果让所有基分类器在完全相同的样本集上训练，它们的决策就会高度雷同，聚合就无法抵消方差。 Bootstrap 的做法是“大小为 N 的有放回抽样”。 数学上，一个样本在一次抽取中未被选中的概率是 1 - 1/N。连续抽取 N 次后，依然完全没被抽中的概率为 (1 - 1/N) 的 N 次方。 当 N 趋向无穷大时，这个极限恰好是 1/e，约等于 36.8%。 这意味着每个重采样集合天然包含约 63.2% 的去重原始样本，并带有多次重复的样本；而剩下的约三分之一样本从未参与该子集的训练，这被称为“袋外样本”（OOB），正好为后续无需额外验证集的无偏自评估提供了基础。
