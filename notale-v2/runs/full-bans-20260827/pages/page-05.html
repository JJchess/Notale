拖动同一个合成分数，沿垂直投影线读曲线交点，再核对右侧预测；曲线形状始终不变。预测是网络当前给出的 0 到 1 输出，也可显示成百分比。

主读数整数百分比，便于快速判断

边界越来越接近 0 或 1，但不越过
0 下界：只接近，不到达

1 上界：只接近，不到达

sigmoid 让任意合成分数都变成 0%–100% 的预测；0 分正好对应 50%。
