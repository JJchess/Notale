# page-05 · 把分数压成预测 · **100 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `ACT I · ACTIVATION` |
| 主标题 | 激活函数把合成分数压到 0 到 1 |
| 收束句 | sigmoid 让任意合成分数都变成 0%–100% 的预测；0 分正好对应 50%。 |
| 下一问 | 有了预测和正确答案，怎样把“错了多少”记成一个数？ |

## 知识结构：process

**关系不变量**：输入分数游标、sigmoid 曲线上的交点和右侧预测读数必须由同一条垂直投影线连接；横轴 0 与纵轴 0.5 必须同时对齐中点，不得把曲线画成硬门槛。

**共享原语**：`.k-process` 表达“合成分数→激活函数→预测”的单向转换，`.step` 分别承载输入游标、压缩曲线和输出菱形，`.arw` 维持向右阅读；整体置于 `.focus`，曲线是中央唯一操作焦点。

## 表征形式

交互式 sigmoid 曲线：ECharts 绘制连续函数、坐标轴、参考线和当前点，DOM range 作为扫描控件。当前输出调用 `Lec.P` 中公开的 layers 逐层计算接口，配置单层 `sigmoid` 激活；显示常量直接采用下表中的 `Lec.K` 实际值。

## 主工作流

build-chart ← 在统一坐标上准确联动输入游标、曲线交点与百分比预测

## 激活参照与画面读数

页面只显示一个公式：`预测 = 1 / (1 + e^(−合成分数))`。

| 内容 | 画面值 | 用途 |
|---|---:|---|
| `ACTIVATION_REFERENCE.sigmoid.asymptoticOutputMin` | 0 | 纵轴下界与“接近 0%”旁注 |
| `ACTIVATION_REFERENCE.sigmoid.asymptoticOutputMax` | 1 | 纵轴上界与“接近 100%”旁注 |
| `ACTIVATION_REFERENCE.sigmoid.outputAtZero` | 0.5 | 中点参考线与默认预测 |
| 合成分数默认值 | 0.0 | 初始游标 |
| 默认预测 | 50% | `.mark-pred` 菱形主读数 |

“激活函数”首次解释为把合成分数转换成规定输出范围的规则；“sigmoid”解释为本页采用的 S 形激活函数；“预测”解释为网络当前给出的 0 到 1 输出，可显示成百分比。

横轴为“合成分数”，范围 −6 至 6，主刻度为 −6、−3、0、3、6；纵轴为“预测”，范围 0 至 1，标记 0%、50%、100%。上下边缘写“越来越接近，但不越过”。

## 交互

学习者拖动合成分数游标，范围 −6.0 至 6.0，步长 0.1，默认 0.0。曲线不动，垂直投影线、交点和预测菱形沿曲线同步移动；主读数显示到整数百分比，旁边的小读数保留三位小数用于复看。

拖过 0 时，50% 参考线保持可见；负分数给出低于 50% 的预测，正分数给出高于 50% 的预测。提供三个快捷按钮“−2”“0”“2”，它们只是观察位置，不标正确答案。

## 动效

拖动时交点沿曲线在 100ms 内更新，预测数字使用 `[data-anim="count"]`；从横轴游标到曲线、再到预测读数的路径执行一次短促 `[data-anim="trace"]`。曲线本身不反复绘制。

## 核对

| 合成分数 | 期望 sigmoid 输出 | 百分比显示 |
|---:|---:|---:|
| −2 | 0.119203 | 12% |
| 0 | 0.500000 | 50% |
| 2 | 0.880797 | 88% |

精确值只用于测试和三位小读数；整数百分比为主画面显示。还应核对所有有限输入的输出严格位于 0 与 1 之间。

## 不许碰

不得引入正确答案、比较预测好坏或计算损失；二分类交叉熵归 p06。不得回讲输入乘加或偏置平移，只把它们产出的“合成分数”作为本页输入。
