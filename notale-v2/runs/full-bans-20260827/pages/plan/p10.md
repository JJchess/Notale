# page-10 · 预测逐层向前 · **105 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `FORWARD PASS` |
| 主标题 | 预测按层向前，直到得到最终输出 |
| 收束句 | 前向传播只读取当前参数，把一层的结果交给下一层；此时还没有修改任何权重。 |
| 下一问 | 最终预测错了，责任会沿哪些连接返回？ |

## 知识结构：process

关系不变量：输入、隐藏层计算和最终输出必须从左到右共用一条方向轴；每层只能读取左侧已经产生的值，已出现的数值在后续步骤中持续保留。

共享原语：`.k-process` 提供唯一的左向右流程，三个 `.step` 分别承载输入、隐藏层和输出，`.arw.flow-forward` 明确数值传递方向。整组落入 `.stage-cards`，卡片同宽、同基线。

## 表征形式

交互式三阶段数值台。学习者逐层推进，网络节点与连接只呈现前向实线箭头；隐藏层卡同时显示合成分数和 sigmoid 输出。

原生 SVG 更适合固定的小型网络和逐层显隐，无需关系布局库。

## 三阶段读数

| 阶段 | 画面文字与数值 |
|---|---|
| 输入 | `x₁ = 0.80`；`x₂ = 0.40` |
| 隐藏神经元 h₁ | 权重 `0.50, −0.50`，偏置 `0.00`；合成分数 `0.20`；输出 `0.550` |
| 隐藏神经元 h₂ | 权重 `−0.25, 0.75`，偏置 `−0.10`；合成分数 `0.00`；输出 `0.500` |
| 输出神经元 | 读取 `h₁` 的权重 `1.00`、读取 `h₂` 的权重 `0.00`，偏置 `−0.20`；合成分数 `0.350` |
| 最终预测 | 菱形预测标记内写 `58.7%` |

页面只显示三位小数；权重旋钮均为只读状态，并附短标“本页不更新”。

## 交互

主按钮依次显示“推进到隐藏层”“推进到输出层”“重新播放”。每次点击后，下一段实线连接出现，目标层数值由占位短横线变为读数；已完成层保持可见。键盘 Enter、Space 与点击行为一致。

“重新播放”恢复到仅输入已记录的状态。交互没有正确位置，目的只是让学生观察“上一层先算完，下一层才能读取”。

## 动效

每次推进时，当前实线连接从左向右描绘，时长 500ms；同层两个隐藏神经元的读数相隔 120ms 出现。数字变化使用计数动效，但最终值必须精确落在内容表数值上。

## 核对

| 检查 | 期望结果 |
|---|---|
| `0.80×0.50 + 0.40×(−0.50)` | `0.20`，sigmoid 后约 `0.549834` |
| `0.80×(−0.25) + 0.40×0.75 − 0.10` | `0.00`，sigmoid 后 `0.500000` |
| `0.549834×1.00 + 0.500000×0.00 − 0.20` | `0.349834`，sigmoid 后约 `0.586577` |
