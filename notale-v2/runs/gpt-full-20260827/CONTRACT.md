## 1. 这堂课在讲什么

全课主张：神经网络的“学习”不是突然理解答案，而是重复一个可观察的动作——先预测，把错误变成可比较的罚分，从输出端反向判断每个参数该往哪边改，再做有限的小步更新。

五幕任务：

1. 01–03：把“学习”落到反复修改内部旋钮的动作上。
2. 04–08：说明单个神经元如何汇总输入、加入偏置并输出预测；同时确认它只能形成直线式边界。
3. 09–13：把预测差异压成损失；通过比较参数附近的损失找到下坡方向，并反复小步更新。
4. 14–18：用隐藏层组合多个简单边界；用反向传播把最终错误逐层分摊到所有连接。
5. 19–22：串起“前向预测—计算损失—反向传播—更新参数”，再用未参与训练的新样本检验是否真的学会。

跨页证据链：

- E1：输入、权重、偏置和压缩门共同决定预测；参数变化会系统性地改变输出。
- E2：损失把预测与答案的差异变成一个数；比较附近位置可得到下降方向。
- E3：沿下降方向反复做有限小步，参数会逐渐形成更合适的分类边界。
- E4：隐藏层组合简单边界；反向传播逐层传递“影响有多大”，一次得到所有参数的更新方向。
- E5：完整训练循环可以降低训练损失，但新样本表现必须另行检验。

01、03、08、13、18、21、22 为无交互页，不添加可点击、拖动或可调控件。其余页面是否交互、交互目标及页内构图只服从本页 `pNN.md`。

不得提前讲解、复现或暗示由别页负责的证据；“不许碰”的内容不以补充框、预告动画、旁注或默认隐藏状态出现。跨页只复用统一视觉语法：

- 样本是直径 18–22 px 的实心圆；参数是带刻度的实体旋钮。
- 前向信息流是 3 px 蓝色实线单向箭头；反向责任是在同一路径上的反向空心箭头。
- 神经元是圆角 12 px 矩形；层是无阴影的竖向框组。
- 正确边界用连续线；错误或尚未形成的边界用 6 px 间隔虚线。
- 每页至少留出画布宽度 8% 的空白，隔开输入、计算和结果。
- 逐行账本固定记录“预测—罚分—改动”；坡面脚印只表示有限幅度的参数更新。

## 2. 颜色语义

| token / 色相 | 唯一含义 | 允许出现的位置 |
|---|---|---|
| `signal / #1F5A7A` 深蓝 | 模型实际算出的信号、预测或信息流 | 预测值、激活、前向箭头、模型输出、由模型生成的边界 |
| `focus / #D97706` 琥珀橙 | 当前需要观看、点击或拖动的位置 | 当前控件、当前步骤、教师当下指向的局部高亮 |
| `loss / #A33A3A` 暗红 | 损失、错误或错误贡献 | 损失数值、误差标记、罚分轨迹、错误区域 |
| `given / #31363B` 深灰 | 题目给定的数据与目标答案 | 输入数据、样本标签、目标值、题干条件 |
| `paper / #F4F1E8` 暖灰 | 实验记录本底色，无概念含义 | 页面和记录区域底色 |

语义色不得交换含义或用作装饰。边框、网格、分隔、禁用态、普通正文及无概念含义的图形使用主题中性色。颜色不能成为唯一编码；同时使用形状、线型、箭头方向或文字标签。不得引入霓虹发光、暗色宇宙背景、生物脑图像、代码编辑器界面或黑板式微积分推导。

## 5. 技术契约

固定文档骨架：

    <!doctype html>
    <html lang="zh">
    <head>
      <meta charset="utf-8">
      <link rel="stylesheet" href="assets/base.css">
      <link rel="stylesheet" href="assets/theme.css">
    </head>
    <body data-page="NN" data-total="22">
      <div id="stage"></div>
      <script src="assets/base.js"></script>
      <script src="assets/lec.js"></script>
    </body>
    </html>

- 只修改 `#stage` 内容。保留两位 `data-page` 和 `data-total="22"`；不得把页码显示给读者。
- 逻辑画布固定为 1600 × 900，不得滚动。`#stage` 是 flex 列；顶层区块使用固定高度或 flex 份额，主内容区使用 `flex:1`。
- 默认使用 flex；只有真正二维对齐时使用 grid。
- 字号只用主题 token。正文与成句说明 ≥16px；控件标签、图例、图注和提示 ≥14px；纯数字刻度 ≥12px；多行文字行高 ≥1.35。
- 颜色、字体、圆角、阴影和共享组件取自主题接口。一次性尺寸可内联，不为单页尺寸创建公共类。
- 不移除或覆盖 `.min0`、`.cv-fill`、`.no-pan` 的机制；缩放画布内禁止 `position:fixed`。
- 页面必须自包含运行，只引用 `pages/` 内相对路径，不使用 CDN。
- 图表优先使用已安装库，不重复实现成熟能力。ECharts 必须使用 SVG renderer，并显式设置符合字号地板的全局、坐标轴、图例和提示文字。
- Konva 只绘制场景图形；文字优先用 DOM 叠放。必须使用 `Konva.Text` 时显式指定合规字号。
- KaTeX 必须同时引用本地 CSS 与 JS；统一以 ≥20px 基准字号排版公式。
- Canvas 使用 `Deck.fit()` / `Deck.autofit()`；指针坐标使用 `Deck.pt()`；动画使用 `Deck.loop()`。
- 动画不得承担首屏唯一信息；首屏静止状态必须已经包含可讲内容。

两三层小网络的实时训练必须优先使用 `mlp.js`，不得用 TensorFlow.js 替代。使用 TensorFlow.js 时，每步必须 `tf.tidy()` 或显式 `dispose()`，并检查张量数量不持续增长。

## 7. 文字风格

面向无微积分、线性代数和编程基础的大学通识课学生。先说可观察动作，再给术语；术语首次出现时用一句人话限定含义。可以使用“输入、权重、偏置、预测、损失、学习率、隐藏层、前向传播、反向传播、训练集、测试样本”，但不得把导数、梯度、链式法则、矩阵运算或代码语法设为理解前提。

使用适合教师口述的短句；一句只推进一个判断，避免连续堆叠定义。提示使用直接动作口吻，如“拖动旋钮”“比较两次罚分”“先看箭头方向”；不使用责备、考试式或幼儿化口吻。

删除“如图所示”“显而易见”“接下来我们将”“本页旨在”等空指代和教学设计元评论。数字要给可感换算，例如“从 0.8 降到 0.2，罚分只剩原来的四分之一”。近似、经验性或受数据影响的结论明确写“约”“在这组样本中”或“当前设置下”。

标签贴近所指对象；同一参数跨页保持同名。按钮用动作词，状态用结果词。收束句只写读者应带走的主张；下一问负责推进到后续页面，不把收束写成本页内容摘要。
