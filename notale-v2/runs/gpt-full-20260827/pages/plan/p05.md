# page-05 · 门槛一移动，神经元就会改口 · **100 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `ONE NEURON · BIAS` |
| 主标题 | 门槛一移动，同一份输入总分也可能得到不同回答 |
| 收束句 | 同一总分下，门槛越低越容易回答“是”；偏置就是决定这个门槛的旋钮。 |
| 下一问 | 如果不只回答“是”或“否”，神经元怎样表达自己有多确定？ |

## 知识结构：comparison

关系不变量：固定的输入总分与可移动门槛必须落在同一条水平数轴、使用同一尺度和零点；两者之间的相对位置直接连到右侧“是／否”结果，不能拆成两个独立图。

共享原语：`.k-comparison` 在 `canvas-full` 中组织“固定总分—可动门槛—当前回答”的同基线比较；`.ctl` 承担门槛滑杆及键盘操作；`.panel` 收纳右侧同步读数，使原因与结果保持一眼可追踪。

## 表征形式

交互式数轴仪器：蓝色固定标记表示输入总分，琥珀色三角标记表示决定门槛，右侧同步显示偏置、最终总分和回答。

使用原生 DOM 与 SVG；几何只有一条数轴、两个标记和一段差值，不需要图表库。

## 主工作流

build-interaction ← 拖动门槛时同步维护位置、偏置换算、最终总分与二元回答

## 一条标尺上的读数

| 画面对象 | 文字或数值 |
|---|---|
| 数轴标题 | `同一份输入总分，换一个门槛` |
| 数轴范围 | `−3` 至 `3`，主刻度每 `1` |
| 固定标记 | `输入总分 = 1.2` |
| 可动标记 | `决定门槛 θ` |
| 默认门槛 | `θ = 0.5` |
| 偏置读数 | `偏置 b = −θ` |
| 最终总分 | `z = 输入总分 + b` |
| 判断规则 | `z ≥ 0：是`；`z < 0：否` |
| 等价提示 | `输入总分 ≥ 门槛，回答“是”` |
| 右侧结果标题 | `神经元当前回答` |
| 默认结果 | `是` |
| 操作提示 | `左右拖动门槛；也可用方向键微调` |
| 复位按钮 | `回到 θ = 0.5` |

## 交互

学习者拖动门槛 `θ`，范围 `−3.0～3.0`、步进 `0.1`，默认 `0.5`；输入总分始终固定为 `1.2`。每次变化立即更新门槛位置、`b=−θ`、`z=1.2+b` 及“是／否”回答。

当门槛从 `1.2` 左侧越过到右侧时，回答由“是”切为“否”；恰好 `θ=1.2` 时按 `z≥0` 显示“是”。页面不设置正确位置，也不使用对错反馈。点击复位恢复默认值。

## 核对

| 门槛 θ | 偏置 b | 最终总分 z | 期望回答 |
|---:|---:|---:|---|
| `−0.8` | `0.8` | `2.0` | 是 |
| `1.2` | `−1.2` | `0.0` | 是 |
| `1.6` | `−1.6` | `−0.4` | 否 |

## 不许碰

不展示 sigmoid 曲线、概率、百分比或“压缩到 0～1”的过程，这些归 p06。两个权重和输入贡献保持锁定，不允许自由调参；三枚参数的联合手调归 p10。
