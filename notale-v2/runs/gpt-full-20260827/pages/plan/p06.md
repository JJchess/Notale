## 知识结构：process

关系不变量：左侧总分游标、中央单向箭头、右侧压缩曲线与预测读数必须处在同一水平流程中；游标位置、曲线上对应点和数值读数始终表示同一个 `z`，不可分离或使用不同尺度的总分轴。

共享原语：`.split-lr` 左侧承载可拖动的总分仪器，右侧承载映射结果；`.k-process` 用 `.step` 固定“总分—压缩门—预测”的顺序，并以 `.arw` 穿过中部留白；右侧 `.panel` 将曲线与实时读数收成同一个结果单元。

## 表征形式

交互式映射仪器：左侧为带正负刻度的水平总分游标，右侧为 sigmoid 曲线、同步定位点和大号预测读数。

使用 ECharts 绘制固定坐标轴、曲线和联动标记；滑杆与读数使用原生 DOM，避免为单一控件增加额外依赖。

## 主工作流

build-chart ← 让滑杆、曲线定位点与概率读数保持真实且同步的定量映射

## 压缩门的读数

## 交互

学习者拖动 `z` 游标，范围 `−6` 至 `6`、默认 `0`、步进 `0.1`；键盘方向键同样可逐格调整。每次变化立即同步更新右侧曲线定位点、`p` 的三位小数读数，以及“每 100 次中约有多少次回答 1”。

曲线上的点只能沿曲线移动：向右时逐渐接近 1，向左时逐渐接近 0，经过 `z=0` 时必须准确显示 `p=0.500`。本交互没有正确位置或成功反馈；“回到 0 分”仅用于课堂快速复位。

## 核对

| 输入 | 期望输出 |
|---:|---:|
| `z = −2` | `p = 0.1192029…`，画面显示 `0.119`，生活化读法约 `12 次` |
| `z = 0` | `p = 0.5000000`，画面显示 `0.500`，生活化读法 `50 次` |
| `z = 2` | `p = 0.8807971…`，画面显示 `0.881`，生活化读法约 `88 次` |

另核对范围端点：`z=−6 → p≈0.002473`，`z=6 → p≈0.997527`；读数不得显示为精确的 `0` 或 `1`。
