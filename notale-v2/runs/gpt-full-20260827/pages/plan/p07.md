# page-07 · 一条直线的极限 · **85 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `LIMIT · ONE NEURON` |
| 主标题 | 无论怎样摆，一个神经元都只能画一条直线 |
| 收束句 | 两类点彼此交错时，单条直线最多分对 3 个，不能把 4 个全部分开。 |
| 下一问 | 边界摆不好时，模型怎样知道自己错了多少？ |

## 知识结构：classification

关系不变量：四个样本必须在同一正方形坐标场、同一尺度下同行比较；唯一分类线贯穿整个坐标场，两侧分别嵌套“预测 0”和“预测 1”，每个点的目标答案与当前预测必须就地相邻。

共享原语：`.k-classification` 规定“全部样本—直线两侧—各点归属”的层级；中央 `.box` 承载完整坐标场，`.lv` 标记预测侧，`.bt` 把动态分对数挂接到同一分类结果。骨架铺满 `.canvas-full`，右下只留窄控制带，不另起第二幅图。

## 表征形式

交互式二维分类场：学习者平移、旋转一条有方向的直线，并交换两侧类别；点旁即时显示预测是否符合答案。

使用 Konva；拖拽命中、裁切半平面、端柄旋转和文字覆盖比常规图表更适合自定义画布交互。

## 主工作流

build-interaction ← 让单条可拖动直线以确定、可访问的方式实时重算四点分类

## 四个交错样本

| 坐标 | 点旁文字 | 目标类别 |
|---|---|---:|
| `(0, 0)` | `答案 0` | 0 |
| `(1, 0)` | `答案 1` | 1 |
| `(0, 1)` | `答案 1` | 1 |
| `(1, 1)` | `答案 0` | 0 |

坐标轴只显示 `x₁`、`x₂` 与刻度 `0`、`1`。预测侧写 `预测 0`、`预测 1`；连续线写 `这个神经元的分类线`。状态读数为 `分对 n / 4`、`本次最高 n / 4`。默认竖线 `x₁=0.5`，左侧预测 0、右侧预测 1，初始分对 `2 / 4`。

## 交互

拖动线身可在坐标场内平移；拖动琥珀色端柄可旋转 `0°–180°`；“交换两侧”按钮互换预测 0 与预测 1；“复位”恢复默认竖线并清除最高记录。键盘聚焦线身后，方向键平移，`[`、`]` 每次旋转 `2°`，空格交换两侧。

每次变化立即重绘两侧淡色区域，并按 `p≥0.5` 属于预测 1 的统一口径更新每点的 `分对/分错` 标记、总数和最高记录。达到 `3 / 4` 时显示：`已经只错 1 个；继续摆，只会把错误换到别的点。` 不设置“4 / 4”成功态。

## 核对

| 状态 | 期望预测 | 期望分对 |
|---|---|---:|
| `x₁=0.5`，右侧为 1 | 左列 0，右列 1 | `2 / 4` |
| `x₁+x₂=0.5`，右上侧为 1 | 仅 `(0,0)` 为 0 | `3 / 4` |
| 任意直线、任意两侧指派 | 不可能同时符合四个目标 | 最大 `3 / 4` |

点恰在线上时按预测 1 处理，避免边界状态在像素误差下抖动。

## 不许碰

不引入隐藏层、多神经元或组合边界；这些归 p14。只呈现单神经元的直线限制，不讲损失、罚分或参数如何更新；罚分归 p09，调参与下降方向归 p10–p12。
