# page-09 · 自信地答错，罚得更重 · **100 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `LOSS · 罚分` |
| 主标题 | 同样有信心，答错比答对罚得重得多 |
| 收束句 | 交叉熵把预测变成罚分：答对越自信，罚分越接近 0；答错越自信，罚分越大。 |
| 下一问 | 既然罚分能比较，转动哪些旋钮能让 4 个样本的平均罚分下降？ |

## 知识结构：comparison

1. **关系不变量**：左右两栏始终使用同一个信心值、同一个目标答案和同尺度损失尺；左栏“预测正确”、右栏“预测错误”必须逐行同基线对齐，使差异只来自预测方向。
2. **共享原语**：`.k-comparison` 组织共享信心、预测概率与交叉熵罚分三行；两侧 `.panel` 落入 `.split-lr`，右侧损失读数使用错误语义，底部 `.conclusion` 横跨两栏收束比较。

## 表征形式

交互式双栏损失仪器：共享信心滑杆驱动两侧概率读数和同尺度竖向罚分柱，左侧固定为答对，右侧固定为答错。

原生 DOM 与 SVG 更合适；仅有一维滑杆、数值换算和两根柱，不增加图表库依赖。

## 主工作流

build-interaction ← 让同一信心同时生成“答对／答错”两组可核验罚分

## 同一信心的两种结果

| 位置 | 画面文字或值 |
|---|---|
| 共同题目 | `目标答案：1` |
| 控件标签 | `模型对自己答案的信心` |
| 默认信心 | `90%` |
| 左栏标题 | `答对了` |
| 左栏预测 | `预测 1；给答案 1 的概率 p = 0.900` |
| 左栏罚分 | `交叉熵罚分 L = 0.105` |
| 右栏标题 | `答错了` |
| 右栏预测 | `预测 0；给答案 1 的概率 p = 0.100` |
| 右栏罚分 | `交叉熵罚分 L = 2.303` |
| 规则卡 | `目标为 1 时：L = −ln(p)` |
| 通用公式（次级） | `L = −[t ln(p) + (1−t) ln(1−p)]` |
| `ln` 旁注 | `把概率换成罚分的固定规则` |
| 尺度标注 | `罚分：0 至 4.7（本仪器范围）` |

## 交互

学习者拖动共享信心滑杆，范围 `50%–99%`、步进 `1%`、默认 `90%`。左栏令 `p=信心`，右栏令 `p=1−信心`；两侧概率、罚分数字和罚分柱立即同步变化。

拖向 `99%` 时，左柱逼近 0，右柱升至约 4.605；拖回 `50%` 时两柱同为约 0.693。滑杆支持方向键，当前百分比通过可访问读数播报。状态完全可逆，不设成功位置，也不另设复位按钮。

## 核对

| 信心 | 答对：p / L | 答错：p / L |
|---:|---:|---:|
| `50%` | `0.500 / 0.693` | `0.500 / 0.693` |
| `90%` | `0.900 / 0.105` | `0.100 / 2.303` |
| `99%` | `0.990 / 0.010` | `0.010 / 4.605` |

动态计算使用自然对数；概率仅在计算时夹到 `[1e-12, 1−1e-12]`，该常量不印在画面上。

## 不许碰

不引入权重、偏置或任何“参数怎样改变罚分”的解释；三枚参数旋钮及人工调参归 p10。本页也不寻找下降方向，正负小步探路归 p11。

## 存疑

公开的两个 `Lec.P` 签名均未提供交叉熵计算所需的参数名与返回键，无法按接口调用本页动态罚分；实现时需补充可用签名，否则只能按给定公式直接计算。
