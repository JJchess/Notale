# page-12 · 下坡一步 · **95 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `ONE STEP · GRADIENT DESCENT` |
| 主标题 | 按一下，三个参数就一起向下坡迈一步 |
| 收束句 | 学习的数学动作：用当前的下坡方向数值，把每个参数小改一点。 |
| 下一问 | 如果旋钮多到无法逐个探路，怎样一次找出所有方向？ |

## 知识结构：process

关系不变量：画布以“当前参数 → 算出方向 → 同步更新 → 新损失”为唯一横向流程，四步同基线相连；三枚参数在更新前后始终逐行对齐，右侧损失曲线与同一步编号同步。

共享原语：`.canvas-full.k-process` 承担整条单步流程，`.step` 固定四个阶段，`.arw` 表示计算方向；参数行使用 `.knob` 与等宽读数，曲线置于末步 `.panel` 内，作为本次更新的结果而非平行叙事。

## 表征形式

交互式单步训练仪器：三行参数更新账本配一张平均损失折线图，每次点击只执行一次真实更新。

折线图使用 ECharts；按钮、参数账本与计算状态使用原生 DOM，更适合清晰同步一步离散状态。

## 四个样本与更新口径

| 画面对象 | 写入内容 |
|---|---|
| 样本 | `(0,0)→0`、`(1,0)→1`、`(0,1)→1`、`(1,1)→1` |
| 初始参数 | `w₁ = −0.800`　`w₂ = 0.400`　`b = −0.200` |
| 当前预测 | `0.450`　`0.269`　`0.550`　`0.354`，顺序与样本一致 |
| 初始平均损失 | `0.887 平均罚分` |
| 学习率 | `0.500`，固定显示为“每步比例” |
| 更新式 | `新参数 = 旧参数 − 0.500 × 下坡方向数值` |
| 参数行表头 | `参数｜旧值｜下坡方向数值｜本步改动｜新值` |
| 曲线坐标 | 横轴“学习步数”`0–12`；纵轴“平均罚分”`0–1.0` |
| 主按钮 | `执行 1 步学习` |
| 次按钮 | `重新开始` |

页面实时计算 `z=w₁x₁+w₂x₂+b`、sigmoid、四个交叉熵的平均值及三个下降方向数值；不把核对用的后续答案预先印在画面上。

## 交互

默认停在第 0 步。点击“执行 1 步学习”后，同时更新 `w₁`、`w₂`、`b`，参数行显示旧值、方向、改动和新值；四个预测、平均损失读数及曲线新增点立即同步。最多执行 12 步，到达后按钮改为“已完成 12 步”，仍可重新开始。

学习者不能拖动单枚旋钮，也不能改变学习率；本页只观察算法怎样自动、同步地迈步。重新开始恢复固定初始参数并清除第 0 步之后的曲线点。

## 动效

触发后，三枚旋钮同时旋转到新刻度，时长 `360 ms`；更新式中的“本步改动”在 `120 ms` 后亮起，曲线新点再延后 `120 ms` 出现并以 `240 ms` 连线。仅响应点击，不自动连播。
