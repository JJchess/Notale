# page-14 · 直线围出新边界 · **100 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `HIDDEN LAYER` |
| 主标题 | 隐藏层不是画一条更聪明的线，而是组合多条简单边界 |
| 收束句 | 每个隐藏神经元只负责一次直线切分；下一层把这些切分合起来，就能围出分区边界。 |
| 下一问 | 放入一个样本后，它怎样依次经过这些层并得到预测？ |

## 知识结构：classification

关系不变量：三联从“单条切分—同时叠放—组合区域”由左至右同行；三个方格使用相同坐标范围、刻度和样本位置，激活的边界在三栏保持同一编号与线型。

共享原语：`.triptych.k-classification` 承担三层归属关系；每栏以 `.box` 容纳同尺度方格，`.boundary` 让单线、叠线与最终连续边界保持可追踪对应。

## 表征形式

交互式三联 SVG：左栏单看最近操作的隐藏神经元，中栏叠放所有已开启直线，右栏显示这些条件共同保留的预测 1 区域。

原生 DOM/SVG 更适合固定四条直线、矩形裁切与按钮状态，无需额外可视化库。

## 主工作流

build-interaction ← 四个开关必须同步改变单线说明、叠加边界与组合区域

## 四条隐藏边界

| 编号与画面标签 | 直线 | 保留的一侧 | 默认 |
|---|---|---|---|
| `H1 左边挡板` | `x₁ = −0.5` | `x₁ ≥ −0.5` | 开 |
| `H2 右边挡板` | `x₁ = 0.5` | `x₁ ≤ 0.5` | 开 |
| `H3 下边挡板` | `x₂ = −0.5` | `x₂ ≥ −0.5` | 开 |
| `H4 上边挡板` | `x₂ = 0.5` | `x₂ ≤ 0.5` | 开 |
| 中栏标题 | `已开启的简单边界` | 标签：`每条线只切一次` | — |
| 右栏标题 | `下一层组合` | 全开时标注：`四条都满足 → 预测 1` | — |

三栏坐标均为 `x₁,x₂ ∈ [−1,1]`，显示刻度 `−1、−0.5、0、0.5、1`。样本固定：目标 1 为 `(±0.2,±0.2)`；目标 0 为 `(±0.8,0)`、`(0,±0.8)`、`(±0.75,±0.75)`。每个实心圆旁直接标 `1` 或 `0`，不能只靠颜色区分类别。

## 交互

学习者点击或键盘切换 `H1–H4`。按钮同时承担开关与选中：最近操作者用强调色，左栏展示它的直线、保留侧和“已开启/已关闭”；关闭时该线改为虚线且不参与中、右栏组合。

右栏实时显示所有已开启半平面的交集；少一条边，区域就在对应方向敞开。四条全关时不填充区域，显示 `还没有可组合的边界`。不设正确答案；操作提示为 `试着关掉一条：组合区域会从哪一边打开？`。提供 `恢复四条`，回到全开且选中 `H1`。

## 核对

- 四条全开：预测 1 区域应为 `−0.5 ≤ x₁ ≤ 0.5` 且 `−0.5 ≤ x₂ ≤ 0.5`。
- 仅关闭 `H2`：点 `(0.75,0)` 从区域外变为区域内；点 `(−0.75,0)` 仍在区域外。
- 仅开启 `H1`：预测 1 区域应覆盖方格中 `x₁ ≥ −0.5` 的整个右侧，不得误画成封闭矩形。
