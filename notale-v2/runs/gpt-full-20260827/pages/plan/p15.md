# page-15 · 同一个样本向前走 · **110 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `FORWARD PASS` |
| 主标题 | 同一个样本逐层变形，最后成为一次预测 |
| 收束句 | 前向传播只做一件事：把输入依次交给后面的神经元计算，直到得到预测。 |
| 下一问 | 预测已经算出；如果它错了，前面的连接怎样知道自己该负责多少？ |

## 知识结构：process

**关系不变量**：左侧样本卡与右侧网络共用一条水平行进基线；输入层、隐藏层、输出层等距排列并由单向实线相连。当前层、对应读数与经过该层的信号必须同步高亮。

**共享原语**：`.k-process` 规定从左到右的阶段顺序，`.step` 承载三层节点与实时数值，`.arw` 只表示前向信息流；整体落入 `.split-lr`，左侧放投放控制与样本，右侧保留主要传播路径。

## 表征形式

交互式分步网络图：固定样本进入一个 `2→3→1` 小网络，逐层显露真实总分与激活值。原生 DOM 配合 SVG 更合适，节点少、路径固定，便于同步读数、键盘控制和信号沿线运动，无需图表库。

## 主工作流

build-interaction ← 让单一样本可播放、暂停并回看逐层计算状态

## 一次前向传播

| 阶段 | 画面文字 | 写入画面的值 |
|---|---|---|
| 样本 | `投入样本` | `x₁=1　x₂=0` |
| 输入层 | `原样接收两路输入` | `1`、`0` |
| 隐藏神经元 H₁ | `先汇总，再压缩` | `z=1.000 → h=0.731` |
| 隐藏神经元 H₂ | `先汇总，再压缩` | `z=−0.400 → h=0.401` |
| 隐藏神经元 H₃ | `先汇总，再压缩` | `z=0.400 → h=0.599` |
| 输出层 | `汇总三个隐藏信号` | `z=0.562 → p=0.637` |
| 预测牌 | `约每 100 次中有 64 次回答“1”` | `预测：1` |
| 控件 | 按钮与进度 | `投入样本`、`暂停`、`重新开始`、`输入—隐藏—输出` |

隐藏层旁固定小注：`每个神经元看到的是同一份输入，但使用不同的连接强度。`  
输出判定旁固定小注：`p≥0.5，回答“1”。`

## 交互

默认停在进度 `0/3`，样本位于左侧托盘，网络读数以短横线占位。点击“投入样本”或按空格后，进度依次到输入、隐藏、输出；当前阶段立即显示数值并高亮对应节点和箭头，已经过部分保留为深蓝，未经过部分保持中性。

“暂停”冻结当前位置；进度条可在 `0–3` 间拖动或用左右方向键逐段回看。“重新开始”清空读数并把同一固定样本放回托盘，不随机更换参数或输入。

## 动效

样本卡向右移动 `48px`、`320ms` 后停在输入层外；随后蓝色信号点沿输入到隐藏的连线运动 `520ms`，三枚隐藏节点按 `90ms` 错开亮起；隐藏到输出的信号运动 `520ms`，输出读数在 `240ms` 内显现。只在用户触发后播放，不循环；拖回进度时直接还原对应静态状态。

## 核对

| 检查 | 参数入口 | 期望结果 |

| H₁ | `σ(1.2x₁−0.7x₂−0.2)`，`x=(1,0)` | `z=1.000`，`h≈0.731059` |
| H₂、H₃ | `σ(−0.8x₁+0.6x₂+0.4)`；`σ(0.5x₁+0.9x₂−0.1)` | `0.401312`；`0.598688` |
| 输出 | `σ(1.1h₁−0.9h₂+0.7h₃−0.3)` | `z≈0.562065`，`p≈0.636976`，判为 `1` |

## 不许碰

不显示目标答案、损失、红色错误信号或任何反向箭头；错误如何按相反顺序传回归 p16。也不解释单条连接应承担多少责任，该计算归 p17。
