## 知识结构：process

关系不变量：顶部四步必须按“前向预测 → 计算损失 → 反向传播 → 更新参数”同行相连；下方决策场与损失曲线共享同一训练时刻，更新次数、平均罚分和训练准确率保持同基线。

共享原语：`.canvas-full.k-process` 承载唯一主几何；`.step` 与 `.arw` 固定循环顺序，左侧 `.cvbox` 放动态决策场，右侧 `.panel` 放同步读数与曲线，两区之间保留至少画布宽度 8% 的隔离。

## 表征形式

动态交互训练控制台：Canvas 绘制 `80×80` 决策场和 200 个训练点，ECharts 绘制“平均罚分—更新次数”曲线，DOM 呈现四步状态、按钮与数值读数。

使用 `mlp.js` 实时执行网络训练，`seedrandom` 保证数据与初始化可复现；Canvas 更适合频繁刷新分类背景，常规损失曲线交给 ECharts。

## 主工作流

build-interaction ← 让训练控制、真实计算、决策边界与损失证据保持同步且可确定重放

## 训练控制台内容

| 区域 | 画面文字或数值 |
|---|---|
| 四步带 | `① 前向预测`、`② 计算损失`、`③ 反向传播`、`④ 更新参数` |
| 网络标签 | `2 → 10 → 10 → 1`；`隐藏层：tanh` |
| 决策场标题 | `模型此刻怎样划分训练点` |
| 图例 | `实心圆：训练样本`；`背景：模型预测`；`p ≥ 0.5 判为 1` |
| 曲线标题 | `训练平均罚分` |
| 横轴 / 纵轴 | `更新次数` / `平均罚分` |
| 实时读数 | `更新 0`、`平均罚分 —`、`训练准确率 —` |
| 控件 | `开始`、`暂停`、`重置`；`学习率：0.03｜0.3｜30` |
| 默认提示 | `先用 0.3 开始，再比较脚步过小或过大。` |
| 失稳提示 | `数值失稳：请暂停、换小学习率或重置。` |

训练数据用 `seedrandom("nn-lesson-xor-01")` 依次生成：`x₁,x₂∈[-1,1]` 均匀取值，`x₁x₂<0` 时目标为 1，否则为 0；前 200 点进入本页训练。网络初始化继续使用同一随机流。mini-batch 为 16，每动画帧执行 12 次更新；决策场每 8 帧刷新一次。

## 交互

默认学习率 `0.3`，初始暂停。点击“开始”后持续训练；“暂停”冻结模型、曲线和读数；切换 `0.03 / 0.3 / 30` 从下一次更新生效，不自动重置。每帧追加真实平均交叉熵与累计更新次数，并重新计算 200 点训练准确率；准确率始终明确标作“训练准确率”。

学习者比较三档步幅：`0.03` 通常下降慢，`0.3` 通常较稳定，`30` 可能震荡或失稳；结论只读取本次实时曲线，不预印固定结果。“重置”恢复相同 200 点、相同初始参数、更新次数 0 和空曲线，确保可重复比较。

## 动效

仅在运行时，琥珀橙描边沿四个步骤从左向右移动，每步 120 ms、间隔 40 ms；完成第四步后回到第一步，暂停立即停住。决策场刷新时用 180 ms 交叉淡化旧背景与新背景；训练点不移动。损失曲线只追加点，不使用循环扫光或装饰粒子。
