从一个神经元到反向传播：把“学习”还原成可追踪的计算与更新闭环。

# page-02 [目录页]
全套依次回答神经元怎样预测、误差怎样度量、参数怎样下坡，以及梯度怎样穿过整个网络。

# page-03 [标题页]
第一章：一个神经元怎样把输入变成预测——本章建立前向计算的完整心智模型。

# page-04 [内容页·static]
让读者理解权重决定各输入的影响方向与强弱，而偏置负责整体平移判断门槛。

# page-05 [内容页·interactive]
让读者亲手改变输入、权重和偏置，观察加权和如何逐项形成并改变神经元输出。

# page-06 [内容页·static]
通过对照理解激活函数不是神秘开关，而是把线性总和转换成适合下一层使用的响应。

# page-07 [内容页·interactive]
让读者移动单个神经元的参数，亲眼确认它在输入空间中学习到的是一条可移动、可旋转的决策边界。

# page-08 [内容页·static]
把输入、参数、加权和、激活与预测串成一条可逐步核查的前向计算链。

# page-09 [标题页]
第二章：网络怎么知道自己错了——本章把目标与预测的差距变成可优化的损失。

# page-10 [内容页·static]
让读者区分误差方向与损失大小，明白损失用一个标量概括当前预测有多不合目标。

# page-11 [内容页·interactive]
让读者连续改变预测并追踪损失曲线，形成“离目标越远，代价如何变化”的几何直觉。

# page-12 [内容页·static]
从单个样本扩展到一批样本，说明训练目标为何需要汇总多个样本的损失而非只讨好一个样本。

# page-13 [内容页·static]
把参数看作坐标、损失看作地形高度，为“学习就是在参数空间寻找更低位置”建立空间隐喻。

# page-14 [标题页]
第三章：参数怎样沿着损失下坡——本章用导数和梯度解释每次更新从何而来。

# page-15 [内容页·static]
让读者把导数理解为当前位置的局部敏感度：参数轻微变化会让损失朝哪个方向、变化多快。

# page-16 [内容页·interactive]
让读者亲手改变学习率并反复下坡，比较步子过小、合适与跨过低谷时的不同轨迹。

# page-17 [内容页·static]
通过同一神经元内各参数的对照，说明梯度是每个参数各自对损失影响的集合。

# page-18 [内容页·interactive]
让读者改变某条局部关系的敏感度，观察链式法则如何把沿途影响相乘并传到更早的参数。

# page-19 [标题页]
第四章：反向传播怎样贯穿整个网络——本章把链式法则组织成高效、可复用的梯度计算流程。

# page-20 [内容页·static]
让读者理解前向传播不仅产生预测，也保存反向计算梯度时必须复用的中间结果。

# page-21 [内容页·static]
沿计算图逆向追踪损失影响，说明每个节点接收上游梯度、乘上局部导数，再把结果继续传回去。

# page-22 [内容页·interactive]
让读者在一个小型网络中逐步执行前向、反向与更新，观察所有参数怎样共同推动损失下降。

# page-23 [内容页·static]
区分一次反向传播、一次参数更新、一轮遍历与持续训练，避免把不同训练尺度混为一谈。

# page-24 [内容页·interactive]
让读者比较训练前后的决策结果与损失轨迹，判断网络究竟学到了模式还是只记住了训练样本。

# page-25 [内容页·static]
归类学习停滞、震荡与激活饱和等现象，把可见症状连接到梯度和学习率层面的原因。

# page-26 [内容页·static]
以“前向算预测、损失定目标、反向算责任、更新改参数”的闭环收束全套心智模型。
