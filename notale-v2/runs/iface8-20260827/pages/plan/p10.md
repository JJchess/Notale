# page-10 · 方向与敏感度 · **100 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `PROBE · LOCAL` |
| 主标题 | 梯度把下坡写成方向与敏感度 |
| 收束句 | 梯度可以先读成两件事：旋钮该往哪边转，以及损失对此刻的转动有多敏感。 |
| 下一问 | 一个模型有多个旋钮时，这些建议怎样合在一起？ |

## 知识结构：comparison

**关系不变量：**左侧参数旋钮、中央当前点与右侧梯度仪表必须共享同一个参数值；“左试、当前、右试”的损失读数同尺度并排，方向和敏感度必须同行显示。

**共享原语：**`.k-comparison` 维持三个探针读数的共同尺度，`.knob` 表示可调参数，`.big` 固定显示当前损失与梯度读数；整组落入 `.split-lr`，左侧操纵、右侧解释结果。

## 表征形式

交互式一维损失曲线与坡面探针。横轴为参数 `w`，纵轴为每个样本的损失；当前点、左右探针和下坡箭头随旋钮同步移动。

使用 ECharts SVG 渲染坐标图；参数控件与梯度仪表使用原生 DOM。

## 坡面探针内容

| 画面对象 | 默认显示 | 计算或文字 |
|---|---:|---|
| 样本 | `x = 1，真实答案 = 1` | 固定偏置 `0`，预测为 `sigmoid(w)` |
| 参数旋钮 | `w = −1.00` | 范围 `−4.00–4.00`，步长 `0.10` |
| 左探针 | `w = −1.25，损失 ≈ 1.502` | 仅用于可见比较 |
| 当前点 | `预测 ≈ 0.269，损失 ≈ 1.313` | `neuronForward` 后接 `binaryCrossEntropy` |
| 右探针 | `w = −0.75，损失 ≈ 1.137` | 仅用于可见比较 |
| 梯度仪表 | `−0.731` | `finiteDifferenceGradient`，计算步长 `0.00001` |
| 仪表释义 | `下坡：向右　敏感度：0.731` | “梯度”首次解释：符号给出上升方向，更新取相反方向；绝对值表示局部敏感度 |
| 目标切换 | `真实答案 1 / 真实答案 0` | 默认选中 `1` |

显示常量 `FINITE_DIFFERENCE_STEP = 0.00001` 只进入探针旁注，不把 `Lec.K` 名称印在画面上。

## 交互

学习者拖动 `w`，或切换真实答案 `0/1`。预测、损失曲线、三个探针读数、梯度符号、下坡方向和敏感度立即更新。默认状态为 `w = −1、真实答案 = 1`；“复位探针”恢复该状态。此观察仪器没有正确位置。
