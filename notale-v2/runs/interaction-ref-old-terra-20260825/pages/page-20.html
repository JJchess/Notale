当前顺序：C → A → D → B

观察仪器

依赖关系，不是背诵顺序

ABCD

每一步都用到前一步留下的结果：没有预测，就无法比较目标；没有误差，就没有参数移动的方向。

每步交给下一步的东西

A当前网络 → 预测
B预测 + 目标 → 损失
C损失 → 调整方向
D调整方向 → 新参数
  • A 前向：用当前参数给出预测。
  • B 损失：把预测和目标的差压成一个数。
  • C 反向：把这份差分给每个参数，得到调整方向。
  • D 更新：沿着让损失变小的方向移动参数。
!

学习不是直接“得到答案”：它先预测、再量出误差、再分配影响，最后才更新参数。
