# page-04
从这一页开始建立贯穿全课的例子：一个语音助手神经元，要根据「音量」和「语速」两个输入判断「现在要不要打断说话人」。用 .focus 版式，主视觉是一个小型电路图：两个输入节点 x1（音量）、x2（语速）通过两条标了权重的导线汇入一个求和节点 z，导线和节点都用 --forward 色。面板给出可拖动的四个滑杆：x1（0–1，默认 0.6）、x2（0–1，默认 0.3）、w1（-3–3，默认 2.0）、w2（-3–3，默认 1.5），以及一个偏置 b 固定显示为 -1.0（不设滑杆，先按住不动）。右侧一个 .big 读数实时显示 z = w1·x1 + w2·x2 + b，默认值应为 0.6×2.0+0.3×1.5+(-1.0)=0.65。提供「复位」按钮把四个滑杆还原到默认值。这一页只讲加权求和这一步本身，不出现激活函数、不出现σ曲线，那部分留给第 05 页。
