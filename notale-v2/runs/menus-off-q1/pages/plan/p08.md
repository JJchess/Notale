# page-08
这一页要让读者相信「前向传播」就是把上一页那张结构图按顺序真算一遍，每一步都是熟悉的加权求和加激活函数。用 .k-process 骨架把计算拆成四个可点击推进的 .step：第一步「输入」显示 x1=0.6（音量），x2=0.8（语速）；第二步「隐藏层」依次点亮 H1、H2、H3 并显示各自数值——H1: z=1.2×0.6+(-0.5)×0.8-0.1=0.22，a=σ(0.22)=0.555；H2: z=-0.8×0.6+1.0×0.8+0.2=0.52，a=σ(0.52)=0.627；H3: z=0.5×0.6+0.5×0.8-0.6=0.10，a=σ(0.10)=0.525；第三步「输出层」显示 z=1.0×0.555+(-1.0)×0.627+0.8×0.525-0.3=0.048；第四步「预测」显示 ŷ=σ(0.048)=0.512。提供「下一步」按钮逐步点亮每个 .step 并把对应导线染成 --forward 色，「复位」按钮回到第一步。这一页只管前向算到预测值 ŷ=0.512，不涉及这个预测对不对，评判留给第 09 页。
