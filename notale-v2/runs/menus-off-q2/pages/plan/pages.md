# page-01
整页作为开场，标题写「从一个受精卵到两百种细胞」，导语一句话写「同一份基因组，怎么读出两百种活法」。上半区静置两个真实数字并列展示：左边是「1」配注记「受精卵，一个细胞」，右边是「37,200,000,000,000」配注记「成年人体细胞总数，约37.2万亿个，Bianconi et al. 2013 估算」，两个数字用等宽大字体对照，中间一支箭头贯穿，暗示这一整套课要讲清这支箭头里发生了什么。下半区占满剩余高度，放一张神经元高尔基染色的显微照片作为角落小图（配文「显微镜下的神经元，高尔基染色」），照片右侧用文字简单列出人体里差异巨大的几种细胞轮廓提示：神经元、红细胞、肌纤维、皮肤角质细胞——不展开讲，只是让读者先直观感受到「同一个基因组」和「长得完全不一样的细胞」之间的落差。全页静态，不设交互，为后面二十分钟搭出问题：基因不变，细胞为什么变了。

# page-03
左右对照骨架，左栏标题「同一份基因组」，右栏标题「不同的读法」。左栏写：人类基因组约含2万个蛋白编码基因，每一个体细胞的DNA序列几乎完全相同（生殖细胞除外）；右栏用一张简化条形对照表列出三种细胞——神经元、肌纤维细胞、皮肤角质细胞——各自“正在被使用”的基因数量级差异提示：约8,000个基因是几乎所有细胞都持续使用的“看家基因”（FANTOM5项目对人类转录组的统计，2014），剩下约1万多个基因则因细胞种类而或开或关。用一行强调差异写「同样的乐谱，只是每个乐手翻开了不同的乐章」。这一页只建立“基因表达是可选择的”这一核心命题，不涉及机制（转录因子、染色质），机制留给04和05；静态呈现，不设交互。

# page-04
单焦点版式，主图区放一张极简的五基因调控网络图：中心是一个可点击开关标注「MyoD（转录因子）」，四周连出四个下游基因节点，标注「肌球蛋白基因」「肌动蛋白基因」「结蛋白基因」「肌钙蛋白基因」。读者点击MyoD开关，四个下游节点从灰色空心变为实心并点亮连线，模拟1987年Davis、Weintraub与Lassar发现的经典实验：把MyoD这一个转录因子强制表达进非肌肉细胞（如皮肤纤维细胞），就足以打开一整套肌肉基因程序，把它转变成能收缩的肌肉样细胞。右侧文字面板解释：转录因子是能结合DNA、决定某个基因“读”还是“不读”的蛋白质，MyoD是肌肉命运的主开关之一。设一个「复位」按钮把开关和下游节点都清回初始灰色态，供读者反复操作体会“一个开关，牵动一整条基因链”。这一页只讲转录因子这一层机制，不涉及DNA本身是否被物理封闭，那是下一页的内容。

# page-05
左右对照骨架，比较“开放染色质”和“封闭染色质”两种状态。左栏标题「开放：可以被读」，配示意描述：DNA松散缠绕在组蛋白上，转录因子能够靠近基因起始位点；右栏标题「封闭：暂时读不了」，配示意描述：DNA被甲基化标记并紧密卷曲，转录机器无法靠近。中间一行「差异」标注：同一个基因（例如肌肉细胞特有的MyoD基因）在肌肉细胞里处于开放态，在皮肤细胞、肝细胞里则处于封闭态——这解释了为什么04页那种“开一个开关就能改变细胞命运”的实验，在正常发育中并不会随时随地发生：染色质的开合状态本身就是一层被继承、被锁住的记忆。这一页不展开讲这把锁怎么形成、怎么被继承，那部分留给15页的稳定性机制；这里只建立“表达差异背后还有一层物理层面的开关”这一事实，静态呈现，不设交互。

# page-07
左右对照骨架，呈现囊胚阶段的第一次真正的命运分岔。左栏标题「内细胞团（ICM）」，写：约100—150个细胞中位于囊胚内部的一小群，将来发育成胎儿本体，具有分化成几乎所有胎儿细胞类型的多能性；右栏标题「滋养层（TE）」，写：包裹在囊胚外层的细胞，将来发育成胎盘和胎膜，不再参与构成胎儿身体本身。中间一行标出「差异」：这是受精后第一次出现的“同样来自卵裂、但命运已经不可逆分开”的例子，对应06页地形图上小球第一次滚下的那道山脊。页面角落放人类囊胚显微照片作内容图，图注标出内细胞团和滋养层在图中的大致位置。这一页只讲这一次分岔本身，不展开讲三胚层（那是下一页），也不做交互，保持和06页的地形图语言呼应即可。

# page-10
横向流程骨架，展示发育潜能从高到低收窄的六个等级，每级配一个真实存在的代表细胞和一句能力说明：「全能性（totipotent）——受精卵及卵裂早期细胞，能发育成完整个体外加胎盘」「多能性（pluripotent）——内细胞团细胞，能形成胎儿的所有约200种细胞类型，但不能再形成胎盘」「多向性（multipotent）——骨髓中的造血干细胞，能分化出约10种血细胞类型（红细胞、多种白细胞、血小板等）」「寡向性（oligopotent）——髓系前体细胞，只能分化成粒细胞、单核细胞等少数几种」「单向性（unipotent）——成红细胞，只能沿一条路径走到成熟红细胞」「终末分化——成熟红细胞本身，不再具有分化能力」。六个节点用箭头连成一条单向轴线，强调箭头不可逆转，呼应06页地形图上“小球一路向下、很难回头”的画面。这一页只讲潜能等级本身，不涉及是谁、靠什么信号推动小球往下走，那是接下来两页的内容，不设交互。

单焦点版式，主图区呈现神经管横截面示意图，底部标注「脊索」并向上延伸出一条颜色渐变带代表Shh（Sonic Hedgehog）形态发生素的浓度梯度，这是脊椎动物神经管背腹轴分化的经典阈值模型（Jessell实验室等提出）。读者拖动一个滑块，滑块数值用0—100的相对浓度百分比表示（页面明确标注「此处用0—100的相对浓度百分比模拟真实实验中的浓度—位置关系，非精确实验读数」），滑块位置对应神经管上某一高度：当相对浓度≥70时，该位置分化为「运动神经元／底板细胞」；当相对浓度在30—70之间时，分化为「中间神经元」；当相对浓度低于30时，分化为「背侧感觉相关神经元」。滑块拖动时，截面图对应高度实时点亮并显示当前应分化出的细胞类型标签，提供「复位」按钮把滑块拉回顶端最高浓度处。这一页专门用亲手拖动来建立“浓度阈值决定命运”这一具体机制直觉，不重复讲01—10页已经讲过的基因表达或潜能等级概念。

# page-12
概括骨架，主张写在最上方最重的位置：「细胞命运往往不是自己决定的，而是由邻近组织发出的信号决定的」，下方用主干连出一条支撑：「1924年，Spemann与Mangold的移植实验」，展开说明：把一只蝾螈胚胎的“组织者”区域（背唇部位）移植到另一只胚胎的腹侧，被移植处的宿主组织没有按自己原来的命运发育，而是被诱导形成了一整套新的神经管和体轴结构，等于长出了第二套身体轴——这个实验后来被称为“组织者”实验，Spemann因此获得1935年诺贝尔生理学或医学奖。这一页只呈现这一个历史证据支撑一个核心主张，不重复11页Shh梯度的具体机制细节，也不展开讲更多诱导案例，保持概括页应有的精炼；静态呈现，不设交互。

# page-13
左右对照骨架改为三栏时间线呈现，依次陈列三个关于“分化能否被逆转”的历史证据：「1962年，Gurdon」——把已经分化的蝾螈蝾螈蝾蟾（非洲爪蟾）肠上皮细胞的细胞核，移植进去核的卵细胞，培育出了正常蝾蟾蝌蚪，证明分化细胞的细胞核仍保留着发育出完整个体所需的全部信息；「1996年，Dolly」——罗斯林研究所用一只成年母羊乳腺细胞的细胞核克隆出了世界上第一只用体细胞克隆出的哺乳动物；「2006年，Yamanaka」——用四个转录因子Oct4、Sox2、Klf4、c-Myc（合称OSKM）强制表达进小鼠皮肤纤维细胞，成功把它们重编程回多能干细胞状态，即诱导多能干细胞（iPSC）。三项并列，标出Gurdon与Yamanaka共同获得2012年诺贝尔生理学或医学奖。角落放Dolly羊标本的照片作为内容图，图注写「Dolly羊标本，苏格兰国家博物馆」。这一页只陈列证据本身，不展开重编程的具体操作画面，那交给下一页的互动。

左右对照骨架，用一张横向条形对照展示不同组织的细胞更新速度真实数据：「表皮」整层更新周期约27—40天（常引用约28天）；「小肠上皮」更新周期约4—5天，是人体更新最快的组织之一；「红细胞」平均寿命约120天，之后由骨髓造血干细胞持续补充；「心肌细胞」每年更新率不到1%（Bergmann等，2009年，碳-14年代测定法）；「皮层神经元」在成年后基本不再新增或替换，绝大多数伴随一生。条形长度按更新周期的相对长短排列，越长表示更新越慢。右侧一行小结：08页讲过的三胚层分类，加上10页讲过的潜能等级，共同决定了每种组织背后是否还留有活跃的干细胞库——这也是为什么皮肤和肠道能不断自我修复，而心肌梗死和某些神经损伤很难自然恢复。这一页只呈现数据对照，不展开干细胞龛的具体调控机制，静态呈现，不设交互。
