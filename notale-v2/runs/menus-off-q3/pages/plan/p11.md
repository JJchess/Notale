# page-11
用 .layout-stack 呈现圈地立法的规模，做成横向时间轴。轴上标出五个年代节点按钮：1700、1750、1780、1810、1830，做成一组 .btns，点击某个年份后，轴下方两个 .big 读数联动更新——「累计议会圈地法案数」与「累计圈占英亩数」，对应数据取自历史学者（如 Turner 等）对英国议会圈地的估算：1700年之前累计约500项、覆盖约150万英亩；到1750年累计约900项、约250万英亩；到1780年累计约1900项、约450万英亩；到1810年累计约3400项、约640万英亩；到1830年累计约4000项、约680万英亩，其中1750—1830年间新增约2500项，圈占约680万英亩，约占当时英格兰耕地的四分之一。轴线颜色用 --land，当前选中年份节点用 --attention 描边，提供「复位到1700」按钮回到初始态。这一页只呈现法案与圈占面积的规模增长，不解释圈地对农业产出或劳动力的影响——那是接下来两页的内容。
