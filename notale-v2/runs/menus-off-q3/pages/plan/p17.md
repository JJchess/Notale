# page-17
用 .k-classification 呈现制度环境这一类因素，顶层 .box 标题「英国的制度环境如何降低了投资的不确定性」，下设三个二级分支：分支一「专利制度」——「1624年《垄断法案》确立专利权原则；瓦特1769年获得的专利经1775年议会立法延长至1800年，获得约25年市场独占」；分支二「产权保护」——「议会以立法形式逐案确认圈地后的新地权归属，把地权变更从习惯法的模糊地带搬进了成文法」；分支三「资本市场」——「伦敦的证券市场与合股公司为运河、矿山、工厂提供了超出个人财力的长期资金」。三个分支边框统一用中性 --rule 而不引入新的语义色，因为「制度」本身在第09页已用 --mechanism 系的 .tag 预告过、这里回收呼应。这一页只讲制度如何配合前面已经出现的煤、地权、蒸汽机三条线，不重复它们各自的数据。静态、无交互。
