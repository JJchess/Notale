# page-01
用 `.layout-cover` 铺开这套讲义的第一面：读者要相信的是"接下来30分钟能看懂一个具体的判断是怎么被算出来的，以及网络怎么把这个算法一步步改对"，靠的是给出一个具体到可以心算的场景而不是抽象口号。画面中央是 kicker 文字"NEURAL NETWORK · 从一个神经元到反向传播"，标题写"一个数字判断的诞生"，导语写清任务原型："给定两个数字——花瓣长 x1=0.5，花瓣宽 x2=0.8——网络要输出一个 0 到 1 之间的数，判断它更像哪一类花。今天要看穿这个数字怎么算出来，又怎么被教得越来越准。"标题下方用三个 `.tag` 横排列出本讲路线："单个神经元 → 前向传播与损失 → 反向传播 → 权重更新"，作为后续页面的路标，不展开细节。这一页完全静态，不出现任何滑块或按钮，也不做任何数值演算，只负责把整堂课的问题摆正。
