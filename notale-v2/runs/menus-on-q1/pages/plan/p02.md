# page-02
用 `.layout-standard` 讲清"神经元到底是什么"：header 标题"神经元的构造"，kicker"STEP 1 · 加权求和"。主区左侧是一个 `.panel`，用简单的图示（三条输入线汇入一个节点）呈现公式 z = w1·x1 + w2·x2 + b，并写出当前取值 x1=0.5、x2=0.8、w1=0.6、w2=-0.3、b=0.1；主区右侧是一个 `.panel.q`，放两条 `.ctl` 滑块（w1 范围 -1 到 1，w2 范围 -1 到 1，初始分别为 0.6 与 -0.3）和一个 `.big` 读数实时显示 z 的计算结果，初始应显示 z=0.16（0.6×0.5 + (-0.3)×0.8 + 0.1）。读者拖动任一滑块，z 的读数随之用当前公式重新算出并更新，下方 `.hint` 提示"z 只是三个数相乘再相加，还没有变成最终的判断"；提供一个"复位"按钮把两个滑块和 z 都还原到初始值。这一页不涉及激活函数、不涉及多神经元，只讲加权和这一步。
