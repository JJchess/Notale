# page-04
用 `.layout-standard` 呈现"权重如何决定一条分界线"：header 标题"神经元 = 一条分界线"，kicker"STEP 3 · 决策边界"。主区左侧 `.panel` 用一个二维坐标画布（x1 轴 0 到 1，x2 轴 0 到 1），公式标注 w1·x1 + w2·x2 + b = 0 是平面上的一条直线，直线把平面分成两半；画布上标出两个训练点：A(0.5, 0.8) 属于类别 1（用 `.tag` 标"目标=1"），B(0.2, 0.1) 属于类别 0（`.tag` 标"目标=0"）。主区右侧 `.panel.q` 放三个 `.ctl` 滑块：w1（-1到1，初始0.6）、w2（-1到1，初始-0.3）、b（-1到1，初始0.1），拖动任一滑块时画布中的分界线实时旋转或平移，读者要靠拖动让分界线把 A 和 B 分到直线两侧。提供复位按钮。`.hint`写"分界线的方向由 w1、w2 决定，位置由 b 决定"。这一页不讨论损失数值，只建立"权重=几何"的直觉。
