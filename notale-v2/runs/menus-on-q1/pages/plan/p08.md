# page-08
用 `.layout-standard` 讲损失函数：header 标题"损失：网络错得有多远"，kicker"STEP 5 · 衡量误差"。主区左侧 `.panel` 呈现公式 L = 0.5×(y-ŷ)²，代入页07的结果 y=1、ŷ=0.5710，算出 L = 0.5×(1-0.5710)² = 0.5×0.1841 ≈ 0.0920，用 `.big` 突出显示 0.0920。主区右侧 `.panel.q` 放一个 `.ctl` 滑块，拖动范围 0 到 1，代表"如果 ŷ 是别的值"，初始值 0.5710，滑块旁 `.big` 实时显示对应 L 值；下方 `.k-comparison` 列出三行对照：ŷ=0.95 时 L≈0.00125，ŷ=0.5710 时 L≈0.0920，ŷ=0.10 时 L≈0.4050。`.hint`写"loss 是一个数，越接近 0 说明预测越准；训练的全部目的就是让这个数变小"。这一页不涉及权重怎么调，只建立"loss 是什么、怎么算"的直觉。
