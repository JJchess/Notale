# page-01

大标题「细胞为什么会分化」，kicker 写「从一个受精卵到两百种细胞」，作为整堂课唯一的静态开场页，要让读者在十几秒内接住这堂课要解决的悖论：一个受精卵经过反复分裂，最终长成一个人体，而这个人体里住着大约两百种形态和功能天差地别的细胞类型（Vickaryous & Hall, 2006 对人体细胞类型的经典统计约200种），却全部来自同一个基因组，细胞总数约37.2万亿（Bianconi et al., 2013 的整体估算）。画面用两个大号读数并排呈现：一个写「1」并标注「受精卵」，另一个写「≈200」并标注「细胞类型」，中间用一个简单的箭头连接，暗示这是一个需要被解释的转变而不是自然而然的事。箭头下方并排三枚静态标签，写「神经元」「红细胞」「肌纤维」，提示这些截然不同的细胞正是要被解释的终点。底图用受精卵/囊胚显微照片压得很浅，只做氛围，不承担信息。这一页不解释任何机制，只负责让读者带着这个问题往下走，机制留给后面每一页逐步拆解。

# page-02

这一页要让读者相信：细胞之间的差异不是因为它们携带不同的DNA，而是因为它们「读取」了同一份基因组里不同的段落——这是整堂课后续所有内容的地基假设。画面用对照骨架呈现一张小型基因开关表：左侧列出四个真实的基因名——胰岛素基因（INS）、β-珠蛋白基因（HBB）、肌球蛋白重链基因（MYH）、视紫红质基因（RHO）；右侧三栏分别代表「胰腺β细胞」「红细胞前体」「视网膜感光细胞」，每个格子用勾号或叉号标出该基因在这类细胞里是「开」还是「关」（不用红绿色块，只用符号），呈现出INS只在β细胞里打勾、HBB只在红细胞前体里打勾、RHO只在感光细胞里打勾、而三种细胞都不表达对方专属基因的错位模式。文字点明一个真实数字：人类基因组约有2万个编码蛋白质的基因（GENCODE 权威注释估算），但任何一种细胞类型通常只稳定表达其中四到六成，正是这份「读取清单」的差异定义了细胞身份。交互很轻：点击某一栏的细胞类型标签，该列的勾号会加粗高亮，让读者直观感到「换一种细胞，就是换一份清单」。这一页不讨论这份清单是如何被决定的（转录因子等机制留给后面），只负责立住「基因不变、读法在变」这句话。

# page-03

这一页用时间线骨架呈现受精卵最初五天的分裂过程，让读者对「细胞数量怎么从1变多」有一个具体的时间感。时间带上依次排列五个节点：受精卵（第0天，1个细胞）、2细胞期（约30小时）、4细胞期（第2天）、8细胞期（第3天）、桑葚胚到囊胚（第4–5天，细胞数约100–150个），这一套分期取自人类体外受精胚胎学的标准培养时间表。配图用早期卵裂显微照片，随着推进逐渐切换成对应阶段的画面。交互方式是一个「下一天」按钮：每点一次，时间带上的当前节点向右推进一格，页面上的细胞数字读数随之更新（1→2→4→8→约120），并解释一个关键术语「全能性」——第4细胞期之前，任何一个单独的细胞理论上仍能独立发育成完整个体，自然发生的同卵双胞胎正是这种全能性的真实证据。这一页只交代「时间轴上发生了什么」，不涉及囊胚内部结构的分工，那是下一页的任务。

# page-04

这一页聚焦囊胚内部的第一次真正分工，用对照骨架把囊胚拆成两部分放在同一高度比较：左栏是「内细胞团」，标注为潜能色调，说明它在第5天时约由5–20个细胞组成，将来发育成胚胎本体的三个胚层，仍保持多能性；右栏是「滋养层」，标注为命运色调，说明它由外层约60–85个细胞组成，将来只形成胎盘和绒毛膜等支持结构，已经不能再形成胚胎本体。配图用囊胚横截面显微照片，内细胞团和滋养层的实际空间位置清晰可辨。交互是点击式的：点击「内细胞团」或「滋养层」标签，对应一侧展开一行说明文字，解释它的去向和潜能范围，不设滑块，保持和上一页「下一天」按钮不同的操作手感。这一页不展开「多能」这个词的完整阶梯（留给第10页），只负责让读者第一次看到「同一个囊胚里，细胞已经分化出了不可逆的两条路」。

# page-05

这一页要立住整堂课最关键的一句断言：分化不是基因被删除，而是同一套基因被不同地调用。用概括骨架呈现：顶部主张写「已分化的细胞仍然保留完整基因组，身份差异来自调控而非基因丢失」，下面挂两条支撑证据。第一条支撑是约翰·格登（John Gurdon）1962年的核移植实验：把已经分化的蝾蚪/蟾蚌肠上皮细胞的细胞核，移植进被去核的卵细胞里，结果这颗重组细胞正常发育成了一只健康的蝌蚪——证明分化细胞的核里仍装着发育出完整个体所需的全部信息。第二条支撑简要提及植物界的对应证据：1958年斯图尔德（Steward）用单个胡萝卜体细胞培养出了完整的胡萝卜植株，说明这条规律并非两栖动物的特例。配图用格登实验的历史资料照片。这一页保持静态，不加互动，专注于把这句断言讲清楚、讲扎实，留给下一页去看它在哺乳动物身上有多难重演。

# page-06

这一页承接上一页的断言，把证据从两栖动物推进到哺乳动物，同时揭示这件事有多困难。核心事实：1996年罗斯林研究所用一只成年母羊乳腺细胞的细胞核做体细胞核移植，最终成功培育出了克隆羊多莉——这是哺乳动物基因组等效性的第一个直接证明。但要点在效率上：整个实验尝试了277次核移植，只成功产出了1只活着诞生的多莉，成功率约0.36%。配图用多莉标本（现存于苏格兰国家博物馆）的照片。文字点出这一页要留下的悬念：既然分化细胞的基因组完好无损，为什么把它「重启」回发育起点这么困难——这暗示了分化状态并不是轻飘飘地存在，而是被某种机制主动锁住的，为后面转录因子和表观遗传标记的内容做铺垫。这一页保持静态，不重复上一页的骨架结构，只做证据的延伸和转折。

# page-07

这一页要让读者亲手感受到「一个转录因子可以扳动一整条细胞命运」。核心内容是1987年戴维斯、温特劳布和拉萨（Davis, Weintraub, Lassar）的经典实验：把编码转录因子MyoD的基因强制导入普通的皮肤纤维细胞，几天内这些细胞就会开始表达肌球蛋白、肌动蛋白等肌肉专属基因，并在培养约3至5天后融合成肌管——从一种细胞变成另一种细胞，只靠打开一个基因。画面用过程骨架排出三步：「纤维细胞（MyoD关闭）」→「开始表达肌球蛋白、肌动蛋白（调控色标注）」→「融合成肌管」。交互是一个「MyoD 开/关」的切换按钮：打开时，中间和末尾步骤的基因标签依次点亮为调控色，末端标签文字从「纤维细胞」变为「肌管」；关闭时全部复位。这一页只讲单个主调控因子的力量，不涉及多个转录因子互相制衡的复杂情形，那是第14页要处理的。

# page-08

这一页引入贯穿后续课程的核心视觉母题——分支谱系树。内容是线虫（C. elegans）发育谱系图谱：秀丽隐杆线虫成年雌雄同体个体恰好由959个体细胞组成，从单个受精卵开始的每一次分裂、每一个细胞的最终去向，都被苏尔斯顿（Sulston）及同事在1983年完整绘制出来（这项工作后来获得2002年诺贝尔奖），是已知发育生物学里最精确的一份「命运账本」。画面主体是一株从单点向下分支的谱系树，末端标出几个具体细胞命运，例如「ASE感觉神经元」「肠上皮细胞」「阴门前体细胞」，配图用线虫胚胎显微照片作为侧证。交互是点击树上的某个分支节点，右侧浮出该节点到最终命运经过的确定分裂次数（例如「距受精卵6次分裂」）和最终细胞类型名称——强调这条路径是完全确定、可重复的，同一物种的每一只线虫谱系几乎完全相同。这一页只建立「谱系树」这个视觉语言，不涉及细胞命运是如何被分子机制决定的，那是接下来几页的任务。

# page-09

这一页把上一页的谱系树抽象成一套可操作的直觉模型——沃丁顿表观遗传景观（Waddington's epigenetic landscape，1957）。画面底图用一幅钢笔线描风格的插画：一片起伏的地形，一颗弹珠停在最高处的平台上，往下是层层分支的山谷，每一个分岔代表一次命运选择，每一个谷底代表一种稳定的细胞类型，谷与谷之间的山脊代表不稳定的过渡状态。交互是一个标注为「发育时间」的滑块，从0（受精卵，弹珠在最高平台）拉到100（终末分化，弹珠稳稳停在某个具体山谷里，山谷标签随机显示为「神经元谷」或「血细胞谷」之一），拖动过程中弹珠沿着插画上的路径下滑，并在经过每一个岔口时短暂停顿，暗示这是一次次离散的选择而不是平滑滑坡。滑块上还有一个「回退」按钮，读者会发现把滑块往回拉，弹珠并不会自动滚回上坡——这是特意设计的行为，用来直观呈现「正常情况下分化是单向的」这一事实。这一页不解释单向性背后的分子锁（留给第13页），只负责让「潜能收窄」这句话第一次变得可操作、可看见。

# page-10

这一页用归类骨架把「潜能」这个词精确分成四个等级，纠正读者可能把「干细胞」当成一个笼统词的印象。四层嵌套呈现：最外层「全能性」举例受精卵和4细胞期之前的每个分裂球，能形成完整个体连同胎盘；往内一层「多能性」举例内细胞团细胞、体外培养的胚胎干细胞，能形成外胚层、中胚层、内胚层三大胚层的所有细胞类型，但不能单独形成胎盘；再往内「多潜能性」举例骨髓里的造血干细胞，能分化出红细胞、血小板、多种白细胞等约十种血液细胞类型，但不能变成神经元或肌肉；最内层「单潜能性」举例表皮基底层的角质形成干细胞，一生只负责补充新的角质细胞。交互是点击每一层，右侧浮出对应的举例说明，层与层之间用缩进和边框表达包含关系，而不是用颜色深浅暗示优劣。这一页只负责把术语摆整齐，不涉及位置信息如何决定命运，那是下一页浓度梯度要处理的内容。

# page-11

这一页要让读者亲手体会「同一种分子的不同浓度可以指定不同的细胞命运」。内容是神经管背腹轴上音猜蛋白（Sonic hedgehog，Shh）的浓度梯度模型：Shh由神经管最底部的底板细胞分泌，沿背腹方向形成由高到低的浓度梯度，不同浓度阈值激活不同的转录因子组合，进而决定不同的神经元亚型（这套阈值-命运对应关系来自Briscoe等2000年提出的经典基因调控网络模型）——离底板最近、浓度最高处诱导出V3神经元前体和运动神经元前体，中等浓度诱导出V0至V2各类腹侧联络神经元，浓度最低的背侧区域则形成完全不同谱系的背侧联络神经元。画面是一条横向的位置滑块，标注「距底板的距离」，从0（贴着底板）拉到100（背侧最远端），下方一个数字读数随位置指数式下降模拟浓度值，读数下方的命运标签随着滑块越过若干条阈值线而跳变（依次显示「底板」「V3/运动神经元」「V0–V2」「背侧联络神经元」），阈值线本身画成竖直虚线并标出大致位置。这一页只呈现连续变量如何被切成离散命运，不涉及命运之间如何相互抑制强化，那是第14页的任务。

# page-12

这一页要让读者看见一个可以用肉眼在真实动物身上验证的表观遗传证据——X染色体失活。核心内容：雌性哺乳动物每个细胞里有两条X染色体，但发育早期（人和小鼠约在第5、6天前后，由Xist RNA触发）每个细胞会随机沉默其中一条，而这个「选哪条」的决定会被这个细胞的所有后代细胞忠实继承，形成成片的克隆区域。三花猫的毛色正是这份随机选择的可见证据：橘色和黑色的毛色基因恰好位于X染色体上，于是猫的毛皮上出现橘、黑两色的镶嵌色块。画面用概括骨架呈现：主张写「表观遗传的沉默选择一旦做出，会通过细胞分裂被稳定继承下去」，下面挂两条支撑，第一条是三花猫毛色镶嵌本身（配三花猫照片），第二条补充2001年第一只克隆猫CC的例子——CC与提供体细胞核的供体猫基因组完全相同，但毛色花纹完全不同，恰恰证明花纹图案由随机的表观遗传事件决定，而不是由DNA序列决定。这一页保持静态，不设交互，把「随机但稳定」这句话讲透。

# page-13

这一页要解释上一页说的「稳定继承」具体靠什么分子机制实现。核心内容是DNA甲基化和组蛋白修饰构成的表观遗传记忆：在已分化的体细胞里，全基因组范围内大约70%到80%的CpG双核苷酸带有甲基标记（Bird, 2002 综述给出的典型哺乳动物基因组比例），而像OCT4、NANOG这类多能性核心基因的启动子区域，一旦细胞完成谱系选择，就会被高度甲基化并永久沉默——这解释了为什么肝细胞分裂产生的子细胞只会是肝细胞，而不会意外变成神经元。画面用一个简化的过程示意：一条DNA双链在中间复制成两条子链，甲基标记（小圆点标记）在DNA聚合酶复制的同时由DNMT1这种维持型甲基转移酶原样拷贝到两条新链上，呈现「标记跟着复制走」这一核心逻辑。这一页保持静态，专注把机制讲清楚，画面刻意收敛，不引入新的交互形式，为下一页的双稳态开关留出对比空间。

# page-14

这一页要让读者亲手体会「命运选择有时不是渐变的，而是一翻就翻到底的开关」。核心内容是造血系统里GATA1与PU.1这两个转录因子的相互压制模型（源自Stuart Orkin实验室的经典研究）：一个共同的髓系祖细胞该走向红细胞系还是走向髓系（巨噬细胞、粒细胞等），取决于这两个因子谁先占优势——GATA1和PU.1不仅各自激活自己的基因表达，还彼此压制对方的基因，这种「自我增强、互相拆台」的结构形成一个双稳态开关，没有稳定的中间态：谁先领先一点，就会把对方压到底。画面提供两个独立滑块，分别标注「GATA1起始水平」和「PU.1起始水平」（各0到10档），松手后画面会「翻转」向数值更高的一侧，最终稳定显示为「红细胞系」（潜能色标注逐渐让位给命运色）或「髓系」，读者会发现即便把两个滑块设得几乎相等（比如6和7），系统依然会干净地翻向数值较高的一侧，而不会停在中间——这正是双稳态开关的关键直觉，读者可点击「复位」重新尝试不同起点。这一页的交互形式与第11页的连续阈值滑块刻意不同，用来对照「阈值切分」和「双稳态翻转」这两种不同的决策形状。

# page-15

这一页要让读者看见「维持分化状态」这件事本身在不同组织里的节奏差异极大，用对照骨架把几种组织的更新周期摆在同一尺度上比较。内容摆出四行真实数据：肠道上皮细胞由肠腺基部的干细胞在Wnt信号维持的微环境（niche）驱动下持续供应，整层上皮大约每4到5天完全更新一次；皮肤表皮由基底层干细胞供应，整层大约28天完成一次更新；红细胞平均寿命约120天，之后由骨髓造血干细胞衍生的祖细胞持续补充；成年大脑皮层里的成熟神经元几乎不再更新，终身维持同一批细胞（海马齿状回等少数区域是已知的例外）。画面用同尺度的横向条形呈现这四个周期的天数，用对数刻度让4天和终身不更新能在同一张图里被读懂，条形右侧标注对应的干细胞来源。这一页保持静态，不设交互，作用是让读者意识到「分化之后并不是故事的结束」，为后面重编程和再生的内容做对照背景。

# page-16

这一页把整堂课的方向第一次反过来讲：分化不仅能往前走，还能被人为拉回起点。核心内容是2006年高桑一虎（Kazutoshi Takahashi）与山中伸弥（Shinya Yamanaka）的发现：只需强制表达四个基因——Oct4、Sox2、Klf4、c-Myc（合称OSKM）——就足以把一个已经完全分化的小鼠皮肤纤维细胞，在培养约2到4周后重编程回一种类似胚胎干细胞的多能状态，称为诱导多能干细胞（iPSC），早期方案的重编程效率大约只有0.01%到1%。画面用过程骨架呈现一条反方向的箭头：「成熟皮肤细胞」→（标注「强制表达OSKM」，调控色）→「iPSC」→「可重新分化为几乎任意一种细胞类型」，并配一张iPSC集落显微照片，说明它们呈紧密圆润的集落状，明显区别于铺展开的纤维细胞形态。文字回扣第9页的景观图比喻：这相当于把弹珠从山谷底部硬推回最初的高地，也回扣第5页的格登实验，山中伸弥与格登因为分别在哺乳动物和两栖动物身上证明了这种可逆性，共同获得了2012年诺贝尔生理学或医学奖。这一页保持静态，作为叙事上的转折点。

# page-17

这一页要给上一页的乐观叙事加上一层必要的警惕。核心内容：驱动重编程的一些因子本身就是致癌基因——c-Myc是人类各类癌症中最常被扩增激活的癌基因之一；如果在活体动物身上过度或过久地强制激活完整的OSKM重编程程序，会诱发畏形瘤（teratoma，一种混杂着多种随机组织类型的肿瘤），这一点在小鼠体内重编程实验中已被反复观察到（如Ohnishi等2014年、Abad等2013年的相关研究）。画面用对照骨架并排两栏：左栏「受控分化」，特征写「分步推进、有检查点、终末命运单一而稳定」；右栏「失控去分化/增殖」，特征写「检查点被绕过、命运混杂或未定、形成肿瘤」。这一页保持静态，语气刻意放低，作为两页高强度交互（第14、16页）之后的一次收束和警示，不引入新的机制细节，只负责把「潜能是把双刃剑」这句话说清楚。

# page-18

这一页要给上一页的警示找一个自然界里真实存在、却不失控的反例。核心内容是墨西哥钝口螨（axolotl）的断肢再生：截肢伤口附近原本已经分化的细胞，会在几天内退回一种叫做「芽基」（blastema）的祖细胞样状态，随后重新分化，在大约40到60天内重建出包含骨骼、肌肉、神经的完整肢体，且过程中既不形成肿瘤也不留疤痕。文字特别指出克拉格（Kragl）等人2009年用谱系追踪技术做出的一个精确发现：参与再生的细胞大多只在自己原来所属的组织谱系内退回和前进（比如肌肉细胞退回后主要还是重新变成肌肉），而不是像iPSC那样退回到完全多能的状态——这是一种「受限的去分化」，天然地把再生能力和肿瘤风险分隔开。画面配一组轴螨断肢再生不同阶段的照片。这一页保持静态，作为第17页警示之后的一次舒缓和延展，让读者带着一个温和的问题进入收束页：为什么人类没有演化出同样安全的再生能力。

# page-19

这一页不引入任何新证据，而是把前面十八页收拢成一张单一的总图，让整堂课的脉络在视觉上「咔」地合拢。画面复用第9页的沃丁顿景观插画作为底图，在弹珠下滑的路径上按发生顺序钉上几个小标签，对应回前面出现过的具体机制：靠近顶端平台的位置标注「转录因子扳动开关（第7页 MyoD）」；第一个分岔口标注「浓度阈值切分命运（第11页 Shh梯度）」；分岔口下方一段标注「相互压制的双稳态开关（第14页 GATA1/PU.1）」；每个谷底钉着一个小锁形符号，标注「甲基化等表观遗传标记锁定状态（第13页）」；靠近谷底但被人为拉回顶端的一条虚线路径标注「OSKM强制重编程（第16页）」。这一页保持静态，没有交互，作用是让读者在动手做任何自测之前，先获得一次完整而安静的整体回看。

# page-20

这一页是整堂课的自测收束，用纵向题目栈呈现三道选择题，检验三个最容易混淆的关键区分。第一题题干「全能性和多能性最主要的区别是什么」，选项包括「发育阶段早晚与可分化谱系的宽度不同」「细胞体积大小不同」「DNA含量不同」「分裂速度不同」，正确项指向第一个选项，对应第3、10页的内容。第二题题干「MyoD实验说明了什么」，选项包括「单个转录因子足以启动一整套细胞命运程序」「肌肉细胞比皮肤细胞基因更多」「细胞分化需要改变DNA序列」「转录因子只能在胚胎期起作用」，正确项指向第一个选项，对应第7页。第三题题干「克隆羊多莉的培育成功率只有约0.36%，最可能的原因是」，选项包括「体细胞里的表观遗传标记很难被完全擦除重编程」「羊的基因组比其他动物更不稳定」「核移植技术在当时完全没有验证过」「多莉本身携带罕见基因突变」，正确项指向第一个选项，对应第6、13页。选中某个选项后该选项加下划线标出被选中，随后揭示答案，正确选项打勾、其余选项不特别标红，并在题目下方浮出一到两句简短解释文字。三题之后是一句收束语，指出这套「分化如何被建立、被维持、又能被打破」的逻辑，正是类器官培养、抗衰老研究和再生医学正在继续深挖的方向，为读者留一个可以自行继续探索的出口。
