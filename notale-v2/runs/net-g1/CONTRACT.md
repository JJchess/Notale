## 1. 这堂课在讲什么

全课主张：神经网络的“学习”不是突然理解，而是反复执行“计算预测—计算误差—反向求梯度—更新参数”，让训练误差逐步下降，再用未参与训练的数据检验能否迁移。

| 幕 | 页 | 必须建立的认识 |
|---|---:|---|
| I. 一个神经元会做什么 | 01–09 | 输入经权重、偏置和激活函数确定地产生预测；改参数就会改判断 |
| II. “学习”是怎样的一步 | 10–16 | 损失把预测质量变成数；梯度指出参数微调会让损失升还是降 |
| III. 多层网络怎样分配责任 | 17–22 | 隐藏层组合简单边界；反向传播沿计算链逐层分配误差责任 |
| IV. 看见网络真的学起来 | 23–25 | 重复更新能形成决策边界；训练表现不等于对新数据可靠 |

证据链必须保持顺序：

- E1：神经元输出由输入、权重、偏置和激活函数确定；参数变化导致判断变化。
- E2：损失函数给出单一误差数值；参数梯度给出局部上升或下降方向。
- E3：多层网络组合多个简单判断；反向传播从输出向输入计算各参数责任。
- E4：持续执行完整训练循环可降低训练误差；迁移必须由未参与训练的数据检验。

每页只实现自己的 `pNN.md`。未被本页规格要求的概念、证明、例子、术语、交互和结论均“不许碰”，由对应页面负责；不得提前讲解、重复演示或自行补做跨页回顾。

## 2. 颜色语义

| token / 色相 | 唯一含义 | 允许出现的位置 |
|---|---|---|
| `--signal` / `#2457A6` | 前向计算得到的信号或预测 | 输入到输出的路径、当前预测、对应数值或曲线 |
| `--focus` / `#E4572E` | 当前正在观察或刚被改变的量 | 当前旋钮、被调参数、当前步骤、临时高亮；焦点结束即恢复中性色 |
| `--paper` / `#F4F0E6` | 无概念含义的纸张底色 | 页面背景与记录页底面 |

语义色不得作边框花纹、标题装饰、类别配色或面积填充。误差、梯度、类别、正确与错误没有固定色相；除当前焦点外使用主题中性色，并以文字、形状、线型或位置区分。不得新增概念色。

## 3. 知识结构——骨架约定

容器不是知识关系，不以“卡片网格”或“左右两栏”代替结构。

| 结构 | 必须直接看见的关系 | 最低几何要求 | 失败形态 |
|---|---|---|---|
| process | 先后、因果或状态推进 | 可见方向轴、箭头或连续路径 | 只有并排块 |
| comparison | 同一维度上的差异 | 同行、同尺度、同基线 | 两边各画各的 |
| classification | 上下位或部分—整体 | 嵌套、包含或明确缩进 | 同级平铺 |
| generalization | 主张与支撑 | 主张更重，支撑挂在同一主干 | 主张和证据同权 |

优先使用 `theme.css` 提供的 `.k-*` 知识结构原语；SVG、Canvas 或图表可以替代，但画面必须满足上表关系，不能只在文字中声称存在关系。

跨页图形词汇固定：

- 前向信号：从左向右的连续实线单向箭头。
- 梯度或责任返回：从右向左的双线箭头；不得仅靠颜色区分。
- 神经元：圆角矩形；参数：带旋钮缺口的圆片；样本：实心圆点。
- 实验步骤使用编号签；每次更新在误差记录带中追加一行。
- 卡片统一为 8px 圆角、1.5px 实线边框、无投影。
- 分区依靠记录本分隔线、缩进、编号和层级，不依靠大面积色块。
- 主结论四周至少留一个正文字高净空；标签就近放置。
- 标题与一句话结论用主题衬线字体；正文、标签和控件用无衬线；参数值、逐步算式和训练记录用等宽字体。

## 4. 交互的规矩

- 同一个关系只使用一种主要交互路径，不用滑块、按钮、拖拽等多个控件重复同一结论。
- 教学常量、范围、初值和结果来自 `Lec.K` / `Lec.P`，并在页面运行时当场计算；禁止硬编码预录结果、截图结果或假数据。
- 随机过程必须使用固定种子；同一操作序列必须得到同一结果。
- 首屏保持静止，且不操作也能看见本页要讲的关系、初值和操作入口。
- 交互页必须给出动词开头的明确提示，并让操作结果就近反馈。
- 滑块、切换和游标是观察仪器；没有目标态时不得显示“正确/错误”、得分或通关。只有分拣、配对、拼装等本来存在唯一或明确答案的任务才判定正确性。
- 无交互页为 01、02、09、16、22、25；这些页面不得添加装饰性按钮、拖拽、悬停揭秘或自动播放操作。
- 动画只表达状态变化；尊重主题的减弱动态机制，不用循环动画吸引注意。

## 5. 技术契约

固定骨架：

    <!doctype html>
    <html lang="zh">
    <head>
      <meta charset="utf-8">
      <link rel="stylesheet" href="assets/base.css">
      <link rel="stylesheet" href="assets/theme.css">
    </head>
    <body data-page="NN" data-total="25">
      <div id="stage"></div>
      <script src="assets/base.js"></script>
      <script src="assets/lec.js"></script>
    </body>
    </html>

- 只修改 `#stage` 内容。`data-page` 必须为两位页码，保留 `data-total="25"`；不得把页码显示给读者。
- 逻辑画布固定 1600×900，不得滚动。`#stage` 为 flex 列；顶层区块使用固定高度或 flex 份额，主内容区使用 `flex:1`。
- 字号只用主题 token。正文与成句说明 ≥16px；控件标签、图例、图注、提示 ≥14px；纯数字刻度 ≥12px；多行文字行高 ≥1.35。
- 颜色、字体、圆角、阴影和共享组件取自主题接口。一次性尺寸可内联，不为单页尺寸新增公共类。
- 不移除或覆盖 `.min0`、`.cv-fill`、`.no-pan` 的机制；缩放画布内禁止 `position:fixed`。
- 默认用 flex；只有真正二维对齐时使用 grid。
- 页面必须在 `file://` 下自包含运行，只引用 `pages/` 内相对路径，不用 CDN。
- 图表优先使用已安装库，不重复实现成熟能力。ECharts 必须使用 SVG renderer，并显式设置全局、坐标轴、图例和提示字号。
- Canvas 使用 `Deck.fit()` / `Deck.autofit()`；手写 Canvas 指针坐标使用 `Deck.pt()`，动画使用 `Deck.loop()`。
- Konva 图形可用于拖拽与命中；文字标签优先使用 DOM 叠加。必须使用 `Konva.Text` 时显式设置合规字号。
- KaTeX 必须同时引用其 CSS；基准字号统一取 ≥20px。
- 小型实时二分类训练使用 `mlp.js`；不得用 tf.js 或 ml-matrix 重写。tf.js 仅用于预训练模型、真实图片卷积或确需 GPU 的大矩阵，并用 `tf.tidy()` 或 `dispose()` 管理张量。

| 用途 | 库 |
|---|---|
| 物理、碰撞、约束 | Matter |
| 三维场景；地球；生成背景 | THREE；Globe；VANTA |
| 常规图表 | ECharts，`renderer:'svg'` |
| 二维拖拽与命中；矢量数据绑定；海量精灵 | Konva；D3；PIXI |
| 分步动画；时间线；滚动绑定；矢量动画 | anime；GSAP；ScrollTrigger；Lottie |
| 伪三维、指针倾斜、入场淡入 | Zdog；VanillaTilt；AOS |
| 公式、矩阵计算、固定随机 | KaTeX；mlMatrix；seedrandom |
| 小网络实时训练；大型模型与卷积 | MLP；TensorFlow.js |

随机样本使用 `new Math.seedrandom('page-NN')`。`MLP.diverged` 只表示数值崩溃，不表示模型学会或没学会；训练效果必须读取 `evaluate()` 的损失与准确率。

`Lec` 公开接口仅按以下签名调用，不读取实现：

- `Lec.K`：`BINARY_CROSS_ENTROPY_AT_HALF`、`FINITE_DIFFERENCE_STEP`、`NUMERIC_EPSILON`、`RELU_DERIVATIVE_AT_ZERO`、`SIGMOID_AT_ZERO`、`SIGMOID_MAX_SLOPE`
- `Lec.P.activation(name, z)`
- `Lec.P.activationSlope(name, z, output)` → 数值
- `Lec.P.applyGradients(layers, layerGradients, learningRate)`
- `Lec.P.backprop(inputs, targets, layers, loss)` → `{output, loss, layerGradients, inputGradient, forward}`
- `Lec.P.centralDifference(fn, x, step)` → 数值
- `Lec.P.denseLayerForward(inputs, weights, biases, activation)` → `{inputs, z, outputs, activation}`
- `Lec.P.loss(name, predictions, targets)`
- `Lec.P.lossGradient(name, predictions, targets)`
- `Lec.P.networkForward(inputs, layers)` → `{input, layers, output}`
- `Lec.P.neuronForward(inputs, weights, bias, activation)` → `{inputs, z, output, activation}`
- `Lec.P.singleNeuronGradients(inputs, target, weights, bias, activation, loss)` → `{z, output, loss, dLossDOutput, dLossDZ, weightGradients, biasGradient, inputGradients}`
- `Lec.P.weightedSum(inputs, weights, bias)`

## 7. 文字风格

- 面向无微积分、线性代数和编程前提的大学通识课学生；术语首次出现时先说动作，再给名称。
- 使用教师可直接说出口的短句；一句尽量只承担一个判断，避免连续多层从句。
- 公式必须紧邻人话解释；符号只引入本页立即使用的部分。梯度先解释为“参数轻微增加时，误差往哪边变”，再使用术语。
- 操作提示用直接口吻，如“转动权重旋钮，观察预测怎样移动”；不用程序员术语要求学生“运行代码”。
- 删除“如图所示”“显而易见”“接下来我们将”以及评价教学设计的元评论。
- 关键数字给可感换算或基线，例如“误差从 0.69 降到 0.40，相当于少了约四成”；不得用未经计算的形容词替代数值。
- 只在数据支持范围内下结论；随机性、近似、局部关系或未验证迁移必须明确标注。
- 收束句写成本页应带走的主张，不写成本页摘要；下一问只负责推进到后续问题，不提前给出答案。

- JS 错误 0、资源失败 0、越界 0、裁切 0。
- 字号与行高符合分层地板；ECharts、KaTeX及 Canvas/图形叠加标签单独核查。
- 交互页覆盖初始态、主要操作态、边界值、重置态及规格要求的异常态；每个主要控件均可实际改变计算结果。
- 固定种子下结果可复现；页面讲解中的数值与运行时计算一致。
- 问题区域先用 `Look` 查看，再用 `Patch` 合并修复，不以整页重写掩盖局部问题。

## 9. 版面密度与常见坑

- 主内容用 flex 吃满剩余空间，不给普通内容块写死高度；需要收缩的子项设置正确的最小尺寸机制。
- 画面有效占用低于 45% 时，检查失控的 flex 空隙，并放大有教学意义的关系；不得添加装饰撑满。
- 画面有效占用高于 85% 时，删减内容或报告需要拆页；不得缩小字号、压低行高或裁掉标签。
- 骨架和包裹层优先用线、缩进、编号与层级表达，不堆叠多层填色卡片。
- 不把颜色当作唯一编码；前向与反向、类别与状态在灰度下仍须可辨。
- 不用远离对象的总图例代替就近标签，不让连线穿过正文，不让箭头方向含混。
- 不用静态数字冒充计算结果，不让重置产生不同随机样本，不把“数值未崩溃”写成“训练成功”。
- 照片使用主题已有的边框、圆角和底图规则；Canvas 交互区必须添加 `.no-pan`。
