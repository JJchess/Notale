# 《神经网络是怎么学会的：从一个神经元到反向传播》 45 分钟互动讲义 · 总规划

## 0. 这套讲义的主线

神经网络的“学习”不是突然理解，而是反复计算误差、算清每个参数该往哪边改，再把它们改一点点。

| 章 | 页 | 这一章要让读者信什么 |
|---|---|---|
| I. 一个神经元会做什么 | 01–09 | 一个神经元只是把输入加权、加偏置并压成预测；权重和偏置决定它的判断 |
| II. “学习”是怎样的一步 | 10–16 | 学习就是测量参数对误差的影响，再沿着让误差下降的方向更新参数 |
| III. 多层网络怎样分配责任 | 17–22 | 隐藏层能组合多个简单边界，而反向传播能逐层算出每个参数应承担的误差 |
| IV. 看见网络真的学起来 | 23–25 | 重复同一套更新会让决策边界逐渐成形，但训练表现不等于对新数据可靠 |

- **E1**：一个神经元的输出完全由输入、权重、偏置和激活函数的确定计算产生，改变参数就会改变判断。
- **E2**：误差函数把“预测得有多差”变成一个数；参数梯度指出微小改变会让这个数上升还是下降。
- **E3**：多层网络能把多个简单判断组合成非直线边界；反向传播按计算链从后向前分配误差责任。
- **E4**：持续应用“计算预测—计算误差—反向求梯度—更新参数”会降低训练误差，但必须用未参与训练的数据检验迁移。

## 0.5 视觉世界

- **现实参照：实验记录本。** 采用大学基础实验课中带方格、编号、测量栏和修订痕迹的记录页传统，适合把训练呈现为可复查的连续实验，也能在投影距离较远时保留清晰层级。
- **形状语言：**
  1. 信号路径一律用连续实线和单向箭头，梯度返回路径一律用双线箭头，不依赖颜色也能区分前向与反向。
  2. 神经元使用圆角矩形，参数使用带旋钮缺口的圆片，样本使用实心圆点，三类对象轮廓固定。
  3. 所有卡片使用 8px 圆角、1.5px 实线边框和无投影扁平层级，避免投影环境中浅阴影消失。
  4. 页面分区依靠粗细不同的记录本分隔线与编号签，不依靠大面积色块，降低文理混合受众的视觉解码负担。
  5. 主结论周围至少保留一个正文字高的净空；图旁标签就近放置，避免远距离来回寻找图例。
- **底色：浅暖色 `#F4F0E6`。** 接近纸张而非纯白，能降低高亮投影的眩光，同时维持深色文字的对比度。
- **主色相：`#2457A6`，唯一代表“前向计算得到的信号或预测”。** 蓝色只沿输入到输出方向出现，使观看距离较远的学生也能追踪计算流。
- **强调色：`#E4572E`，只用于“当前正在观察或刚被改变的量”。** 它不固定代表误差、类别或梯度，离开当前注意点即恢复中性色，避免同屏出现多个竞争焦点。
- **字体：** 衬线字体用于页标题和一句话结论，强化课堂停顿；无衬线字体用于讲解、按钮和标签，保证投影识读；等宽字体只用于参数数值、逐步算式和训练记录，使小数位纵向对齐。
- **材质：线性扁平。** 所有网络、曲线和操作物均以 SVG 或 DOM 线图呈现，适合解释抽象计算，也不会让零编程基础学生误以为必须阅读代码。
- **母题：**
  1. 带编号的实验步骤签。
  2. 从左向右流动的前向信号箭头。
  3. 从右向左返回的双线责任箭头。
  4. 可旋转的参数圆片。
  5. 每次更新后追加一行的误差记录带。

被否决的整体方向：

- **否决“深色霓虹网络空间”。** 暗底与细亮线在普通教室投影中容易丢失，且会把注意力引向人工智能的神秘感，与本课“可计算、可检查”的主张冲突。
- **否决“生物脑与突触写实插画”。** 本课不解释生物神经系统，写实脑图会诱导学生把权重更新等同于真实突触变化，并占用本就有限的术语辨析时间。
- **否决“代码编辑器界面”。** 受众不具备编程前提，代码外观会把调参数误读为编程练习；本课改用旋钮、按钮和可见记录，让算法真实运行但不要求读代码。

## 0.6 对这个受众的取舍

- 能用：四则运算、正负方向、百分比、调旋钮、看折线升降、按步骤追踪因果和“猜测—核对”的生活经验。
- 不用：矩阵记号、偏导符号推导、链式法则证明、向量空间、优化器家族、卷积、softmax、语言模型和编程语法。
- 换算：输入统一缩放为 0–1 的仪表刻度，预测换成 0%–100% 把握，误差变化换成“每拨动一小格增减多少”。
- 争议：神经网络内部表示不必对应人类可命名概念；训练误差下降不保证因果正确、公平或在新环境中可靠。
