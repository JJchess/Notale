## 1. 这堂课在讲什么

全课主张：神经网络的“学习”不是获得意识，而是先计算预测误差，再把误差逐层传回参数，并反复把参数朝误差更小的方向移动。

| 幕 | 页 | 必须建立的认识 |
|---|---:|---|
| I 从旋钮到神经元 | 01–07 | 神经元是一组可调旋钮：输入经过加权、加偏置和激活后得到输出。 |
| II 误差如何推动参数移动 | 08–12 | 损失把预测偏差变成可比较的数；比较参数附近的损失，就能判断旋钮该往哪边转。 |
| III 误差怎样穿过多层网络 | 13–16 | 参数对最终误差的影响可沿连接逐段计算；反向传播高效完成责任分配。 |
| IV 让网络亲自学一次 | 17–22 | 网络重复前向、算损失、反向和更新，最终形成可在新样本上检验的分类规律。 |

证据链固定为：

- E1：输出由输入、权重、偏置和激活规则决定；权重与偏置可调。
- E2：损失把“离目标多远”压成一个可比较的数；学习可定义为让损失下降。
- E3：轻微扰动参数并观察损失变化，可得到下降方向；学习率决定步长。
- E4：多层网络中，影响沿连接路径逐段计算；反向传播把输出误差分给各参数。
- E5：重复“前向预测—计算损失—反向传播—更新参数”，可形成训练样本之外仍可检验的分类规律。

每页只实现自己的 `pNN.md`。规格中标为“不许碰”或由别页承担的定义、推导、案例、结论和交互，不得提前讲、重复讲或另造替代版本。无交互页固定为 01、02、07、12、16、21、22。

## 2. 颜色语义

| token / 色相 | 唯一含义 | 允许出现的位置 |
|---|---|---|
| 主题暖亮底色 / `#F4F1E8` | 实验记录纸面 | 页面底色、方格纸底、大片留白 |
| 主题深蓝 / `#2457A6` | 当前模型算出的值或前向信息 | 当前预测、激活值、前向实线箭头、当前模型曲线或读数 |
| 主题橙 / `#E76F2E` | 当前需要观察、拖动或点击的注意点 | 活动控件、当前游标、被要求比较的局部、即时操作提示 |
| 主题中性色 | 无概念含义的结构与文字 | 正文、边框、刻度、辅助线、未激活控件、背景分区 |
| 主题错误/警示 token（若 `theme.css` 提供） | 数值失败、越界或明确错误反馈 | 真正的错误状态；不得代替橙色注意提示 |

语义色不得挪作装饰，不用颜色单独承载差异。参数用带刻度旋钮，输入与输出用圆角读数框；前向用连续实线箭头，反向影响用双线空心箭头。神经元用圆角矩形，层用虚线分区框。不得引入霓虹赛博、生物神经元显微图或纯代码编辑器视觉。

## 3. 知识结构——骨架约定

容器不是知识关系，不以“卡片网格”或“左右两栏”代替结构。

| 结构 | 必须直接看见的关系 | 最低几何要求 | 失败形态 |
|---|---|---|---|
| process | 先后、因果或状态推进 | 可见方向轴、箭头或连续路径 | 只有并排块 |
| comparison | 同一维度上的差异 | 同行、同尺度、同基线 | 两边各画各的 |
| classification | 上下位或部分—整体 | 嵌套、包含或明确缩进 | 同级平铺 |
| generalization | 主张与支撑 | 主张更重，支撑挂在同一主干 | 主张和证据同权 |

优先使用 `theme.css` 提供的 `.k-*` 知识结构原语。SVG、Canvas 或图表可替代这些原语，但必须让关系在画面上直接成立。公式、图和结论各占独立分区；注释不得塞进连线之间。每页至少保留画面宽度 12% 的有效空白。

## 4. 交互的规矩

- 同一个关系只使用一种主要交互路径，不用滑块、按钮、拖拽等多个控件重复同一结论。
- 教学常量、范围、初值来自 `Lec.K`；计算调用 `Lec.P`，结果必须当场产生。禁止预录结果、硬编码轨迹或伪造数据。
- 随机过程必须固定种子；同一操作序列应得到同一结果。
- 首屏必须静止且已有可讲信息，不依赖自动动画才成立。
- 交互页必须给出明确的动作提示和可观察量，例如“拖动权重，观察损失读数”。
- 滑块、切换、旋钮和游标是观察仪器；没有目标态时不得编造“正确/错误”。
- 只有分拣、配对、拼装等本来存在唯一或明确答案的任务才判定正确性。
- 交互反馈贴近被操作对象，持续显示当前参数、预测或损失中的必要读数。
- 未规划交互的页面不得添加装饰性点击、自动播放、悬停彩蛋或无教学作用的拖拽。

## 5. 技术契约

固定骨架：

    <!doctype html>
    <html lang="zh">
    <head>
      <meta charset="utf-8">
      <link rel="stylesheet" href="assets/base.css">
      <link rel="stylesheet" href="assets/theme.css">
    </head>
    <body data-page="NN" data-total="22">
      <div id="stage"></div>
      <script src="assets/base.js"></script>
      <script src="assets/lec.js"></script>
    </body>
    </html>

- 只修改 `#stage` 内容。`data-page` 保留两位页码，`data-total="22"`；不得把页码显示给读者。
- 逻辑画布固定为 1600 × 900，不得滚动。`#stage` 为 flex 列；顶层区块使用固定高度或 flex 份额，主内容区使用 `flex:1`。
- 字号只用主题 token。正文与成句说明 ≥16px；控件标签、图例、图注、提示 ≥14px；纯数字刻度 ≥12px；多行文字行高 ≥1.35。
- 颜色、字体、圆角、阴影和共享组件取自主题接口。卡片统一 8px 圆角；可操作物使用 2px 实线边框，纯说明区无边框。一次性尺寸可内联，不为单页尺寸新造公共类。
- 不移除或覆盖 `.min0`、`.cv-fill`、`.no-pan` 的机制；缩放画布内禁止 `position:fixed`。
- 默认使用 flex；只有真正二维对齐时使用 grid。
- 页面必须自包含运行，只引用 `pages/` 内相对路径，不用 CDN。
- 图表优先使用已安装库，不重复实现成熟能力。ECharts 必须使用 SVG renderer，并显式设置全局、坐标轴、图例和提示文字字号。
- Canvas 使用 `Deck.fit()` / `Deck.autofit()`；指针坐标使用 `Deck.pt()`；动画使用 `Deck.loop()`。
- Konva 主要画图形；标签优先用 DOM 叠加。必须使用 `Konva.Text` 时显式指定合规字号。
- KaTeX 必须同时引入本地 CSS 与 JS；公式基准字号默认 ≥20px。
- 页面实时训练小型网络使用 `mlp.js`，不得用 TensorFlow.js 或另写一套训练器替代。TensorFlow.js 仅用于预训练模型、真实图片卷积或必须由 GPU 承担的大矩阵；循环中使用 `tf.tidy()` 或显式 `dispose()`。

| 用途 | 库 |
|---|---|
| 物理、碰撞、约束 | Matter.js |
| 三维场景；地球；生成背景 | Three.js；Globe.gl；Vanta |
| 常规图表 | ECharts，`renderer:'svg'` |
| 可拖拽二维场景 | Konva |
| 矢量连线、数据绑定 | D3 |
| 大量元素动画 | PixiJS |
| 分步或时间线动画 | anime.js；GSAP |
| 矢量动画、伪三维、倾斜、淡入 | Lottie；Zdog；Vanilla Tilt；AOS |
| 数学排版 | KaTeX |
| 矩阵计算 | ml-matrix |
| 可复现随机 | seedrandom |
| 小型二分类网络实时训练 | `mlp.js` |
| 预训练模型、卷积、大型 GPU 计算 | TensorFlow.js |

所需库按 `assets/lib/文件名` 本地引用，只加载本页实际使用的库。随机样本使用 `new Math.seedrandom('page-NN')` 或本页规格指定种子。

`Lec.P` 公开接口只按以下签名调用，不读取或复制实现：

    activation(name, x)
    activationDerivative(name, z, output)
    backpropNetwork(inputs, layers, targets, lossName)
    denseForward(inputs, weights, biases, activationName)
    forwardNetwork(inputs, layers)
    lossValueAndGradient(predictions, targets, lossName)
    neuronForward(inputs, weights, bias, activationName)
    sgdStep(layers, gradients, learningRate)
    weightedSum(inputs, weights, bias)

不得改名、增删参数或假定未公开返回字段。

优先使用 `assets/img/IMG.md` 已登记素材，不重复下载、生成或复制同类图片。使用登记索引要求的说明填写 `<img title="…">`。出处与许可不进入主画面。生成插画自带的“AI生成”角标必须完整可见，不得被裁切、覆盖或与控件重叠。照片沿用主题已有边框、圆角和底图规则。

## 7. 文字风格

- 面向无微积分、线性代数和编程基础的大学通识课学生；术语首次出现时用短句解释，但不把正式概念改成拟人化故事。
- 使用教师可直接讲出的短句；一句尽量只承担一个动作或判断。
- 操作提示使用直接口吻：“拖动权重”“比较两次损失”“把学习率调大一格”。
- 避免“如图所示”“显而易见”“接下来我们将”以及评价教学设计的元评论。
- 不把神经元写成会思考的小脑袋，不把反向传播写成误差在网络中“寻找答案”。
- 公式旁必须给变量的人话含义；不用未解释的矩阵记号、导数符号或代码语法推进论证。
- 关键数字给可感换算，例如“损失从 0.80 降到 0.32，约少六成”。近似、随机波动或只在当前样本成立的结论必须明确标注。
- 收束句写成读者应带走的主张；下一问负责推进，不把收束句写成本页内容摘要。

## 8. 自检

完成后使用 `Check` 检查本页：

- JS 错误为 0。
- 资源加载失败为 0。
- 越界与裁切为 0。
- 字号符合正文、标签、刻度的分层地板。
- 前向与反向线型、参数与读数形状、颜色语义均一致。
- 教学常量来自 `Lec.K`，结果由 `Lec.P` 或规定库现场计算。
- 交互页覆盖初始态、边界态和每个主要状态；固定种子可复现。
- 无交互页不存在额外操作。

发现问题时，先用 `Look` 查看问题区域，再用 `Patch` 合并修复。最终只交付本页 HTML；不得修改公共资源，不得增加测试、截图、日志或报告文件。

## 9. 版面密度与常见坑

- 主内容使用 flex 吃满剩余空间，不给普通内容块写死高度。
- 画面占用低于 45% 时，先检查失控的 flex 空隙，再放大有教学意义的关系；不得加装饰撑满。
- 画面占用高于 85% 时，删减内容或报告需要拆页；不得缩小字号规避。
- 骨架和包裹层优先用线、缩进、包含和层级表达，不堆叠多层填色卡片。
- 不用颜色代替箭头方向、线型、标签或位置关系。
- 旋钮、曲线和即时读数应就近对应；不要让读者跨越整页寻找反馈。
- 方格纸、刻度、印章只在承载实验记录、测量或训练轮次时出现，不作背景装饰。
- 照片使用主题已有的边框、圆角和底图规则。
- Canvas 交互区必须添加 `.no-pan`。
