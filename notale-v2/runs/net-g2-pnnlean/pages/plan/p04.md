# page-04 · 转动影响旋钮 · **90 秒**

本规格只锁定教学目标、事实、状态和边界；标题措辞、构图、组件、渲染器和动效由 Builder 按 workflow 决定。

## 页面任务

让学生连续改变权重，观察固定输入产生的加权信号怎样随大小和正负变化：绝对值决定影响强弱，符号决定影响方向。

## 必须看见的关系

输入 `0.80` 始终不变，只有权重和结果变化。权重与加权信号必须保持直接因果联系，并共享以 0 为中心的正负方向语义；负数不是“坏”或“错误”。

## 内容与证据

- 固定输入：`x = 0.80`。
- 可调权重：默认 `w = 0.50`，范围 `−1.00～1.00`，步长 `0.05`。
- 当前结果：`加权信号 = 0.80 × w`，调用 `Lec.P.weightedSum([0.8], [w], 0)`，显示两位小数。
- `w > 0` 表示同方向影响，`w = 0` 表示暂不影响，`w < 0` 表示反方向影响。
- 常驻提示必须说清：只改变权重，观察加权信号。

## 交互状态

- 学生连续调节权重；方向键每次 `0.05`，PageUp/PageDown 每次 `0.10`。
- 权重值、算式、信号大小和方向立即同步。绝对值越大，离 0 越远；越过 0 时结果符号与方向同时翻转。
- 状态连续可逆，没有正确位置；可恢复到 `0.50`。

## 核对

| 输入 | 权重 | 期望结果 |
|---:|---:|---:|
| 0.80 | 0.50 | 0.40 |
| 0.80 | 0.00 | 0.00 |
| 0.80 | −0.75 | −0.60 |

负零必须显示为 `0.00`。

## 主工作流

design-interaction ← 让连续调节、键盘操作与正负影响反馈保持即时且一致

## 边界

不解释权重如何自动更新，不出现学习率或更新公式；参数下降归 p10。偏置与激活分别归 p05、p06。
