# page-05 · 偏置把门槛整体平移 · **75 秒**

本规格只锁定教学目标、事实、状态和边界；标题措辞、构图、组件、渲染器和动效由 Builder 按 workflow 决定。

## 页面任务

让学生保持输入与权重不变，只改变偏置，发现偏置会给加权结果整体加减一个数，并使“加权总和为 0”的输入门槛平移。

## 必须看见的关系

`x = 0.8`、`w = 0.5` 和输入位置始终固定；偏置、加权总和与门槛位置同步变化。必须能直接比较 `b = 0` 与当前偏置，不能因尺度不同把门槛位移误读成输入变化。

## 内容与证据

- 关系式：`0.8 × 0.5 + b = z`。
- `b` 默认 `−0.2`，范围 `−0.4～0.4`，步长 `0.1`。
- 当前加权总和调用 `Lec.P.weightedSum([0.8], [0.5], b)`；门槛输入位置为 `−b / w`。
- 门槛定义：使加权总和刚好为 0 的输入位置。
- `b = 0` 时门槛在 `x = 0.0`；默认 `b = −0.2` 时门槛在 `x = 0.4`。
- 可视输入范围为 `0–1`；门槛超出时仍须报告真实值。

## 交互状态

- 学生调节偏置；方向键每次一格。
- 输入和权重锁定，偏置、`z` 与当前门槛同步变化。偏置增大时门槛左移，偏置减小时门槛右移。
- 状态连续可逆，无正确位置；可恢复到 `−0.2`。

## 核对

| `b` | 期望 `z` | 期望门槛 |
|---:|---:|---:|
| −0.2 | 0.2 | 0.4 |
| 0.0 | 0.4 | 0.0 |
| 0.2 | 0.6 | −0.4 |

## 主工作流

design-interaction ← 保持输入不动、用同尺度即时呈现偏置导致的门槛平移

## 边界

不绘制激活曲线，不把加权总和转换成 sigmoid 输出；激活归 p06。也不讨论偏置如何自动更新。
