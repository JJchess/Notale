# page-06 · 激活定出口 · **70 秒**

本规格只锁定教学目标、事实、状态和边界；标题措辞、构图、组件、渲染器和动效由 Builder 按 workflow 决定。

## 页面任务

让学生比较同一个加权总和经过三种规则后的结果，理解激活规则决定输出的形状和范围；后续单神经元统一使用 sigmoid。

## 必须看见的关系

直通、阶跃和 sigmoid 必须使用同一个输入 `z = 0.2` 与相同坐标口径，差异只能来自规则。三种规则都是“激活”的并列实例，其中 sigmoid 是本课后续采用的规则。

## 内容与证据

| 规则 | 定义或解释 | `z = 0.2` 的输出 |
|---|---|---:|
| 直通 | 输出等于加权总和，范围不受限 | `Lec.P.activation("linear", 0.2)` |
| 阶跃 | `z ≥ 0` 输出 1，否则输出 0 | `Lec.P.activation("step", 0.2)` |
| sigmoid | 平滑压到 0–1，本课采用 | `Lec.P.activation("sigmoid", 0.2)` |

比较曲线时横轴统一为 `z = −4～4`，纵轴统一为 `−1～4`；必须标出 sigmoid 的 0–1 范围和当前输入。sigmoid 读数链应传达 `0.2 → sigmoid → 约 0.5498`。

## 交互状态

- 默认关注 sigmoid；学生可在三种规则间切换，支持左右方向键。
- 当前规则的输入点、输出读数与解释同步强调，另外两种仍可见以便比较。
- 没有正确答案，不需要复位；允许反复切换。

## 核对

| 调用 | 期望结果 |
|---|---:|
| `activation("linear", 0.2)` | `0.2` |
| `activation("step", 0.2)` | `1` |
| `activation("sigmoid", 0.2)` | 约 `0.5498` |

## 主工作流

design-interaction ← 让学习者在同尺度比较中切换规则，并即时看到同一输入产生不同输出

## 边界

不比较 ReLU、tanh、sigmoid 的优劣，也不讨论隐藏层选型；该内容归 p19。
