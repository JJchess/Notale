## 页面任务

完成第一章转折：同一个神经元已经能用给定参数得到预测，但参数算完仍是原值，因此还没有发生“学习”。

## 必须看见的关系

“会算”和“会学”是同一模型的两个状态，不是两个神经元。输入、参数、计算和预测已经存在；缺少的是一个衡量结果好坏的数，以及它推动参数改变的过程。

## 内容与证据

| 项目 | 当前记录 |
|---|---|
| 输入 | `0.8` |
| 权重与偏置 | `w = 0.5`，`b = −0.2` |
| 计算 | 加权 → 激活 |
| 预测 | `0.5498` |
| 算完以后 | `w = 0.5`、`b = −0.2`，仍是原值 |
| 尚缺 | 一个衡量结果好坏的数字 |

必须传达：给定参数就能得到预测；只有结果会推动参数改变，才叫学习。
