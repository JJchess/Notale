# page-14 · 误差逐层回传 · **90 秒**

本规格只锁定教学目标、事实、状态和边界；标题措辞、构图、组件、渲染器和动效由 Builder 按 workflow 决定。

## 页面任务

让学生逐步追踪一次反向传播：从损失出发，沿原计算关系逐层向输入侧返回，把同一个输出误差分配成权重和偏置各自的影响量。

## 必须看见的关系

前向关系为 `输入 → 加权总和 → 预测 → 损失`；反向追踪从损失开始，经过预测和加权总和，最后分到参数。不能跳层，也不能把各影响量画成互不相干的结论。目标固定，不被反向改变。

## 内容与证据

| 对象 | 前向值 | 追踪到此时要说明什么 |
|---|---:|---|
| 输入 `x` | `0.8` | 本次样本提供的信号 |
| 权重 `w` | `0.5` | 影响量约 `−0.0891` |
| 偏置 `b` | `−0.2` | 影响量约 `−0.1114` |
| 加权总和 `z=x×w+b` | `0.2000` | 误差经过 sigmoid 的局部关系 |
| 预测 `ŷ` | `0.5498` | 预测低于目标 |
| 目标 `y` | `1` | 固定，不反向改变 |
| 损失 `½(ŷ−y)²` | `0.1013` | 追踪起点 |

计算必须调用 `Lec.P.neuronForward`、`Lec.P.lossValueAndGradient` 和 `Lec.P.backpropNetwork`，不手写结果。

## 交互状态

- 第 0 步显示完整前向结果。
- 学生开始后可在 0–4 步间前后移动：①输出差多少；②预测对损失的影响；③加权总和承担多少；④分到权重与偏置。
- 每步只增加已经走过的反向关系和当前解释；第 4 步同时显示两个不同影响量。
- 没有正确/失败状态；可重新回到第 0 步。

## 核对

- `neuronForward([0.8],[0.5],-0.2,"sigmoid") → z=0.2000，ŷ=0.5498`。
- `Lec.P.lossValueAndGradient([0.5498339973],[1],"halfSquaredError")` 得到半平方损失约 `0.1013`。
- `backpropNetwork` 得到权重影响量约 `−0.0891`、偏置影响量约 `−0.1114`；前者应近似等于后者乘 `0.8`。

## 主工作流

design-interaction ← 让学习者逐步揭示反向路径，并始终看清当前误差归属

## 边界

只追踪影响量，不执行 `sgdStep`，不显示学习率、更新后的 `w = 0.5891` 或更新公式；这些归 p15。不重复 p13 的扰动实验。
