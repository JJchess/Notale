# page-15 · 真正转动一次旋钮 · **140 秒**

本规格只锁定教学目标、事实、状态和边界；标题措辞、构图、组件、渲染器和动效由 Builder 按 workflow 决定。

## 页面任务

让学生执行且只执行一次反传更新，理解“参数影响量 × 学习率”如何真正变成权重移动，并能检查更新符号。

## 必须看见的关系

前向值、损失、权重影响量、学习率和新权重依次依赖；影响量是更新依据，不是另一个并列读数。更新前后的 `w` 是同一个参数。

## 内容与证据

固定样本：`x = 0.8`、目标 `y = 1`。更新前：`w = 0.5000`、`b = −0.2000`。

| 阶段 | 必须显示的记录 |
|---|---|
| 前向 | `z = 0.8 × 0.5 − 0.2 = 0.2000`；`ŷ = 0.5498` |
| 损失 | `L = 0.1013` |
| 反向 | 权重影响量 `−0.0891`；负号表示增大权重会让损失下降 |
| 步长 | 学习率 `η = 1.0` |
| 更新式 | `新权重 = 旧权重 − 学习率 × 权重影响量` |
| 代入 | `0.5000 − 1.0 × (−0.0891) = 0.5891` |
| 结果 | `w: 0.5000 → 0.5891`；已完成 1 次更新 |

调用 `Lec.P.neuronForward`、`Lec.P.lossValueAndGradient`、`Lec.P.backpropNetwork`、`Lec.P.sgdStep` 当场计算。偏置影响量可次级显示，但不更新偏置。

## 交互状态

- 初始已经有前向值，但尚未更新。
- 学生执行一次更新后，依次揭示损失、权重影响量、更新式和新权重；随后禁止再次执行。
- 更新前旧值仍可追认；支持键盘执行。
- 可“重置本步”，恢复 `w = 0.5000` 并清除反向与更新状态。

## 核对

- `neuronForward → z=0.2000，ŷ=0.5498`。
- `backpropNetwork → 权重影响量约 −0.0891`。
- `sgdStep(..., 1.0) → w=0.5891`；若为 `0.4109`，更新符号反了。

## 主工作流

design-interaction ← 把一次不可重复的“计算并更新”拆成可检查、可复位的单步操作

## 边界

只执行一次更新，不连续训练或画轮次曲线；连续训练归 p18。路径机制归 p14，学习率比较归 p11。
