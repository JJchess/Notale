# page-04 · 转动影响旋钮 · **90 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `WEIGHT · 权重` |
| 主标题 | 转动权重，就在改变这个输入的影响 |
| 收束句 | 权重的大小决定影响有多强，正负决定影响朝哪个方向。 |
| 下一问 | 如果不改变输入，怎样让整体结果再挪一点？ |

## 知识结构：process

1. **关系不变量**：输入读数、权重旋钮、乘号与加权信号必须沿同一水平流水线相连；输入固定，旋钮与结果同步变化，正负方向共用同一条以 0 为中心的尺度。
2. **禁止画法**：不得把不同权重结果拆成互不对齐的卡片，否则会削弱“只改一个旋钮，其余不变”的因果关系。
3. **共享原语**：`.canvas-full.k-process` 承载从输入到结果的单向计算链；`.knob` 表示唯一可调参数；`.panel` 固定输入与即时读数，使操纵量和结果量可辨。

## 表征形式

交互式单神经元加权流水线。使用原生 DOM 与 SVG：DOM 承担旋钮、滑块和数值读数，SVG 绘制连续实线箭头及以 0 为中心的正负影响尺，无需图表库。权重与结果共享线性方向语义；所有即时数值保留两位小数。状态变化时调用 `Lec.P.weightedSum([0.8], [weight], 0)`，随后更新读数、旋钮角度、结果标记位置及连线方向 class。

## 加权流水线

| 区域 | 画面文字 | 值或规则 |
|---|---|---|
| 输入框 | 输入 | `0.80`，固定 |
| 运算符 | × | 固定 |
| 旋钮标签 | 权重 w | 默认 `0.50` |
| 结果框 | 加权信号 | `输入 × 权重` |
| 正向尺右端 | 同方向影响 | 权重 `> 0` |
| 中点 | 暂不影响 | 权重 `= 0` |
| 正向尺左端 | 反方向影响 | 权重 `< 0` |
| 提示 | 拖动旋钮：只改变权重，观察加权信号 | 常驻 |
| 算式行 | `0.80 × w = 加权信号` | 等宽字，随拖动刷新 |

页面不显示偏置、激活、预测或损失。负结果不用“坏”或“错误”描述，只标为反方向。

## 交互

学习者拖动权重旋钮或其关联滑块；范围 `−1.00～1.00`，步长 `0.05`，默认 `0.50`。支持方向键每次改变 `0.05`，PageUp/PageDown 每次改变 `0.10`。

拖动后立即更新权重值、算式、加权信号与影响尺标记：绝对值越大，标记离 0 越远；越过 0 时，结果符号与箭头方向同步翻转；到 0 时连线仍保留，但结果标记停在中点。状态连续可逆，不设置正确位置；提供“复位到 0.50”按钮。

## 核对

| 输入 | 权重 | `Lec.P.weightedSum([输入], [权重], 0)` 期望值 |
|---:|---:|---:|
| 0.80 | 0.50 | 0.40 |
| 0.80 | 0.00 | 0.00 |
| 0.80 | −0.75 | −0.60 |

实现时核对符号翻转、两位小数显示及负零规整为 `0.00`。

## 不许碰

不解释权重如何根据误差自动更新，也不出现“下坡”、学习率或更新公式；参数下降归 p10。偏置与激活分别归 p05、p06，本页只处理输入乘权重。
