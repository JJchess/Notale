# page-05 · 偏置把门槛整体平移 · **75 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `BIAS · 偏置` |
| 主标题 | 输入没变，偏置把响应门槛整体平移 |
| 收束句 | 偏置是另一只可调旋钮：它不改输入，只给加权结果整体加上或减去一个数。 |
| 下一问 | 得到加权总和之后，神经元怎样把它变成 0–1 的输出？ |

## 知识结构：comparison

1. **关系不变量**：上区固定展示同一个输入 `x = 0.8`、同一个权重 `w = 0.5`；下区“偏置为 0”与“当前偏置”两行必须共用同一条 0–1 输入刻度、零点门槛定义和左右基线，样本标记始终停在 `0.8`。
2. **禁止画法**：不得把两种偏置拆成尺度不同、无法水平对齐的独立卡片，否则门槛位移会被误读为输入变化。
3. **共享原语**：`.split-tb` 上区承载固定条件与偏置控件，下区承载对齐比较；`.k-comparison` 规定两行共享尺度；`.panel` 包住可操作读数，`.tag` 标记“输入未变”。

## 表征形式

交互式双行门槛尺：原生 DOM、`input[type=range]` 与 SVG 最合适，因核心是单轴对齐、游标平移和即时数值更新，不需要图表库。SVG 使用共享线性尺度 `x: 0–1`；纯数字刻度不小于 `13px`，门槛与即时读数不小于 `15px`。滑块输入后重新计算并更新 SVG 的门槛位置、连线和文本；状态切换 class 标出当前操作点。

## 两行比较内容

| 位置 | 画面文字 | 值与关系 |
|---|---|---|
| 固定条件 | `输入 x`、`权重 w` | `x = 0.8`，`w = 0.5` |
| 上区算式 | `加权结果 + 偏置 = 加权总和` | `0.8 × 0.5 + b = z` |
| 基准行 | `偏置为 0` | `b = 0.0`；门槛在 `x = 0.0` |
| 当前行 | `当前偏置` | 默认 `b = −0.2`；门槛在 `x = 0.4` |
| 固定样本标记 | `输入仍是 0.8` | 两行同位置显示 |
| 即时读数 | `当前加权总和 z` | 默认 `0.2` |
| 尺旁注 | `门槛：加权总和刚好为 0 的输入位置` | 仅解释零点，不展示输出曲线 |

计算入口：当前加权总和调用 `Lec.P.weightedSum([x], [[w]] 的对应单输出权重形式按接口要求传入, b)`；若该函数实际接收单神经元权重向量，则传 `[0.5]`。门槛位置按 `−b / w` 计算并限制在可视轴 `0–1`；超出时贴边显示箭头和数值。

## 交互

学习者拖动“偏置尺”，范围 `−0.4` 至 `0.4`，步长 `0.1`，默认 `−0.2`。输入 `0.8` 与权重 `0.5` 始终锁定；偏置数值、加权总和、当前行门槛游标同步变化。向右拖大偏置时门槛向左移，向左拖小偏置时门槛向右移，以形成“输入没动，整道门槛在移动”的直觉。键盘方向键每次移动一格；提供“回到 −0.2”按钮。

## 动效

拖动时仅让当前行门槛游标沿水平轴移动，单次补间 `160ms`；加权总和数字同步变更。固定输入标记不移动。启用减少动态效果时取消补间，直接落位。

## 核对

| 参数 | 期望加权总和 | 期望门槛位置 |
|---|---:|---:|
| `x=0.8, w=0.5, b=−0.2` | `0.2` | `0.4` |
| `x=0.8, w=0.5, b=0.0` | `0.4` | `0.0` |
| `x=0.8, w=0.5, b=0.2` | `0.6` | `−0.4`，轴左侧贴边标注 |

## 主工作流

design-interaction ← 保持输入不动、用同尺度即时呈现偏置导致的门槛平移

## 不许碰

不绘制或比较任何激活曲线，不把加权总和转换成 sigmoid 输出；激活规则与 0–1 输出归 p06。也不讨论偏置如何自动更新。
