# page-06 · 激活定出口 · **70 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `ACTIVATION RULE` |
| 主标题 | 同一个加权总和，经过不同激活规则，会得到不同形状的输出 |
| 收束句 | 激活规定输出怎样变化；本课采用 sigmoid，把任意加权总和压到 0–1。 |
| 下一问 | 神经元会算出预测了，但怎样把“预测得好不好”变成一个数？ |

## 知识结构：classification

1. **关系不变量**：三个激活规则必须在 `.triptych` 中同行、等宽、同基线；每栏都按“同一输入 \(z\) → 规则曲线 → 输出 \(y\)”嵌套，并共享相同横轴范围与当前输入标记，保证差异只来自激活规则。
2. **禁止画法**：不得把三种规则画成横轴范围、纵轴范围或当前输入不同的独立示意卡，否则输出差异无法归因于规则。
3. **共享原语**：`.k-classification` 负责把“激活”总类落入三个并列规则分支；`.triptych` 承担同尺度横向归类；每栏用 `.panel` 包住曲线与读数，当前输入点用 `.tag` 标明。

## 表征形式

交互式三联 SVG 函数图：原生 DOM + SVG 足以完成三条简单曲线、共享坐标和状态切换，无需图表库。三栏横轴统一为 \(z=-4\) 到 \(4\)，纵轴统一为 \(-1\) 到 \(4\)，同时以淡线标出 sigmoid 的 0–1 输出带；默认当前加权总和为 `z = 0.2`。按钮切换 `直通 / 阶跃 / sigmoid` 的关注状态，统一调用 `Lec.P.activation(name, z)` 重算输出并切换 class；非当前栏保持可见，当前栏边框、曲线和读数获得强调。

## 三种激活规则

| 栏 | 画面标签 | 规则文字 | 当前输入 | 当前输出 | 页面注记 |
|---|---|---|---:|---:|---|
| 左 | 直通 | `输出 = 加权总和` | `z = 0.2` | 动态计算 | 原样放行，输出范围不受限 |
| 中 | 阶跃 | `z ≥ 0 输出 1；否则输出 0` | `z = 0.2` | 动态计算 | 只给 0 或 1，跳变发生在 0 |
| 右 | sigmoid · 本课采用 | `平滑压到 0–1` | `z = 0.2` | 动态计算 | 任意输入都落在 0 与 1 之间 |

右栏另显示读数链：`加权总和 0.2 → sigmoid → 输出 0.5498`。`0.5498` 由接口计算，不硬编码为运算结果；表中仅作为画面格式与核对目标。

## 交互

学习者点击三枚规则按钮或用左右方向键切换；默认选中 `sigmoid`。切换后，橙色当前点在对应曲线上出现，输出读数立即更新，规则说明同步强调；另外两栏保持灰阶可比较。交互没有正确答案，目的是观察“输入相同，转换规则不同，输出形状与范围不同”。再次点击任一按钮即可反复比较，无需复位。

## 动效

切换时当前点沿同一条 `z = 0.2` 竖向参考线移动到新输出位置，时长 240ms；输出数字同时交叉淡变 160ms。遵循 reduced-motion 时取消位移，只瞬时更新点位与读数。

## 主工作流

design-interaction ← 让学习者在同尺度三联图中切换规则，并即时看到同一输入产生不同输出

## 核对

| 调用 | 参数 | 期望结果 |
|---|---|---:|
| `Lec.P.activation("linear", z)` | `z = 0.2` | `0.2` |
| `Lec.P.activation("step", z)` | `z = 0.2` | `1` |
| `Lec.P.activation("sigmoid", z)` | `z = 0.2` | 约 `0.5498` |

## 不许碰

不比较 ReLU、tanh、sigmoid 等隐藏层激活函数的优劣，也不讨论网络深度中的选型；该比较归 p19。本页只建立“激活规定输出形状与范围”并确定后续单神经元统一使用 sigmoid。
