# page-09 · 扫描误差曲线 · **110 秒**

| 主标题 | 权重每停在一个位置，损失就有一个确定读数 |

## 知识结构：process

1. **关系不变量**：权重横轴、损失纵轴、完整误差曲线、扫描竖线与当前读数必须共用同一坐标系；竖线所指曲线点必须与权重、预测、损失三项读数严格同步。
2. **禁止画法**：不得把不同权重的损失拆成互不对齐的卡片或按时间顺序排列，以免把“同一函数上的位置”误读成训练过程。
3. **共享原语**：`.canvas-full` 内以 `.k-process` 承担从“选择权重位置”到“前向计算”再到“损失落点”的连续关系；`.cvbox` 承载共享尺度曲线；`.panel` 承载同步数值读数。

## 表征形式

交互式单变量误差曲线：横轴为权重 \(w\)，纵轴为半平方损失 \(L\)，橙色扫描线可沿横轴移动，深蓝曲线保持静态；当前点、预测值与损失值即时更新。

使用 ECharts，SVG renderer。两轴均为线性轴；横轴固定 `−2.0～4.0`，纵轴固定 `0～0.50`，避免扫描时自动缩放制造“曲线在移动”的错觉。曲线采样步长 `0.02`，关闭数据缩放与动画，tooltip 仅显示当前扫描点。状态变化通过 `setOption` 更新 markLine、当前散点和读数。

## 误差地形内容

| 对象 | 画面文字或值 | 生成方式 |
|---|---|---|
| 固定样本 | `输入 x = 0.8`；`目标 y = 1` | 写入内容 |
| 固定规则 | `偏置 b = −0.2`；`激活 sigmoid`；`损失 ½(预测−目标)²` | 写入内容 |
| 横轴 | `权重 w`，刻度 `−2, −1, 0, 1, 2, 3, 4` | 写入内容 |
| 纵轴 | `损失 L`，单位“损失分” | 写入内容 |
| 曲线 | 每个 \(w\) 对应一个 \(L\) | 对每个采样值调用 `Lec.P.neuronForward([0.8], [w], -0.2, "sigmoid")`，再调用 `Lec.P.lossValueAndGradient([prediction], [1], "halfSquaredError")` |
| 当前扫描 | 默认 `w = 0.5` | 写入内容 |
| 即时读数 | `权重`、`预测`、`损失` | 由同一次计算更新；预测 4 位小数，损失 4 位小数 |
| 图内注记 | `一处权重位置 → 一个损失读数` | 写入内容 |
| 操作提示 | `拖动扫描尺；这里只观察，不更新权重。` | 写入内容 |

## 交互

学习者拖动图下方扫描尺或直接点击曲线横向位置；键盘方向键每次改变 `0.1`，Shift＋方向键每次改变 `0.5`。范围 `−2.0～4.0`，默认 `0.5`。

扫描时只改变探针位置：橙色竖线、曲线上的橙色点、`w`、预测和损失同步变化；曲线本身、样本、偏置与目标不变。拖过多个位置后保留浅色小圆点作为“已测位置”，最多 24 个，强调曲线由许多参数—损失配对组成。提供“清除扫描痕迹”，恢复默认探针并移除历史点；不得出现“更新”“下一步”“下降”等执行按钮。

## 主工作流

visualize-data ← 构造共享尺度、可扫描且数值严格同步的参数—损失曲线

## 核对

| 参数 | 期望预测 | 期望半平方损失 |
|---|---:|---:|
| `w = 0.5` | `0.5498` | `0.1013` |
| `w = 0.6` | `0.5695` | `0.0927` |
| `w = 0.4` | `0.5300` | `0.1105` |

三组均固定 `x=0.8`、`b=−0.2`、目标 `1`；核对值不作为预标答案印在曲线上。
