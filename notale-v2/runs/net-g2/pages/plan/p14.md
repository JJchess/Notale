# page-14 · 误差逐层回传 · **90 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `BACKPROP · 单步追踪` |
| 主标题 | 一个输出误差，怎样逐层变成每个参数的影响？ |
| 收束句 | 反向传播从损失出发，沿连接反向复用局部关系，算出每个参数对这次误差的影响。 |
| 下一问 | 知道影响方向后，怎样把它真正变成一次参数调整？ |

## 知识结构：classification

1. **关系不变量**：画面按“输入 → 加权总和 → 预测 → 损失”从左到右同基线排列；参数旋钮嵌在其所属连接下方。反向追踪必须从损失开始，以双线空心箭头沿原连接逐层向左返回，最终落到权重与偏置，不能跨层跳接。
2. **禁止画法**：不得把各步拆成互不相连的说明卡片，否则会把“沿同一计算路径逐层分配影响”误读成若干独立结论。
3. **共享原语**：`.canvas-full.k-classification` 承载单一层级连接图；`.panel` 包住各层即时读数，`.knob` 只标识参数归属。前向实线与反向双线在同一几何路径上叠置但略微错开。

## 表征形式

交互式单步路径追踪。使用原生 DOM + SVG：节点和数值用 DOM 保证投影可读，SVG 绘制可定向、可高亮的连接；无需图表坐标轴或网络布局库。点击“下一步”或按方向键切换追踪状态，通过切换 class 更新当前节点、已走过的双线箭头和解释条；调用 `Lec.P.neuronForward`、`Lec.P.lossValueAndGradient` 与 `Lec.P.backpropNetwork` 当场计算，禁止手写推导结果。共享数值保留 4 位小数，影响量保留 4 位。

## 主工作流

design-interaction ← 让学习者逐步揭示反向路径，并始终看清当前误差归属

## 单步追踪内容

| 层级/对象 | 画面文字 | 初始显示 | 追踪到此时显示 |
|---|---|---:|---|
| 输入 | `输入 x` | `0.8` | `本次样本提供的信号` |
| 权重参数 | `权重 w` | `0.5` | `影响量 −0.0891` |
| 偏置参数 | `偏置 b` | `−0.2` | `影响量 −0.1114` |
| 加权总和 | `z = x×w+b` | `0.2000` | `误差要经过 sigmoid 这一关` |
| 预测 | `ŷ = sigmoid(z)` | `0.5498` | `预测低于目标` |
| 目标 | `目标 y` | `1` | `固定，不反向改变` |
| 损失 | `L = ½(ŷ−y)²` | `0.1013 损失分` | `反向追踪从这里开始` |

底部当前步骤条依次写：`① 输出差了多少`、`② 预测对损失的影响`、`③ 加权总和承担多少`、`④ 分到权重与偏置`。最终只标出影响量，不出现新参数值。

## 交互

学习者点击橙色按钮“开始反向追踪”，随后用“上一步 / 下一步”或键盘左右方向键，在 0–4 步间移动；默认第 0 步仅显示完整前向结果。每前进一步，只新增一段从右向左的双线空心箭头，并高亮当前节点及对应步骤文字；第 4 步同时落到 `w` 与 `b`，显示二者不同的影响量，使学生看到同一误差会按连接关系分配。提供“重新追踪”回到第 0 步；无正确/失败状态。

## 动效

每段反向箭头由右向左描边 260ms，当前节点随后轻亮 180ms；相邻步骤错开 80ms。第 4 步的路径在加权总和处分叉，先共同到达该点，再分别用 180ms 落到权重与偏置。启用 reduced-motion 时取消描边动画，直接切换完整静态状态。

## 核对

- `Lec.P.neuronForward([0.8],[0.5],-0.2,"sigmoid")`：加权总和应为 `0.2000`，预测应为 `0.5498`。
- `Lec.P.lossValueAndGradient([0.5498339973],[1],"halfSquaredError")`：损失应约为 `0.1013`。
- 同一层网络调用 `Lec.P.backpropNetwork`：权重影响量应约为 `−0.0891`，偏置影响量应约为 `−0.1114`；若权重影响量未近似等于偏置影响量乘输入 `0.8`，检查权重布局与符号。
