# page-15 · 真正转动一次旋钮 · **140 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `ONE BACKPROP STEP` 一次反传更新 |
| 主标题 | 方向乘上步长，才真正变成参数更新 |
| 收束句 | 一次训练步，就是先算出参数对损失的影响，再按学习率朝相反方向移动。 |
| 下一问 | 反向传播是在倒着重新预测吗？ |

## 知识结构：process

1. **关系不变量**：上区按同一条水平时间轴同行排列“前向值 → 输出误差 → 参数影响量”；下区把旧权重、学习率、影响量和新权重放在同一更新式与同一数值基线上，并用连线对应上区的权重影响量。
2. **禁止画法**：不得把四个量拆成互不对齐的独立卡片，否则会误读为四条知识点，而不是一次更新中依次依赖的计算。
3. **共享原语**：`.split-tb` 承担“先得到调整依据、再执行更新”的上下因果；`.k-process` 用贯穿箭头保持步骤方向；`.panel` 承载即时读数，`.knob` 只表现更新前后的同一个权重旋钮。

## 表征形式

交互式单步计算流水线。使用原生 DOM 与 SVG：DOM 保证公式、按钮和读数清晰可访问；SVG 绘制上区前向实线箭头、反向双线空心箭头及上下区对应连线，无需图表库。数值状态由 `Lec.P.neuronForward`、`Lec.P.lossValueAndGradient`、`Lec.P.backpropNetwork`、`Lec.P.sgdStep` 计算；点击后切换阶段 class 并重绘 SVG。所有读数保留 4 位小数，学习率显示 1 位。

## 主工作流

design-interaction ← 把一次不可逆的“计算并更新”拆成可检查、可复位的单步操作

## 一次更新记录

| 阶段 | 画面文字 | 写入画面的值或入口 |
|---|---|---|
| 固定样本 | 输入与目标 | `输入 x = 0.8`；`目标 y = 1` |
| 更新前参数 | 当前旋钮 | `权重 w = 0.5000`；`偏置 b = −0.2000` |
| 前向 | 先算预测 | `z = 0.8 × 0.5 − 0.2 = 0.2000`；`预测 ŷ = 0.5498` |
| 误差 | 再量偏差 | `损失 L = 0.1013` |
| 反向 | 分给权重的影响 | `权重影响量 = −0.0891`；旁注“负号：增大权重会让损失下降” |
| 步长 | 本次移动倍率 | `学习率 η = 1.0` |
| 更新式 | 朝影响量的反方向移动 | `新权重 = 旧权重 − 学习率 × 权重影响量` |
| 代入 | 真正转动旋钮 | `0.5000 − 1.0 × (−0.0891) = 0.5891` |
| 结果 | 更新后参数 | `w：0.5000 → 0.5891`；状态标记“已完成 1 次更新” |

偏置影响可由反传接口计算，但本页只以次级读数显示“偏置也收到自己的影响量”；不执行或展示其更新结果，避免产生第二条主计算线。

## 交互

默认停在“已算出前向值，尚未更新”。学习者点击橙色按钮“执行这一次更新”；第一次点击依次显露输出误差、权重影响量和更新式，随后权重旋钮从 `0.5000` 转到 `0.5891`，旧值保留为灰色刻度标记。按钮随后变为不可再次执行的“本步已完成”，杜绝连续训练。

提供“重置本步”，恢复 `w = 0.5000`、隐藏反向结果并清除更新轨迹。键盘可聚焦按钮并用 Enter/Space 执行；不提供可拖动权重或学习率，避免退回 p10–11 的探索任务。

## 动效

点击后按过程反馈：输出端误差橙色闪亮 180ms；双线空心箭头自右向左绘出 360ms；更新式各项以 100ms 间隔高亮；旋钮顺时针转至新刻度 420ms。总时长不超过 1.1s。减少动态模式下取消绘制与旋转，仅即时切换最终状态并保留方向高亮。

## 核对

- `Lec.P.neuronForward([0.8], [0.5], −0.2, "sigmoid")`：加权总和应为 `0.2000`，输出应为 `0.5498`。
- `Lec.P.backpropNetwork([0.8], 单层网络, [1], "halfSquaredError")`：权重影响量应约为 `−0.0891`。
- `Lec.P.sgdStep(单层网络, gradients, 1.0)`：权重应从 `0.5000` 更新为 `0.5891`；若得到 `0.4109`，说明更新符号写反。

## 不许碰

只执行并锁定一次参数更新，不重复多轮、不画训练轮次损失折线；连续训练归 p18。不要重新教学反向传播如何逐层追踪，路径机制归 p14；学习率优劣比较归 p11。
