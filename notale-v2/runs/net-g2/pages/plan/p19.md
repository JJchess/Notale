## 知识结构：comparison

1. **关系不变量**：三列必须共用同一批 200 个样本、同一输入坐标范围、同一分类阈值与同尺寸边界视窗；网络结构图、最终边界、结构标签必须逐列垂直对齐。
2. **禁止画法**：不得把三种网络拆成尺度不同、样本不同或训练条件不明的独立卡片，否则无法把差异归因于层结构。
3. **共享原语**：`.triptych.k-comparison` 承担三列同尺度比较；每列用 `.cvbox` 固定相同输入空间，用 `.tag` 标出结构与训练状态。

## 表征形式

交互式三联对照：左列“无隐藏层”，中列“1 个隐藏层”，右列“2 个隐藏层”；每列上方是简化网络层图，下方是同一二维样本散点与分类边界。

使用原生 Canvas 绘制 80×80 概率场、样本点和阈值边界，原生 SVG 绘制网络层图；三列共享坐标域、色标和绘制逻辑，避免图表默认留白破坏同比例。状态切换后调用统一 `draw(modelIndex)` 重绘三列；训练计算调用 `Lec.P.forwardNetwork`、`Lec.P.backpropNetwork` 与 `Lec.P.sgdStep`。

## 三列对照

| 列 | 结构标签 | 网络示意 | 画面说明 | 观察标签 |
|---|---|---|---|---|
| 左 | `2–1` | 输入层直连输出层 | 边界只能是一条直线，无法贴合弯曲分界 | `欠贴合` |
| 中 | `2–10–1` | 1 个隐藏层，每层节点仅作示意 | 可组合出弯曲边界，明显贴近两类样本 | `能弯曲` |
| 右 | `2–10–10–1` | 2 个隐藏层，每层节点仅作示意 | 可形成更细致的弯曲边界；本页不评价其必然更好 | `更深 ≠ 必然更好` |

| 共同条件 | 画面文字/值 |
|---|---|
| 数据 | `同一批 200 个样本｜两类各 100` |
| 随机性 | `固定种子 1` |
| 学习率 | `0.3` |
| 小批量 | `16` |
| 输出规则 | `输出 ≥ 0.5 判为类别 1` |
| 边界采样 | `80×80` |
| 隐藏层激活 | `tanh` |
| 输出激活 | `sigmoid` |
| 控制状态 | 默认选中 `同时训练`；可切换 `只看左 / 中 / 右` |

## 交互

学习者点击“同时训练”，三列从同一固定数据与固定初始化规则开始，按相同轮数同步更新；按钮随后变为“暂停”。点击列标签可突出一列，其余两列降对比但保持可见；键盘可用 Tab 聚焦、Enter/Space 操作。

即时变化仅包括概率底色、0.5 分类边界与当前训练轮数；三列始终共享轮数。提供“重新开始”，恢复种子 1、轮数 0 和三组初始参数。学习直觉是：训练动作相同，结构限制了网络能画出的边界形状；不设置“最佳深度”或胜负判定。

## 动效

每次更新后，边界从旧位置向新位置插值 180ms；三列同步、无错开。突出某列时仅做 120ms 对比度切换。开启 reduced-motion 时直接重绘最终状态，不插值。

## 核对

- 数据生成后必须为 200 点，类别 0 与类别 1 各 100；三列点坐标逐点完全相同。
- 所有分类图以 `0.5` 为唯一阈值，概率场采样严格为 `80×80`。
- 同一轮次三列均使用学习率 `0.3`、小批量 `16`；左列结构必须保持 `2–1`，不得暗中增加隐藏特征。

## 主工作流

design-interaction ← 让三种网络在完全相同条件下同步训练、可逆突出并保持公平比较

## 不许碰

不得由右列推出“层数越多越好”，也不比较架构优劣、训练成本或泛化能力；这些边界留给 p21。不得重新讲隐藏神经元各自响应什么区域，该表征归 p17。
