拨动权重，看神经元「多在乎」哪个输入

设想一个神经元在判断"要不要推荐这部电影"——它同时看三个信号，每个信号配一个权重 w，权重决定这个信号有多大的发言权。

x₁ 动作场面
x = 0.90
w₁ +0.6
支持
x×w = +0.54
x₂ 剧情复杂度
x = 0.40
w₂ −0.4
反对
x×w = −0.16
x₃ 演员知名度
x = 0.70
w₃ +0.1
不太在乎
x×w = +0.07
当前是否推荐：a > 0.5 → 支持
0.61
当前判定：推荐（a > 0.5）
z = 0.90×0.6 + 0.40×(−0.4) + 0.70×0.1 = 0.45
w=[1,1,1]
a≈0.88
三路全力支持，权重都推到 +1，输出被拉到接近 1
w=[−1,−1,−1]
a≈0.12
三路全力反对，权重都推到 −1，输出被拉到接近 0
w=[0,0,0]
a=0.50
三路权重都是 0，谁都不在乎，输出回到中性 0.5
拖动任意滑块调整对应权重（−1.0 ~ 1.0，步长 0.1）：连线的粗细和颜色跟着刻度实时变化，输出圆里的 a 值也会立刻刷新——不用等，看一眼就知道这一路现在算不算数。
支持 w ≥ 0.2 反对 w ≤ −0.2 不太在乎 |w| < 0.2

权重越偏离 0（无论正负），这个输入对结果的影响越大；权重贴近 0，这个输入几乎被忽略——权重就是"在乎程度"。
