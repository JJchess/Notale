sigmoid：把任意实数压进 0 到 1，永不越界

曲线：a = σ(z) 渐近线 a=0 / a=1（永不相交） z=0，斜率最大处
z = 0 处斜率最大，σ'(0) = 0.25（越往两端，斜率越接近 0，曲线越平）
七个代表 z 值，与其压缩后的 a 值（Δa 为相对上一 z 的变化量）
z
a = σ(z)
Δa（较上一 z）
两端 z 差 4（−10→−6），a 几乎不变；中段 z 差仅 2（−2→0），a 却大幅跳动——这就是「压扁」的意思：两端早已挤在一起，中段还留着坡度。
无论输入多大或多小，sigmoid 输出都锁在 0 和 1 之间，且永远够不到两端。
