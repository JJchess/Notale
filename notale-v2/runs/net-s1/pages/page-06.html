NEURON · PIPELINE

一次预测，只有三步：加权、求和、压缩

① 输入 × 权重
② 加权求和 z
③ 压缩输出 a
①

输入 × 权重

x₁ = 1.0
w₁ = 0.5
x₁×w₁ = 1.0 × 0.5 = 0.5（线较粗：|w₁| 中等，正向拉高 z）
x₂ = 0.6
w₂ = −0.8
x₂×w₂ = 0.6 × (−0.8) = −0.48（线更粗：|w₂| 更大，负向拉低 z）
b = 0.2 偏置：不看任何输入，直接加进求和里的"底数"
|w₁|
0.50
|w₂|
0.80

这个神经元只认两个输入：x₁、x₂。每个输入配一个权重，权重越大，这个输入说话越有分量——上面这两条短条直接比出来：|w₂| 比 |w₁| 长，说明 x₂ 这一路权重更大；w₂ 又是负的，说明 x₂ 越大反而把结果往下拉。

②

加权求和

z = x₁w₁ + x₂w₂ + b
= 1.0×0.5 + 0.6×(−0.8) + 0.2
= 0.5 + (−0.48) + 0.2
= 0.22

+x₁w₁
+0.50

四行演示加的顺序：从 0 先加 x₁w₁ 跳到 +0.50，再加 x₂w₂ 退回到 +0.02，最后加 b 落在 z=0.22——三笔加法，谁先谁后都不影响最终落点。z 可能是负数，也可能很大，这一步还没有“挤”进任何范围。

③

压缩输出

a
a = σ(z)
σ(0.22) ≈ 0.555
0（不发信号）0.51（强烈发信号）

σ（sigmoid）把任意数字压进 (0, 1) 之间——这是上一页已经确认过的结论，这里直接拿来用。圆圈的深浅、上面这条刻度上的橙色标记，都是同一个数：a 的大小。0.555 比一半稍高，说明这次输入让神经元略微"倾向"发出信号。无论 z 多大多小，a 永远被挤在 0 和 1 之间，这就是"压缩"二字的意思。

从 z = 0.22 到 a ≈ 0.555，数值一步没丢：同一组 x、w、b 算出同一个 z，同一个 z 压缩出同一个 a。这条链路里没有任何一步是随机或靠"感觉"，换一组 x、w、b，答案也会跟着变。

z = −2a ≈ 0.12
z = 0a = 0.50
z = 0.22（本例）a ≈ 0.555
z = +2a ≈ 0.88

z 跃再大，a 不超 1；z 跳再小，a 不过 0。

z = Σ xᵢwᵢ + b
a = σ(z)
本例：z=0.22 → a≈0.555

从输入到输出，每一步都是可以手算的数字，没有任何一步是黑箱。
