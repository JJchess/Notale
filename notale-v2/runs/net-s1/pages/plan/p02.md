## 知识结构：generalization

**关系不变量**：七张卡片必须等大同基线、按 I→VII 的教学顺序单行排列（可换行但顺序不可打乱），每卡只承载"章节号 + 章节名 + 一句问题"三层信息，字号/配色规格完全一致；当前所在章节（I）用橙色高亮标出，其余六张同色同权重。

**禁止画法**：不得按"重要程度"或"难度"重新排序卡片、也不得把某几章合并成一张更大的卡片——七章在证据链上权重相等，排序即时间顺序，绝不能暗示某章比其他章更核心。

**共享原语**：使用 `.k-generalization` 骨架——页面主张（`.claim`：路线图本身）通过 `.trunk`（隐含的从左到右阅读方向）连到七个 `.support`（即七张 `.card`）；版式落地为 `.stage-cards`，七个 `.card` 等权重铺满网格，当前章节所在卡片加 `.card.active` 类，用 `--orange` 描边与其余六张的 `--blue` 描边区分。

## 表征形式

静态 DOM 卡片网格，无需图表库。七个 `.card` 元素直接放入 `.stage-cards` 容器，CSS Grid 自适应换行（建页阶段决定列数）；每卡内部三行文字：章节号（等宽字体，如 `I` `II`）、章节名（`--fs-h2`）、一句问题（`--fs-sec`，`--text-dim`）。当前章节卡片加 `active` class 触发描边变色（`--blue`→`--orange`），纯 CSS 切换，无需 JS 状态机。若需入场节奏可用 `scroll-reveal-libraries` 做一次性 stagger 淡入，不代表任何数据关系，可省略。
