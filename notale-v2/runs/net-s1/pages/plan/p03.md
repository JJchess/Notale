## 知识结构：process

**关系不变量**：输入节点、权重连线、求和节点 z、压缩节点 a 必须排在同一条从左到右的水平流线上，次序不可打乱，且 z 到 a 必须用同一条轴线直接相连，不能中断。
**禁止画法**：不得把"加权求和"和"压缩函数"画成两张并列、互不连接的静态卡片——那会让人误以为它们是两个独立、可拆分调用的步骤，而不是同一条计算流水线上先后发生的两件事。
**共享原语**：`.k-process` 的 `.step` 用 `.arw` 串起"输入→z→a"三段，`.axis` 贯穿整条流水线提供方向感；`.neuron`/`.wire` 承担神经元圆形节点与权重连线的母题绘制（连线粗细=|w|，颜色=正负）；右侧 `.panel.q` 只镜像左图数值，不重复画图形。

## 表征形式

静态图示为主，不需要自动播放动画：左侧 `.pane-l` 用原生 SVG 画神经元结构（两个输入圆 → 两条 `.wire` → 求和节点 z → 压缩节点 a，线宽按 |w| 编码、颜色按正负编码），右侧 `.pane-r` 用 `.panel.q` 卡片配 KaTeX 呈现 z 与 a 的公式并原样填入数值。全页无状态切换、无 `setOption`；若教师需要逐步"拆开讲"，可用 CSS class 手动切换 `.step.revealed` 配合讲解节奏，不做计时自动播放。

## 不许碰

本页只讲单个神经元的前向计算，不出现误差/损失/准确率概念（留给 p07 起的误差主线）；不出现两个神经元相连或多层结构（留给 p13 起的反向传播章）。

## 神经元结构与数值示例

| 量 | 记号 | 数值 |
|---|---|---|
| 输入 1 | x₁ | 0.8 |
| 输入 2 | x₂ | 0.3 |
| 权重 1 | w₁ | 0.5 |
| 权重 2 | w₂ | −0.2 |
| 偏置 | b | 0.1 |
| 加权和 | z = w₁x₁ + w₂x₂ + b | 0.44 |
| 压缩输出 | a = sigmoid(z) | ≈ 0.608 |

计算入口：`Lec.P.neuronForward([0.8, 0.3], [0.5, -0.2], 0.1, Lec.K.ACT.SIGMOID)` → `{z: 0.44, a: 0.608}`。w₂ 为负（红色语义辅助于蓝色连线），代表"反对"该输入；w₁ 为正、更粗，代表"更在乎"x₁。

## 核对

- 参数 `x=[0.8,0.3], w=[0.5,-0.2], b=0.1` → 期望 `z=0.44`，`a≈0.6083`。
- 参数 `x=[0,0], w=[0.5,-0.2], b=0`（z=0 的临界情况）→ 期望 `a=0.5`，用于确认 sigmoid 中点画法正确。
