# page-04 · 权重旋钮：拨一拨，看它多在乎 · **110 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `WEIGHT KNOBS` |
| 主标题 | 拨动权重，看神经元「多在乎」哪个输入 |
| 收束句 | 权重越偏离 0（无论正负），这个输入对结果的影响越大；权重贴近 0，这个输入几乎被忽略——权重就是"在乎程度" |
| 下一问 | 这些数字最终是怎样被压成一条 0–1 的曲线的？ |

## 知识结构：classification

三个输入节点、三条连线、三个权重滑块与最终输出读数必须同排水平对齐、共享同一条中线，任何一条连线的颜色（红=负权重/蓝=正权重）与粗细（∝ |w|）都必须与其对应滑块的当前刻度实时一致，不能有一处滞后。禁止把三路输入拆成纵向错落、互不对齐的独立卡片——那会掩盖"三个权重此刻同时共同决定一个输出"这一整体关系，读者必须能一眼扫过三条连线看到粗细对比。共享原语：`.neuron`/`.wire` 承担节点与连线母题；`.k-classification` 的 `.lv`+`.box`+`.bt` 承担"当前权重值 → 反对 / 不在乎 / 支持"三分支归类，`.legend` 标注红/蓝/灰三色语义。

## 表征形式

交互 + 静态 SVG，原生 DOM 足够，不引入图表库：一个 `<svg>` 画三个输入圆（`.neuron`）+ 三条 `.wire` + 一个输出圆，右侧/下方三个 `input[type=range]` 直接绑定权重。滑块 `input` 事件触发重算：调用 `Lec.P.neuronForward(x, w, b, Lec.K.ACT.SIGMOID)` 得到 `a`，写入 `.big.lg .num`；同时按当前 `w_i` 更新对应 `.wire` 的 `stroke`（`--blue`/`--red`/`--rule`）与 `stroke-width`；`.bt` 分支标签据阈值切换文字与所属 `.box`。不使用 canvas 动画库，状态切换全部通过属性/class 直写完成。

## 三路输入与默认权重

| 输入 | 含义 | 固定值 x | 默认权重 w | 权重范围 |
|---|---|---|---|---|
| x₁ | 动作场面 | 0.9 | 0.6 | −1.0 ~ 1.0，步长 0.1 |
| x₂ | 剧情复杂度 | 0.4 | −0.4 | −1.0 ~ 1.0，步长 0.1 |
| x₃ | 演员知名度 | 0.7 | 0.1 | −1.0 ~ 1.0，步长 0.1 |
| b | 偏置 | — | 0（固定，不可调） | — |

分类阈值（设计值，非 `Lec.K`）：`|w| < 0.2` → "不太在乎"（灰化 `--rule`）；`w ≥ 0.2` → "支持"（蓝，粗细 = 1 + |w|×5 px）；`w ≤ −0.2` → "反对"（红，粗细同公式）。

输出读数：`a = Lec.P.neuronForward([x₁,x₂,x₃], [w₁,w₂,w₃], 0, 'sigmoid').a`，用 `.big.lg` 等宽字体显示两位小数，右上角文字标注"当前是否推荐：a > 0.5 → 支持"。

## 交互

三个滑块各控制一个权重，范围 −1.0 到 1.0，步长 0.1，默认见上表（0.6 / −0.4 / 0.1）。拖动任一滑块：对应 `.wire` 立即变色变粗/变细，`.bt` 分支标签在"反对/不太在乎/支持"间跳转，输出圆内的 `a` 值实时刷新。目标直觉：把某个权重推到接近 ±1 时，那条输入几乎单独决定输出；推到 0 附近时，那条输入即使 x 值很大也几乎不影响 a。提供一个"复位"按钮恢复默认三个权重；无需目标态判定，纯观察仪器。

## 核对

- w=[0.6,−0.4,0.1], b=0, x=[0.9,0.4,0.7] → z=0.45 → a≈0.611
- w=[1,1,1], b=0 → z=2.0 → a≈0.881（三路全力支持）
- w=[−1,−1,−1], b=0 → z=−2.0 → a≈0.119（三路全力反对）
- w=[0,0,0], b=0 → z=0 → a=0.5（完全不在乎，输出回到中性）
