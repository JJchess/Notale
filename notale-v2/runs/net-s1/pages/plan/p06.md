# page-06 · 神经元流水线：输入到输出的三步 · **80 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `NEURON · PIPELINE` |
| 主标题 | 一次预测，只有三步：加权、求和、压缩 |
| 收束句 | 从输入到输出，每一步都是可以手算的数字，没有任何一步是黑箱 |
| 下一问 | 这一步算出的输出对不对？错了多少，又该怎么算？ |

## 知识结构：process

1. **关系不变量**：三栏必须按"输入×权重→加权和 z→压缩输出 a"的先后顺序左中右排列，且贯穿三栏的同一组示例数值（x、w、b）必须原样延续到 z 再延续到 a，不能中途换一套数字。
2. **禁止画法**：不得把三栏做成互不关联的独立卡片（各自配数字却看不出谁流向谁）；必须有一条连续可见的路径把三栏钉在同一条计算链上。
3. **共享原语**：整体套 `.k-process`，`.step` 对应三栏各自的计算阶段，`.axis` 作为贯穿三栏顶部或底部的一条水平主线，`.arw` 在栏间衔接处指示"数值从这里传到那里"；节点用 `.neuron` 画出输入圆与输出圆，`.wire` 画出 x→z 的加权连线，粗细按 |w| 编码、颜色按正负编码（沿用全局蓝/红语义）。

## 表征形式

静态 DOM/SVG 图示，无需图表库。三栏用主题 `.triptych`（`.col` × 3，栏间 1px `--rule` 竖线）。每栏内：左栏用两个 `.neuron` 圆（输入 x₁、x₂）各引出一条 `.wire` 到中栏；中栏放一个方形 `.panel.q` 展示 z 的求和算式（等宽字体，`--font-mono`）；右栏放一个 `.neuron`（输出圆，填充深浅按 a 值编码）配一张 `.panel` 公式卡写 `a = σ(z)`。全页顶部贯穿一条细 `.axis` 线，三个 `.arw` 箭头分别落在"输入→z"和"z→a"的栏间衔接处，强化方向感。所有数值直接写入表中的常量，不做实时计算，因此无需 `setOption` 或 timeline，仅静态渲染一次。

## 不许碰

不展开 sigmoid 曲线形状或其数学证明（唯一图形展示在 p05，本页只引用结论 σ(z)∈(0,1)）；不涉及多个神经元如何连接成层（p13 起）；不提误差或损失（p07 起才引入）。

## 三步数值

| 阶段 | 内容 | 数值 |
|---|---|---|
| 输入与权重 | x₁, w₁ | 1.0, 0.5 |
| 输入与权重 | x₂, w₂ | 0.6, −0.8 |
| 偏置 | b | 0.2 |
| 加权求和 | z = x₁w₁ + x₂w₂ + b | 1.0×0.5 + 0.6×(−0.8) + 0.2 = **0.22** |
| 压缩输出 | a = σ(z) | **≈0.555** |

计算入口：`Lec.P.neuronForward([1.0, 0.6], [0.5, -0.8], 0.2, Lec.K.ACT.SIGMOID)` → `{ z, a }`。

## 核对

- 输入 `x=[1.0, 0.6]`, `w=[0.5, -0.8]`, `b=0.2` → 期望 `z=0.22`，`a≈0.5548`。
- 若将 `b` 改为 0（无偏置）→ 期望 `z=0.02`，`a≈0.5050`（验证偏置对输出的平移作用，仅用于实现自检，不必印在页面上）。
