# page-16 · 三步合成一次迭代 · **120 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `ONE-ITERATION` |
| 主标题 | 前向算错、反向算责、下坡改权——一次迭代三步走 |
| 收束句 | 一次完整迭代＝前向传播出误差＋反向传播出斜率＋梯度下降更新权重，这三步循环就是网络学习时真正做的事 |
| 下一问 | 把这三步重复成千上万次，网络会变成什么样？ |

## 知识结构：process

1. **关系不变量**：三栏是同一个神经元、同一轮迭代的三个连续动作，必须共享同一组符号——第 1 栏产出的 `w,b,z,a,loss` 是第 2 栏的输入，第 2 栏产出的 `dz,dw,db` 是第 3 栏更新公式里唯一的输入，第 3 栏产出的新 `w,b` 要与第 1 栏的旧 `w,b` 同格式对照，暗示"下一轮从这里重新出发"。
2. **禁止画法**：不得把三栏做成互不引用的独立说明卡（如各自重复解释"什么是前向/反向/梯度下降"而不显示数值在栏间流动）；必须能让读者一眼看到数字从左栏流到右栏。
3. **共享原语**：整体套 `.k-process`，`.step` 对应三栏，栏间用贯穿的 `.axis` 箭头（→ 前向 → 反向 → 更新 →）代替竖分隔线的孤立感；第 1 栏内部用 `.neuron`/`.wire` 画出加权求和的小图；三栏的数值读数统一用 `.big`。

## 表征形式

静态 DOM/SVG 页面，无需图表库：三栏皆为固定数值展示，不随时间变化。用 `.triptych` 的 `.col` 承载三步，列间加一条贯穿三栏顶部的箭头轴（原生 SVG `<path>` + 箭头 marker）表示"一次迭代"的方向；数字统一 `--font-mono`，`.big.sm` 规格。无状态切换、无 `setOption`。

## 三步合一（同一神经元，同一轮）

| 阶段 | 符号 | 值 |
|---|---|---|
| 输入/参数 | x₁, x₂ | 1, 0.5 |
| 输入/参数 | w₁, w₂, b | 0.6, −0.3, 0.1 |
| 前向 | z = w·x+b | 0.55 |
| 前向 | a = sigmoid(z) | 0.634 |
| 前向 | loss = bce(1, a) | 0.456 |
| 反向 | dz = a − y | −0.366 |
| 反向 | dw₁, dw₂ | −0.366, −0.183 |
| 反向 | db | −0.366 |
| 更新 | 学习率 lr | 0.1（`DEFAULT_LR`） |
| 更新 | w₁_new, w₂_new | 0.637, −0.282 |
| 更新 | b_new | 0.137 |

来源：`Lec.P.neuronForward(x,w,b,'sigmoid')` → `Lec.P.neuronBackward(...,'bce')` → `Lec.P.sgdUpdateVector`，页面只写计算结果数字。

## 核对

x=[1,0.5], w=[0.6,-0.3], b=0.1, y=1：`neuronForward` 应得 z≈0.55, a≈0.634；`neuronBackward` 应得 dz≈-0.366, dw≈[-0.366,-0.183], db≈-0.366；以 lr=0.1 做 `sgdUpdateVector` 应得 w_new≈[0.637,-0.282], b_new≈0.137。三组数字必须与表格一致，否则符号方向（dz=a−y 而非 y−a）有误。

## 不许碰

不展示多轮迭代后 loss 如何随时间下降（归属 p17 起）；不展示批量样本或多神经元网络的更新（归属 p18）；本页仅一个神经元、一次迭代。
