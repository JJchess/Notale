# page-17 · 循环起来就是训练 · **35 秒**

## 知识结构：generalization

关系不变量：`.claim`（"循环三步 = 训练"）必须在视觉上统领下方的 `.trunk`，`.trunk` 内前向→反向→更新三个环节必须保持同一顺序、同一权重的循环闭合形态（首尾相接，不能画成三段孤立并列）；`.supports` 下的重复次数、误差下降、决策边界成形三条只作轻量陪衬，字重与字号必须明显低于 `.claim`。禁止画法：不得把三步画成一次性的直线流程（那是 p16 已经画过的），本页必须让它闭环，暗示"重复"而非"完成"。共享原语：用 `.k-generalization` 承载整体主张层级，`.claim` 承接主标题式的强论断，`.trunk` 用三个小圆点（复用 `.neuron` 母题，降饱和不出现具体数字）以短弧线首尾相连表示循环，`.supports > .support` 用 `.small` 字级列出三条陪衬信息；整体落入 `.focus` 的 `.fig`（循环图）+ `.cap`（收束句与下一问）双区结构。

## 表征形式

静态构图为主，仅循环箭头做一次入场动效，无持续交互。用原生 SVG 画三个 `.neuron` 圆点（复用既有蓝色圆形母题，不新增视觉词汇）沿一个正三角布局，之间用带箭头意味的弧线（不用箭头符号，用渐粗的 `.wire` 线代替方向暗示，起点降饱和终点橙色）依次连接并闭合成环。三段弧线依次标注"前向""反向""更新"三个 `.tag` 短标签，字号 `--fs-label`。不引入图表库，纯 DOM+SVG 足够；状态无需 `setOption` 或时间线管理，仅一次性 CSS class 触发入场。

## 动效

页面进入时，三段弧线按"前向→反向→更新"顺序依次描边显现，每段 250ms，错开 150ms，总入场时长约 750ms，模拟"循环启动"的感觉；循环闭合后最后一段弧线末端的橙色小箭头轻微脉动一次（透明度 0.6↔1，300ms）提示"回到起点，继续下一圈"，之后静止，不循环播放。

## 不许碰

不展开具体训练过程中 loss 如何下降或决策边界如何变化（p18）；不比较不同学习率下循环的收敛差异（p19）；不涉及训练后泛化到新样本的准确性问题（p20）。
