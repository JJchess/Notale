## 知识结构：generalization

关系不变量：五个证据节点（E1 神经元透明→E2 误差是曲面→E3 沿斜率走→E4 责任逐层回传→E5 循环成训练）必须以单一时间顺序串成一条主干，首尾相连、不可打乱，因为本页的主张正是"它们其实是同一件事的不同侧面"而非五件独立的事。禁止画法：不得把五个节点拆成五张并列同权的卡片——那会暗示它们是平级的知识点集合，而应有一条从上到下的主干把它们串起来，弱化节点自身、强化串联关系。共享原语：用 `.k-generalization` 的 `.claim`（主标题，最重）压在顶部，`.trunk` 是一条竖向或斜向的主干线，`.supports` 下挂五个 `.support`（轻量文字，不用图形复现各页视觉，只留一句话+页码角标），整体嵌入 `.focus` 的 `.fig` 区，`.cap` 承载收束句与下一问。

## 表征形式

静态 DOM 呈现，无动画触发机制、无外部图表库依赖。`.fig` 内是一条纵向 `.trunk`（1px 实线，`--blue`），`.supports` 五项沿主干等距挂靠，末端节点（E5）用 `--orange` 强调收尾；`.claim` 置于 `.fig` 上方或内嵌顶部，字号沿用 `--fs-h1`，五个 `.support` 用 `--fs-sec`。状态无变化，仅靠 CSS class 静态着色，不涉及 `setOption` 或时间轴。
