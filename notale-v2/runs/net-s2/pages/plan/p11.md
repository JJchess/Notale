## 知识结构：generalization

关系不变量：`.claim`（下坡道理不变）必须与 `.trunk`（p06–p08 已建立的单参数下坡线索）同框出现，`.supports`（权重数量从1跃升到上百）要与 `.trunk` 共享同一视觉基线，用量级对比直接呈现"1个参数"和"上百个参数"的落差，不能把两段证据拆成互不相关的两块画面。禁止画法：不能把"上百个权重"画成杂乱无归属的散点堆砌——必须让这些权重仍清楚从属于p10已建立的层结构，不能靠视觉混乱来暗示"复杂"，那会掩盖真正的悬念（责任未分配，不是数量本身）。共享原语：复用 p10–p12 的卡片叠层母题承载网络结构，落入 `.k-generalization`：`.claim` 放主张句，`.trunk` 承接p06–p08的等高线／徒步者母题（下坡道理延续），`.supports` 用一个 `.big` 数值读数呈现权重规模，作为本页唯一强支撑点。

## 表征形式

静态构图为主，进入时allow一次轻量数字动效（参数量由"1"过渡到"81/上百"，强化跃升感）。用原生 DOM + SVG 搭建卡片叠层与 `.big` 数值组件即可，无需图表库；如需动效，用 CSS class 切换驱动一次性过渡，不循环、不常驻。版式为 `focus`：居中单焦点，四周留白，卡片叠层与数值组件垂直居中排列。
