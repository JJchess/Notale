## 1. 这堂课在讲什么

本课讲清：神经网络的“学习”是可复查的重复实验——输入变成预测，预测与答案比较得到损失，损失把责任分给参数，参数朝使总损失变小的方向更新。

| 幕 | 页 | 本幕任务 | 必须留下的证据 |
|---|---:|---|---|
| I 看见一个神经元 | 01–07 | 看懂加权、偏置与输出概率 | 改变权重会转动边界；改变偏置会平移边界 |
| II 看见学习动作 | 08–12 | 看懂预测、损失、更新方向 | 同一批样本上，更新前后总损失可比较且下降 |
| III 看见多层网络 | 13–17 | 看懂多层协作与反向传播 | 责任信号由后往前分配；多层可形成复杂边界 |
| IV 判断它是否真的学会 | 18–20 | 区分训练表现与泛化 | 未训练数据上的表现才支持“学到规律” |

证据链必须保持：`输入 → 预测 → 与答案比较 → 损失 → 参数责任 → 更新 → 新预测/新损失 → 未见数据检查`。

每页只实现自己的 `pNN.md`。本页规格标明“不许碰”的概念、例子、结论、交互或转场，由对应页面负责；不得提前重复、剧透或替别页收束。

## 2. 颜色语义

| token / 色相 | 唯一含义 | 允许出现的位置 |
|---|---|---|
| `--param` / 蓝色 `#246B8F` | 可调整参数 | 权重、偏置、学习率、参数滑块、参数记录条、可修改数值 |
| `--focus` / 橙色 `#E56B3F` | 当前注意点 | 当前更新的参数、当前误差箭头、教师正在讲的数值、当前操作步骤 |
| `--paper` / 浅色 `#F6F1E7` | 实验记录纸底 | 页面底色与大面积留白底 |
| 中性色 | 非概念性结构 | 正文、坐标轴、网格、普通连线、边框、未激活节点、容器与装饰线 |

蓝色不得用于普通按钮、标题装饰或任意“好的一方”；橙色不得表示正确、警告、类别或奖励。分类点不能只靠蓝橙区分类别，必须同时用位置、形状、描边或文字图例建立可读区分。无概念含义的元素使用中性色。

## 3. 知识结构——骨架约定

容器不是知识关系，不以“卡片网格”或“左右两栏”代替结构。固定左侧实验对象区、右侧观察记录区只是一种阅读分工；因果、比较、层级和证据必须由画面关系直接成立。

| 结构 | 必须直接看见的关系 | 最低几何要求 | 失败形态 |
|---|---|---|---|
| process | 先后、因果或状态推进 | 可见方向轴、箭头或连续路径 | 只有并排块 |
| comparison | 同一维度上的差异 | 同行、同尺度、同基线 | 两边各画各的 |
| classification | 上下位或部分—整体 | 嵌套、包含或明确缩进 | 同级平铺 |
| generalization | 主张与支撑 | 主张更重，支撑挂在同一主干 | 主张和证据同权 |

优先使用 `theme.css` 提供的 `.k-process`、`.k-comparison`、`.k-classification`、`.k-generalization` 原语。SVG、Canvas、ECharts 或其他图表可替代这些原语；硬要求不是类名，而是关系必须在画面上成立并可被检查。

神经元一律使用同直径圆形节点、圆心对齐。前向信息使用实线箭头，反向责任使用虚线箭头；连线粗细表示连接强弱，不依赖颜色区分。参数卡片为直角矩形，预测与答案为圆角标签；当前计算步骤用单层 3px 外描边，不堆阴影。

## 4. 交互的规矩

- 同一个关系只使用一种主要交互路径，不用多个控件重复同一结论。
- 教学常量、范围、初值和结果来自 `Lec.K` / `Lec.P` 并当场计算；禁止预录结果、硬编码演示曲线和假数据。
- 使用 `Lec.P` 时保留其公开接口的参数、返回字段与异常约定；不得猜测或改写其实现。
- 随机过程必须固定种子；首屏静止状态已包含可讲信息，不把关键信息藏在自动播放后。
- 交互页必须给出明确操作提示。滑块、切换和游标是观察仪器，没有目标态时不得编造对错。
- 只有分拣、配对、拼装等本来有答案的任务才判定正确性；参数探索只呈现结果、差异与可解释限制。
- 未规划交互的页面不要添加装饰性操作、无意义悬停或自动动画。
- 训练过程必须可暂停、重置或重现；显示的损失、准确率、边界和参数必须来自同一当前状态。

## 5. 技术契约

    <!doctype html>
    <html lang="zh">
    <head>
      <meta charset="utf-8">
      <link rel="stylesheet" href="assets/base.css">
      <link rel="stylesheet" href="assets/theme.css">
    </head>
    <body data-page="NN" data-total="20">
      <div id="stage"></div>
      <script src="assets/base.js"></script>
      <script src="assets/lec.js"></script>
    </body>
    </html>

- 只修改 `#stage` 内容；`NN` 替换为本页两位页码。保留两位 `data-page` 和 `data-total="20"`，不把页码显示给读者。
- 逻辑画布固定 1600 × 900，不得滚动。`#stage` 是 flex 列；顶层区块给固定高度或 flex 份额，主内容区使用 `flex:1`。
- 字号只用主题 token。正文与成句说明 ≥16px；控件标签、图例、图注和提示 ≥14px；纯数字刻度 ≥12px；多行文字行高 ≥1.35。
- 颜色、字体、圆角、阴影和共享组件取自主题接口。一次性尺寸可写内联，不为单页尺寸造公共类。
- 不移除或覆盖 `.min0`、`.cv-fill`、`.no-pan` 的机制；缩放画布内禁止 `position:fixed`。
- 默认用 flex；只有真正二维对齐时用 grid。自包含运行，只引用 `pages/` 内相对路径，不用 CDN。
- 图表优先使用已安装库，不重复实现成熟能力。ECharts 必须使用 `renderer:'svg'`，并显式设置全局文字 ≥16px、带词句的轴/图例 ≥14px、纯数字刻度 ≥12px。
- Canvas 使用 `Deck.fit()` / `Deck.autofit()`，指针坐标使用 `Deck.pt()`，动画使用 `Deck.loop()`。Konva 场景文字优先用 DOM 叠加，不用默认小字号 `Konva.Text`。
- KaTeX 同时引入本地 CSS 与 JS；含分式、上下标的公式基准字号 ≥20px。
- 小型实时二分类训练使用 `MLP`；不为两三层小网络使用 `tf`。随机样本使用带固定种子的 `seedrandom`。若使用 `tf`，每步必须 `tf.tidy()` 或释放张量。

| 用途 | 库 |
|---|---|
| 常规坐标图、散点、折线、柱图 | `echarts.min.js` |
| 可拖拽、命中检测二维场景 | `konva.min.js` |
| 节点连线、精确 SVG 图形 | `d3.min.js` |
| 分步与时间线动画 | `anime.min.js` / `gsap.min.js` |
| 数学公式 | `katex.min.js` |
| 可复现随机 | `seedrandom.min.js` |
| 小网络实时训练、决策边界 | `mlp.js` |
| 矩阵计算 | `ml-matrix.umd.js` |
| 真实图片模型、卷积或 GPU 大矩阵 | `tf.min.js` |

## 6. 图片

优先使用 `assets/img/IMG.md` 已登记的素材，不重复下载或生成。按索引填写 `<img title="…">`；`title` 说明画面内容或其教学用途，不写空泛赞语。出处和许可不进入主画面。

## 7. 文字风格

面向未学微积分、线性代数或编程的大学通识课学生。先说可观察动作，再给术语；首次出现术语紧跟普通说法，例如“损失：预测和答案之间的一份总差距”。

使用讲课短句。一个句子优先只承担一个因果关系。数值写清单位、范围或可感换算；概率明确是 0 到 1 的输出，不把它说成保证发生。结论有条件时明确条件，不确定时标注“不足以说明”“可能”或“需要再测”。

提示使用可执行口吻：`拖动 w，观察边界转动。`、`把学习率调大，再看损失是否仍稳定下降。` 不使用“如图所示”“接下来我们将”，不评价教学设计，不说“这一页告诉我们”。

收束句只给应带走的主张；下一问负责推进。不要把收束写成本页内容摘要。

## 8. 自检

完成后用 `Check` 检查本页：JS 错误、资源失败、越界、裁切均为 0，字号符合分层地板。公式、图例、提示、控件标签和动态更新文本都在检查范围内。

交互页必须覆盖每个主要状态：初始状态、每个可达参数极值、切换状态、训练中、训练后、重置后，以及异常或未收敛但数值未崩溃的状态。问题区域先用 `Look` 查看，再用 `Patch` 合并修复。

最终只交付本页 HTML，不改公共资源，不增加测试、报告或临时文件。

## 9. 版面密度与常见坑

- 主内容用 flex 吃满剩余空间，不给普通内容块写死高度。
- 画面占用低于 45% 时检查失控的 flex 空隙并放大有教学意义的关系；不要加装饰撑满。
- 画面占用高于 85% 时删减或报告需要拆页，不缩字号、不压缩行高。
- 骨架和包裹层优先用线、缩进、箭头、对齐和层级表达，不堆叠多层填色卡片。
- 左侧实验对象区承载操作对象、坐标图、网络或计算过程；右侧观察记录区承载当前读数、比较和结论。两区之间保留足够留白，不让记录区伪装成第二个实验。
- 每页右下角保留小型“实验步数”标记，使用主题既有样式，不抢当前注意点。
- 照片使用主题已有的边框、圆角和底图规则；Canvas 交互区加 `.no-pan`。
- 不用霓虹深底、赛博渐变、大脑解剖插画、游戏积分、角色、奖励或闯关语言。
