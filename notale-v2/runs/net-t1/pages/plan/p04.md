# page-04 · 一条线的能力边界 · **80 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `EXPERIMENT 01 · CLASSIFY` |
| 主标题 | 面对两项位置读数，它先只能画一条线 |
| 收束句 | 单个神经元的“是／否”判断，在平面上只能形成直线分界。 |
| 下一问 | 如果想让这条线转个方向，该动哪个旋钮？ |

## 知识结构：classification

1. **关系不变量**：左侧三种候选分界必须覆盖同一组位置点、同一组横纵坐标与同一坐标尺度；右侧记录只对应当前被投票的那条线。
2. **禁止画法**：不得把三条候选线拆成三个不同坐标范围的小图，造成“谁分得开”无法直接比较。
3. **共享原语**：`.split-lr` 左侧承载坐标纸与候选线，右侧承载投票和观察记录；`.k-classification` 用“位置点 → 线的两侧 → 是／否”显示归属，`.quiz` 显示当前选择及反馈。

## 表征形式

交互式二维分类图：左侧为原生 SVG 坐标纸，蓝色实心点表示“是作业区”，橙色空心点表示“否”；一次只叠加一条候选直线。右侧为三个 `.opt` 投票按钮和 `.fb` 观察记录。

- 原生 DOM/SVG 更合适：只有固定坐标、少量点与直线，无需图表库。
- 坐标轴固定为 `-1.00` 至 `1.00`，横轴为“横向位置”，纵轴为“纵向位置”；刻度使用 `--fs-tick`，点旁标签使用 `--fs-label`。
- 点击按钮或按 `A`、`B`、`C` 后更新 `selectedCandidate`，重新 `draw` 直线、错分点橙色描边与反馈文字；`重投` 清空选择。

## 主工作流

design-interaction ← 让同一批点上的投票、候选直线与错分反馈即时对应

## 不许碰

不要解释权重取什么数值、权重为何让边界旋转；这些归 p05。此页只判断单个神经元能否用一条直线完成分类。

## 位置点与候选线

| 画面对象 | 内容 |
|---|---|
| 坐标范围 | 横向位置、纵向位置均为 `-1.00` 至 `1.00` |
| 是作业区 | `(0.70, 0.40)`、`(0.30, 0.60)`、`(0.80, -0.10)`、`(-0.10, 0.50)` |
| 否作业区 | `(-0.70, -0.40)`、`(-0.30, -0.60)`、`(-0.80, 0.10)`、`(0.10, -0.50)` |
| A 斜线 | 从 `(-1.00, 1.00)` 连到 `(1.00, -1.00)` |
| B 竖线 | 穿过横向位置 `0.00` |
| C 横线 | 穿过纵向位置 `0.00` |
| 未投票提示 | `选一条线：它能把两类位置完全分开吗？` |
| A 反馈 | `A：8 个点分居线的两侧，没有错分。` |
| B 反馈 | `B：有 2 个点落在错误一侧。` |
| C 反馈 | `C：有 2 个点落在错误一侧。` |

## 交互

学习者选择 A、B 或 C 作为“神经元画出的分界”。默认未选择，只显示八个位置点；选择后左图立即出现该直线，错分点加橙色外描边，右侧显示对应观察记录。A 为完成分类的选择；选 B、C 时反馈只指出“仍有错分”，不解释参数原因。按钮支持点击、键盘 `A/B/C` 与焦点确认；`重投` 回到未选择状态。
