# page-05 · 权重让线转向 · **90 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `EXPERIMENT 01 · WEIGHT` |
| 主标题 | 把哪个位置读数看得更重，分界线就朝哪边转 |
| 收束句 | 改变权重会让分界线旋转：权重更大的输入，对判断方向影响更大。 |
| 下一问 | 如果不想转线，只想把整条线推近一群点，该调什么？ |

## 知识结构：process

1. **关系不变量**：三张连续阶段卡片共用同一组横、纵坐标和 `-1.00` 至 `1.00` 的尺度；参数卡中的 `wₓ、wᵧ` 必须通过连线对应到同一张分界图。
2. **禁止画法**：不得把不同权重下的边界画在互不对齐、坐标尺度不同的小图中，造成“线变长”而非“线旋转”的误读。
3. **共享原语**：`.stage-cards` 承载“调旋钮→读组合规则→看边界”的连续动作；`.k-process` 用同向箭头把参数变化连接到边界旋转；`.panel` 固定放置可调权重与即时读数。

## 表征形式

交互式二维坐标纸：左卡显示两个权重旋钮，中卡显示当前分界规则，右卡显示蓝橙位置点与随权重旋转的直线。

- 原生 DOM + SVG 更合适：坐标轴、直线、点位和参数连线数量少，需精确响应滑块与键盘输入。
- SVG 使用固定 `-1.00` 至 `1.00` 双轴尺度；分界线 3px 外描边；点位不随权重缩放。
- 滑块 `input` 事件更新状态 `{wx, wy}`，调用 `drawBoundary()` 重绘规则卡和边界图；按“复位”恢复默认值。

## 主工作流

design-interaction ← 让拖动两个权重时的边界旋转、数值读数与规则表达保持同步且可读

## 不许碰

本页只说明权重改变边界的倾斜方向，不解释把边界整体推近或推远的机制；整体平移归 p06。不得在此页计算输出概率或进入前向传播试算，归 p07。

## 权重旋转实验

| 卡片 | 画面文字或值 | 用途 |
|---|---|---|
| ① 调权重 | `wₓ = 1.00`、`wᵧ = 1.00` | 两个蓝色滑块，分别代表横坐标与纵坐标被看重的程度 |
| ② 写规则 | `wₓ × x + wᵧ × y = 0` | 当前分界线上的位置都满足这条规则 |
| ③ 看边界 | `x`、`y`；坐标范围 `-1.00 … 1.00` | 同尺度坐标纸；边界两侧标记“更偏向是 / 更偏向否” |
| 当前提示 | `现在：横坐标和纵坐标同样重要` | 默认状态的橙色观察句 |
| 操作提示 | `拖动一个权重，看线围绕原点转向` | 放在滑块下方 |
| 复位按钮 | `复位 1.00 / 1.00` | 恢复起始观察状态 |

## 交互

学习者拖动 `wₓ` 或 `wᵧ`，范围均为 `-2.00` 至 `2.00`，步长 `0.10`，默认均为 `1.00`；禁止两个值同时为 `0.00`。

每次变化立即更新权重读数、规则中的系数、边界直线角度和橙色观察句。`wₓ` 相对更大时，边界更接近竖直；`wᵧ` 相对更大时，边界更接近水平。没有“正确位置”，重点是观察哪一个输入被加重后线如何转向。滑块支持键盘方向键，复位按钮恢复默认状态。

## 动效

滑块输入后，分界线以原点为轴旋转至新角度，时长 `180ms`；规则中刚变化的系数短暂切换为橙色 `600ms`。减少动态效果时直接跳至新位置。

## 核对

| 输入 `wₓ, wᵧ` | 应显示的分界线 |
|---|---|
| `1.00, 1.00` | `y = -x`，左上至右下 |
| `1.00, 0.00` | `x = 0`，竖直线 |
| `1.00, -1.00` | `y = x`，左下至右上 |
