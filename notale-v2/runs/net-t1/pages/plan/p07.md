# page-07 · 前向试算 · **115 秒**

## 照这个写

| 元素 | 文字 |

| 主标题 | 先合成一个分数，再读成概率 |
| 收束句 | 前向传播不改任何旋钮：它只把当前位置代入现有参数，得到一次预测。 |
| 下一问 | 有了预测和答案，怎样量出这次到底猜错多少？ |

## 知识结构：process

1. **关系不变量**：两个输入、各自权重和乘积必须上下同行；两个乘积与偏置汇入同一个分数，再唯一地流向概率读数。
2. **禁止画法**：禁止把“加权相乘”“相加”“变成概率”拆成互不相连的说明卡，否则会误读为三种独立计算。
3. **共享原语**：`.canvas-full` 承载横向单流程；`.k-process` 用实线箭头固定“输入→分数→概率”的因果顺序；`.panel` 包住可调输入与最终读数，`.num` 对齐全部数值。

## 表征形式

交互式前向计算器：原生 DOM + SVG 更合适，SVG 绘制两条同尺度连线、乘法节点、求和节点与 0–1 概率刻度；文字和滑块使用 DOM。概率刻度固定为 `0.00–1.00`，数值采用等宽字体并保留两位小数。输入变更时重新计算 `s=x₁w₁+x₂w₂+b` 与 `p=1/(1+e⁻ˢ)`，再 `draw()` 更新乘积、线条粗细、分数指针和概率填充；不使用动画作为计算证据。

## 主工作流

design-interaction ← 让无编程基础者操纵两个输入，并即时看见同一套权重如何合成预测

## 不许碰

不解释怎样根据误差自动改变权重、偏置或学习率；参数更新和损失下降归 p08。这里不出现答案标签、损失值或“该往哪边调”的提示。

## 一次前向试算

| 流程位置 | 画面文字 | 默认值 | 页面是否显示 |
|---|---|---:|---|
| 输入 1 | `横坐标 x₁` | `0.60` | 是，可调 |
| 权重 1 | `权重 w₁` | `1.20` | 是，不可调 |
| 第一项 | `x₁ × w₁` | `0.72` | 是 |
| 输入 2 | `纵坐标 x₂` | `−0.40` | 是，可调 |
| 权重 2 | `权重 w₂` | `−0.70` | 是，不可调 |
| 第二项 | `x₂ × w₂` | `0.28` | 是 |
| 偏移 | `偏置 b` | `−0.10` | 是，不可调 |
| 合成分数 | `s = 0.72 + 0.28 − 0.10` | `0.90` | 是 |
| 概率转换 | `p = 1 ÷ (1 + e⁻ˢ)` | `0.71` | 是，标作 `71%` |

## 交互

学习者分别拖动 `x₁`、`x₂`，范围均为 `−1.00` 至 `1.00`、步长 `0.05`，默认值取表中数值；同时提供左右键微调和可直接输入数值的文本框。每次变更立即重算两项乘积、合成分数和概率；连线粗细按乘积绝对值变化，负值连线加短斜杠，避免只凭颜色判断正负。权重与偏置始终以参数蓝显示但锁定，提示“本页只观察，不更新”。“还原本次位置”按钮恢复 `0.60`、`−0.40`。

## 核对

| x₁ | x₂ | 期望分数 s | 期望概率 p（显示） |
|---:|---:|---:|---:|
| `0.60` | `−0.40` | `0.90` | `0.71` |
| `0.00` | `0.00` | `−0.10` | `0.48` |
| `1.00` | `1.00` | `0.40` | `0.60` |
