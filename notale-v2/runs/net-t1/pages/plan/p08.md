# page-08 · 调低损失 · **105 秒**

## 照这个写

| 元素 | 文字 |
|---|---|

| 主标题 | 把预测和答案逐个对照，错误会汇成一个可下降的损失 |
| 收束句 | 学习先表现为一件可见的事：调动参数后，整批样本的平均错误下降。 |

## 知识结构：comparison

1. **关系不变量**：上半区四个有答案的样本按同一列结构展示“答案、预测、该例损失”，损失读数同尺度；四行损失向下汇入唯一的平均损失。
2. **禁止画法**：不得把每个样本拆成独立卡片或只显示总损失，否则会掩盖“总错误由逐例错误汇成”。
3. **共享原语**：`.split-tb` 上方放样本对照、下方放参数与总读数；`.k-comparison` 让答案、预测、损失逐行对齐；`.panel` 承担参数旋钮和平均损失记录。

## 表征形式

交互式二维参数—损失记录仪：原生 DOM 负责表格、滑块和可访问读数，SVG 绘制四条由样本损失指向平均损失的汇聚线。预测概率按 sigmoid 输出，损失按二元交叉熵即时重算；数值使用等宽字体并保留两位小数。参数输入触发重新 `draw` SVG、更新表格文字，并切换损失读数的下降/上升状态 class。

## 主工作流

design-interaction ← 让无编程基础学生直接调三个参数，并立即看见逐例错误如何汇成总损失

## 不许碰

不解释“为什么能知道更新方向”、误差地形或斜率；这些归 p09。也不定义学习率或比较步长大小，归 p10。

| 区域 | 画面文字/值 | 用途 |

| 样本 2 | `位置 (0.70, −0.50)`；答案 `1` | 批量样本 |
| 样本 3 | `位置 (−0.60, 0.70)`；答案 `0` | 批量样本 |

| 列标题 | `答案` / `当前预测` / `该例损失` | 上半区固定表头 |
| 汇总读数 | `平均损失 = 四个损失的平均` | 指向总读数的说明 |
| 参数 | `w₁`、`w₂`、`b` | 三个可调旋钮 |
| 初始参数 | `w₁ = 0.00`；`w₂ = 0.00`；`b = 0.00` | 写入画面、可复位 |

## 交互

三个蓝色滑块分别操纵 `w₁`、`w₂`、`b`，范围均为 `−3.00` 至 `3.00`，步进 `0.05`，默认均为 `0.00`；键盘方向键可微调，滑块有对应数值输入框。

每次改变参数，立即更新四行预测概率、四个该例损失、汇聚线末端的平均损失；低于初始 `0.69` 时总读数以橙色描边并显示 `比起点低`，高于起点时显示 `比起点高`。不设置唯一正确参数；学生应观察到同一组参数会同时改变多例预测，而总损失是它们的共同账目。`复位到 0.00` 按钮恢复初始状态。

## 动效

首次进入时，四行样本损失沿竖直方向依次出现，间隔 `120ms`；随后四条细线在 `280ms` 内向下汇入平均损失。调参后仅让变化的数字快速替换，不移动表格；若平均损失下降，汇聚线向下缩短 `10px`、持续 `180ms`。减少动态偏好下直接显示最终静态连线和读数。

## 核对
