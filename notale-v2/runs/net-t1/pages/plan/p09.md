# page-09 · 在误差地形上踏下一步 · **110 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `LOSS LANDSCAPE` |
| 主标题 | 学习，就是在参数地形上往低处走 |
| 收束句 | 每一种参数组合都有一个损失高度；训练是在反复测量后，逐步离开高损失处。 |
| 下一问 | 到了坡脚，究竟怎样判断每个旋钮该往哪边挪？ |

## 知识结构：generalization

1. **关系不变量**：全部脚印、等高线、横轴权重 `w`、纵轴偏置 `b` 必须落在同一张参数平面上；损失读数只对应一个脚印位置。
2. **禁止画法**：不得画成透视 3D 山峰，使参数距离和损失高度混为同一视觉尺度。
3. **共享原语**：`.k-generalization` 承载“参数位置 → 损失高度 → 踏向低处”的主干；`.panel` 固定显示当前测量记录；`.ctl` 承担四方向踏点操作，保证操作与脚印位置一一对应。

## 表征形式

交互式二维等高线参数地形：横轴为权重 `w`，纵轴为偏置 `b`；灰黑等高线表示损失区间，橙色圆点为当前位置，实线脚印记录已走路径，蓝色轴标签标明可调参数。

原生 SVG 更合适：需要清晰的坐标、等高线、脚印和可访问的格点命中区，不需要图表库自动布局。每次踏点后重新 `draw` 等高线上的当前位置、路径和 `.panel` 内的损失读数；用切换 class 显示四个相邻格点的即时读数。轴刻度使用 `--fs-tick`，当前损失使用 `.big.num`。

## 主工作流

design-interaction ← 让学生在不引入求导和学习率的前提下，亲手比较相邻参数位置的损失变化

## 不许碰

不讲微积分、斜率、偏导数或“梯度”求法；本页只建立“参数位置有高低、可以朝低处移动”的地形直觉。参数该往哪边挪、每次挪多远归 p10。

## 交互

学生点击当前位置上下左右相邻的格点，或使用方向键踏出一步；可到达范围限于表中格点。初始位置为 `w=0.80，b=0.60`。

每次操作立即更新橙色脚印、路径、当前位置参数和损失读数；相邻四格短暂显示各自损失，帮助学生看见“低处”不是凭感觉判断。踏到更低损失处时记录旁显示“这一步更低”；踏到更高处时显示“这一步更高，仍可换方向再试”。不设成功终点。

“重走”按钮恢复初始脚印、清空路径与步数；键盘可用 `← ↑ ↓ →`，按钮均带相同文字标签。

## 动效

新脚印沿点击方向平移一个格距，时长 `180ms`；旧脚印保留为细线轨迹。当前损失数字在变低时向下滑入、变高时向上滑入，各 `160ms`；减少动态偏好下直接切换读数和位置。

## 核对

| 操作路径 | 期望当前位置 | 期望损失 |
|---|---|---:|
| 初始状态 | `w=0.80，b=0.60` | 0.92 |
| 左一步 | `w=0.60，b=0.60` | 0.70 |
| 左、下、左 | `w=0.40，b=0.40` | 0.31 |
| 左、下、左、下 | `w=0.40，b=0.20` | 0.12 |
