## 知识结构：process

1. **关系不变量**：左侧以当前权重为共同起点，向左、向右两条等距离试探分支必须同尺度；右侧损失读数与两条分支逐行对齐，最低损失明确指向下一步方向。
2. **禁止画法**：不得把“增大”和“减小”拆成不共享当前参数与损失基线的独立卡片。
3. **共享原语**：`.ledger` 固定左侧试探、右侧记录；`.k-process` 表示“当前值→两侧试探→选择较低损失方向”；`.panel` 容纳参数旋钮和逐项读数。

## 表征形式

交互式参数试探仪：一个权重的左右试探点、两条损失读数与方向结论。原生 DOM + SVG 更合适，分支线、数值和反馈均为少量确定元素；参数数值使用等宽字，左右试探共用同一水平刻度。调节学习率后调用 `Lec.P` 当场生成 `w−η`、`w+η`，以固定 sigmoid 前向计算和二元交叉熵重新绘制读数；点击预测按钮切换反馈 class。

## 主工作流

design-interaction ← 让学生先承诺更新方向，再用同尺度损失读数立即验证

## 不许碰

不解释责任信号怎样穿过隐藏层、怎样由输出层逐层回传；该机制归 p11。不要完成“责任值 × 学习率”的具体权重更新算式，归 p12。

## 试探记录

| 区域 | 画面文字或公式 | 默认显示 |
|---|---|---|
| 固定样本 | `输入 x = 0.75`；`答案 y = 0`；其余条件锁定 | 是 |
| 当前参数 | `当前权重 w = 0.40` | 是 |
| 学习率控件 | `学习率 η：0.10`；`每次试探离当前值多远` | 是 |
| 当前读数 | `当前损失 1.609` | 是 |
| 向右试探 | `增大：w + η = 0.50`；`损失 1.670` | 点击后 |
| 向左试探 | `减小：w − η = 0.30`；`损失 1.550` | 点击后 |
| 结论条 | `增大让错误更严重 → 下一步朝减小的方向走` | 点击后 |
| 计算口径 | `p = sigmoid(0.75w + 1.0863)`；`损失 = −ln(1−p)` | 仅实现核对，不印公式 |

## 交互

学习者先在“下一步该让 w 增大还是减小？”下点击 `增大` 或 `减小`；未作答时两侧损失遮住，只保留当前参数、当前损失和方向箭头。作答后同时揭示左右试探读数：选对显示“这边损失更低”，选错显示“增大后损失从 1.609 升到 1.670，所以改朝相反方向”。

学习者可拖动蓝色学习率滑块，范围 `0.02–0.30`，默认 `0.10`；左右试探点、两项损失和方向结论立即重算。学习率只改变试探离当前值的距离，不改变本例“应减小权重”的方向。`重新试一次`恢复 `w=0.40、η=0.10` 并遮住答案；支持方向键调滑块、Tab/Enter 作答。

## 核对

| η | 右试探 `w+η` 的损失 | 左试探 `w−η` 的损失 | 应指向 |
|---:|---:|---:|---|
| 0.02 | 1.621 | 1.598 | 减小 |
| 0.10 | 1.670 | 1.550 | 减小 |
| 0.30 | 1.793 | 1.434 | 减小 |
