# page-11 · 责任倒着走 · **120 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `STEP 03 · BACKWARD` |
| 主标题 | 先从输出的错误开始，责任才能一路分回每条连接 |
| 收束句 | 反向传播传回的不是答案，而是“这条连接对错误该负责多少”的信号。 |
| 下一问 | 拿到一条连接的责任信号后，权重究竟要挪多少？ |

## 知识结构：classification

1. **关系不变量**：左侧网络的输入层、隐藏层、输出层必须从左到右同基线排列；右侧三张责任卡必须与这三层一一对应，并按输出→隐藏→输入的回传顺序自上而下嵌套。
2. **禁止画法**：不得把反向虚线箭头画成从输入层同时射向所有层的并列箭头，否则会误导为责任可以跳过输出层直接得出。
3. **共享原语**：`.split-lr` 左边承载网络、右边承载排序记录；`.k-classification` 用缩进责任卡表达“后层先收到、前层后收到”；`.panel` 固定区分正向实线与反向虚线的两种信息流。

## 表征形式

交互式关系图：左侧为原生 SVG 网络图，两个输入圆节点连到两个隐藏圆节点，再连到一个输出圆节点；正向连线为实线，责任信号为从右向左逐段出现的虚线箭头。右侧为原生 DOM 可拖拽排序卡。

- 不引入图表库；节点、连线和箭头数量少，SVG 的路径、描边和命中区域更易保持同尺度与可读性。
- 参数与责任信号使用 `--param`；当前被排序或被讲解的回传箭头使用 `--attention`；所有节点保持同一直径。
- 拖拽、点击卡片的“上移／下移”按钮及键盘方向键都调用 `renderBackpropOrder(state.order)` 重绘卡片顺序，并切换 SVG 对应虚线的高亮 class。
- 排序正确后调用 `playBackprop()` 依次显示三段虚线；减少动态偏好时直接显示三段箭头及正确顺序。

## 主工作流

design-interaction ← 让“排序箭头”成为可操作的责任传播顺序，而非只看一张静态网络图

## 不许碰

不计算权重、偏置或学习率的更新数值，不出现“旧权重减去学习率乘责任”的算式；具体单步更新归 p12。不要借此展开多层网络怎样画出弯曲边界，隐藏单元组合能力归 p16。

## 责任信号排序内容

| 区域 | 画面文字 | 关系或状态 |
|---|---|---|
| 左侧图上方 | `前向：位置读数 → 预测` | 两条实线方向为输入层→隐藏层→输出层 |
| 左侧输入层 | `输入层` | 2 个圆节点；只提供位置读数 |
| 左侧中间层 | `隐藏层` | 2 个圆节点；接收后层传来的责任 |
| 左侧输出层 | `输出层` | 1 个圆节点；先比较预测与答案 |
| 左侧虚线图例 | `反向：责任信号 ←` | 虚线只从输出层向输入层移动 |
| 右侧提示 | `把三张卡排成责任信号经过网络的顺序` | 初始顺序固定打乱为：隐藏→输入、输出→隐藏、比较预测与答案 |
| 卡片 A | `比较预测与答案：错误先在输出端被看见` | 正确顺序 1 |
| 卡片 B | `输出层 → 隐藏层：分给靠近输出的连接` | 正确顺序 2 |
| 卡片 C | `隐藏层 → 输入层：再分给更早的连接` | 正确顺序 3 |
| 正确反馈 | `顺序正确：先知道错在哪里，才能往前追问是谁造成的。` | 显示三段连续虚线 |
| 错误反馈 | `这一步太早了：前一层要先等后面传来责任信号。` | 高亮被跳过的后一层 |

## 交互

学习者拖动三张责任卡排序；默认采用固定乱序，卡片可拖到任意位置，也可用聚焦后的上下方向键移动。每次交换立即高亮左图中该卡对应的层间虚线路径，但不播放完整回传。

当顺序为“比较预测与答案 → 输出层到隐藏层 → 隐藏层到输入层”时，显示正确反馈并播放完整虚线回传；其他排列显示错误反馈和被跳过层。点击 `重新排序` 恢复固定乱序与未高亮状态。

## 动效

正确排序后，责任虚线从输出节点向左移动：输出到隐藏段 420ms，停 180ms，再由隐藏到输入段 420ms。每段末端节点出现 3px 外描边；动画结束后保留静态虚线，避免责任信号消失。
