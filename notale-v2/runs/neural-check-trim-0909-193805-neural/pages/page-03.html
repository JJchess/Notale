03 · 单个神经元几何机理

二维超平面分割：权重决定倾角，偏置控制平移

判别方程：w₁x₁ + w₂x₂ + b = 0
法向量 n = (w₁, w₂)，截距 d = -b / ||w||
1.20 · x₁ + 0.80 · x₂ + (-0.50) = 0
神经元在激活前的净输入为 z = wᵀx + b。令 z = 0 对应的直线即为决策边界：线上为阈值临界点，一侧 z > 0 输出激活，另一侧 z < 0 抑制。
权重 w₁ (控制 x₁ 贡献与法向 X 分量) 1.20
权重 w₂ (控制 x₂ 贡献与法向 Y 分量) 0.80
偏置 b (平移直线，脱离原点约束) -0.50
典型构型:
分类准确率 (Acc) 95.0%
原点距离 d = |b|/||w|| 0.35
法向量倾角 θ 33.7°
误分类样本数 1 / 20
几何核心洞察： 权重向量 w = [w₁, w₂]ᵀ 是分离直线的正法向量，箭头指向激活区 (z > 0)；改变 w 的比例改变直线的旋转斜率；偏置 b 决定直线距原点的垂直位移。没有偏置，超平面将被迫锁定在原点 (0,0)。

类别 A (目标标签 y = 1)
类别 B (目标标签 y = 0)
超平面决策界 (z=0)
法向量 w 梯度指向
指针探测：x₁ = 0.00, x₂ = 0.00 | z = -0.50 | 预测激活: 0 (抑制)
标尺范围：x₁, x₂ ∈ [-4.0, +4.0] · 阴影明暗度表征神经元净输入强度值 z = w₁x₁ + w₂x₂ + b 移动滑块观察半平面翻转、旋转与平移；在右图内滑动查看任意坐标的前向计算值
同学们，上一讲我们学习了罗森布拉特的感知机模型：输入经过加权求和，再加上偏置，通过阈值决定是否激活。 今天我们在二维平面上彻底看清它的几何本质。 大家看右边的坐标系，横轴是特征 x₁，纵轴是特征 x₂。 神经元的净输入是 z 等于 w₁x₁ 加 w₂x₂ 加 b。 当 z 大于 0 时，神经元激活，判定为类别 A（青绿色区域）；当 z 小于 0 时，判定为类别 B（品红色区域）。 而 z = 0 正好是一条直线——在高维空间中，它就是所谓的“超平面”。 请注意两个关键几何事实： 第一，权重向量 w 构成了这条直线的法向量！红色的箭头垂直于决策直线，严格指向 z 大于 0 的正向分类区域。调节 w₁ 和 w₂，直线的倾斜角度随之旋转。 第二，偏置 b 控制着直线在法向量方向上的平移距离。如果偏置 b 等于 0，这条直线就无论如何都必须经过原点 (0,0)。在很多实际问题中，样本簇根本不在原点周围，若没有偏置 b，网络甚至连最简单的线性分布都无法分开。
