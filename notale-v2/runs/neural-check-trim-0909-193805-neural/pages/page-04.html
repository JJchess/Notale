线性可分性约束与明斯基指出的异或绝境

单个感知机的几何决策边界永远是一条超平面直线：它可以切分逻辑“与”和“或”，却在对角互斥的“异或”前陷入不可调和的代数悖论。

明斯基的形式化代数证伪
1. 假设单神经元权重与偏置 (w₁, w₂, b) 满足 XOR：
点 (0,0) → 0 ：0·w₁ + 0·w₂ + b < 0 ⇒ b < 0
点 (0,1) → 1 ：0·w₁ + 1·w₂ + b ≥ 0 ⇒ w₂ + b ≥ 0
点 (1,0) → 1 ：1·w₁ + 0·w₂ + b ≥ 0 ⇒ w₁ + b ≥ 0
点 (1,1) → 0 ：1·w₁ + 1·w₂ + b < 0 ⇒ w₁ + w₂ + b < 0
2. 将两组不等式相加推导矛盾：
两正例相加：(w₁ + b) + (w₂ + b) ≥ 0
⇒ w₁ + w₂ + 2b ≥ 0 …… ①
两负例相加：b + (w₁ + w₂ + b) < 0
⇒ w₁ + w₂ + 2b < 0 …… ②
代数矛盾：式 ① 与式 ② 相互排斥（同一代数式不可能同时 ≥ 0 且 < 0）。该矛盾证明：在整个实数空间 ℝ³ 中，绝对不存在能正确分类 XOR 的参数三元组 (w₁, w₂, b)。
里程碑判词：1969《感知机》与第一次 AI 寒冬

马文·明斯基与西摩尔·派珀特在此书中指出：单层感知机本质是线性投影机，对最简单的拓扑连通性与互斥问题无能为力。这一严谨的数学定论彻底击碎了当时将感知机神化为“万能大脑”的泡沫，直接引发了长达十余年的神经网络研究低谷，直到多层隐藏层与反向传播的成熟才迎来转机。

各位同学，请看大屏幕。上一节课我们看到了单个神经元在二维几何上的优美表现——它通过权重和偏置构建了一条直线超平面。 但请大家格外注意：一条直线究竟有多大的能力？ 左侧我们列出了三个经典的布尔逻辑门： 第一个是“逻辑与”（AND），只有当两个输入都为1时才输出1，一条斜率为负的直线轻松地把右上方那一个点切了出来； 第二个是“逻辑或”（OR），只要有任意输入为1就输出1，同样，一条直线把左下角(0,0)单独隔开，分类完全正确。 然而，当我们来到第三个门——“异或”（XOR）时，灾难降临了： 同为0或同为1时输出0，一奇一偶时输出1。在二维平面上，类别0占据了左下与右上，类别1占据了左上与右下。它们呈现出“对角交叉”的拓扑分布。 大家试着在脑海里画一条直线，无论你怎么旋转、平移这条直线，你最多只能分对3个点，永远会把第4个点割错！ 右侧展示了1969年图灵奖得主明斯基给出的形式化代数证明： 把四个点的阈值不等式列出来，分别将正例相加与负例相加，会得出同一个代数式 w1 + w2 + 2b 既必须大于等于0，又必须严格小于0。这是赤裸裸的数学矛盾！ 这意味着，单层感知机受制于“线性可分性约束”，它连最基本的异或都做不到。这个发现直接导致了历史上第一次人工智能寒冬。 那么，如何打破这种单一直线的诅咒？下一页我们将看到：引入隐藏层进行空间变换，正是破局的关键！
