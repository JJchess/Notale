Query、Key、Value 与位置编码直觉

内容寻址与顺序补偿

动态内容检索机制 点积打分 · Softmax 加权 · 汇聚 Value

Query

“我需要什么信息？”当前词发出的寻址向量。

Key

“我是什么标签？”候选词特征，与 Q 点积求相关度。

Value

“我承载什么内容？”匹配后按权重 α 加权汇聚的信息实体。

位置编码 (PE) 的顺序补偿 消除排列不变性

注入位置编码：

自注意力基于内容匹配，打乱词序相关度不变。叠加正余弦波形后，每个位置获得专属相位。

注意力机制把传统的序列逐步隐状态递推，改造成了类似数据库或哈希表的软寻址检索。 Query、Key、Value 是这个机制的三个核心投影。Query 代表当前词正在寻找何种上下文，Key 代表候选位置提供了什么特征供检索，点积计算它们的相关度得分，经过 Softmax 得到权重系数后，加权汇聚 Value，得到该位置的上下文表征。 但是，纯粹的内容寻址是置换不变的，打乱单词顺序计算出的注意力权重完全一样。因此必须为每个位置叠加独一无二的位置编码，通过不同频率的正余弦波形，把时序几何结构补偿回特征空间中。
