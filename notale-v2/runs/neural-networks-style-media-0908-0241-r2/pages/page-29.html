归纳偏置与数据需求

强偏置用硬编码结构约束换取样本效率；注意力放弃几何与时间先验，用 O(1) 路径换取全局表征上限，更依赖海量数据自主学习。

这一页我们对前几章学过的三种核心网络架构做一次关键的横向收敛：CNN、RNN 与自注意力机制。 所谓归纳偏置，就是模型在看到数据之前对问题规律所做的先验结构假定。 CNN 假定空间局部相关和平移等变，每次只看 k×k 的小窗口，要靠多层堆叠才能逐步扩大感受野，路径是 O(log N)；RNN 假定时序因果递推，隐状态沿时间一步步压缩，信息传递路径是 O(N)，带来长程遗忘与无法并行的瓶颈； 自注意力彻底打破了空间距离与时间递推的硬编码限制，直接用 Query 与 Key 的相关度做动态寻址，任意两个位置的信息路径只有 O(1)。 但天下没有免费的午餐：偏置越弱，网络对数据的预设约束就越少，虽然天花板更高，却必须依靠海量数据来学会位置与结构关系。
