损失函数

同一预测，标签不同，惩罚不同

模型给出预测概率 p = 0.8（判断“是正类”的信念），这个数字不会因真实标签而改变；改变的是损失函数用它算出的惩罚。

预测概率 p（模型判断“是正类”的信念）
真实标签 y = 1 预测方向一致

模型判断“是”，答案也是“是”。

L = −[y·log(p) + (1−y)·log(1−p)]
L = −[1·log(0.8) + 0·log(0.2)]
L = −log(0.8)
0
L(1) = —
真实标签 y = 0 预测方向相反

模型判断“是”，答案其实是“否”。

L = −[y·log(p) + (1−y)·log(1−p)]
L = −[0·log(0.8) + 1·log(0.2)]
L = −log(0.2)
0
L(0) = —

p 完全没变；标签把它送进公式的位置变了，惩罚随之从很小跳到很大——损失把“对不对”翻译成一个能驱动训练的数字。
