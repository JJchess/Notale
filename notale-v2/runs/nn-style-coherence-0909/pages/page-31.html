RNN · 跨时间梯度

梯度连乘导致消失或爆炸

上一页把展开图当成深网络求梯度：同一个梯度要经过 t 个时间步的因子连乘才能传回最早的隐藏状态。因子略小于 1 时乘积迅速逼近 0；因子略大于 1 时乘积迅速失控。

∂L/∂h₀ = ∂L/∂h₆ · ∏t=1…6 (∂ht/∂ht−1)

六个时间步、六个几乎相同的因子相乘。下方用两个教学简化数值：因子恒为 0.5（<1）与恒为 1.5（>1），对照连乘的两种命运。真实训练中因子每步不同、并非常数，但连乘的指数式趋势相同。

纵轴对数尺度：每格相差 10 倍，才能同时看清趋近于 0 与迅速变大的两条轨迹 横轴：t = 0（最近时间步）→ t = 6（回传到最早时间步）
因子 0.5：梯度消失

0.5 → 0.25 → 0.125 → 0.0625 → 0.03125 → 0.0156 → 0.0078

六次连乘后只剩初始梯度的 0.78%。最早时间步几乎收不到任何更新信号——不是没有误差，是误差在传递途中被逐步磨平。

因子 1.5：梯度爆炸

1.5 → 2.25 → 3.375 → 5.06 → 7.59 → 11.39 → 17.09

六次连乘后放大到初始梯度的 17 倍以上。参数更新的步子被这个放大系数撑大，训练容易在这一步之后突然震荡或发散。

两条链共享同一个结构：结果 = 因子t。因子是否偏离 1，决定连乘是收缩还是放大；序列越长，t 越大，偏离的后果被指数级放大。
