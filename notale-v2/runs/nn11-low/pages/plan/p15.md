# page-15 · 一个人学不会 · 幕 II · **2.5 分钟**

## 知识结构：process
代际推进，有方向。**必须让"一代传给下一代"的方向在画面上可见**：
横轴是代数、从左到右；技能水平曲线随代数推进；每一代的"选谁做榜样→模仿→出误差"这三步
要在画面上有一个小示意（哪怕只是一行带箭头的图例）。

## 表征形式
交互·群体模拟（**真跑**，`assets/lib/seedrandom.min.js`，种子 `'page-15'`）。
曲线用 `echarts`（`{renderer:'svg'}`）或自绘 canvas 都行；控件用 `.ctl`。

## 模型（Henrich 2004 的经典形式，**当场跑，不许写死曲线**）
每一代：
1. 上一代 N 个个体里技能值最高的那个当榜样，技能值 `z_model`
2. 新一代每个个体 `z_i = z_model - α + β·G_i`，其中 `G_i` 是标准 Gumbel 随机数
   （`G = -ln(-ln(u))`，`u` 取自 seedrandom 的 `rng()`）
3. 记录这一代的最大值，作为下一代的榜样
参数含义写在页面上：`α` = 每次模仿平均损失多少（学不像），`β` = 个体之间的发挥差异（有人会学得更好）
理论阈值（可以直接显示）：`Δz ≈ β·(ln N + 0.5772) − α`，大于 0 技能就会累积，小于 0 就会退化。

## 交互（两个滑块 + 两个预设 + 重跑，属于同一个交互，不算多头）
- 滑块 `群体规模 N`：2 → 2000，**对数刻度**，默认 **150**
- 滑块 `模仿损失 α`：0.1 → 3.0，默认 **1.0**（β 固定 0.5，写在页面上）
- 按钮预设：`塔斯马尼亚（N≈4000 但与外界断开、有效传承群体小）` → 设 N=15；`大陆（N=1500）`
- 按钮 `重跑`（换一个子种子，但仍然可复现：种子用 `'page-15-'+runIndex`）
- 曲线实时更新：横轴 0–200 代，纵轴技能水平。同时显示当前的 `Δz` 理论值和"累积/退化"判定。
`.hint`：`拖两个滑块，看棘轮什么时候开始倒转`

## 必须点出来的两句
1. 阈值只跟 **ln N** 有关：群体从 10 人变成 100 人，效果只相当于加了一个常数——
   但从 10 人掉到 3 人，技能就会**开始净损失**。
2. 塔斯马尼亚：约 1 万年前海平面上升把它与澳洲大陆隔开，之后当地人群**丢失了骨器、渔网、御寒衣物**。
   不是变笨了，是传承的人数不够了。（页面上标注：这个案例在学界仍有讨论。）
