## 知识结构：comparison
**共同基准 = 同一根对数时间轴（1 年 → 10 万年）。**
基因案例的条（赭）和技术普及案例的条（青）必须画在**同一根轴上、上下并置**，
让"两簇完全不重叠"成为画面本身。两边各画各的图 = 失败。

## 表征形式
交互·对数轴上的条形对比 + 一个选择系数滑块（基因那一簇是**真算**出来的）。

## 基因那一簇（**当场算**）
一个新的有利等位基因从频率 1% 升到 90% 所需时间（确定性近似）：
```
t_generations = (1/s) · ln[ (p2/(1−p2)) / (p1/(1−p1)) ]      p1=0.01, p2=0.90
t_years = t_generations × 25        // 一代按 25 年
```
核对：`s=0.02 → 340 代 → 8500 年`；`s=0.05 → 136 代 → 3400 年`；`s=0.10 → 68 代 → 1700 年`；`s=0.005 → 1359 代 → 34,000 年`。
滑块 `选择系数 s`：0.002 → 0.10（对数刻度），默认 **0.02**。
（页面上要说明 s=0.02 已经算是很强的选择；多数位点远小于这个值。）

同时画三个真实锚点（不随滑块变）：乳糖酶持续 ≈ 7500 年、欧洲肤色扫荡 ≈ 6000–12000 年、
EPAS1 ≈ 3000–8000 年。
