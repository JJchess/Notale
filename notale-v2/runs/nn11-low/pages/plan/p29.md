# page-29 · 牛顿的大炮 · 幕 IV · **2.5 分钟**

`Chrome.mount({ act:4, title:'牛顿的大炮', sub:'轨道不是"飞出去"。轨道是一直在往下掉，而地面一直在躲开。', foot:'既然要 7.8 km/s，那就得问：这个速度从哪儿来？' })`

## 知识结构：process
状态迁移：随着初速增加，轨迹依次经过 `落回` → `椭圆（近地点在发射点对面）` → `圆` → `椭圆（远地点在对面）` → `逃逸`。
**这几种状态要在画面上被显式标出**（当前状态用文字 + 颜色标明，并在速度滑块上标出各状态的分界速度）。
只画一条轨迹不算 process。

## 表征形式
交互·**真实轨道积分**沙盒（自绘 canvas；轨道曲线不是常规图表，不要用 echarts）。

## 物理（**必须真积分，不许用椭圆解析式画完了事——积分本身就是这一页要展示的东西**）
```
GM = 3.986e14, R = 6.371e6
发射点：北极上方 h0 = 200 km（避开大气），速度方向水平
积分：速度 Verlet 或 RK4，dt = 1 s，最多积 20000 步或直到 r < R（撞地）
a = −GM · r_vec / |r|³
```
核对：`h0=200 km 处圆轨道速度 = sqrt(3.986e14/6.571e6) = 7,788 m/s`；
该处逃逸速度 = `7788×√2 = 11,014 m/s`。

## 交互（只有这一个）
滑块 `发射速度`：4.0 → 12.0 km/s，步长 0.01，默认 **6.0**（先让学生看见"掉回来"）。
拖动时立刻重新积分并重画轨迹。画面：
- 一个按比例画的地球圆（半径 R），一个小炮口在顶端 200 km 高处
- 轨迹线（当前状态色：落回=`--warn`，椭圆=`--gene`，圆=`--cult`，逃逸=`--cult-2`）
- 滑块上四个刻度锚点：`7.79 圆轨道`、`11.01 逃逸`
- 读数区：`初速`、`状态`、`近地点高度`、`远地点高度`、`周期`（撞地时显示"撞地，飞行 N 分钟"）
  近/远地点和周期从积分结果里**统计出来**（取 |r| 的极值；周期用回到起点附近的时间）
`.hint`：`拖滑块改变初速，轨迹会重新算一遍`

## 必须点出来的一句
「圆轨道上的航天器**一直在自由下落**——它每秒往下掉 4.9 米，
而地球表面在这一秒里也弯下去了 4.9 米。**它永远追不上地面。**」
（这句可以配一个小示意：切线直线 vs 地球弧面，标出 4.9 m。）
