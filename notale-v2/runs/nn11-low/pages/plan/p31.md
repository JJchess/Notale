## 公式与常数（**当场算**）
```
v_e = I_sp × g₀          g₀ = 9.80665 m/s²
Δv  = v_e × ln(m₀ / m₁)
```
核对：`I_sp=350 s → v_e = 3432.3 m/s`；`m₀/m₁ = 15 → Δv = 9,293 m/s`；
`m₀/m₁ = e ≈ 2.718 → Δv = v_e`；`= e² → 2v_e`；`= e³ → 3v_e`。

## 交互（只有这一个复合控件）
- 滑块 `比冲 I_sp`：250 → 460 s，默认 **350**（旁注：`液氧煤油 ≈ 310 · 液氧液氢 ≈ 450`）
- 滑块 `质量比 m₀/m₁`：1.0 → 30，**对数刻度**，默认 **15**
- 输出（`.big`）：`Δv = X m/s`，并与一条固定的目标线比较：`到近地轨道需要约 9,400 m/s（含重力损失与气动损失）`
- 曲线：横轴 m₀/m₁（对数，1–30），纵轴 Δv，当前点用大圆点标出；
  横轴上标 `e / e² / e³` 三个刻度，纵轴对应标 `1×v_e / 2×v_e / 3×v_e`——这就是"对数"的可视化解释
`.hint`：`拖两个滑块，看 Δv 怎么变`

## 必须写在页面上的一句直觉解释（不用微积分）
「**每让 Δv 多出一个 v_e，质量比就要再乘一次 e（约 2.72）。**
不是加，是乘。要 3 倍的 v_e，起飞质量就得是最后质量的 **20 倍**。」

## 一句"为什么会是对数"的白话
「因为你扔掉的燃料，前一秒还得被你带着一起加速。
越到后面，火箭越轻，同样多的燃料能加更多速——这就是对数的来源。」（不展开推导。）
