## 知识结构：classification
**层级归属**，两层嵌套，必须用包含框 + 缩进（`.hier > .lv` 或自绘的树）画出来。
**不能平铺成三张卡片。** 每个二级项归到它的一级类里，视觉上要能看出"这一条属于那一类"。

```
重力被拿掉
├─ 结构负荷类（骨、肌、脊柱：它们的存在理由就是对抗 1 g）
│   ├ 承重骨每月流失 1–1.5%
│   ├ 抗重力肌 5–11 天可失去约 20% 的质量
│   └ 脊柱伸长 3–5 cm，返回后腰痛与椎间盘突出风险升高
├─ 流体分布类（心血管、颅内、眼：它们的校准前提是"站着"）
│   ├ 约 2 升体液从下肢移向胸腔和头部
│   ├ 血浆容量下降 10–15%，心脏后负荷下降
│   └ 航天相关神经眼综合征（SANS）：视盘水肿、远视漂移，长期任务中报告率超过 60%
└─ 姿态与感觉类（前庭、本体感觉、视觉：它们靠重力定"哪边是下"）
    ├ 太空适应综合征：入轨头两三天约 70% 的人出现，头晕呕吐
    └ 返回后立位耐受不良：站起来就晕，需要数天到数周恢复
```

骨头会按受力重塑，体液会按重力分布，内耳会按重力找"下"。规则没错，环境换了。」
