## 三个问题

**Q1 · 第一个在火星上出生的孩子，长大后和地球人最大的差别会来自哪里？**
- A 基因（在辐射下发生的突变） → 回应：`突变是随机的，几乎全是有害的，而且一代人根本不够。这条太慢。`
- B 发育（在 0.38 g 下长骨头、长心脏、长内耳） → 回应：`这一条我们整堂课都没讲——因为没人知道答案。人类从未在 1 g 之外发育过一个胚胎。这是第三条通道：不是基因，也不是文化，是发育可塑性。`
- C 文化（在一个封闭的小社会里长大） → 回应：`很可能是最大的那一项，但它和地球上任何一个封闭小社会没有本质区别。真正新的是 B。`

**Q2 · 如果体外通道断了——所有存储被抹掉，会用它的人也不在了——人类要多久回到今天？**
- A 一两代人，因为原理还在人脑子里 → 回应：`回想第 15 页。一个人学不会。"原理还在"和"有足够多的人同时掌握它"是两回事。`
- B 几千年，相当于重走一遍农业到工业 → 回应：`有一个新的障碍：容易开采的浅层煤和石油已经被我们用掉了。第二次工业革命没有第一次的燃料。`
- C 永远回不来 → 回应：`可能太悲观。但塔斯马尼亚的例子说明，退化是真的会发生的，而且不需要任何灾难，只需要人变少。`

**Q3 · 两到三个数量级的错配，该让身体追上去，还是让环境慢下来？**
- A 让身体追上去（基因编辑、器械增强） → 回应：`那等于把身体也变成体外通道的一部分——变化速度会和技术一样快。你确定那是"追上"，还是"放弃了那把慢的尺子"？`
- B 让环境慢下来 → 回应：`人类历史上没有任何一次成功地让技术慢下来过。而且慢下来的代价通常由最穷的人先付。`
- C 两个都不选，学会带着错配生活 → 回应：`这大概是现实的答案，但"学会"本身也是一项要靠体外通道传下去的技能——它得被教。比如，被这样一堂课教。`
