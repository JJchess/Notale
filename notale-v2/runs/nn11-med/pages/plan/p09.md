# page-09 · 直立的代价：过不去的产道 · 幕 I · **2.0 分钟**

## 知识结构：process
一条**因果链**，必须用 `.flow.v` 或自绘的箭头链显式画出方向：
`直立行走` → `骨盆变短变宽、产道被夹住` → `胎儿头径受限` → `必须在脑发育很早时出生` → `婴儿极度无助` → `长期抚养 + 群体协作`
每一环之间有可见的箭头。最后一环用 `--cult` 色（它是通向幕 II 的接口）。

## 表征形式
交互·真算几何约束（自绘 SVG/canvas 的"头能不能过去"示意 + 一个滑块）。

## 计算（**当场算**）
把新生儿脑近似成球：
```
d_brain = 2 × (3V / 4π)^(1/3)          V 单位 cm³(=cc)，d 单位 cm
d_head  = d_brain + 1.6                 颅骨与软组织的经验加量，页面上必须写明这是简化估计
```
产道最窄处（骨盆入口前后径）取 **11.0 cm**（现代女性均值量级，页面上写明是均值）。

核对：
- V=380 cc（人类新生儿实际值）→ d_brain = 8.98 cm → d_head = 10.58 cm → **过得去，余量 0.42 cm**
- V=540 cc（若按黑猩猩的比例，新生儿脑＝成年 1350 cc 的 40%）→ d_brain = 10.11 → d_head = 11.71 → **过不去，差 0.71 cm**

## 交互（只有这一个）
滑块：`出生时的脑容量`，250–700 cc，默认 **380**。
- 左侧画一个固定的产道最窄截面（11.0 cm 的圆/椭圆轮廓）和一个随滑块变化的头颅圆。
  两个圆**同心、同一比例尺**，直接看得出谁大。过得去＝`--ok`，过不去＝`--warn`。
- 右侧读数：脑容量 / 头径 / 余量（cm，正负）/ 判定。
- 滑块上标两个刻度锚点：`380 人类实际` 和 `540 若按黑猩猩比例`。
`.hint`：`拖滑块，看头什么时候过不去`

## 必须点出来的三句（挂在因果链上，16px）
1. 黑猩猩新生儿的脑是成年的 **40%**，人类只有 **28%**——人类的孩子是被"提前"生出来的。
2. 按灵长类的发育节奏外推，人类的妊娠"应该"是 **18–21 个月**。多出来的那一年在子宫外面过。
3. 所以人类的婴儿不能自己抓住母亲的毛、不能跟着走。**抚养必须由不止一个人来做。**
