# page-32 · 为什么火箭几乎全是燃料 · 幕 IV · **2.0 分钟**

`Chrome.mount({ act:4, title:'为什么火箭几乎全是燃料', sub:'把结构和载荷一起算进去，单级火箭连轨道都上不了——载荷比会变成负数。', foot:'解决办法只有一个：把用完的壳子扔掉。' })`

## 知识结构：comparison
**共同基准 = 同一根"起飞总质量 = 100%"的横条。** 一根条按 Δv 目标实时切成三段：
`推进剂 / 结构 / 载荷`。载荷变负时，把它画成从条的右端**向左倒扣出去的红色缺口**，
和正常状态在同一根条上对照。两张图 = 失败。

## 表征形式
交互·质量比可视化（自绘 DOM/canvas 条 + 一个 Δv 滑块）。

## 公式（**当场算**）
```
v_e = 3432.3 m/s   （I_sp = 350 s，与上一页一致，页面上写明）
推进剂质量分数  f_p = 1 − e^(−Δv/v_e)
结构质量        f_s = ε × f_p ,  ε = 0.09     （结构质量约为推进剂质量的 9%，写明这是典型值）
载荷质量分数    f_L = 1 − f_p − f_s
```
核对：`Δv=9400 → f_p=0.9354, f_s=0.0842, f_L=−0.0196`（**负数**）；
`Δv=7000 → f_p=0.8703, f_s=0.0783, f_L=0.0514`；
`Δv=4000 → f_p=0.6884, f_s=0.0620, f_L=0.2496`。

## 交互（只有这一个）
滑块 `目标 Δv`：2,000 → 12,000 m/s，步长 50，默认 **9,400**（近地轨道）。
- 条实时切分并标百分比（`.num`，13px 起）
- 载荷段为正时 `--ok`／为负时画成 `--warn` 的缺口并标 `载荷比 −2.0%：这枚火箭连自己都送不上去`
- 滑块上标锚点：`4,000 探空火箭`、`9,400 近地轨道`、`12,000 地月转移`
- 一个开关 `结构系数 ε`：0.06 / 0.09 / 0.12（三档按钮），让学生看到"就算结构做到极限也救不回来"
`.hint`：`拖 Δv 到 9400（近地轨道），看载荷比会怎么样`

## 必须点出来的一句
「**在 ε = 0.09 的条件下，单级火箭的 Δv 上限约 8,561 m/s——离入轨还差约 840 m/s。**
（这个上限可以当场解 `1 − (1+ε)(1 − e^(−Δv/v_e)) = 0`，即 `Δv = v_e·ln((1+ε)/ε)` 得到。）
所以从来没有一枚单级火箭把有效载荷送进过轨道。」
