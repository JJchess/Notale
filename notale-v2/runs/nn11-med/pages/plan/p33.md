## 知识结构：comparison
**共同基准 = 起飞总质量 2,970,000 kg 这一个 100%。**
用一张**按面积严格成比例**的方块图（一个大矩形按质量切分成嵌套的小块），
让"送到月球的那一块小到几乎看不见"成为画面本身。用条形图也可以，但必须同一根刻度。

## 表征形式
交互·比例块点选 + 一张真实照片。

## 数据（阿波罗 11 号，kg；照抄，比例**当场算**）

| 部分 | 质量 | 占比（当场算） |
|---|---|---|
| 第一级 S-IC 推进剂 | 2,145,000 | 72.2% |
| 第一级 S-IC 干重 | 131,000 | 4.4% |
| 第二级 S-II 推进剂 | 456,100 | 15.4% |
| 第二级 S-II 干重 | 36,000 | 1.2% |
| 第三级 S-IVB 推进剂 | 106,600 | 3.6% |
| 第三级 S-IVB 干重 + 仪器舱 | 13,500 | 0.45% |
| 送往月球的飞船（指令舱+服务舱+登月舱+适配器） | 48,600 | 1.64% |
| 其中最终溅落回地球的指令舱 | 5,560 | **0.19%** |
| **起飞总质量** | **2,970,000** | 100% |

（推进剂合计 2,707,700 = 91.2%；结构合计 180,500 = 6.1%。这两个汇总也要当场算并显示。）
高度 110.6 m。

## 交互（只有这一个）
点任意一块 → 高亮该块，读数区显示 `名称 / 质量 / 占比 / 相当于总质量的几分之一`。
另有一个按钮 `只留下回来的那部分`：其余全部降到 `opacity:.12`，只剩 0.19% 的那一小片亮着。
默认选中 `送往月球的飞船`。`.hint`：`点任意一块看它占多少`
