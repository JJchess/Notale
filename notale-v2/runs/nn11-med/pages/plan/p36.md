## 数据与公式（**当场算**）
```
BMD(t) = 100 × (1 − r)^t          t 单位：月
```
| 情形 | 月流失率 r | 说明 |
|---|---|---|
| 微重力，无对抗措施 | 1.5% | 早期空间站的观测量级（承重骨：股骨颈、腰椎） |
| 微重力，ARED 抗阻训练 + 药物 | 0.3% | 国际空间站现行方案的量级 |
| 地面，绝经后骨质疏松 | 0.083% | 相当于每年 1% |

核对：`6 个月无对抗 → 91.3%（掉 8.7%）`；`6 个月有对抗 → 98.2%`；
`30 个月（火星往返量级）无对抗 → 63.6%（掉 36.4%）`；`30 个月有对抗 → 91.4%`。

## 交互（只有这一个）
滑块 `任务时长`：0 → 36 个月，步长 1，默认 **6**（一个标准的空间站乘组任务）。
- 图上一条竖线随滑块移动，三条曲线在该处的值实时读出（`.big` 显示"无对抗"那个数）
- 滑块上标锚点：`6 一次空间站任务`、`12`、`30 火星往返（含地表）`
- 读数区加一行换算：`相当于在地面上老化 N 年`（= 无对抗流失量 ÷ 每年 1%，当场算）
`.hint`：`拖任务时长，看骨头掉到什么程度`
