# page-41 · 一项太空适应都没有 · 幕 VI · **2.0 分钟**

## 知识结构：generalization
一个主张 + 五条支撑。主张 `.claim`（26px），五条支撑挂在 `.trunk` 上。
**五条支撑必须是同一个句式**（"身体按 X 校准 → 在太空 X 不存在 → 解法在体外：Y"），
句式的重复本身就是论证——版面上要让三段（校准前提 / 失效 / 体外解法）**三列对齐**，
这样"解法那一列全都在身体外面"成为可见的事实。

## 主张
「**从 366 万年前到今天，这具身体没有为太空做过任何一项准备。
它在轨道上出的每一个问题，解法都不在身体里。**」

## 五条支撑（三列对齐：身体按什么校准 / 在太空里失效成什么 / 解法）

| 身体按什么校准 | 在太空里 | 解法（全部在体外） |
|---|---|---|
| 骨骼按 1 g 的受力重塑 | 每月流失 1–1.5%（p36） | 一台跑步机、一套抗阻器械、双膦酸盐 |
| 循环系统按站立姿势校准 | 2 升体液上移，视力受损（p37） | 下体负压装置——**还在试验阶段** |
| 皮肤和 DNA 靠大气与磁层挡射线 | 火星往返 982 mSv（p38） | **目前没有可行的屏蔽方案** |
| 体温调节靠对流和蒸发 | 真空里两者都不存在（p39） | 14 层的服装 + 90 米水冷管 |
| 每天要 7.6 kg 物质流过身体 | 那里什么都没有（p40） | 整套再生生保系统 |

**注意第 2、3 行的"解法"是空的或不成熟的**——这两行用 `--warn` 标出来。
不要把这堂课讲成"人类无所不能"。
