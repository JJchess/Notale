# page-04 · 一个神经元怎样算出预测 · **90 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `NEURON FORWARD` |
| 主标题 | 一个神经元用“各自相乘、合在一起、压到 0～1”算出预测 |
| 收束句 | 输入是题目给定的信息；权重和偏置是机器可以修改的参数。 |
| 下一问 | 权重和偏置都是旋钮，它们改变预测的方式有什么不同？ |

## 知识结构：process

**关系不变量**：两条输入轨道、各自权重、乘积、偏置、总分和预测必须沿同一条从左到右的前向轴相连；输入值与参数形状始终不同，两个乘积必须先汇合，偏置只能在汇合处加入。

**共享原语**：`.k-process` 承担前向先后关系，`.input-track` 与 `.input-mark` 表示不可学习的输入，`.param-knob` 表示可学习的权重和偏置。整条过程置于 `.canvas-full`，唯一有向连接使用 `.flow-forward`。

## 表征形式

交互式单神经元前向记录：学习者逐步送入两条信号，再加入偏置，最后通过 S 形压缩器 sigmoid。首次解释：“sigmoid 是把任意总分压到 0 与 1 之间的压缩器；本课不要求计算它的公式。”

原生 SVG 适合精确连接轨道、旋钮、汇合点和预测圆标；控件与读数使用原生 DOM。

## 主工作流

build-interaction ← 让无编程经验者逐步触发并核查一次完整前向计算

## 五段实验记录

| 阶段 | 画面文字 | 写入内容的值 |
|---|---|---|
| 输入 1 | `输入 x₁ = 0.8`，经过 `权重 w₁ = 0.7` | `0.8 × 0.7 = 0.56` |
| 输入 2 | `输入 x₂ = 0.3`，经过 `权重 w₂ = −0.4` | `0.3 × (−0.4) = −0.12` |
| 合并 | `把两条证据合在一起` | `0.56 − 0.12 = 0.44` |
| 偏置 | `再加入偏置 b = −0.1` | `0.44 − 0.1 = 0.34` |
| 压缩 | `sigmoid(0.34)` | `预测 ≈ 0.584` |

计算入口：`Lec.P.neuronForward([0.8, 0.3], [0.7, -0.4], -0.1, "sigmoid")`。页面显示返回的 `preActivation` 与 `output`，不硬编码派生结果。

## 交互

初始状态显示完整灰色结构和全部固定读数，但尚无高亮路径。学习者点击“送入下一项”，依次激活输入 1、输入 2、偏置、合计、压缩；“上一步”可回看，“重新开始”回到未激活状态。键盘 Enter/Space 可触发按钮，当前步骤通过文字“第 n/5 步”同步播报。

每次推进只新增本段乘法或加法记录，已完成段保持可读。最终预测以蓝色圆形 `.prediction-mark` 出现；本页没有正确或失败状态。

## 动效

信号沿 `.flow-forward` 从左向右移动 120–180px，每段 420ms，相邻两轨错开 120ms；汇合后总分读数脉冲一次，持续 260ms。压缩阶段由总分位置移动至预测圆标，持续 500ms，不循环播放。
