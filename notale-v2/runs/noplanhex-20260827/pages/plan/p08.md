# page-08 · 权重扫出损失曲线 · **125 秒**

## 知识结构：process

关系不变量：权重轴、预测读数和损失曲线共享同一个权重游标；游标移动时三处必须同步，曲线横轴只表示第一个权重，不能混入其他参数变化。

共享原语：`.k-process` 把“转动权重→预测变化→损失变化”串成单向观察过程；`.loss-terrain` 承载完整损失曲线与 `.current-mark`；`.param-knob` 明确唯一可操作对象。整套置于 `.canvas-full` 的单一画布。

## 表征形式

交互式单参数折线图：上方是权重旋钮与预测读数，下方是完整损失曲线；竖直游标贯穿两者。

使用 ECharts绘制连续曲线和坐标轴；外层原生 DOM 控制旋钮、读数与播放按钮。

## 固定条件与曲线

| 项目 | 页面内容 |
|---|---|
| 固定输入 | x₁＝0.8，x₂＝0.3 |
| 固定参数 | w₂＝−0.4，偏置＝−0.1 |
| 可调参数 | w₁，范围 −1.00 至 2.00，步进 0.01，默认 0.70 |
| 正确目标 | 1 |
| 横轴 | 第一个权重 w₁ |
| 左侧联动读数 | 预测，0 至 1 |
| 纵轴 | 损失，0 至 1.4 |
| 当前状态 | w₁＝0.70，预测≈0.584，损失≈0.538 |

每个采样点先调用 `Lec.P.neuronForward([0.8,0.3],[w₁,-0.4],-0.1,"sigmoid")`，再调用 `Lec.P.binaryCrossEntropy([output],[1])`。曲线采样间隔 0.01。

## 交互

学生拖动或用方向键调整 w₁；旋钮角度、竖直游标、圆形预测标记、预测读数和损失读数立即同步。“从左扫到右”以固定速度遍历全范围，按钮再次点击暂停；手动拖动立即接管。经过位置留下细中性刻痕，但不设置最低点挑战，也不宣称有限范围内存在唯一最优值。“回到 0.70”恢复首帧。

要形成的直觉是：参数不是只有“对/错”两个状态，细小转动会带来连续的预测和损失变化。

## 动效

自动扫描时游标从 w₁＝−1.00 向 2.00 匀速移动，单程 6 秒；预测标记沿 0–1 轨道同步平移，曲线当前点只做 180 毫秒读数脉冲。暂停后所有痕迹保持可复查。
