# page-14 · 双方法核对 · **100 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `GRADIENT CHECK` |
| 主标题 | 左右轻推会核对同一支箭头 |
| 收束句 | 快速反传与左右轻推给出近似相同的方向和强度，说明它们回答的是同一个问题。 |
| 下一问 | 既然每支箭头都可信，整张网怎样迈出一步？ |

## 知识结构：comparison

关系不变量：同一权重、同一初始状态与同一损失必须贯穿两种方法；反传结果和左右轻推结果要同列、同单位、同小数位，并在底部汇合成唯一核对结论。

共享原语：`.k-comparison` 组织“反向传播 / 左右轻推”两列同尺度记录，`.error-ledger` 固定预测、目标和损失口径，`.delta-mark` 只在两列完成后表示共同认可的参数修改方向。骨架置于 `.ledger` 中段，上方锁定被检权重，下方给核对结论。

## 表征形式

交互式实验账本：两个按钮分别运行反向传播和左右轻推，完成后逐项比较方向、数值与相对差。

使用原生 DOM/SVG 适合两列固定账目和单个权重的短轴试探，无需图表坐标系。

## 核对账目

| 字段 | 反向传播 | 左右轻推 |
|---|---:|---:|
| 被检参数 | 隐藏神经元 1→输出的权重 `w=0.9` | 同一权重 `w=0.9` |
| 试探位置 | 不改变参数 | `0.89` 与 `0.91` |
| 损失 | 基准约 `0.660` | 左约 `0.663`；右约 `0.657` |
| 损失对权重的指示 | 约 `−0.282` | `(右侧损失−左侧损失)÷0.02≈−0.282` |
| 参数应迈向 | 增大 `w` | 增大 `w` |
| 核对判据 | colspan 语义：相对误差小于 `0.0001` 即通过 | 页面显示“双线轮廓：近似一致” |

显示步长固定为 `0.01` 权重单位。计算入口：反传列取 `networkBackward` 的对应梯度；轻推列调用 `finiteDifferenceGradient(valueFunction,[0.9],0.01)`；再用 `gradientRelativeError` 比较。`0.0001` 来自 `Lec.K.GRADIENT_CHECK_RELATIVE_TOLERANCE`。

## 交互

默认两列结果遮住，只显示参数当前位置和两个运行按钮。点击“运行反传”立即填写左列；点击“左右各推 0.01”依次计算 `w=0.89`、`w=0.91` 并填写右列。两列都完成后才显示共同的向右更新箭头和核对结论，操作顺序不限。

“清空核对”只清除实验结果，恢复同一初始网络。若实现误差超出阈值，结论使用虚线轮廓并提示“检查是否用了同一参数、同一初始状态和中心差值”，不使用红绿底色。

## 动效

轻推时当前位置实心圆先左移 32px、返回，再右移 32px、返回；每段 220ms。损失读数在对应位置完成后脉冲一次。最终更新箭头从当前位置向右伸出 40px、用时 260ms。

## 核对

| 参数 | 期望结果 |
|---|---|
| `w=0.9` | 解析梯度约 `−0.2823` |
| `w=0.89 / 0.91`，步长 `0.01` | 两侧损失约 `0.663 / 0.657`，中心差值约 `−0.2823` |
| 解析值与数值值 | 最大相对误差应小于 `1e−4`，`passes=true` |
