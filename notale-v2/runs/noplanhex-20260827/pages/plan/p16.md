## 知识结构：generalization

关系不变量：中心主张位于完整训练画布上方；下方“二维分类场”和“损失记录”并列且共享训练步数，按钮、当前步数和当前损失必须属于同一状态。边界每次变化与损失曲线新增点严格同步。

共享原语：`.k-generalization` 用一个 `.claim` 统领两条 `.support`；左侧支撑是分类边界逐渐包住两圈，右侧支撑是损失随训练步数下降。`.sample-train` 标记参与更新的实心圆点，预测区域只用 `.prediction-mark` 的语义色。

## 表征形式

交互式实时训练画布：左侧 Canvas 绘制 200 个训练点与概率场，右侧 ECharts 折线图记录全训练集损失，下方白色 `.panel` 放训练按钮和读数。Canvas 适合周期重算 80×80 场并稳定绘制大量点，ECharts 适合带轴的损失历程。

## 主工作流

build-interaction ← 按住按钮时协调训练计算、边界刷新、曲线记录与可复位状态

## 训练配置与读数

| 项目 | 画面文字或真实值 | 用途 |
|---|---|---|
| 网络 | `2→10→10→1` | 页面显示 |
| 隐层 | `tanh` | 页面短标 |
| 训练点 | `200 个` | 实心圆；内圈目标 0，外圈目标 1 |
| 半径 | 内圈 `0.35–0.65`；外圈 `0.85–1.15` | 生成规则，不另画半径公式 |
| 场地 | 横纵轴均 `−1.3 至 1.3` | 左右同尺度 |
| 概率场 | `80×80` | 预测不小于 0.5 的区域以蓝色硬边表示 |
| 判断门槛 | `0.5` | 页面图例显示 |
| 批量 | `16 个点/小步` | 控件旁短注 |
| 速度 | `12 小步/帧` | 只在按住时执行 |
| 学习率 | `0.3` | 固定读数，不提供调节 |
| 种子 | 网络 `1`；数据 `rings-v1` | 只用于复现，不进入主画面 |
| 动态读数 | 训练小步、全训练集损失 | 页面显示，损失现场计算 |

每批前向使用 `Lec.P.networkForward`，损失使用 `Lec.P.binaryCrossEntropy`，反传使用 `Lec.P.networkBackward`，更新使用 `Lec.P.applyGradients`。

## 交互

学习者按住“按住训练”才运行，松开立即暂停；键盘用户按一次空格切换运行/暂停。每帧执行 12 个批量小步，每累计 60 小步重算完整概率场和全训练集损失，并向曲线追加一点。按钮上方四个短词“预测→计分→反传→更新”依次加粗，但不逐项停顿。点击“从头再来”恢复相同数据、参数种子和空损失曲线。没有目标终点，也不判成功；观察任务是同时看边界成形与损失总体下降。

## 动效

训练时仅让四步轴以 480ms 一轮沿前向、计分、反传、更新方向描线；边界采用 160ms 直接插值，损失折线从上一点延伸至新点。训练点保持静止，避免误以为数据在移动。

## 核对

初始状态重复打开时，200 个点的位置与初始损失必须完全一致。任一轮更新前后，网络层尺寸保持 `2→10→10→1`；分类判断必须使用“预测 ≥ 0.5 为第 1 类”。暂停后训练步数、参数、边界和曲线均不得继续变化。
