# page-21 · 一句话收束 · **30 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `TAKEAWAY` |
| 主标题 | 神经网络的“学会”，就是让错误持续指导参数修改 |
| 收束句 | 用错误为每个参数指出方向，沿反方向小步、反复地改，并用新样本检查规律是否站得住。 |
| 下一问 | 下一次看到一个模型说“训练完成”，你会先追问它的误差、更新方向和新样本表现吗？ |

## 知识结构：classification

关系不变量：中央只有一个“学习”总类，内部按从属关系包含“错误指出方向”“参数小步修改”“循环反复执行”三项；“新样本检验”放在总类外侧作为结果检查，不得与参数更新混成同一动作。

共享原语：`.k-classification` 构成唯一视觉中心，根层 `.lv` 是“学习”，内部三个 `.box` 以缩进和 `.bt` 表示动作组成；外侧检查项使用独立轮廓，说明它检验学到的结果而不参与当轮更新。

## 表征形式

静态中央聚焦页。使用原生 DOM 与简单 SVG 连接线构成层级陈述；没有数据变化或复杂关系，不引入图表库。

## 中心层级

| 层级 | 画面文字 |
|---|---|
| 总类 | 学习 |
| 动作 1 | 错误为每个参数指出方向 |
| 动作 2 | 参数沿梯度反方向迈一小步 |
| 动作 3 | 预测、计分、反传、更新反复执行 |
| 外部检查 | 未参与训练的新样本仍表现良好？ |

中心下方保留一行短注：“一次更新只是一步；反复降低误差，并不自动等于真正理解。”

## 动效

三个内部动作依次上升 8px 入场，间隔 120ms；随后外部检查项从右侧移动 16px 接入，时长 220ms。所有对象入场后保持静止，供教师读出收束句。

## 主工作流

build-page ← 用单一层级中心压缩全课主线并保持动作与检验的边界

## 不许碰

不增加公式、案例、模型类型或新的训练证据；预测、损失、梯度、反向传播、学习率与新样本的依据均由 p04–p18 负责。本页只收束已经建立的结论。
