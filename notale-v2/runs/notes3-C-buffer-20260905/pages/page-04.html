CH₃COOH / CH₃COO⁻ 体系的协同承接

外加强酸 H⁺ 共轭碱承接
承接前：A⁻ 与 HA 保持平衡
H⁺ + CH₃COO⁻ → CH₃COOH 游离 H⁺ 被转化结合
共轭碱消耗量 [A⁻] 5.00 -1.00 mmol

外加强碱 OH⁻ 弱酸电离补偿
中和前：HA 与 A⁻ 保持平衡
OH⁻ + CH₃COOH → CH₃COO⁻ + H₂O 游离 OH⁻ 被质子中和
弱酸消耗量 [HA] 5.00 -1.00 mmol
共轭碱生成量 [A⁻] 5.00 +1.00 mmol
溶液 pH 变化响应 4.76 → 4.94 (仅微升 0.18)
缓冲溶液能够抵抗外加酸碱扰动的根源，在于其内部同时存在足够浓度的弱酸和共轭碱两种有效微粒。 当我们向溶液中加入少量强酸 H⁺ 时，游离的 H⁺ 并不在溶液中累积，而是立即被体系中富集的共轭碱 CH₃COO⁻ 结合，转化为解离度极低的弱酸分子 CH₃COOH； 反之，当我们加入少量强碱 OH⁻ 时，游离的 OH⁻ 会迅速被富集的弱酸分子 CH₃COOH 释放的质子中和生成水，自身转化为共轭碱。 外加的酸碱扰动因此被完全转化为弱酸与共轭碱之间的轻微比例波动，溶液中的游离氢离子和氢氧根离子浓度保持几乎恒定。
