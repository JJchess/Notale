# page-01 [标题页]
缓冲溶液与酸碱滴定曲线

# page-02 [标题页]
缓冲溶液：让 pH 面对少量酸碱扰动仍保持相对稳定

# page-03 [内容页]
什么是缓冲溶液：由弱酸及其共轭碱构成的体系能减小 pH 变化

# page-04 [内容页]
缓冲作用的粒子机制：共轭碱承接外加酸，弱酸补偿外加碱

# page-05 [内容页]
Henderson–Hasselbalch 方程：pH 由 pKa 与共轭碱和弱酸的比例共同决定

# page-06 [内容页]
缓冲范围与缓冲容量：比例决定有效区间，总浓度决定可承受扰动的多少

# page-07 [交互页]
外加酸碱量与水、缓冲液 pH 响应的实时关系（模拟训练）

# page-08 [内容页]
缓冲液的定量配制：从目标 pH 反推共轭碱与弱酸的物质的量之比

# page-09 [标题页]
酸碱滴定曲线：用滴定剂体积追踪溶液组成与 pH 的连续变化

# page-10 [内容页]
滴定曲线的基本结构：起点、缓冲区、半当量点、当量点与过量区各有不同控制因素

# page-11 [内容页]
强酸—强碱滴定：当量点附近的陡跃来自微量过量 H₃O⁺ 与 OH⁻ 的主导权切换

# page-12 [内容页]
弱酸—强碱滴定的分段计算：起始电离、缓冲共存、中和完成与强碱过量分别使用不同模型

# page-13 [内容页]
半当量点连接两大主题：弱酸与共轭碱等量时 pH = pKa，缓冲能力最强

# page-14 [内容页]
弱酸滴定的当量点并非中性：共轭碱水解使当量点 pH 大于 7

# page-15 [交互页]
滴定剂体积、溶液主要粒子、适用模型与曲线位置的联动证据（模拟训练）

# page-16 [内容页]
指示剂选择：变色范围应落在当量点附近的陡跃区，而不是机械追求 pH 7

# page-17 [标题页]
收束：缓冲区是滴定曲线上的一段化学状态，曲线是缓冲体系被逐步改写的全程记录
