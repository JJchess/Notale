本页是酸碱滴定这一部分的综合交互演练页。 我们设定的体系为标准的 25.0 mL 0.100 mol/L 醋酸 (pKa = 4.76)，使用 0.100 mol/L 氢氧化钠标准溶液进行滴定。 滴定过程经历了四个具有根本区别的化学平衡阶段： 第一阶段是加入 0 mL 时的单一弱酸起始电离，此时主要物质是 HA，溶液 pH 完全由醋酸的 Ka 决定； 第二阶段是加入 0 到 25 mL 之间的缓冲区域，随着 NaOH 不断消耗 HA 并生成共轭碱 A⁻，体系形成了共轭酸碱对，符合 Henderson-Hasselbalch 方程，其中在 12.5 mL 的半当量点处，[HA] = [A⁻]，达到最大缓冲容量； 第三阶段是加入正好 25.0 mL 时的化学计量点（当量点），HA 全部转化为 NaA，此时溶液不存在过量强碱，而是由强碱弱酸盐 A⁻ 的微弱水解主导，产生碱性（pH 约为 8.72）； 第四阶段是超过 25 mL 之后，滴入的强碱 NaOH 开始剩余，微量的水解被强碱彻底抑制，过量的强碱 OH⁻ 成为决定 pH 的绝对主导因素。 学生可以通过拖动滑块实时观察曲线上点的位置、四种关键微观粒子的消长关系，并自主选择诊断适用的计算模型。
