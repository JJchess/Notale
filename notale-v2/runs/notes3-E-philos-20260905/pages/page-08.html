在 Bagging 和随机森林中，我们需要基学习器之间存在差异，但我们往往只有一个训练集。 Bootstrap 重采样（有放回抽样）优雅地解决了这个问题：从容量为 N 的数据集里，每次随机取出一个样本记录并放回，重复抽取 N 次。 因为是有放回的，部分样本会被重复抽中 2 次甚至 3 次，而另一些样本则一次都没有被抽中。 数学上可以严格证明，当数据量 N 很大时，一个样本在 N 次抽取中始终没有被抽中的概率逼近 1/e，也就是约 36.8%。 这意味着每个 Bootstrap 子集平均只包含原始数据中约 63.2% 的独特样本，子集之间既有重叠保持相似性，又有差异性破坏相关性。 剩下的约 36.8% 样本被称为袋外样本（Out-Of-Bag），为后续的袋外评估留下了天然验证证据。
