# page-06 为什么一行页面都没写 —— 真因是规格不可满足

2026-08-28。结论先写:**我先前判的「跨页读被禁 → 只好走 Bash」是错的**，护栏做完之后
page-06 照样 35 次 Bash、0 次 Write。真因是 `p06.md` 要的东西**根本不存在**。

## 抓到的现行

护栏那轮重跑时，用 0.05s 间隔轮询 builder 的子进程，抓到了它在跑什么：

```
cd .../runs/sonnet-plan-20260828/pages && timeout 115 node -e '
  var MLP = require("./assets/lib/mlp.js"); function seed(s){ …
```

**它在用 node 跑 `mlp.js`，真的训练网络、想把权重取出来** —— 正是 `p06.md` 要求的
「页面在加载时静默训练至收敛后取出这三个权重」。这既不是跨页访问、也不在 run 目录之外，
所以新护栏正确地放行了它。护栏没错，是我诊断的病错了。

## 规格要的数不存在

`p06.md`：「权重固定为 `v_A=1.4, v_B=-1.3, b=0.1`（与 `mlp.js` 内部一个已训练好的
`[2,2,1]` 小网络对应，页面在加载时静默训练至收敛后取出这三个权重）」。

按 `p05.md`/`p06.md` 的四象限数据（第一、三象限标签 1，第二、四象限标签 0）
真训了 5 个种子，每个 4000 个 mini-batch：

| seed | 输出层 W | b | acc |
|---|---|---|---|
| 1 | [5.56, 5.83] | -0.37 | 0.715 |
| 2 | [3.53, -3.52] | -4.17 | 0.820 |
| 3 | [5.93, 5.29] | -0.74 | 0.708 |
| 4 | [3.65, 4.01] | 5.21 | 0.833 |
| 5 | [-6.12, 5.78] | 0.52 | 0.755 |

权重在 ±3–6 量级、偏置从 -4 到 +5，**没有一个接近 `1.4 / -1.3 / 0.1`**。
那三个数是规划时**编出来的好看数字**，然后被声称成训练结果。

于是 page-06 成了一个不可满足的任务：模型照规格去训练取权重，取出来的永远对不上
规格写死的值，它就再换个种子/参数试一次。43 次（护栏轮 35 次）Bash 就是这么烧掉的，
从头到尾没进到写页面那一步。

`mlp.js` 本身没问题：`module.exports = MLP`，node 里 `require` 得到
`{create, sigmoid, ACT}`，模型的思路是通的 —— 通向一个不存在的目标。

## 这正是 deck.md 已经禁过的事

`prompts/deck.md:189-191`：

> **要显示的数值连同单位和出处**。真实的数、真实的单位——不要写占位数，
> 也不要写成「从某处取值」：这一页要用的数就写在这一段里，页面直接照抄。

规则早就在，Sonnet 违反了它。而且违反得很隐蔽：它**确实**把数写进了规格
（`v_A=1.4, v_B=-1.3, b=0.1`），只是又加了一句「训练至收敛后取出」，
把「照抄」变成了「复现」。一句话之差，代价是整页没建出来。
