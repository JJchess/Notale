两阶段的物质与能量闭环

光能单向流入糖类，载体在类囊体与基质间循环摆渡。

输入 光能 H₂O
释放 O₂
输入 CO₂
产出 (CH₂O) 糖

光反应

类囊体薄膜
  • 水光解产生氧与质子
  • 光能转为电能与化学能
  • 合成 ATP 与 NADPH

暗反应

叶绿体基质
  • 固定 CO₂ 生成三碳酸
  • 消耗 ATP 与 NADPH
  • 还原产糖并再生 RuBP

高能还原态 (ATP + NADPH)

将光能固化后输入基质

低能氧化态 (ADP + Pi + NADP⁺)

卡尔文循环放能后归还空载体

载体循环不被净消耗：任一侧受阻均会导致光反应与暗反应停滞
同学们，我们来看光反应与暗反应之间的协同关系。 很多人容易把它们看成两个孤立阶段，但实际上它们构成了一个严密的物质与能量闭环。 在类囊体薄膜上，光反应捕获光能裂解水，把能量储存在 ATP 和 NADPH 这两种还原态高能载体中，顺向送往叶绿体基质。 而在基质中进行的暗反应，也就是卡尔文循环，利用这些能量固定二氧化碳合成糖类，同时把放能脱氢后的 ADP、Pi 以及 NADP⁺ 重新归还给光反应。 请注意：载体分子本身没有净消耗，它们在两个阶段之间循环摆渡。这就意味着，一旦暗反应因为缺乏二氧化碳而停滞，光反应很快会因为缺乏受体 ADP 和 NADP⁺ 而减速甚至停止；反之，没有光照提供 ATP 和 NADPH，暗反应也无法维持。
