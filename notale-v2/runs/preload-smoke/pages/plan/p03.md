# page-03 · 读懂 0–1 输出 · **80 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `READOUT · 0–1` |
| 主标题 | 0–1 输出先读成信心，再用 0.5 变成二选一判断 |
| 收束句 | 同一个数既表示模型对“答案为 1”的信心，也能跨过阈值变成类别。 |
| 下一问 | 这个 0–1 输出，是怎样从输入里产生的？ |

## 知识结构：comparison

**关系不变量：** 左右两区共享同一个输出值与同一条 0–1 尺度；左区解释连续信心，右区显示阈值后的类别，二者必须同步变化并保持读数同基线。

**共享原语：** `.k-comparison` 约束两种读法使用同一数值，`.split-lr` 将“连续信心”和“二选一判断”并置，`.ctl` 把唯一滑块、刻度和动态读数绑定为同一观察仪器。

## 表征形式

交互式阈值判读仪：左侧为 0–1 水平刻度、滑块和信心读法，右侧为固定阈值线及类别结果框。使用原生 DOM、`input[type=range]` 与内联 SVG；关系简单且需要无障碍键盘操作，不引入图表库。

## 主工作流

build-interaction ← 让一个连续输出同时驱动概率表述与阈值判断

## 两种读法与固定口径

| 区域 | 标签 | 画面内容 |
|---|---|---|
| 共用输入 | 模型输出 | `p = 0.72`，默认值 |
| 左区 | 读成信心 | “模型认为答案为 1 的信心是 72%” |
| 左区 | 换成频率 | “按模型的估计，100 次相似情况中约有 72 次是 1” |
| 右区 | 判断阈值 | `0.50` |
| 右区 | 判断规则 | `p < 0.50 → 类别 0` |
| 右区 | 判断规则 | `p ≥ 0.50 → 类别 1` |
| 右区 | 当前判断 | `类别 1` |

显示常量直接写入页面逻辑：`BINARY_CLASSIFICATION_THRESHOLD = 0.5`。画面只显示短标法“判断阈值 `0.50`”，常量名不印在页面上。

## 交互

学习者拖动“模型输出”滑块，范围 `0.00–1.00`、步长 `0.01`、默认 `0.72`。左侧深蓝长度、百分比文字和“100 次中约多少次”立即同步；右侧依据固定规则即时切换类别，当前结果框使用 3px 橙色边界。

滑块经过 `0.49 → 0.50 → 0.51` 时，信心只发生小幅变化，但类别在 `0.50` 处从 0 切到 1，以此形成“连续数值经过阈值成为离散判断”的直觉。阈值本身不可拖动，避免误以为本页在选择最佳阈值。

键盘支持方向键每次移动 `0.01`、Page Up/Down 每次移动 `0.10`、Home/End 到达两端；动态信心与类别放入同一礼貌播报区域。状态完全可逆且默认值清楚，不另设复位按钮，也不设置成功或失败。

## 核对

| 输出 `p` | 百分比文字 | 阈值判断 |
|---:|---:|---|
| `0.49` | `49%` | 类别 `0` |
| `0.50` | `50%` | 类别 `1` |
| `0.72` | `72%` | 类别 `1` |

边界判定必须使用“不小于 `0.5` 即为 1”，不得误写成“大于 `0.5`”。

## 不许碰

不计算或比较损失，不出现交叉熵、对数或“自信答错惩罚更大”；损失计算归 p07。本页只建立二分类输出与 `0.5` 阈值的读法，后页不得再次设置阈值操纵。
