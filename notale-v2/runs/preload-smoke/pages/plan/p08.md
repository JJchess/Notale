# page-08 · 左右试出下坡 · **130 秒**

| 元素 | 文字 |

## 知识结构：process

关系不变量：同一参数的“左侧、当前位置、右侧”必须位于同一水平刻度轴，距当前位置都为 `0.2`；三者的预测和损失按垂直列一一对应，只有两侧都测量后才能连接出局部下坡箭头。

共享原语：`.k-process` 组织“定当前位置—左试—右试—判方向”的因果次序；`.knob.on` 承担当前参数位置；`.step` 用粗框标记正在执行的试探阶段。全套实验居中铺入 `.canvas-full`。

## 表征形式

交互式单参数局部探针：参数轴上固定显示三个相邻采样点，下方同步列出各自预测和损失，并在完成两次试探后显示朝较低损失一侧的箭头。原生 DOM 与 SVG 更适合离散按钮、精确刻度和局部折线，无需常规图表库。

## 主工作流

build-interaction ← 管理左右试探的先后状态、即时计算证据与可重复的局部方向判断

## 局部试探内容

| 项目 | 画面值 | 说明 |
|---|---:|---|
| 固定输入 | `x=1` | 写入实验条件 |
| 真实答案 | `1` | 写入实验条件 |
| 固定偏置 | `0` | 写入实验条件，不再解释 |
| 当前权重 | 默认 `0.0` | 可调范围 `−2.0–2.0`，步长 `0.1` |
| 左右试探距离 | `0.2` | 两侧必须等距 |
| 激活 | `sigmoid` | 只作实验条件 |
| 损失 | 二元交叉熵 | 只显示读数 |

每个采样点先调用 `Lec.P.neuronForward([1], [w], 0, "sigmoid")` 得到预测，再调用 `Lec.P.binaryCrossEntropy([output], [1]).value` 得到损失。

## 交互

学习者可先调当前权重，再点击“向左试 0.2”和“向右试 0.2”。第一次试探只揭示对应一侧读数；两侧都试过后，比较两边损失，较小一侧获得橙色测量框，并从当前位置画出单向下坡箭头。按钮“把当前位置移到较低一侧”仅在两侧测完后启用；点击后把中心移到该侧并清空两次测量，开始新的局部试探。此动作是实验定位，不连续自动训练。“重置实验”恢复 `w=0.0` 且隐藏两侧读数。

若两侧损失显示到三位小数后相同，仍按未舍入值判断；只有真实差值低于 `1e-10` 时显示“这一小段几乎一样平”，不强画方向。

## 动效

点击试探后，橙色探针从当前位置水平移动 `32px` 至相应采样点，耗时 `240ms`；预测读数随后出现，损失再延迟 `120ms` 出现。两侧完成后，局部折线在 `300ms` 内连接三点，下坡箭头最后出现。移动当前位置时只平移中心标记，不播放训练曲线。
