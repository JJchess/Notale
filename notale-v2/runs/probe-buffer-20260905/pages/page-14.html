1. 计算中和后共轭碱有效浓度 c_b
总体积加倍 (20.00 + 20.00 = 40.00 mL)：
c_b = (0.100 mol/L × 20.00 mL) / 40.00 mL = 0.0500 mol/L
2. 由共轭碱水解平衡求 [OH⁻]
K_b = K_w / K_a = 1.0×10⁻¹⁴ / 1.75×10⁻⁵ = 5.71×10⁻¹⁰
[OH⁻] ≈ √(K_b · c_b) = √(5.71×10⁻¹⁰ × 0.0500) = 5.34×10⁻⁶ mol/L
3. 换算 pOH 与当量点 pH
pOH = -lg(5.34×10⁻⁶) = 5.27 ⟹ pH = 14.00 - 5.27 = 8.72
