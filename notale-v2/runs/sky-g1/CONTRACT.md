# 阅读边界

- 必须阅读本契约、`assets/CHASSIS.md` 和当前页面的 `pNN.md`。
- 不得阅读其他页面规格、`PLAN.md`，也不得阅读 CSS/JS 实现源码。
- 每个 agent 只实现自己的 `pNN.md`；跨页一致性以本契约为准。

## 1. 这堂课在讲什么

全课主张：星图不是今晚天空的完整照片，也不会直接给出行星答案。它提供近似稳定的恒星背景。先把纸图与真实天空对准，再在黄道附近筛出图上缺席的亮点，最后通过数日后相对恒星的位置变化复核。

| 幕 | 页 | 本幕任务 |
|---|---:|---|
| I 入场：星图能做什么 | 01–03 | 建立“星图是恒星背景方向索引，不是完整天空照片” |
| II 把纸图对准天空 | 04–08 | 对准方向、时刻和观看姿势，使图上星形与天空对应 |
| III 从恒星背景中筛行星 | 09–14 | 在黄道附近搜索；用亮度、颜色、闪烁逐步缩小候选，但不据此定案 |
| IV 检验而不是猜测 | 15–17 | 检查候选是否在恒星图上，并比较数日后相对邻星的位置 |
| V 户外执行 | 18–19 | 按固定顺序完成一次肉眼与纸图可复核辨认 |

证据链：

1. 恒星之间的形状关系近似不变；方向、时刻、图面朝向匹配后，纸图才能成为坐标框架。
2. 肉眼可见行星相对恒星背景移动，并位于黄道附近的有限天空带内。
3. 亮度、颜色和少闪烁只用于筛选，任何一项都不能单独证明行星身份。
4. “图上没有”形成候选；数日后相对邻近恒星改变位置，形成更可靠、可复核的证据。

每页只实现本页 `pNN.md` 指定的教学任务、状态与内容。`pNN.md` 标为“不许碰”或由别页负责的内容，不得提前解释、重复演示或替后页下结论。

## 2. 颜色语义

| token / 色相 | 唯一含义 | 允许出现的位置 |
|---|---|---|
| `--bg` / 极暗冷灰蓝 `#070B12` | 夜间低亮画布 | 页面底色、空黑区 |
| `--framework` / 灰蓝 `#8FA7B3` | 星图给出的固定恒星框架 | 恒星、星座辅助线、纸质星图边界及与固定背景直接关联的标签 |
| `--attention` / 琥珀黄 `#FFB347` | 此刻应看、应拖或应核对的位置 | 当前操作目标、当前步骤、当前待核对位置；单页只设一个注意中心 |

语义色不得挪作装饰，也不得为不同概念复用同一语义色。正文、边框、分隔线、非概念性图形使用主题中性色。候选与确认主要依靠形状编码：候选为开放圆环，确认对象为双圆环，不新增颜色语义。黄道与星座线主要依靠线型和线宽区分：黄道为 3px 长虚线，星座辅助线为 1.5px 实线。

## 3. 知识结构——骨架约定

容器不是知识关系，不以“卡片网格”或“左右两栏”代替结构。

| 结构 | 必须直接看见的关系 | 最低几何要求 | 失败形态 |
|---|---|---|---|
| process | 先后、因果或状态推进 | 可见方向轴、箭头或连续路径 | 只有并排块 |
| comparison | 同一维度上的差异 | 同行、同尺度、同基线 | 两边各画各的 |
| classification | 上下位或部分—整体 | 嵌套、包含或明确缩进 | 同级平铺 |
| generalization | 主张与支撑 | 主张更重，支撑挂在同一主干 | 主张和证据同权 |

优先使用 `theme.css` 提供的 `.k-*` 知识结构原语。SVG、Canvas 或图表可以替代这些原语；硬要求是关系在画面几何中直接成立，而非仅靠标题或讲解文字说明。

## 4. 交互的规矩

- 同一个关系只使用一种主要交互路径，不用多个控件重复得到同一结论。
- 教学常量、范围、初值和结果来自 `Lec.K` / `Lec.P`，并在页面运行时当场计算；禁止预录结果、硬编码派生答案或使用假数据。
- 随机过程必须使用固定种子，保证同种子同序列。首屏必须静止且已包含可讲信息，不依赖自动播放才成立。
- 交互页必须给出明确、就近的操作提示。
- 滑块、切换和游标是观察仪器；没有目标态时不得编造“正确/错误”。只有分拣、配对、拼装等本来存在确定答案的任务才判定正确性。
- 未规划交互的页面不得添加装饰性拖拽、悬停、点击、自动动画或伪控件。
- 无交互页为 01、02、19。

## 5. 技术契约

固定骨架：

    <!doctype html>
    <html lang="zh">
    <head>
      <meta charset="utf-8">
      <link rel="stylesheet" href="assets/base.css">
      <link rel="stylesheet" href="assets/theme.css">
    </head>
    <body data-page="NN" data-total="19">
      <div id="stage"></div>
      <script src="assets/base.js"></script>
      <script src="assets/lec.js"></script>
    </body>
    </html>

- 只修改 `#stage` 内容。保留两位 `data-page` 和 `data-total="19"`，不得把页码显示给读者。
- 逻辑画布固定为 1600 × 900，不得滚动。`#stage` 是 flex 列；顶层区块使用固定高度或 flex 份额，主内容区使用 `flex:1`。
- 字号只用主题 token。正文与成句说明 ≥16px；控件标签、图例、图注、提示 ≥14px；纯数字刻度 ≥12px；多行文字行高 ≥1.35。
- 颜色、字体、圆角、阴影和共享组件取自主题接口。一次性尺寸可内联，不为单页尺寸创建公共类。
- 不移除或覆盖 `.min0`、`.cv-fill`、`.no-pan` 的机制。缩放画布内禁止 `position:fixed`。
- 默认使用 flex；仅在真正二维对齐时使用 grid。
- 页面必须自包含运行，只引用 `pages/` 内相对路径，不使用 CDN。
- 图表优先使用已安装库，不重复实现成熟能力。ECharts 必须使用 SVG renderer，并显式设置符合字号地板的全局文字、轴、图例与 tooltip 字号。
- Canvas 使用 `Deck.fit()` / `Deck.autofit()`；指针坐标使用 `Deck.pt()`；动画使用 `Deck.loop()`。
- Konva 场景文字优先用 DOM 叠加；必须使用 `Konva.Text` 时显式设置合规字号。
- KaTeX 同时引用 CSS 与 JS；基准字号统一 ≥20px。
- TensorFlow.js 仅用于预训练模型、真实图片卷积或 GPU 级大矩阵；逐帧小型二分类训练使用 `mlp.js`。创建张量时必须 `tf.tidy()` 或手动 `dispose()`。
- 新增库也必须放在 `pages/` 下本地引用；用不到的库不加载。

| 用途 | 库 |
|---|---|
| 物理、碰撞、约束 | Matter.js |
| 三维场景 | Three.js |

| 可拖拽二维场景、命中检测 | Konva |
| 节点连线、矢量与数据绑定 | D3 |
| 大量元素运动 | PixiJS |
| 分步、路径与形变动画 | anime.js |
| 精确动画时间线 | GSAP |
| 滚动绑定动画 | GSAP + ScrollTrigger |
| 矢量动画文件 | lottie-web |
| 伪三维插画 | Zdog |
| 指针倾斜 | Vanilla Tilt |
| 进入视野淡入 | AOS |
| 数学公式 | KaTeX |
| 矩阵运算 | ml-matrix |
| 可复现随机 | seedrandom |
| 实时小型二分类网络 | `mlp.js` |
| 预训练模型、卷积与 GPU 大矩阵 | TensorFlow.js |

`Lec` 公开接口必须原样使用，不复制实现：

`Lec.K(常量)`：`AU_KM`、`DAY_SECONDS`、`DEG_TO_RAD`、`J2000_JD`、`J2000_OBLIQUITY_DEG`、`JULIAN_YEAR_DAYS`、`MEAN_SIDEREAL_DAY_HOURS`、`NAKED_EYE_LIMIT_MAG`、`PLANETS`、`RAD_TO_DEG`、`UNIX_EPOCH_JD`。

## 6. 图片

优先使用 `assets/img/IMG.md` 已登记素材，不重复下载或生成。按素材索引填写 `<img title="…">`。出处与许可不进入主画面。生成插画自带的“AI生成”角标必须完整可见，不得被内容、裁切或遮罩遮挡。图片仍须服从暗适应、低亮度和本页教学证据要求，不得退回深空照片画廊方向。

## 7. 文字风格

- 面向无天文学、球面几何或编程基础的大学通识课学生；首次出现的必要术语用一句人话解释，不展开专业推导。
- 使用教师可直接讲出的短句；一句只承担一个判断或动作，避免长串从句。
- 操作提示使用直接、具体、非责备口吻，如“转动纸图，让北方标记朝向真实北方”。
- 删除“如图所示”“接下来我们将”以及评价教学设计的元评论。
- 关键数字同时给可感换算；例如天数配“隔几晚再看”，角度配手掌或天空范围，但换算必须来自本页规格或运行时计算。
- 线索写成线索，不确定结论明确使用“可能”“候选”“还不能确认”。
- 不把“亮”“偏黄”“少闪烁”写成证明；不把“图上没有”单独写成最终确认。
- 收束句给出本页应带走的主张；下一问负责推进，不把收束写成本页摘要。
- 文字集中在一侧；每页至少保留画面面积 30% 的空黑区。

## 8. 自检

完成后使用 `Check` 检查本页：

- JS 错误为 0。
- 资源加载失败为 0。
- 元素越界为 0。
- 非设计性裁切为 0。
- 字号符合正文、标签、刻度的分层地板。
- 交互页覆盖每个主要状态，包括初始态、操作中状态、边界态和结果态。
- 随机输出可复现，运行时结果与文字一致。
- 问题区域先用 `Look` 查看，再用 `Patch` 合并修复，避免零散覆盖。
- 最终只交付本页 HTML；不修改公共资源，不增加测试、截图或报告文件。

## 9. 版面密度与常见坑

- 主内容用 flex 吃满剩余空间，不给普通内容块写死高度。
- 画面占用低于 45% 时，先检查失控的 flex 空隙，再放大有教学意义的关系；不得添加装饰撑满。
- 画面占用高于 85% 时，删减内容或报告需要拆页；不得缩小字号规避。
- 骨架与包裹层优先用线、缩进和层级表达，不堆叠多层填色卡片。
- 每页至少保留 30% 空黑区；空黑区不得被无意义星点、纹理或发光背景填满。
- 星点使用无描边圆点，点径按视星等分四档。定位所需星座辅助线为 1.5px 实线；黄道为 3px 长虚线。
- 行星候选使用开放圆环，确认对象使用双圆环；圆环不得遮挡亮点。
- 卡片和步骤框使用 8px 小圆角、无投影、硬边分区。
- 无衬线用于标题、正文和操作指令；衬线仅用于纸质星图式方向名称与观测记录标题；等宽字体仅用于时刻、方位角和两次观测记录。
- 照片使用主题已有的边框、圆角和底图规则。
- Canvas 交互区必须添加 `.no-pan`。
- 不采用高亮深空照片画廊、霓虹科幻驾驶舱或大面积白底教科书样式。
