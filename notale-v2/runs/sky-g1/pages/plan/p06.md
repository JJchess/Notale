# page-06 · 把星图举到天空里 · **115 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `HOLD THE CHART` |
| 主标题 | 别把星图当墙上的地图：面对哪边，就让图上哪边朝向真实天空 |
| 收束句 | 看南方时让“南”朝真实南方；看北方时让“北”朝真实北方，并把图举到头顶比较。 |
| 下一问 | 姿势对了，先用哪几个星点确认图与天空真的重合？ |

## 知识结构：comparison

1. **关系不变量**：左右两栏必须同尺度、同地平线基线、同人物视角；人物、面对方向箭头、头顶星图和对应方向边缘必须在每栏内连成一条方向关系。
2. **禁止画法**：不得把南北两种持法拆成视角不同、大小不同的独立卡片，否则学生会把差异误读为两张不同星图。
3. **共享原语**：`.split-lr` 承载“面向南方 / 面向北方”并列；`.k-comparison` 锁定同行基线与镜像关系；`.panel.q` 只包住操作提示，不切断人物—星图—真实方向的连线。

## 表征形式

交互式双栏姿势示意：每栏显示同一人物侧后方剪影、水平地平线、真实方向箭头及可拖动的圆形纸质星图。采用 Konva 绘制人物、星图边框、方向连线和命中区；方向名称用 DOM 叠加，保证投影可读。

两栏共享人物与星图尺度。拖动时通过 Konva `dragmove` 更新星图位置、倾角和方向边缘连线；离散按钮切换“面向南方 / 面向北方”。不使用透视 3D，不让远近缩放承担判断。

## 两种持图姿势

| 比较项 | 面向南方 | 面向北方 |
|---|---|---|
| 真实方向 | 身前箭头标“南” | 身前箭头标“北” |
| 图面 | 举过头顶，印刷面朝向自己 | 举过头顶，印刷面朝向自己 |
| 对准边缘 | 图上“南”边朝真实南方 | 图上“北”边朝真实北方 |
| 画面提示 | `南 ↔ 真实南方` | `北 ↔ 真实北方` |
| 常见错误 | 竖在胸前，像看墙上地图 | 沿用看南方时的持法，不随转身调整 |
| 达成反馈 | `姿势已对：抬头即可逐区比较` | `姿势已对：转身后方向边缘也已换位` |

星图内部只放三颗无名称的固定星点和两条短辅助线，用于辨认同一张图；不出现黄道、行星或星座名称。

## 交互

学习者拖动星图，从胸前竖直位置移到头顶观看位置，并旋转图面，使当前方向边缘与身前真实方向箭头一致。默认状态为“面向南方”、星图竖在胸前且方向边缘错置。

提供“面向南方”“面向北方”按钮；切换后人物转身、真实方向箭头和目标边缘同步改变，但星图保持学习者上一步姿势，迫使其重新校正。拖拽接近头顶且对应边缘夹角不超过 12°时，连线改为琥珀黄并显示达成反馈；否则只显示低亮提示“先举过头顶，再让方向名称朝向同一真实方向”。

支持方向键微调旋转、空格键在胸前与头顶位置间切换；“重新开始”恢复默认错误姿势。

## 动效

切换面对方向时，人物与地面箭头在 320 ms 内水平镜像；星图不自动旋正。达成时仅让对应方向边缘与真实方向箭头之间的连线亮起 220 ms，不旋转整片星空。`prefers-reduced-motion` 下直接切换终态。

## 主工作流

design-interaction ← 让拖动、转身与方向边缘校正共同形成可验证的持图姿势

## 不许碰

不绘制或说明黄道搜索带，黄道定位归 p09。不得借本页讲时刻旋转、行星位置或跨夜移动；本页只校正看南方与看北方时的持图姿势。
