## 知识结构：classification

**关系不变量**：四条线索必须作为同一份候选记录的同行字段，共用“较弱—较强”基线；下方三名候选按相同字段汇总，并嵌套进“排除 / 暂留 / 优先核对”三级结果。

**禁止画法**：不得把四条线索拆成四张互不对齐的卡片或画成四个等权投票按钮，否则会误示“满足任一项即可确认”或“四票多数决”。

**共享原语**：`.ledger.k-classification` 以记录表承载同字段比较和三级归类；`.panel` 包住候选记录主体，`.tag` 只标示当前筛选结果，不标“恒星/行星”结论。

## 表征形式

交互式线索权重判别表。使用原生 DOM 与 SVG：DOM 承担可读文字、单选控件和反馈；SVG 绘制贯穿各行的共享强弱基线及开放候选圆环，无需图表库。选择线索描述后切换 class，实时更新各行刻度、结果标签与一句反馈；不显示总分数字，避免伪精确。

## 四条线索与三份记录

| 字段 | 画面文字 | 判别作用 |
|---|---|---|
| 黄道位置 | 在搜索带内 / 边缘 / 带外 | 主筛选；带外通常先排除，带内仍不能确认 |
| 亮度 | 很醒目 / 普通可见 / 很暗 | 中等线索；亮点优先看，但亮恒星也可能很醒目 |
| 闪烁 | 较稳定 / 轻微 / 明显 | 条件线索；较稳定会加分，低空目标即使是行星也可能闪 |
| 颜色 | 白黄、偏红或难判断 | 弱线索；颜色可帮助描述，不能单独辨认种类 |

| 候选 | 黄道位置 | 亮度 | 闪烁 | 颜色 | 初始归类 |
|---|---|---|---|---|---|
| A | 带内 | 很醒目 | 较稳定 | 白黄 | 优先核对 |
| B | 带内 | 普通可见 | 明显 | 偏红 | 暂留 |
| C | 带外 | 很醒目 | 较稳定 | 白黄 | 通常先排除 |

结果区固定备注：`“优先核对”仍只是候选，不等于已经认出行星。`

## 交互

学习者先点选 A、B、C，再分别改动四个字段；每个字段均为三档离散按钮，默认使用表中记录。结果即时落入“通常先排除 / 暂留 / 优先核对”，并突出造成变化的那一行。

规则固定：带外直接进入“通常先排除”；带内或边缘才综合其余三项。亮度与稳定程度可提升优先级，明显闪烁可降低但不直接排除；颜色只改变描述与轻量提示，不得单独改变最终等级。

当学习者试图仅凭“很亮”“不闪”或“偏红”作结论时，反馈：`这只能调整候选顺序，不能定案。` 点击“恢复三份记录”回到默认状态；键盘可用方向键换档，数字 `1–3` 切换候选。

## 动效

字段改变后，开放圆环沿共享强弱基线水平移动 24–48 px，时长 180 ms；结果标签在圆环停止后延迟 80 ms 更新。切换候选时只交叉淡化记录内容 120 ms；减少动态模式下取消位移，仅即时切换状态。
