## 1. 这堂课在讲什么

这堂课教学生把纸质星图当作现场比对工具，而不是行星照片册：先把日期、时刻、方向和地平线对准真实天空；再用恒星图样作为稳定背景；最后用位置、黄道与隔日位移确认行星。

- I（01–07）：配准星图。任务是让纸图的地点、时间、方向和地平线与天空对应。
- II（08–12）：找可疑亮点。任务是在稳定恒星图样中发现黄道附近、不属于图样的亮点。
- III（13–16）：比较证据。任务是区分“帮助筛选”的亮度、颜色、闪烁，与“可复查”的位置证据。
- IV（17–20）：留下记录。任务是记录候选相对邻近亮星的位置，并在之后复看位移。

证据链必须保持：配准星图 → 恒星图样作背景 → 黄道附近的异常亮点 → 相对恒星记录 → 隔日位移验证。

E1：未按本地日期时间、朝向和地平线配准的纸图不能作参照。  
E2：一次观测中恒星图样可视为固定；肉眼行星通常在黄道附近，且不完全落在星图恒星位置上。  
E3：亮度、颜色、闪烁不能单独认定行星；“图上没有的亮点＋黄道附近”才是强候选。  
E4：记录候选相对恒星的位置，并在之后复看位移，才能把猜测升级为验证。

无交互页：01、03、07、12、16。不得为其添加装饰性操作。  
“不许碰”的内容由别页负责；不得提前讲完、重复演示或替别页下结论。

## 2. 颜色语义

| token / 色相 | 唯一含义 | 允许出现的位置 |
|---|---|---|
| `--night` / `#07111F` | 夜间观察环境与非信息底面 | 页面底色、大块留白、远景天空 |
| `--map-cyan` / `#86BBD8` | 已配准的星图坐标、恒星连线与刻度 | 纸质星图、配准标记、星座细实线、刻度、已对齐方向 |
| `--observe-yellow` / `#FFD166` | 当前正在寻找、比较或记录的唯一候选目标 | 单一候选亮点的圆环、当前比较位置、当前日志字段 |
| 中性白／灰蓝 | 普通文字、未强调线条、纸图框、背景恒星 | 标题、说明、普通恒星、边界、图例 |

语义色不得挪作装饰。恒星亮度用圆点大小与亮星四短芒表达，不靠颜色。星座连线一律细实线；黄道一律宽虚线；方向与地平线一律粗弧线；候选行星一律为黄环包住亮点。无概念含义的元素使用中性色。

## 3. 知识结构——骨架约定

容器不是知识关系，不以“卡片网格”或“左右两栏”代替结构。卡片只区分可操作与可看：可操作区域用圆角卡片，静态证据用无圆角图纸框。

| 结构 | 必须直接看见的关系 | 最低几何要求 | 失败形态 |
|---|---|---|---|
| process | 先后、因果或状态推进 | 可见方向轴、箭头或连续路径 | 只有并排块 |
| comparison | 同一维度上的差异 | 同行、同尺度、同基线 | 两边各画各的 |
| classification | 上下位或部分—整体 | 嵌套、包含或明确缩进 | 同级平铺 |
| generalization | 主张与支撑 | 主张更重，支撑挂在同一主干 | 主张和证据同权 |

优先使用 `theme.css` 的 `.k-*` 结构原语。SVG、Canvas 或图表可替代 `.k-*`；硬要求是先后、比较、包含、支撑等关系必须在画面几何中成立，而非仅靠文字说明。

## 4. 交互的规矩

- 同一个关系只使用一种主要交互路径，不用多个控件重复导向同一结论。
- 教学常量、范围、初值和结果必须来自 `Lec.K` / `Lec.P` 并当场计算；禁止预录结果、假数据或与控件脱节的数字。
- 随机过程必须固定种子。首屏静止状态已经包含可讲信息。
- 交互页必须给出明确操作提示。
- 滑块、切换和游标是观察仪器；没有目标态时不得编造对错。
- 只有分拣、配对、拼装等本来有答案的任务才判定正确性。
- 未规划交互的页面不得添加装饰性操作。
- 交互应服务“对准、比图、筛选、记录、复查”之一；不得改造成太阳系漫游、摄影辨识或霓虹界面。

## 5. 技术契约

固定骨架：

    <!doctype html>
    <html lang="zh">
    <head>
      <meta charset="utf-8">
      <link rel="stylesheet" href="assets/base.css">
      <link rel="stylesheet" href="assets/theme.css">
    </head>
    <body data-page="NN" data-total="20">
      <div id="stage"></div>
      <script src="assets/base.js"></script>
      <script src="assets/lec.js"></script>
    </body>
    </html>

- 只修改 `#stage` 内容；保留两位 `data-page` 和 `data-total`，不把页码显示给读者。
- 逻辑画布固定为 1600 × 900，不得滚动。`#stage` 是 flex 列；顶层区块给固定高度或 flex 份额，主内容区使用 `flex:1`。
- 字号只用主题 token。正文与成句说明 ≥16px；控件标签、图例、图注和提示 ≥14px；纯数字刻度 ≥12px；多行文字行高 ≥1.35。
- 颜色、字体、圆角、阴影和共享组件取自主题接口。一次性尺寸可内联，不为单页尺寸新增公共类。
- 不移除或覆盖 `.min0`、`.cv-fill`、`.no-pan` 的机制；缩放画布内禁止 `position:fixed`。
- 默认用 flex；只有真正二维对齐时用 grid。自包含运行，只引用 `pages/` 内相对路径，不用 CDN。
- 图表优先使用已安装库，不重复实现成熟能力。ECharts 必须使用 SVG renderer，并显式设置可读字号。
- Canvas 使用 `Deck.fit()` / `Deck.autofit()`；指针坐标使用 `Deck.pt()`；动画使用 `Deck.loop()`。
- `Lec` 仅按 `assets/lec.js` 公开接口使用；不得依赖未公开字段或改写其实现。

| 用途 | 库 |
|---|---|
| 常规坐标图表 | `echarts` |
| 可拖拽二维场景、命中检测 | `Konva` |
| 矢量关系图、数据绑定 | `d3` |
| 分步动画、路径描绘 | `anime` |
| 精确动画时间线 | `gsap` |
| 可复现随机 | `Math.seedrandom` |
| 物理拖拽、碰撞、约束 | `Matter` |
| 三维场景或球面地球 | `THREE`、`Globe` |
| 数学公式 | `katex` |

ECharts：`echarts.init(dom, null, {renderer:'svg'})`；全局文字 ≥16px，含词句的轴标签、图例、轴名 ≥14px，纯数字刻度可为 12px。  
Konva：图形可用 Konva；场景文字优先用 DOM 叠放，避免默认小号 `Konva.Text`。  
随机生成的点、样本或抽样必须显式使用固定种子，如 `new Math.seedrandom('page-NN')`。  
KaTeX 同时引入本地 CSS；复杂公式基准字号 ≥20px。  
不用的库不引入；新增库必须置于 `pages/` 内本地引用。

## 6. 图片

优先使用 `assets/img/IMG.md` 已登记素材，不重复下载或生成。按索引填写 `<img title="…">`。出处和许可不进入主画面。生成插画的“AI生成”角标不得被内容遮挡。

照片不是主视觉；优先使用高对比矢量线条、纸图边注、地平线弧、旋转星图边框、恒星连线、黄道与候选环。避免依赖暗部摄影细节、微弱星点或多色霓虹区分信息。

## 7. 文字风格

面向无天文学、球面几何和编程基础的大学通识学生。先说可做动作，再给必要术语；术语首次出现用一句日常语言落地，例如“黄道：太阳和多数行星常出现的一条天空路径附近”。

使用讲课短句。一个提示只要求一个动作。用“把北字朝向北边”“找不属于连线图样的亮点”“记下它靠哪颗亮星”这类现场口吻。避免长定义、公式堆叠和抽象术语链。

删除“如图所示”“接下来我们将”和评价教学设计的元评论。关键数字给可感换算；不确定结论明确标注“可能”“候选”“需隔日复查”。收束句给出可带走的主张；下一问负责推进，不写成本页摘要。

页角观测日志字段统一为：日期、时刻、方向、邻近亮星。短记录可用衬线体；日期、时刻、方位和角距离等现场数据用等宽体。

## 8. 自检

完成后用 `Check` 检查本页：JS 错误、资源失败、越界、裁切均为 0，字号符合分层地板。交互页必须覆盖每个主要状态；问题区域先用 `Look` 查看，再用 `Patch` 合并修复。

检查首屏：不操作也能讲清当前关系；当前候选最多一个黄环；青蓝仅表示已配准星图信息；黄道为宽虚线；方向和地平线为粗弧线；至少一侧保留大块深色留白。

最终只交付本页 HTML，不改公共资源，不增加测试或报告文件。

## 9. 版面密度与常见坑

- 主内容用 flex 吃满剩余空间，不给普通内容块写死高度。
- 画面占用低于 45% 时，检查失控的 flex 空隙并放大有教学意义的关系；不要加装饰撑满。
- 画面占用高于 85% 时，删减或报告需要拆页，不缩字号。
- 骨架和包裹层优先用线、缩进和层级表达，不堆叠多层填色卡片。
- 每页至少保留一侧大块深色留白，供教师在穹幕下指向单一对象。
- 照片使用主题已有的边框、圆角和底图规则；Canvas 交互区加 `.no-pan`。
- 不把纸质星图画成行星照片册；不以颜色、亮度或闪烁单独断言行星；不以复杂三维太阳系替代纸图与天空的几何对照。
