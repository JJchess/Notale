# 《肉眼看夜空：怎样用一张星图认出行星》 30 分钟互动讲义 · 总规划

## 0. 这套讲义的主线

一张纸质星图不是“行星照片册”，而是把某时某地的恒星背景对准天空后，用“偏离恒星图样、靠近黄道、隔日会移动”三条证据确认行星的现场工具。

| 章 | 页 | 这一章要让读者信什么 |
|---|---:|---|
| I. 先让星图对准天空 | 01–07 | 星图只有在地点、时间、方向都对上后，才是可用的天空参照。 |
| II. 在恒星背景中找到可疑亮点 | 08–12 | 恒星图样相对稳定；行星是黄道附近“不属于图样”的亮点。 |
| III. 用证据而不是印象认出行星 | 13–16 | 亮度和颜色只能帮助筛选，位置与恒星图样才是主要证据。 |
| IV. 到户外完成一次可复查的指认 | 17–20 | 一次指认必须留下可复核记录；隔日相对恒星的位置变化能确认行星。 |

- E1：纸质星图必须先按本地日期时间、朝向和地平线方向与真实天空配准，才能作为恒星背景使用。
- E2：恒星之间的图样在一次观测中可视为固定；肉眼可见行星通常出现在黄道附近，并与星图中的恒星位置不完全重合。
- E3：亮度、颜色和是否闪烁都不是单独可靠的身份证；“星图上没有的亮点”加“位于黄道附近”才构成强候选证据。
- E4：对候选亮点记录相对恒星的位置，并在之后复看其位移，能把“猜测”升级为可验证的行星辨认。

## 0.5 视觉世界

- 现实参照：天文馆观测日志与纸质星图边注；它直接对应学生手中将带到户外的纸图，穹幕远距离观看时可用大字、粗线和明确的方向标记阅读。
- 形状语言：
  1. 恒星以大小不同的圆点表示，亮星加四短芒，避免只靠颜色区分亮度。
  2. 星座连线一律为细实线，黄道一律为宽虚线，方向与地平线一律为粗弧线。
  3. 行星候选一律使用“圆环包住亮点”的外形，不与恒星圆点混淆。
  4. 可操作区域采用圆角卡片，静态证据采用无圆角的图纸框，区分“可做”和“可看”。
  5. 每页保留至少一侧大块深色留白，让教师在穹幕下用手势指向单一对象，避免密集文字漂浮在暗背景中。
- 底色：深夜蓝黑 `#07111F`；接近夜空但不使用纯黑，保留纸图线条和白字在低亮投影下的对比。
- 主色相：星图青蓝 `#86BBD8`，唯一代表“已配准的星图坐标、连线与刻度”。
- 强调色：观测黄 `#FFD166`，只用于当前正在寻找、比较或记录的一个候选目标。
- 字体：无衬线体承担标题、说明和按钮，保证穹幕远距离识读；衬线体仅承担纸质观测日志中的短记录，提示“可抄写”；等宽体仅承担日期、时刻、方位和角距离等现场数据。
- 材质：以线性图纸为主；夜空、地平线、星点和纸图边注都用高对比矢量线条，避免暗场中照片细节丢失。
- 母题：
  1. 带北、东、南、西方位字母的地平线弧。
  2. 可旋转的圆形星图边框。
  3. 青蓝色恒星连线与宽虚线黄道。
  4. 黄环包住的单一候选亮点。
  5. 页角“观测日志”字段：日期、时刻、方向、邻近亮星。

被否决的整体方向：

- 被否决：真实夜空摄影主导。理由：穹幕接近全暗时，照片阴影细节和微弱星点难以辨认；学生真正需要练的是纸图与天空的几何对照，不是辨识摄影曝光效果。
- 被否决：霓虹科幻界面。理由：多种高饱和色会把恒星、黄道、候选行星和交互提示混为一谈，且会破坏纸质星图的迁移关系。
- 被否决：复杂三维太阳系漫游。理由：30 分钟内学生的现场任务是向天空抬头、转图、比图和记录，不需要建立行星轨道尺度或三维球面几何模型。

## 0.6 对这个受众的取舍

- 能用：方向感、手臂伸直后的拳头角距直觉、看地图时“先定自己位置再找目标”的经验、识别熟悉图形轮廓的能力。
- 不用：赤经赤纬、黄赤交角、球面三角、岁差、开普勒定律、星等公式、望远镜寻星镜操作。
- 换算：角距离统一换成“手臂伸直时一拳约 10°、三根手指约 5°、一根小指约 1°”的现场尺度。
- 争议：行星当晚是否可见受地点、时刻、地平线遮挡、天气和光污染影响；亮度与颜色会随高度、大气、相位和个人视觉而变化。

## 0.7 要用的图

本套无需图池。所有承担证据、场景和操作的图均为可缩放的星图、地平线、黄道、候选亮点与观测日志矢量组件，以保证暗场投影清晰并与纸质星图一致。
