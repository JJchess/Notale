# page-06 · 地平线先删掉一半天空 · **115 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `STEP 03 · CUT THE HORIZON` |
| 主标题 | 星图上的星，不一定在你眼前 |
| 收束句 | 地平线以下的星仍在星图上，但此刻不在可见天空里。 |
| 下一问 | 删去看不见的半边后，哪几颗亮星能把纸图钉在天空上？ |

## 知识结构：process

1. **关系不变量**：一张已配准的圆形星图由同一条粗地平线弧切成上下两区；弧线上方的恒星保持青蓝可见，弧线下方的同尺度恒星被压暗并从搜索范围排除。
2. **禁止画法**：不得把“可见”和“不可见”拆成两张独立小星图；学生必须看见同一组恒星被同一条地平线裁切。
3. **共享原语**：`.canvas-full` 承载整张圆形星图与大块夜空留白；`.k-process` 以“完整星图 → 地平线裁切 → 可见半边”沿同一圆心推进；`.panel.q` 只承载操作提示与结果句，不与星图争夺视觉中心。

## 表征形式

交互式矢量星图：圆形纸质星图边框、青蓝恒星点与连线、宽虚线黄道、粗地平线弧，以及地平线以下的深色裁切蒙层。

- 使用原生 DOM + SVG；恒星、弧线和裁切路径需要精确共用圆心、半径与命中区域，且暗场投影下 SVG 线条比 Canvas 更易保持清晰。
- 星图固定为同一尺度；地平线使用粗弧线，黄道保持宽虚线但不作为本页讲解对象；方向字母仅保留 `E`、`S`、`W` 作为已配准提示。
- 初始状态显示完整星图，但地平线以下恒星已降至低对比；操作后切换 `.cut` class，使下半区被深夜蓝黑蒙层覆盖、恒星与连线淡出。
- 通过切换 class 更新 SVG `clipPath`、提示文字和按钮状态；键盘以 Enter/Space 触发，不依赖拖拽。

## 主工作流

design-interaction ← 用一次可逆的地平线裁切，让“图上存在”与“眼前可见”成为同一画面中的空间区别

## 可见天空裁切表

| 画面层 | 文字或对象 | 状态 |
|---|---|---|
| 星图顶部标签 | `已配准 · 面向南方` | 常显 |
| 粗弧线标签 | `地平线` | 常显，贴近弧线中央 |
| 弧线上方 | `眼前可见的天空` | 青蓝星点、细实线星座连线可见 |
| 弧线下方 | `星图上有，但在地平线以下` | 初始低对比；裁切后不显示星点与连线 |
| 操作按钮 | `切开地平线以下` | 初始可用 |
| 操作后反馈 | `现在只用上半边和真实天空比对。` | 裁切后显示 |
| 侧边提示 | `先删去看不见的半边，再认亮星。` | 常显 |

## 交互

学习者点击或按键触发 `切开地平线以下`。

- 默认：整张圆形星图可见；地平线以上恒星为青蓝，以下恒星为低对比青灰，仍可辨认其“在图上存在”。
- 触发后：地平线以下区域由深夜蓝黑蒙层完全覆盖；弧线上方保持不动，黄道仅保留其可见段；按钮改为 `还原整张星图`。
- 再次触发可还原，状态始终可逆。
- 形成的直觉：纸图不是把所有印出的星都交给眼睛寻找；先按地平线裁掉不可见区域，剩余图样才可与眼前天空逐颗比对。
- 无成功或失败判定；教师可先问“下半边的星消失了吗？”再执行裁切，强调消失的是可见性，不是恒星本身。

## 动效

点击后，地平线以下蒙层自粗弧线向下展开，位移覆盖至圆形边框底部，时长 `320ms`；下方星点与连线在前 `160ms` 淡出。还原时反向执行。启用减少动态时直接切换状态。

## 不许碰

不解释树木、建筑、云层、光污染或天气造成的遮挡；这些现场条件归 p18。不得讨论行星候选、黄道搜索或亮度判断；本页只完成“地平线以下不进入当前比对范围”的裁切。
