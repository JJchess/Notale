# page-20 · 把猜测变成可复查的判断 · **75 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `EXIT CHECK` |
| 主标题 | 说清证据链，才算完成一次辨认 |
| 收束句 | 今晚先记录“行星候选”；明天比较它相对恒星的位置。 |
| 下一问 | 走到户外后，你能用这句话为自己的候选留下证据吗？ |

## 知识结构：generalization

1. **关系不变量**：中心黄环候选与四条证据必须连成一条连续判断链：已配准星图 → 图样缺口 → 黄道附近 → 次日复看相对恒星位置；结论置于链尾，不得脱离证据单独出现。
2. **禁止画法**：不得把“亮、颜色、少闪烁”画成与四条主证据同权的确认条件。
3. **共享原语**：`.focus` 将黄环候选固定为单一视觉焦点；`.k-generalization` 以一条从证据到行动的主干组织判断；`.quiz` 承担出口陈述的选择与反馈。

## 表征形式

静态 SVG 证据链加单题出口判断。原生 DOM/SVG 更适合：黄环、青蓝星点、宽虚线黄道和箭头均需与纸质星图图例一致；文字保持 `--fs-body` 以上，现场字段使用 `--font-mono`。选择后切换 `.opt`、`.fb` 的正确/待改状态；不使用图表库。

## 主工作流

design-interaction ← 将四项既有证据压缩为可判断、可反馈的一句现场记录

## 四条证据与出口陈述

| 区域 | 画面文字 | 视觉编码 |
|---|---|---|
| 证据 1 | 星图已按地点、时刻和方向配准 | 青蓝星图圆框 |
| 证据 2 | 亮点不在星图对应的恒星图样中 | 黄环与空出的图样位置 |
| 证据 3 | 它在黄道上下约一拳宽的搜索带内 | 青蓝宽虚线黄道 |
| 证据 4 | 明天记录它相对两颗邻近亮星的位置 | 两颗青蓝亮星与细量距线 |
| 题干 | 哪一句能作为今晚的出口记录？ | 居中 `.quiz` |
| A | 它最亮，所以我确认它是行星。 | 错误选项 |
| B | 它不太闪，颜色偏白，所以我确认它是行星。 | 错误选项 |
| C | 我把它记为行星候选：它偏离已配准星图的恒星图样、在黄道附近；明天比较它相对两颗邻近亮星的位置。 | 正确选项 |

## 交互

学习者点选 A、B 或 C，默认未选。选 A 或 B 后，立即在该选项下显示“亮度、颜色和闪烁只能辅助筛选；还缺少位置证据与复看动作。”选 C 后，四条证据依次点亮，中心黄环由“候选”标记为“可复查记录”，反馈为“可以出发：今晚记下位置，明天看它是否相对恒星移动。”允许改选；“重新判断”清空选择并熄灭证据链。
