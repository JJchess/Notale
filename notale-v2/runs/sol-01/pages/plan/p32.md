# page-32 · 冰层之下 · **110 秒**

## 知识结构：generalization
用一条由具体对象通向一般判断的主干显式化迁移：欧罗巴表面切片 → 潮汐形变产生内部热 → 冰下可长期保留液态海洋 → 宜居环境不必位于受恒星照亮的行星表面。左侧可判读切片提供个案证据，右侧将“能量来源—液态介质—环境位置”对齐为因果箭头，承接 p31 的宜居条件框架。

## 表征形式
动态交互切片。以欧罗巴真实圆盘为外层，指针移动时用圆形扫描窗揭示与球体轮廓对齐的科学剖面；三轮判读依次定位海洋、热源与完整能量链。剖面只表达层次和机制，不伪装成精确比例。

## 四条支撑
1. 冰壳：寒冷表面之下存在隔绝外界的内部环境。
2. 地下海洋：液态介质可以藏在不受阳光直接照射的位置。
3. 潮汐形变：木星引力随轨道位置改变，反复拉伸欧罗巴内部。
4. 能量迁移：形变耗散成热，帮助地下水体避免完全冻结，并把 p31 的宜居框架推广到冰卫星。

数值与对象信息只取 `Lec.K.REFERENCE`、`Lec.K.PLANETS`；需要显示相对量时使用 `Lec.P.ratio`、`Lec.P.significant`，不得另建欧罗巴参数或写死数值。

## 必须点出来的一到三句
宜居环境不只存在于恒星照亮的行星表面：潮汐加热可以为冰层下的液态海洋持续供能。

## 交互（只有这一个）
读者移动扫描窗揭开欧罗巴切片，并按提示点击“液态水在哪里”“热从哪里来”“哪条箭头构成完整机制”；画面从层次识别推进到因果链，形成“内部能量也能支持宜居环境”的直觉。

做对了立刻看到什么：目标层以强调色描边发光，对应说明与因果箭头接通，扫描窗短暂停驻后进入下一问。  
做错了立刻看到什么：所点区域轻微横向抖动并变暗；分别提示“这是冰壳，不是液态水层”“潮汐形变发生在内部，不是来自表面阳光”“还缺少从形变到热、再到海洋的连接”。  
做到哪儿了怎么知道：右上固定显示三段能量链，已完成段点亮，并标示“判读 1/3、2/3、3/3”。  
做完了怎么收：扫描窗扩展为完整剖面，木星 → 潮汐形变 → 内部热 → 地下海洋整链发光，右侧主张定格；提供重置图标一键回到未揭示状态。

## 场景构图
母题采用“带昼夜分界线的行星圆盘”“发光轨道环”“半透明测量标记”。底色深空，左侧约六成宽放置从暗面浮出的欧罗巴真实圆盘，木星方向以一段青色轨道弧和细引力线提示；扫描窗内出现冰壳、海洋、岩石内部的同心切片。右侧不是独立卡片，而是沿同一高度排开的三节点因果链。Kicker 为 `HABITABILITY / BEYOND SURFACES`，主标题为“冰层之下，也可能有宜居环境”。

## 动效
入场：欧罗巴从左侧暗处缓慢转入，轨道弧随后描出，右侧三个空节点自上而下显现。  
反馈：正确时亮线从所点层流向下一节点；错误时扫描窗收缩一下并回弹，提示贴近误点位置出现。

## 不许碰
不判断欧罗巴是否存在生命，不展示生物、细胞或“发现生命”措辞；不把液态水等同于生命，不给出生命概率。只讲潮汐加热支持地下海洋这一机制迁移，不展开轨道共振推导、探测任务史或冰壳厚度争议。
