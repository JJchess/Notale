# page-02
采用 `.split`，标题写“先拆开一个神经元”，左侧画两个输入端口汇入求和节点再经过激活函数，实际标签完整出现为“输入 x₁、x₂”“权重 w₁、w₂”“偏置 b”“加权和 z = w₁x₁ + w₂x₂ + b”“输出 ŷ = σ(z)”；右侧用一条总括句“权重决定听谁的，偏置决定整体门槛，激活函数决定怎样响应”，并列出形状：x∈ℝ²、w∈ℝ²、b∈ℝ、ŷ∈(0,1)。这一页要让读者相信一个神经元首先是一个可计算函数，靠端口、公式与形状一一对齐来证明；所有量均为无量纲教学变量，出处为本页定义，不安排交互，也不谈误差如何回传，那归 page-10 至 page-12。
