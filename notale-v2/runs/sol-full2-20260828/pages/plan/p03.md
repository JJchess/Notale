# page-03
采用 `.workbench`，标题写“亲手做一次前向计算”，主画布把 x₁=0.60、x₂=−0.40 经过 w₁=0.80、w₂=−0.50 与 b=0.10 汇成 z=0.78，再显示 σ(z)=1/(1+e⁻ᶻ)=0.686；右侧控制区提供 w₁、w₂ 的 −2.00 至 2.00 滑杆和 b 的 −1.00 至 1.00 滑杆，步长均为 0.05，拖动时每条乘积、z 与 ŷ 即时更新，按钮写“复位到 0.80, −0.50, 0.10”。这一页要让读者相信权重不是抽象旋钮，而是每条输入对结果的带符号贡献；数值均无量纲，0.686 由本页公式计算并保留三位小数，不谈几何边界或训练。
