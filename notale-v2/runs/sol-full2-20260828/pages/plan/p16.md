# page-16
采用 `.compare`，标题写“批次大小改变的是梯度噪声”，三列共用同一纵轴“平均二元交叉熵 / nat”和横轴“epoch 0–30”，比较 batch size=1、8、64；数据为固定随机种子 42 生成的 64 个二维点，规则 y=1[x₁+x₂>0]，x₁、x₂ 独立均匀取自 [−1,1]，模型为单 sigmoid 神经元、初始参数全 0、η=0.20，每次点选批次大小都从头训练并画出确定可复现的曲线，同时显示当前 epoch、当前损失和“每 epoch 更新次数”分别为 64、8、1。页面要让读者相信小批次给出更频繁但更抖的方向，大批次更稳但每轮更新少；所有显示值直接来自上述算法运行，损失单位 nat，不把其中一种说成永远最好，也不讲硬件吞吐。
