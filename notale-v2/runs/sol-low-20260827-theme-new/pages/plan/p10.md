# page-10 · 给旋钮一支下坡箭头 · **100 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `STEP 03 · 找方向` |
| 主标题 | 梯度告诉旋钮往哪边转，也告诉它此刻有多敏感 |
| 收束句 | 箭头方向指向损失下降的一侧；数值越大，同样转一点，损失变化越明显。 |

## 知识结构：comparison

关系不变量：左栏的损失坡面与右栏的探针账页共享同一个参数位置；“向左试一点—当前位置—向右试一点”必须同行、同尺度、同基线，左右损失读数直接连到方向与敏感度结论。

共享原语：`.split-lr` 左栏承载可拖动的坡面探针，右栏承载同次测量结果；`.k-comparison` 固定三点并排比较；`.panel` 将方向箭头与敏感度读数收为同一仪表。

## 表征形式

交互式一维损失曲线：参数旋钮移动时，曲线上的当前位置、左右探针、三项损失读数、下坡箭头和敏感度同步更新。

使用原生 SVG 绘制曲线、探针和连接线，原生 DOM 承载滑杆与读数；几何简单且需与控件精确联动，无需图表库。

## 主工作流

build-interaction ← 让一次参数移动同时产生可比较的局部证据与方向反馈

## 坡面与仪表

| 画面对象 | 文字或值 | 用途 |
|---|---|---|
| 参数标签 | `参数旋钮 w` | 滑杆标题 |
| 损失定义 | `损失 = (w − 2)²` | 曲线旁短标 |
| 左探针 | `向左试 0.2` | 显示 `w−0.2` 与对应损失 |
| 中央探针 | `当前位置` | 显示当前 `w` 与损失 |
| 右探针 | `向右试 0.2` | 显示 `w+0.2` 与对应损失 |
| 方向仪表 | `此刻应向：左 / 右 / 两侧都不更低` | 由两侧损失比较决定 |
| 敏感度仪表 | `敏感度：每转 1 格，损失约变化 {值}` | 显示梯度绝对值，单位为“损失/参数格” |
| 梯度短标 | `梯度 = 方向 + 敏感度` | 右栏结论标签 |
| 内部计算步长 | `0.00001`，不印在画面 | `Lec.K.FINITE_DIFFERENCE_STEP` |
| 计算入口 | `Lec.P.finiteDifferenceGradient(valueFunction, [w], 0.00001)` | `valueFunction` 调用 `Lec.P.meanSquaredError([w], [2]).value` |

## 交互

学习者拖动 `w`，范围 `−1.0–5.0`，步长 `0.1`，默认 `4.0`。左右可见探针固定相距 `0.2`；拖动后立即更新三点位置、三项损失、较低一侧的橙色外框、方向箭头及敏感度。

方向只由左右试探读数判定；敏感度由有限差分结果的绝对值给出。接近 `w=2.0` 时箭头缩短，仪表显示“两侧都不更低”，形成“坡底附近方向不明显、敏感度接近零”的直觉。状态完全可逆，不设正确位置；提供“回到 4.0”按钮便于课堂重播。滑杆支持方向键，每次移动 `0.1`。

## 动效

拖动时，中央探针沿曲线即时移动；左右探针保持水平参数间距 `0.2`。方向箭头在 `160ms` 内翻转或缩放，损失读数以 `120ms` 数字过渡更新；不做循环动画。

## 核对

| 参数 | 期望损失比较 | 期望仪表 |
|---:|---|---|
| `w=4.0` | 左 `3.24`，当前 `4.00`，右 `4.84` | 向左；敏感度约 `4.00` |
| `w=1.0` | 左 `1.44`，当前 `1.00`，右 `0.64` | 向右；敏感度约 `2.00` |
| `w=2.0` | 左 `0.04`，当前 `0.00`，右 `0.04` | 两侧都不更低；敏感度约 `0.00` |

## 不许碰

不出现导数、偏导或任何导数符号，也不推导连续变化公式。这里只命名并读懂单个参数的梯度；多个参数的方向集合归 p11，学习率与实际更新步长归 p12。
