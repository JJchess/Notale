# page-13 · 让训练循环跑起来 · **110 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `TRAINING LOOP` |
| 主标题 | 点一次，神经元就沿下坡方向改一次参数 |
| 收束句 | 预测、计错、求方向、更新反复相接，损失才会一步步下降。 |
| 下一问 | 参数变多、连接变深后，这套循环还成立吗？ |

## 知识结构：process

关系不变量：四张阶段卡按“预测 → 计错 → 求方向 → 更新”同行、等宽、同基线并由箭头相连；当前卡加粗外框。损失曲线与更新次数共用同一条时间方向，每完成整轮才新增一个点。

共享原语：`.stage-cards.k-process` 承担四步因果轴；`.panel` 承担参数与损失读数；`.btns` 将“执行下一次更新”和“重新开始”固定在流程末端，避免被误读为第五步。

## 表征形式

交互式四阶段训练账页：上方逐卡显示本轮计算，下方用损失折线和“更新前 → 更新后”参数记录呈现累计结果。

损失曲线使用 ECharts SVG；四卡、读数和控制使用原生 DOM，更适合清晰切换离散训练状态。

## 四步内容

| 阶段 | 卡片标题 | 本轮显示 |
|---|---|---|
| `01` | 预测 | `4 个样本 → 4 个预测`；逐项显示 `x、真实答案、预测` |
| `02` | 计错 | `平均损失 L = …`；注记“越小表示这批预测整体越接近答案” |
| `03` | 求方向 | `w：向右，强度 …`；`b：向左/向右/暂不动，强度 …` |
| `04` | 更新 | `w：旧值 → 新值`；`b：旧值 → 新值`；`学习率 0.3` |
| 曲线 | 损失记录 | 横轴“参数更新次数”，纵轴“平均损失”；初始点记为第 `0` 次 |
| 状态 | 训练进度 | `已更新 n 次`；`当前平均损失 …` |

## 样本与初始值

| 项目 | 写入页面的值 |
|---|---|
| 训练样本 | `(x=0, y=0)`、`(x=1, y=0)`、`(x=2, y=1)`、`(x=3, y=1)` |
| 模型 | `预测 = sigmoid(w × x + b)` |
| 初始参数 | `w = 0.000`，`b = 0.000` |
| 固定学习率 | `0.3` |
| 损失 | 四个样本的平均二元交叉熵 |
| 更新规则 | `新参数 = 旧参数 − 0.3 × 本轮方向数值` |

计算调用 `Lec.P.binaryCrossEntropyWithLogits(logits, targets)` 得到平均损失、预测概率与 `dLogits`；据此汇总 `w`、`b` 的方向数值。画面只显示三位小数。

## 交互

学习者点击“执行下一次更新”。每次点击依次点亮四张卡，随后修改 `w、b`，在曲线上追加一个损失点，并把更新次数加一；按钮运行期间禁用，防止重复触发。

默认可连续执行至少 12 次。曲线纵轴保持同一尺度，不随下降自动夸张；悬停或键盘聚焦数据点时显示“第 n 次、损失、w、b”。“重新开始”恢复初始参数、四个固定样本和第 0 次损失。学习率固定为 `0.3`，本页不提供旋钮。

## 动效

点击后，四卡按左到右每隔 `180ms` 切换当前粗框；预测数字在 `160ms` 内替换，方向双线箭头从损失卡指回参数卡，持续 `260ms`；参数旧值淡出、新值淡入后，曲线新点于 `220ms` 内从上一点连出。整轮不超过 `1.1s`。

## 核对

| 状态 | 期望结果 |
|---|---|
| 初始 `w=0，b=0` | 四个预测均为 `0.500`；平均损失约 `0.693147` |
| 第 1 次更新 | `w` 方向数值约 `−0.500`，`b` 约 `0.000`；更新后 `w=0.150，b=0.000`；损失约 `0.627927` |
| 第 2 次更新 | 更新后 `w≈0.261133，b≈−0.016688`；损失约 `0.590`，应低于前两点 |

## 主工作流

build-interaction ← 让一次点击严格完成四步计算、参数更新与曲线追加，并可确定性复位

## 不许碰

只训练一个无隐藏层的 sigmoid 神经元，不增加隐藏单元、层间连接或责任分配；隐藏层作用归 p15，反向传播细节归 p17。不得重新开放学习率调节或比较不同步长，该机制归 p12。
