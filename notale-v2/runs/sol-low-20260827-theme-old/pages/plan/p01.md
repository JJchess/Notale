# page-01 · 看得见的学习 · **10 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `OPENING NOTE` |
| 主标题 | 神经网络的“学习”，可以拆成几次看得见的参数修改 |
| 收束句 | 它不是突然“懂了”，而是在一次次尝试后修改可调参数。 |
| 下一问 | 这些修改串起来，究竟经过哪几步？ |

## 知识结构：generalization

关系不变量：主标题居中作为唯一主干，下方三个等尺度支撑沿同一水平基线排列，并分别以短线连接主干；三个支撑不可拆散、错位或改成先后流程。

共享原语：`.focus` 将主张收束在版心中央；`.k-generalization` 负责“一条主干连接三个支撑”的关系；`.tag` 承担三个短标签，使它们被读作同一主张的并列依据。

## 表征形式

静态关系图：中央主张连接三张实验记录式短卡，卡片共同呈现“可调、可见、可重复”。

使用原生 DOM 与 CSS 即可；本页没有坐标图、复杂网络或命中检测，不增加可视化库依赖。

## 三条支撑

| 标签 | 卡片文字 | 图形记号 |
|---|---|---|
| `01 可调` | 模型里有可以改变的参数 | 带刻度旋钮，刻度不标数值 |
| `02 可见` | 每次修改前后都能留下记录 | `修改前 → 修改后` 实验账页 |
| `03 可重复` | 同样的动作可以一轮轮继续 | 三段首尾相接的短循环箭头 |

三张卡只使用概念文字，不显示参数名、公式、损失值、预测值或更新幅度。主干和卡框使用正文色；仅“修改前 → 修改后”的箭头使用强调色。
