# page-06 · 基准与出口 · **90 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `ADJUST THE BASELINE` |
| 主标题 | 偏置移动判断基准，sigmoid 把得分压进 0–1 |
| 收束句 | 偏置先平移内部得分；sigmoid 只负责把平移后的结果变成 0–1 输出。 |
| 下一问 | 有了 0–1 的预测，怎样把“错得多严重”记成一个数？ |

## 知识结构：classification

关系不变量：三个等宽分栏必须按“偏置 → 内部得分 → 0–1 输出”同行相连；固定汇合值与偏置嵌套归入内部得分，内部得分再归入 sigmoid 的输入，三栏共用同一条水平数值基线。

共享原语：`.triptych.k-classification` 承担三层归属与从属顺序；`.ctl` 把偏置明确标成可调量；`.panel` 包住内部得分和输出读数，使观察量与控件分层。

## 表征形式

交互式三联仪表：左栏为偏置旋钮，中栏为加法账式内部得分，右栏为可切换的“原始得分 / 经过 sigmoid”出口及压缩曲线。

使用原生 DOM 与 SVG；关系简单且无需坐标轴、缩放或图表工具提示，不增加图表库。

## 主工作流

build-interaction ← 激活切换与偏置变化必须同步产生可核验的数值和曲线反馈

## 三联内容

| 分栏 | 画面文字 | 数值与关系 |
|---|---|---|
| ① 移动基准 | `偏置 b`；“给所有样本统一加上或减去一段” | 滑杆 `−3.0` 至 `3.0`，步长 `0.1`，默认 `−1.2` |
| ② 得到内部得分 | `固定汇合值 + 偏置 = 内部得分` | `1.2 + b = z`；默认显示 `1.2 + (−1.2) = 0.0` |
| ③ 压到 0–1 | `sigmoid(z)`；“再大的正负得分，也会落在 0 与 1 之间” | 默认 `sigmoid(0.0) = 0.500`；范围标注 `0–1` |
| 固定参照 | `z = 0` 对应输出 `0.5` | `0.5` 直接写入画面；不提供阈值操作 |
| 切换按钮 | `看内部得分` / `经过 sigmoid` | 默认选中 `经过 sigmoid` |

计算入口：调用 `Lec.P.neuronForward([1], [1.2], b, "sigmoid")`，使用返回的 `preActivation` 与 `output`。画面仅显示 `z` 和三位小数输出，不显示数组或接口名。

## 交互

学习者拖动偏置 `b`，中栏的加法式、`z` 的位置标记及右栏输出立即同步变化。切换到“看内部得分”时，右栏显示可越过 0–1 的 `z`；切回“经过 sigmoid”时，同一位置沿实线箭头映射到 S 形曲线上的 0–1 输出。

应形成的直觉是：偏置不改变各输入原有贡献，而是统一移动判断基准；sigmoid 不决定移动多少，只把结果转换成有限范围。提供“复位”按钮，恢复 `b = −1.2` 与“经过 sigmoid”。

## 动效

拖动偏置时，中栏的 `z` 标记沿水平轴移动，时长 `120ms`；右栏对应点延迟 `40ms` 沿曲线更新。切换激活视图时，只做 `160ms` 的线条与读数淡换，不播放循环动画。

## 核对

| 参数 | 期望内部得分 `z` | 期望 sigmoid 输出 |
|---:|---:|---:|
| `b = −2.2` | `−1.0` | `0.269` |
| `b = −1.2` | `0.0` | `0.500` |
| `b = 0.0` | `1.2` | `0.769` |

## 不许碰

不比较 ReLU、tanh 或其他激活函数，也不讨论隐藏层为何采用不同激活；多种隐藏单元及其组合归 p15。不得重新设置 0.5 阈值判读任务，该交互归 p03。
