## 知识结构：comparison

关系不变量：同一批 200 个样本始终固定；左侧决策场与右侧损失曲线共享同一更新次数，初始态和训练态必须能沿同一时间基线直接比较。当前损失、训练准确率和更新次数必须与两图同步。

`.canvas-full.k-comparison` 承担同尺度比较；左侧 `.panel.q` 容纳样本与概率场，右侧 `.panel` 对齐损失曲线和实时账页；`.btns` 固定在共同基线下方，避免控制被误认成第三组证据。

## 表征形式

交互式实时训练仪表：二维概率热力场叠加固定样本点，旁列损失折线与数值账页。使用 `mlp.js` 执行真实 2→10→10→1 前向、反向传播和更新；两张坐标图均用 ECharts SVG。

## 主工作流

build-interaction ← 协调真实多层训练、边界刷新、曲线读数与可复现重置

## 训练仪表内容

| 区域 | 画面文字或数值 |
|---|---|
| 网络标牌 | `2 → 10 → 10 → 1` |
| 样本标牌 | `固定训练样本 200 个` |
| 训练配置 | `mini-batch 16`　`学习率 0.3` |
| 主按钮 | `开始训练`；运行时改为 `暂停` |
| 辅助按钮 | `再更新 1 次`　`重置` |
| 左图标题 | `决策场：背景表示预测为第 1 类的程度` |
| 左图坐标 | 横轴 `输入 1`；纵轴 `输入 2`；范围均为 `−1.5～1.5` |
| 左图图例 | 空心圆 `第 0 类`；实心圆 `第 1 类`；线 `0.5 边界` |
| 右图标题 | `训练损失` |
| 右图坐标 | 横轴 `参数更新次数`；纵轴 `平均损失`，从 0 起 |
| 实时账页 | `更新次数`、`平均损失`、`训练准确率` |
| 限定标记 | `仅针对这 200 个训练样本` |
| 显示常量 | 分类阈值 `0.5` |
| 运行参数 | 每动画帧训练 `12` 个 mini-batch；概率场 `80×80`；每 `8` 帧刷新一次 |

样本用固定种子生成两条交错弯月，每类 100 点；刷新与重置不更换坐标。网络初始化种子固定为 `1`。损失读数由当前 200 个预测调用 `Lec.P.binaryCrossEntropy(probabilities, targets).value`；分类用阈值 `0.5`。

## 交互

默认停在未训练初态。点击“开始训练”后连续更新；“暂停”冻结全部读数；“再更新 1 次”只执行一个 mini-batch 的反向传播与参数更新，便于看见一次学习动作。左图立即更新样本位置上的预测，边界按刷新间隔重算；右图追加损失点，账页同步变化。

“重置”恢复种子 `1` 的初始权重、清空曲线并回到第 0 次更新，样本保持不变。按钮支持键盘操作；暂停或重置后再次播放必须得到相同训练轨迹。

## 动效

每次边界重算时，概率场用 160ms 线性过渡到新值，`0.5` 等值线随之移动；损失曲线仅从旧末端延长到新点，120ms。数值变化以等宽数字原位更新，不滚动、不闪烁。

## 核对

| 情形 | 期望结果 |
|---|---|
| 重置后 | 更新次数为 `0`；损失曲线只含初始点；样本坐标与上次重置完全一致 |
| 概率 `0.5` | 分类为第 `1` 类，且必须落在显示的 `0.5` 边界上 |
| 连续训练 | 参数保持有限；损失总体下降，边界由近似随机形状逐渐弯曲；训练准确率可接近 `1`，但页面不得承诺固定终值 |

## 不许碰

不把训练准确率写成现实表现、泛化能力或公平性的保证；这里只标明它针对固定的 200 个训练样本，局限集中留给 p20。不要重播逐连接反向责任动画，那是 p17 的归属。
