# page-04 · 输入怎样变成预测 · **110 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `STEP 02 · 一个神经元` |
| 主标题 | 两项输入先汇合成一个分数，再变成 0–1 的预测 |
| 收束句 | 一个神经元就是一条可调的数值流水线：输入 → 内部得分 → 预测。 |
| 下一问 | 汇合时，为什么有的输入影响大，有的影响小？ |

## 知识结构：process

关系不变量：两张输入卡、一个神经元和一个预测框必须沿同一水平主轴从左向右相连；两项输入先在神经元的单一入口汇合，内部得分与输出预测同行显示，不能画成两条彼此独立的预测路线。

共享原语：`.canvas-full` 承载一条横贯版心的实验流水线；`.k-process` 固定“输入—汇合—输出”的先后与实线箭头方向；输入拨杆置于 `.ctl`，当前内部得分和预测分别用 `.num` 保持数值更新时位置稳定。

## 表征形式

交互式单神经元流程图：左侧两根输入拨杆，中部圆角六边形神经元，右侧 0–1 预测仪表；拨动任一输入后，内部得分、输出数值与填充长度同步变化。

使用原生 DOM 与 SVG 更合适：关系固定、节点少，需精确联动滑杆、连线和数值，无需引入图表库。

## 主工作流

build-interaction ← 输入拨杆必须即时驱动真实神经元计算并给出可读反馈

## 流水线内容

| 区域 | 画面文字或数值 | 备注 |
|---|---|---|
| 样本题签 | `预测：这株植物会开花吗？` | 仅作为具体情境 |
| 输入 1 | `光照`；范围 `0.00–1.00`；默认 `0.50` | 数值保留两位 |
| 输入 2 | `水分`；范围 `0.00–1.00`；默认 `0.50` | 数值保留两位 |
| 汇合入口 | `把两项输入汇成一个内部得分` | 不展示分项贡献 |
| 内部读数 | `内部得分  0.00` | 可为负数或正数 |
| 输出口 | `压到 0–1` | 不出现 sigmoid 名称或曲线 |
| 预测读数 | `开花预测  0.500` | 三位小数 |
| 生活化读法 | `约等于 100 次相似情况中有 50 次开花` | 随输出取整更新 |
| 固定模型设置 | `weights=[2, 1]`，`bias=-1.5`，`activationName="sigmoid"` | 只供实现调用，不印在画面上 |
| 计算入口 | `Lec.P.neuronForward(inputs, weights, bias, activationName)` | 使用返回的 `preActivation`、`output` |

## 交互

学习者分别拨动“光照”和“水分”，步长 `0.01`。每次输入变化立即更新输入卡数值、神经元内的内部得分、右侧预测数值、0–1 填充条及“100 次中约有多少次”的读法；所有前向实线箭头短暂变为深蓝，橙色只标记正在操作的拨杆。

交互没有正确位置，目标是观察“输入改变会沿同一条流水线传到预测”。两根滑杆均可逆；提供“回到中间值”按钮，将两项输入恢复为 `0.50`。

## 动效

拨杆变化后，沿左向右主轴依次点亮：输入卡 `120ms`、汇合入口 `160ms`、内部得分 `160ms`、预测框 `180ms`，相邻阶段错开 `70ms`。数值直接插值到新值，不让箭头循环流动，不制造反向信号。

## 核对

| 输入 `[光照, 水分]` | 期望内部得分 | 期望输出 |
|---|---:|---:|
| `[0.00, 0.00]` | `-1.50` | `0.1824255` |
| `[0.50, 0.50]` | `0.00` | `0.5000000` |
| `[1.00, 1.00]` | `1.50` | `0.8175745` |

## 不许碰

不解释权重的正负、大小或每项输入的分项贡献，这些归 p05；不拆解偏置，也不命名、比较或绘制 sigmoid，归 p06。
