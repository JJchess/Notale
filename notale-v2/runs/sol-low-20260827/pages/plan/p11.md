## 知识结构：classification

关系不变量：账页从上到下嵌套为“当前样本与预测 → 三个参数仪表 → 合并后的修改建议”。`w₁`、`w₂`、`b` 必须同行同尺度、共用零点与 `0–0.40` 强度标尺，方向箭头紧贴各自参数，不得按数值大小改变行高。

共享原语：`.ledger.k-classification` 用纵向账目和缩进表现“单项建议属于总建议”；三行 `.panel.q` 承载同尺度仪表，底部 `.panel` 汇总三项方向，只有当前检查行使用加粗外框。

## 表征形式

交互式梯度仪表：固定一个单神经元状态，学生逐项点按参数行，查看该参数应向左还是向右转，以及影响强弱；最后展开合并建议。使用原生 DOM 与 SVG 即可，三条共轴仪表和少量状态切换不需要图表库。

## 主工作流

build-interaction ← 三个参数仪表的逐项检查、同尺度比较与合并反馈

## 当前记录与仪表

| 区域 | 画面文字/值 |
|---|---|
| 当前样本 | `x₁ = 0.80`　`x₂ = −0.40`　真实答案 `1` |
| 当前参数 | `w₁ = 0.50`　`w₂ = −0.25`　`b = 0.10` |
| 当前预测 | `0.646`，即“100 次相似情况中约 65 次答 1” |
| 当前损失 | `0.437` |
| `w₁` 仪表 | 向右增大；强度 `0.283` |
| `w₂` 仪表 | 向左减小；强度 `0.142` |
| `b` 仪表 | 向右增大；强度 `0.354` |
| 合并建议 | `w₁ ↑　w₂ ↓　b ↑` |
| 仪表脚注 | 强度越大，表示同样轻微转动对当前损失的影响越明显。 |

仪表数值由 `Lec.P.neuronForward([0.8,−0.4],[0.5,−0.25],0.1,"sigmoid")` 与 `Lec.P.binaryCrossEntropyWithLogits([内部得分],[1])` 当场计算；参数建议强度分别取 `|dLogit×x₁|`、`|dLogit×x₂|`、`|dLogit|`。页面只显示三位小数和方向，不显示公式。

## 交互

初始时三只仪表均停在零点并标记“待测”。学生依次点击 `检查 w₁`、`检查 w₂`、`检查 b`；对应指针从零点移向左或右，显示方向词、强度数值，并在底部账页追加一行建议。三项检查后，`合并建议` 按钮可用，点击后把三行收束为 `w₁ ↑　w₂ ↓　b ↑`，同时强调“缺少任何一行都不是完整建议”。

提供 `重新检查`，恢复三项“待测”状态；键盘可逐行聚焦并用 Enter/Space 触发。点击顺序不影响最终结果。

## 动效

每只指针从零点沿水平轴移动，方向按建议左右展开，时长 `320ms`；方向词与数值延后 `80ms` 出现。合并时三行各以 `60ms` 错开向下亮起连接线，最终落入汇总框，总时长不超过 `420ms`。

## 不许碰

不解释这些建议怎样在多层网络中逐层计算，也不出现反向传播路径或责任分配；该机制归 p17。本页只建立“多个参数各有方向和强度，并共同构成一次修改建议”，不引入学习率或实际更新步长；步长比较归 p12。
