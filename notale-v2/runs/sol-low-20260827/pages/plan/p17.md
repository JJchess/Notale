## 知识结构：process

关系不变量：上栏固定同一张 `1→1→1` 网络的前向结果；下栏沿完全相同的节点位置，从损失框向输出层、隐藏层、输入侧依次反向相连。每段责任必须贴着其对应连接，不另画第二张网络。

共享原语：`.split-tb` 将“已知的前向快照”与“逐段反传追踪”上下对齐；下栏以 `.k-process` 承担右到左的阶段顺序；`.panel` 容纳当前责任读数，`.btns` 只控制追踪进度。

## 表征形式

交互式 SVG 关系网络：上栏静态显示蓝色前向数值，下栏用右向左双线逐连接追踪橙色责任，并同步生成参数方向账页。使用 D3 绘制和更新节点、连接及阶段状态，适合保持两栏几何严格对齐。

## 主工作流

build-interaction ← 让学习者逐段追踪同一份错误如何跨层分配，并获得即时方向反馈

## 本页网络与读数

| 对象 | 画面文字 | 值或状态 |
|---|---|---|
| 输入 | `输入 x` | `1.000` |
| 输入→隐藏参数 | `w₁` / `b₁` | `1.000` / `0.000` |
| 隐藏单元 | `隐藏输出 h` | `0.731` |
| 隐藏→输出参数 | `w₂` / `b₂` | `1.000` / `0.000` |
| 输出 | `预测 p` | `0.675` |
| 真实答案 | `目标 y` | `1` |
| 损失框 | `这次错了多少` | `0.393` |
| 阶段 1 | `输出端先接到错误责任` | `预测偏低：应把输出推高` |
| 阶段 2 | `责任沿 w₂ 传给隐藏层` | `隐藏输出也应提高` |
| 阶段 3 | `各参数得到本次改参方向` | `w₁ ↑　b₁ ↑　w₂ ↑　b₂ ↑` |

计算入口：用 `Lec.P.networkForward` 得到预测与缓存，`Lec.P.binaryCrossEntropy` 得到损失及输出责任，再将其传入 `Lec.P.networkBackward`，取得两层的 `dWeights`、`dBiases`。完整梯度只驱动画面；正文显示三位小数与增减方向。

## 交互

默认只显示完整前向快照和未点亮的反向双线。学习者点击 `开始反传` 后，再用 `下一段` 依次推进三个阶段；也可点任一尚未追踪的连接，系统只推进到该连接并突出对应责任框。每一步立即更新橙色双线、当前阶段说明及参数方向账页；已经经过的连接转为中性实线，不与蓝色前向动画同时播放。

完成后显示 `四个参数都已收到方向`，不要求猜数值。`重新追踪` 恢复初始快照、清空责任线与账页；键盘 Enter 推进，左右方向键回看或前进。

## 动效

每次推进仅让一段双线从右向左延伸，时长 `420ms`；责任读数在连线到达后 `80ms` 淡入。参数方向依 `w₂、b₂、w₁、b₁` 每项错开 `90ms` 出现；回看时直接切换状态，不倒放前向传播。

## 不许碰

不出现链式法则、导数或偏导公式，也不把责任追踪展开成符号推导。只追踪反向传播；多层网络的实时训练、损失曲线和决策边界留给 p18。
