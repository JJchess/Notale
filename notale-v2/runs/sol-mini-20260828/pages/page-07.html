从输出到学习信号

损失把“预测偏了多少”压成一个可优化的标量

预测来自模型，目标来自数据；损失函数读取两者的差异，但不等同于其中任何一个。

ŷ
MODEL OUTPUT

预测

模型根据当前参数算出的答案；参数改变，预测也会改变。

y
DATA LABEL

目标

训练样本给出的参照答案；它告诉模型应该靠近哪里。

LOSS FUNCTION

损失

L= ℓ(ŷ,y)

损失函数规定如何衡量偏差，把预测与目标之间可能很复杂的差异汇总为一个量。

优化器只需寻找让 L 变小的参数方向。

ŷ谁给出的？

模型给出，可随参数更新。

y拿什么作参照？

训练数据给出，本轮比较时保持不变。

L优化什么？

优化一个标量，而不是直接“优化目标”。
