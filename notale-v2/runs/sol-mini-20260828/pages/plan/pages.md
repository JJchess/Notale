本套无需图池

# page-01 [目录页]
建立全程问题：一个神经网络怎样把一次错误转化为每个参数下一步该改多少。

# page-02 [内容页·static]
让读者先看见学习的闭环由前向计算、衡量误差、反向分配责任和更新参数四段组成。

# page-03 [内容页·static]
让读者把单个神经元理解为输入的加权汇总再加偏置，而不是一个会思考的生物细胞。

# page-04 [内容页·interactive]
让读者亲手改变权重与偏置，观察同一组输入如何被推成不同的神经元输出。

# page-05 [内容页·static]
让读者理解激活函数把线性汇总变成非线性响应，从而使多层网络不再等价于一层线性变换。

# page-06 [内容页·static]
让读者沿着一条小网络逐层追踪数值，形成前向传播就是重复执行局部计算的认识。

# page-07 [内容页·static]
让读者区分预测、目标与损失，并理解损失只是把预测偏差压缩成可优化的标量。

# page-08 [内容页·interactive]
让读者移动预测值并即时观察损失变化，以建立偏得越远通常代价越高的直觉。

# page-09 [内容页·static]
让读者把训练重新表述为在参数空间中寻找较低损失的位置，而不是记住训练样本的口令。

# page-10 [内容页·static]
让读者从曲线切线理解导数的符号给出应移动的方向、大小给出局部敏感程度。

# page-11 [内容页·interactive]
让读者在一维损失曲线上拖动参数并比较当前位置的斜率与下一步方向。

# page-12 [内容页·static]
让读者理解梯度下降用负梯度更新参数，而学习率只决定沿这个方向迈多大一步。

# page-13 [内容页·interactive]
让读者亲手调学习率，比较停滞、平稳收敛与来回震荡如何来自步长差异。

# page-14 [内容页·static]
让读者从一条曲线过渡到多参数曲面，理解梯度是所有偏导数组成的最陡上升方向。

# page-15 [内容页·static]
让读者用链式法则理解复合计算的总影响等于沿路径把各段局部影响相乘。

# page-16 [内容页·static]
让读者把神经元展开成计算图，并识别每个节点只需保存前向值和局部导数。

# page-17 [内容页·interactive]
让读者逐段传递上游梯度并亲手完成乘法，看到末端误差怎样回到早先参数。

# page-18 [内容页·static]
让读者理解分叉处的梯度要相加、串联处的梯度要相乘，这两条规则足以覆盖整张网络。

# page-19 [内容页·static]
让读者对照前向信号与反向梯度，明确反向传播计算的是责任分配而不是把数据倒着播放。

# page-20 [内容页·static]
让读者把一次参数更新嵌回训练循环，理解多轮学习就是不断重算预测、梯度与新参数。

# page-21 [内容页·interactive]
让读者在页内训练一个小网络并观察决策边界、损失和参数轨迹如何同步演化。

# page-22 [内容页·static]
让读者区分单个样本的梯度与一批样本的平均梯度，并理解批量训练为何更稳定但仍有波动。

# page-23 [内容页·interactive]
让读者根据损失曲线和梯度读数诊断学习率不当、激活饱和与梯度消失这三类训练故障。

# page-24 [目录页]
收束为一条可复述的因果链：参数产生预测，损失衡量偏差，梯度分配责任，更新促成下一次更好的预测。
