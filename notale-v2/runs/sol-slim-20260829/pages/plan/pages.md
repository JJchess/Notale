本套无需图池

# page-01 [目录页]
从“一个参数怎样变好”这一问题进入全课，并明确最终要解释的是误差如何一路传回每个权重。

# page-02 [目录页]
建立从单个神经元、前向传播、损失、梯度下降到反向传播的学习路线。

# page-03 [内容页·static]
把一个神经元理解为先对输入加权汇总、再加偏置并产生输出的计算单元。

# page-04 [内容页·interactive]
让读者亲手改变输入、权重与偏置，形成参数决定输出方向和幅度的直觉。

# page-05 [内容页·static]
对照线性输出与非线性激活，理解没有非线性时堆叠多层仍等价于一次线性变换。

# page-06 [内容页·interactive]
让读者操纵激活前的数值并观察不同激活响应，从而区分截断、饱和与平滑变化。

# page-07 [内容页·static]
把多个神经元归入层并首尾相接，理解网络能力来自简单变换的逐层复合。

# page-08 [内容页·static]
沿输入到输出的顺序梳理前向传播，明确每层只使用上一层的结果完成本地计算。

# page-09 [内容页·static]
对照模型预测与已知目标，理解监督学习首先需要把“差多少”定义成可计算的损失。

# page-10 [内容页·interactive]
让读者移动预测并观察损失曲线的变化，建立误差大小与惩罚强弱之间的函数关系。

# page-11 [内容页·static]
把训练概括为在参数空间中寻找更低损失的位置，而不是让网络记住一条人为规则。

# page-12 [内容页·interactive]
让读者沿损失曲面的局部坡度更新参数，亲自验证负梯度为何指向最快下降方向。

# page-13 [内容页·static]
对照过小、适中与过大的学习率，理解步长会分别导致停滞、收敛或来回震荡。

# page-14 [内容页·interactive]
让读者调节学习率并重复下降过程，用轨迹差异形成对收敛速度与稳定性的联合判断。

# page-15 [内容页·static]
用“上游微小变化会让下游改变多少”解释导数，并把链式法则理解为局部敏感度的相乘。

# page-16 [内容页·interactive]
让读者扰动计算链中的一个中间量并追踪最终损失变化，验证整条路径的敏感度来自各段局部效应。

# page-17 [内容页·static]
把网络整理成计算图，区分前向保存中间结果与反向计算局部导数这两类信息。

# page-18 [内容页·static]
按输出到输入的逆序梳理反向传播，理解同一节点收到的多条误差信号需要累加后再继续传递。

# page-19 [内容页·interactive]
让读者在一条小型计算图上逐节点传回梯度，亲手确认每个权重只需局部导数和上游梯度。

# page-20 [内容页·static]
把一次完整训练归纳为前向计算、求损失、反向求梯度、更新参数并重复的闭环。

# page-21 [内容页·interactive]
让读者训练一个小型网络并联看损失、决策结果与参数更新，体会局部梯度如何累积成整体学习。

# page-22 [内容页·static]
归类梯度消失、梯度爆炸、学习率不当与数据不足，明确“没学会”可能发生在训练链条的不同环节。

# page-23 [内容页·static]
辨析反向传播不是倒放数据、梯度不是误差本身、一次下降也不保证到达全局最优这三类常见误解。

# page-24 [目录页]
以“算预测、量差距、传责任、改参数”的因果链收束全课，使读者能口述神经网络如何学会。
