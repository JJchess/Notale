# 页面构建契约

## 1. 工作边界

- 只编辑自己的 `page-NN.html`。
- 不读取、不修改、不比较任何其他 `page-*.html`。
- 不新建资源、文档、测试或说明文件。
- 只使用共享的 `PLAN.md`、本契约、`assets/theme.css`、`assets/lec.js`，以及按需读取的 `assets/CHASSIS.md`、技法文档和 `assets/lib/LIBS.md`。
- 最终只交付自己的 HTML；不写总结。

## 2. 固定骨架

文件必须保持以下骨架；只向 `#stage` 内加入本页标题、正文和呈现内容，并按需在现有引用之间加入本地库、页内样式与脚本。不得删除、替换或改写骨架已有节点和资源。

```html
<!doctype html>
<html lang="zh">
<head>
  <meta charset="utf-8">
  <link rel="stylesheet" href="assets/base.css">
  <link rel="stylesheet" href="assets/theme.css">
</head>
<body data-page="NN" data-total="TT">
  <div id="stage"></div>
  <script src="assets/base.js"></script>
  <script src="assets/lec.js"></script>
</body>
</html>
```

- 只把 `NN`、`TT` 改为计划规定的页号与总页数。
- 骨架只有空的 `#stage`：不得自行加入统一页眉、页脚或 `Lec.mount()`。
- 标题位置、组件和本页版式按 `PLAN.md` 决定，不套自创的全局框架。
- 页面必须自包含，可由 `file://` 直接打开；所有资源使用相对路径，禁止 CDN。
- 底盘接口只去读 `assets/CHASSIS.md`，不得复制或改写其内容。

## 3. 版面硬预算

设计画布为 1600×900。

- 画面占用比必须 ≥45%。
- 页面文本块总数必须为 20–70 个；标题、正文、标签、图注、刻度、图例、按钮、输入标签、读数和提示均计入。
- 叙述性正文不超过 260 个汉字；标题、数值、刻度和控件短标签不计入。
- 可操作控件不超过 4 个；同组单选项、按钮、滑块、输入框分别逐个计数。
- 同时展示的独立读数不超过 6 个。
- 超过任一上限即判定本页内容超载：删减、合并或报告需要拆页；禁止靠缩字号、减行高、压间距或遮藏内容塞入。
- 低于占用比或文本块下限时，应补足真实教学结构、比较维度或过程步骤；禁止用装饰、空卡片、放大字号或拉大间距充数。
- `#stage` 是 flex 列。其顶层区域必须设固定高度或 `flex` 份额，主内容区必须 `flex:1`；禁止顶层区域全部按内容自然取高。
- 默认使用 flex；只有矩阵、维度表等确需二维对齐时使用 grid。
- 一次性尺寸写内联或页内样式，不为单个元素发明通用类。
- 需要计算坐标才能对齐时应改结构：拖拽用 `transform` 偏移并保留正常流；刻度与控件拆成相邻区块。禁止用 `left/top` 凑布局。
- 禁止在缩放舞台内使用 `position:fixed`；需要覆盖时用相对内容容器的 `position:absolute`。
- 不得删除底盘或主题提供的类，不得 `classList.remove()` 移除 `lec-root`、`lec-page`、`min0`、`cv-fill` 等类，也不得覆盖这些类的定位属性。

## 4. 字号与可读性

以下是最终计算字号的硬下限：

- 纯数字刻度：≥12px。
- 带词句的刻度、标签、图例、图注、控件标签、短读数：≥14px。
- 正文、解释、提示、按钮文字、tooltip：≥16px。
- 正文行高：≥1.35。
- KaTeX 基准字号统一 ≥20px。
- 不得用 canvas 绘制承担教学信息的长文字。

1600×900 舞台在 1366×768 屏幕上的等比缩放约为 `min(1366/1600,768/900)≈0.85`；因此必须在逻辑画布上守住以上下限，不得按 1600 画布“看起来够大”自行放宽。

## 5. 视觉系统

- 所有颜色、字体、圆角、阴影、边框和间距从 `assets/theme.css` 的 token 与骨架类取用。
- 禁止自创另一套配色、字体体系、间距尺度或卡片风格。
- 可为本页结构写少量页内 CSS，但值必须引用主题变量；主题没有对应值时优先组合现有类，不得随意造常量。
- 不得通过覆盖底盘缩放、舞台定位或主题核心类改变全局行为。

## 6. 内容与数字

- 页面内容严格服从 `PLAN.md`，不提前讲后页，不重复第一讲“观测手段与尺度”。
- 所有天文常量、行星数据、比例、派生数值、进度和格式化结果一律从 `Lec.K`、`Lec.P` 取得；HTML 和脚本中不得写死教学数字。
- 页号、HTML 尺寸、CSS 尺寸、动画时长、数组索引和无教学含义的控制参数不属于教学数字。
- 交互变化后的读数必须由当前状态实时计算；禁止预录结果、假数据或写死答案。
- 随机样本必须引入 `seedrandom` 并使用固定种子，如页号；同一页面每次打开结果必须一致。
- 计算结果的文字格式使用 `Lec.P` 提供的格式化或舍入函数，单位必须明确。

## 7. 受众与语言

- 面向大学一年级通识课学生，文理混合；不假定微积分、天文学或编程基础。
- 首次出现的必要术语必须用一句日常语言就地解释；非必要术语不用。
- 不以公式代替概念解释；使用公式时先说明各量代表什么，以及读者应观察的关系。
- 每个说明句只表达一个主要判断，单句不超过 35 个汉字；避免连续定义和长括号。
- 提示语使用直接、合作式口气，如“拖动后观察……”“比较两种情况……”；禁止命令式训斥、卖萌、拟人化夸张和考试腔。
- 课堂上应便于教师指认与停顿；课后独立重看时，页面自身仍能说明“做什么、看什么、得到什么”。
- 不重复第一讲已经建立的观测方法与尺度背景；只有本页推理不可缺时，才用一句话调用已知结论。

## 8. Canvas、缩放与交互

- canvas 尺寸一律使用 `Deck.fit` 或 `Deck.autofit`。
- 手写 canvas 的指针坐标一律使用 `Deck.pt`。
- 动画循环一律使用 `Deck.loop`。
- canvas 取色一律使用 `Deck.rgb` 或 `Deck.rgba`。
- 禁止自行实现 `devicePixelRatio` 缩放、`getBoundingClientRect` 坐标换算或 `requestAnimationFrame` 循环。
- 使用 Konva 时由 `stage.getPointerPosition()` 处理缩放坐标，不再二次换算。
- DOM、canvas、SVG、WebGL 容器都必须跟随其布局盒尺寸更新；窗口或舞台缩放后不得拉伸、模糊、错位或命中偏移。
- 所有持续动画必须提供 `prefers-reduced-motion: reduce` 分支：停止循环或改为静态终态，不得只降低速度。
- 所有可点击、拖动或切换操作都必须键盘可达；使用原生按钮/输入控件，或补齐 `tabindex`、角色、可见焦点与 Enter/Space/方向键行为。
- 仅靠 hover 出现的信息必须也能通过焦点或点击获得。
- 颜色不得是唯一的信息通道；同时使用文字、形状、线型或位置编码。
- 交互后焦点不丢失，状态变化必须有就近的可见文字反馈。

## 9. 库的强制使用

动手前先按任务读取 `assets/lib/LIBS.md`。凡已有库能完成的呈现工作，禁止从底层重写：

| 呈现任务 | 必用库 |
|---|---|
| 常规坐标轴、刻度、图例、折线、柱状、散点、面积、饼、热力 | ECharts |
| 可拖拽、需命中检测的二维场景 | Konva |
| 三维场景 | Three.js |
| 下落、碰撞、摆动、堆叠、物理约束 | Matter.js |
| 节点连线、数据驱动矢量图形 | D3 |
| 成千上万元素同时运动 | PixiJS |
| 分步动画 | anime.js |
| 多动画时间线编排 | GSAP |
| 数学公式 | KaTeX |
| 矩阵运算 | ml-matrix |
| 页面实时训练小型二分类网络 | `mlp.js` |

- 库从 `pages/` 相对引用：`<script src="assets/lib/xxx.js"></script>`；样式同理。
- 依赖库必须在使用者之前加载：Three 在 globe.gl/Vanta 之前，GSAP 在 ScrollTrigger 之前；页面脚本最后加载。
- 版本以 `assets/lib/LIBS.md` 为准，禁止读取压缩库文件查版本。
- 不需要的库不引用；禁止 CDN。确需清单外库时只能放在 `pages/` 下本地引用。
- ECharts 必须使用 `echarts.init(el,null,{renderer:'svg'})`，并显式设置全局、轴、图例和 tooltip 字号，满足本契约字号下限。
- Konva 主要绘图形；场景标签使用绝对定位的 DOM。确需 `Konva.Text` 时必须显式设置合规字号。
- KaTeX 必须同时引入 `assets/lib/katex.min.css` 与 `assets/lib/katex.min.js`，基准字号 ≥20px。
- 小型实时神经网络使用 `mlp.js`，不得用 tf.js 或重写一套；只有预训练模型、真实图片卷积或 GPU 大矩阵才用 tf.js。使用 tf.js 时每步必须 `tf.tidy()` 或 `dispose()`，并确认 `tf.memory().numTensors` 不持续增长。
- 呈现可交给库，计算必须真实执行；不得用动画冒充计算。

## 10. 技法文档

- 清单中存在对应技法文档时，必须先用 `Skill` 读取再编码。
- 不得跳过现有技法文档后自行摸索另一套实现。
- 清单中没有对应项时才自行实现。
- 底盘能力与接口只读取 `assets/CHASSIS.md`。

## 11. 交互验收标准

真交互必须同时满足：

1. 用户能改变至少一个有教学意义的输入或状态。
2. 画面、数据或结论根据该状态实时重新计算。
3. 不同有效输入产生可辨认且正确的不同结果。
4. 页面明确提示操作目标与观察重点。
5. 有键盘路径、焦点样式和 reduced-motion 分支。
6. 在允许输入范围内，说明文字始终成立。

以下不算真交互：纯悬停发光、卡片倾斜、自动播放、装饰粒子、无结果变化的按钮、预录动画、点击后只换颜色、拖动但不影响任何教学量。装饰不得占用控件预算，也不得成为本页唯一互动。

## 12. 完工自检

在 `pages/` 目录运行：

`python3 assets/selfcheck.py page-NN.html`

有交互状态时，继续用一个或多个：

`python3 assets/selfcheck.py page-NN.html --after "<触发交互的 JS>"`

必须逐项检查并修改到干净：

- 无 JavaScript 报错。
- 无资源加载失败。
- 无元素超出 1600×900。
- 无非预期裁切。
- 无文字叠压。
- 字号最小值满足分档下限，正文行高 ≥1.35。
- 画面占用比 ≥45%。
- 文本块为 20–70 个。
- 无占比不足 1% 的无意义小容器。
- 默认状态及关键交互后的截图均无错位、遮挡、空白或状态矛盾。
- 键盘可完成主要交互，焦点可见。
- reduced-motion 下无持续运动。
- 随机结果可复现，交互读数真实计算。
- ECharts 文字可被自检读取，canvas 内无承担主要信息的隐藏文字。

任何一项失败都必须继续修改并重跑；不得以“浏览器里看起来可以”代替通过判据。

## 13. 交付

只交付 `page-NN.html`。不提交文档、测试、资源副本、修改说明或完成总结。
