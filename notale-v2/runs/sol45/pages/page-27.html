一个天体，怎样才算行星？

“行星”不是凭大小、名字或熟悉程度判断，而是三个必要条件的交集。

候选 1 / 4 把候选送进当前判定门，再回答 三问已完成 0 / 3
太阳判定起点
必要条件 ①它绕太阳运行吗？判断对象轨道中心是 → 第二问否 → 不是行星等待判断
必要条件 ②自身引力足以使它接近球形吗？判断对象天体自身形状是 → 第三问否 → 不是行星等待判断
必要条件 ③它清空了轨道附近区域吗？判断对象轨道邻域中的主导地位是 → 行星否 → 不是行星等待判断
判定终点
三项都是“是”
→ 行星0 个
任一项为“否”
→ 不是行星0 个
