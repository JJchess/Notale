# page-03 · 谁真正占据太阳系 · **75 秒**

## 照这个写
`Lec.mount({index:3,kicker:'MASS SHARE',title:'谁真正占据太阳系？',take:'行星体积醒目，但太阳占太阳系绝大部分质量'})`

质量口径：
```js
const planetMass = Lec.P.totalPlanetMassKg();
const sunMass = Lec.K.sun.massKg;
const sunShare = Lec.P.percent(sunMass, sunMass + planetMass);
const shownShare = Lec.P.significantFigures(sunShare, 4);
```

D3：`d3.scaleLinear().domain([0,100]).range([0,chartWidth]).clamp(true)`；份额条高 `56`，太阳填充 `#FFC857`，八行星合计填充 `#4DB6FF`；标签 `16px`，结果数字 `48px` 等宽。估值滑杆 `min:0,max:100,step:1,value:50`。

## 知识结构：comparison
用左右并置与同一问题的两种表征显式比较“看起来占空间”与“实际上占质量”。左侧八颗行星圆盘刻意保持可辨识、体积醒目；右侧只按质量份额画一条 100% 堆叠条。提交估值前右侧真实分界隐藏，提交后对齐揭示估值线与真实线。

## 表征形式
交互式质量份额比较。左侧是非比例行星圆盘，仅表达“视觉上很显眼”；右侧是严格按计算值生成的质量份额条，建立“体积印象不能替代质量比较”的心理表征。

## 两种印象 × 两列
| 比较维度 | 八颗行星 | 太阳 |
|---|---|---|
| 画面印象 | 八个清晰、醒目的圆盘 | 一个主要圆盘 |
| 质量 | 八颗行星合计约 `0.13%` | 约 `99.87%` |
| 读取口径 | `Lec.P.totalPlanetMassKg()` | `1.98847e30 kg` |
| 结论 | 看得见、数量多，不等于质量占比大 | 太阳是系统的质量主体 |

百分比文案必须由 `shownShare` 与 `100-shownShare` 运行时生成；表中数值是预期显示，不得写死进脚本。注明“小字口径：太阳与八颗行星质量合计”。

## 必须点出来的一句
行星体积醒目，但太阳占太阳系绝大部分质量。

## 交互（只有这一个）
读者拖动“你猜太阳占多少质量？”滑杆并提交；估值线停在份额条上，随后真实分界揭示，使“几乎全部质量集中于太阳”可见。

做对了立刻看到什么：估值在真实值 ±1 个百分点内，估值线吸附到真实分界并泛金光，显示“很接近：太阳约占 99.87%”。

做错了立刻看到什么：估值线保留、真实线从右端切入；提示“低估了太阳：行星看起来很大，不代表质量份额大”。

做到哪儿了怎么知道：按钮依次显示“先拖动估值”→“提交估值”→“已揭晓”，不设置多轮任务。

做完了怎么收：份额条下方亮起结论句，左侧行星圆盘整体降至 35% 亮度；提供“重新估一次”重置滑杆与遮罩。

## 场景构图
使用“深蓝星空中的稀疏定向星点”“扁平行星圆盘”“日光金高亮的当前观察窗口”。`split-lr`：左侧 42% 为八颗行星组成的紧凑陈列，强调视觉存在感；右侧 58% 为横贯面板的质量份额条与滑杆。太阳金色份额几乎铺满右侧，行星蓝只留下细窄末端；背景不出现轨道公式或力箭头。

## 动效
入场：八颗行星圆盘由左向右依次浮现；右侧空份额条随后从 0% 生长至 100%，真实分界保持遮蔽。

反馈：提交后估值线短暂停顿，真实太阳金色区域在 `700ms cubic-out` 内铺开；错误时估值线水平抖动 `2×6px`，正确时金色光晕脉冲两次。

## 不许碰
不出现万有引力公式、引力大小计算、轨道速度或“持续下落”解释；不把质量主导直接讲成轨道机制。只比较太阳与八颗行星合计的质量份额，不扩展矮行星、卫星和小天体分类。
