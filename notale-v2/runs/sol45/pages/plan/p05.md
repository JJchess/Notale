# page-05 · 拼出一张会动的地图 · **90 秒**

## 照这个写
`Lec.mount({index:5,kicker:'MAP LAB',title:'拼出一张会动的太阳系地图',take:'有用的太阳系地图必须同时表达顺序、分区和运动'})`

Konva：`new Konva.Stage({container:'map-stage',width:容器宽,height:容器高})`；分层固定为 `backgroundLayer / orbitLayer / tokenLayer / feedbackLayer`。拖拽吸附半径 `28px`，正确吸附时长 `180ms`，错误回弹 `260ms`。轨道位置仅作示意，不映射真实大小或距离。

## 知识结构：process
用“摆顺序 → 看聚集 → 让系统运动”三步显式化地图的建构过程。八颗行星沿共同中心向外排列；背景区域随就位数量逐渐显影；最后连接环形方向标记，使所有轨道出现同向流动光点。顶部步骤条固定显示 `1 顺序 / 2 分区 / 3 运动`，不是知识讲解目录。

## 表征形式
全屏二维交互画布。太阳固定在左侧中心，八条压缩后的同心椭圆轨道横向展开；底部托盘放行星圆片与“共同绕行”方向片。天体尺寸统一为可拖拽符号，不按真实比例。

## 三个 step

| step | 学生完成的动作 | 画面形成的关系 |
|---|---|---|
| 1 摆顺序 | 水星、金星、地球、火星、木星、土星、天王星、海王星依次放入 1–8 号轨道 | 从太阳向外的顺序 |
| 2 看分区 | 第 4、5 轨之间显出“小天体密集带”；1–4 与 5–8 背景分别聚成两片 | 成员并非均匀散布 |
| 3 加运动 | 把“共同绕行”方向片接到太阳旁的环形接口 | 行星是绕太阳运动的成员 |

## 必须点出来的一句
一张有用的太阳系地图，不只回答“谁在谁外面”，还要让人看见成员怎样成区、怎样绕太阳运动。

## 交互（只有这一个）
读者拖动八颗行星与一个方向片，看到顺序、区域聚集和轨道流动逐层出现，从中形成“太阳系地图是关系图，不是八颗球的队列”的直觉。

做对了立刻看到什么：圆片吸附进轨道槽，日光金描边闪亮一次，并接通该轨道至太阳的细线。  
做错了立刻看到什么：圆片左右抖动后回弹；提示原话为“这颗行星与太阳的远近顺序不在这里。”方向片放早则提示“先让八位成员各就各位。”  
做到哪儿了怎么知道：右上角显示 `已就位 3 / 8`；完成八颗后切换为 `方向 0 / 1`，顶部步骤同步点亮。  
做完了怎么收：全部轨道出现缓慢同向流动光点，区域底色完全显影，中央浮出结论句；右下提供“重拼一次”，保留首次错误次数但不评分。

## 场景构图
采用“深蓝星空中的稀疏定向星点”“围绕太阳展开的发光轨道环”“按区域切分的扁平行星圆盘”“日光金当前观察窗口”。太阳作为左侧发光锚点，轨道环占画布中央至右侧；底部托盘像地图制图台，九枚拼件横排。区域色块藏在轨道下方，随进程显影，避免提前给出完整答案。

## 动效
入场：太阳先由暗到亮，轨道线从中心向外依次描出；拼件随后从底部上移，间隔 `55ms`。  
反馈：正确时吸附并沿轨道产生一圈蓝色脉冲；错误时仅拼件抖动回弹，不改变其他轨道状态。

## 不许碰
不追求天体大小与距离同时按比例；不显示 AU、直径或比例尺，不声称轨道间距真实。区域只用于暴露“会不会分区”的先备概念，不解释正式区域边界、成员密度或形成原因。运动只表达共同绕太阳，不讲引力机制、速度差异或轨道形状。
