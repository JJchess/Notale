# page-06 · 光要走多久 · **85 秒**

## 照这个写
`Lec.mount({index:6,kicker:'LIGHT-TIME RELAY',title:'光要走多久？',take:'即使信息以光速传播，从太阳到各行星仍需要数分钟到数小时'})`

行星顺序固定为 `['mercury','venus','earth','mars','jupiter','saturn','uranus','neptune']`；秒数逐项调用 `Lec.P.lightTravelTimeFromAU(semimajorAxisAU)`，拆分调用 `Lec.P.lightTravelTimeParts(seconds)`，显示值取整数秒。

`anime({targets:'.light-pulse',translateX:[0,targetX],duration:travelMs,easing:'linear'})`；课堂压缩播放 `travelMs = 900 + 180 * rank`，真实时间只用于读数，不按真实时长等待。  
正确反馈：`anime({targets:card,scale:[1,1.06,1],boxShadow:['0 0 0 #FFC857','0 0 22px #FFC857'],duration:420,easing:'easeOutQuad'})`。  
错误反馈：`anime({targets:card,translateX:[0,-8,8,-5,5,0],duration:360,easing:'easeInOutSine'})`。  
字号：标题 `40px`，行星名 `18px`，时间读数 `20px` 等宽，辅助文字 `14px`。

## 知识结构：enumeration
以太阳为共同起点，把八颗行星并列成八个接力站。上半部光脉冲依次抵达；下半部八行严格对齐“顺序—日距—单程光时—口语读法”，显式呈现距离增加时等待从分钟跨入小时。

## 表征形式
动态交互式单程时间轴。轨道距离采用压缩标尺，不能从屏幕间距直接读比例；每站的真实光行时间以数字标签承担精确表征。

## 必须点出来的一到三句
即使信息以光速传播，从太阳到各行星仍需要数分钟到数小时。  
这里看到的是单程光行时间，不是飞船航行时间。

## 交互（只有这一个）
读者从候选托盘依次选择“下一站”行星；选对后光脉冲从太阳接力抵达该站并揭示时间，从中形成外太阳系具有小时级光尺度的直觉。

做对了立刻看到什么：卡片吸附到下一空位，金色描边点亮，光脉冲接通并翻出时间。  
做错了立刻看到什么：卡片横向抖动并回弹；提示“这颗行星不在下一站：按离太阳由近到远选择”。  
做到哪儿了怎么知道：固定显示“已接通 3 / 8”，时间轴对应站点由空心变实心。  
做完了怎么收：八站同时微亮，顶端出现“3 分钟 → 4 小时”，提供“重新接力”按钮恢复初始状态。

## 场景构图
使用母题“深蓝星空中被局部照亮的发光轨道环”与“从太阳向外延伸、逐渐稀疏的系统剖面”。上半屏是一条由左向右穿过八个轨道站的蓝色光路，太阳在左端发出金色脉冲；下半屏为深色技术面板，八行时间清单与候选托盘并置。外行星段用断裂刻度提示距离压缩。

## 动效
入场：太阳先亮，八个站点由内向外每隔 `90ms` 淡入，蓝色主干线随后从左向右绘出。  
反馈：正确时金色脉冲线性飞抵并扩散一圈；错误时仅卡片抖动，光路不前进。
