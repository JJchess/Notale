# page-16 · 四只时间翻牌 · **85 秒**

## 照这个写
`Lec.mount({index:16,kicker:'TIME ≠ DISTANCE',title:'一天、一年、昼夜、季节：别混成一只钟',take:'自转、公转、昼夜与季节是不同概念，不能用“离太阳更近”解释全部时间现象'})`

四张主卡固定 `data-id="rotation|orbit|daynight|season"`；八张线索牌固定 `data-target`。翻牌动画统一：
`anime({targets:card,duration:420,rotateY:[0,180],easing:'easeInOutQuad'})`；错配抖动：
`anime({targets:card,translateX:[0,-8,8,-5,5,0],duration:360,easing:'easeOutQuad'})`。尊重 `prefers-reduced-motion`，降级为 120 ms 淡入与即时换面。

## 知识结构：classification
用“运动—时间现象”两层分类，而非四个并列同义词。上层是天体自身运动：自转、公转；下层是由运动参与形成的时间现象：昼夜、季节。四列对齐展示“定义—回答的问题—关键因素—不能推出什么”，连线只允许线索归入对应概念。

## 表征形式
交互式翻牌分类台。先看四张背面概念卡，再逐张翻出定义；随后把八张线索牌归位。卡面用方向箭头区分“绕自身轴”与“绕太阳”，避免用距离远近编码时间现象。

## 层级里的各项

| 层级 | 概念 | 卡面定义 | 回答的问题 | 关键因素 | 不能据此推出 |
|---|---|---|---|---|---|
| 运动 | 自转 | 天体绕自身轴旋转 | 自己转一圈多久 | 自转周期、方向 | 一年有多长 |
| 运动 | 公转 | 天体绕太阳运行 | 绕太阳一圈多久 | 轨道尺度、公转周期 | 昼夜必然多长 |
| 现象 | 昼夜 | 地表随自转交替朝向与背向太阳 | 为什么明暗交替 | 自转与日照方向 | 四季冷暖 |
| 现象 | 季节 | 一年中日照条件周期变化 | 为什么年内冷暖与昼长变化 | 轴倾角、公转位置 | 仅由日距决定 |

| 线索牌 | 正确归类 |
|---|---|
| 绕自身轴 | 自转 |
| 约 0.997 日转一圈（地球恒星自转） | 自转 |
| 绕太阳 | 公转 |
| 约 365.256 日绕一圈（地球公转） | 公转 |
| 朝向太阳的一侧较亮 | 昼夜 |
| 约 1 个太阳日重复一次（地球） | 昼夜 |
| 年内昼长与太阳高度变化 | 季节 |
| 需要同时考虑轴倾角与公转位置 | 季节 |

## 必须点出来的一到三句
“一天”和“一年”不是同一种运动的快慢：前者通常联系自转与昼夜，后者联系公转。季节不能简化成“更靠近太阳就更热”。

## 交互（只有这一个）
读者点击翻开概念卡，再拖动八张线索牌归类；卡面定义与连线随归位显现，形成“四词分属运动与现象、彼此有关但不等同”的直觉。

做对了立刻看到什么：线索牌吸附归位，日光金描边亮起，细线接通所属概念。  
做错了立刻看到什么：牌回弹并抖动，提示“这张牌说的是运动/现象，不是它造成或回答的另一件事”。  
做到哪儿了怎么知道：顶部显示 `已归类 3 / 8`，四张卡各有 `0/2、1/2、2/2` 状态点。  
做完了怎么收：四卡同时翻到正面，上下两层框线点亮，中央出现“运动 ≠ 现象；相关 ≠ 相同”；提供“重置翻牌”。

## 场景构图
母题采用“深蓝星空中被局部照亮的发光轨道环”与“扁平行星圆盘和日照方向”。中央像一张时间分类台：上排两张“运动”卡置于细蓝轨道环，下排两张“现象”卡落在半明半暗的地球圆盘前；八张线索牌沿底部弧形托盘排开，金色日照从右上方斜切，不画季节机制图。

## 动效
入场：轨道环先由中心描出，四卡按上左、上右、下左、下右依次翻入，线索牌从底部错峰上浮。  
反馈：正确时金色亮边沿连线流向目标；错误时只做短促水平抖动与回弹，不触发全场动画。

## 不许碰
不展开地球季节机制：不画四季轨道图，不讲近日点/远日点、南北半球相反季节、太阳高度与昼长的因果细节；不把“自转周期”等同于所有语境中的“一天”，也不引入恒星日与太阳日的推导。
