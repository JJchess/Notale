# 页面构建契约

## 1. 工作边界

- 只编辑并交付 `pages/page-NN.html`。
- 不读取、比较、复制或修改任何其他 `page-*.html`。
- 不新建 CSS、JS、图片、数据、测试或说明文件。
- 可读取且只依赖：`PLAN.md`、`assets/theme.css`、`assets/lec.js`、`assets/CHASSIS.md`、`assets/lib/LIBS.md`及对应技法文档。
- 底盘接口先读 `assets/CHASSIS.md`，本契约不转抄。
- 每页必须能以 `file://` 直接打开，资源只用相对路径，禁止 CDN、网络请求和服务端依赖。
- 不重复第一讲已讲过的观测方法与尺度背景；只在理解本页不可缺少时用一句话承接。

## 2. HTML 骨架

保留以下结构与顺序。只改 `NN`、页内标题和 `#stage` 正文；需要库时，仅在标记位置加入本地依赖和页内脚本。

```html
<!doctype html>
<html lang="zh">
<head>
  <meta charset="utf-8">
  <link rel="stylesheet" href="assets/base.css">
  <link rel="stylesheet" href="assets/theme.css">
  <!-- 仅在需要时加入库的 CSS -->
</head>
<body data-page="NN" data-total="31">
  <div id="stage">
    <!-- 本页标题、版面与正文 -->
  </div>
  <script src="assets/base.js"></script>
  <script src="assets/lec.js"></script>
  <!-- 仅在需要时加入库脚本，再放本页内联脚本 -->
</body>
</html>
```

- 骨架中只有空的 `#stage`；不得另加统一页眉、页脚或 `mount()`。
- 标题位置、组件组合由本页内容决定。
- 不移动、删除或替换 `base.css`、`theme.css`、`base.js`、`lec.js`。
- `#stage` 必须保留，且按主题既定规则作为 flex 列使用。
- `#stage` 的顶层区域必须给固定高度或 `flex` 份额；主内容区必须 `flex:1`。禁止所有顶层区域都按内容取高。
- 一次性尺寸可写内联样式；不要为单个元素发明类名。

## 3. 内容与版面预算

以下均为硬限制：

- 正文最多 260 个汉字；标题、刻度、短标签、数值不计入正文。
- 可操作控件最多 6 个；一个按钮、滑块、输入框、选择器或独立拖拽对象各计 1 个。
- 页面文本块总数必须为 20–70，标题、正文、刻度、图例、标签、控件文字、读数均计入。
- 画面占用比必须 ≥45%。
- 文本不得藏进 canvas、伪元素或图片来规避计数。
- 超出预算时删减、合并信息或拆页；必须明确判定“本页超预算”，禁止缩字号、压行高、挤间距或遮挡内容。
- 低于占用比时增加有教学意义的结构、比较维度或过程展开；禁止靠放大字号、装饰图形和空白间距凑占用。

布局规则：

- 默认使用 flex；只有矩阵、维度表等真正二维对齐时使用 grid。
- 需要计算坐标才能对齐时，先改 DOM 结构，不用 `left/top` 凑位置。
- 拖拽视觉位移用 `transform`，元素保留在正常结构中。
- 禁止在缩放舞台内使用 `position:fixed`；需要悬置时用相对内容容器的 `position:absolute`。
- 不得删除 `min0`、`cv-fill`、`no-pan` 等底盘或主题类，不得覆盖它们的定位属性。

## 4. 字号与可读性

按最终计算字号检查：

- 纯数字刻度：≥12px。
- 带词句的刻度、标签、图注、图例、轴名：≥14px。
- 正文、提示、控件文字、tooltip、动态读数：≥16px。
- 正文行高：≥1.35。
- KaTeX 基准字号统一 ≥20px。
- 禁止用 `transform:scale()`、浏览器缩放或 canvas 字形绕过字号下限。

舞台从 1600×900 缩放到 1366×768 时，系数为  
`min(1366/1600, 768/900) ≈ 0.853`。因此 16px 在常见课堂屏幕上只约 13.6px；上述下限已经包含缩放损失，不得再降低。

## 5. 主题与样式

- 所有颜色、字体、阴影、圆角和常用间距从 `theme.css` 的变量、token或现有骨架类取得。
- 禁止另建配色、字体体系或间距标尺。
- 禁止硬编码与主题重复的十六进制、RGB、字体族和成套间距。
- canvas 取色一律使用 `Deck.rgb()` / `Deck.rgba()`。
- 保证默认态、hover、focus、disabled及图表各状态均有足够对比度。

## 6. 数字与计算

- 所有教学内容中的常量、物理量、比例、距离、时间、质量、速度、温度及其派生数值，一律从 `Lec.K` 和 `Lec.P` 取得或计算，禁止写死。
- 坐标轴数据、读数、tooltip、图注和正文中出现的对应数字必须来自同一计算结果。
- 单位换算使用 `Lec.P.fromUnit()` / `Lec.P.inUnit()`，不得复制换算常数。
- `Lec.P` 已公开的计算不得另写近似公式。
- `data-page`、`data-total`、CSS尺寸、动画时长、数组索引、循环次数及纯界面范围不属于教学数字。
- 若 `Lec` 无法提供 PLAN 要求的教学量，不得编造；改为无伪数值的定性呈现。
- 随机数据必须引用 `seedrandom.min.js` 并使用固定种子，如 `page-NN`。禁止 `Math.random()`。
- 交互允许改变参数时，所有说明必须在完整允许范围内保持为真；不得用预录结果、假数据或写死读数冒充计算。

## 7. 库与加载

动手前先查 `assets/lib/LIBS.md`。已有库能完成的呈现工作，禁止从底层重写。

| 工作 | 必用库文件 |
|---|---|
| 下落、碰撞、摆动、堆叠、物理约束 | `matter.min.js` |
| 三维场景、光照材质 | `three.min.js` |
| 三维地球、球面点线区块 | `three.min.js` 后加载 `globe.gl.min.js` |
| 生成式网络背景 | `three.min.js` 后加载 `vanta.net.min.js` |
| 常规坐标轴、折线、柱、散点、面积、饼、热力 | `echarts.min.js` |
| 可拖拽、可命中检测的二维场景 | `konva.min.js` |
| 节点连线、数据绑定矢量图 | `d3.min.js` |
| 成千上万元素同时运动 | `pixi.min.js` |
| 分步、路径、形变动画 | `anime.min.js` |
| 多动画时间线 | `gsap.min.js` |
| 滚动绑定动画 | `gsap.min.js` 后加载 `ScrollTrigger.min.js` |
| 矢量动画文件 | `lottie.min.js` |
| 伪三维插画 | `zdog.min.js` |
| 指针倾斜 | `vanilla-tilt.min.js` |
| 进入视野淡入 | `aos.js` |
| 数学公式 | `katex.min.css` 与 `katex.min.js` |
| 矩阵运算 | `ml-matrix.umd.js` |
| 可复现随机 | `seedrandom.min.js` |
| 页面实时训练小型二分类网络 | `mlp.js` |
| 预训练模型、卷积、GPU大矩阵 | `tf.min.js` |

引用格式固定为：

```html
<script src="assets/lib/文件名"></script>
```

- 库脚本放在 `base.js`、`lec.js` 之后，页内初始化脚本之前。
- 依赖库必须先于其插件加载：three 先于 globe.gl/Vanta，GSAP 先于 ScrollTrigger。
- API版本以 `assets/lib/LIBS.md` 为准，禁止读取压缩文件查版本。
- 不需要的库不得引用。
- ECharts 必须使用 `echarts.init(el, null, {renderer:'svg'})`，并显式设置全局16px、标签与图例14px、纯数字刻度12px以上。
- Konva 图形可用 canvas；文字标签优先使用叠加的 DOM。必须使用 `Konva.Text` 时显式设置合规字号。
- KaTeX 必须同时引用预置 CSS 和 JS，禁止替换官方字体资源；`throwOnError:false`。
- 小型逐帧二分类训练使用 `mlp.js`，不得另写训练框架，也不得改用 tf.js。
- tf.js 仅用于预训练模型、卷积或确需GPU的大矩阵；每步使用 `tf.tidy()`或显式 `dispose()`，并确认 `tf.memory().numTensors` 不持续增长。
- 库负责的渲染、拖拽、命中、坐标轴或时间线不得再手写一套。

## 8. Canvas、缩放与动画

- 页面自有 canvas 一律使用 `Deck.fit()` / `Deck.autofit()`适配逻辑尺寸、高分屏和舞台缩放。
- 指针坐标一律通过 `Deck.pt()`换算；禁止自行使用 `getBoundingClientRect()`或手算缩放比例。
- 动画循环一律使用 `Deck.loop()`；禁止直接建立 `requestAnimationFrame`循环。
- 禁止自行乘 `devicePixelRatio`或重复实现 resize 逻辑。
- 使用库生成的画布时，容器尺寸变化必须调用该库的 resize/setSize 接口；库内部命中与指针换算不得二次修正。
- 每帧只更新必要状态；销毁不用的监听器、实例、纹理和计时器。
- 必须实现 `prefers-reduced-motion: reduce` 分支：停止自动循环、粒子漂移、连续旋转和无必要过渡，直接显示稳定且完整的静态状态。
- reduced-motion 下不得丢失数据、标签、反馈或操作能力。
- 动画不是信息唯一载体；暂停后仍能读懂当前结论。

## 9. 交互与可达性

真交互必须满足：

- 用户操作会改变模型参数、数据选择、视角、步骤或可检验结果。
- 变化由真实计算或库状态产生，并有即时可见的图形及文字反馈。
- 用户能恢复初始状态；多步骤交互能看出当前状态。
- 结果与本页教学目标直接相关。

以下仅算装饰，不算交互：

- hover变色、发光、倾斜、浮动、自动播放。
- 点击后只出现预写句子。
- 与结果无关的粒子、背景运动或按钮动效。
- 假拖拽、预录动画、随机但不影响结论的变化。

可达性要求：

- 优先使用原生 `button`、`input`、`select`。
- 所有操作必须可用键盘完成，不得只监听指针。
- 自制控件必须有正确的 `tabindex`、角色、可见焦点和键盘处理；Enter/Space触发按钮，方向键调整连续或分档参数。
- canvas拖拽必须提供等价的键盘或邻近表单控件。
- 控件必须有可见标签；图标按钮必须有可访问名称。
- 动态关键读数使用邻近DOM文本，必要时设置克制的 `aria-live`。
- 点击目标不得被图层遮挡，禁用状态必须真实不可操作。

## 10. 教学语言

- 面向大学一年级文理混合学生，不假定微积分、天文学或编程基础。
- 不使用未解释的专业术语；首次出现时用一句普通话定义，随后统一用同一名称。
- 公式必须同时说明符号指什么、结果说明什么；不要求学生从公式自行猜结论。
- 单个说明句不超过32个汉字，最多两个分句。
- 每段只表达一个判断或操作，避免连续术语和多层括号。
- 提示语使用直接、平静的课堂口气，如“拖动后观察……”“比较两项……”；禁止卖萌、责备、考试口吻和含糊的“试试看”。
- 教师带讲时应能快速指认重点；课后重看时，页面自身仍须说明操作、反馈和结论。
- 不复述第一讲内容，不写课程背景长段落，不把讲稿塞进页面。

## 11. 技法文档

- 可用技法清单中存在对应文档时，必须先用 `Skill` 阅读，再写页面。
- 禁止在已有技法覆盖的事项上另发明实现。
- 清单没有对应项时才自行实现，并仍受库、底盘和本契约约束。

## 12. 完工自检

在 `pages/` 目录运行：

```bash
python3 assets/selfcheck.py page-NN.html
```

所有交互状态还必须用一次或多次：

```bash
python3 assets/selfcheck.py page-NN.html --after "<触发该状态的 JS>"
```

通过判据：

- 无JavaScript错误、控制台异常或资源加载失败。
- 页面可在 `file://` 下完整显示和操作。
- 无元素越出1600×900画布，无非预期裁切。
- 无文字叠压、控件遮挡、不可见标签或失效命中区域。
- 字号和行高全部达到本契约下限。
- 画面占用比 ≥45%。
- 文本块为20–70个。
- 正文≤260字，控件≤6个。
- 无占比不足1%的无意义小容器。
- 初始态、极值、重置后、主要分支及reduced-motion状态均正确。
- 随机结果可复现，动态数值与图形一致。
- 检查未通过就修改同一HTML并重跑，直到报告干净；不得忽略、解释或带错交付。

## 13. 交付

只交付 `page-NN.html`。不提交文档、测试、截图、资源、变更记录或总结。
