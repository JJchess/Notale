# 页面构建契约

## 1. 工作边界

- 只创建或修改分配给你的 `page-NN.html`。
- 绝不读取、复制、比较或修改任何其他 `page-*.html`。
- 可读文件仅限任务要求、`PLAN.md`、`assets/theme.css`、`assets/lec.js`、`assets/CHASSIS.md`、`assets/lib/LIBS.md`及 Skill 清单中的相关技法文档。
- 底盘接口只读 `assets/CHASSIS.md`；不得把其内容复制进页面或本契约。
- 每页必须自包含，可由 `file://` 直接打开并完整显示、交互；资源只用相对路径，不用 CDN，不要求服务器。
- 不创建额外资源、文档、测试、报告或总结。

## 2. 固定 HTML 骨架

以此为唯一骨架；`NN` 改为两位页号，`data-total` 固定为 `30`。页面标题、正文、控件、图形及页内代码放入 `#stage`；除引入确有需要的库外，不改动其余固定标签。

```html
<!doctype html>
<html lang="zh">
<head>
  <meta charset="utf-8">
  <link rel="stylesheet" href="assets/base.css">
  <link rel="stylesheet" href="assets/theme.css">
</head>
<body data-page="NN" data-total="30">
  <div id="stage"></div>
  <script src="assets/base.js"></script>
  <script src="assets/lec.js"></script>
</body>
</html>
```

- 骨架只有空的 `#stage`，没有统一页眉、页脚或 `mount()`；标题位置和组件布局由本页内容决定。
- 不删除、替换、重排固定的 `base.css`、`theme.css`、`base.js`、`lec.js`。
- 不删除底盘或主题添加的类，不得 `classList.remove()` 掉 `min0`、`cv-fill`、`no-pan` 等类，也不得覆盖这些类的定位属性。
- 页面专用 CSS 只处理本页结构；一次性尺寸可内联，不为一次性元素发明类名。

## 3. 受众与语言

- 面向大学一年级通识课学生，文理混合；不假定微积分、天文学或编程基础。
- 本讲是第二讲；不得重复第一讲已覆盖的观测方法和尺度背景，只可用一句必要的承接语。
- 先说可观察的现象或结论，再引入术语；术语首次出现时用一句短释义展开。
- 不用未解释的公式、缩写、代码术语或学科黑话。公式必须同时有自然语言含义。
- 单句尽量不超过 32 个汉字；一段最多 3 句。标签用名词短语，提示语用直接、友好的动作句，如“拖动查看”“按空格暂停”，不用责备或考试口吻。
- 教师课堂可快速指讲，学生课后无需教师补充也能理解当前页的结论、操作和反馈。
- 不写空泛引言、重复结论、拟人化噱头或与本页学习目标无关的背景。

## 4. 版面与密度预算

画布逻辑尺寸固定为 `1600 × 900`。

- 正文说明文字：每页最多 240 个汉字；标题、短标签、刻度、单位和按钮文字不计入该项。
- 可操作控件：最多 6 个。一个按钮、滑块、输入框、开关、选择器或可拖拽物各计 1 个；成组单选项逐项计数。
- 页面文本块总数必须为 20–70 个。标题、段落、列表项、按钮文字、控件标签、图例项、坐标轴名、每个刻度、读数、图注及 canvas 内文字均计数。
- 画面占用比必须 `≥45%`。
- 超出任一上限时，向调度者明确报告“本页范围超出预算”，要求拆页或删减；不得缩字号、压行高、堆叠、裁切或隐藏文字后交付。
- 文本块不足 20 或占用比不足 45% 时，应增加真实的信息结构、比较维度或过程步骤；不得靠放大字号、装饰背景或拉大空隙充数。
- 太满应删减或拆页；太空应补足内容或调整计划，不得制造无教学作用的组件。

`#stage` 是 flex 列。其顶层区域必须给固定高度或 `flex` 份额，主内容区使用 `flex:1`；不得让全部顶层区域仅按内容取高而在底部留下死空间。

默认使用 flex。仅在矩阵、维度表等真正需要二维对齐时使用 grid。需要计算坐标才能对齐时应重构 DOM：拖拽用 `transform` 偏移并保留正常流位置，不改 `left/top`；刻度与滑块拆成相邻区块，不用绝对坐标硬凑。

禁止在缩放画布内使用 `position:fixed`；固定于局部区域的元素用相对容器中的 `position:absolute`。

## 5. 字号硬下限

以下均指 1600×900 逻辑舞台中的最终计算字号：

- 纯数字或极短单位刻度：`≥12px`
- 标签、图例、轴名、图注、控件文字、带词句的刻度：`≥14px`
- 正文、提示、读数解释、tooltip：`≥16px`
- 正文行高：`≥1.35`
- KaTeX 基准字号：统一 `≥20px`

1366×768 显示时，宽度比例 `1366/1600≈0.854`，高度比例 `768/900≈0.853`，底盘取约 `0.85` 的整体缩放；因此不得以“1600 画布上勉强可读”为理由突破字号下限。

不得用 canvas 绘制本可由 DOM 承载的标签。Konva 场景标签优先用绝对定位 DOM 叠加；确实必须随图形变换的 `Konva.Text` 要显式设置合规字号，并人工计入文本总数。

## 6. 主题与样式

- 所有颜色、字体、圆角、阴影、间距和层级从 `assets/theme.css` 的 token 或现有骨架类取得。
- 不建立第二套配色、字体系统、间距标尺、按钮样式或卡片样式。
- 不用未经主题定义的渐变、发光、纹理、随机颜色或装饰动画。
- 页面专用 CSS 只允许组合主题 token、完成布局和必要的图形尺寸。
- canvas 取色一律使用 `Deck.rgb()` / `Deck.rgba()`，不得在绘图代码中写死颜色字符串。

## 7. 数据与计算

- 页面展示的课程事实、天体参数、比例、单位换算和结果数字一律来自 `Lec.K` 或 `Lec.P`；不得在 HTML、配置或脚本中写死数据值。
- 派生值必须从 `Lec` 返回值实时计算；显示时可用 `Lec.P.round()`，不得先抄入常量。
- 控件初值、图表数据、比较基准和解释句中的数字必须来自同一计算链，确保交互后仍一致。
- `assets/lec.js` 只有 `Lec.K` 和 `Lec.P`，不提供布局。
- 随机数据必须引入 `seedrandom` 并使用稳定种子；同一页面每次打开应得到同一结果。
- 不用预录动画、假数据、预设答案或写死轨迹冒充计算。允许用已有计算库或真实页内算法。

## 8. 库与技法

凡 `assets/lib/` 中已有库能完成的呈现工作，不得从底层重写。动手前先查 `assets/lib/LIBS.md`：

- 常规坐标轴、刻度、图例、折线、柱、散点、面积、饼、热力图：ECharts
- 可拖拽、需命中检测的二维场景：Konva
- 三维场景：Three.js
- 下落、碰撞、摆动、堆叠、约束：Matter.js
- 节点连线、数据驱动矢量图形：D3
- 成千上万元素同时运动：PixiJS
- 多动画时间线：GSAP
- 数学公式：KaTeX
- 矩阵运算：ml-matrix
- 小型二分类网络逐帧训练：`mlp.js`
- 预训练模型、真实图片卷积或 GPU 大矩阵：TensorFlow.js

使用方式：

- 直接以 `<script src="assets/lib/xxx.js"></script>` 本地引入；KaTeX 同时引入 `assets/lib/katex.min.css`。
- 依赖先于插件：Three 在 Globe/Vanta 前；GSAP 在 ScrollTrigger 前；库在本页调用代码前。
- 版本和 API 只以 `assets/lib/LIBS.md` 为准，不读压缩库文件找版本。
- 不引入无用库；确需清单外库时只能放在 `pages/` 下并本地引用。
- ECharts 必须 `echarts.init(el,null,{renderer:'svg'})`，并显式设置全局、轴、图例和 tooltip 的合规字号。
- KaTeX 必须同时引 CSS 和 JS，基准字号不低于 20px。
- TensorFlow.js 每步必须使用 `tf.tidy()` 或显式 `dispose()`，并确认 `tf.memory().numTensors` 不持续增长。
- 清单中有对应技法文档时，必须先用 `Skill` 阅读再实现；没有对应文档才自行设计。

## 9. Canvas、缩放与动画

- 自写 canvas 一律使用 `Deck.fit()` / `Deck.autofit()` 做高分屏、容器尺寸和舞台缩放适配。
- 自写 canvas 指针坐标一律用 `Deck.pt()`；不得自行用 `getBoundingClientRect()`、缩放比或 `devicePixelRatio` 换算。
- 动画循环一律使用 `Deck.loop()`；不得直接建立 `requestAnimationFrame` 循环。
- canvas 颜色一律使用 `Deck.rgb()` / `Deck.rgba()`。
- 使用 Konva 时采用其自带命中检测和逻辑坐标，不再实现第二套拖拽或坐标换算。
- 容器变化后必须同步更新渲染尺寸；不得仅改 CSS 尺寸造成模糊、拉伸或命中偏移。
- 必须实现 `prefers-reduced-motion: reduce` 分支：停止自动循环、惯性、闪烁和持续背景运动，直接显示稳定终态；交互计算仍可手动触发。
- 页面隐藏或组件销毁时停止循环、计时器和监听；不得重复启动多个循环。

## 10. 交互标准

真交互必须同时满足：

1. 用户通过点击、拖动、滑动、键盘或选择改变输入或状态；
2. 页面据此重新计算真实结果；
3. 图形、读数或解释立即给出可辨识反馈；
4. 操作可重复、可复位，且结果在允许输入范围内始终成立。

仅有 hover 变色、按钮按压效果、自动播放、视差、淡入、倾斜、装饰粒子或播放预录步骤，不算真交互。

每个交互必须：

- 使用原生可聚焦控件，或为自定义控件提供正确的 `tabindex`、ARIA 名称和状态。
- 可用键盘完成核心操作；拖拽物提供方向键操作，按钮支持 Enter/Space。
- 焦点样式清晰，焦点顺序符合视觉顺序，不设正数 `tabindex`。
- 提供就近的短操作提示和复位方式。
- 不只靠颜色表达状态；同时使用文字、形状、位置或线型。
- 指针目标不被装饰层遮挡，缩放后命中位置必须与视觉位置一致。

## 11. 完工自检

在 `pages/` 目录执行：

`python3 assets/selfcheck.py page-NN.html`

对初始状态及每个关键交互状态分别检查；交互后状态用一个或多个：

`python3 assets/selfcheck.py page-NN.html --after "<一段 JS>"`

交付前必须满足：

- 无 JavaScript 报错、控制台异常或资源加载失败。
- 无元素越出 1600×900、无真实裁切、无文字叠压。
- 字号最小值符合 12/14/16px 分档，正文行高不低于 1.35。
- 画面占用比 `≥45%`。
- 文本块总数为 20–70。
- 正文不超过 240 个汉字，控件不超过 6 个。
- 无占比不足 1% 且无意义的小容器。
- 初始、极值、复位及关键交互状态均无新增溢出、遮挡或错误。
- 1366×768 缩放下图形清晰，指针、tooltip、拖拽和键盘操作位置正确。
- reduced-motion 分支无持续自动运动。
- 随机结果可复现，页面刷新后数据与讲解一致。

任何真实问题都必须修改页面并重新运行检查，循环至报告干净；不得以“误差很小”“课堂上看不见”或隐藏元素规避。
