# 《神经网络是怎么学会的：从一个神经元到反向传播》 30 分钟互动讲义 · 总规划

## 0. 这套讲义的主线

神经网络的“学习”不是凭空理解，而是反复计算预测误差、把误差责任向后分配，再把每个参数朝能减小误差的方向移动一点。

| 章 | 页 | 这一章要让读者信什么 |
|---|---|---|
| I. 一个神经元如何预测 | 01–05 | 一个神经元只是把输入按权重合成，再把结果变成 0 到 1 的预测 |
| II. “学一下”究竟做什么 | 06–08 | 学习的最小动作是比较误差、确定方向、移动参数 |
| III. 误差如何穿过多层网络 | 09–13 | 反向传播会沿连接倒着计算每个参数对最终误差的责任 |
| IV. 多个神经元为何更有能力 | 14–18 | 隐藏层能组合多个简单边界，训练会让这些边界逐步适合数据 |
| V. 带走一套可迁移解释 | 19–20 | 看到任何神经网络训练，都可追问预测、误差、责任和更新四件事 |

- E1：权重决定各输入影响多大，偏置决定整体门槛，激活函数把合成结果转换成可解释的预测。
- E2：损失函数把“错了多少”变成一个数；比较参数附近的损失，就能判断哪边更可能变好。
- E3：一次学习就是按局部敏感度调整参数；重复“预测—算错—调整”，总体误差可以下降。
- E4：多层网络的最终误差可沿连接反向分配，隐藏神经元因此也能获得各自的调整信号。
- E5：隐藏层组合多个简单判断，能够形成单个神经元无法表达的非线性边界，但训练表现仍须用未参与训练的数据检验。

## 0.5 视觉世界

现实参照：

- 实验记录本——适合在投影上持续保留输入、预测、误差和参数改动的可追踪记录，减少远距离观看时的识字负担。

必须靠形状区分的概念对：

- 输入值 / 权重 —— 一个是本次样本带来的信息，一个是跨样本保留并被学习修改的参数。
- 预测 / 正确答案 —— 两者会同时出现，混淆后就无法理解误差来自哪里。
- 前向传播 / 反向传播 —— 两者经过相同连接但方向和任务不同。
- 神经元 / 连接 —— 一个执行计算，一个携带数值并保存权重。
- 训练样本 / 未见样本 —— 两者必须分开，才能说明误差下降不等于真正学会。

需要专属色的概念：

- 预测值——只代表网络当前给出的 0 到 1 输出。
- 正确答案——只代表样本提供的目标值。
- 损失——只代表预测与目标不一致所产生的代价。
- 参数更新——只代表本轮学习实际改变的权重或偏置。

母题：

- 参数旋钮——反复锚定“学习改变的是哪些数”。
- 误差刻度——反复锚定每次操作是否让结果变好。
- 带方向的连接路径——分别承载前向数值和反向责任。
- 训练记录行——连续保留轮次、预测、损失与参数变化。
- 二维样本平面——承载直线边界、隐藏层组合和最终决策区域。

被否决的整体方向：

- 仿生大脑与神经细胞插画——会让读者误以为本课在解释真实大脑的学习机制，而不是人工神经网络中的参数优化。
- 代码编辑器与终端界面——会让没有编程经验的学生把注意力放在语法和报错上，而不是参数、误差与更新之间的因果关系。
- 黑箱魔法或拟人化机器人——会强化“网络自己想明白了”的误解，遮蔽可逐步检查的数值计算。
- 高密度公式板书——在课堂投影距离下会增加符号辨认负担，并错误暗示理解反向传播必须先掌握微积分。

## 0.6 对这个受众的取舍

- 能用：四则运算、正负数、百分比、调旋钮、试错、沿路线追踪责任和比较高低的生活经验。
- 不用：矩阵、向量记号、导数与偏导数、链式法则的符号推导、优化器谱系、卷积、注意力、代码语法和生物神经科学类比。
- 换算：输入统一缩放到约 −1 到 1，预测换成 0%–100%，损失换成可比较的“错题分”，参数更新换成旋钮移动的距离。
- 争议：误差下降不保证对新数据有效；隐藏神经元形成的内部特征通常不应被解释成唯一、稳定的人类概念。
