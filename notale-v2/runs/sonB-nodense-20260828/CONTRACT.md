# 1. 这堂课在讲什么

全课主张：神经网络的“学习”是可检查的数值过程。网络先用当前参数做预测，再把预测与正确答案比较得到损失，随后计算每个参数对损失的局部责任，并把参数朝可能减小损失的方向移动一点。重复这组动作，训练误差才可能下降。

五幕任务：

1. 01–05：建立单个神经元的预测过程。输入与权重配对，加入偏置，经激活函数得到 0 到 1 的预测。
2. 06–08：拆开一次学习。先量化“错了多少”，再比较参数附近的损失，最后执行一次有方向、有步幅的更新。
3. 09–13：把责任计算扩展到多层网络。前向传播计算预测；反向传播沿同一批连接反向计算各参数对最终损失的责任。
4. 14–18：说明隐藏层的能力与限制。多个简单判断可组合成非线性边界；训练结果还须用未参与训练的数据检查。
5. 19–20：形成迁移框架。面对任何网络训练，依次追问：如何预测、如何算错、如何分配责任、如何更新参数。

证据链固定为：权重与偏置改变预测 → 预测与答案产生损失 → 参数附近的损失揭示改动方向 → 局部责任可沿多层连接反向计算 → 多轮更新改变决策边界 → 未见样本检验这种改变是否可迁移。

每页只完成自己的 `pNN.md`。规格标为别页负责的定义、例子、结论或互动不得提前复述，也不得自行补写后续推论。01、02、09、14、19、20 不设置可点击、拖拽、输入或调参控件。

# 7. 文字风格

- 术语深度：可直接使用“输入、权重、偏置、参数、预测、正确答案、损失、学习率、隐藏层、训练样本、未见样本”。“激活函数”首次说明为“把合成结果转换成输出的规则”；“局部敏感度”首次说明为“参数轻微改变时，损失会变多少”；“反向传播”首次说明为“从最终损失倒着计算各参数责任”。整门课不引入导数、偏导、梯度、链式法则、雅可比矩阵、向量点积、优化器、logit、epoch 等术语及其符号体系。
- 表述禁忌：不得说网络“理解了、想要、意识到、猜到规律”或神经元“兴奋、发火”。不得把权重直接称为输入的“重要性”。不得说误差像液体一样流回去；应说责任信号沿连接反向计算。不得说反向传播本身更新参数；它计算责任，更新是下一动作。不得用训练损失下降证明网络已经学会或一定能处理未见样本。
- 记号口径：统一使用 `x` 表示输入、`w` 表示权重、`b` 表示偏置、`z` 表示激活前合成值、`p` 表示预测、`t` 表示正确答案、`L` 表示损失。变量首次出现及关键公式旁必须并列中文含义。乘法写 `×`，不靠字母相邻暗示；画面不出现微积分符号。一个公式只承担一步计算，复杂过程拆成连续记录行。
- 数字换算：预测以 `0.73（73%）` 这类 0–1 数值加百分比呈现；正确答案保持 `0` 或 `1`。损失、权重、偏置和学习率均不写物理单位。展示值通常保留两位小数，方向判断和比较使用未舍入值；参数变化保留正负号。近似值加“约”，仅对当前样本成立的结论标“对这个样本”，仅在当前参数附近成立的方向标“在当前位置附近”。
