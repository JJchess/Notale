# page-18 · 翻到未见样本 · **100 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `UNSEEN CHECK` |
| 主标题 | 未见样本才检验边界能否迁移 |
| 收束句 | 训练误差低只说明记分册上的题做得好；同一边界面对未见样本仍有效，才提供了迁移证据。 |
| 下一问 | 换成更大的网络，我们还能用哪四步追踪它？ |

## 知识结构：comparison

关系不变量：训练集与未见样本必须使用同一模型快照、同一 80×80 决策场、同一坐标范围和同一指标定义；左右只允许样本集合及其评估读数不同。

共享原语：`.k-comparison` 对齐左右两列的样本数、平均损失和正确率；`.sample-plane` 在同尺度上叠加相同边界；训练点使用 `.sample-train`，未见点使用 `.sample-unseen`。整体落入 `.split-lr`。

## 表征形式

交互式双栏检验：左栏固定显示 160 个训练样本，右栏先覆盖为“尚未翻面”，点击后显示 40 个未见样本；两栏共享 p17 的模型预测场。使用原生 Canvas 绘制平面，DOM 负责翻面状态与指标表。

## 主工作流

build-interaction ← 无训练地复用上一页模型，并严格隔离训练样本与未见样本的评估状态

## 同模型双份记分册

| 比较项 | 左：训练样本 | 右：未见样本 |
|---|---|---|
| 是否参与更新 | 是 | 否 |
| 样本数量 | 160 | 40 |
| 点形 | 实心圆 | 空心虚线圆 |
| 决策场 | p17 最终模型快照 | 与左栏完全相同 |
| 显示指标 | 平均损失、正确率 | 平均损失、正确率 |
| 参数是否变化 | 否 | 否 |

指标在翻面时由当前快照即时计算；预测达到或超过 50% 判为 1。画面只显示两位小数的平均损失和整数百分比正确率，不预写固定结果。

## 交互

默认左栏可见，右栏以中性记录纸覆盖，只显示“40 个未见样本从未参与更新”。点击“翻到未见样本”后移除覆盖，显示空心虚线点及右栏指标；再次点击恢复覆盖，模型和左栏不变。

页面不得出现开始、单步或继续训练控件。若从 p17 进入，读取离页时保存的权重；若直接打开，则加载构建时序列化的种子 1、更新 600 的固定检查点，不在本页后台训练。按钮旁持续显示“参数已冻结”。

## 动效

翻面采用 180 毫秒的水平硬切换：覆盖层向右移动 24px 后消失，未见点按固定顺序在 200 毫秒内出现。决策场保持静止，明确变化的是检验数据而非模型。

## 核对

翻面前后所有权重、偏置、更新次数和80×80网格预测必须逐项相同。左栏指标只遍历索引 0–159，右栏只遍历 160–199；两栏样本数必须分别为 160 和 40，且未见样本不得进入任何更新调用。

## 不许碰

只建立“训练表现与未见表现必须分开”的检验边界，不展开正则化、早停、数据增强或其他过拟合治理方法。不得在本页继续训练，也不得把一次未见集结果表述成绝对保证。
