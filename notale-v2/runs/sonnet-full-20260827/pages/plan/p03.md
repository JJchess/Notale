# page-03 · 换个激活函数，曲线换个形状 · **60 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `SAME INPUT, DIFFERENT SHAPE` |
| 主标题 | 同一个输入，换一种激活函数，输出曲线完全变形 |
| 收束句 | 激活函数决定了神经元把「加权求和」这个数拧成什么形状的输出 |
| 下一问 | 这个数字算出来了，但它离目标差多少？ |

## 知识结构：comparison

三种激活函数（Sigmoid、Tanh、ReLU）共享同一条横轴（输入 z 的范围，如 -4 到 4）和同一个当前输入点，必须同行对齐、同尺度显示，才能让「同样输入不同输出」这句话成立；左栏是控件与当前读数，右栏是三条曲线叠放或并排的对比区，曲线本身不比高低对错，只比形状差异。

用 `.k-comparison` 承担：`.dim` 固定为「输入 z」这一维，`.hdr` 标出三个激活函数名，`.rowline` 让三条曲线在同一 x 位置画出竖直参照线，`.diff` 高亮当前点在三条曲线上取值的差异（用红铅笔色标出三个不同的 y 值）。`.panel` 装左侧滑块与当前数值读数框。

## 表征形式

交互 + 动态图表：左栏一个 `.panel` 装输入值滑块（范围 -4 到 4）和三个 `.big` 读数框分别显示三种激活函数在当前输入下的输出值；右栏用 ECharts 画三条静态曲线（sigmoid、tanh、relu，x 从 -4 到 4 采样），叠加一根随滑块移动的竖直参考线（markLine）和三个跟随的高亮点（markPoint），三色分别用主色钢笔蓝画曲线本体、红铅笔色仅标当前点。ECharts 适合三条曲线+联动参考线这种规整数值对比，比手绘 Canvas 更省事且轴刻度精确。

## 主工作流

build-chart ← 三条激活函数曲线随同一输入点联动高亮，需要精确对齐的坐标轴与可复用的图表联动逻辑

## 不许碰

不比较三种激活函数哪个更好用或该选哪个（本课不展开，全课无归属页处理这个问题）；不提梯度消失/爆炸等训练层面的后果（p05 讲梯度含义，p08 讲学习率，均不在此提前铺垫）；不展开导数公式推导，只可在核对用途内部使用 `Lec.K` 数值，不在正文写微积分记号。

## 激活函数取值表

| 激活函数 | 公式入口 | 在 z=0 处的值 | 特征说明 |
|---|---|---|---|
| Sigmoid | `Lec.P.sigmoid(z)` | 0.5（`SIGMOID_AT_ZERO`） | 输出压缩在 0~1 之间，两端趋平 |
| Tanh | `Lec.P.tanh(z)` | 0（`TANH_AT_ZERO`） | 输出压缩在 -1~1 之间，关于原点对称 |
| ReLU | `Lec.P.relu(z)` | 0 | 负数全部归零，正数原样通过，呈折线 |

## 交互

学习者拖动一个横向滑块控制输入值 z（范围 -4 到 4，默认 0）。滑块移动时：右侧三条曲线上的高亮点同步左右移动，左侧三个读数框实时显示 `Lec.P.sigmoid(z)`、`Lec.P.tanh(z)`、`Lec.P.relu(z)` 的当前值（等宽字体，钢笔蓝书写，变化的那一位可有红铅笔色轻微强调）。目的是让学习者直觉到：同一个 z，三个函数给出的答案形状不同——sigmoid 永远正、tanh 有正有负、relu 负半轴直接归零。无正确位置，可随意拖动，松手即定，无需复位（状态由滑块位置完全决定，可逆）。

## 核对

- z = 0 时：sigmoid → 0.5，tanh → 0，relu → 0。
- z = 4 时：sigmoid → 约 0.982，tanh → 约 0.999，relu → 4。
- z = -4 时：sigmoid → 约 0.018，tanh → 约 -0.999，relu → 0（验证负半轴归零的折线特征）。
