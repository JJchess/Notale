链式法则:拆开再乘起来

已展开 0 / 3 行
例子:f(x) = σ(2x + 1),在 x = 0 处求 df/dx
STEP 1 外层线性:u = 2x + 1,在 x = 0 处 u = 1 展开
u = 2 × 0 + 1 = 1 —— 这是套进 sigmoid 之前的中间量。
STEP 2 套上 sigmoid:σ(1) ≈ 0.731,它对 u 的导数 σ(1)·(1−σ(1)) ≈ 0.731×0.269 ≈ 0.197 展开
σ(1) = 1/(1+e⁻¹) ≈ 0.731,1−0.731 ≈ 0.269,两者相乘 ≈ 0.197,这是 f 对 u 的局部导数。
STEP 3 u 对 x 的导数是 2 展开
u = 2x + 1,对 x 求导,系数项消失,只剩 du/dx = 2。
df/dx ≈ 0.197 × 2 ≈ 0.393
链式法则就是把每一步的局部导数依次乘起来。
