# page-01
这一页要让读者相信这三十分钟能把"神经网络怎么学会东西"讲成一件看得见的机械过程，而不是一句"训练一下就好了"的模糊说法。画面居中呈现主标题《神经网络是怎么学会的：从一个神经元到反向传播》，标题上方一行 kicker 写"30 分钟走线图"，标题下方一行导语："从一个加权求和的神经元开始，一路走到让整张网络自己纠错的反向传播。"再往下用蓝色实线与锈红虚线各画一段短短的走线，交汇于一个小圆点，暗示"预测"和"纠错"是同一条线的两个方向——这是全套课反复出现的视觉母题，这里只作为封面的安静预告，不作任何解释。这一页完全静态，不出现任何数字、不定义任何术语，具体的"神经元""损失""梯度"留给后面逐页展开。
