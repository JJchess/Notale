# page-02
这一页要让读者相信"神经元"就是一次加权求和加一次非线性变换，没有更多神秘之处。画面标题"一个神经元在算什么"，下方左栏展示一个具体例子：输入 x₁=0.8、x₂=−0.3 固定不变，两个权重滑块 w₁、w₂ 初始为 0.6 和 0.9，偏置滑块 b 初始为 0.1；右栏用一张小图解画出"输入→乘权重→加总→加偏置→sigmoid→输出"的走线，走线用蓝色实线画出（呼应全套"前向=蓝色"的约定）。当前数值实时显示：z = w₁x₁ + w₂x₂ + b，初始 z = 0.6×0.8 + 0.9×(−0.3) + 0.1 = 0.31，y = sigmoid(z) ≈ 0.577，两个读数都用大号数字显示并随滑块拖动即时刷新。读者拖动任意一个滑块，z 和 y 的数字与走线上标出的中间值同步变化，提供一个"复位到初始值"的按钮。这一页只讲单个神经元内部的计算，不比较不同激活函数的形状（下一页专门讲），也不涉及多个神经元如何组成一层。
