# page-04
这一页要让读者相信"一层"不过是把好几个神经元并排放在一起、共享同一份输入。画面标题"从一个神经元到一层"，用一条从左到右的过程图呈现四个阶段：输入向量 → 与权重矩阵相乘 → 加上偏置向量 → 逐元素做非线性激活，每个阶段是一个方框，方框之间用蓝色箭头连接。为了具体，这里用一个 2 输入、2 输出的小例子：输入向量 x=[1.0, 2.0]，权重矩阵第一行 [0.5, −0.3]、第二行 [0.2, 0.4]，偏置向量 [0.1, −0.1]；点击"下一步"按钮，阶段方框依次亮起并显示中间结果：先显示两次加权求和结果 z=[0.0, 0.9]，再显示加激活后的输出 a=[0.500, 0.710]。读者每点一次按钮往前推进一个阶段，也可以点击已经算过的阶段回看该步数字，提供复位按钮回到第一阶段。这一页只建立"层=并排的神经元共享输入"这一个概念，不涉及多层堆叠、也不涉及这层输出之后会发生什么。
