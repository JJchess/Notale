# page-06
这一页要让读者相信"错得有多少"可以被写成一个具体的数字，这个数字就是损失。画面标题"把'错多少'变成一个数"，公式区显示 L = ½(t − y)²，并说明 t 是目标值（这里固定取 1，代表"正确答案"），y 是模型当前的输出。下方一个滑块让读者拖动 y 从 0 到 1，右侧同步显示一条抛物线形的损失曲线，曲线上有一个游标点随 y 移动。具体锚点数值：y=0.1 时 L=0.405；y=0.5 时 L=0.125；y=0.9 时 L=0.005；y=1.0 时 L=0.000。读者拖动滑块时，当前 y 和对应 L 的数字实时刷新在游标旁边，可复位到 y=0.5。这一页只讲"损失是什么、怎么随预测值变化"，不涉及权重、不涉及如何让损失变小——那是下一页梯度下降要回答的问题。
