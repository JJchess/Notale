# page-07
这一页要让读者相信"沿着坡度反方向走，就能走到损失最低的地方"，建立梯度下降最核心的直觉。画面标题"损失是一片地形"，主区域是一张等高线图，代表一个示意性的两参数损失函数 L(w₁, w₂) = (w₁−3)² + (w₂+1)²，最低点在 (3, −1)，等高线以同心方框近似圆形的方式画出，颜色越深代表损失越高。读者可以在图上任意点击一处作为起点（默认起点是 (−2, 2)），点击"下山"按钮后，一个小圆点沿着当前位置的负梯度方向逐步移动，每一步都在图上留下一个淡淡的轨迹点，最终停在最低点附近；提供"重置"按钮清空轨迹并允许重新选起点。这一页只建立"跟着坡度反方向走会更低"的空间直觉，不出现学习率这个参数（下一页专门处理走多大一步），也不涉及真实网络的权重。
