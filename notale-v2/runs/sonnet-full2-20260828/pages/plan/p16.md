# page-16
这一页要让读者亲眼看到前面讲的整套机制真的能训练出一条正确的决策边界，是全课最重要的证据页。画面标题"真的练一遍"，左栏是控制区：一个"训练 1 步"按钮、一个"训练 50 步"按钮、一个 epoch 滑块（范围 0 到 300，可直接拖动跳到任意进度）、一个"重置"按钮；数据集说明文字："二维平面上 40 个点，分两类，排成两条交错的月牙形"（呼应第5页示意图，这次是真实训练）。右栏上半部分是散点图叠加当前决策边界，下半部分是一条损失随 epoch 下降的曲线图，标注当前 epoch 数和当前损失值。读者拖动 epoch 滑块或点击训练按钮，散点图上的边界从初始几乎随机的直线，逐渐弯曲成把两条月牙基本正确分开的曲线，损失曲线同步从初始的较高值下降并趋于平缓；点击"重置"回到 epoch=0 的随机初始状态。这一页不再解释任何公式，只呈现结果，具体的失败情形留给下一页。
