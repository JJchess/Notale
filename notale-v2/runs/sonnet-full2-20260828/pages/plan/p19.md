# page-19
这一页要让读者用两道题自我检验是否真的抓住了学习率和反向传播传递方式这两个关键点。画面标题"检查点"，第一题题干"如果把学习率从 0.1 调到 2.0，最可能发生什么？"三个选项："A. 收敛得更快更稳"、"B. 在最优点附近来回震荡，甚至越走越远"、"C. 损失曲线基本不受影响"。读者点击一个选项后，选中的选项出现描边高亮，下方浮现反馈条：选 B 时反馈条前面是一个"✓"符号加粗显示，文字"没错——这正是第8页里 η=1.05 时轨迹震荡放大的原因"；选 A 或 C 时反馈条前面是一个较淡的"✗"符号，文字"再想想第8页那条震荡的轨迹"。第二题题干"反向传播里，δ_output 要经过什么才能变成 δ_hidden？"三个选项："A. 什么都不用，直接照抄"、"B. 乘以对应的权重，再乘以隐藏层自身的激活导数"、"C. 只和输入 x 有关，与权重无关"，正确答案 B，反馈方式与第一题一致，用符号和字重区分对错，不使用红绿配色。这一页不引入新数字，两题都直接呼应第8页和第13页已经出现过的内容。
