# page-01
这一页要让读者相信这三十分钟能把"神经网络怎么学会东西"讲成一件看得见的机械过程，而不是一句"训练一下就好了"的模糊说法。画面居中呈现主标题《神经网络是怎么学会的：从一个神经元到反向传播》，标题上方一行 kicker 写"30 分钟走线图"，标题下方一行导语："从一个加权求和的神经元开始，一路走到让整张网络自己纠错的反向传播。"再往下用蓝色实线与锈红虚线各画一段短短的走线，交汇于一个小圆点，暗示"预测"和"纠错"是同一条线的两个方向——这是全套课反复出现的视觉母题，这里只作为封面的安静预告，不作任何解释。这一页完全静态，不出现任何数字、不定义任何术语，具体的"神经元""损失""梯度"留给后面逐页展开。

# page-02
这一页要让读者相信"神经元"就是一次加权求和加一次非线性变换，没有更多神秘之处。画面标题"一个神经元在算什么"，下方左栏展示一个具体例子：输入 x₁=0.8、x₂=−0.3 固定不变，两个权重滑块 w₁、w₂ 初始为 0.6 和 0.9，偏置滑块 b 初始为 0.1；右栏用一张小图解画出"输入→乘权重→加总→加偏置→sigmoid→输出"的走线，走线用蓝色实线画出（呼应全套"前向=蓝色"的约定）。当前数值实时显示：z = w₁x₁ + w₂x₂ + b，初始 z = 0.6×0.8 + 0.9×(−0.3) + 0.1 = 0.31，y = sigmoid(z) ≈ 0.577，两个读数都用大号数字显示并随滑块拖动即时刷新。读者拖动任意一个滑块，z 和 y 的数字与走线上标出的中间值同步变化，提供一个"复位到初始值"的按钮。这一页只讲单个神经元内部的计算，不比较不同激活函数的形状（下一页专门讲），也不涉及多个神经元如何组成一层。

# page-03
这一页要让读者相信"没有非线性激活函数，网络就只能是一条直线"，并认识三种常见激活函数的形状差异。画面标题"为什么必须弯一下"，中央是一张坐标图，横轴是输入 z（范围 −4 到 4），同时画出三条曲线：sigmoid（蓝色）、tanh（锈红，仅此一页借用来区分曲线，不代表反向传播语义，图例会明确标注为"tanh"）、ReLU（灰绿描边），图例用色块+文字标出三个名字。读者拖动一个"z ="滑块，三条曲线上同步出现一个游标点，并列出三个数值：z=0 时 sigmoid=0.500、ReLU=0.000、tanh=0.000；z=2 时 sigmoid=0.881、ReLU=2.000、tanh=0.964；z=−2 时 sigmoid=0.119、ReLU=0.000、tanh=−0.964。数值随滑块连续变化实时刷新，不限于这三个锚点。这一页只讲"形状为什么必须弯"以及三种函数的差异，不讨论这些函数在深层网络中会带来的梯度消失问题，那留给后面专门的问题分类页。

# page-04
这一页要让读者相信"一层"不过是把好几个神经元并排放在一起、共享同一份输入。画面标题"从一个神经元到一层"，用一条从左到右的过程图呈现四个阶段：输入向量 → 与权重矩阵相乘 → 加上偏置向量 → 逐元素做非线性激活，每个阶段是一个方框，方框之间用蓝色箭头连接。为了具体，这里用一个 2 输入、2 输出的小例子：输入向量 x=[1.0, 2.0]，权重矩阵第一行 [0.5, −0.3]、第二行 [0.2, 0.4]，偏置向量 [0.1, −0.1]；点击"下一步"按钮，阶段方框依次亮起并显示中间结果：先显示两次加权求和结果 z=[0.0, 0.9]，再显示加激活后的输出 a=[0.500, 0.710]。读者每点一次按钮往前推进一个阶段，也可以点击已经算过的阶段回看该步数字，提供复位按钮回到第一阶段。这一页只建立"层=并排的神经元共享输入"这一个概念，不涉及多层堆叠、也不涉及这层输出之后会发生什么。

# page-06
这一页要让读者相信"错得有多少"可以被写成一个具体的数字，这个数字就是损失。画面标题"把'错多少'变成一个数"，公式区显示 L = ½(t − y)²，并说明 t 是目标值（这里固定取 1，代表"正确答案"），y 是模型当前的输出。下方一个滑块让读者拖动 y 从 0 到 1，右侧同步显示一条抛物线形的损失曲线，曲线上有一个游标点随 y 移动。具体锚点数值：y=0.1 时 L=0.405；y=0.5 时 L=0.125；y=0.9 时 L=0.005；y=1.0 时 L=0.000。读者拖动滑块时，当前 y 和对应 L 的数字实时刷新在游标旁边，可复位到 y=0.5。这一页只讲"损失是什么、怎么随预测值变化"，不涉及权重、不涉及如何让损失变小——那是下一页梯度下降要回答的问题。

# page-07
这一页要让读者相信"沿着坡度反方向走，就能走到损失最低的地方"，建立梯度下降最核心的直觉。画面标题"损失是一片地形"，主区域是一张等高线图，代表一个示意性的两参数损失函数 L(w₁, w₂) = (w₁−3)² + (w₂+1)²，最低点在 (3, −1)，等高线以同心方框近似圆形的方式画出，颜色越深代表损失越高。读者可以在图上任意点击一处作为起点（默认起点是 (−2, 2)），点击"下山"按钮后，一个小圆点沿着当前位置的负梯度方向逐步移动，每一步都在图上留下一个淡淡的轨迹点，最终停在最低点附近；提供"重置"按钮清空轨迹并允许重新选起点。这一页只建立"跟着坡度反方向走会更低"的空间直觉，不出现学习率这个参数（下一页专门处理走多大一步），也不涉及真实网络的权重。

# page-08
这一页要让读者相信"每一步走多大"这个选择本身会决定训练是顺利收敛、缓慢爬行还是直接失控，这个选择的名字是学习率。画面标题"学习率：走多大一步"，用一个更简单的单变量例子把上一页的地形压缩成一条曲线：L(w) = (w−4)²，导数 dL/dw = 2(w−4)，起点 w₀=0，更新公式 w := w − η·dL/dw 显示在公式区。三个可选学习率按钮 η=0.1、η=0.5、η=1.05，点击任意一个后，图上画出对应的更新轨迹点序列（w₀, w₁, w₂, …，取前 6 步）：η=0.1 时轨迹缓慢逼近 4（w₁=0.8, w₂=1.44, w₃=1.952…）；η=0.5 时轨迹迅速逼近 4（w₁=4.0，一步到位，因为 2×0.5=1 恰好抵消系数）；η=1.05 时轨迹在 4 附近来回震荡并逐步放大（w₁=8.4, w₂=−0.8, w₃=17.84…，明显发散）。读者切换三个按钮即可对比三条轨迹叠加或分别显示，提供复位按钮回到未选择状态。这一页只讲学习率这一个参数的作用，不涉及多变量、也不涉及具体网络里的权重更新，那是后面第14页要处理的事。

# page-09
这一页要让读者复习并信任链式法则——反向传播接下来全部依赖这一条法则，而它其实只是"把几步导数按顺序乘起来"。画面标题"链式法则：拆开再乘起来"，用一张带三段标注的公式卡呈现具体例子 f(x) = σ(2x + 1)，在 x=0 处求导。卡片从上到下分三行展开：第一行"外层线性：u = 2x+1，在 x=0 处 u=1"，第二行"套上 sigmoid：σ(1) ≈ 0.731，它对 u 的导数 σ(1)·(1−σ(1)) ≈ 0.731×0.269 ≈ 0.197"，第三行"u 对 x 的导数是 2"。读者点击每一行可以展开该行的具体算式，三行都展开后，页面在卡片底部显示最终乘积 df/dx ≈ 0.197 × 2 ≈ 0.393，并用一句话总结："链式法则就是把每一步的局部导数依次乘起来。"这一页是纯粹的数学工具铺垫，不出现网络结构、不出现损失函数，是为第12、13页的推导做准备。

# page-10
这一页要让读者亲眼看着一个具体的小网络把输入一步步算成输出，为随后的反向传播提供一份完全同一套数字的素材。画面标题"正向传播：走一遍完整的计算"，左栏文字固定列出网络设定：输入 x=[1.0, 2.0]；隐藏层权重 W1 第一行 [0.5, −0.3]、第二行 [0.2, 0.4]，偏置 b1=[0.1, −0.1]；输出层权重 W2=[0.7, −0.5]，偏置 b2=0.2；目标 t=1。右栏是一条竖排的过程图，读者点击"下一步"依次揭示：第一步 z_h1 = 0.5×1.0 + (−0.3)×2.0 + 0.1 = 0.000，a_h1 = sigmoid(0.000) = 0.500；第二步 z_h2 = 0.2×1.0 + 0.4×2.0 − 0.1 = 0.900，a_h2 = sigmoid(0.900) ≈ 0.710；第三步 z_o = 0.7×0.500 + (−0.5)×0.710 + 0.2 = 0.195，ŷ = sigmoid(0.195) ≈ 0.549；第四步 L = ½(1 − 0.549)² ≈ 0.102。每一步的数字用蓝色写在对应的方框里，箭头统一是蓝色实线。提供"复位"按钮回到第一步重新点。这一页只算前向，完全不涉及导数或梯度，那从下一页开始处理。

# page-11
这一页要让读者建立"误差会沿着同一张网络往回走"这个方向性的直觉，在动手算任何数字之前先把方向感立住。画面复用上一页那张网络结构图（输入、隐藏层两个神经元、输出），标题"反向传播：同一张网，另一个方向"，图上有一句话反复出现在每个箭头旁："这一层在问：如果我改变一点点，最终的损失会怎么变？"页面中央一个大按钮在"正向"和"反向"两态之间切换：切到"正向"时，所有走线是蓝色实线、箭头从输入指向输出；切到"反向"时，所有走线变成锈红虚线、箭头从输出指向输入，其余结构完全不变。这一页完全不出现任何具体数字，只做方向和颜色的切换，目的是让读者把"前向蓝色/反向锈红"这套约定和"同一条连接、两个方向"这个关系记牢，具体的反向数值从下一页开始逐步展开。

# page-12
这一页要让读者看到反向传播的第一步具体怎么算：从损失出发，算出输出层那个神经元该往哪个方向、多大力度调整。画面标题"反向传播第一步：输出层的误差信号"，沿用第10页的数字：ŷ≈0.549，t=1。用一条横排过程图分三段：第一段"损失对输出的导数：dL/dŷ = ŷ − t = 0.549 − 1 = −0.451"，第二段"输出对求和值的导数：dŷ/dz_o = ŷ(1−ŷ) = 0.549×0.451 ≈ 0.248"，第三段"两者相乘得到 δ_output = −0.451 × 0.248 ≈ −0.112"。读者点击每一段可展开对应的算式细节，三段展开后自动在末尾高亮显示 δ_output ≈ −0.112，并用一句话呼应第9页："这就是链式法则——把两步局部导数乘起来。"这一页只算到输出层这一个数，不涉及它接下来怎么传给隐藏层的两个神经元，那是下一页的内容。

# page-13
这一页要让读者看到刚算出的那一个误差信号 δ_output，是怎么按不同的权重分别加权传回两个隐藏神经元的。画面标题"反向传播第二步：传回隐藏层"，图上画出两条从输出神经元分别通向隐藏神经元1和隐藏神经元2的支路，都是锈红虚线。读者可以点击任意一个隐藏神经元查看它专属的传回算式：点击隐藏神经元1显示"δ_h1 = δ_output × W2_1 × a_h1(1−a_h1) = −0.112 × 0.7 × 0.5 × 0.5 ≈ −0.0196"；点击隐藏神经元2显示"δ_h2 = δ_output × W2_2 × a_h2(1−a_h2) = −0.112 × (−0.5) × 0.710 × 0.290 ≈ 0.0115"。两条支路旁标注对应的权重值 W2_1=0.7、W2_2=−0.5，强调"同一个 δ_output，被不同的权重分别加权，传给不同的神经元"。这一页只算到两个 δ_h，不涉及这些数值最终如何变成权重的更新量，那是下一页要做的事。
