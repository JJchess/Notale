# page-02

这一页教会读者一件事：一个神经元在做什么，只是“把输入按权重加起来，再加一个偏置”。用 `.layout-focus`：左侧 `.stage-main` 画一张简化电路图——两个输入端子 `x1`、`x2` 各引出一条导线（用 `.weight` 色，粗细随权重绝对值变化）汇入一个圆形汇合节点，节点里显示当前的加权和数值；右侧 `.stage-side` 放三个 `.ctl` 滑条：`w1 ∈ [-2,2]`、`w2 ∈ [-2,2]`、`b ∈ [-2,2]`，初始 `w1=0.8, w2=-0.5, b=0.1`，固定输入 `x1=1, x2=1`。用 KaTeX（20px 基准）在节点上方常驻公式 `z = w_1x_1 + w_2x_2 + b`，下方是当前代入的数字，随滑条实时刷新，例如初始状态显示 `z = 0.8×1 + (-0.5)×1 + 0.1 = 0.40`，用 `.big.sm` 展示这个 0.40。拖动任意滑条，导线粗细、节点里的数字、公式下方的代入式都同步变化。这一页不出现激活函数、不出现“分类”，那是下一页和第四页的事；这里只让读者亲手感受“权重决定每条输入的话有多重”。
