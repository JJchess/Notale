# page-10

这一页要把“梯度”从比喻还原成一个具体的数：它是“权重稍微动一下，损失变化多少”。继续用第七页的算例，聚焦单个权重 `w11`（当前值 0.5）。用 `.layout-split`：左侧放一个滑条，范围 `w11±0.05`，步进 0.001，右侧显示两个并排读数——“数值估计”和“解析梯度”。数值估计的做法写清楚给读者看：把 `w11` 微调 `ε=0.001` 变成 0.501，重新走一遍第七页的前向传播算出新的损失 `L(0.501)`，与原始 `L(0.5)=0.497` 的差除以 `ε`，结果约为 `-0.063`；解析梯度用链式法则直接给出同一个数 `∂L/∂w_{11}≈-0.063`（这就是第十一、十二页要展开推导的那条链）。滑条拖动时，右侧“数值估计”读数跟随微调量实时重算，读者能看到不管怎么把 `ε` 缩小，两种算法都收敛到同一个 -0.063 附近。这一页不展开链式法则的推导过程，那是下一页的任务；这里只建立“梯度=变化率，两种算法算出同一个数”的信任。
