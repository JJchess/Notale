本套无需图池

# page-01 [标题页]
全课开场：说明为什么理解神经网络要从一个神经元讲起，并预告本课从神经元到反向传播的整体路线。

# page-02 [内容页]
讲解单个神经元的结构：多个输入分别乘以权重再加上偏置，如何组合成一个加权和。

# page-03 [内容页]
讲解激活函数的作用：为什么加权和算出来之后还要经过一个非线性函数才成为神经元的输出。

# page-04 [交互页]
交互调整一个神经元的权重和偏置，观察其输出数值和形态如何随之变化。

# page-05 [标题页]
第二章：神经元怎样连成网络——本章回答一个输入信号如何在层与层之间逐步传递并算出最终输出。

# page-06 [内容页]
讲解网络的分层结构：输入层、隐藏层、输出层各自承担的角色，以及层与层之间如何相连。

# page-07 [内容页]
讲解前向传播：一个输入从输入层出发，逐层计算，最终在输出层得到网络的预测结果。

# page-08 [交互页]
交互演示一个小型多层网络的前向传播过程，逐层查看每一步的数值是如何算出来的。

# page-09 [内容页]
讲解为什么需要多层结构和非线性激活函数，才能让网络表达比一条直线复杂得多的关系。

# page-10 [标题页]
第三章：网络怎么知道自己错了——本章回答网络的预测与真实答案之间的差距该如何被衡量。

# page-11 [内容页]
讲解损失函数的概念：如何用一个数字概括网络预测值和真实值之间的差距。

# page-12 [内容页]
讲解损失如何随参数取值不同而变化，从而在参数空间里形成一整片高低起伏的损失曲面。

# page-13 [交互页]
交互调整网络的参数，同步观察对应的损失数值以及在损失曲面上位置的变化。

# page-14 [标题页]
第四章：学习的机制——本章回答网络在知道自己错了之后，如何一步步调整参数来减小误差。

# page-15 [内容页]
讲解梯度的含义：它指向损失增大最快的方向，理解这一点是理解“往反方向走”的关键。

# page-16 [内容页]
讲解梯度下降算法：沿着梯度的反方向小步调整参数，使损失逐步降低的完整过程。

# page-17 [交互页]
交互演示梯度下降在损失曲面上一步一步向较低点移动的过程。

# page-18 [内容页]
讲解学习率的作用，以及学习率取得过大或过小时分别会给下降过程带来什么后果。

# page-19 [交互页]
交互调整学习率的大小，观察梯度下降的路径形态和收敛速度发生怎样的变化。

# page-20 [标题页]
第五章：反向传播——本章回答最终的误差如何一路传回网络中每一层的参数。

# page-21 [内容页]
讲解链式法则的直觉：在一个多层网络里，最终的误差如何被逐层归因到更靠前的参数上。

# page-22 [内容页]
讲解反向传播算法的整体过程：误差信号从输出层出发，逐层向输入层方向传递并计算出每一层的梯度。

# page-23 [交互页]
交互演示反向传播在一个小型网络中的误差信号传递过程，逐层查看梯度的大小变化。

# page-24 [交互页]
通过代码演示训练一个小型神经网络的完整过程，观察损失数值随训练轮次逐步下降。

# page-25 [标题页]
收束：把前向传播、损失计算、反向传播、参数更新连成一个完整的学习循环，回望整节课的路线。

# page-26 [内容页]
回顾整节课讲过的完整学习循环，并留下一个开放性问题供读者课后继续思考。
