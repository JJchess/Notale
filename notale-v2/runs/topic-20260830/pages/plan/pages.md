# page-01 [标题页]
《神经网络是怎么学会的》：用一个神经元、一个损失和一条梯度路径回答模型如何从错到会。

# page-02 [目录页]
四章依次回答神经元如何计算、模型如何知道错、误差如何传回参数、训练为何能形成可泛化的能力。

# page-03 [标题页]
第一章：一个神经元在做什么——本章回答输入如何经过权重与偏置变成输出。

# page-04 [内容页·static]
把神经元看成一个可检查的计算单元：输入、权重、偏置、加权和与激活函数各自承担什么角色。

# page-05 [内容页·interactive]
改变输入和权重，观察加权和及激活后的输出如何响应，从而建立参数不是标签而是计算规则的直觉。

# page-06 [内容页·static]
用分类边界连接单个神经元与几何直觉：权重决定方向，偏置移动边界，激活函数决定输出表达方式。

# page-07 [标题页]
第二章：模型怎么知道自己错了——本章回答预测与目标之间的差距如何成为可计算的损失。

# page-08 [内容页·static]
区分目标、预测、残差与损失，并说明损失函数把一次样本的偏差汇总成可比较的标尺。

# page-09 [内容页·interactive]
在预测值与目标值之间移动，比较平方损失和绝对损失的变化，形成“离得越远，代价如何增长”的感受。

# page-10 [内容页·static]
从一维损失曲线进入参数空间：曲线的斜率表示局部上坡方向，低处代表当前定义下更好的参数。

# page-11 [内容页·static]
解释训练目标不是记住一个答案，而是寻找一组能让许多样本总体损失变小的参数。

# page-12 [标题页]
第三章：误差怎样传回去——本章回答反向传播如何用链式法则分配每个参数的责任。

# page-13 [内容页·static]
把前向计算拆成有向步骤，并为每一步标出局部导数，说明最终输出对中间量的依赖可以逐段记录。

# page-14 [内容页·interactive]
沿着一条计算路径改变局部量，观察链式相乘如何得到某个参数对损失的梯度，建立“责任沿路径传递”的直觉。

# page-15 [内容页·static]
对照数值微分与反向传播：一个用微小试探估计斜率，一个复用中间结果高效计算许多参数的导数。

# page-16 [内容页·static]
从单个神经元推广到多层网络，说明梯度在层间传递、参数共享计算图结构，以及深层网络中的梯度变小或变大。

# page-17 [标题页]
第四章：一次更新如何变成学习——本章回答梯度、学习率与数据循环如何共同改变模型。

# page-18 [内容页·interactive]
在损失地形上改变学习率并执行更新，比较小步、合适步长与越过低点时的轨迹，形成优化稳定性的直觉。

# page-19 [内容页·static]
串起训练循环：取样本、前向计算、计算损失、反向传播、更新参数，再重复并记录损失变化。

# page-20 [内容页·static]
区分训练集上的下降与新样本上的表现，用过拟合和验证集说明“学会规律”不等于“把样本背下来”。

# page-21 [内容页·interactive]
在一个小型分类任务上观察训练步数、模型复杂度与泛化表现的共同变化，并据此判断何时应停止或调整训练。

# page-22 [内容页·static]
用一张因果链收束全课：参数定义计算，预测产生损失，链式法则产生梯度，更新反复改变参数，数据分布决定泛化边界。
