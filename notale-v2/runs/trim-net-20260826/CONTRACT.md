## 1. 这堂课在讲什么

全课主张：神经网络的“学习”不是获得神秘能力，而是让内部参数根据误差给出的方向反复小改，使预测逐渐接近答案。反向传播负责把这条改动建议从输出端逐层传回去。

五幕任务：

1. 01–03：把学习变成可观察的问题。让读者看到模型学会前后，真正变化的是内部数字。
2. 04–08：拆开一个神经元的预测。输入经过权重、偏置和激活函数，得到 0–1 数值；预测与答案必须进入同一误差标尺。
3. 09–12：教会一个参数。轻推参数、比较两侧误差、找到下降方向，再朝该方向小改一步。
4. 13–17：从一个神经元扩展到多层网络。直边界不足以处理弯曲分类；隐藏层通过组合特征改变可表达的边界。
5. 18–21：连接反向传播与完整训练。输出误差逐层分配责任，整组参数在训练循环中共同变化。

全课证据链必须保持为：

- E1：输出由输入、权重、偏置和激活函数共同算出，不是规则文字。
- E2：预测与已知答案进入同一误差标尺后，才有可比较、可优化的“做得多差”。
- E3：在当前位置轻推参数并比较两侧误差，可以判断上升与下降方向；学习一步就是朝下降方向小改。
- E4：对多条样本重复“预测—算误差—改参数”形成训练；步子太小会慢，太大会越过低处。
- E5：多层网络用反向传播逐层计算责任，使隐藏层参数也能学习。

每页只实现自己的 `pNN.md`。本页规格未要求的结论、术语、公式、例子和交互均“不许碰”，由指定页面负责，不得提前讲解、重复证明或补成微型总课。01、03、12、20、21 无交互；其他页面是否交互及交互目标只按本页规格执行。

跨页对象语法固定：计算信息从左向右；责任建议从右向左；计算连接为 3px 单向实线箭头。神经元为直径 72px 的圆，参数为圆角 8px 标签，样本为方形卡片。当前计算路径使用 5px 外轮廓，其余路径为 2px。误差用带刻度的竖直差距尺和黑白斜纹区表达。更新记录统一写成“改前 → 改后”。页面按“问题—操作—读数”组织，相邻区块至少留 40px。

## 2. 颜色语义

| token / 色相 | 唯一含义 | 允许出现的位置 |
|---|---|---|
| `--paper` / `#F4F1E8` | 实验记录纸底色 | 页面底色、留白区 |
| `--model` / `#176B87` | 模型当前算出的数值、路径或决策区域 | 当前预测值、前向计算路径、模型决策边界与区域 |
| `--focus` / `#F59E0B` | 教师此刻指向或用户正在操作的对象 | 当前指示、正在拖动的参数、本步刚出现的箭头；步骤结束立即撤除 |
| 主题中性色 | 无概念含义的结构与文字 | 正文、边框、坐标轴、网格、非当前路径、正确答案、背景辅助线 |
| 黑白斜纹 | 误差差距，不编码正误类别 | 差距尺、误差区 |

语义色不得用于装饰、章节区分、正确/错误、按钮美化或制造随机层级。正确答案不得借用 `--model`；需要区分时使用文字、形状、线型或主题中性色。所有信息在灰度投影下仍须可辨，不得只靠颜色表达方向、类别、选中或误差大小。

## 5. 技术契约

页面骨架固定为：

    <!doctype html>
    <html lang="zh">
    <head>
      <meta charset="utf-8">
      <link rel="stylesheet" href="assets/base.css">
      <link rel="stylesheet" href="assets/theme.css">
    </head>
    <body data-page="NN" data-total="21">
      <div id="stage"></div>
      <script src="assets/base.js"></script>
      <script src="assets/lec.js"></script>
    </body>
    </html>

只修改 `#stage` 的内容。`data-page` 必须是两位页码，`data-total="21"`；不得在主画面显示页码。

逻辑画布固定为 1600 × 900，不得产生页面或内部滚动。`#stage` 使用 flex 列布局；顶层区块给固定高度或 flex 份额，主内容区使用 `flex:1`。默认使用 flex，只有真正需要横纵二维对齐时才用 grid。

字号只使用主题 token。正文和成句说明不小于 16px；控件标签、图例、图注、提示不小于 14px；仅含数字的刻度不小于 12px；多行文字行高不小于 1.35。字体、颜色、圆角、阴影和共享组件取自主题接口。一次性尺寸可内联，不为单页尺寸新造公共类。

不得移除、覆盖或绕过 `.min0`、`.cv-fill`、`.no-pan` 的机制。缩放画布内禁止 `position:fixed`。页面必须自包含运行，只引用 `pages/` 内的相对路径，不使用 CDN。

| 用途 | 库 |
|---|---|
| 常规坐标轴、折线、柱、散点、热力 | `echarts.min.js` |
| 可拖拽、可命中二维图形 | `konva.min.js` |
| 节点连线、矢量图形、数据绑定 | `d3.min.js` |
| 小型二分类网络实时训练与决策边界 | `mlp.js` |
| 大模型、真实图片卷积、GPU 大矩阵 | `tf.min.js` |
| 物理运动与约束 | `matter.min.js` |
| 三维、地球、生成背景 | `three.min.js`；按需追加 `globe.gl.min.js` 或 `vanta.net.min.js` |
| 分步或时间线动画 | `anime.min.js`、`gsap.min.js`；滚动绑定再加 `ScrollTrigger.min.js` |
| 大量二维元素、矢量动画、伪三维、指针倾斜、淡入 | `pixi.min.js`、`lottie.min.js`、`zdog.min.js`、`vanilla-tilt.min.js`、`aos.js` |
| 公式、矩阵、可复现随机 | `katex.min.js`、`ml-matrix.umd.js`、`seedrandom.min.js` |

图表优先使用已安装库，不重复实现成熟能力。ECharts 必须以 `echarts.init(el, null, {renderer:'svg'})` 初始化，并显式设置全局文字 ≥16px、带词句的轴标签/图例 ≥14px、纯数字刻度 ≥12px。Konva 用于图形；文字优先用可检查字号的 DOM 叠加，必须使用 `Konva.Text` 时显式设置字号。KaTeX 必须同时引用 `katex.min.css`，统一以不小于 20px 的基准字号排版。

Canvas 必须使用 `Deck.fit()` / `Deck.autofit()` 适配，指针坐标使用 `Deck.pt()`，动画使用 `Deck.loop()`。使用 Konva 时由其指针系统换算，不再手写第二套坐标转换。

小型实时网络直接使用 `mlp.js`，不得用 tf.js 替代或重写同等训练循环。只有加载预训练模型、真实图片卷积或 GPU 大矩阵时才使用 tf.js；每步以 `tf.tidy()` 或 `dispose()` 释放张量。随机生成、抽样或初始化必须使用 `seedrandom.min.js` 和固定种子。

教学常量、范围、初值和结果必须来自 `Lec.K` / `Lec.P` 并在当前页面当场计算。禁止预录结果、硬编码训练读数、伪造曲线或使用与交互脱节的假数据。首屏必须静止且已包含可讲信息；动画不能是理解首屏的前提。

公开接口仅按下列签名和字段使用，不读取 `lec.js` 源码：

Lec.K(常量): BCE_CLIP_EPSILON、CENTRAL_DIFFERENCE_STEP、RELU_SLOPE_NON_POSITIVE、RELU_SLOPE_POSITIVE、SIGMOID_MAX_SLOPE、SIGMOID_VALUE_AT_ZERO  
Lec.P(2 个函数,参数名和返回键如下,不用再去读 lec.js 源码):  
  for(i = 0; i < count; i += 1)  
  if(!layer || typeof layer !== "object")

## 7. 文字风格

面向无微积分、线性代数和编程基础的大学通识课学生。先说对象和动作，再给术语；术语首次出现时用一句人话解释。公式只使用普通算术可解释的短式，不连续推导，不展示代码语法或终端输出。

使用适合教师口述的短句：一句只承担一个判断或动作，尽量不超过 24 个汉字；按钮使用动词，提示直接说明“调什么、看哪里”。操作提示使用“拖动 `w`，观察误差尺”，不使用命令式责备或“答错了”。删除“如图所示”“显而易见”“接下来我们将”以及评价课程设计的元评论。

参数名、数值变化和训练步数使用等宽字体。关键数字同时给可感换算，例如“误差从 0.40 降到 0.20，差距减半”。近似值标 `≈`；受样本、随机种子或初值影响的结论明确写“这次运行中”或给出范围，不把偶然读数写成恒真结论。

每页唯一结论使用衬线体。收束句只写本页允许读者带走的主张，不复述页面流程；下一问只负责推进到下一证据缺口，不提前给答案。
