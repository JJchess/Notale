# 《神经网络是怎么学会的：从一个神经元到反向传播》 30 分钟互动讲义 · 总规划

## 0. 这套讲义的主线

神经网络的“学习”，就是用误差指出参数该往哪边改，反复小改后让预测更接近答案；反向传播则把这条改动建议从输出端逐层传回去。

| 章 | 页 | 这一章要让读者信什么 |
|---|---|---|
| I. 把“学习”变成可观察的问题 | 01–03 | 学会不是获得神秘能力，而是模型内部的一些数字发生了有方向的变化 |
| II. 一个神经元怎样做预测 | 04–08 | 输入经过权重、偏置和压缩后成为概率，误差给预测好坏一个可比较的分数 |
| III. 一个参数怎样被教会 | 09–12 | 轻推参数并比较误差，就能找到下降方向；训练是重复“小改一步” |
| IV. 从一个神经元到多层网络 | 13–17 | 单个神经元只能画直边界，多层网络通过隐藏特征组合出弯曲边界 |
| V. 反向传播与完整训练 | 18–21 | 反向传播逐层分配责任，真实训练循环会让整组参数共同改变并降低误差 |

- E1：神经元的输出不是规则文字，而是由输入、权重、偏置和激活函数共同算出的 0–1 数值。
- E2：只有把预测与已知答案放进同一误差标尺，模型才有可优化的“做得多差”。
- E3：在当前位置轻推参数并比较两侧误差，可以得到误差上升与下降的方向；学习一步就是朝下降方向小改参数。
- E4：对多条样本反复执行“预测—算误差—改参数”，会形成训练过程；步子太小会慢，太大会越过低处。
- E5：多层网络中，反向传播把输出误差沿连接逐层传回，为每个参数算出责任大小，使隐藏层也能学习有用特征。

## 0.5 视觉世界

- 现实参照：大学基础实验课的实验记录本；参数、观测值和改动前后结果都像一项可复查实验，适合教师投影讲解，也便于课后按步骤重看。
- 形状语言：
  1. 所有计算连接使用 3 px 单向实线箭头，信息流向始终从左到右，避免依赖颜色辨认方向。
  2. 神经元使用直径 72 px 的圆，参数使用圆角 8 px 的小标签，数据样本使用方形卡片，形状直接区分对象类别。
  3. 当前计算路径使用 5 px 外轮廓，其余路径降为 2 px，不靠缩小非重点文字制造层级。
  4. 误差用带刻度的竖直“差距尺”和黑白斜纹区表示，确保投影偏色时仍能看出大小。
  5. 页面按实验记录的“问题—操作—读数”分区，区块间至少留 40 px 空白，不使用厚重卡片阴影。
- 底色：亮色取向 `#F4F1E8`；接近纸张的暖灰能降低纯白投影眩光，并保持黑字在教室后排的对比度。
- 主色相：`#176B87`，唯一代表模型当前算出的数值、路径和决策区域；它不代表正确答案或注意焦点。
- 强调色：`#F59E0B`，只用于教师当前指向、正在拖动的参数或本步新出现的箭头，离开当前步骤立即撤除。
- 字体：衬线体承担每页唯一结论和章间提问；无衬线体承担正文、标签和按钮，以降低混合背景学生的识字负担；等宽字体只承担参数名、数值变化和训练步数，便于纵向比较。
- 材质：线性扁平图解为主；网络结构和误差曲线必须保持清晰可量读，不使用拟物发光、玻璃或装饰性三维。
- 母题：
  1. 带刻度的误差差距尺，跨页显示“离答案还有多远”。
  2. 参数旋钮 `w`、`b` 和学习率旋钮，表示真正被修改的数字。
  3. 从左向右的预测箭头与从右向左的责任箭头。
  4. 实验记录行“改前 → 改后”，固定并列每次参数更新。
  5. 二维点阵与决策边界，承接单神经元和多层网络的能力比较。

被否决的整体方向：

- 否决“霓虹发光的大脑与神经突触”：它会暗示课程在解释生物脑机制，且暗底霓虹在亮教室投影中容易丢失细线和小节点。
- 否决“代码编辑器与终端输出”：读者不具备编程前提，代码会把注意力从参数、误差和因果关系转移到语法。
- 否决“公式黑板推导”：连续符号推演依赖微积分与代数熟练度，不适合 30 分钟通识课堂；本课只保留可用普通算术解释的短式和图形读数。

## 0.6 对这个受众的取舍

- 能用：加减乘、正负方向、旋钮调节、山坡高低、考试答案与扣分、反复试错的生活经验。
- 不用：矩阵乘法、向量记号、导数极限、偏导符号、链式法则公式、softmax、卷积、正则化、优化器谱系和生物神经元细节。
- 换算：概率统一换成“100 次相似情况中模型押多少次”，误差换成差距尺高度，梯度换成“参数旋钮每转一点，误差会上升还是下降”。
- 争议：反向传播是工程中的有效学习算法但不是人脑学习机制的定论；训练误差下降不保证模型面对新数据、公平性要求或现实变化时仍可靠。
