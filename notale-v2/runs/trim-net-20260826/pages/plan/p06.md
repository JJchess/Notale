# page-06 · 同一条计算路 · **75 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `SAME RULE · NEW SAMPLE` |
| 主标题 | 四条样本，都走同一条计算路 |
| 收束句 | 换的是输入；`w=0`、`b=0` 和计算步骤始终不变。 |
| 下一问 | 四次预测都是 `0.5`，怎样判断它们做得有多差？ |

## 知识结构：comparison

**关系不变量**：四条样本必须按同一列宽逐行对齐，共享 `输入 → 乘权重 → 加偏置 → 激活 → 预测` 五列；参数标签固定在表头，所有数值使用同一小数精度与基线，当前行只强化轮廓，不改变尺度。

**共享原语**：`.ledger` 将“问题—操作—读数”纵向排列，中央用 `.k-comparison` 保证四行同尺度比较；`.sample` 区分输入样本，`.param` 固定标出共享的 `w=0`、`b=0`，`.path` 连接当前行的左到右计算路径。

## 表征形式

交互式逐行计算账本：学生点选任一样本，中央路径展开该行算术，底部读数同步显示预测 `0.500`；已看过的行保留中性记录。

使用原生 DOM 与 SVG；表格、短算术和单向路径无需额外可视化库。

## 主工作流

design-interaction ← 让逐条试算明确证明“样本改变、规则与参数不变”

## 四条预测记录

页面表头固定显示：`共享参数：w = 0，b = 0`。

| 样本 | 输入 `x` | 已知答案 `t` | `x × w` | `+ b` 后总分 | 激活后预测 |
|---|---:|---:|---:|---:|---:|
| 1 | -2 | 0 | `-2 × 0 = 0` | `0 + 0 = 0` | `0.500` |
| 2 | -1 | 0 | `-1 × 0 = 0` | `0 + 0 = 0` | `0.500` |
| 3 | 1 | 1 | `1 × 0 = 0` | `0 + 0 = 0` | `0.500` |
| 4 | 2 | 1 | `2 × 0 = 0` | `0 + 0 = 0` | `0.500` |

激活读数使用显示常量：

| 常量 | 画面文字 | 值 |
|---|---|---:|
| `SIGMOID_VALUE_AT_ZERO` | `总分 0 → 预测 0.5` | 0.5 |

## 交互

默认选中样本 1。学生可点击任一行，或使用“上一条”“下一条”；当前样本获得 5 px 外轮廓，计算路径依次显示该行的 `x`、乘法结果、总分和预测。键盘方向键执行同样切换，焦点始终可见。

每次切换只替换输入与逐步算术；表头中的 `w=0`、`b=0` 保持不动，使学生观察到不同输入经过完全相同的操作。四行都查看后，在读数区显示：“4 条输入不同，4 次规则相同，预测都是 0.500。”

提供“重置本页”，恢复样本 1，并清除已查看标记。

## 动效

切换样本时，强调色沿当前行从左向右移动四段，每段 140 ms、错开 90 ms；抵达预测读数后立即撤除强调色，仅保留模型色当前路径。减少动态模式下取消移动，改为四段同时显现。

## 核对

| 参数 | 期望总分 | 期望预测 |
|---|---:|---:|
| `x=-2, w=0, b=0` | 0 | 0.500 |
| `x=1, w=0, b=0` | 0 | 0.500 |
| `x=2, w=0, b=0` | 0 | 0.500 |

不得因 `x` 的正负号把零显示成 `-0`；画面统一显示 `0`。

## 不许碰

不得提供旋钮、滑块或任何修改 `w`、`b` 的入口；人工调参归 p08。不得计算误差、评价哪条预测更差或解释交叉熵，误差定义归 p07。
