# page-07 · 风切变让结构难对齐 · **90 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `ENERGY ≠ ORGANIZATION` |
| 主标题 | 上下层风差越大，台风越难上下对齐 |
| 收束句 | 暖海面可以供能，但较大的垂直风切变会妨碍台风维持竖直结构，因此暖海不是增强的充分条件。 |
| 下一问 | 暖层、风切变和陆地，分别属于哪一类条件？ |

## 知识结构：process

1. **关系不变量**：下层风、上层风必须使用同一原点、方向和速度尺度；两箭头端点由差矢量相连，再顺序连接到右侧同高度分带中的结构偏移，形成“上下层风 → 矢量差 → 难以对齐”。
2. **禁止画法**：不得把上下层风拆成尺度不同的独立卡片，也不得用台风整体平移箭头表现风切变。
3. **共享原语**：`.split-lr` 左侧放共享矢量尺与计算读数，右侧放竖直结构结果；`.k-process` 用 `.step` 与 `.arw` 串起输入、差值和结构响应；`.panel` 承载可操作矢量尺与实时数值。

## 表征形式

交互式二维矢量尺与分层台风剖面。使用原生 SVG：四个速度分量需要共享线性尺度、可拖端点和精确键盘控制，SVG 比常规图表更直接。坐标范围东西、南北均为 `−25–25 m/s`，等比例尺度；环境风画直线箭头，台风环流只画闭合螺旋线。状态改变时调用 `Lec.P.verticalWindShear(...)`，随后更新 SVG 属性、读数文本和结构偏移 class；不显示工具提示浮层。

## 主工作流

design-interaction ← 让两支可操作风矢量在共享尺度上即时生成差矢量与结构反馈

## 两层风与结果

| 画面对象 | 默认内容 | 显示口径 |
|---|---:|---|
| 下层环境风 | 东向 `5 m/s`，北向 `2 m/s` | 实线深青蓝箭头，标签“下层风” |
| 上层环境风 | 东向 `20 m/s`，北向 `8 m/s` | 实线深青蓝箭头，标签“上层风” |
| 上下层风差 | 东向 `15 m/s`，北向 `6 m/s` | 橙红端点连线，标签“风切变” |
| 风切变大小 | `16.2 m/s` | 页面实时计算，等宽数字 |
| 经验参照带 | `<10 较有利`；`10–20 影响增大`；`>20 较强` | 只作环境量级参照，不作单一判据 |
| 结构反馈 | “上下层中心较难保持对齐” | 右侧高层螺旋相对低层偏移，不画移动路径 |

经验参照来源：NOAA/NHC 热带气旋发展条件资料；页面短标法写 `NOAA/NHC`。

## 交互

学习者可拖动“下层风”和“上层风”的箭头端点；每个东西、南北分量范围均为 `−25–25 m/s`、步长 `1 m/s`，默认值见表。方向键每次改变 `1 m/s`，Shift＋方向键改变 `5 m/s`。操作后立即更新两箭头、端点间差矢量、风切变读数、参照带位置及右侧上下层中心偏移。

结构偏移只表达“更难对齐”的趋势：`0–10 m/s` 近似对齐，`10–20 m/s` 逐渐偏移，`20 m/s` 以上达到示意最大偏移，不继续外推。提供“恢复示例”按钮；交互没有正确位置。

## 核对

- `Lec.P.verticalWindShear(5, 2, 20, 8)` → 差分量 `(15, 6) m/s`，大小约 `16.2 m/s`。
- `Lec.P.verticalWindShear(5, 2, 5, 2)` → `0.0 m/s`，上下层中心对齐。
- `Lec.P.verticalWindShear(-5, 0, 15, 0)` → `20.0 m/s`；确认先算“上层减下层”，再取模，反向分量不得相加遗漏。

## 不许碰

不把上下层环境风合成为台风移动方向，也不讲各气层如何加权；多层引导风归 p10。本页只说明垂直风切变对结构组织的限制，不断言暖海供给的能量会按固定比例转化为风速。
