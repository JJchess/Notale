# page-04 · 暖海面如何补给台风 · **100 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `ENERGY INPUT` |
| 主标题 | 海面越暖、空气越不饱和，蒸发补给的潜力通常越大 |
| 收束句 | 暖海面与较干的近海面空气共同拉大“水汽缺口”，让更多水汽和能量有机会进入空气。 |
| 下一问 | 还差什么，才能把这种潜力变成每平方米的实际通量？ |

## 知识结构：process

1. **关系不变量**：海面饱和比湿、近海面空气实际比湿和两者之差必须使用同一 `g/kg` 尺度；“海面状态 → 水汽缺口 → 向上补给潜力”必须连续相连。左栏画海气两层，右栏将两个湿度读数按相同高度基线对齐。
2. **禁止画法**：不得把海温和空气湿度拆成两张互不对齐、各自得出结论的卡片；补给潜力来自二者之差，不是任一滑杆的单独效果。
3. **共享原语**：`.split-lr` 左侧承载海气剖面、右侧承载同尺度读数与控件；`.k-process` 用 `.step` 与 `.arw` 串起三个因果环节；`.panel` 包住实时仪表，`.ctl` 承载双滑杆。

## 表征形式

交互式海气剖面与水汽缺口仪表。使用原生 DOM＋SVG：图形仅含两条水平分带、向上箭头、两条共享尺度量条和差值括号，原生实现更利于投影清晰度与无障碍标注。

SVG 使用线性共享尺度 `0–30 g/kg`；海面饱和值与空气实际值均从同一零点延伸，缺口用两端括号表示。滑杆 `input` 事件调用计算接口，更新 SVG 属性、箭头数量/长度及 `textContent`；复位按钮恢复默认状态。

## 海气状态与实时读数

| 项目 | 画面文字或数值 | 口径 |
|---|---|---|
| 海面温度 | `26.0–31.0°C`，默认 `29.0°C`，步长 `0.5°C` | 学生操纵 |
| 暖海经验参考 | `约 26.5°C：经验参考，不是开关` | `Lec.K.warmSeaSurfaceReferenceC = 26.5` |
| 近海面空气相对湿度 | `50–90%`，默认 `70%`，步长 `5%` | 学生操纵 |
| 固定空气状态 | `空气 26°C · 气压 1010 hPa` | 只显示一次 |
| 海面饱和比湿 | `海面若饱和：xx.x g/kg` | `Lec.P.saturationSpecificHumidity(海温, 1010) × 1000` |
| 空气实际比湿 | `空气现有：xx.x g/kg` | `Lec.P.airSpecificHumidity(26, 相对湿度, 1010) × 1000` |
| 水汽缺口 | `可补给缺口：xx.x g/kg` | 前两项之差；本页范围内保持为正 |
| 过程标签 | `较暖海面` → `水汽缺口较大` → `蒸发补给潜力较大` | 末项只表达潜力，不写通量 |

参考口径：NOAA/AOML Tropical Cyclone Introduction；WMO 热带气旋教学资料。页面短标写 `NOAA/AOML；WMO`。

## 交互

学生拖动“海面温度”和“空气相对湿度”。海温升高时，海面饱和比湿量条伸长；相对湿度降低时，空气实际比湿量条缩短；差值括号及向上箭头同步增强。箭头只编码水汽缺口大小，不显示 `W/m²`。

支持方向键调整滑杆，实时读数带 `aria-live="polite"`；“恢复示例”回到 `29°C、70%`。无正确位置或得分，目标是比较“同湿度改海温”和“同海温改湿度”两种变化。

## 核对

| 参数 | 期望结果 |
|---|---|
| 海温 `29°C`、空气 `26°C`、`RH 70%`、`1010 hPa` | 海面约 `25.1 g/kg`；空气约 `14.6 g/kg`；缺口约 `10.4 g/kg` |
| 海温 `26°C`、`RH 90%` | 海面约 `21.0 g/kg`；空气约 `18.8 g/kg`；缺口约 `2.1 g/kg` |
| 海温 `31°C`、`RH 50%` | 海面约 `28.7 g/kg`；空气约 `10.4 g/kg`；缺口约 `18.3 g/kg` |

## 主工作流

design-interaction ← 双滑杆必须共同控制同一水汽缺口，并给出即时、可比较的因果反馈

## 不许碰

不得把海温称作台风移动的“方向盘”，路径机制归 p10。不得计算风速参与的海气焓通量或显示 `kW/m²`，该定量关系归 p05。
