# page-05 · 风与焓差共同抬高通量 · **115 秒**

## 照这个写

| 元素 | 文字 |
|---|---|
| kicker | `ENERGY SUPPLY` |
| 主标题 | 风越强、海气焓差越大，海面向上的焓通量越高 |
| 收束句 | 示例条件下，`30 m/s × 25 kJ/kg` 对应约 `1.0 kW/m²` 的向上焓通量。 |
| 下一问 | 如果风浪把海面下的冷水翻上来，这份供能还能维持多久？ |

## 知识结构：generalization

1. **关系不变量**：主张置于上方，经同一条 `.trunk` 连接公式与结果；风速、焓差两个可变输入必须同行、同尺度并共同汇入结果，固定参数作为第三条支撑附在公式下，不能与滑杆等权。
2. **禁止画法**：不得把两个滑杆拆成互不对齐的独立卡片，或画成“风速先造成焓差、焓差再造成通量”的串联因果。
3. **共享原语**：`.canvas-full.k-generalization` 承担整页主几何；`.claim` 放主张，`.trunk` 连接公式与总读数，`.supports` 并列承载两个输入和固定条件；读数使用 `.panel`、`.big/.num/.unit` 保持单位稳定。

## 表征形式

交互式海气焓通量仪表：上部为主张与公式，中部是海面—近海面空气双水平带及向上通量箭头，下部并列双滑杆，右侧显示即时数值。

使用原生 DOM 与 SVG；关系简单且需让箭头、公式和控件精确同步，无需图表库。SVG 使用固定线性尺度 `0–2.8 kW/m²` 映射箭头长度与线宽，海面和空气边界保持实线。每次 `input` 调用 `Lec.P.surfaceEnthalpyFlux` 后更新读数、箭头和刻度游标；状态变化通过 DOM 属性与 class 切换完成。

## 主工作流

design-interaction ← 双滑杆、公式计算与通量箭头必须即时保持同一数值口径

## 画面内容与计算口径

| 画面对象 | 显示文字或数值 | 口径 |
|---|---|---|
| 公式 | `Qₖ = ρ Cₖ V Δk` | `Qₖ` 为向上焓通量 |
| 风速滑杆 | `近海面风速 V`；`0–50 m/s` | 步长 `1 m/s`，默认 `30 m/s` |
| 焓差滑杆 | `海气焓差 Δk`；`0–40 kJ/kg` | 步长 `1 kJ/kg`，默认 `25 kJ/kg` |
| 固定条件 | `空气密度 ρ = 1.15 kg/m³` | 示例常量，写入画面 |
| 固定条件 | `交换系数 Cₖ = 0.0012` | 无量纲，写入画面 |
| 主读数 | `1.04 kW/m²`；旁标 `≈ 1.0 kW/m²` | 默认状态实时计算 |
| 图中标签 | `近海面空气`、`向上焓通量`、`暖海面` | 箭头只从海面向上 |
| 注记 | `这是海面向大气输送能量的速率，不等于台风风速的增加量。` | 常驻低干扰层 |
| 来源短标 | `Bulk aerodynamic flux；Emanuel 热带气旋热力学框架` | 页面底部短标 |

计算入口：`Lec.P.surfaceEnthalpyFlux(windSpeedMps, surfaceEnthalpyDifferenceJPerKg, 0.0012, 1.15)`；滑杆的 `kJ/kg` 调用前乘 `1000` 转为 `J/kg`，返回 `W/m²`，显示时除以 `1000`。

## 交互

学习者可独立拖动风速与焓差。当前值、公式代入项、主读数和向上箭头立即同步；任一输入为 `0` 时通量归零。拖动中的滑块、对应公式项及读数使用强调色，松开后只保留游标强调。

目标直觉是两项共同以乘法控制通量：固定其中一项，另一项加倍时通量加倍；不存在“正确位置”。提供“恢复示例”按钮，回到 `30 m/s` 与 `25 kJ/kg`；键盘方向键可按步长调节，触控命中区不小于 `44 px`。

## 核对

| 参数 | 期望结果 |
|---|---:|
| `V=30 m/s`，`Δk=25 kJ/kg` | `1035 W/m² = 1.035 kW/m²`，显示 `1.04` |
| `V=20 m/s`，`Δk=20 kJ/kg` | `552 W/m² = 0.552 kW/m²`，显示 `0.55` |
| `V=50 m/s`，`Δk=40 kJ/kg` | `2760 W/m² = 2.760 kW/m²`，显示 `2.76` |

## 不许碰

不得把焓通量解释为会全部转化成台风风速或保证台风增强；结构能否组织起来留给 p07。不得把暖海面或更大通量称为路径“方向盘”，移动机制由 p10–p11 负责。
