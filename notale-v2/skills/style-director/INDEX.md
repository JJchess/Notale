# 风格轻索引

40 项用户参考的入口。自动选样同时加载下表与完整小概览；选中后宿主预载对应详情、原参考图和中英字体声明，无需额外 Read 回合。明确匹配名称/ID 时直接预载详情。

每项详情区分核心特征、参考图观察、推荐与条件备选字体、可变表达、项目建议和来源，不是 CSS 配方、固定页型或继承层。用户要求优先，允许组合及表外方向。
