# Bento Grid · 便当盒布局

稳定 ID：`05-bento-grid`。本资料是创作参考，不是成品主题或固定版式。

## 核心特征

在共同网格中以不同尺度的区域组织内容，通过跨格、对齐和间距建立主次与关联。

这是布局方式，不是卡片组件库。区域可以通过留白、图像或对齐显现，不必有独立底板。

## 参考图观察

不等尺寸模块、跨格主次、块间对齐、统一间距。

## 可变表达

网格关系独立于配色和字体；不按模块平均分色，也不派生一套必用白底容器。

## 项目应用建议

### 构图与阅读

区域大小与跨格关系用于建立主次，Builder 按内容决定网格，不将其写入共享主题。交互区域保留连贯的操作空间。

### 形状与材质

优先由图像边界、对齐和区域间距呈现模块关系；必要的对象或控件可有局部外观，不提供给任意内容套用的白底圆角软影壳。网格组织不等于必须画网格或每区铺底色。

### 使用边界

不能因为选了 Bento 就把每句话放一个盒子；共享主题不写固定网格坐标。
