# 中文文案

按修辞动作判断，不按孤立词语判断；技术术语、正式名称和承担实义的用法放行。
删套话不改变数字、条件、因果、责任归属、否定和边界。单位、适用条件、必要图例和错误提示必须保留。

- 删开场铺垫和过渡废话，如“值得注意的是／众所周知／让我们看看／在当今时代／综上所述／换句话说／从某种意义上说”，直接给事实或结论。
- 删价值拔高骨架：“真正的 X 不是…而是…”“不仅仅…更是…”“最后比拼的是…”，保留具体判断。
- 无来源不写“研究表明／数据显示／有专家指出／据报道”等引用口吻；使用时给具体研究、数据、人物或媒体与时间。
- 长定语拆短句，被动堆砌改主动；“基于／通过…来／对于…而言／在…方面”能删则删。
- “至关重要／前所未有／意义非凡／深远影响”等程度词须有可验证的数字、对比或机制支撑，否则删掉。
- 不用“机制／体系／逻辑／路径”等抽象名词回避“谁对谁做了什么”。
- 操作标签和实时数值信息前置，8–14 个词（中文约 12–20 字）；错误反馈说明发生了什么、原因和下一步，不能只说“超出范围”。
- 步骤标签写实际动作，如“取一个样本”；不以“阶段一／步骤 2／Phase 01”代替内容，序号交给 CSS 计数器。
- 删重复解释、无信息括注和装饰性标签，说明贴近对象。Check 的次级文字比例只是复查提醒，不是配额；不得靠放大字号或加深颜色改善数字来代替删冗余。
- 按钮文案不塞 Unicode 方向箭头，如“继续 →”；必要的方向提示用图形元素。
- 不留 lorem ipsum、“特性一／示例内容／待补充”等占位文案；空白用构图和留白处理。
- 不写换题目也成立的口号标题，如“开启新篇章／重新定义／探索无限可能”；标题写本页要让读者相信的判断。
- 同一页画面文字里破折号最多一次；其余改句号或删冗余补语。
