# 配色禁用清单(讲义主题层)

判断看**整套配方**,不看单个颜色。紫色、米白、暗底、渐变、玻璃拟态单独出现都可能是对的选择;
问题是**没有经过选择就一起出现**。每条下面点名的是组合,不是孤立元素。

## 1. 奶油纸张 cream palette(最高频的默认)

判据可直接口算:

    min(R,G,B) ≥ 209   且   R ≥ G ≥ B   且   6 ≤ R−B ≤ 48

底色落进这个区间,**并且**同时出现下面两项以上,就是命中:

- 陶土/黄铜/赭石强调色(`#B08947` `#B6553A` `#9A2436` `#9C6E2A` `#BC7C3A` `#7D5621` 一族)
- espresso 暖近黑正文(`#1A1714` `#1A1814` `#1B1814` 一族)
- 大衬线标题,或某一个词用衬线斜体强调

暖米白在教室投影下会被环境光进一步冲淡,1px 细线和刻度字立不住;它还把画面推向
"editorial 随笔"语域,和"可操作的实验记录"是两件事。

**例外**:题目本身就是纸张、手稿、书籍史、饮食或手工艺时可以用，但必须能由题目解释，
不能只是因为它安全。

## 2. 青on暗底

近黑底 + 青色辅助色,再加下面任意两项:

- 中灰正文(对比度贴着及格线)
- 细白半透明边框(`rgba(255,255,255,.1)` 一族)
- 彩色外发光 / `backdrop-filter: blur()` 玻璃卡片

教室有环境光,暗底吞掉 1px 细线和小字号刻度;满画面发光会淹没"哪里是当前操作点"这个唯一该发光的信息。

**例外**:题目本身是夜空、深海、显微、辐射这类需要暗底的场景；选了暗底就同时禁掉发光。

## 3. 全死中性

所有中性 token(`--bg` `--paper` `--text` `--muted` `--rule` …)都是 `R=G=B`。

中性色要有一致的冷暖倾向,并且**整套只锁一种** —— 不许页面底色是暖灰、卡片是蓝灰、
正文是棕灰、边框又是纯中性灰。多套灰底调混在一起,画面会读成"逐个组件生成的"。

## 4. 胆小的平均分色

三个以上非语义色、饱和度和明度都接近、面积也接近,没有主色也没有真正的强调
(例:四个语义色色相 `207° 162° 28° 301°`,明度全挤在 `L=26–39%`)。

要的是**一个主色扛整页 + 一个小面积的锐利强调**。强调色在单页里的面积按 5% 左右当警戒线。
颜色的层级要和内容的层级对上:主张比支撑重,当前操作点比静态读数重。

## 5. 渐变与发光

- **渐变标题文字**:`background-clip:text` + `color:transparent`。任何主题都不用。
  强调用字重、字号或换一个语义色,不用渐变填色。
- **彩色外发光**:`box-shadow` 带饱和色、零偏移、blur > 4px。发光要么什么都不说,
  要么和"当前焦点"抢同一个信号。
- **整页 Aurora / mesh gradient / 漂浮模糊光球当主题底子**:装饰性形状必须能说出它在图解什么。
- 需要渐变时优先**同色相 tonal 渐变**,而不是两个不同色相之间的"信任渐变"
  (紫→蓝、蓝→青、靛→粉都在此列)。

## 6. 框架默认色板

不许直接用这几个 Tailwind/shadcn 原始色值当强调色:

    #6366F1  #4F46E5  #4338CA  #3730A3  #8B5CF6  #7C3AED  #A855F7

也不许把 `zinc` / `slate` 的默认灰阶原样当中性系统。**禁的不是这些颜色本身**,
是"没做选择就用了框架的 demo 配色"。

## 7. 状态色与默认配方

`success/warning/error` 只用于稳定状态，不装饰普通元素；一个色相只代表一个概念。
答题的选中与正确性分开，不默认红绿对错。

禁的是未经选择的配方，不是某个色相；换 hex 后仍平均分色、暖米白或无语义发光，仍算命中。
不存在安全色，任何配色都必须能由课程内容解释。
