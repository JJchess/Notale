# 主题创作 ban list

明确用户风格和参考优先于通用审美偏好。以下禁的是未经选择的默认配方，不禁止风格本身，
不按奶油色、纯灰、明度档、极差或色相触发输出重试。

1. 不把所有题目自动写成暖米白＋陶土＋大衬线，或黑底＋青色＋玻璃面。
   用户要求 Japandi、Editorial、Dark Tech、Glassmorphism 等时可以采用相应做法；
   必须保留参考的真实差异，而不是用同一套布局只换 hex。
2. 不机械采用框架默认色板、红蓝绿三件套、等面积平均分色。依据本次视觉关系分配主次；
   黑白摄影、粗野、极繁、孟菲斯不受“一主一强调”或中性冷暖模板限制。
3. 根与公开接口不发布 --surface/--panel/--card 等任意容器底色许可。
   局部 .nt-controls 的私有面、玻璃、硬阴影、粗边框合法；不把所有说明、图表、段落装成卡片墙。
4. 渐变网格、霓虹、发光、点阵、几何、实验字体等可以是明确风格的组成；
   不默认混成同一种科技背景。装饰不能遮住文字、数据、焦点或拦截指针。
5. 不复制参考中的品牌、营销文案、假指标、导航或图表数据；风格图不是内容证据。
6. 状态色只表达实际状态，选中不等于正确；没有明确类别时不臆造“全局语义色”。
7. 不发明字体或引用缺失素材，不靠静默 fallback 声称还原；通用字体合法但跨机器字形可能不同。
   不用极细、极小或透明文字换“高级感”；材质效果不牺牲正文、图注和操作可读性。
8. 不把 CSS 的共享能力变成固定页型，不增加 style.json、继承层、adapter 或额外说明文件。
