# 视觉禁用清单

这份清单管的是**具体、可判断的形状**,不是"要有品味"这种原则性要求。检查方式是渲染后逐条比对,不是设计前默念清单。命中判断看形状而非孤立元素:一个元素单独出现通常正常,遇到下面点名的具体组合才是问题。标题渐变填色/彩色外发光是配色决定,正本在 `scrub-theme-slop.md`,此处不留副本。

## 检查顺序

1. 先看第一屏/整页截图有没有落进下面某个具体形状(悬挂式表头、假 UI 边框、装饰性图表)。
2. 再核对数字:画面上的每一个数字要么来自本页规格,要么是页面当场算出的真实结果。不能为了填充布局或让图表"看起来有内容"编一个演示数字;编不出真数据就删掉该图形。

**1. 大标题斜体冒充编辑排版**(`font-style: italic` 用在 h1–h6 或页面主标题上)
标题保持正体;需要强调时用字重、强调色或下划线,斜体只用于正文中的强调词。

**2. 无语义锚点的漂浮光斑/极光装饰**
页面上自己加的装饰性形状必须能说出它在图解什么;说不出就删掉。

**3. emoji 顶替图标系统**(✨🚀⚡🔥🎯✅ 当功能图标使用)
用统一线宽/风格的图标库或自绘 SVG,不用 emoji 凑图标。

**4. 一页混用不同图标库或线宽**
一页只用一套图标语言。

**5. 手绘假浏览器/手机/IDE 边框包真实截图**
需要展示界面截图或设备画面时,直接用真实截图配 `.cvbox`(定位、圆角、裁切),不要用 HTML/CSS/SVG 画一个假的浏览器地址栏、手机边框或代码编辑器窗口。

**6. sparkline/进度环/圆角方块充当"内容"而非真数据**
教学页的图表必须来自真实数据或当场算出的结果,不能用装饰性的迷你图形冒充数据存在。

**7. 不发明 kicker；必要标签的两条形状禁令**

默认不在标题上方添加英文同义词、小型大写眉题、页型名或章节名(例如把中文标题再翻译一遍做成
`ENSEMBLE LEARNING · BOOSTING`),也不写只为占空位的课程名、版本或制作说明。只有本页规格
明确要求、且该标签带来标题之外的真实分类或状态信息时才显示；删掉后意义不变就删掉。
显示时仍须满足:kicker 不得做成带边框的徽章/胶囊(bordered badge/pill)——那是"NEW/BETA/LIVE"状态徽章的
落地页视觉语言,和 kicker 在页面里"页面定位标签"的功能无关。kicker 只用文字处理(颜色、字重、字间距),
不套矩形或圆角矩形边框。

页码、总页数、章节数、deck 名称等宿主元数据也不得被做成顶栏、底栏、角标、进度轨道或装饰性
信息条；它们留在 HTML 属性和宿主导航中，不进入 `#stage` 的可见构图。

**8. 用几何色块拼贴冒充插画**
同一个 SVG 里 ≥3 种不同纯色 fill 的圆/方/三角拼在一起、不构成真实图形关系。图必须图解具体关系或对象;拼不出就不画,用文字或表格。

**9. 弹跳/回弹缓动**
`animation` 名字里带 `bounce`/`elastic`/`wobble`/`spring`,或 `cubic-bezier` 控制点越界(y < -0.1 或 y > 1.1)。**过冲给运动加物理暗示,而那个量并不弹。**用线性或标准缓出。

**10. 脉冲圆点 / 闪烁光标当装饰**
无限循环的呼吸小圆点(`● live`)、模拟打字的闪烁竖线。表示"当前步骤"就一次性播完,不做无限循环。

**11. 重复条纹/网格当背景纹理**
`repeating-linear-gradient` 铺的斜纹、点阵或网格底。它和图表里真正的网格线抢"哪条线有意义"。
