# 视觉禁用清单

渲染后按具体形状检查，判断组合及作用，不禁孤立元素。数据真实性由技术契约约束。

1. 标题不靠斜体冒充编辑排版；强调用字重、语义色或下划线，正文强调词可用斜体。
2. 不加无语义锚点的漂浮光斑、极光或装饰形状；每个形状须图解具体对象或关系。
3. 功能图标不用 emoji；统一图标库或自绘 SVG 的风格和线宽。
4. 界面或设备画面直接用真实截图并按需定位、圆角、裁切；不另画假浏览器地址栏、手机或 IDE 外壳。
5. sparkline、进度环等必须承载真实数据或计算结果，不充当装饰性“内容”。
6. 默认不发明 kicker：英文同义眉题、页型名、章节名、课程名、版本或制作说明。仅当规格要求且提供标题之外的分类或状态信息时显示；用文字处理，不套带边框的徽章或胶囊。页码、总页数、章节数等宿主元信息留在 HTML 属性和宿主导航，不进入画面。
7. 不用 ≥3 种纯色的圆／方／三角拼贴冒充插画；几何必须表达真实对象或关系，否则改用文字或表格。
8. 不用 bounce／elastic／wobble／spring 弹跳缓动或 y < -0.1、y > 1.1 的 cubic-bezier 控制点；用线性或标准缓出。
9. 不用无限呼吸圆点或闪烁光标作装饰；当前步骤提示一次性播完。
10. 不用 repeating-linear-gradient 斜纹、点阵或网格作背景；网格线只属于真实坐标系或图表。
