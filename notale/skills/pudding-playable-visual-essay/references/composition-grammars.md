# Composition Grammars

Choose one primary grammar. Combine only when the same dominant visual object remains in control.

## Visual world

Use when one spatial, material, or model system can carry the page. Establish stable coordinates and
object identities, then vary focus, scale, state, participation, or interpretation without replacing the
whole scene.

## Hero model

Use for a manipulable system, map, grid, mechanism, or simulation. Give the model most of the frame;
attach direct labels and quiet controls to it instead of wrapping it in an application panel.

## State sequence

Use when the same model explains the claim through two or more computed states. Keep geometry and IDs
stable. Change emphasis, path, ordering, subset, result, or trace; make every state reproducible from
explicit state rather than previous animation history.

## Data field

Use when quantity, distribution, diversity, or accumulation is the argument. Repeated marks share a
scale and become a field. Highlight only the subset needed for the claim; avoid turning observations
into a grid of mini-cards.

## Annotated model

Use when one object explains the lesson through spatial details. Keep two to four annotations near their
targets, align them to a few invisible rails, and prefer short leader lines over a detached legend.

## Statement with evidence

Use when one decisive claim can be established by one comparison, statistic, path overlay, annotated
chart, or measured artifact. Treat the evidence as the dominant object rather than surrounding it with
unrelated metrics.
