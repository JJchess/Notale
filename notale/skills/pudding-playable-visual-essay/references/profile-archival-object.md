# Family: Archival Object

Use when primary sources, menus, letters, maps, manuscripts, ads, newspapers, specimens, or historical objects are the evidence.

## Visual DNA

- artifacts are treated as objects with scale, edge, wear, caption, provenance
- warm/neutral field, restrained accent, museum-like or book-like typography
- cropping and magnification turn details into visible evidence
- annotation lines should feel curatorial, not dashboard-like

## Composition

- full artifact establish: 50–80% canvas
- detail crop: 65–95% canvas
- annotation labels <= 4 per frame
- provenance/caption remains visually quiet

## Never

- fake paper textures stronger than the source itself
- excessive sepia filters
- replacing authentic artifacts with AI-generated "historical" imagery when sources exist
