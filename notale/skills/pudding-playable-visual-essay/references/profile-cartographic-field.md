# Family: Cartographic Field

Use for geography, distribution, movement, place, spatial memory, or many observations across a territory.

## Visual DNA

- map/field is the canvas, not a chart inside a panel
- data marks become visual texture at scale
- local labels appear only where story demands
- zoom level is a narrative device

## Composition

- map coverage 65–100%
- copy can float in clear regions of the field
- legends should be embedded/direct where possible
- geographic shapes may bleed beyond slide edges

## Never

- tiny choropleth inside a card with a giant legend
- pan/zoom purely for spectacle
