# Family: Graphic Editorial

Use for arguments driven by a strong claim, chart, typographic statement, comparison, or a sequence of evidence without a literal world model.

## Visual DNA

- extreme hierarchy, confident typography, disciplined grid, direct annotation
- one visual proof per page state
- images/charts can bleed or collide with type intentionally
- colors are semantic, not decorative

## Composition

- hero claim: 72–144px display text
- visual 45–75%
- one major alignment axis plus one deliberate break
- avoid equal columns unless comparison semantics demand it

## Never

- corporate presentation templates
- three-card summaries
