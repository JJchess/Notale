# Family: Illustrated Journey

Use for intimate, embodied, emotional, biographical, medical, or life-course stories where the audience should feel accompanied through a path.

## Visual DNA

- authored illustration rather than generic iconography
- one coherent world with recurring characters/objects
- state changes feel like moving through one coherent place
- soft spatial depth, selective texture, intentional quiet
- text can be more present than in Playful System, but imagery remains the emotional anchor

## Composition

- 45–75% illustration
- keep text blocks narrow enough that the illustration remains the emotional anchor
- character and object placement should create a clear reading direction
- preserve intentional quiet around emotionally important evidence

## Never

- stock healthcare illustrations
- identical speech-bubble cards
- cheerful colors when emotional tone requires restraint
