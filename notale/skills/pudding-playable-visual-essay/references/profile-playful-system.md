# Family: Playful System

Use when the subject can become a game board, map, network, mechanism, grid, simulation, or manipulable object.

## Visual DNA

- The model is the artwork.
- Geometry is simplified enough to invite action, but specific enough to encode real meaning.
- Use chunky or characterful marks, visible path states, direct labels, and a small palette with one high-energy accent.
- Playfulness must emerge from state/action, not stickers.

## Composition

- world occupies 60–88% of the slide during interactive beats
- controls <= 10% of visual area
- copy typically 1 headline + 0–2 short lines
- allow purposeful asymmetry and edge bleed

## Implementation

Prefer SVG for exact nodes and paths and HTML for copy and controls. Canvas is allowed for many
particles or agents. If a reader trace matters, preserve it in memory and annotate its computed result
within this page.

## Never

- wrap the system in a dashboard card
- use progress bars unrelated to the world
- detach the user's result into a generic KPI panel
