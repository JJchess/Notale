# Family: Scrapbook Pop

Use for fandom, youth culture, personal memory, music, identity, cultural eras, media history.

## Visual DNA

- collage of photographs, covers, labels, hand-drawn marks, stickers, stars, tape, paper scraps, UI fragments
- controlled abundance: many elements, but one dominant hierarchy
- era changes may shift accent palette/texture while preserving the master system
- typography can be louder and more playful than normal editorial work

## Composition

- allow overlap and rotation within strict bounds
- 1 dominant media object, 2–5 supporting artifacts
- keep at least one clean negative-space corridor for copy
- artifact clusters should form a silhouette, not scatter randomly

## Never

- random decorative stickers with no cultural/semantic tie
- every element rotated differently
- scrapbook treatment on charts that require precise comparison
