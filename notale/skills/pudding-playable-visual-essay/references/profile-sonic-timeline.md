# Family: Sonic / Temporal Timeline

Use for music, speech, recurring motifs, time-series narratives, repeated events, sequences where recurrence matters.

## Visual DNA

- time axis is a stage
- recurring motifs keep a stable visual identity
- sound controls are subordinate and tightly integrated
- use state or interaction to reveal recurrence rather than showing an unreadable dense timeline

## Composition

- timeline/waveform coverage 55–90%
- use stable horizontal geometry across states
- direct-highlight the current event; dim the rest

## Never

- equal emphasis on every timestamp
- detached audio-player chrome dominating the page
