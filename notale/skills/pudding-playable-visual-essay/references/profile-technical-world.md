# Family: Technical World

Use for mechanisms, engineering, code, physics, biology systems, algorithms, scientific apparatus.

## Visual DNA

- exact geometry + editorial art direction
- diagram objects have stable identities and persistent coordinates
- semantic color is sparse
- labels are direct and spatially attached
- can borrow blueprint, lab notebook, oscilloscope, terminal, or scientific-illustration material language when causally appropriate

## Composition

- model 55–85%
- annotation labels 2–6
- equations/code are treated as visual objects, not paragraphs

## Never

- boxes-within-boxes architecture diagrams by default
- decorative circuit-board backgrounds
