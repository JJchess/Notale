# 数据结构：从树到图

本讲义面向具备基础编程经验的学习者，目标是建立关系型数据结构的统一视角。

- 节点承载对象，边表达对象之间的关系。
- 树是连通且无环的层级结构，除根节点外每个节点只有一个父节点。
- 深度优先搜索沿分支深入，广度优先搜索按距离逐层扩展。
- 二叉搜索树用有序性支持查找；平衡机制限制树高。
- 堆只维护父子优先级，不维护全局有序。
- 图允许多入口、环与多重路径，适合描述网络关系。
- 邻接表适合稀疏图，邻接矩阵适合稠密图或常数时间查边。
- 算法选择应同时考虑结构约束、核心操作、数据规模与更新模式。

## 教学原则

- 每页只回答一个核心问题。
- 先识别关系，再选择结构，最后选择算法。
- 复杂度是结构与操作共同作用的结果。
- 可视化必须忠实呈现节点、边和遍历顺序。
