# 课程任务

为计算机专业初学者制作一套 36 页中文讲义，系统讲清线性结构与半线性结构。这里的“半线性结构”采用本课程的操作性定义：树状层级中，一个结点可以有多个直接后继，但除根结点外通常只有一个直接前驱；它介于一对一线性关系与任意多对多图关系之间。这不是所有教材统一使用的分类名，第一页必须主动说明口径。

# 学习结果

- 能区分逻辑结构、存储结构与抽象数据类型。
- 能比较顺序表与链表在访问、插入、删除和空间局部性上的代价。
- 能解释栈、队列、双端队列的约束如何塑造算法行为。
- 能用不变量理解括号匹配、表达式求值、搜索边界和缓冲处理。
- 能掌握树、二叉树、遍历、二叉搜索树与堆的核心关系。
- 能依据操作频率、数据规模和结构关系选择合适的数据结构。

# 建议叙事范围

1. 数据结构解决的不是“存什么”，而是“关系与操作如何约束成本”。
2. 逻辑结构、物理结构、ADT 与复杂度的四层视角。
3. 线性表、数组、顺序表、链表及其变体。
4. 栈、队列、循环队列、双端队列与典型应用。
5. 串、数组、稀疏矩阵与广义表的线性边界。
6. 从线性到半线性：层级关系为什么需要树。
7. 树与二叉树术语、性质、存储和遍历。
8. 二叉搜索树、堆与选择策略。

# 内容边界

- 不把“大 O”当作实测时间；必须说明模型、输入规模与操作前提。
- 不声称链表插入永远是 O(1)：若需先定位结点，查找成本必须计入。
- 不把完全二叉树、满二叉树、平衡树混为一谈。
- 代码只在讲者备注中给出短伪代码；成片优先用操作路径与关系图，避免图像模型伪造代码。
- 图结构只作为边界对照，不展开成完整图论课程。

# 视觉方向

视觉应像优秀算法教材、工程蓝图和数据流实验的结合。可使用节点、指针、缓冲区、轨道、堆叠物、层级分叉和内存带等原创隐喻；避免网页 UI、终端截图、代码墙、霓虹黑客风和无意义卡片阵列。
