# HTTP 请求生命周期

本讲义用分层视角解释一次浏览器请求如何抵达服务器并返回结果。

- 域名解析把人类可读的名称转换为网络地址。
- 建立连接为双方创建可靠或加密的通信通道。
- HTTP 请求携带方法、路径、首部和可选消息体。
- 服务器处理请求并返回状态、首部和响应内容。
- 缓存命中可以直接复用仍然新鲜的响应，避免访问源站。
- 缓存未命中或内容过期时，需要重新访问源站并更新缓存。
- 排查故障时应依次检查地址、连接、协议和应用处理。

## 教学原则

- 一页只解释一个主路径或判断。
- 图形必须体现方向、分支与层次变化。
- 文字保持短而准确，不使用伪代码或无意义协议字段。
