# 课程任务

为大学文学课程与深度阅读者制作一套 36 页中文讲义，讨论意识流文学的基本机制，并以《百年孤独》为主要案例进行赏析。课程必须避免把《百年孤独》简单归类为典型意识流小说：它通常首先被讨论为魔幻现实主义与拉丁美洲“文学爆炸”的代表，但其时间循环、记忆涌现、感知转换和叙述意识仍可与意识流方法形成有边界的比较。

# 学习结果

- 能区分意识流作为心理学隐喻、叙事方法和文学史标签的不同层次。
- 能识别内心独白、自由间接引语、联想跳跃、感觉蒙太奇和时间非线性。
- 能解释《百年孤独》中循环时间、家族重名、集体失忆、预言文本与重复命运的结构作用。
- 能区分个体意识流与家族/共同体记忆的叙述效果。
- 能将魔幻现实主义、神话时间、历史创伤和现代性经验放入同一分析框架。
- 能提出有证据的赏析判断，而不是复述情节或套用“魔幻”标签。

# 建议叙事范围

1. 意识流是什么、又不是什么。
2. 心理时间、叙述时间与线性因果的松动。
3. 内心独白、自由间接引语、联想与感觉组织。
4. 《百年孤独》的叙述声音、马孔多和布恩迪亚家族结构。
5. 时间循环、重名、记忆与遗忘。
6. 日常与超自然并置如何建立魔幻现实主义的可信度。
7. 个体意识、集体历史和拉丁美洲经验的交汇。
8. 细读方法：叙述人称、时间信号、意象复现、因果断裂与结构回声。

# 内容与版权边界

- 不大段引用小说原文；以概述、释义和结构分析为主。
- 如需引用，只使用极短短语，并在讲者备注中标注版本与来源。
- 不复制现有书封、影视画面、插画或艺术家的独特风格。
- 不把作者生平简化成作品的唯一解释。
- 允许讨论结局和完整结构；开篇应提示包含剧透。

# 视觉方向

视觉应像文学批评季刊、拉丁美洲档案和梦境地理图谱的结合。可使用原创的热带植物、旧宅、雨幕、铁路、手稿、家族树、圆环时间、冰与黄色蝶群等象征，但不能重现书封或影视分镜。文字克制，依靠意象与结构关系建立气氛。
